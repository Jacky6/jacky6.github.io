    从零实现 MCP Client¶

    生产项目应优先使用官方 SDK。本章先给出 SDK 版，再手写一个教学版 Modern stdio Client，目的是看清版本、元数据、请求 ID、分页和 Tool 调用的真实过程。

    1. Client 在 Host 中的位置¶

    Host
├── Conversation / LLM Provider
├── Permission & UI
├── Tool Registry
└── MCP Client Manager
    ├── Client A → Server A
    └── Client B → Server B

    一个完整 Client 需要：

    • Transport；
    • 版本与能力处理；
    • Request ID 生成器；
    • 并发 Pending Map；
    • Tool/Resource/Prompt API；
    • 分页与缓存；
    • MRTR；
    • 订阅、进度和取消；
    • OAuth；
    • 超时、重试和可观测性。

    2. 使用 Python SDK¶

    安装：

    uv init mcp-client
cd mcp-client
uv add "mcp>=2.0.0"

    Python SDK v2 要求 Python 3.11+。最小 stdio Client：

    import asyncio
import sys

from mcp import Client, StdioServerParameters
from mcp.types import TextContent


async def main(server_script: str) -> None:
    params = StdioServerParameters(
        command=sys.executable,
        args=[server_script],
    )

    async with Client(params) as client:
        print("protocol:", client.protocol_version)
        print("capabilities:", client.server_capabilities)

        tool_page = await client.list_tools()
        print("tools:", [tool.name for tool in tool_page.tools])

        result = await client.call_tool(
            "search_documents",
            {"query": "MCP", "limit": 5},
        )

        text = "\n".join(
            block.text
            for block in result.content
            if isinstance(block, TextContent)
        )
        print("is_error:", result.is_error)
        print("text:", text)
        print("structured:", result.structured_content)


if __name__ == "__main__":
    asyncio.run(main(sys.argv[1]))

    运行：

    uv run client.py /ABSOLUTE/PATH/server.py

    SDK 通常会处理：

    • 启动和关闭子进程；
    • Modern/Legacy 协议选择；
    • 每请求 _meta；
    • JSON-RPC ID；
    • 消息分帧；
    • Result 类型；
    • Tool Result 内容类型。

    不要通过“Client 没抛异常”判断 Tool 成功，必须检查 result.is_error。

    3. MCP Tool 怎样接入 LLM¶

    MCP 与模型 Tool Calling 之间需要适配：

    mcp_tools = await client.list_tools()

provider_tools = [
    {
        "name": tool.name,
        "description": tool.description,
        "input_schema": tool.input_schema,
    }
    for tool in mcp_tools.tools
]

    通用循环：

    1. MCP tools/list
2. 转换为 Provider Tool Schema
3. 用户消息 + Tools → LLM
4. LLM 返回 tool_use(name, arguments)
5. Host 做权限确认
6. MCP tools/call
7. Tool Result → Provider Tool Result Message
8. 再次调用 LLM
9. 重复直到模型返回最终文本

    Host 还需要保存 Tool 来源映射：

    public tool name → (MCP Client, original server tool name)

    多 Server 都提供 search 时，可以暴露为 github.search、docs.search，但调用 Server 时仍使用其原始名称。

    4. 教学版 Modern stdio Client¶

    下面实现只支持：

    • 2026-07-28；
    • stdio；
    • 同步单请求；
    • server/discover；
    • tools/list 分页；
    • tools/call。

    它不支持 OAuth、订阅、MRTR、并发和 Legacy 回退，因此不能直接作为生产 Client。

    from __future__ import annotations

import json
import subprocess
import threading
from typing import Any


class MCPError(RuntimeError):
    pass


class ModernStdioMCPClient:
    PROTOCOL_VERSION = "2026-07-28"

    def __init__(self, command: str, args: list[str] | None = None):
        self.command = command
        self.args = args or []
        self.process: subprocess.Popen[str] | None = None
        self.next_id = 0
        self.client_capabilities: dict[str, Any] = {}
        self.server_capabilities: dict[str, Any] = {}
        self.supported_versions: list[str] = []

    def start(self) -> None:
        self.process = subprocess.Popen(
            [self.command, *self.args],
            stdin=subprocess.PIPE,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
            text=True,
            encoding="utf-8",
            bufsize=1,
        )
        threading.Thread(target=self._drain_stderr, daemon=True).start()

    def close(self) -> None:
        if self.process is None or self.process.poll() is not None:
            return

        assert self.process.stdin is not None
        self.process.stdin.close()
        try:
            self.process.wait(timeout=5)
        except subprocess.TimeoutExpired:
            self.process.terminate()
            try:
                self.process.wait(timeout=5)
            except subprocess.TimeoutExpired:
                self.process.kill()
                self.process.wait(timeout=5)

    def discover(self) -> dict[str, Any]:
        result = self.request("server/discover")
        self.supported_versions = result.get("supportedVersions", [])
        self.server_capabilities = result.get("capabilities", {})
        return result

    def list_tools(self) -> list[dict[str, Any]]:
        self._require_server_capability("tools")
        tools: list[dict[str, Any]] = []
        cursor: str | None = None

        while True:
            params: dict[str, Any] = {}
            if cursor is not None:
                # 空字符串也是合法 Cursor，不能写成 if cursor。
                params["cursor"] = cursor

            page = self.request("tools/list", params)
            tools.extend(page.get("tools", []))

            if "nextCursor" not in page or page["nextCursor"] is None:
                break
            cursor = page["nextCursor"]

        return tools

    def call_tool(self, name: str, arguments: dict[str, Any]) -> dict[str, Any]:
        self._require_server_capability("tools")
        return self.request(
            "tools/call",
            {"name": name, "arguments": arguments},
        )

    def request(
        self,
        method: str,
        params: dict[str, Any] | None = None,
    ) -> dict[str, Any]:
        self.next_id += 1
        request_id = self.next_id
        request_params = dict(params or {})
        request_params["_meta"] = self._request_meta()

        self._send(
            {
                "jsonrpc": "2.0",
                "id": request_id,
                "method": method,
                "params": request_params,
            }
        )

        while True:
            message = self._read()

            if message.get("id") == request_id:
                if "error" in message:
                    error = message["error"]
                    raise MCPError(
                        f"{error.get('code')}: {error.get('message')} "
                        f"data={error.get('data')}"
                    )
                if "result" in message:
                    result = message["result"]
                    result_type = result.get("resultType", "complete")
                    if result_type == "input_required":
                        raise MCPError(
                            "This teaching client does not implement MRTR"
                        )
                    if result_type != "complete":
                        raise MCPError(f"Unsupported resultType: {result_type}")
                    return result

            self._handle_notification(message)

    def _request_meta(self) -> dict[str, Any]:
        return {
            "io.modelcontextprotocol/protocolVersion": self.PROTOCOL_VERSION,
            "io.modelcontextprotocol/clientInfo": {
                "name": "teaching-client",
                "version": "1.0.0",
            },
            "io.modelcontextprotocol/clientCapabilities": self.client_capabilities,
        }

    def _send(self, message: dict[str, Any]) -> None:
        if self.process is None or self.process.stdin is None:
            raise MCPError("Client has not been started")

        line = json.dumps(
            message,
            ensure_ascii=False,
            separators=(",", ":"),
        )
        self.process.stdin.write(line + "\n")
        self.process.stdin.flush()

    def _read(self) -> dict[str, Any]:
        if self.process is None or self.process.stdout is None:
            raise MCPError("Client has not been started")

        line = self.process.stdout.readline()
        if line == "":
            raise EOFError("MCP Server closed stdout")
        try:
            return json.loads(line)
        except json.JSONDecodeError as exc:
            raise MCPError(f"Invalid stdout message: {line!r}") from exc

    def _handle_notification(self, message: dict[str, Any]) -> None:
        if "method" in message and "id" not in message:
            # 生产实现应按 method 处理 progress、logs 和 subscription events。
            return
        raise MCPError(f"Unexpected MCP message: {message}")

    def _require_server_capability(self, name: str) -> None:
        if name not in self.server_capabilities:
            raise MCPError(f"Server did not advertise capability: {name}")

    def _drain_stderr(self) -> None:
        if self.process is None or self.process.stderr is None:
            return
        for line in self.process.stderr:
            # 生产实现应写入结构化日志并脱敏。
            print(f"[server stderr] {line}", end="")

    def __enter__(self) -> "ModernStdioMCPClient":
        self.start()
        return self

    def __exit__(self, *_: object) -> None:
        self.close()


if __name__ == "__main__":
    with ModernStdioMCPClient("python", ["server.py"]) as client:
        info = client.discover()
        print("server:", info)
        print("tools:", client.list_tools())
        print(
            "result:",
            client.call_tool(
                "search_documents",
                {"query": "MCP", "limit": 5},
            ),
        )

    5. 代码体现的协议原则¶

    5.1 一行一消息¶

    self.process.stdin.write(json.dumps(message) + "\n")

    不是 Content-Length，也不能在 stdout 混入日志。

    5.2 每请求元数据¶

    request_params["_meta"] = self._request_meta()

    Modern Server 不会记住上一次 Request 的版本和能力。

    5.3 Request ID¶

    self.next_id += 1

    每个未完成请求 ID 唯一。生产并发版需要：

    reader task + pending[id] = Future

    不能在每个 Request 中各自同步读 stdout，否则多个协程会争抢同一流。

    5.4 Cursor 不透明¶

    if cursor is not None:

    空字符串 Cursor 仍然有效。Client 不解析、不修改 Cursor。

    5.5 Result 类型¶

    缺少 resultType 按 Legacy 兼容规则当成 complete；未知值必须拒绝；input_required 进入 MRTR，而不是当成最终 Tool Result。

    5.6 stderr 必须持续消费¶

    如果子进程持续写 stderr，而 Client 从不读取，OS Pipe Buffer 可能写满并阻塞 Server，表现为“协议突然卡死”。

    6. 生产并发架构¶

    graph TD
    API[Client API] --> W[Writer Lock]
    W --> T[Transport]
    T --> R[Single Reader Task]
    R --> D{Dispatch}
    D -->|Response id| P[pending id → Future]
    D -->|Progress| G[Progress Handler]
    D -->|Subscription| S[Subscription Handler]

    必备组件：

    • 唯一 Reader Task；
    • 写锁或原子消息队列；
    • Pending Map；
    • 每请求 Timeout；
    • 取消；
    • EOF/崩溃时让所有 Pending Future 失败；
    • 最大消息大小；
    • Backpressure；
    • 重连与订阅恢复。

    7. Modern / Legacy 回退¶

    手写 Dual-era stdio Client：

    server/discover (Modern _meta)
    ├─ DiscoverResult → Modern
    ├─ UnsupportedProtocolVersion → Modern，选共同版本
    └─ 其他错误/超时 → Legacy initialize

    不能仅把 -32601 当回退条件，因为旧实现可能返回 -32602、自定义错误或不响应。

    生产项目应使用官方 SDK 的兼容处理，而不是复制一套易错状态机。

    8. MRTR Client 算法¶

    async def call_with_mrtr(method, params, max_rounds=4):
    request_state = None
    input_responses = None

    for _ in range(max_rounds):
        current = dict(params)
        if request_state is not None:
            current["requestState"] = request_state
        if input_responses is not None:
            current["inputResponses"] = input_responses

        result = await request(method, current)  # 每轮新 ID
        if result["resultType"] == "complete":
            return result

        request_state = result.get("requestState")
        input_responses = await fulfill_input_requests(
            result.get("inputRequests", {})
        )

    raise RuntimeError("MRTR round limit exceeded")

    真实实现还必须：

    • 检查 Server 是否请求了未声明能力；
    • 原样回传 requestState；
    • 支持用户 decline/cancel；
    • 限制输入请求大小；
    • 防止重复 URL 打开；
    • 对敏感 URL Elicitation 要求用户确认。

    9. Tool Registry 与上下文成本¶

    天真实现会把所有 Server 的全部 Tool Schema 放进模型上下文。Server 多时应采用：

    • 稳定命名空间；
    • Tool Catalog 索引；
    • 关键词/BM25/Embedding 检索；
    • 只注入 Top-K 完整 Schema；
    • 缓存 tools/list；
    • 收到 tools/list_changed 后刷新索引；
    • 根据 Context Window 占比阈值切换渐进式发现。

    官方建议可从 Tool Schema 占上下文约 1%–5% 时开始评估渐进式发现。

    10. Tool 调用安全¶

    Host 在调用前应判断：

    • Server 是否可信；
    • Tool 是否只读或有副作用；
    • 参数是否含用户秘密；
    • Tool Result 是否会流向另一个 Server；
    • 是否需要用户确认；
    • 是否超出当前任务授权范围。

    Tool Annotation 只是 Server 提供的提示，不能作为安全事实。

    Client 还应：

    • 对 Tool Result 限长和类型校验；
    • 把 Tool Result 与 System Instructions 隔离；
    • 记录 Server、Tool、参数摘要、用户批准和结果状态；
    • 避免把 Access Token 交给 LLM 或 Tool 参数；
    • 对跨 Server 数据流重新确认权限。

    11. 重试策略¶

    请求 是否适合自动重试
    server/discover 是，指数退避
    tools/list / resources/list 是
    resources/read 通常是
    只读 Tool 视业务而定
    写 Tool 只有明确幂等键时
    已返回部分副作用的 Tool 否，先查询状态
    MRTR Retry 按协议重试，不等价于网络重试

    网络断开时不知道 Server 是否已执行写操作。没有幂等键就盲重试，可能创建两份订单或重复扣款。

    12. Client 测试清单¶

    • Modern Discover 与版本错误重试
    • Legacy 回退（如需要）
    • 乱序响应
    • 重复、未知和迟到 ID
    • 非法 stdout 消息
    • Server EOF、崩溃与重启
    • 分页，包括空字符串 Cursor
    • isError: true
    • Text/Image/Audio/Resource/Structured Result
    • MRTR 多轮、拒绝、取消和轮数上限
    • Progress 限频
    • stdio 与 HTTP 取消差异
    • 订阅确认、断开与重建
    • TTL 和通知缓存失效
    • Tool 名冲突
    • Prompt Injection 与超大结果
