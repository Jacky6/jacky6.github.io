    Perception 感知层¶

    Agent 的"眼睛和耳朵"——处理多模态输入、环境感知、信息提取。

    1. 模块定位¶

    Perception 是 Agent 与外部世界交互的第一道关口。它负责：

    • 接收 各类输入（文本、图片、音频、视频、结构化数据、网页等）
    • 理解 输入内容（多模态理解、语义解析、实体识别）
    • 提取 关键信息（摘要、关键实体、意图分类）
    • 路由 到合适的下游模块（memory / reasoning / planning）
    外部世界
    │
    ├── 文本输入  ────┐
    ├── 图片输入  ────┤
    ├── 音频输入  ────┼──→  Perception  ───→  结构化理解  ───→  下游模块
    ├── 网页/文件 ────┤
    ├── API 数据 ─────
    └── 传感器/环境 ──┘

    2.1 多模态输入处理¶

    输入类型 处理方式 典型工具
    文本 直接输入，无需特殊处理 -
    图片 视觉模型解析 (Vision-Language Model) GPT-4V, CLIP, Qwen-VL
    音频 语音识别 → 文本 Whisper, FunASR
    视频 抽帧 → 视觉模型 同上 + 视频抽帧工具

    网页 HTML 解析 + 内容提取 Playwright, BeautifulSoup
    PDF/Word 文档解析 + OCR PyMuPDF, python-docx

    3. LangGraph 实现示例¶

    3.1 多模态感知节点¶

    from typing import TypedDict, Literal
from langgraph.graph import StateGraph, END
from langchain_core.messages import HumanMessage, AIMessage
from langchain_openai import ChatOpenAI

# ---- State ----
class AgentState(TypedDict):
    raw_input: str
    input_type: str  # "text" | "image" | "audio" | "file"
    perception_result: dict
    intent: str
    routed_to: str

# ---- Perception Node ----
llm_vision = ChatOpenAI(model="gpt-4o")
llm_text = ChatOpenAI(model="gpt-4o-mini")  # 轻量模型做意图识别

def perceive(state: AgentState) -> AgentState:
    """多模态感知处理"""
    input_type = state["input_type"]

    if input_type == "image":
        # 视觉理解
        msg = HumanMessage(content=[
            {"type": "text", "text": "Describe what you see in this image in detail."},
            {"type": "image_url", "image_url": {"url": state["raw_input"]}}
        ])
        result = llm_vision.invoke([msg])
        perception = {
            "type": "image",
            "description": result.content,
            "entities": [],  # 可进一步提取
        }
    elif input_type == "audio":
        # 语音识别 (调用 Whisper API)
        import whisper
        model = whisper.load_model("base")
        transcript = model.transcribe(state["raw_input"])
        perception = {
            "type": "audio",
            "transcript": transcript["text"],
            "language": transcript["language"],
        }
    else:
        # 纯文本 - 直接传递
        perception = {
            "type": "text",
            "content": state["raw_input"],
        }

    return {
        **state,
        "perception_result": perception,
    }

# ---- Intent Recognition Node ----
def recognize_intent(state: AgentState) -> AgentState:
    """意图识别 - 用轻量模型降低成本"""
    content = (
        state["perception_result"].get("description", "")
        or state["perception_result"].get("transcript", "")
        or state["perception_result"].get("content", "")
    )

    prompt = f"""
    Classify the user's intent. Return ONLY one of:
    - question: asking for information
    - command: requesting an action
    - analysis: requesting data analysis
    - creation: requesting content creation
    - chitchat: casual conversation

    Input: {content[:500]}
    Intent:
    """
    result = llm_text.invoke(prompt).content.strip().lower()

    return {**state, "intent": result}

# ---- Routing Node ----
def route_to_module(state: AgentState) -> Literal["reasoning", "tool_use", "chitchat", "end"]:
    """根据意图路由到不同处理模块"""
    intent = state["intent"]

    if intent == "chitchat":
        return "chitchat"
    elif intent in ("command", "analysis", "creation"):
        return "tool_use"  # 需要调用工具
    elif intent == "question":
        return "reasoning"  # 需要推理
    return "end"

# ---- Build Graph ----
builder = StateGraph(AgentState)
builder.add_node("perceive", perceive)
builder.add_node("recognize_intent", recognize_intent)
builder.add_node("reasoning", lambda s: {**s, "routed_to": "reasoning"})
builder.add_node("tool_use", lambda s: {**s, "routed_to": "tool_use"})
builder.add_node("chitchat", lambda s: {**s, "routed_to": "chitchat"})

builder.set_entry_point("perceive")
builder.add_edge("perceive", "recognize_intent")
builder.add_conditional_edges("recognize_intent", route_to_module)
builder.add_edge("reasoning", END)
builder.add_edge("tool_use", END)
builder.add_edge("chitchat", END)

perception_graph = builder.compile()

# ---- 使用 ----
result = perception_graph.invoke({
    "raw_input": "帮我分析一下这张截图里的数据趋势",
    "input_type": "image",
})
print(result["perception_result"])  # 图片描述
print(result["intent"])              # 意图分类
print(result["routed_to"])           # 路由目标

    3.2 网页内容感知（Scraping + 理解）¶

    from playwright.async_api import async_playwright

async def perceive_webpage(url: str) -> dict:
    """网页感知：访问页面 → 提取内容 → 理解语义"""
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page()
        await page.goto(url, wait_until="domcontentloaded")

        # 提取主要内容
        content = await page.evaluate("""
            () => {
                // 简单的主内容提取
                const main = document.querySelector('main, article, .content, #content');
                return main ? main.innerText : document.body.innerText;
            }
        """)

        await browser.close()

    # 用轻量模型做内容理解和摘要
    prompt = f"""
    Analyze this webpage content:

    URL: {url}
    Content (first 3000 chars): {content[:3000]}

    Return JSON with:
    - title: page title
    - topic: main topic (1-2 words)
    - summary: 2-3 sentence summary
    - key_entities: list of important names/terms
    - language: detected language
    """

    analysis = llm_text.invoke(prompt, response_format={"type": "json_object"})
    return json.loads(analysis.content)

    4. 自实现感知层¶

    4.1 统一的 Perception 接口¶

    from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Any, Optional
import hashlib

@dataclass
class PerceptionInput:
    """统一的感知输入"""
    content: Any           # 原始内容
    input_type: str        # text/image/audio/file/web
    source: Optional[str]  # 来源 (URL, 文件名等)
    metadata: dict = None  # 额外元数据

    def __post_init__(self):
        if self.metadata is None:
            self.metadata = {}

@dataclass
class PerceptionOutput:
    """统一的感知输出"""
    understood: str        # 理解后的文本描述
    structured: dict       # 结构化提取的信息
    confidence: float      # 理解置信度
    requires_followup: bool  # 是否需要进一步感知

class PerceptionModule(ABC):
    """感知模块抽象基类"""

    @abstractmethod
    def process(self, inp: PerceptionInput) -> PerceptionOutput:
        pass

    @abstractmethod
    def supports(self, input_type: str) -> bool:
        pass


# ---- 具体实现 ----
class TextPerception(PerceptionModule):
    """文本感知：意图识别 + 情感分析 + 实体提取"""

    def __init__(self, llm):
        self.llm = llm

    def supports(self, input_type: str) -> bool:
        return input_type == "text"

    def process(self, inp: PerceptionInput) -> PerceptionOutput:
        prompt = f"""
        Analyze the following text input:

        Text: {inp.content}

        Return a JSON object with:
        - understood: a concise summary of what the user wants
        - intent: one of [question, command, analysis, creation, chitchat]
        - key_entities: list of important names, dates, numbers
        - sentiment: positive/negative/neutral
        - language: detected language code
        - complexity: simple/medium/complex
        """

        result = self.llm.invoke(
            prompt, 
            response_format={"type": "json_object"}
        )
        data = json.loads(result.content)

        return PerceptionOutput(
            understood=data.get("understood", inp.content),
            structured=data,
            confidence=0.9,
            requires_followup=False,
        )


class ImagePerception(PerceptionModule):
    """图片感知：视觉理解 + OCR"""

    def __init__(self, vision_model, ocr_model=None):
        self.vision_model = vision_model
        self.ocr_model = ocr_model

    def supports(self, input_type: str) -> bool:
        return input_type in ("image", "screenshot")

    def process(self, inp: PerceptionInput) -> PerceptionOutput:
        # 1. 视觉理解
        vision_prompt = [{
            "role": "user",
            "content": [
                {"type": "text", "text": "Describe this image in detail. What do you see? What information does it convey?"},
                {"type": "image_url", "image_url": {"url": inp.content}}
            ]
        }]
        vision_result = self.vision_model.invoke(vision_prompt)

        # 2. 可选：OCR 提取文字
        text_content = ""
        if self.ocr_model:
            text_content = self.ocr_model.recognize(inp.content)

        combined = f"{vision_result.content}\n\nExtracted text (if any):\n{text_content}"

        return PerceptionOutput(
            understood=combined,
            structured={"visual_description": vision_result.content, "ocr_text": text_content},
            confidence=0.85,
            requires_followup=False,
        )


# ---- Perception Router ----
class PerceptionRouter:
    """感知路由器：根据输入类型选择合适的感知模块"""

    def __init__(self):
        self.modules: list[PerceptionModule] = []

    def register(self, module: PerceptionModule):
        self.modules.append(module)

    def process(self, inp: PerceptionInput) -> PerceptionOutput:
        for module in self.modules:
            if module.supports(inp.input_type):
                return module.process(inp)

        raise ValueError(f"No perception module supports input type: {inp.input_type}")

# ---- 使用 ----
router = PerceptionRouter()
router.register(TextPerception(llm_text))
router.register(ImagePerception(llm_vision))

output = router.process(PerceptionInput(
    content="帮我查一下今天北京天气怎么样",
    input_type="text",
))
print(output.understood)     # 用户想查询北京今日天气
print(output.structured)     # {intent: "question", entities: ["北京", "今天", "天气"], ...}

    5. 最佳实践¶

    5.1 轻量模型优先¶

    • 意图识别、信息提取等任务用 轻量模型（gpt-4o-mini / Qwen-7B）
    • 视觉理解等复杂任务才用 大模型（gpt-4o / Claude Sonnet）
    • 成本节省 60-80%

    5.2 渐进式感知¶

    Level 1: 快速获取基本信息（标题、语言、类型）
    ↓ 如果需要更多
Level 2: 深度理解（语义分析、实体关系）
    ↓ 如果需要更多
Level 3: 专业分析（领域特定理解、复杂推理）

    5.3 缓存感知结果¶

    • 相同 URL / 相同图片的感知结果应该缓存
    • 使用 content hash 作为缓存键
    • TTL 根据数据类型设置（网页较短，图片较长）

    5.4 感知失败降级¶

    def perceive_with_fallback(inp: PerceptionInput) -> PerceptionOutput:
    try:
        return primary_perception.process(inp)
    except Exception as e:
        logger.warning(f"Primary perception failed: {e}")
        # 降级：简单文本化
        return PerceptionOutput(
            understood=str(inp.content)[:1000],
            structured={"raw": True},
            confidence=0.3,
            requires_followup=True,
        )

    6. 与下游模块的衔接¶

    Perception Output
    │
    ├── understood → 放入 Context / Memory
    ├── structured.entities → 放入 Memory (short-term)
    ├── structured.intent → 驱动 Planning / Routing
    ├── confidence → 决定是否需要 Human-in-the-Loop
    ── requires_followup → 触发补充感知

    感知层的质量直接影响 Agent 后续所有环节——垃圾进，垃圾出。

    7. 与其他模块的关系¶

    Perception (感知层)
    │
    ├──→ Reasoning (推理层)：提供结构化理解结果
    ├──→ Memory (记忆层)：提取的实体存入短期记忆
    ├──→ Planning (规划层)：意图识别驱动任务路由
    └──→ Tool Use (工具层)：需要工具时触发调用

    关键连接： - Perception 的输出是 Context Engineering 的输入 → engineering/context-engineering/ - 多模态感知依赖 MCP 协议接入外部数据 → protocols/mcp/

    9. 面试话术速记¶

    Q: Perception 模块的核心职责是什么？

    "Perception 是 Agent 的'眼睛和耳朵'，负责三件事： 1. 接收多模态输入（文本、图片、音频、网页等） 2. 理解内容语义（视觉理解、语音转文本、实体提取） 3. 路由到合适的下游模块（根据意图分类决定走推理还是工具调用）

    工程实践上，我们用轻量模型做意图识别（gpt-4o-mini），大模型做复杂理解（gpt-5o），成本能节省 60-80%。"

    Q: 如何处理多模态输入？

    "我们采用渐进式感知策略： - Level 1: 快速获取基本信息（类型、语言、标题） - Level 2: 深度理解（语义分析、实体关系） - Level 3: 专业分析（领域特定理解）

    同时用内容哈希缓存感知结果，相同输入直接返回，避免重复调用大模型。"

    加分项：提到"Perception 是 Context Engineering 的入口，感知质量直接决定上下文质量"。
