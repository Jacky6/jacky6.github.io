    Agent Architecture 多体架构¶

    Agent 的组织形态——从单体到团队，从串行到协作。

    1. 模块定位¶

    ┌────────────────────────────────────────────────────────────┐
│              Agent Architecture Spectrum                    │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  Single Agent ──→  Workflow ──→  Team ──→  Supervisor      │
│  (独立完成)     (固定流程)    (协作)    (动态调度)          │
│                                                            │
│  简单任务          中等复杂       复杂       高度复杂        │
│  低延迟           可控          灵活       自适应           │
│  低成本           成本可控       成本中等    成本较高        │
│                                                            │
└────────────────────────────────────────────────────────────┘

    选择原则：能用单体解决的不用多体，能用 Workflow 解决的不用 Team。

    2. Single Agent（单体 Agent）¶

    2.1 概念¶

    一个 Agent 独立完成感知 → 推理 → 规划 → 执行的全部流程。

    ┌───────────────────────────────────────────┐
│             Single Agent                   │
├───────────────────────────────────────────┤
│                                           │
│  User Input                                │
│      ↓                                     │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │Perceive │→│ Reason  │→│  Act    │   │
│  └─────────┘  └─────────┘  └─────────┘   │
│      ↑                        │           │
│      └──── Reflect ←──────────┘           │
│                                           │
│      ↓                                     │
│  Output                                    │
│                                           │
───────────────────────────────────────────┘

    2.2 LangGraph 单体实现¶

    from typing import TypedDict, Annotated, Literal
from langgraph.graph import StateGraph, END
from langgraph.graph.message import add_messages
from langchain_openai import ChatOpenAI
from langchain_core.messages import SystemMessage

class SingleAgentState(TypedDict):
    messages: Annotated[list, add_messages]
    task: str

# 系统提示
SYSTEM_PROMPT = """
You are a helpful AI assistant. You can:
1. Answer questions directly
2. Use tools when needed
3. Break down complex tasks

Always think step by step before acting.
"""

llm = ChatOpenAI(model="gpt-4o")

def agent_node(state: SingleAgentState) -> SingleAgentState:
    """单体 Agent 核心节点"""
    messages = [SystemMessage(content=SYSTEM_PROMPT)] + state["messages"]
    response = llm.invoke(messages)
    return {"messages": [response]}

# 构建图
builder = StateGraph(SingleAgentState)
builder.add_node("agent", agent_node)
builder.set_entry_point("agent")
builder.add_edge("agent", END)

single_agent = builder.compile()

# 使用
result = single_agent.invoke({
    "messages": [{"role": "user", "content": "帮我写一个 Python 快速排序函数"}],
    "task": "write_quick_sort",
})

    2.3 何时用单体¶

    适用场景 示例
    单轮对话 问答、翻译、摘要
    简单工具调用 查天气、计算器
    短任务 代码片段生成、邮件起草
    低延迟要求 实时对话
    不适用场景 原因
    长链路任务 Context 爆炸、容易跑偏
    多领域任务 一个模型难以覆盖所有专业领域
    需要并行 单体只能串行

    3. Workflow（工作流 Agent）¶

    3.1 概念¶

    固定流程的多节点编排，每个节点有明确的职责和输入输出。

    User Input
    ↓
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│Research │ →  │Analyze  │ →  │  Draft  │ →  │ Review  │
│ Node    │    │ Node    │    │ Node    │    │ Node    │
└─────────┘    └─────────┘    └─────────┘    └─────────┘
    ↓              ↓              ↓              ↓
  收集信息       数据分析        生成草稿        质量检查
                                                      ↓
                                                 Final Output

    3.2 LangGraph Workflow 实现¶

    from typing import TypedDict
from langgraph.graph import StateGraph, END
from langchain_openai import ChatOpenAI

class WorkflowState(TypedDict):
    topic: str
    research_results: str
    analysis: str
    draft: str
    review_feedback: str
    final_output: str

llm_research = ChatOpenAI(model="gpt-4o")
llm_analyze = ChatOpenAI(model="gpt-4o")
llm_draft = ChatOpenAI(model="gpt-4o")
llm_review = ChatOpenAI(model="gpt-4o-mini")  # 评审用轻量模型

def research_node(state: WorkflowState) -> WorkflowState:
    """研究节点：收集信息"""
    prompt = f"""
    Research the following topic thoroughly:

    Topic: {state['topic']}

    Provide:
    1. Key facts and data
    2. Different perspectives
    3. Sources and references

    Be comprehensive and accurate.
    """
    result = llm_research.invoke(prompt).content
    return {**state, "research_results": result}

def analyze_node(state: WorkflowState) -> WorkflowState:
    """分析节点：整理和洞察"""
    prompt = f"""
    Analyze the research findings:

    {state['research_results']}

    Provide:
    1. Key insights
    2. Patterns and trends
    3. Contradictions or gaps
    4. Actionable conclusions
    """
    result = llm_analyze.invoke(prompt).content
    return {**state, "analysis": result}

def draft_node(state: WorkflowState) -> WorkflowState:
    """起草节点：生成内容"""
    prompt = f"""
    Write a comprehensive report based on:

    Topic: {state['topic']}

    Research:
    {state['research_results']}

    Analysis:
    {state['analysis']}

    Requirements:
    - Clear structure with headings
    - Data-driven arguments
    - Actionable recommendations
    - Professional tone
    """
    result = llm_draft.invoke(prompt).content
    return {**state, "draft": result}

def review_node(state: WorkflowState) -> WorkflowState:
    """评审节点：质量检查"""
    prompt = f"""
    Review this draft report:

    {state['draft']}

    Check for:
    1. Factual accuracy
    2. Logical consistency
    3. Completeness
    4. Clarity and readability
    5. Actionable recommendations

    Provide specific feedback and a revised version if needed.
    """
    result = llm_review.invoke(prompt).content
    return {**state, "review_feedback": result}

def finalize_node(state: WorkflowState) -> WorkflowState:
    """定稿节点：整合评审意见"""
    # 如果评审通过，直接返回草稿
    if "no changes needed" in state["review_feedback"].lower()[:50]:
        return {**state, "final_output": state["draft"]}

    # 否则根据评审意见修订
    prompt = f"""
    Revise the draft based on the review feedback:

    Original draft:
    {state['draft']}

    Review feedback:
    {state['review_feedback']}

    Return the revised final version.
    """
    result = llm_draft.invoke(prompt).content
    return {**state, "final_output": result}

# 构建工作流
builder = StateGraph(WorkflowState)
builder.add_node("research", research_node)
builder.add_node("analyze", analyze_node)
builder.add_node("draft", draft_node)
builder.add_node("review", review_node)
builder.add_node("finalize", finalize_node)

builder.set_entry_point("research")
builder.add_edge("research", "analyze")
builder.add_edge("analyze", "draft")
builder.add_edge("draft", "review")
builder.add_edge("review", "finalize")
builder.add_edge("finalize", END)

workflow = builder.compile()

# 使用
result = workflow.invoke({
    "topic": "Python 在 AI 开发中的应用趋势",
})
print(result["final_output"])

    3.3 条件分支 Workflow¶

    from typing import Literal

def route_by_complexity(state: WorkflowState) -> Literal["simple_path", "complex_path"]:
    """根据任务复杂度路由"""
    topic = state["topic"]

    # 关键词判断（也可用 LLM 分类）
    complex_keywords = ["分析", "研究", "报告", "对比", "评估"]
    if any(kw in topic for kw in complex_keywords):
        return "complex_path"
    return "simple_path"

# 在图中使用条件分支
builder.add_conditional_edges("research", route_by_complexity, {
    "simple_path": "draft",      # 简单任务：研究 → 起草
    "complex_path": "analyze",   # 复杂任务：研究 → 分析 → 起草
})

    3.4 何时用 Workflow¶

    适用场景 示例
    固定流程任务 报告生成、内容创作
    需要质量保证 起草 → 评审 → 修订
    可预测步骤 数据 ETL 流程
    需要审计追踪 每个节点输出可记录

    4. Team（多体协作）¶

    4.1 概念¶

    多个 Agent 协作完成一个任务，每个 Agent 有专门的领域能力。

                        ┌─────────────────┐
                    │   User Input    │
                    └────────┬────────
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
        ┌──────────┐  ┌──────────┐  ┌──────────┐
        │ Research │  │  Coding  │  │  Writing │
        │ Agent    │  │  Agent   │  │  Agent   │
        ────┬─────┘  └────┬─────┘  └────┬─────┘
             │             │             │
             └─────────────┼─────────────┘
                           ▼
                    ┌──────────┐
                    │  Merge & │
                    │  Deliver │
                    └──────────┘

    4.2 LangGraph Team 实现¶

    from typing import TypedDict
from langgraph.graph import StateGraph, START, END
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, AIMessage

class TeamState(TypedDict):
    messages: list
    task: str
    research_output: str
    code_output: str
    writing_output: str
    final_output: str

# 各角色的系统提示
RESEARCHER_PROMPT = """
You are a Research Specialist. Your job is to gather and synthesize information.
Focus on accuracy, comprehensiveness, and citing sources.
"""

CODER_PROMPT = """
You are a Coding Specialist. Your job is to write, review, and debug code.
Focus on correctness, efficiency, and best practices.
"""

WRITER_PROMPT = """
You are a Writing Specialist. Your job is to produce clear, engaging content.
Focus on structure, tone, and readability.
"""

# 各角色的 LLM（可以用不同模型）
llm_researcher = ChatOpenAI(model="gpt-4o")
llm_coder = ChatOpenAI(model="gpt-4o")
llm_writer = ChatOpenAI(model="gpt-4o")

def researcher_node(state: TeamState) -> TeamState:
    """研究员节点"""
    messages = [
        {"role": "system", "content": RESEARCHER_PROMPT},
        {"role": "user", "content": f"Research task: {state['task']}"},
    ]
    result = llm_researcher.invoke(messages).content
    return {**state, "research_output": result}

def coder_node(state: TeamState) -> TeamState:
    """程序员节点"""
    messages = [
        {"role": "system", "content": CODER_PROMPT},
        {"role": "user", "content": f"Coding task: {state['task']}"},
    ]
    result = llm_coder.invoke(messages).content
    return {**state, "code_output": result}

def writer_node(state: TeamState) -> TeamState:
    """写手节点"""
    messages = [
        {"role": "system", "content": WRITER_PROMPT},
        {"role": "user", "content": f"Writing task: {state['task']}"},
    ]
    result = llm_writer.invoke(messages).content
    return {**state, "writing_output": result}

def coordinator_node(state: TeamState) -> TeamState:
    """协调员节点：整合各成员输出"""
    prompt = f"""
    You are the team coordinator. Synthesize the work from all team members:

    Research: {state.get('research_output', 'N/A')}
    Code: {state.get('code_output', 'N/A')}
    Writing: {state.get('writing_output', 'N/A')}

    Original task: {state['task']}

    Produce a cohesive final deliverable that integrates all contributions.
    """
    result = llm_writer.invoke(prompt).content
    return {**state, "final_output": result}

# 构建团队图
builder = StateGraph(TeamState)
builder.add_node("researcher", researcher_node)
builder.add_node("coder", coder_node)
builder.add_node("writer", writer_node)
builder.add_node("coordinator", coordinator_node)

# 并行执行：researcher, coder, writer 同时工作
builder.add_edge(START, "researcher")
builder.add_edge(START, "coder")
builder.add_edge(START, "writer")

# 所有成员完成后交给协调员
builder.add_edge("researcher", "coordinator")
builder.add_edge("coder", "coordinator")
builder.add_edge("writer", "coordinator")
builder.add_edge("coordinator", END)

team = builder.compile()

# 使用
result = team.invoke({
    "task": "创建一份关于 Python Web 开发的教程，包含代码示例和说明",
    "messages": [],
})
print(result["final_output"])

    4.3 顺序协作 Team¶

    # 如果团队成员需要顺序协作（前一个的输出是后一个的输入）
class SequentialTeamState(TypedDict):
    messages: list
    task: str
    handoff: str  # 在成员间传递的工作成果

def researcher_node(state: SequentialTeamState) -> SequentialTeamState:
    result = llm_researcher.invoke(f"""
    System: {RESEARCHER_PROMPT}
    Task: {state['task']}
    """).content
    return {**state, "handoff": result}

def coder_node(state: SequentialTeamState) -> SequentialTeamState:
    result = llm_coder.invoke(f"""
    System: {CODER_PROMPT}
    Task: {state['task']}

    Research context from previous team member:
    {state['handoff']}
    """).content
    return {**state, "handoff": result}

def writer_node(state: SequentialTeamState) -> SequentialTeamState:
    result = llm_writer.invoke(f"""
    System: {WRITER_PROMPT}
    Task: {state['task']}

    Work from previous team members:
    {state['handoff']}
    """).content
    return {**state, "handoff": result, "final_output": result}

# 顺序执行
builder = StateGraph(SequentialTeamState)
builder.add_node("researcher", researcher_node)
builder.add_node("coder", coder_node)
builder.add_node("writer", writer_node)

builder.set_entry_point("researcher")
builder.add_edge("researcher", "coder")
builder.add_edge("coder", "writer")
builder.add_edge("writer", END)

sequential_team = builder.compile()

    5. Supervisor（监督者模式）¶

    5.1 概念¶

    一个 Supervisor Agent 动态决定下一步由哪个成员执行，实现自适应的任务分解和调度。

                        ┌──────────────┐
                    │  Supervisor  │ ← 决策中心
                    └──────┬───────┘
                           │ 分配任务
            ┌──────────────┼──────────────┐
            ▼              ▼              ▼
       ┌─────────┐  ┌─────────┐  ┌─────────┐
       │Research │  │ Coding  │  │ Writing │
       │  Agent  │  │  Agent  │  │  Agent  │
       ────┬────┘  └────┬────┘  └────┬────┘
            │            │            │
            └────────────┼────────────┘
                         │ 返回结果
                         ▼
                   ┌──────────────┐
                   │  Supervisor  │ ← 评估结果，决定下一步
                   └──────┬───────┘
                          │
                   完成？→ 是 → 输出
                          ↓ 否
                   继续分配下一个任务

    5.2 LangGraph Supervisor 实现¶

    from typing import TypedDict, Literal
from langgraph.graph import StateGraph, START, END
from langchain_openai import ChatOpenAI
from langchain_core.messages import SystemMessage, HumanMessage

class SupervisorState(TypedDict):
    messages: list
    task: str
    next: str  # supervisor 决定的下一个执行者

# 角色定义
MEMBERS = ["Researcher", "Coder", "Writer"]
ROLE_DESCRIPTIONS = {
    "Researcher": "Research and gather information on the given topic.",
    "Coder": "Write code, debug, and provide technical solutions.",
    "Writer": "Write clear, well-structured content and documentation.",
}

SYSTEM_PROMPT_TEMPLATE = f"""
You are a supervisor managing a team of specialized agents.

Your team members:
{chr(10).join(f'- {name}: {desc}' for name, desc in ROLE_DESCRIPTIONS.items())}

For each step:
1. Review the current state and messages
2. Decide which team member should work next
3. Or respond "FINISH" if the task is complete

Respond with ONLY the name of the next agent or "FINISH".
"""

llm_supervisor = ChatOpenAI(model="gpt-4o")
llm_researcher = ChatOpenAI(model="gpt-4o")
llm_coder = ChatOpenAI(model="gpt-4o")
llm_writer = ChatOpenAI(model="gpt-4o")

def supervisor_node(state: SupervisorState) -> SupervisorState:
    """Supervisor 决策下一个执行者"""
    conversation = "\n".join(
        f"{m.type}: {m.content[:200]}" for m in state["messages"][-10:]
    )

    prompt = f"""
    {SYSTEM_PROMPT_TEMPLATE}

    Task: {state['task']}

    Conversation so far:
    {conversation}

    Who should work next? (Researcher / Coder / Writer / FINISH)
    """

    response = llm_supervisor.invoke(prompt).content.strip()

    # 解析响应
    next_agent = "FINISH"
    for member in MEMBERS + ["FINISH"]:
        if member.lower() in response.lower():
            next_agent = member
            break

    return {**state, "next": next_agent}

def researcher_node(state: SupervisorState) -> SupervisorState:
    messages = [
        SystemMessage(content=ROLE_DESCRIPTIONS["Researcher"]),
        HumanMessage(content=f"Task: {state['task']}"),
    ] + state["messages"]
    result = llm_researcher.invoke(messages)
    return {
        **state,
        "messages": state["messages"] + [result],
        "next": "supervisor",
    }

def coder_node(state: SupervisorState) -> SupervisorState:
    messages = [
        SystemMessage(content=ROLE_DESCRIPTIONS["Coder"]),
        HumanMessage(content=f"Task: {state['task']}"),
    ] + state["messages"]
    result = llm_coder.invoke(messages)
    return {
        **state,
        "messages": state["messages"] + [result],
        "next": "supervisor",
    }

def writer_node(state: SupervisorState) -> SupervisorState:
    messages = [
        SystemMessage(content=ROLE_DESCRIPTIONS["Writer"]),
        HumanMessage(content=f"Task: {state['task']}"),
    ] + state["messages"]
    result = llm_writer.invoke(messages)
    return {
        **state,
        "messages": state["messages"] + [result],
        "next": "supervisor",
    }

# 构建 Supervisor 图
builder = StateGraph(SupervisorState)
builder.add_node("supervisor", supervisor_node)
builder.add_node("Researcher", researcher_node)
builder.add_node("Coder", coder_node)
builder.add_node("Writer", writer_node)

builder.set_entry_point("supervisor")

# Supervisor 路由到各成员
def route_supervisor(state: SupervisorState) -> str:
    next_agent = state["next"]
    if next_agent == "FINISH":
        return END
    return next_agent

builder.add_conditional_edges("supervisor", route_supervisor)

# 各成员完成后回到 supervisor
for member in MEMBERS:
    builder.add_edge(member, "supervisor")

supervisor_agent = builder.compile()

# 使用
result = supervisor_agent.invoke({
    "task": "创建一个 Python 数据分析教程，包含数据获取、清洗、分析和可视化",
    "messages": [],
})

# 查看执行过程
for msg in result["messages"]:
    print(f"[{msg.type}] {msg.content[:100]}...")

    5.3 Supervisor 增强版（带状态管理）¶

    from typing import TypedDict, Literal
from langgraph.graph import StateGraph, START, END

class EnhancedSupervisorState(TypedDict):
    messages: list
    task: str
    next: str
    iterations: int
    max_iterations: int
    final_answer: str
    team_outputs: dict  # 记录每个成员的贡献

MAX_ITERATIONS = 10

def supervisor_node(state: EnhancedSupervisorState) -> EnhancedSupervisorState:
    iterations = state.get("iterations", 0) + 1

    if iterations >= MAX_ITERATIONS:
        return {**state, "next": "FINISH", "iterations": iterations}

    # ... 决策逻辑同上 ...

    return {**state, "next": next_agent, "iterations": iterations}

def researcher_node(state: EnhancedSupervisorState) -> EnhancedSupervisorState:
    # ... 执行逻辑 ...
    result = llm_researcher.invoke(messages)

    new_outputs = {**state.get("team_outputs", {}), "Researcher": result.content}

    return {
        **state,
        "messages": state["messages"] + [result],
        "next": "supervisor",
        "team_outputs": new_outputs,
    }

# ... 其他节点类似 ...

def finalize_node(state: EnhancedSupervisorState) -> EnhancedSupervisorState:
    """汇总最终答案"""
    prompt = f"""
    Task: {state['task']}

    Team contributions:
    {json.dumps(state.get('team_outputs', {}), indent=2)}

    Synthesize a final answer.
    """
    final = llm_supervisor.invoke(prompt).content
    return {**state, "final_answer": final}

builder = StateGraph(EnhancedSupervisorState)
builder.add_node("supervisor", supervisor_node)
builder.add_node("Researcher", researcher_node)
builder.add_node("Coder", coder_node)
builder.add_node("Writer", writer_node)
builder.add_node("finalize", finalize_node)

builder.set_entry_point("supervisor")
builder.add_conditional_edges("supervisor", lambda s: s["next"] if s["next"] != "FINISH" else "finalize")
for member in MEMBERS:
    builder.add_edge(member, "supervisor")
builder.add_edge("finalize", END)

enhanced_supervisor = builder.compile()

    8. Agent Architecture Checklist¶

    • Single Agent：最简实现，快速验证
    • Workflow：固定流程编排，条件分支
    • Team：并行/顺序协作，角色分工
    • Supervisor：动态调度，迭代控制
    • 不同模型：不同角色可用不同模型（成本优化）
    • 状态管理：团队输出记录、迭代次数限制
    • Human-in-the-Loop：关键节点引入人工审批
    • 架构演进：从 Single → Workflow → Team → Supervisor 逐步升级

    9.3 从零搭建 Agent¶

    import json
class SimpleAgent:
    def __init__(self, llm, tools: dict, max_steps=5):
        self.llm = llm; self.tools = tools; self.max_steps = max_steps

    def run(self, user_input: str) -> str:
        messages = [{"role": "user", "content": user_input}]
        tool_desc = "\n".join(f"  {name}: {desc}" for name, (desc, _) in self.tools.items())
        system = f"""You have access to these tools: {tool_desc}
To use: TOOL_CALL: <name>\nTOOL_INPUT: <json>\nWhen done: FINAL: <answer>"""
        messages.insert(0, {"role": "system", "content": system})

        for _ in range(self.max_steps):
            response = self.llm(messages)
            if response.startswith("FINAL:"): return response[6:].strip()
            if response.startswith("TOOL_CALL:"):
                lines = response.split("\n")
                name = lines[0].replace("TOOL_CALL:", "").strip()
                inp = json.loads(lines[1].replace("TOOL_INPUT:", "").strip())
                result = self.tools[name](**inp) if name in self.tools else f"Unknown: {name}"
                messages.append({"role": "assistant", "content": response})
                messages.append({"role": "tool", "content": str(result)})
        return "Max steps reached."

    12. 面试话术速记¶

    Q: 如何选择 Agent 架构？

    "根据任务复杂度选择： - Single Agent：简单任务，单轮对话，低延迟要求 - Workflow：固定流程，需要质量保证，可预测步骤 - Team：多领域协作，需要并行执行 - Supervisor：高度复杂，需要动态调度

    核心原则：能用简单的不用复杂的。单体能解决的不用多体，Workflow 能解决的不用 Team。"

    Q: Supervisor 模式的核心是什么？

    "Supervisor 是一个'项目经理' Agent，核心能力是： 1. 任务分析：理解用户需求，判断需要哪些 Worker 2. 动态分配：根据任务类型和 Worker 能力，决定下一步交给谁 3. 结果整合：收集各 Worker 的输出，整合成最终结果

    工程上，Supervisor 用 LLM 做路由决策，用 StateGraph 管理状态流转，用 条件边实现动态调度。"

    加分项：提到"多体架构是 A2A 协议的应用场景，好的架构设计能让 Agent 团队像人类团队一样高效协作"。
