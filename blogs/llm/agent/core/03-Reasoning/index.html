    Reasoning 推理模块¶

    Agent 的"大脑皮层"——让模型从"直接回答"升级为"有条理地思考"。

    1. 模块定位¶

    推理模块是 Agent 智能程度 的核心决定因素。同一个模型，用不同的推理策略，效果天差地别。

    ┌─────────────────────────────────────────────────────────┐
│                  Reasoning Hierarchy                     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Level 3: Tree/Self-Consistency   ← 复杂决策、探索分支    │
│  Level 2: ReAct                    ← 边想边做、工具交互   │
│  Level 1: CoT                      ← 提升推理深度         │
│  Level 0: Direct                   ← 直接回答（无推理）    │
│                                                         │
│  ↑ 复杂度 / 能力                                          │
│  ↑ Token 消耗                                            │
│  ↑ 延迟                                                  │
│                                                         │
└─────────────────────────────────────────────────────────┘

    2. CoT (Chain-of-Thought)¶

    2.1 核心思想¶

    让模型把思考过程显式化，而不是直接给出答案。

    直接回答:  问题 → 答案              ❌ 容易跳步、算错
CoT:       问题 → 步骤1 → 步骤2 → 答案  ✅ 提升推理深度

    2.2 基础 CoT Prompt¶

    # Zero-shot CoT（最简单，不需要示例）
COT_PROMPT = """
{question}

Let's think step by step.
"""

# Few-shot CoT（带示例，效果更好）
FEW_SHOT_COT = """

   Each can has 3 tennis balls. How many tennis balls does he have now?
A: Roger started with 5 balls. 2 cans of 3 balls each is 6 balls.
   5 + 6 = 11. The answer is 11.

Q: {question}
A:
"""

    2.3 LangGraph 实现¶

    from typing import TypedDict
from langgraph.graph import StateGraph, END
from langchain_openai import ChatOpenAI

class ReasoningState(TypedDict):
    question: str
    thinking_steps: list[str]
    answer: str
    confidence: float

llm = ChatOpenAI(model="gpt-4o", temperature=0)

def cot_reasoning(state: ReasoningState) -> ReasoningState:
    """Chain-of-Thought 推理"""
    prompt = f"""
    Question: {state['question']}

    Think step by step:
    1. First, identify what is being asked
    2. Break down the problem into sub-problems
    3. Solve each sub-problem
    4. Combine results for the final answer

    Format your response as:
    Thinking:
    - Step 1: ...
    - Step 2: ...
    - Step 3: ...

    Final Answer: [your answer]
    Confidence: [0.0-1.0]
    """

    response = llm.invoke(prompt).content

    # 解析响应
    lines = response.split("\n")
    steps = []
    answer = ""
    confidence = 0.5

    in_thinking = False
    for line in lines:
        if line.startswith("Thinking:"):
            in_thinking = True
            continue
        if in_thinking and line.startswith("- Step"):
            steps.append(line.strip())
        if line.startswith("Final Answer:"):
            answer = line.replace("Final Answer:", "").strip()
        if line.startswith("Confidence:"):
            try:
                confidence = float(line.split(":")[1].strip())
            except:
                pass

    return {
        **state,
        "thinking_steps": steps,
        "answer": answer,
        "confidence": confidence,
    }

# 构建图
builder = StateGraph(ReasoningState)
builder.add_node("cot", cot_reasoning)
builder.set_entry_point("cot")
builder.add_edge("cot", END)

cot_graph = builder.compile()

# 使用
result = cot_graph.invoke({
    "question": "一个农场有鸡和兔子，共35个头，94条腿。各有多少只？",
    "thinking_steps": [],
})
print("思考过程:")
for step in result["thinking_steps"]:
    print(f"  {step}")
print(f"答案: {result['answer']}")
print(f"置信度: {result['confidence']}")

    2.4 结构化 CoT（推荐生产使用）¶

    from pydantic import BaseModel, Field
from typing import Literal

class CoTStep(BaseModel):
    """结构化思考步骤"""
    step_number: int = Field(description="步骤编号")
    description: str = Field(description="这一步做了什么")
    reasoning: str = Field(description="为什么这样做")
    intermediate_result: str = Field(description="中间结果")

class CoTResult(BaseModel):
    """结构化 CoT 结果"""
    problem_understanding: str = Field(description="对问题的理解")
    steps: list[CoTStep] = Field(description="推理步骤")
    final_answer: str = Field(description="最终答案")
    confidence: float = Field(ge=0.0, le=1.0, description="置信度")
    assumptions: list[str] = Field(description="做出的假设")

def structured_cot(question: str) -> CoTResult:
    """使用 Pydantic 输出格式的结构化 CoT"""
    prompt = f"""
    Solve this problem using structured reasoning:

    Question: {question}

    Requirements:
    - Break the problem into logical steps
    - Explain your reasoning at each step
    - State any assumptions you make
    - Provide a confidence level for your answer
    """

    return llm.with_structured_output(CoTResult).invoke(prompt)

# 使用
result = structured_cot("如果今天是2026年5月28日星期四，那么100天后是星期几？")
print(f"理解: {result.problem_understanding}")
for step in result.steps:
    print(f"步骤 {step.step_number}: {step.description}")
    print(f"  推理: {step.reasoning}")
    print(f"  结果: {step.intermediate_result}")
print(f"答案: {result.final_answer}")

    3. ReAct (Reasoning + Acting)¶

    3.1 核心思想¶

    边思考边行动，每步推理后调用工具，根据工具返回的观察结果继续推理。

    Thought: 我需要查找北京的天气
Action: search_weather
Action Input: {"city": "Beijing", "date": "today"}
Observation: 北京今日晴，22-30°C
Thought: 天气信息已获取，现在整理回答
Final Answer: 北京今天晴天，气温22-30°C

    3.2 从零实现 ReAct¶

    import json
from typing import Callable

class Tool:
    """工具定义"""
    def __init__(self, name: str, description: str, func: Callable):
        self.name = name
        self.description = description
        self.func = func

    def to_prompt(self) -> str:
        return f"- {self.name}: {self.description}"

class ReActAgent:
    """从零实现的 ReAct Agent"""

    REACT_PROMPT = """
    Answer the following question by thinking step by step.
    You have access to these tools:

    {tool_descriptions}

    Use the following format:
    Thought: <your reasoning about what to do next>
    Action: <tool_name>
    Action Input: <json input>
    Observation: <tool output>
    ... (repeat Thought/Action/Action Input/Observation as needed)
    Thought: <final reasoning>
    Final Answer: <your final answer>

    Question: {question}

    {history}
    Thought:
    """

    MAX_ITERATIONS = 10

    def __init__(self, llm, tools: list[Tool]):
        self.llm = llm
        self.tools = {t.name: t for t in tools}
        self.tool_descriptions = "\n".join(t.to_prompt() for t in tools)

    def run(self, question: str) -> dict:
        """执行 ReAct 循环"""
        history = ""
        trace = []

        for i in range(self.MAX_ITERATIONS):
            # 1. 生成 Thought + Action
            prompt = self.REACT_PROMPT.format(
                tool_descriptions=self.tool_descriptions,
                question=question,
                history=history,
            )
            response = self.llm.invoke(prompt).content.strip()

            # 2. 解析响应
            parsed = self._parse_react_response(response)
            trace.append(parsed)

            if parsed["type"] == "final_answer":
                return {
                    "answer": parsed["content"],
                    "trace": trace,
                    "iterations": i + 1,
                }

            # 3. 执行工具
            tool_name = parsed.get("action")
            tool_input = parsed.get("action_input", {})

            if tool_name not in self.tools:
                observation = f"Error: Unknown tool '{tool_name}'"
            else:
                try:
                    result = self.tools[tool_name].func(**tool_input)
                    observation = str(result)
                except Exception as e:
                    observation = f"Error: {str(e)}"

            # 4. 记录到历史
            history += f"{response}\nObservation: {observation}\n"

        return {
            "answer": "Failed to reach a conclusion within max iterations.",
            "trace": trace,
            "iterations": self.MAX_ITERATIONS,
        }

    def _parse_react_response(self, text: str) -> dict:
        """解析 ReAct 响应"""
        # 检查是否有 Final Answer
        if "Final Answer:" in text:
            answer = text.split("Final Answer:")[-1].strip()
            return {"type": "final_answer", "content": answer}

        # 解析 Thought + Action + Action Input
        thought = ""
        action = ""
        action_input = {}

        lines = text.split("\n")
        for line in lines:
            if line.startswith("Thought:"):
                thought = line.replace("Thought:", "").strip()
            elif line.startswith("Action:"):
                action = line.replace("Action:", "").strip()
            elif line.startswith("Action Input:"):
                try:
                    action_input = json.loads(
                        line.replace("Action Input:", "").strip()
                    )
                except:
                    action_input = line.replace("Action Input:", "").strip()

        return {
            "type": "action",
            "thought": thought,
            "action": action,
            "action_input": action_input,
        }

# ---- 使用示例 ----

# 定义工具
def search_weather(city: str, date: str = "today") -> str:
    """模拟天气查询"""
    weather_data = {
        "Beijing": {"today": "晴，22-30°C", "tomorrow": "多云，20-28°C"},
        "Shanghai": {"today": "阴转雨，18-25°C", "tomorrow": "雨，17-23°C"},
    }
    return weather_data.get(city, {}).get(date, "No data available")

def calculator(expression: str) -> str:
    """安全计算器"""
    # 只允许基本运算
    allowed = set("0123456789+-*/(). ")
    if not all(c in allowed for c in expression):
        return "Error: Invalid characters"
    try:
        return str(eval(expression))
    except:
        return "Error: Invalid expression"

tools = [
    Tool("search_weather", "Query weather for a city and date", search_weather),
    Tool("calculator", "Evaluate a math expression", calculator),
]

agent = ReActAgent(llm=llm, tools=tools)
result = agent.run("北京今天天气怎么样？如果明天气温下降5度，是多少度？")

print(f"答案: {result['answer']}")
print(f"迭代次数: {result['iterations']}")
for i, step in enumerate(result['trace']):
    print(f"\n步骤 {i+1}:")
    print(f"  类型: {step['type']}")
    if step['type'] == "action":
        print(f"  思考: {step['thought']}")
        print(f"  动作: {step['action']}({step['action_input']})")

    3.3 LangGraph ReAct 实现¶

    from typing import TypedDict, Literal
from langgraph.graph import StateGraph, END
from langgraph.prebuilt import ToolNode
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI

# 定义工具
@tool
def search_weather(city: str, date: str = "today") -> str:
    """Query weather information."""
    return search_weather_func(city, date)

@tool
def calculator(expression: str) -> str:
    """Evaluate a mathematical expression."""
    return calculator_func(expression)

tools = [search_weather, calculator]
tool_node = ToolNode(tools)

llm_with_tools = llm.bind_tools(tools)

# State
class ReActState(TypedDict):
    messages: list
    question: str

# Nodes
def agent_node(state: ReActState) -> ReActState:
    """Agent 思考并决定是否调用工具"""
    messages = state["messages"]
    response = llm_with_tools.invoke(messages)

    return {
        "messages": state["messages"] + [response],
    }

def should_continue(state: ReActState) -> Literal["tools", END]:
    """判断是否需要调用工具"""
    last_message = state["messages"][-1]

    # 如果消息中有 tool_calls，继续执行工具
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        return "tools"

    return END

# Build Graph
builder = StateGraph(ReActState)
builder.add_node("agent", agent_node)
builder.add_node("tools", tool_node)

builder.set_entry_point("agent")
builder.add_conditional_edges("agent", should_continue)
builder.add_edge("tools", "agent")  # 工具执行后回到 agent

react_graph = builder.compile()

# 使用
result = react_graph.invoke({
    "messages": [{"role": "user", "content": "北京今天天气怎么样？"}],
    "question": "北京今天天气怎么样？",
})

for msg in result["messages"]:
    role = getattr(msg, "type", "unknown")
    content = getattr(msg, "content", "")
    if content:
        print(f"{role}: {content[:100]}...")

    3.4 ReAct 的最佳实践¶

    技巧 说明
    工具描述要精确 模型靠描述决定用哪个工具，描述越精确越好
    限制最大迭代次数 防止无限循环（建议 5-10 次）
    错误恢复 工具调用失败时返回友好的错误信息，让模型重试
    Thought 质量检查 用另一个轻量模型评估 Thought 质量
    并行工具调用 多个独立工具调用可以并行执行，减少延迟

    3.5 面试速记：ReAct 手写¶

    面试最常考："手写一个 ReAct 循环"。

    精简版（30 行内，可直接手写）：

    def react(agent_llm, tools, question, max_iter=5):
    """手写 ReAct 循环——面试精简版"""
    history = ""
    for _ in range(max_iter):
        prompt = f"""Answer the question using tools.
Tools: {describe_tools(tools)}
Question: {question}
{history}
Thought:"""
        resp = agent_llm(prompt).text
        if "Final Answer:" in resp:
            return resp.split("Final Answer:")[-1].strip()
        action, inp = parse_action(resp)

    4. Tree of Thoughts (ToT)¶

    4.1 核心思想¶

    CoT 是线性的（一条思考链），ToT 是树状的——在关键决策点探索多个可能的思考路径，然后选择最优的。

              Root
         / | \
       T1  T2  T3     ← 生成多个可能的下一步思考
      /|\   |   |\
    ... ... ... ...  ← 每步继续分支
      |
   Evaluate          ← 评估各路径质量
      |
   Select Best       ← 选择最优路径继续

    4.2 实现¶

    from typing import Optional
import heapq

class ThoughtNode:
    """思考树节点"""
    def __init__(self, content: str, depth: int = 0, parent: Optional['ThoughtNode'] = None):
        self.content = content
        self.depth = depth
        self.parent = parent
        self.children: list['ThoughtNode'] = []
        self.value: float = 0.0  # 评估分数
        self.visits: int = 0

    def get_path(self) -> list[str]:
        """获取从根到当前节点的路径"""
        path = []
        node = self
        while node:
            path.append(node.content)
            node = node.parent
        return path[::-1]

class TreeOfThoughts:
    """Tree of Thoughts 推理"""

    def __init__(self, llm, branching_factor: int = 3, max_depth: int = 5):
        self.llm = llm
        self.branching_factor = branching_factor
        self.max_depth = max_depth

    def solve(self, problem: str) -> dict:
        """用 ToT 解决问题"""
        root = ThoughtNode(content=f"Problem: {problem}")

        # DFS 搜索
        best_leaf = self._search(root, problem)

        return {
            "solution": best_leaf.content,
            "path": best_leaf.get_path(),
            "value": best_leaf.value,
        }

    def _search(self, node: ThoughtNode, problem: str) -> ThoughtNode:
        """深度优先搜索 + 评估"""
        if node.depth >= self.max_depth:
            # 达到最大深度，评估当前节点
            node.value = self._evaluate(node, problem)
            return node

        # 生成下一步思考的候选
        candidates = self._generate_candidates(node, problem)

        best_child = None
        best_value = -1

        for candidate in candidates:
            node.children.append(candidate)
            result = self._search(candidate, problem)

            if result.value > best_value:
                best_value = result.value
                best_child = result

        node.value = best_value
        return best_child or node

    def _generate_candidates(self, node: ThoughtNode, problem: str) -> list[ThoughtNode]:
        """生成下一步思考的候选"""
        path = node.get_path()
        context = "\n".join(path)

        prompt = f"""
        Problem: {problem}

        Current thinking path:
        {context}

        Generate {self.branching_factor} different possible next thinking steps.
        Each step should be a distinct approach or direction.

        Return as JSON array of strings.
        """

        response = self.llm.invoke(
            prompt,
            response_format={"type": "json_object"}
        )

        try:
            candidates = json.loads(response.content).get("steps", [])
        except:
            candidates = [f"Continue reasoning: step {node.depth + 1}"]

        return [
            ThoughtNode(content=step, depth=node.depth + 1, parent=node)
            for step in candidates[:self.branching_factor]
        ]

    def _evaluate(self, node: ThoughtNode, problem: str) -> float:
        """评估节点质量"""
        path = node.get_path()
        context = "\n".join(path)

        prompt = f"""
        Evaluate the quality of this reasoning path for the given problem.
        Score from 0.0 (worst) to 1.0 (best).

        Problem: {problem}
        Reasoning path:
        {context}

        Consider:
        - Logical correctness
        - Progress toward solving the problem
        - Completeness of reasoning

        Return only a number between 0.0 and 1.0.
        """

        try:
            score = float(self.llm.invoke(prompt).content.strip())
            return max(0.0, min(1.0, score))
        except:
            return 0.5

    场景 为什么用 ToT

    复杂数学题 尝试不同解题策略

    5. Self-Consistency¶

    5.1 核心思想¶

    多次采样取共识——对同一个问题多次独立推理，选择出现频率最高的答案。

    问题: 2+2=?

采样1: → 4
采样2: → 4
采样3: → 5  ← 异常值
采样4: → 4
采样5: → 4

共识: 4 (4/5) ✅

    5.2 实现¶

    from collections import Counter

class SelfConsistencyReasoner:
    """Self-Consistency 推理"""

    def __init__(self, llm, num_samples: int = 5, temperature: float = 0.7):
        self.llm = llm
        self.num_samples = num_samples
        self.temperature = temperature

    def reason(self, question: str) -> dict:
        """多次采样并取共识"""
        answers = []
        all_traces = []

        for i in range(self.num_samples):
            # 用较高 temperature 增加多样性
            prompt = f"""
            {question}

            Think step by step, then give your final answer.
            Format: "Final Answer: [answer]"
            """

            response = self.llm.invoke(
                prompt,
                temperature=self.temperature,
            ).content

            # 提取答案
            answer = self._extract_answer(response)
            answers.append(answer)
            all_traces.append(response)

        # 统计共识
        counter = Counter(answers)
        best_answer, count = counter.most_common(1)[0]
        consensus_score = count / self.num_samples

        return {
            "answer": best_answer,
            "consensus_score": consensus_score,
            "all_answers": answers,
            "all_traces": all_traces,
        }

    def _extract_answer(self, text: str) -> str:
        """提取 Final Answer"""
        if "Final Answer:" in text:
            return text.split("Final Answer:")[-1].strip()
        return text.strip()[-100:]  # 兜底：取最后 100 字符

    5.3 成本优化¶

    Self-Consistency 的 token 消耗 = num_samples × 单次消耗。优化策略：

    class CostOptimizedSelfConsistency:
    """成本优化的 Self-Consistency"""

    def __init__(self, base_llm, cheap_llm, num_samples: int = 5):
        self.base_llm = base_llm     # 高质量模型
        self.cheap_llm = cheap_llm   # 轻量模型
        self.num_samples = num_samples

    def reason(self, question: str) -> dict:
        # 用轻量模型做多次采样
        answers = []
        for _ in range(self.num_samples):
            response = self.cheap_llm.invoke(
                f"{question}\nThink step by step. Final Answer:",
                temperature=0.7,
            ).content
            answers.append(self._extract_answer(response))

        # 取共识
        counter = Counter(answers)
        best_answer, _ = counter.most_common(1)[0]

        # 用高质量模型验证共识答案
        verification = self.base_llm.invoke(f"""
        Question: {question}
        Proposed answer: {best_answer}

        Is this answer correct? Explain briefly.
        Answer "yes" or "no" with reasoning.
        """)

        return {
            "answer": best_answer,
            "verification": verification.content,
        }

    6. 推理策略选择指南¶

    问题复杂度评估
    │
    ├── 简单事实查询 ────────→  Direct (无需推理)
    │
    ├── 需要逻辑推导 ────────→  CoT
    │   ── 数学/逻辑题 ────→  CoT + Self-Consistency
    │
    ├── 需要外部信息/工具 ───→  ReAct
    │   └── 多步骤复杂任务 ──→  ReAct + CoT（每一步用 CoT）
    │
    ├── 需要探索多种方案 ────→  Tree of Thoughts
    │
    └── 需要全局规划执行 ────→  Plan-and-Execute
        └── （详见 Planning 模块）

    7. LangGraph 推理策略路由¶

    from typing import TypedDict, Literal
from langgraph.graph import StateGraph, END

class ReasoningState(TypedDict):
    question: str
    complexity: str  # simple/medium/complex/creative
    requires_tools: bool
    reasoning_method: str
    result: dict

def classify_problem(state: ReasoningState) -> ReasoningState:
    """分类问题复杂度，选择合适的推理策略"""
    prompt = f"""
    Classify this problem and recommend a reasoning strategy:

    Problem: {state['question']}

    Return JSON:
    {{
        "complexity": "simple|medium|complex|creative",
        "requires_tools": true/false,
        "reasoning_method": "direct|cot|react|tot|plan_execute"
    }}
    """

    classification = json.loads(
        llm.invoke(prompt, response_format={"type": "json_object"}).content
    )

    return {
        **state,
        **classification,
    }

def route_reasoning(state: ReasoningState) -> Literal[
    "direct", "cot", "react", "tot", "plan_execute"
]:
    return state["reasoning_method"]

# 构建推理路由图
builder = StateGraph(ReasoningState)
builder.add_node("classify", classify_problem)
builder.add_node("direct", lambda s: {**s, "result": {"answer": "直接回答"}})
builder.add_node("cot", cot_reasoning)
builder.add_node("react", lambda s: {**s, "result": {"answer": "ReAct 推理"}})
builder.add_node("tot", lambda s: {**s, "result": {"answer": "ToT 推理"}})
builder.add_node("plan_execute", lambda s: {**s, "result": {"answer": "Plan-Execute"}})

builder.set_entry_point("classify")
builder.add_conditional_edges("classify", route_reasoning)

for node in ["direct", "cot", "react", "tot", "plan_execute"]:
    builder.add_edge(node, END)

reasoning_router = builder.compile()

    9. 面试速记¶

    9.1 CoT / ToT / Self-Consistency 对比¶

    模式 一句话 适用场景 成本
    CoT 让模型显式写出推理步骤 需要逻辑推导的题目 低
    ToT 多路径探索，选最优 创意、策略等多可行路径问题 高
    Self-Consistency 多次采样取共识 对准确性要求极高的场景 中

    成本排序：CoT < Self-Consistency < ToT（通常）

    面试加分：Self-Consistency 可用"轻量模型多次采样 + 重模型验证"来优化成本（见 5.3 成本优化）。

    9.2 Self-Consistency 手写速记¶

    from collections import Counter

def self_consistency_cot(llm, question, n=5, temperature=0.7):
    """Self-Consistency + Chain-of-Thought"""
    answers = []
    for _ in range(n):
        response = llm(f"{question}\nLet's think step by step. Final Answer:", temperature=temperature)
        if "Final Answer:" in response:
            answers.append(response.split("Final Answer:")[-1].strip())
        else:
            answers.append(response.strip()[-50:])
    best, count = Counter(answers).most_common(1)[0]
    return {"answer": best, "consensus": count / n, "all_answers": answers}

    12. 面试话术速记¶

    Q: CoT、ReAct、ToT 有什么区别？

    "这三个是推理策略的递进： - CoT（Chain-of-Thought）：线性思考链，一步步推理，适合简单问题 - ReAct（Reasoning + Acting）：边想边做，每步推理后调用工具，根据观察继续推理，适合需要外部信息的任务 - ToT（Tree-of-Thought）：树状探索，在关键决策点尝试多条路径，选最优的，适合复杂决策

    工程上，ReAct 是最常用的，因为它平衡了推理深度和执行效率。"

    Q: 如何选择推理策略？

    "根据任务复杂度选择： - 简单问答 → 直接回答（无推理） - 需要推理 → CoT - 需要工具 → ReAct - 复杂决策 → ToT - 高风险任务 → ReAct + Self-Reflection

    核心原则：能用简单的不用复杂的，因为推理越深，token 消耗越大，延迟越高。"

    加分项：提到"Reasoning 是 Loop Engineering 的核心，好的推理策略能让 Agent Loop 更高效"。
