    Self-Reflection 自反思¶

    Agent 的"元认知"——让 Agent 能评估自己、纠正错误、持续改进。

    1. 模块定位¶

    Self-Reflection 让 Agent 从 "做了就完" 升级为 "做了再想想对不对"。

    没有 Self-Reflection:              有 Self-Reflection:

User: 这段代码有 bug 吗？          User: 这段代码有 bug 吗？
  │                                  │
  ▼                                  ▼
Agent: 没有 bug。                  Agent: 让我检查一下...
(实际有边界条件 bug)                 ↓
                                   检查 → 发现边界条件问题
                                   ↓
                                   Agent: 有一个边界条件 bug，
                                   当输入为空列表时会出错。
                                   修复方案如下...

    核心价值： - 减少幻觉和错误输出 - 提升复杂任务的完成率 - 形成自我改进的闭环

    2. Critique（批评/审查）¶

    2.1 基础 Critique¶

    from pydantic import BaseModel, Field

class CritiqueResult(BaseModel):
    """审查结果"""
    issues: list[dict] = Field(description="发现的问题列表")
    severity: str = Field(description="整体严重程度: critical/major/minor/none")
    suggestions: list[str] = Field(description="改进建议")
    needs_revision: bool = Field(description="是否需要修改")

class Critiquer:
    """通用审查器"""

    CRITIQUE_PROMPT = """
    Critically review the following output against the original request.

    Original Request:
    {request}

    Output to Review:
    {output}

    Check for:
    1. Correctness: Is the output factually and logically correct?
    2. Completeness: Does it fully address the request?
    3. Quality: Is the output well-structured and clear?
    4. Edge cases: Are there any overlooked scenarios?
    5. Safety: Is there anything harmful or inappropriate?

    For each issue found, specify:
    - type: correctness/completeness/quality/edge_case/safety
    - description: what's wrong
    - severity: critical/major/minor
    - suggestion: how to fix it

    Return JSON matching the CritiqueResult schema.
    """

    def __init__(self, llm):
        self.llm = llm

    def critique(self, request: str, output: str) -> CritiqueResult:
        """执行审查"""
        prompt = self.CRITIQUE_PROMPT.format(
            request=request,
            output=output,
        )
        return self.llm.with_structured_output(CritiqueResult).invoke(prompt)

# 使用
critiquer = Critiquer(llm)

result = critiquer.critique(
    request="写一个快速排序函数",
    output="""
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]
    left = [x for x in arr[1:] if x < pivot]
    right = [x for x in arr[1:] if x >= pivot]
    return quicksort(left) + [pivot] + quicksort(right)
    """,
)

print(f"严重程度: {result.severity}")
print(f"需要修改: {result.needs_revision}")
for issue in result.issues:
    print(f"  [{issue['severity']}] {issue['description']}")
    print(f"    建议: {issue['suggestion']}")

    class CodeCritiquer(Critiquer):
    """代码审查器"""

    CRITIQUE_PROMPT = """
    Perform a professional code review:

    Code:
    ```{language}
    {output}
    ```

    Review criteria:
    1. Correctness: Logic errors, edge cases, off-by-one errors
    2. Performance: Time/space complexity, unnecessary operations
    3. Security: Injection, XSS, path traversal, etc.
    4. Style: Naming conventions, formatting, documentation
    5. Best practices: Language-specific idioms and patterns

    Language: {language}

    Return JSON matching CritiqueResult schema.
    """

    def critique_code(self, code: str, language: str = "python", context: str = "") -> CritiqueResult:
        prompt = self.CRITIQUE_PROMPT.format(
            language=language,
            output=code,
        )
        return self.llm.with_structured_output(CritiqueResult).invoke(prompt)


class TextCritiquer(Critiquer):
    """文本审查器"""

    CRITIQUE_PROMPT = """
    Review this text content:

    {output}

    Review criteria:
    1. Grammar and spelling
    2. Clarity and coherence
    3. Tone appropriateness
    4. Factual accuracy
    5. Structure and flow

    Return JSON matching CritiqueResult schema.
    """

    def critique_text(self, text: str) -> CritiqueResult:
        prompt = self.CRITIQUE_PROMPT.format(output=text)
        return self.llm.with_structured_output(CritiqueResult).invoke(prompt)

    2.3 LangGraph Critique 节点¶

    from typing import TypedDict, Literal
from langgraph.graph import StateGraph, END

class CritiqueState(TypedDict):
    request: str
    draft: str
    critique: CritiqueResult
    revised: str
    revision_count: int

def critique_node(state: CritiqueState) -> CritiqueState:
    """审查节点"""
    critiquer = Critiquer(llm)
    result = critiquer.critique(state["request"], state["draft"])
    return {
        **state,
        "critique": result,
        "revision_count": state.get("revision_count", 0) + 1,
    }

def revise_node(state: CritiqueState) -> CritiqueState:
    """修订节点"""
    critique_text = json.dumps(state["critique"].dict(), ensure_ascii=False, indent=2)

    prompt = f"""
    Revise the following draft based on the critique:

    Original draft:
    {state['draft']}

    Critique:
    {critique_text}

    Return the revised version that addresses all issues.
    """

    revised = llm.invoke(prompt).content
    return {**state, "revised": revised}

def should_revise(state: CritiqueState) -> Literal["revise", END]:
    """判断是否需要修订"""
    # 达到最大修订次数
    if state.get("revision_count", 0) >= 3:
        return END

    # 审查认为需要修改
    if state["critique"].needs_revision:
        return "revise"

    return END

# 构建审查-修订循环
builder = StateGraph(CritiqueState)
builder.add_node("critique", critique_node)
builder.add_node("revise", revise_node)

builder.set_entry_point("critique")
builder.add_conditional_edges("critique", should_revise)
builder.add_edge("revise", "critique")

critique_graph = builder.compile()

# 使用
result = critique_graph.invoke({
    "request": "写一个线程安全的计数器类",
    "draft": """
class Counter:
    def __init__(self):
        self.count = 0

    def increment(self):
        self.count += 1

    def get(self):
        return self.count
    """,
})

print(f"修订次数: {result['revision_count']}")
print(f"最终版本: {result.get('revised', result['draft'])}")

    3. Self-Correction（自我纠正）¶

    3.1 基于 Critique 的 Self-Correction¶

    class SelfCorrectingAgent:
    """带自我纠正能力的 Agent"""

    MAX_CORRECTIONS = 3

    def __init__(self, llm, tools: dict = None):
        self.llm = llm
        self.tools = tools or {}
        self.critiquer = Critiquer(llm)

    def run(self, request: str) -> dict:
        """执行带自我纠正的任务"""
        attempt = 1
        current_output = ""
        history = []

        while attempt <= self.MAX_CORRECTIONS:
            # 生成或修订输出
            if attempt == 1:
                current_output = self._generate(request)
            else:
                current_output = self._revise(request, current_output, history[-1]["critique"])

            # 审查输出
            critique = self.critiquer.critique(request, current_output)

            history.append({
                "attempt": attempt,
                "output": current_output,
                "critique": critique,
            })

            # 如果没有问题，返回
            if not critique.needs_revision:
                return {
                    "output": current_output,
                    "attempts": attempt,
                    "history": history,
                    "status": "success",
                }

            # 有严重问题，继续纠正
            if critique.severity in ("critical", "major"):
                attempt += 1
                continue

            # 只有 minor 问题，可以接受
            return {
                "output": current_output,
                "attempts": attempt,
                "history": history,
                "status": "accepted_with_minor_issues",
                "notes": [i["description"] for i in critique.issues],
            }

        # 达到最大纠正次数
        return {
            "output": current_output,
            "attempts": attempt,
            "history": history,
            "status": "max_corrections_reached",
        }

    def _generate(self, request: str) -> str:
        """首次生成"""
        prompt = f"""
        {request}

        Think carefully and provide your best answer.
        """
        return self.llm.invoke(prompt).content.strip()

    def _revise(self, request: str, previous_output: str, critique: CritiqueResult) -> str:
        """基于审查结果修订"""
        issues_text = "\n".join(
            f"- [{i['severity']}] {i['description']}: {i['suggestion']}"
            for i in critique.issues
        )

        prompt = f"""
        Revise your previous output based on the following critique:

        Request: {request}

        Previous output:
        {previous_output}

        Issues to fix:
        {issues_text}

        Provide the revised output. Only return the revised content.
        """

        return self.llm.invoke(prompt).content.strip()

# 使用
agent = SelfCorrectingAgent(llm)
result = agent.run("写一个 Python 装饰器，用于记录函数执行时间")

print(f"状态: {result['status']}")
print(f"尝试次数: {result['attempts']}")
print(f"输出: {result['output']}")

    3.2 执行后验证（Execution-based Verification）¶

    对于可验证的任务（如代码、数学），可以用 执行结果 来判断对错：

    class VerifyAndCorrect:
    """执行验证 + 自动纠正"""

    def __init__(self, llm, executor, max_attempts: int = 3):
        self.llm = llm
        self.executor = executor  # 代码执行器
        self.max_attempts = max_attempts

    def run(self, request: str) -> dict:
        attempt = 1

        while attempt <= self.max_attempts:
            # 生成代码
            if attempt == 1:
                code = self._generate_code(request)
            else:
                code = self._fix_code(request, code, error_msg)

            # 执行验证
            success, output, error_msg = self.executor.execute(code)

            if success:
                return {
                    "code": code,
                    "output": output,
                    "attempts": attempt,
                    "status": "success",
                }

            attempt += 1

        return {
            "code": code,
            "error": error_msg,
            "attempts": attempt,
            "status": "failed",
        }

    def _generate_code(self, request: str) -> str:
        prompt = f"""
        {request}

        Write the complete code. Include test cases.
        Return only the code, no explanations.
        """
        return self.llm.invoke(prompt).content.strip()

    def _fix_code(self, request: str, code: str, error: str) -> str:
        prompt = f"""
        Fix the following code. It has this error:

        Error: {error}

        Code:
        {code}

        Request: {request}

        Return the fixed code only.
        """
        return self.llm.invoke(prompt).content.strip()

# 使用
from code_execution_sandbox import CodeExecutionSandbox

verifier = VerifyAndCorrect(
    llm=llm,
    executor=CodeExecutionSandbox(),
)
result = verifier.run("写一个函数，计算两个矩阵的乘积")
print(f"状态: {result['status']}")

    4. 反思性改进（Reflective Improvement）¶

    4.1 从错误中学习¶

    class ReflectiveLearner:
    """从历史错误中学习的反思系统"""

    def __init__(self, llm, memory):
        self.llm = llm
        self.memory = memory  # 长期记忆
        self.error_patterns: list[dict] = []

    def record_error(self, request: str, output: str, critique: CritiqueResult):
        """记录错误"""
        error_record = {
            "request": request,
            "output_summary": output[:200],
            "issues": [
                {
                    "type": i.get("type", ""),
                    "description": i.get("description", ""),
                    "severity": i.get("severity", ""),
                }
                for i in critique.issues
            ],
        }
        self.error_patterns.append(error_record)

        # 存入长期记忆
        if critique.severity in ("critical", "major"):
            lesson = self._extract_lesson(error_record)
            self.memory.store(
                content=lesson,
                category="lessons",
                importance=0.8 if critique.severity == "critical" else 0.6,
            )

    def _extract_lesson(self, error_record: dict) -> str:
        """从错误中提取教训"""
        prompt = f"""
        Based on this error, extract a general lesson learned:

        Request: {error_record['request']}
        Issues: {json.dumps(error_record['issues'], indent=2)}

        Return a concise lesson (1-2 sentences) that can help avoid similar errors in the future.
        """
        return self.llm.invoke(prompt).content.strip()

    def get_relevant_lessons(self, request: str) -> list[str]:
        """获取与当前请求相关的历史教训"""
        memories = self.memory.retrieve(
            query=request,
            category_filter="lessons",
            top_k=3,
        )
        return [m["content"] for m in memories]

    def generate_with_lessons(self, request: str) -> str:
        """带历史教训的生成"""
        lessons = self.get_relevant_lessons(request)

        prompt = f"""
        {request}

        Important lessons from past mistakes (keep these in mind):
        {chr(10).join(f"- {l}" for l in lessons)}

        Think carefully and provide your answer.
        """

        return self.llm.invoke(prompt).content.strip()

    4.2 定期反思总结¶

    class PeriodicReflector:
    """定期反思：从近期所有交互中提炼洞察"""

    def __init__(self, llm, memory):
        self.llm = llm
        self.memory = memory

    def reflect_on_session(self, session_history: list[dict]) -> dict:
        """对一次会话进行反思总结"""
        history_text = "\n".join(
            f"Turn {i+1}: {h.get('request', '')[:100]}... → {h.get('status', '')}"
            for i, h in enumerate(session_history)
        )

        prompt = f"""
        Reflect on this agent session:

        {history_text}

        Provide:
        1. What went well
        2. What could be improved
        3. Patterns noticed
        4. Recommendations for future interactions

        Return JSON:
        {{
            "went_well": ["list"],
            "needs_improvement": ["list"],
            "patterns": ["list"],
            "recommendations": ["list"]
        }}
        """

        return json.loads(
            self.llm.invoke(
                prompt,
                response_format={"type": "json_object"}
            ).content
        )

    5. Self-Reflection 在 LangGraph 中的集成¶

    5.1 完整的 ReAct + Reflect 循环¶

    from typing import TypedDict, Literal
from langgraph.graph import StateGraph, END

class ReActReflectState(TypedDict):
    messages: list
    step_count: int
    last_critique: str
    max_steps: int

def agent_think_act(state: ReActReflectState) -> ReActReflectState:
    """Think + Act 节点"""
    response = llm.bind_tools(tools).invoke(state["messages"])
    return {
        "messages": state["messages"] + [response],
        "step_count": state["step_count"] + 1,
    }

def agent_reflect(state: ReActReflectState) -> ReActReflectState:
    """Reflect 节点：自我审查最后一步的结果"""
    last_msg = state["messages"][-1]

    prompt = f"""
    Review your last action's result:

    {last_msg.content[:1000]}

    Self-assessment questions:
    1. Did I accomplish what I intended?
    2. Is the result correct and complete?
    3. Should I continue or is the task done?

    Return:
    - "continue" if more work is needed
    - "done" if the task is complete
    - "revise" if the last result needs fixing

    Also provide a brief self-critique.
    """

    response = llm.invoke(prompt).content.strip().lower()

    if "done" in response:
        decision = END
    elif "revise" in response:
        decision = "revise"
    else:
        decision = "continue"

    return {
        **state,
        "last_critique": response,
        "_route_decision": decision,
    }

def agent_revise(state: ReActReflectState) -> ReActReflectState:
    """Revise 节点：根据反思修订"""
    prompt = f"""
    Your last action had issues. Review and revise:

    Previous result: {state["messages"][-1].content[:1000]}

    Self-critique: {state["last_critique"]}

    Provide an improved result.
    """

    revised = llm.invoke(prompt)
    return {
        "messages": state["messages"] + [revised],
    }

def route_after_reflect(state: ReActReflectState) -> str:
    decision = state.get("_route_decision", "continue")

    if decision == END:
        return END
    if decision == "revise":
        return "revise"

    # 检查步数限制
    if state["step_count"] >= state.get("max_steps", 10):
        return END

    return "agent"

# 构建完整循环
builder = StateGraph(ReActReflectState)
builder.add_node("agent", agent_think_act)
builder.add_node("tools", tool_node)
builder.add_node("reflect", agent_reflect)
builder.add_node("revise", agent_revise)

builder.set_entry_point("agent")
builder.add_conditional_edges("agent", lambda s: "tools" if hasattr(s["messages"][-1], "tool_calls") and s["messages"][-1].tool_calls else "reflect")
builder.add_edge("tools", "agent")
builder.add_conditional_edges("reflect", route_after_reflect)
builder.add_edge("revise", "reflect")

react_reflect_graph = builder.compile()

    6. Self-Reflection 模式总结¶

    模式 机制 适用场景
    Critique 独立审查节点评估输出质量 内容生成、代码编写
    Self-Correction 根据 Critique 自动修订 需要高质量输出的任务
    Verify-and-Correct 执行验证 + 错误修复 代码、数学等可验证任务
    Reflective Learning 从历史错误中提取教训 长期运行的 Agent
    Periodic Reflection 定期回顾和总结 会话级别的元分析

    7. Self-Reflection Checklist¶

    • Critique 节点：独立审查输出质量
    • Self-Correction：自动修订发现的问题
    • 执行验证：代码/数学任务的自动化验证
    • 修订次数限制：防止无限修订循环
    • 错误记录：记录历史错误模式
    • 教训提取：从错误中提炼可复用的教训
    • 教训注入：生成时自动加载相关历史教训
    • 定期反思：会话级别的元分析和总结

    8. 与 Control Loop 的关系¶

    Control Loop 决定"什么时候反思"
    ↓
Self-Reflection 决定"怎么反思、怎么改进"
    ↓
改进后的输出回到 Control Loop 继续评估

    Self-Reflection 是 Control Loop 中 Reflect 阶段的具体实现方式。

    10. 与其他模块的关系¶

    Self-Reflection (自反思)
    │
    ├──← Reasoning (推理层)：接收推理结果进行审查
    ├──← Planning (规划层)：接收计划结果进行验证
    ├──→ Memory (记忆层)：将错误教训存入长期记忆
    ├──→ Control Loop (控制循环)：作为 Reflect 阶段的核心
    └──→ Evaluation (评估层)：提供自我评估能力

    12. 面试话术速记¶

    Q: Self-Reflection 的核心价值是什么？

    "Self-Reflection 让 Agent 从'做了就完'升级为'做了再想想对不对'，核心价值有三个： 1. 减少幻觉：通过自我审查发现事实错误 2. 提升质量：通过 Critique-Revise 循环持续改进输出 3. 从错误中学习：把错误教训存入长期记忆，避免重复犯错

    工程上，我们用 LLM-as-Critiquer 做审查，用 结构化输出定义问题类型，用 最大修订次数防止无限循环。"

    Q: Critique-Revise 循环怎么实现？

    "核心流程： 1. 生成：Agent 生成初始输出 2. 审查：用另一个 LLM（或同一个模型）审查输出，找出问题 3. 修订：根据审查结果修订输出 4. 判断：如果还有严重问题，继续循环；否则返回

    关键设计： - 用 Pydantic 结构化输出定义审查结果（问题类型、严重程度、建议） - 设置 最大修订次数（通常 3 次），防止无限循环 - 只有 critical/major 问题才继续修订，minor 问题可以接受"

    加分项：提到"Self-Reflection 是 Loop Engineering 的 Reflect 阶段，好的反思机制能让 Agent 像人一样从错误中学习"。
