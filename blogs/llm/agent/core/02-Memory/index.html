    Memory 记忆系统¶

    Agent 的"海马体"——管理短期记忆、会话上下文、长期知识库。

    1. 模块定位¶

    Memory 是 Agent 实现 跨轮次、跨会话、跨任务 连续性的核心。没有记忆，Agent 每次对话都从零开始。

    ┌─────────────────────────────────────────────────────────┐
│                   Memory Architecture                    │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌─────────────┐   ┌─────────────┐   ┌───────────────┐  │
│  │ Short-Term  │   │   Session   │   │   Knowledge   │  │
│  │  Working    │←→│   Context   │←→│   Long-Term   │  │
│  │  Memory     │   │   Memory    │   │   Memory      │  │
│  ─────────────┘   └─────────────┘   └───────────────  │
│       ↑                  ↑                  ↑            │
│    RAM / Cache       Context Window      Vector DB      │
│    (几轮对话)        (当前会话)          (永久存储)      │
│                                                         │
└─────────────────────────────────────────────────────────┘
    层级 容量 生命周期 存储方式 检索速度
    Short-Term 极小（几KB） 几轮对话 内存 / Context 即时
    Session 中等（几十KB） 当前会话 Context Window 即时
    Knowledge 极大（GB+） 永久 Vector DB + 文件 秒级检索

    2. Short-Term Memory（短期记忆 / Working Memory）¶

    2.1 概念¶

    短期记忆是 Agent 当前工作线程 中保持的上下文，通常通过 Context Window 管理 来实现。

    核心问题：Context Window 有限，如何优先保留最重要的信息？

    2.2 实现策略¶

    策略 A：滑动窗口（最简单）¶

    class SlidingWindowMemory:
    """保留最近 N 轮对话"""

    def __init__(self, max_messages: int = 10):
        self.messages: list = []
        self.max_messages = max_messages

    def add(self, message: dict):
        self.messages.append(message)
        # 超出限制时删除最旧的
        while len(self.messages) > self.max_messages:
            self.messages.pop(0)

    def get_context(self) -> list:
        return self.messages.copy()

    缺点：可能丢掉重要但不"新"的信息。

    策略 B：重要性过滤（推荐）¶

    from langchain_core.messages import AIMessage, HumanMessage, SystemMessage

class ImportanceBasedMemory:
    """基于重要性评分的短期记忆管理"""

    def __init__(self, llm, max_tokens: int = 4000):
        self.messages: list = []
        self.llm = llm
        self.max_tokens = max_tokens
        self.system_message: SystemMessage | None = None

    def add(self, message: HumanMessage | AIMessage):
        # 为每条消息计算重要性分数
        importance = self._score_importance(message)
        self.messages.append({
            "message": message,
            "importance": importance,
            "age": 0,  # 年龄（轮次）
        })

    def _score_importance(self, message) -> float:
        """用轻量模型评估消息重要性 (0-1)"""
        content = message.content[:500]
        prompt = f"""
        Rate the importance of this message for future context (0.0 to 1.0):
        - 1.0: Critical decisions, user preferences, key facts
        - 0.7: Important task details, intermediate results
        - 0.4: General conversation, minor details
        - 0.1: Greetings, filler, acknowledgments

        Message: {content}
        Score (number only):
        """
        try:
            score = float(self.llm.invoke(prompt).content.strip())
            return max(0.0, min(1.0, score))
        except:
            return 0.5  # 默认中等重要性

    def trim_to_budget(self) -> list:
        """裁剪到 token 预算内，保留重要消息"""
        # 计算总 tokens
        total_tokens = sum(
            len(m["message"].content) // 4  # 粗略估算
            for m in self.messages
        )

        if total_tokens <= self.max_tokens:
            return [m["message"] for m in self.messages]

        # 按 importance * decay 排序
        for m in self.messages:
            m["age"] += 1
            m["score"] = m["importance"] * (0.95 ** m["age"])

        # 保留分数最高的消息
        self.messages.sort(key=lambda x: x["score"], reverse=True)
        kept = []
        tokens = 0
        for m in self.messages:
            msg_tokens = len(m["message"].content) // 4
            if tokens + msg_tokens <= self.max_tokens:
                kept.append(m)
                tokens += msg_tokens

        self.messages = kept
        return [m["message"] for m in kept]

    策略 C：摘要压缩（适合长对话）¶

    class SummarizingMemory:
    """定期将旧对话压缩为摘要"""

    def __init__(self, llm, summary_interval: int = 5):
        self.messages: list = []
        self.summaries: list[str] = []  # 历史摘要
        self.llm = llm
        self.summary_interval = summary_interval

    def add(self, message):
        self.messages.append(message)

        # 达到间隔时触发摘要
        if len(self.messages) >= self.summary_interval:
            self._compress()

    def _compress(self):
        """将旧消息压缩为摘要"""
        old_messages = self.messages[:-2]  # 保留最后 2 条
        conversation_text = "\n".join(
            f"{type(m).__name__}: {m.content[:200]}"
            for m in old_messages
        )

        prompt = f"""
        Summarize this conversation concisely. Include:
        - Key decisions made
        - Important facts discovered
        - User preferences mentioned
        - Current task status

        Conversation:
        {conversation_text}

        Summary (2-3 sentences):
        """
        summary = self.llm.invoke(prompt).content.strip()
        self.summaries.append(summary)

        # 保留最后 2 条消息
        self.messages = self.messages[-2:]

    def get_context(self) -> list:
        """构建完整上下文：摘要 + 近期消息"""
        context = []

        # 添加历史摘要
        if self.summaries:
            summary_text = "\n\n".join(
                f"[Past Conversation Summary {i+1}]: {s}"
                for i, s in enumerate(self.summaries)
            )
            context.append(SystemMessage(content=f"Previous conversation summaries:\n{summary_text}"))

        # 添加近期消息
        context.extend(self.messages)
        return context

    class SessionState:
    """完整的会话状态管理"""

    def __init__(self, session_id: str):
        self.session_id = session_id
        self.messages: list = []
        self.variables: dict = {}      # 临时变量
        self.tools_used: list = []     # 工具使用记录
        self.errors: list = []         # 错误历史
        self.metadata: dict = {        # 元数据
            "created_at": None,
            "last_active": None,
            "turn_count": 0,
            "total_tokens": 0,
        }

    def snapshot(self) -> dict:
        """创建状态快照（用于恢复）"""
        return {
            "session_id": self.session_id,
            "messages": self.messages[-20:],  # 最近 20 条
            "variables": self.variables,
            "metadata": self.metadata,
        }

    def restore(self, snapshot: dict):
        """从快照恢复"""
        self.messages = snapshot["messages"]
        self.variables = snapshot["variables"]
        self.metadata = snapshot["metadata"]

    4.2 基于 ChromaDB 的实现¶

    import chromadb
from chromadb.utils import embedding_functions
from datetime import datetime
from typing import Optional

class LongTermMemory:
    """基于向量数据库的长期记忆"""

    def __init__(
        self,
        db_path: str = "./memory_db",
        collection_name: str = "agent_memory",
        embedding_model: str = "all-MiniLM-L6-v2",
    ):
        self.client = chromadb.PersistentClient(path=db_path)

        # 使用 sentence-transformers 嵌入
        self.embedder = embedding_functions.SentenceTransformerEmbeddingFunction(
            model_name=embedding_model
        )

        self.collection = self.client.get_or_create_collection(
            name=collection_name,
            embedding_function=self.embedder,
            metadata={"description": "Agent long-term memory"},
        )

    def store(
        self,
        content: str,
        category: str = "general",
        importance: float = 0.5,
        metadata: dict = None,
    ) -> str:
        """存储记忆"""
        doc_id = f"{category}_{datetime.now().strftime('%Y%m%d_%H%M%S')}_{hash(content) % 10000}"

        doc_metadata = {
            "category": category,
            "importance": importance,
            "created_at": datetime.now().isoformat(),
            "content_length": len(content),
        }
        if metadata:
            doc_metadata.update(metadata)

        self.collection.add(
            documents=[content],
            metadatas=[doc_metadata],
            ids=[doc_id],
        )

        return doc_id

    def retrieve(
        self,
        query: str,
        top_k: int = 5,
        category_filter: str = None,
        min_importance: float = 0.0,
    ) -> list[dict]:
        """检索相关记忆"""
        where_clause = {}
        if category_filter:
            where_clause["category"] = category_filter
        if min_importance > 0:
            where_clause["importance"] = {"$gte": min_importance}

        results = self.collection.query(
            query_texts=[query],
            n_results=top_k,
            where=where_clause if where_clause else None,
        )

        return [
            {
                "content": doc,
                "id": id_,
                "metadata": meta,
                "distance": dist,
                "relevance": 1.0 - dist,  # 转换为相关度分数
            }
            for doc, id_, meta, dist in zip(
                results["documents"][0],
                results["ids"][0],
                results["metadatas"][0],
                results["distances"][0],
            )
        ]

    def update(self, doc_id: str, new_content: str):
        """更新记忆"""
        self.collection.update(
            ids=[doc_id],
            documents=[new_content],
        )

    def delete(self, doc_id: str):
        """删除记忆"""
        self.collection.delete(ids=[doc_id])

    def forget_old(self, max_age_days: int = 90, keep_important: bool = True):
        """清理过期记忆"""
        cutoff = datetime.now()
        # ChromaDB 的日期过滤需要自定义逻辑
        all_results = self.collection.get()
        to_delete = []

        for doc_id, meta in zip(all_results["ids"], all_results["metadatas"]):
            created = datetime.fromisoformat(meta["created_at"])
            age_days = (cutoff - created).days
            if age_days > max_age_days:
                if not (keep_important and meta.get("importance", 0) > 0.8):
                    to_delete.append(doc_id)

        if to_delete:
            self.collection.delete(ids=to_delete)

        return len(to_delete)

    4.4 自动记忆提取¶

    class AutoMemoryExtractor:
    """自动从对话中提取值得记忆的内容"""

    def __init__(self, llm, memory: LongTermMemory):
        self.llm = llm
        self.memory = memory

    def extract_from_conversation(
        self,
        messages: list,
    ) -> list[dict]:
        """从对话中提取记忆点"""
        conv_text = "\n".join(
            f"{m['role']}: {m['content'][:300]}"
            for m in messages[-10:]  # 最近 10 条
        )

        prompt = f"""
        Analyze this conversation and extract memorable items.
        For each item, determine:
        - content: the key information (1-2 sentences)
        - category: one of [user_profile, preferences, project_info, code_snippets, decisions, lessons, patterns, conv_summary, follow_ups]
        - importance: 0.1-1.0 (how valuable for future reference)

        Only extract genuinely useful information. Skip greetings and acknowledgments.

        Conversation:
        {conv_text}

        Return a JSON array of memory items:
        """

        result = self.llm.invoke(
            prompt,
            response_format={"type": "json_object"}
        )

        try:
            items = json.loads(result.content).get("memories", [])
        except:
            items = []

        # 存储高重要度的记忆
        stored = []
        for item in items:
            if item.get("importance", 0) > 0.5:
                doc_id = self.memory.store(
                    content=item["content"],
                    category=item.get("category", "general"),
                    importance=item.get("importance", 0.5),
                )
                stored.append({"doc_id": doc_id, **item})

        return stored

    5. LangGraph Memory 集成示例¶

    from langgraph.graph import StateGraph, END
from langgraph.checkpoint.memory import MemorySaver
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages

class AgentState(TypedDict):
    messages: Annotated[list, add_messages]
    retrieved_memories: list
    current_query: str

# 初始化记忆系统
long_term_memory = LongTermMemory(db_path="./agent_memory")
checkpointer = MemorySaver()

def retrieve_relevant_memory(state: AgentState) -> AgentState:
    """从长期记忆中检索相关信息"""
    query = state["current_query"]

    memories = long_term_memory.retrieve(
        query=query,
        top_k=3,
        min_importance=0.3,
    )

    # 将检索到的记忆注入系统提示
    if memories:
        context = "\n\n".join(
            f"Memory (relevance: {m['relevance']:.2f}):\n{m['content']}"
            for m in memories
        )
        memory_msg = {
            "role": "system",
            "content": f"Relevant past memories:\n{context}"
        }
    else:
        memory_msg = {
            "role": "system",
            "content": "No relevant past memories found."
        }

    return {
        **state,
        "retrieved_memories": memories,
        "messages": [memory_msg] + state["messages"],
    }

def process_with_memory(state: AgentState) -> AgentState:
    """主处理节点（使用记忆增强）"""
    # ... 实际处理逻辑 ...
    response = {"role": "assistant", "content": "处理结果"}

    return {
        **state,
        "messages": [response],
    }

def extract_and_store_memory(state: AgentState) -> AgentState:
    """会话结束后提取记忆"""
    extractor = AutoMemoryExtractor(llm=llm, memory=long_term_memory)
    memories = extractor.extract_from_conversation(state["messages"])

    if memories:
        print(f"Stored {len(memories)} new memories")

    return state

# 构建图
builder = StateGraph(AgentState)
builder.add_node("retrieve", retrieve_relevant_memory)
builder.add_node("process", process_with_memory)
builder.add_node("extract_memory", extract_and_store_memory)

builder.set_entry_point("retrieve")
builder.add_edge("retrieve", "process")
builder.add_edge("process", "extract_memory")
builder.add_edge("extract_memory", END)

graph = builder.compile(checkpointer=checkpointer)

    6. 记忆刷新机制（Memory Consolidation）¶

    类似人脑的"睡眠巩固"，定期将短期记忆整合为长期记忆：

    class MemoryConsolidator:
    """记忆巩固：定期整理和提炼记忆"""

    def __init__(self, llm, memory: LongTermMemory):
        self.llm = llm
        self.memory = memory

    def consolidate(self):
        """执行记忆巩固"""
        # 1. 获取所有低重要度记忆
        all_memories = self.memory.collection.get()

        # 2. 找出相似记忆并合并
        merged = self._merge_similar(all_memories)

        # 3. 提炼新洞察
        insights = self._extract_insights(all_memories)

        # 4. 删除冗余
        self._remove_redundant(all_memories)

        return {
            "merged": len(merged),
            "insights": insights,
        }

    def _merge_similar(self, memories: dict) -> list:
        """合并相似记忆"""
        # 简化的相似度检查
        prompt = f"""
        Review these memories and merge similar ones:

        {json.dumps(memories["documents"], indent=2)}

        Return merged memories as JSON array.
        """
        result = self.llm.invoke(prompt, response_format={"type": "json_object"})
        return json.loads(result.content).get("merged_memories", [])

    def _extract_insights(self, memories: dict) -> list:
        """从记忆中提取新洞察"""
        prompt = f"""
        Based on these memories, what patterns or insights can you identify?

        Memories:
        {json.dumps(memories["documents"][:20], indent=2)}

        List 3-5 insights as JSON array.
        """
        result = self.llm.invoke(prompt, response_format={"type": "json_object"})
        return json.loads(result.content).get("insights", [])

    7. 最佳实践¶

    7.1 分层存储策略¶

    热数据（Session）→ 内存 / Redis       → 毫秒级
温数据（Recent） → SQLite / Local FS   → 秒级
冷数据（Archive） → Vector DB + 对象存储 → 秒-分钟级

    7.2 检索优化¶

    • Hybrid Search：向量检索 + 关键词检索（BM25）结合
    • Metadata Filtering：用元数据缩小检索范围
    • Re-ranking：用 Cross-Encoder 对检索结果重排

    7.3 记忆生命周期¶

    创建 → 短期记忆（几轮对话）
    ↓ 自动提取

    7.4 隐私保护¶

    class PrivacyFilter:
    """记忆存储前的隐私过滤"""

    SENSITIVE_PATTERNS = [
        r"\b\d{4}[-\s]?\d{4}[-\s]?\d{4}[-\s]?\d{4}\b",  # 信用卡
        r"\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b",  # 邮箱
        # ... 更多模式
    ]

    def filter(self, content: str) -> str:
        """过滤敏感信息"""
        for pattern in self.SENSITIVE_PATTERNS:
            content = re.sub(pattern, "[REDACTED]", content)
        return content

    9.1 记忆系统设计标准答案¶

    面试官问："如何设计 Agent 的记忆系统？"

    三层架构（这是标准答案）：

短期记忆（Short-term）  →  当前轮次的上下文窗口
会话记忆（Session）     →  本次对话的摘要/关键信息
长期记忆（Long-term）   →  跨会话的知识库（向量数据库）

关键实现细节：
- 短期：滑动窗口 / 摘要压缩，控制 token 成本
- 会话：LLM 自动提取关键信息写入
- 长期：ChromaDB / Milvus 等向量库，embedding + 语义检索
- 记忆巩固：定期把会话记忆提炼为长期记忆（类似人脑的睡眠巩固）

    9.2 手搓向量检索（面试可能要求）¶

    import chromadb

class MemoryStore:
    def __init__(self, path="./memory_db"):
        client = chromadb.PersistentClient(path)
        self.collection = client.get_or_create_collection("memories")
        self.id_counter = 0

    def store(self, content: str, metadata: dict = None):
        self.collection.add(
            documents=[content],
            ids=[str(self.id_counter)],
            metadatas=[metadata or {}],
        )
        self.id_counter += 1

    def retrieve(self, query: str, top_k: int = 3) -> list:
        results = self.collection.query(query_texts=[query], n_results=top_k)
        return results["documents"][0]

    12. 面试话术速记¶

    Q: Memory 的三层架构是什么？

    "Memory 分三层，对应不同的生命周期和存储方式： 1. 短期记忆（Working Memory）：当前对话的几轮，用滑动窗口管理，存在 Context Window 里 2. 会话记忆（Session Memory）：当前会话的完整上下文，用 LLM 摘要压缩，通过 Checkpoint 持久化 3. 长期记忆（Knowledge Memory）：跨会话的永久知识，用向量数据库存储，支持语义检索

    工程上，我们用重要性评分 + 时间衰减来决定哪些消息保留、哪些压缩、哪些存入长期记忆。"

    Q: 如何避免 Context Window 爆炸？

    "三个策略： 1. 滑动窗口：只保留最近 N 轮对话 2. 摘要压缩：定期用 LLM 把旧对话压缩成摘要 3. 重要性过滤：用轻量模型给每条消息打分，优先保留重要的

    生产环境推荐摘要压缩 + 重要性过滤组合，既能保留关键信息，又不会超出 token 限制。"

    加分项：提到"Memory 是 Context Engineering 的核心，好的记忆管理能让 Agent 像人一样'记住'重要事情"。
