    Agent Loop 防御机制¶

    面试必考题："Agent 陷入死循环一直重复同一个操作，怎么办？"

    一、面试官在问什么¶

    这个问题考察三个层面：

    1. 问题意识——你是否知道 Agent 会死循环？（很多新手不知道）
    2. 系统化思维——你能否从多维度给出防御方案？（不是只想到一个 max_iter）
    3. 工程能力——你写的代码能真正防住，还是纸上谈兵？

    二、标准答案框架（五层防御）¶

    用户问："Agent 陷入循环怎么办？"

你应该回答："我在 Agent 控制循环里做了五层防御：

 第一层：最大迭代次数 —— 硬限制
 第二层：重复动作检测 —— 识别模式循环
 第三层：Token 预算控制 —— 防止 token 爆炸
 第四层：超时机制 —— 防止永远跑不完
 第五层：状态收敛检测 —— 识别停滞状态

 五层配合，层层兜底。"

    三、五层防御完整实现¶

    第一层：最大迭代次数（最基本的）¶

    MAX_ITERATIONS = 10

for step in range(MAX_ITERATIONS):
    resp = llm(prompt)
    if "Final Answer:" in resp:
        return parse_answer(resp)
    # ... 执行工具

return "Max iterations reached. Could not complete the task."

    面试说法：

    "这是最基础的硬限制，10 次以内解决不了就说明任务超出能力范围，应该优雅退出而不是继续消耗资源。"

    第二层：重复动作检测（识别循环模式）¶

    这是最能体现工程能力的一层。

    from collections import deque

class LoopDetector:
    """循环检测器"""

    def __init__(self, window_size: int = 3, max_same_action: int = 2):
        self.window_size = window_size
        self.max_same_action = max_same_action
        self.history: deque[dict] = deque(maxlen=window_size)

    def add_step(self, action: str, action_input: str, observation: str):
        """记录一步"""
        self.history.append({
            "action": action,
            "input": action_input,
            "observation": observation[:200],  # 截断，避免内存爆炸
        })

    def is_looping(self) -> bool:
        """检测是否在循环"""
        if len(self.history) < self.window_size:
            return False

        recent = list(self.history)

        # 检测 1：相同动作连续出现
        actions = [s["action"] for s in recent]
        if len(set(actions)) == 1:
            return True

        # 检测 2：动作-输入对完全相同
        pairs = [(s["action"], s["input"]) for s in recent[-2:]]
        if len(set(pairs)) == 1 and len(pairs) >= 2:
            return True

        return False

    def get_loop_summary(self) -> str:
        """生成循环摘要（用于反馈给 LLM 或记录日志）"""
        recent = list(self.history)
        actions = [s["action"] for s in recent]
        return f"Detected loop: repeating action '{actions[-1]}' for {len(recent)} steps"


# 集成到 ReAgent 循环
def react_with_loop_detection(llm, tools, question, max_iter=10):
    loop_detector = LoopDetector(window_size=3, max_same_action=2)
    history = ""

    for step in range(max_iter):
        prompt = build_prompt(question, tools, history)
        resp = llm(prompt).text

        if "Final Answer:" in resp:
            return parse_answer(resp)

        action, inp = parse_action(resp)
        obs = tools[action](**inp) if action in tools else f"Unknown tool: {action}"

        # 记录并检测
        loop_detector.add_step(action, str(inp), obs)

        if loop_detector.is_looping():
            return (
                f"I detected that I'm repeating the same action. "
                f"This might be a loop. "
                f"Let me try a different approach or ask for clarification.\n\n"
                f"Loop summary: {loop_detector.get_loop_summary()}"
            )

        history += f"\n{resp}\nObservation: {obs}"

    return "Max iterations reached."

    面试加分点：

    • 用 deque(maxlen=N) 自动维护固定大小的窗口，内存安全
    • 检测两个维度：相同动作 + 相同 (动作, 输入) 对
    • 检测到循环后不是直接崩溃，而是生成摘要让 Agent 换策略

    第三层：Token 预算控制¶

    class TokenBudget:
    """Token 预算管理"""

    def __init__(self, max_tokens: int = 50000):
        self.max_tokens = max_tokens
        self.used = 0

    def record(self, tokens: int):
        self.used += tokens

    def is_exceeded(self) -> bool:
        return self.used >= self.max_tokens

    def remaining(self) -> int:
        return max(0, self.max_tokens - self.used)


# 集成
budget = TokenBudget(max_tokens=50000)

for step in range(MAX_ITERATIONS):
    resp = llm(prompt)
    budget.count(resp.token_usage)

    if budget.is_exceeded():
        return f"Token budget exceeded ({budget.used} tokens). Task incomplete."

    import time

class TimeoutGuard:
    """超时保护"""

    def __init__(self, max_seconds: int = 60):
        self.max_seconds = max_seconds
        self.start_time = None

    def start(self):
        self.start_time = time.time()

    def is_expired(self) -> bool:
        if not self.start_time:
            return False
        return (time.time() - self.start_time) > self.max_seconds

    def elapsed(self) -> float:
        if not self.start_time:
            return 0
        return time.time() - self.start_time

    第五层：状态收敛检测（最高级）¶

    检测 Agent 的整体状态是否在"原地踏步"。

    class StateConvergenceDetector:
    """状态收敛检测——判断 Agent 是否在原地踏步"""

    def __init__(self, window_size: int = 4):
        self.window_size = window_size
        self.state_history: deque[str] = deque(maxlen=window_size)

    def record_state(self, state_summary: str):
        """记录状态摘要（可以是工具调用序列的哈希）"""
        self.state_history.append(state_summary)

    def is_stagnant(self) -> bool:
        """判断状态是否停滞"""
        if len(self.state_history) < self.window_size:
            return False

        # 如果最近 N 个状态摘要完全相同
        return len(set(self.state_history)) == 1

    def progress_score(self) -> float:
        """计算进度分数：状态变化越多，分数越高"""
        if len(self.state_history) < 2:
            return 1.0
        unique = len(set(self.state_history))
        return unique / len(self.state_history)


# 集成到 Agent
def compute_state_summary(history: str) -> str:
    """从对话历史中提取状态摘要"""
    # 简单版：提取所有 action 名称
    actions = []
    for line in history.split("\n"):
        if line.startswith("Action:"):
            actions.append(line.replace("Action:", "").strip())
    return "|".join(actions[-5:])  # 最近 5 个动作


detector = StateConvergenceDetector(window_size=4)

for step in range(MAX_ITERATIONS):
    # ... 执行一轮

    summary = compute_state_summary(history)
    detector.record_state(summary)

    if detector.is_stagnant():
        # 进度分数太低，强制退出
        return f"Agent appears stuck (stagnation detected). " \
               f"Progress score: {detector.progress_score():.2f}"

    四、LangGraph 中的循环防御¶

    from langgraph.graph import StateGraph, END
from typing import TypedDict
from collections import deque

class AgentState(TypedDict):
    messages: list
    step_count: int
    action_history: list  # 记录每步的 action

def agent_node(state: AgentState) -> AgentState:
    response = llm.bind_tools(tools).invoke(state["messages"])

    # 记录 action
    action = ""
    if hasattr(response, "tool_calls") and response.tool_calls:
        action = response.tool_calls[0]["name"]

    return {
        "messages": state["messages"] + [response],
        "step_count": state["step_count"] + 1,
        "action_history": state["action_history"] + [action],
    }

def should_continue(state: AgentState) -> str:
    # 防御 1：最大步数
    if state["step_count"] >= 15:
        return "max_steps_reached"

    # 防御 2：重复动作检测
    history = state["action_history"]
    if len(history) >= 3:
        recent = history[-3:]
        if len(set(recent)) == 1:  # 连续 3 次相同 action
            return "loop_detected"

    last_msg = state["messages"][-1]
    if hasattr(last_msg, "tool_calls") and last_msg.tool_calls:
        return "tools"

    return END

# 添加兜底节点
def max_steps_handler(state: AgentState) -> AgentState:
    return {
        "messages": state["messages"] + [{
            "role": "assistant",
            "content": "Max steps reached. Could not complete the task within the allowed iterations."
        }],
    }

def loop_handler(state: AgentState) -> AgentState:
    repeated_action = state["action_history"][-1]
    return {
        "messages": state["messages"] + [{
            "role": "assistant",
            "content": f"Detected a loop: repeating '{repeated_action}'. "
                       f"Please rephrase your request or provide more guidance."
        }],
    }

builder = StateGraph(AgentState)
builder.add_node("agent", agent_node)
builder.add_node("tools", tool_node)
builder.add_node("max_steps", max_steps_handler)
builder.add_node("loop", loop_handler)

builder.set_entry_point("agent")
builder.add_conditional_edges("agent", should_continue, {
    "tools": "tools",
    "max_steps_reached": "max_steps",
    "loop_detected": "loop",
    END: END,
})
builder.add_edge("tools", "agent")
builder.add_edge("max_steps", END)
builder.add_edge("loop", END)

graph = builder.compile()

    五、面试标准回答模板¶

    面试官："Agent 陷入循环怎么办？"

回答：
"这个问题很重要，我在 Agent 设计中做了五层防御。

最简单的一层是 max_iterations，比如设为 10，10 轮没结果就退出。

但光有这个不够，因为 Agent 可能在 10 轮内来回循环。所以我加了第二层：
重复动作检测。我会用一个 deque 维护最近 3 步的 (action, input) 记录，
如果连续 3 次相同，就判定为循环，强制退出并换策略。

第三层是 Token 预算，防止 Agent 因为大量无效调用消耗太多 token。
第四层是超时机制，比如 60 秒没结果就终止。

第五层是状态收敛检测，通过计算最近几步的状态摘要来判断 Agent
是否在原地踏步。

LangGraph 里我把这些逻辑都放在 should_continue 函数里，
通过条件边路由到不同的处理节点，而不是直接抛异常。

这样不管什么形式的循环，总有一层能兜住。"

    六、为什么 Agent 会陷入循环？¶

    面试官可能追问："为什么会循环？"

    原因 解释 对应防御
    工具调用失败后模型重试同一工具 参数不对→报错→模型不调整参数直接重试 重复动作检测
    工具返回信息不足以推进任务 工具返回的内容模型无法从中推导下一步 状态收敛检测
    System Prompt 指令冲突 既要求做 A 又要求做 B，Agent 反复摇摆 任务前置验证
    没有明确的终止条件 Agent 不知道什么时候该停 最大迭代次数
    多 Agent 互相等待 A 等 B 的结果，B 等 A 的结果 超时 + 死锁检测

    七、进阶：如何从循环中恢复¶

    检测到循环后，不是简单地报错，而是尝试恢复：

    def recover_from_loop(history: str, loop_summary: str) -> str:
    """循环恢复策略"""

    recovery_prompt = f"""
    You seem to be stuck in a loop. Here's what happened:

    {loop_summary}

    Last few steps:
    {history[-2000:]}

    Please try ONE of the following:
    1. Use a DIFFERENT tool than the one you've been repeating
    2. Ask the user for clarification
    3. Provide the best answer you can with the information you have

    Do NOT repeat the same action again.
    """

    return llm(recovery_prompt).text

    三种恢复策略：

    1. 换工具：用不同的工具尝试
    2. 问用户：承认自己做不了，请求更多信息
    3. 给出最佳猜测：用已有信息给出最接近的答案

    八、总结 Checklist¶

    • MAX_ITERATIONS 硬限制（10-15）
    • 滑动窗口重复动作检测（deque, window=3）
    • Token 预算控制
    • 超时机制（60s）
    • 状态收敛检测（progress score）
    • LangGraph should_continue 集中判断
    • 循环后恢复策略（换工具 / 问用户 / 最佳猜测）
    • 完整 Trace 记录（便于事后分析）
