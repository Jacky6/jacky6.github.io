    2. Tool 插件 Demo¶

    2.1 最小 Tool 插件¶

    这是一个"天气预报"工具的完整插件实现。

    目录结构¶

    my-weather-tool/
├── package.json          # 包元信息
├── openclaw.plugin.json  # 插件清单
└── index.ts              # 入口

    package.json¶

    {
  "name": "openclaw-weather-tool",
  "version": "1.0.0",
  "type": "module",
  "openclaw": {
    "extensions": ["./index.ts"],
    "compat": {
      "pluginApi": ">=2026.3.24-beta.2",
      "minGatewayVersion": "2026.3.24-beta.2"
    },
    "build": {
      "openclawVersion": "2026.3.24-beta.2",
      "pluginSdkVersion": "2026.3.24-beta.2"
    }
  }
}

    openclaw.plugin.json¶

    {
  "id": "weather-tool",
  "name": "Weather Tool",
  "description": "Query weather info for a city",
  "contracts": {
    "tools": ["get_weather"]
  },
  "activation": {
    "onStartup": true
  },
  "configSchema": {
    "type": "object",
    "additionalProperties": false
  }
}

    index.ts (核心!)¶

    import { Type } from "typebox";
import { definePluginEntry } from "openclaw/plugin-sdk/plugin-entry";

export default definePluginEntry({
  id: "weather-tool",
  name: "Weather Tool",
  description: "Query weather for any city",

  register(api) {
    // 注册一个 Tool
    api.registerTool({
      name: "get_weather",
      description: "Get current weather for a given city",
      // JSON Schema 描述参数 — 模型会据此生成调用
      parameters: Type.Object({
        city: Type.String({ description: "City name, e.g. Shanghai" }),
        unit: Type.Optional(
          Type.Union([Type.Literal("celsius"), Type.Literal("fahrenheit")], {
            description: "Temperature unit",
          })
        ),
      }),

      // 实际执行函数
      async execute(_toolCallId, params) {
        const { city, unit = "celsius" } = params;

        // 模拟 API 调用 (真实场景可以用 web_fetch 或 HTTP 请求)
        const weather = await fetchWeather(city, unit);

        return {
          // Tool 返回内容，支持 text / image / 等多种类型
          content: [
            {
              type: "text",
              text: JSON.stringify(weather),
            },
          ],
        };
      },
    });
  },
});

// --- 模拟 weather API ---
async function fetchWeather(city: string, unit: string) {
  // 真实实现: await fetch(`https://wttr.in/${city}?format=j1`)
  const mockData: Record<string, any> = {
    shanghai: { temp: 28, condition: "Sunny ☀️", humidity: 65 },
    beijing: { temp: 32, condition: "Cloudy ⛅", humidity: 40 },
    tokyo: { temp: 25, condition: "Rainy 🌧️", humidity: 80 },
  };

  const data = mockData[city.toLowerCase()] ?? {
    temp: 22,
    condition: "Unknown",
    humidity: 50,
  };

  if (unit === "fahrenheit") {
    data.temp = Math.round((data.temp * 9) / 5 + 32);
  }

  return data;
}

    2.2 安装 & 使用¶

    # 本地安装
openclaw plugins install -l ./my-weather-tool

# 检查是否加载
openclaw plugins inspect weather-tool --runtime --json

# 重启 Gateway
openclaw gateway restart

    安装后，模型就能在对话中看到 get_weather 工具：

    用户: 上海今天天气怎么样？

模型思考: 用户问天气，我有 get_weather 工具可用 → 调用!

模型输出 tool_call:
{
  "name": "get_weather",
  "arguments": { "city": "Shanghai", "unit": "celsius" }
}

Gateway 执行 execute → 返回结果 → 放回对话

模型看到结果 → 组织回复:
"上海现在 28°C，晴天 ☀️，湿度 65%。"

    2.3 可选 Tool (Optional Tool)¶

    某些工具只在用户明确允许时才暴露：

    register(api) {
  api.registerTool({
    name: "send_email",
    description: "Send an email on behalf of the user",
    parameters: Type.Object({
      to: Type.String(),
      subject: Type.String(),
      body: Type.String(),
    }),
    async execute(_id, params) {
      // ...
      return { content: [{ type: "text", text: "Email sent!" }] };
    },
  }, { optional: true });  // ← 可选! 需要用户手动 allow
}

    用户在配置中启用：

    {
  tools: {
    allow: ["send_email"],  // 显式允许
  },
}

    2.4 Tool 调用流程 (详细)¶

    ┌──────────────────────────────────────────────────────────────┐
│                    Tool 调用详细流程                          │
│                                                              │
│  1. 用户发消息 "上海天气如何？"                                │
│     ↓                                                        │
│  2. Gateway 构建 Prompt:                                     │
│     - 系统 Prompt (SOUL.md, USER.md, 技能描述...)             │
│     - 对话历史                                                │
│     - tools: [ {name: "get_weather", description: ...,       │
│                 parameters: {...}}, ... ]                     │
│     ↓                                                        │
│  3. 发送给模型 (OpenAI/Anthropic API)                         │
│     ↓                                                        │
│  4. 模型返回响应，包含 tool_calls:                            │
│     {                                                         │
│       "role": "assistant",                                    │
│       "tool_calls": [{                                        │
│         "id": "call_abc123",                                  │
│         "function": {                                         │
│           "name": "get_weather",                              │
│           "arguments": "{\"city\": \"Shanghai\"}"             │
│         }                                                     │
│       }]                                                      │
│     }                                                         │
│     ↓                                                        │
│  5. Gateway 查找已注册的 tool → 执行 execute()                 │
│     ↓                                                        │
│  6. 工具结果放回消息列表:                                      │
│     {                                                         │
│       "role": "tool",                                         │
│       "tool_call_id": "call_abc123",                          │
│       "content": "{\"temp\": 28, \"condition\": \"Sunny\"}"  │
│     }                                                         │
│     ↓                                                        │
│  7. 再次发送给模型 (带工具结果)                                │
│     ↓                                                        │
│  8. 模型生成最终回复:                                         │
│     "上海现在 28°C，晴天 ☀️"                                   │
└──────────────────────────────────────────────────────────────┘
