    4. MCP 配置与实战 Demo¶

    MCP vs Tool 的详细对比请查看 4-mcp-vs-tool.md

    4.1 什么是 MCP?¶

    MCP (Model Context Protocol) 是 Anthropic 提出的开放协议， 让 AI 应用标准化地访问外部数据和工具。

    ┌─────────────┐         ┌─────────────┐
│   AI App    │◄───────►│  MCP Server │
│  (Client)   │   MCP   │  (Provider) │
│   OpenClaw  │ Protocol│  文件系统    │
│             │         │  数据库      │
│             │         │  API 服务    │
└─────────────┘         └─────────────┘

    MCP Server 可以提供三种能力: - Tools — 可调用的函数 (最常用) - Resources — 可读取的文件/数据 - Prompts — 预设的提示词模板

    4.2 OpenClaw 中的 MCP 配置¶

    在 openclaw.json 中配置 MCP Server:

    {
  mcp: {
    servers: {
      // 本地文件系统 MCP (stdio)
      filesystem: {
        command: "npx",
        args: [
          "-y",
          "@modelcontextprotocol/server-filesystem",
          "/home/yixiu/Documents",  // 允许访问的目录
        ],
      },
      // SQLite 数据库 MCP (stdio)
      sqlite: {
        command: "uvx",
        args: [
          "mcp-server-sqlite",
          "--db-path", "/home/yixiu/data/app.db",
        ],
      },
      // 自定义 HTTP MCP Server
      myapi: {
        url: "http://localhost:3000/mcp",
        transport: "streamable-http",  // 或省略用 sse
        headers: {
          "Authorization": "Bearer <token>"
        },
      },
    },
  },
}

    4.3 实战: 编写自己的 MCP Server¶

    Python MCP Server 示例¶

    # my_mcp_server.py
"""一个简单的 MCP Server，提供股票查询功能"""

from mcp.server.fastmcp import FastMCP
import requests

mcp = FastMCP("Stock Server")

@mcp.tool()
def get_stock_price(symbol: str) -> str:
    """Get current stock price for a given symbol.

    Args:
        symbol: Stock ticker symbol, e.g. AAPL, TSLA
    """
    url = f"https://query1.finance.yahoo.com/v8/finance/chart/{symbol}"
    resp = requests.get(url, headers={"User-Agent": "Mozilla/5.0"})
    data = resp.json()

    try:
        price = data["chart"]["result"][0]["meta"]["regularMarketPrice"]
        currency = data["chart"]["result"][0]["meta"]["currency"]
        return f"{symbol}: {price} {currency}"
    except (KeyError, IndexError):
        return f"Could not find price for {symbol}"

@mcp.tool()
def get_stock_info(symbol: str) -> str:
    """Get basic info about a stock.

    Args:
        symbol: Stock ticker symbol
    """
    url = f"https://query1.finance.yahoo.com/v10/finance/quoteSummary/{symbol}"
    resp = requests.get(
        url,
        headers={"User-Agent": "Mozilla/5.0"},
        params={"modules": "price,summaryDetail"},
    )
    data = resp.json()

    try:
        result = data["quoteSummary"]["result"][0]
        name = result["price"]["longName"]
        market_cap = result["price"]["marketCap"]["fmt"]
        return f"{name} ({symbol})\nMarket Cap: {market_cap}"
    except (KeyError, IndexError):
        return f"Could not find info for {symbol}"

if __name__ == "__main__":
    mcp.run(transport="stdio")

    配置 OpenClaw 连接这个 Server¶

    {
  mcp: {
    servers: {
      stock: {
        command: "python",
        args: ["/home/yixiu/.openclaw/workspace/demo-agent-tool-calling/my_mcp_server.py"],
      },
    },
  },
}

    效果¶

    重启 Gateway 后，模型就能直接看到并使用这两个工具:

    用户: 苹果股票现在多少钱？

模型: tool_call({name: "get_stock_price", args: {symbol: "AAPL"}})
       → MCP Server 执行 → 返回 "AAPL: 215.48 USD"
       → 模型回复: "苹果股票当前价格 215.48 美元"

    模型不需要读任何文件就知道怎么用！ MCP Server 的 tools/list 已经把工具信息告诉了 Gateway。

    4.4 三者如何协同工作¶

    一个完整的场景:

    用户: "帮我分析下特斯拉股票，然后把报告存到 ~/Documents/"

1. Stock Skill (SKILL.md)
   → 告诉模型: 你有 stock-analysis 技能
   → 模型读取 SKILL.md → 知道要用哪些工具

2. MCP Server (stock)
   → 提供 get_stock_price, get_stock_info 等工具
   → 模型直接调用获取实时数据

3. MCP Server (filesystem)
   → 提供 read_file, write_file 工具
   → 模型直接调用保存报告

最终: Skill 指导 → MCP 提供工具 → Tool 执行
