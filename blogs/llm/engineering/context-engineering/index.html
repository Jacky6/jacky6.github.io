    Context Engineering（上下文工程）¶

    2025-2026 年 AI 工程核心概念：为 LLM 构建最优信息上下文。

    一、什么是 Context Engineering？¶

    Context Engineering 是为 AI 模型设计和构建最优输入上下文（prompt + 检索内容 + 记忆 + 工具结果）的工程实践。

    核心思想：

    "AI 的输出质量取决于你给它的输入质量。Context Engineering 就是系统化地提升这个输入质量。"

    与 Prompt Engineering 的区别：

    维度 Prompt Engineering Context Engineering
    范围 单次 prompt 编写 整个上下文管道
    关注点 措辞、格式 信息检索、筛选、组装
    复杂度 静态文本 动态管道
    典型操作 "你是一个助手..." RAG + 记忆 + 工具结果 + 系统提示

    四、Context Engineering 的 5 个原则¶

    # 原则 说明
    1 相关性优先 只放入与当前任务相关的信息
    2 分层优先级 系统提示 > 检索结果 > 历史记忆
    3 动态组装 每轮对话重新计算最优上下文
    4 压缩去噪 移除冗余、无关、过时的信息
    5 可观测性 记录每次上下文组装的决策过程

    5.1 Token 预算管理¶

    class ContextBudget:
    def __init__(self, max_tokens: int = 128000):
        self.max_tokens = max_tokens
        self.budget = {
            "system": 2000,      # 1.5%
            "retrieval": 40000,  # 31%
            "memory": 10000,     # 8%
            "tools": 20000,      # 16%
            "conversation": 50000, # 39%
            "output_reserve": 6000 # 5%
        }

    def assemble(self, components: dict) -> list:
        result = []
        used = 0
        for key, limit in self.budget.items():
            if key in components:
                content = components[key][:limit]
                result.append(content)
                used += len(content)
        return result

    六、面试话术¶

    Q: 什么是 Context Engineering？

    Context Engineering 是为 LLM 构建最优输入上下文的工程实践。它超越了 Prompt Engineering 的单点优化，关注整个上下文管道：系统提示、RAG 检索、记忆系统、工具结果的动态组装。

    核心挑战是 token 预算管理——在有限的上下文窗口内，选择最相关的信息。我通常用分层优先级 + 动态路由 + 压缩去噪三个策略来解决。

    和 Loop Engineering 的关系：Loop Engineering 关注 Agent 的循环控制（什么时候调用工具、什么时候停止），Context Engineering 关注每轮循环中输入信息的质量。两者结合才能构建可靠的 Agent 系统。
