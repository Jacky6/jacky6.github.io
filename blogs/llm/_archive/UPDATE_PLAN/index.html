    LangChain 生态教程更新计划¶

    创建时间：2026-06-04 基于官方文档对比：https://docs.langchain.com/ 状态：待执行

    更新原则¶

    1. 保留教程结构和风格，只更新过时的内容和 API
    2. 模型名称统一为官方最新推荐
    3. 代码示例以官方 Quickstart 为准
    4. 新增内容补充到合适章节，不破坏现有章节编号
    5. 每完成一个文件，在本文件标记 ✅

    Phase 1: LangChain 核心教程（优先级 🔴 高）¶

    1.1 00-langchain-overview.md — 概述¶

    需要更新：

    • 模型生态对比：官方示例模型已更新
    • 旧：gpt-4o, claude-3.5-sonnet
    • 新：gpt-5.4, gemini-3.5-flash, claude-sonnet-4-6, qwen3p5-397b-a17b, GLM-5, devstral-2
    • LangSmith 生态新增产品：
    • LangSmith Engine：自动检测 trace 问题并提议修复
    • LangSmith Fleet：无代码 Agent 构建器
    • 产品对比关系图更新：官方已重新定义四件套
    • Deep Agents = agent harness（batteries-included）
    • LangChain = agent framework（create_agent harness）
    • LangGraph = orchestration runtime（durable execution, streaming, human-in-the-loop）
    • LangSmith = tracing, evaluation, deployment platform
    • 安装验证示例：init_chat_model() → 改为直接用 create_agent() 验证

    官方参考：https://docs.langchain.com/oss/python/langchain/overview

    1.3 02-quickstart.md — 快速开始¶

    需要更新：

    • 主示例代码更新为官方最新 Quickstart： 
      from langchain.agents import create_agent

def get_weather(city: str) -> str:
    """Get weather for a given city."""
    return f"It's always sunny in {city}!"

agent = create_agent(
    model="openai:gpt-5.4",  # 或 google_genai:gemini-3.5-flash
    tools=[get_weather],
    system_prompt="You are a helpful assistant",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "What's the weather in San Francisco?"}]}
)
print(result["messages"][-1].content_blocks)
    • 多 Provider 示例：补充 OpenRouter、Fireworks、Baseten、Ollama、Azure、AWS Bedrock、HuggingFace 示例
    • 对话持久化示例：新增 checkpointer + thread_id 示例： 
      from langchain.agents import create_agent
from langchain_core.utils.uuid import uuid7
from langgraph.checkpoint.memory import InMemorySaver

agent = create_agent(
    model="openai:gpt-5.4",
    tools=[],
    checkpointer=InMemorySaver(),
)

config = {"configurable": {"thread_id": str(uuid7())}}
result = agent.invoke(
    {"messages": [{"role": "user", "content": "你好"}]},
    config=config,
)
# 后续对话复用同一个 thread_id
    • 上下文传递示例：新增 context_schema 示例： 
      from dataclasses import dataclass

@dataclass
class Context:
    user_id: str

agent = create_agent(
    model="openai:gpt-5.4",
    tools=[],
    context_schema=Context,
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "你好"}]},
    config={"configurable": {"thread_id": str(uuid7())}},
    context=Context(user_id="user-123"),
)

    官方参考：https://docs.langchain.com/oss/python/langchain/quickstart

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()
