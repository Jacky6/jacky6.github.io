    LLM 知识库¶

    LLM 与 Agent 知识体系，按主题分类，便于检索和学习。

    最后核对：2026-10-29

    📐 内容分类约定¶

    本库所有内容分为四类，每篇文档头部应标注：

    类型 含义 维护要求
    canonical 概念事实源，框架无关 稳定，不写易失效的版本信息
    framework 特定框架/SDK 的版本化教程 必须标注 package_version + verified_at
    protocol 协议规范教程 必须标注 protocol_version + verified_at
    snapshot 产品/源码快照研究 必须标注观察日期、版本、Commit
    derived 从事实源派生的速记/问答 只引用不定义事实，跟随事实源更新

    🚀 快速导航¶

    1. Agent 概念 → agent/¶

    框架无关的 Agent 核心概念主线，按执行生命周期组织（总览 → 循环 → 工具 → 状态 → 规划 → 多 Agent → 可靠性 → 安全 → 评估 → 生产）。

    • 概念主线：agent/concepts/
    • 面试速记：agent/interview/

    2. LangChain 生态 → langchain/¶

    子目录 内容 适用场景
    tutorial/ create_agent 系统教程 入门到中级
    langgraph/ 状态图与运行时 自定义编排
    deep-agents/ 开箱即用 Harness 长任务 Agent

    学习路径（按需分叉，不是强制线性）： 

    langchain/tutorial/（create_agent 基础）
    ├─→ 需要精细控制流 → langchain/langgraph/
    └─→ 需要开箱即用长任务 Harness → langchain/deep-agents/

    3. 协议层 → protocols/¶

    协议 说明 状态
    MCP Model Context Protocol，主线版本 2026-07-28 ✅ 本库唯一 MCP 事实源
    A2A Agent-to-Agent 互操作 ✅ 教程已按 1.0 重写（a2a-sdk 1.3.0 实测）+ 官方 SDK 示例

    ⚠️ 其他目录中涉及 MCP 的内容以 protocols/mcp/ 为准。

    4. 工程实践 → engineering/¶

    主题 说明
    Context Engineering 每次模型调用看见什么信息
    Harness Engineering 模型外围的运行系统
    Loop Engineering 内循环、事件循环、优化循环

    5. 实战 Demo → demos/¶

    Demo 内容 类型
    minimal-agent-loop/ 最小 Agent Loop（零依赖、可测试，对应 concepts/01） lab
    langchain-reference-agent/ LangChain v1 基线（create_agent + Checkpointer，无需 Key） lab
    agent-tool-calling/ OpenClaw 工具机制源码分析 + LangGraph Demo snapshot + lab

    6. 部署 → deployment/¶

    工具 说明
    vllm/ vLLM 推理引擎部署
