    第一章：概述与核心概念¶

    Deep Agents 的设计哲学、架构组件和适用场景

    1.1 什么是 Deep Agents？¶

    Deep Agents 是 LangChain 团队开发的开源代理框架，专为需要深度思考、长时间运行和复杂任务分解的 AI 代理场景设计。

    核心设计理念¶

    ┌─────────────────────────────────────────────────────────────┐
│                    Deep Agents 设计哲学                       │
├─────────────────────────────────────────────────────────────┤
│  🧠 深度思考 > 快速响应                                       │
│  📁 文件系统作为工作空间                                      │
│  🔧 工具调用作为第一公民                                      │
│  💾 记忆持久化跨会话                                          │
│  🎯 模块化技能可复用                                          │
│  👥 子代理协作完成任务                                        │
└─────────────────────────────────────────────────────────────┘

    与传统 Agent 框架的对比¶

    特性 传统 Agent Deep Agents
    执行模式 单次对话 长时间运行
    工作空间 内存/临时 虚拟文件系统
    工具调用 可选 核心能力
    记忆 对话历史 持久化文件
    技能 硬编码 SKILL.md 模块化
    部署 自定义 LangSmith/自托管

    组件详解¶

    1. Deep Agent 核心引擎¶

    from deepagents import create_deep_agent

agent = create_deep_agent(
    model="anthropic:claude-opus-4-6",
    system_prompt="你是一个专业的编程助手",
    backend=...,      # 文件后端配置
    middleware=[...], # 中间件（限流、日志等）
    skills=[...]      # 技能列表
)

    2. 记忆系统 (Memory)¶

    记忆类型：
├── 短期记忆 (StateBackend)
│   └── 会话内持久，会话结束清除
│   └── 用途：草稿、中间结果、临时笔记
│
└── 长期记忆 (StoreBackend)
    ├── 跨会话持久
    ├── 用途：用户偏好、学习知识、项目上下文
    └── 作用域：Private/Assistant/User/Organization

    3. 工具系统 (Tools)¶

    工具来源：
├── 内置工具
│   ├── shell 命令执行
│   ├── 文件读写 (ls/read_file/write_file/edit_file)
│   └── 子代理管理
│
├── 技能工具 (Skills)
│   └── 从 SKILL.md 定义的脚本
│
└── MCP 工具
    └── 从 MCP 服务器动态加载

    4. 后端系统 (Backend)¶

    后端类型：
├── StateBackend (默认)
│   └── 文件存储在 LangGraph 线程状态中
│   └── 特点：临时、会话级
│
├── StoreBackend
│   └── 文件存储在 LangGraph Store 中
│   └── 特点：持久、跨会话
│
├── CompositeBackend
│   └── 组合多个后端，按路径路由
│   └── 用途：混合存储（临时 + 持久）
│
└── SandboxBackend
    └── 隔离容器环境
    └── 用途：代码执行、安全隔离

    1.3 核心概念详解¶

    1.3.1 虚拟文件系统¶

    Deep Agents 使用虚拟文件系统作为工作空间，Agent 可以：

    # 查看当前目录
ls /

# 读取文件
read_file /path/to/file.txt

# 写入文件
write_file /path/to/new_file.txt "内容"

# 编辑文件
edit_file /path/to/file.txt "查找内容" "替换内容"

# 创建目录
mkdir /path/to/dir

# 移动/复制文件
mv /src /dst
cp /src /dst

    路径约定：

    路径前缀 用途 持久性
    / 根目录，临时工作区 会话级
    /memories/ 长期记忆 持久
    /skills/ 技能脚本 持久
    /scratch/ 临时草稿 会话级

    1.3.2 技能系统 (Skills)¶

    技能是可复用的能力模块，存储在 memories/skills/<skill-name>/SKILL.md：

    # Skill: code-review

## Description
代码审查技能，提供代码质量检查、最佳实践建议

## Tools
- lint: 代码风格检查
- security: 安全漏洞扫描
- performance: 性能分析

## Instructions
1. 接收代码文件路径
2. 运行 lint 检查
3. 运行安全检查
4. 生成审查报告

    技能类型：

    类型 作用域 编辑权限
    Private 单个代理 创建者
    Shared 工作区所有代理 创建者

    1.3.3 子代理 (Subagents)¶

    Deep Agents 可以动态创建子代理来并行处理任务：

    # 主代理创建子代理
subagent = await create_subagent(
    role="数据分析师",
    task="分析 sales_data.csv",
    tools=["pandas", "matplotlib"]
)

# 等待子代理完成
result = await subagent.finish()

    使用场景： - 并行处理多个独立任务 - 专业化分工（一个负责搜索，一个负责分析） - 任务分解和结果聚合

    1.3.4 MCP (Model Context Protocol)¶

    MCP 允许从外部服务器加载工具，无需修改 Agent 本身：

    // .mcp.json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {"GITHUB_TOKEN": "ghp_..."}
    }
  }
}

    1.4 适用场景¶

    ✅ 适合使用 Deep Agents 的场景¶

    场景 说明 核心优势
    🔧 编程助手 代码生成、调试、重构 文件系统 + 工具调用
    📊 数据分析 数据清洗、分析、可视化 沙箱执行 + 持久记忆
    🔬 研究助理 文献调研、知识整理 长期记忆 + 子代理
    🤖 自动化工作流 CI/CD、定时任务 长时间运行 + 可靠性
    📝 内容创作 长文写作、多稿迭代 文件版本 + 记忆
    🎓 学习伴侣 个性化教学、进度跟踪 用户偏好记忆

    ❌ 不适合的场景¶

    场景 原因 替代方案
    ⚡ 简单问答 过度设计 直接使用 LLM API
    🔄 高频低延迟 Deep Agents 侧重深度思考 传统 Agent 框架
    📱 移动端 资源消耗大 轻量化方案

    1.5 与其他框架对比¶

    Deep Agents vs LangGraph¶

    LangGraph:
├── 底层图执行引擎
├── 提供状态管理和持久化
└── 需要自己构建 Agent 逻辑

Deep Agents:
├── 基于 LangGraph 构建
├── 开箱即用的 Agent 实现
├── 内置文件系统、技能、记忆
└── 更适合终端用户直接使用

    Deep Agents vs AutoGen¶

    特性 Deep Agents AutoGen
    设计目标 深度思考代理 多代理协作
    文件系统 内置虚拟文件系统 需自行实现
    技能系统 SKILL.md 规范 自定义
    部署 LangSmith/自托管 自托管
    学习曲线 中等 较陡

    Deep Agents vs OpenClaw¶

    特性 Deep Agents OpenClaw
    定位 通用代理框架 个人 AI 助手
    部署 云服务/自托管 本地优先
    技能格式 SKILL.md SKILL.md (兼容)
    记忆系统 Store/State 本地文件
    目标用户 开发者/企业 个人用户
