    🚀 什么是 Deep Agents？¶

    Deep Agents 是 LangChain 推出的开源代理框架，专为需要深度思考、长时间运行和复杂任务分解的 AI 代理设计。

    核心特性¶

    特性 说明
    🧠 深度思考 支持长时间推理，处理复杂多步骤任务
    📁 文件系统 内置虚拟文件系统，支持文件读写和操作
    🔧 工具调用 原生支持 shell 命令执行和工具扩展
    💾 持久记忆 支持短期和长期记忆，跨会话保持
    🎯 技能系统 可复用的能力模块，基于 SKILL.md 规范
    👥 子代理 支持动态创建和协调多个子代理
    🔌 MCP 集成 通过 Model Context Protocol 扩展工具
    🚢 生产就绪 支持 LangSmith 部署和自托管

    📖 学习路径¶

    🛠️ 环境准备¶

    系统要求¶

    • Python 3.10+
    • uv 包管理器（推荐）或 pip

    安装¶

    # 使用 uv 安装（推荐）
uv tool install deepagents-cli

# 基础安装（仅 OpenAI）
uv tool install deepagents-cli

# 安装多个 Provider
uv tool install 'deepagents-cli[anthropic,groq,google-genai]'

# 完整安装（所有 Provider）
uv tool install 'deepagents-cli[anthropic,baseten,bedrock,cohere,deepseek,fireworks,google-genai,groq,huggingface,ibm,litellm,mistralai,nvidia,ollama,openai,openrouter,perplexity,vertexai,xai]'

    配置 API Key¶

    # OpenAI
export OPENAI_API_KEY="sk-..."

# Anthropic
export ANTHROPIC_API_KEY="sk-ant-..."

# Google
export GOOGLE_API_KEY="..."

# 或添加到 ~/.bashrc / ~/.zshrc

    📝 学习建议¶

    1. 先动手 - 按照快速开始章节，5 分钟内让 Agent 跑起来
    2. 理解概念 - 重点理解记忆、沙箱、技能三个核心概念
    3. 循序渐进 - 从 CLI 开始，逐步深入到 SDK 和部署
    4. 参考案例 - 多看实战案例，理解最佳实践
    5. 加入社区 - 遇到问题在 Discord 或 GitHub 提问
