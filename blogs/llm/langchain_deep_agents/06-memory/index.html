    第六章：记忆系统¶

    短期记忆与长期记忆 | 跨会话持久化完全指南

    6.1 记忆系统概述¶

    Deep Agents 的记忆系统基于虚拟文件系统，支持两种记忆类型：

    记忆类型：
├── 短期记忆 (Short-term Memory)
│   ├── 后端：StateBackend
│   ├── 持久性：会话内持久，会话结束清除
│   └── 用途：草稿、中间结果、临时笔记
│
└── 长期记忆 (Long-term Memory)
    ├── 后端：StoreBackend
    ├── 持久性：跨会话持久
    └── 用途：用户偏好、学习知识、项目上下文

    记忆架构图¶

    6.2 短期记忆¶

    配置¶

    StateBackend 是默认配置，无需额外设置：

    from deepagents import create_deep_agent

# 默认使用 StateBackend
agent = create_deep_agent()

    特点¶

    特性 说明
    持久性 会话内持久，会话结束清除
    存储位置 LangGraph Thread State
    适用场景 草稿、中间结果、临时笔记
    性能 快速（内存级访问）
    限制 不适合大文件（每次检查点保存）

    使用示例¶

    # 对话 1
> 帮我写一个快速排序算法

🤖 好的，我写到 /quicksort.py

# 对话继续
> 能优化一下吗？

🤖 让我修改 /quicksort.py ...

# 对话结束 → 文件清除

    6.3 长期记忆¶

    配置¶

    使用 CompositeBackend 路由 /memories/ 到 StoreBackend：

    from deepagents import create_deep_agent
from deepagents.backends import CompositeBackend, StateBackend, StoreBackend
from langgraph.store.memory import InMemoryStore

# 创建 Store（开发用 InMemoryStore，生产用 PostgresStore）
store = InMemoryStore()

def make_backend(runtime):
    return CompositeBackend(
        # 默认：临时存储
        default=StateBackend(runtime),
        # 路由：/memories/ 路径持久化
        routes={
            "/memories/": StoreBackend(
                runtime,
                # 命名空间：按用户隔离
                namespace=lambda ctx: (ctx.runtime.context.user_id,),
            ),
        },
    )

agent = create_deep_agent(
    store=store,
    backend=make_backend,
    system_prompt="""你有持久记忆在 /memories/ 目录。

    读取 /memories/instructions.txt 获取累积的知识和偏好。
    当你学到应该持久保存的内容时，更新那个文件。"""
)

    特点¶

    特性 说明
    持久性 跨会话持久
    存储位置 LangGraph Store (内存/Postgres)
    适用场景 用户偏好、学习知识、项目上下文
    性能 中等（数据库访问）
    限制 需要配置 Store 和命名空间

    跨会话验证¶

    import uuid

# 对话 1：写入记忆
config1 = {"configurable": {"thread_id": str(uuid.uuid4())}}
await agent.ainvoke({
    "messages": [{"role": "user", "content": "保存我的偏好：我喜欢用双引号"}]
}, config=config1)

# Agent 操作：write_file /memories/preferences.txt "quote_style = 'double'"

# 对话 2：读取记忆（不同 thread！）
config2 = {"configurable": {"thread_id": str(uuid.uuid4())}}
await agent.ainvoke({
    "messages": [{"role": "user", "content": "我的偏好是什么？"}]
}, config=config2)

# Agent 操作：read_file /memories/preferences.txt
# 输出：quote_style = 'double'

    6.4 命名空间作用域¶

    命名空间决定谁能看到什么数据。

    作用域类型¶

    作用域 Namespace 谁共享 用途
    Private (assistant_id, user_id) 单用户单助手 个人偏好
    Assistant (assistant_id) 所有用户单助手 团队知识
    User (user_id) 单用户所有助手 全局用户配置
    Organization (org_id) 所有用户所有助手 组织政策

    配置示例¶

    Private（最常用）¶

    from langgraph.config import get_config

def make_backend(runtime):
    return CompositeBackend(
        default=StateBackend(runtime),
        routes={
            "/memories/": StoreBackend(
                runtime,
                namespace=lambda ctx: (
                    get_config()["metadata"]["assistant_id"],
                    ctx.runtime.context.user_id,
                ),
            ),
        },
    )

    场景： 邮件助手中，每个用户的签名偏好独立。

    Assistant¶

    def make_backend(runtime):
    return CompositeBackend(
        default=StateBackend(runtime),
        routes={
            "/memories/": StoreBackend(
                runtime,
                namespace=lambda ctx: (
                    get_config()["metadata"]["assistant_id"],
                ),
            ),
        },
    )

    场景： 社交媒体助手的共享规则（"帖子不超过 280 字符"）。

    User¶

    def make_backend(runtime):
    return CompositeBackend(
        default=StateBackend(runtime),
        routes={
            "/memories/": StoreBackend(
                runtime,
                namespace=lambda ctx: (ctx.runtime.context.user_id,),
            ),
        },
    )

    场景： 用户的全局偏好（"首选语言：西班牙语"）。

    Organization¶

    def make_backend(runtime):
    return CompositeBackend(
        default=StateBackend(runtime),
        routes={
            "/memories/": StoreBackend(
                runtime,
                namespace=lambda ctx: (ctx.runtime.context.org_id,),
            ),
        },
    )

    场景： 组织级政策（"永不披露内部定价"）。

    ⚠️ 警告： 共享记忆是指令注入的向量。确保组织级政策对 Agent 只读。

    模式 1：用户偏好¶

    agent = create_deep_agent(

    > 我喜欢代码中使用 4 空格缩进

[下次对话]

> 帮我格式化这段代码

🤖 根据你的偏好，使用 4 空格缩进...

    模式 2：自改进指令¶

    agent = create_deep_agent(

    模式 4：研究项目¶

    research_agent = create_deep_agent(
    store=InMemoryStore(),
    backend=lambda rt: CompositeBackend(
        default=StateBackend(rt),
        routes={"/memories/": StoreBackend(rt)}
    ),
    system_prompt="""你是研究助理。

保存研究进度到 /memories/research/:
- /memories/research/sources.txt - 来源列表
- /memories/research/notes.txt - 关键发现
- /memories/research/report.md - 报告草稿

这允许研究跨多个会话继续。"""
)

    记忆结构：

    /memories/research/
├── sources.txt      # 已阅读的论文/文章
├── notes.txt        # 关键发现和笔记
├── questions.txt    # 待解答问题
└── report.md        # 最终报告草稿

    6.6 从外部代码访问记忆¶

    部署到 LangSmith 时，可从服务器代码读写记忆：

    from langgraph_sdk import get_client

client = get_client(url="<DEPLOYMENT_URL>")

# 读取记忆文件（路径不含 /memories/ 前缀）
item = await client.store.get_item(
    (assistant_id, "filesystem"),  # namespace
    "/preferences.txt"              # key
)
print(item.value["content"])  # ["line 1", "line 2"]

# 写入记忆文件
from deepagents.backends.utils import create_file_data

await client.store.put_item(
    (assistant_id, "filesystem"),
    "/preferences.txt",
    create_file_data("quote_style = 'double'")
)

# 搜索记忆
items = await client.store.search_items(
    (assistant_id, "filesystem"),
    prefix="/preferences"
)

    ⚠️ 注意： CompositeBackend 会移除路由前缀。/memories/preferences.txt 在 Store 中存储为 /preferences.txt。

    6.7 Store 实现¶

    InMemoryStore（开发）¶

    from langgraph.store.memory import InMemoryStore

store = InMemoryStore()
agent = create_deep_agent(
    store=store,
    backend=lambda rt: CompositeBackend(
        default=StateBackend(rt),
        routes={"/memories/": StoreBackend(rt)}
    )
)

    特点： - ✅ 无需配置 - ✅ 快速 - ❌ 重启后数据丢失

    PostgresStore（生产）¶

    from langgraph.store.postgres import PostgresStore
import os

# 作为上下文管理器使用
with PostgresStore.from_conn_string(os.environ["DATABASE_URL"]) as store:
    store.setup()

    agent = create_deep_agent(
        store=store,
        backend=lambda rt: CompositeBackend(
            default=StateBackend(rt),
            routes={"/memories/": StoreBackend(rt)}
        )
    )

    特点： - ✅ 持久化 - ✅ 支持多实例 - ✅ 可扩展

    LangSmith Store（部署）¶

    使用 LangSmith Deployments 时，Store 自动配置，无需手动设置。

    6.8 FileData Schema¶

    通过 StoreBackend 存储的文件使用以下 schema：

    {
    "content": ["line 1", "line 2", "line 3"],  # 字符串列表（每行）
    "created_at": "2024-01-15T10:30:00Z",       # ISO 8601 时间戳
    "modified_at": "2024-01-15T11:45:00Z"       # ISO 8601 时间戳
}

    辅助函数¶

    from deepagents.backends.utils import create_file_data

# 从字符串创建
file_data = create_file_data("Hello\nWorld")
# {'content': ['Hello', 'World'], 'created_at': '...', 'modified_at': '...'}

# 从列表创建
file_data = create_file_data(["line1", "line2"])

    6.9 最佳实践¶

    1. 使用描述性路径¶

    # ✅ 好的组织
/memories/user_preferences.txt
/memories/research/topic_a/sources.txt
/memories/research/topic_a/notes.txt
/memories/project/requirements.md

# ❌ 避免扁平结构
/memories/file1.txt
/memories/file2.txt

    2. 在系统提示中记录结构¶

    system_prompt="""你的持久记忆结构：
- /memories/preferences.txt: 用户偏好和设置
- /memories/context/: 关于用户的长期上下文
- /memories/knowledge/: 随时间学习的事实和信息
- /memories/projects/:: 项目特定信息"""

    3. 定期清理¶

    # 实现定期清理过期记忆
async def cleanup_old_memories(store, max_age_days=30):
    cutoff = datetime.now() - timedelta(days=max_age_days)
    items = await store.search_items(namespace)
    for item in items:
        if item.updated_at < cutoff:
            await store.delete_item(namespace, item.key)

    6.11 本章小结¶

    关键要点¶

    1. 两种记忆类型 - 短期（StateBackend）和长期（StoreBackend）
    2. 命名空间作用域 - Private/Assistant/User/Organization
    3. CompositeBackend - 混合存储，按路径路由
    4. 外部访问 - 通过 Store API 读写记忆

    配置速查¶

    # 仅短期记忆（默认）
agent = create_deep_agent()

# 添加长期记忆
store = InMemoryStore()
backend = CompositeBackend(
    default=StateBackend(runtime),
    routes={"/memories/": StoreBackend(runtime, namespace=...)}
)
agent = create_deep_agent(store=store, backend=backend)

# 从外部访问
item = await client.store.get_item(namespace, key)
