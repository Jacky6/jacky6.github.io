    第八章：子代理¶

    多代理协作 | 任务分解和结果聚合完全指南

    8.1 什么是子代理？¶

    子代理（Subagents） 是主代理动态创建的辅助代理，用于： - 并行处理独立任务 - 专业化分工（搜索、分析、编码） - 复杂任务分解 - 结果聚合和整合

    单代理 vs 多代理¶

    ┌─────────────────────────────────────────────────────────────┐
│                   单代理 vs 多代理架构                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  单代理模式：                                                │
│  ┌─────────────┐                                           │
│  │   Agent     │  所有任务串行处理                          │
│  │  (全能型)   │  ⚠️ 上下文限制                             │
│  └─────────────┘  ⚠️ 容易迷失方向                           │
│                                                             │
│  多代理模式：                                                │
│  ┌─────────────┐                                           │
│  │   Main      │  协调和整合                                │
│  │   Agent     │                                            │
│  └──────┬──────┘                                           │
│         │ 分解任务                                          │
│    ┌────┼────┬────┐                                        │
│    ▼    ▼    ▼    ▼                                        │
│  ┌────┐┌────┐┌────┐┌────┐                                 │
│  │Sub1││Sub2││Sub3││Sub4│  并行专业化处理                  │
│  │搜索││分析││编码││测试│  ✅ 效率提升                      │
│  └────┘└────┘└────┘└────┘  ✅ 质量提高                      │
│         │ 聚合结果                                          │
│         ▼                                                   │
│  ┌─────────────┐                                           │
│  │   Result    │                                           │
│  └─────────────┘                                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘

    适用场景¶

    场景 说明 优势
    🔍 研究任务 多来源信息收集 并行搜索，覆盖更广
    📊 数据分析 多数据集处理 分工处理，效率更高
    💻 项目开发 前后端分离 专业化，减少上下文切换
    🧪 测试套件 多模块测试 并行执行，快速反馈
    📝 内容创作 多章节写作 风格一致，进度可控

    8.2 子代理创建¶

    基本创建¶

    from deepagents import create_deep_agent, create_subagent

# 主代理
main_agent = create_deep_agent(
    model="anthropic:claude-opus-4-6",
    system_prompt="你是项目协调员，负责任务分解和结果整合"
)

# 创建子代理
subagent = await create_subagent(
    role="数据分析师",
    task="分析 sales_data.csv，生成销售报告",
    model="openai:gpt-4o",
    tools=["pandas", "matplotlib"],
    backend=...  # 可选，默认继承主代理
)

# 等待子代理完成
result = await subagent.finish()
print(result)

    创建选项¶

    subagent = await create_subagent(
    # 必需参数
    role="代码审查员",           # 角色描述
    task="审查 /src 目录下的代码", # 任务描述

    # 可选参数

    tools=[lint_tool, security_tool],     # 工具
    backend=custom_backend,               # 后端
    system_prompt="你是资深代码审查专家...", # 系统提示
    timeout=300,                          # 超时（秒）
    memory="shared",                      # 记忆共享模式
)

    8.3 任务分解模式¶

    模式 1：并行分解¶

    独立任务并行执行：

    # 主代理
> 帮我研究机器学习在医疗诊断中的应用

🤖 我来分解这个任务：

1. 创建子代理 A：搜索最新论文
2. 创建子代理 B：分析临床应用案例
3. 创建子代理 C：整理技术挑战

# 并行执行
subagent_a = await create_subagent(
    role="学术研究员",
    task="搜索 2024-2025 年 ML 在医疗诊断的论文"
)
subagent_b = await create_subagent(
    role="行业分析师",
    task="分析 ML 医疗应用的临床案例"
)
subagent_c = await create_subagent(
    role="技术顾问",
    task="整理技术挑战和解决方案"
)

# 等待所有完成
results = await asyncio.gather(
    subagent_a.finish(),
    subagent_b.finish(),
    subagent_c.finish()
)

# 整合结果
final_report = integrate_results(results)

    模式 2：流水线分解¶

    任务有依赖关系，顺序执行：

    # 阶段 1：数据收集
collector = await create_subagent(
    role="数据收集员",
    task="收集销售数据从各个源"
)
raw_data = await collector.finish()

# 阶段 2：数据清洗（依赖阶段 1）
cleaner = await create_subagent(
    role="数据工程师",
    task=f"清洗数据：{raw_data}"
)
clean_data = await cleaner.finish()

# 阶段 3：数据分析（依赖阶段 2）
analyst = await create_subagent(
    role="数据分析师",
    task=f"分析 cleaned data: {clean_data}"
)
analysis = await analyst.finish()

# 阶段 4：报告生成（依赖阶段 3）
reporter = await create_subagent(
    role="报告撰写员",
    task=f"基于分析生成报告：{analysis}"
)
final_report = await reporter.finish()

    模式 3：混合分解¶

    部分并行，部分串行：

    # 第一阶段：并行数据收集
sales_data = await create_subagent(
    role="销售数据收集员",
    task="收集 Q4 销售数据"
).finish()

marketing_data = await create_subagent(
    role="市场数据收集员",
    task="收集 Q4 市场数据"
).finish()

# 第二阶段：合并后分析（串行）
combined_data = merge_data(sales_data, marketing_data)

analyst = await create_subagent(
    role="高级分析师",
    task=f"分析合并数据：{combined_data}"
)
analysis = await analyst.finish()

# 第三阶段：并行报告生成
exec_report = await create_subagent(
    role="高管报告撰写员",
    task=f"生成高管摘要：{analysis}"
).finish()

tech_report = await create_subagent(
    role="技术报告撰写员",
    task=f"生成技术细节：{analysis}"
).finish()

    8.4 子代理协调¶

    主代理职责¶

    system_prompt="""你是项目协调员。你的职责：

1. **任务分解**
   - 识别可并行的子任务
   - 为每个子任务分配合适的角色

2. **子代理创建**
   - 为每个子任务创建专门的子代理
   - 提供清晰的指令和上下文

3. **进度跟踪**
   - 监控子代理执行状态
   - 处理超时和错误

4. **结果整合**
   - 收集所有子代理的输出
   - 整合为一致的最终结果
   - 解决冲突和重复

5. **质量保证**
   - 验证结果完整性
   - 必要时请求返工"""

    通信模式¶

    # 模式 1：广播
# 主代理 → 所有子代理（相同消息）
for subagent in subagents:
    await subagent.send("请使用统一的日期格式：YYYY-MM-DD")

# 模式 2：点对点
# 主代理 → 特定子代理
await subagent_a.send("你的数据需要包含地区信息")

# 模式 3：子代理间
# 子代理 A → 子代理 B（通过主代理中转）
await subagent_b.send(f"基于 A 的结果：{result_a}，请继续...")

    8.5 结果聚合¶

    简单聚合¶

    results = await asyncio.gather(
    subagent_a.finish(),
    subagent_b.finish(),
    subagent_c.finish()
)

# 简单拼接
final = "\n\n".join(results)

    智能整合¶

    async def integrate_results(results: list) -> str:
    """智能整合子代理结果"""

    integrator = await create_subagent(
        role="整合专家",
        task=f"""整合以下子代理的报告：

        报告 A（市场研究）：
        {results[0]}

        报告 B（技术分析）：
        {results[1]}

        报告 C（财务预测）：
        {results[2]}

        要求：
        1. 消除重复内容
        2. 解决冲突信息
        3. 保持逻辑连贯
        4. 生成统一格式的报告"""
    )

    return await integrator.finish()

    结构化聚合¶

    from pydantic import BaseModel

class SubAgentResult(BaseModel):
    role: str
    output: str
    confidence: float
    sources: list[str]

class FinalReport(BaseModel):
    executive_summary: str
    sections: list[str]
    conclusions: list[str]
    confidence: float

# 收集结构化结果
results: list[SubAgentResult] = []
for subagent in subagents:
    result = await subagent.finish_structured(SubAgentResult)
    results.append(result)

# 生成结构化报告
final = await generate_structured_report(results, FinalReport)

    8.6 错误处理¶

    超时处理¶

    from asyncio import timeout

try:
    async with timeout(300):  # 5 分钟超时
        result = await subagent.finish()
except asyncio.TimeoutError:
    # 超时处理
    result = "任务超时，部分结果可能不完整"
    # 可选：创建新的子代理重试

    错误恢复¶

    async def run_with_retry(subagent, max_retries=3):
    """带重试的子代理执行"""
    for attempt in range(max_retries):
        try:
            return await subagent.finish()
        except Exception as e:
            if attempt == max_retries - 1:
                raise
            # 创建新的子代理重试
            subagent = await create_subagent(
                role=subagent.role,
                task=subagent.task,
                system_prompt=f"上次尝试失败：{e}. 请重试..."
            )

    部分失败处理¶

    # 使用 asyncio.gather 的 return_exceptions
results = await asyncio.gather(
    subagent_a.finish(),
    subagent_b.finish(),
    subagent_c.finish(),
    return_exceptions=True
)

# 分离成功和失败
successful = [r for r in results if not isinstance(r, Exception)]
failed = [r for r in results if isinstance(r, Exception)]

if failed:
    # 处理失败或通知用户
    print(f"{len(failed)} 个子代理失败：{failed}")

# 继续整合成功结果
final = integrate_results(successful)

    8.7 记忆共享¶

    隔离模式（默认）¶

    每个子代理独立记忆：

    subagent = await create_subagent(
    role="分析师",
    task="分析数据",
    memory="isolated"  # 默认
)

    特点： - ✅ 无干扰 - ✅ 独立上下文 - ❌ 无法共享学习

    共享模式¶

    子代理共享主代理的记忆：

    subagent = await create_subagent(
    role="分析师",
    task="分析数据",
    memory="shared"
)

    特点： - ✅ 知识共享 - ✅ 一致上下文 - ❌ 可能冲突

    选择性共享¶

    # 主代理写入共享记忆
await main_agent.write_to_memory("/memories/shared/context.txt", data)

# 子代理读取
subagent = await create_subagent(
    role="分析师",
    task="基于共享上下文分析",
    memory="read-only"  # 只读共享
)

    8.8 实战案例¶

    案例 1：市场研究报告¶

    async def generate_market_report():
    """生成综合市场研究报告"""

    # 并行：数据收集
    market_data = await create_subagent(
        role="市场数据收集员",
        task="收集 2025 年市场规模、增长率、趋势数据"
    ).finish()

    competitor_data = await create_subagent(
        role="竞争情报分析师",
        task="分析主要竞争对手的策略和份额"
    ).finish()

    customer_data = await create_subagent(
        role="用户研究员",
        task="整理用户调研和反馈数据"
    ).finish()

    # 串行：整合分析
    analysis = await create_subagent(
        role="高级分析师",
        task=f"""整合以下数据并分析：
        市场数据：{market_data}
        竞争数据：{competitor_data}
        用户数据：{customer_data}

        输出：SWOT 分析、机会识别、风险预警"""
    ).finish()

    # 并行：报告撰写
    exec_summary = await create_subagent(
        role="高管报告撰写员",
        task=f"基于分析生成 1 页高管摘要：{analysis}"
    ).finish()

    full_report = await create_subagent(
        role="资深分析师",
        task=f"基于分析生成完整报告：{analysis}"
    ).finish()

    return {
        "executive_summary": exec_summary,
        "full_report": full_report
    }

    案例 2：代码重构项目¶

    async def refactor_codebase():
    """大规模代码重构"""

    # 阶段 1：代码分析（并行）
    analysis_tasks = [
        create_subagent(
            role=f"{module} 专家",
            task=f"分析 {module} 模块的代码质量问题"
        )
        for module in ["auth", "api", "database", "frontend"]
    ]

    analyses = await asyncio.gather(*analysis_tasks)

    # 阶段 2：制定重构计划
    plan = await create_subagent(
        role="架构师",
        task=f"""基于以下分析制定重构计划：
        {analyses}

        输出：优先级、依赖关系、预估时间"""
    ).finish()

    # 阶段 3：执行重构（按依赖顺序）
    for module in get_refactor_order(plan):
        await create_subagent(
            role="高级开发工程师",
            task=f"重构 {module} 模块，遵循计划：{plan}"
        ).finish()

        # 验证
        await create_subagent(
            role="测试工程师",
            task=f"验证 {module} 重构后的功能和性能"
        ).finish()

    # 阶段 4：集成测试
    await create_subagent(
        role="QA 工程师",
        task="执行全系统集成测试"
    ).finish()

    案例 3：内容创作工作流¶

    async def create_content_series():
    """创建系列内容（如博客系列、教程）"""

    # 大纲规划
    outline = await create_subagent(
        role="内容策划师",
        task="规划 10 篇博客系列大纲，主题：Python 进阶"
    ).finish()

    # 并行：多篇文章初稿
    draft_tasks = [
        create_subagent(
            role="技术作者",
            task=f"撰写第{i}篇：{topic}"
        )
        for i, topic in enumerate(outline.topics, 1)
    ]

    drafts = await asyncio.gather(*draft_tasks)

    # 串行：统一风格编辑
    edited = await create_subagent(
        role="资深编辑",
        task=f"""统一编辑以下草稿：
        {drafts}

        确保：风格一致、术语统一、难度递进"""
    ).finish()

    # 并行：补充材料
    extras = await asyncio.gather(
        create_subagent(
            role="示例工程师",
            task="为每篇创建代码示例"
        ).finish(),
        create_subagent(
            role="练习设计师",
            task="为每篇设计练习题"
        ).finish()
    )

    return compile_series(edited, extras)

    8.9 最佳实践¶

    1. 合理分解¶

    # ✅ 好的分解：任务独立、边界清晰
subagents = [
    ("搜索", "搜索 X 相关论文"),
    ("分析", "分析搜索结果"),
    ("总结", "总结关键发现")
]

# ❌ 差的分解：任务重叠、依赖混乱
subagents = [
    ("研究", "研究 X"),  # 太模糊
    ("分析", "分析 X"),  # 与研究重叠
    ("写报告", "写报告")  # 缺少输入
]

    2. 明确指令¶

    # ✅ 好的指令：具体、可衡量
task="分析 sales_data.csv，输出：
1. 月度销售趋势图
2. Top 10 产品列表
3. 异常值标记"

# ❌ 差的指令：模糊、开放
task="分析一下这个数据"

    3. 适当并行¶

    # ✅ 适合并行：独立任务
await asyncio.gather(
    search_papers(),
    analyze_competitors(),
    collect_customer_feedback()
)

# ❌ 不适合并行：有依赖
data = await collect_data()  # 必须先完成
analysis = await analyze(data)  # 依赖 data

    4. 结果验证¶

    async def validate_result(result, criteria):
    """验证子代理结果质量"""
    validator = await create_subagent(
        role="质量检查员",
        task=f"验证以下结果是否符合标准：
        结果：{result}
        标准：{criteria}"
    )
    return await validator.finish()

    5. 资源管理¶

    # 限制并发子代理数量
semaphore = asyncio.Semaphore(5)

async def limited_create(*args, **kwargs):
    async with semaphore:
        return await create_subagent(*args, **kwargs)

# 使用
tasks = [limited_create(...) for _ in range(20)]
results = await asyncio.gather(*tasks)

    8.10 本章小结¶

    关键要点¶

    1. 子代理用于任务分解 - 并行处理、专业化分工
    2. 三种分解模式 - 并行、流水线、混合
    3. 主代理负责协调 - 分解、创建、跟踪、整合
    4. 灵活的记忆共享 - 隔离、共享、选择性共享

    创建速查¶

    # 基本创建
subagent = await create_subagent(
    role="角色",
    task="任务描述"
)
result = await subagent.finish()

# 带选项
subagent = await create_subagent(
    role="角色",
    task="任务",
    model="模型",
    tools=[...],
    timeout=300,
    memory="shared"
)

# 并行执行
results = await asyncio.gather(
    subagent1.finish(),
    subagent2.finish(),
    subagent3.finish()
)
