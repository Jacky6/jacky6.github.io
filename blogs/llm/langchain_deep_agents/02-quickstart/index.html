    第二章：快速开始¶

    5 分钟上手 Deep Agents | 从零到运行第一个 Agent

    2.1 环境准备¶

    系统要求¶

    • Python: 3.10 或更高版本
    • 操作系统: macOS / Linux / Windows (WSL)
    • 包管理器: uv (推荐) 或 pip

    检查 Python 版本¶

    python --version
# 应输出：Python 3.10.x 或更高

    2.2 安装 Deep Agents CLI¶

    方式一：使用 uv（推荐）¶

    # 安装 uv（如果尚未安装）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 安装 Deep Agents CLI（基础版，仅 OpenAI）
uv tool install deepagents-cli

# 验证安装
deepagents --version

    方式二：安装完整版（多 Provider 支持）¶

    # 安装带 Anthropic 和 Groq 支持
uv tool install 'deepagents-cli[anthropic,groq]'

# 安装所有 Provider 支持
uv tool install 'deepagents-cli[anthropic,baseten,bedrock,cohere,deepseek,fireworks,google-genai,groq,huggingface,ibm,litellm,mistralai,nvidia,ollama,openai,openrouter,perplexity,vertexai,xai]'

    方式三：使用 pip¶

    pip install deepagents-cli

# 带额外 Provider
pip install 'deepagents-cli[anthropic,groq]'

    安装验证¶

    $ deepagents --version
deepagents-cli 0.x.x

$ deepagents --help
Usage: deepagents [OPTIONS] [PROMPT]

Deep Agents CLI - Interactive AI agent with filesystem access

Options:
  --model TEXT     Model to use (e.g., openai:gpt-4o)
  --no-mcp         Disable MCP tools
  -n, --non-interactive  Non-interactive mode
  ...

    2.3 配置 API Key¶

    Deep Agents 需要 LLM Provider 的 API Key 才能工作。

    OpenAI¶

    # 临时设置（当前会话）
export OPENAI_API_KEY="sk-..."

# 永久设置（添加到 shell 配置文件）
echo 'export OPENAI_API_KEY="sk-..."' >> ~/.bashrc
# 或 ~/.zshrc
source ~/.bashrc

    Anthropic¶

    export ANTHROPIC_API_KEY="sk-ant-..."

    Google (Gemini)¶

    export GOOGLE_API_KEY="..."

    多 Provider 配置¶

    可以同时配置多个 Provider，CLI 会自动检测可用的：

    export OPENAI_API_KEY="sk-..."
export ANTHROPIC_API_KEY="sk-ant-..."
export GROQ_API_KEY="gsk_..."

    验证配置¶

    # 检查环境变量
echo $OPENAI_API_KEY
# 应输出 API Key（部分隐藏）

# 或在 CLI 中查看可用模型
deepagents --model

```python
class Calculator:
    def add(self, a, b):
        return a + b

    def subtract(self, a, b):
        return a - b

    def multiply(self, a, b):
        return a * b

    def divide(self, a, b):
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b

if __name__ == "__main__":
    calc = Calculator()
    print(f"5 + 3 = {calc.add(5, 3)}")
    print(f"5 - 3 = {calc.subtract(5, 3)}")
    print(f"5 * 3 = {calc.multiply(5, 3)}")
    print(f"5 / 3 = {calc.divide(5, 3)}")

    2.5 基本命令¶

    帮助和退出¶

    /help     # 显示帮助信息
/quit     # 退出会话
/exit     # 同上

    模型切换¶

    /model    # 打开模型选择器
/model openai:gpt-4o        # 直接切换到指定模型
/model --default            # 设置默认模型
/model --default --clear    # 清除默认模型

    文件操作¶

    /ls       # 列出当前目录文件
/cd       # 切换目录
/cat      # 查看文件内容

    其他命令¶

    /history  # 查看对话历史
/clear    # 清除当前会话
/config   # 查看配置

    2.6 配置文件¶

    配置位置¶

    位置 路径 作用域
    用户级 ~/.deepagents/config.toml 所有项目
    项目级 <project>/.deepagents/config.toml 当前项目

    配置文件示例¶

    # ~/.deepagents/config.toml

# 默认模型
[models]
default = "anthropic:claude-opus-4-6"

# 最近使用的模型（自动更新）
recent = "openai:gpt-4o"

# 自定义模型配置
[models.providers.ollama.profile."qwen3:4b"]
tool_calling = true
max_input_tokens = 32768
max_output_tokens = 8192

# 添加模型到交互式选择器
[[models.providers.ollama.models]]
name = "qwen3:4b"
display_name = "Qwen3 4B (Local)"

# MCP 配置
[mcp]
enabled = true
config_file = "~/.deepagents/.mcp.json"

    查看当前配置¶

    deepagents --config

    2.7 文件系统基础¶

    目录结构¶

    /
├── calculator.py      # 用户创建的文件
├── scratch/           # 临时工作区
├── memories/          # 长期记忆（需配置）
└── skills/            # 技能脚本（需配置）

    常用文件命令¶

    # 在 Agent 对话中使用
> ls /
> read_file /calculator.py
> write_file /test.py "print('hello')"
> edit_file /calculator.py "return a + b" "return a + b + 1"
> mkdir /my_project
> mv /old_name.py /new_name.py
> rm /unwanted_file.py

    文件持久性¶

    路径 持久性 说明
    / 根目录 会话级 对话结束清除
    /memories/ 持久 需配置 StoreBackend
    /skills/ 持久 需配置 StoreBackend

## 2.9 常见问题

### Q1: 安装失败

```bash
# 问题：uv tool install 失败
# 解决：确保 uv 已正确安装
which uv
uv --version

# 或使用 pip 安装
pip install deepagents-cli

    Q2: API Key 错误¶

    # 问题：AuthenticationError
# 解决：检查 API Key 是否正确设置
echo $OPENAI_API_KEY

# 确保没有多余的空格或引号
export OPENAI_API_KEY="sk-..."  # 正确
export OPENAI_API_KEY=" sk-... " # 错误

    Q3: 模型不可用¶

    # 问题：模型不在选择器中
# 解决：直接指定模型名
deepagents --model openai:gpt-4o

# 或添加到 config.toml
[[models.providers.openai.models]]
name = "gpt-4o"
display_name = "GPT-4o"

    Q4: 文件操作失败¶

    # 问题：Permission denied
# 解决：检查路径是否正确
# Deep Agents 使用虚拟文件系统，路径以 / 开头

# 错误：write_file ./test.py "..."
# 正确：write_file /test.py "..."

    Q5: 中文乱码¶

    # 问题：输出中文乱码
# 解决：确保终端支持 UTF-8
locale

# 设置 UTF-8
export LANG=en_US.UTF-8
export LC_ALL=en_US.UTF-8
