    第四章：模型与 Provider 配置¶

    支持 20+ LLM Provider | 模型切换和路由完全指南

    4.1 支持的 Provider 总览¶

    Deep Agents 支持任何与 LangChain 兼容的模型 Provider，包括所有支持工具调用（tool calling）的主流 LLM。

    Provider 完整列表¶

    Provider 包名 环境变星 模型 Profile
    OpenAI langchain-openai OPENAI_API_KEY ✅
    Anthropic langchain-anthropic ANTHROPIC_API_KEY ✅
    Google Gemini langchain-google-genai GOOGLE_API_KEY ✅
    Google Vertex AI langchain-google-vertexai GOOGLE_CLOUD_PROJECT ✅
    Azure OpenAI langchain-openai AZURE_OPENAI_API_KEY ✅
    AWS Bedrock langchain-aws AWS_ACCESS_KEY_ID ✅
    Groq langchain-groq GROQ_API_KEY ✅
    Mistral AI langchain-mistralai MISTRAL_API_KEY ✅
    DeepSeek langchain-deepseek DEEPSEEK_API_KEY ✅
    Fireworks langchain-fireworks FIREWORKS_API_KEY ✅
    Together langchain-together TOGETHER_API_KEY ❌
    Cohere langchain-cohere COHERE_API_KEY ❌
    Hugging Face langchain-huggingface HUGGINGFACEHUB_API_TOKEN ✅
    Ollama langchain-ollama (可选) ❌
    Nvidia langchain-nvidia-ai-endpoints NVIDIA_API_KEY ✅
    xAI (Grok) langchain-xai XAI_API_KEY ✅
    Perplexity langchain-perplexity PPLX_API_KEY ✅
    OpenRouter langchain-openrouter OPENROUTER_API_KEY ✅
    LiteLLM langchain-litellm 各 Provider ❌
    Baseten langchain-baseten BASETEN_API_KEY ✅
    IBM watsonx langchain-ibm WATSONX_APIKEY ❌

    模型 Profile 说明¶

    有 Profile (✅): 模型信息（上下文窗口、能力等）自动加载，在交互式选择器中显示

    无 Profile (❌): 需要手动配置或直接用模型名指定

    4.2 安装 Provider¶

    快速安装¶

    # 安装单个 Provider
uv tool install deepagents-cli --with langchain-anthropic

# 安装多个 Provider
uv tool install 'deepagents-cli[anthropic,groq]'

# 安装所有 Provider
uv tool install 'deepagents-cli[anthropic,baseten,bedrock,cohere,deepseek,fireworks,google-genai,groq,huggingface,ibm,litellm,mistralai,nvidia,ollama,openai,openrouter,perplexity,vertexai,xai]'

    使用安装脚本（推荐）¶

    # 安装 OpenAI + Anthropic + Groq
DEEPAGENTS_EXTRAS="anthropic,groq" curl -LsSf https://raw.githubusercontent.com/langchain-ai/deepagents/refs/heads/main/libs/cli/scripts/install.sh | bash

    后续添加 Provider¶

    # 已安装后添加新 Provider
uv tool install deepagents-cli --with langchain-ollama
uv tool install deepagents-cli --with langchain-mistralai

    验证安装¶

    # 列出已安装的 Provider
uv tool list

# 或在 CLI 中查看
deepagents --model

    4.3 配置 API Key¶

    环境变量方式（推荐）¶

    # ~/.bashrc 或 ~/.zshrc

# OpenAI
export OPENAI_API_KEY="sk-..."

# Anthropic
export ANTHROPIC_API_KEY="sk-ant-..."

# Google
export GOOGLE_API_KEY="..."

# Groq
export GROQ_API_KEY="gsk_..."

# 多个 Provider 可同时配置

    配置文件方式¶

    # ~/.deepagents/config.toml

[env]
OPENAI_API_KEY = "sk-..."
ANTHROPIC_API_KEY = "sk-ant-..."

    Provider 特定配置¶

    AWS Bedrock¶

    export AWS_ACCESS_KEY_ID="AKIA..."
export AWS_SECRET_ACCESS_KEY="..."
export AWS_REGION="us-east-1"

    Google Vertex AI¶

    export GOOGLE_CLOUD_PROJECT="my-project"
# 使用 Application Default Credentials
gcloud auth application-default login

    Ollama（本地）¶

    # 无需 API Key，确保 Ollama 服务运行
ollama serve

# 拉取模型
ollama pull qwen3:4b

    4.4 模型切换¶

    交互式切换¶

    # 启动 CLI
deepagents

# 使用 /model 命令
> /model

# 显示模型选择器：
# ┌─────────────────────────────────────┐
# │ OpenAI                              │
# │   gpt-4o                            │
# │   gpt-4o-mini                       │
# │   o1-preview                        │
# ├─────────────────────────────────────┤
# │ Anthropic                           │
# │   claude-opus-4-6                   │
# │   claude-sonnet-4-6                 │
# └─────────────────────────────────────┘

# 使用 ↑↓ 选择，Enter 确认

    命令行切换¶

    # 启动时指定
deepagents --model openai:gpt-4o

# 在交互模式中
> /model openai:gpt-4o

# 使用简写（如果唯一）
> /model gpt-4o

    设置默认模型¶

    # 方式 1：命令行
deepagents --default-model anthropic:claude-opus-4-6

# 方式 2：交互模式
> /model --default anthropic:claude-opus-4-6

# 方式 3：模型选择器
# 选择模型后按 Ctrl+S

# 方式 4：配置文件
# ~/.deepagents/config.toml
[models]
default = "anthropic:claude-opus-4-6"

    清除默认模型¶

    # 命令行
deepagents --clear-default-model

# 交互模式
> /model --default --clear

# 模型选择器
# 在当前默认模型上按 Ctrl+S

    4.5 模型解析顺序¶

    当 CLI 启动时，模型按以下优先级解析：

    1. --model 命令行参数（最高优先级）
   ↓
2. [models].default 配置文件
   ↓
3. [models].recent 最近使用（自动更新）
   ↓
4. 环境自动检测（OPENAI → ANTHROPIC → GOOGLE → VERTEX）
   ↓
5. 默认值（最低优先级）

    示例场景¶

    # 场景 1：config.toml 设置 default = "gpt-4o"
# 但未设置 --model
# → 使用 gpt-4o

# 场景 2：config.toml 设置 default = "gpt-4o"
# 但命令行指定 --model claude-opus-4-6
# → 使用 claude-opus-4-6（命令行优先）

# 场景 3：无配置，但设置 OPENAI_API_KEY
# → 使用 OpenAI 默认模型

# 场景 4：无配置，无环境变量
# → 提示设置 API Key

    4.6 模型选择器工作原理¶

    模型显示条件¶

    模型在交互式选择器中显示需要满足：

    1. Provider 包已安装 

      # 检查
uv tool list | grep langchain-anthropic

# 安装
uv tool install deepagents-cli --with langchain-anthropic

    2. 模型有 Profile 且 tool_calling = true 

      # 对于没有 Profile 的 Provider，手动添加
[models.providers.ollama.profile."qwen3:4b"]
tool_calling = true
max_input_tokens = 32768

    3. 模型支持文本输入输出 

      # 排除嵌入/图像生成模型
[models.providers.xxx.profile."xxx"]
text_inputs = true
text_outputs = true

    添加自定义模型¶

    # ~/.deepagents/config.toml

# 添加到选择器列表
[[models.providers.ollama.models]]
name = "qwen3:4b"
display_name = "Qwen3 4B (Local)"

[[models.providers.ollama.models]]
name = "qwen3:32b"
display_name = "Qwen3 32B (Local)"

# 添加 Profile（可选，用于自动摘要等功能）
[models.providers.ollama.profile."qwen3:4b"]
tool_calling = true
max_input_tokens = 32768
max_output_tokens = 8192
text_inputs = true
text_outputs = true

    4.7 模型路由和代理¶

    使用 OpenRouter¶

    OpenRouter 提供多 Provider 访问：

    # 安装
uv tool install 'deepagents-cli[openrouter]'

# 设置 API Key
export OPENROUTER_API_KEY="..."

# 使用
deepagents --model openrouter:anthropic/claude-opus
deepagents --model openrouter:openai/gpt-4o
deepagents --model openrouter:google/gemini-pro

    使用 LiteLLM¶

    LiteLLM 作为统一代理层：

    # 安装
uv tool install 'deepagents-cli[litellm]'

# 设置 API Keys（根据后端 Provider）
export OPENAI_API_KEY="..."
export ANTHROPIC_API_KEY="..."

# 使用
deepagents --model litellm:openai/gpt-4o
deepagents --model litellm:anthropic/claude-opus

    自定义 API 端点¶

    # ~/.deepagents/config.toml

[models.providers.openai]
base_url = "https://api.custom.com/v1"
api_key_env = "CUSTOM_API_KEY"

[[models.providers.openai.models]]
name = "custom-model"
display_name = "Custom Model"

    4.8 模型能力配置¶

    Profile 字段详解¶

    [models.providers.xxx.profile."model-name"]
# 是否支持工具调用（关键！）
tool_calling = true

# 上下文窗口
max_input_tokens = 128000
max_output_tokens = 8192

# 输入输出类型
text_inputs = true
text_outputs = true
image_inputs = false
audio_inputs = false

# 能力标记
supports_system_messages = true
supports_temperature = true
supports_top_p = true

    为什么要配置 Profile？¶

    1. 自动摘要 - 当对话超过阈值时自动总结
    2. 模型选择器 - 显示上下文窗口等信息
    3. 能力检测 - 避免使用不支持的功能

    4.9 各 Provider 特点¶

    OpenAI¶

    # 安装
uv tool install 'deepagents-cli[openai]'

# 模型
openai:gpt-4o          # 旗舰模型
openai:gpt-4o-mini     # 快速经济
openai:o1-preview      # 深度推理
openai:o1-mini         # 轻量推理

# 特点
# ✅ 工具调用成熟
# ✅ 生态完善
# ⚠️ 价格较高

    Anthropic¶

    # 安装
uv tool install 'deepagents-cli[anthropic]'

# 模型
anthropic:claude-opus-4-6    # 最强
anthropic:claude-sonnet-4-6  # 平衡
anthropic:claude-haiku-4-6   # 快速

# 特点
# ✅ 长上下文（200K）
# ✅ 代码能力强
# ✅ 安全性好

    Google (Gemini)¶

    # 安装
uv tool install 'deepagents-cli[google-genai]'

# 模型
google-genai:gemini-2.0-flash
google-genai:gemini-1.5-pro

# 特点
# ✅ 多模态
# ✅ 长上下文（1M+）
# ⚠️ 工具调用稍弱

    Groq¶

    # 安装
uv tool install 'deepagents-cli[groq]'

# 模型
groq:llama-3.3-70b-versatile
groq:llama-3.1-8b-instant

# 特点
# ✅ 极快（LPU 加速）
# ✅ 免费额度高
# ⚠️ 模型选择有限

    Ollama（本地）¶

    # 安装
uv tool install deepagents-cli --with langchain-ollama

# 配置
[[models.providers.ollama.models]]
name = "qwen3:4b"
display_name = "Qwen3 4B"

[models.providers.ollama.profile."qwen3:4b"]
tool_calling = true

# 特点
# ✅ 本地运行，隐私好
# ✅ 免费
# ⚠️ 需要本地资源
# ⚠️ 工具调用支持因模型而异

    4.10 最佳实践¶

    1. 多 Provider 配置¶

    # ~/.bashrc
export OPENAI_API_KEY="sk-..."        # 主力
export ANTHROPIC_API_KEY="sk-ant-..." # 代码
export GROQ_API_KEY="gsk_..."         # 快速测试
export OLLAMA_HOST="localhost:11434"  # 本地

    2. 按任务选择模型¶

    # 在脚本中根据任务选择
# 复杂推理 → claude-opus
# 代码生成 → claude-sonnet
# 快速问答 → gpt-4o-mini
# 本地测试 → qwen3:4b

    3. 成本控制¶

    # 设置默认使用经济模型
[models]
default = "openai:gpt-4o-mini"

# 需要时手动切换
> /model anthropic:claude-opus-4-6

    4. 故障转移¶

    # 在 SDK 中实现故障转移
models = [
    "anthropic:claude-opus-4-6",
    "openai:gpt-4o",
    "groq:llama-3.3-70b"
]

for model in models:
    try:
        agent = create_deep_agent(model=model)
        break
    except Exception:
        continue

    4.11 故障排查¶

    问题 1：Provider 不显示¶

    # 检查是否安装
uv tool list | grep langchain

# 重新安装
uv tool install deepagents-cli --with langchain-anthropic --force

# 检查导入
python -c "from langchain_anthropic import ChatAnthropic"

    问题 2：认证失败¶

    # 检查环境变量
echo $ANTHROPIC_API_KEY

# 测试连接
curl -H "Authorization: Bearer $ANTHROPIC_API_KEY" \
     https://api.anthropic.com/v1/models

# 检查 Key 是否过期/限额

    问题 3：模型不支持工具调用¶

    # 错误：Model does not support tool calling
# 解决：选择支持工具调用的模型

# 查看支持列表
# https://models.dev/

# 或强制添加 Profile
[models.providers.xxx.profile."model"]
tool_calling = true

    问题 4：本地 Ollama 连接失败¶

    # 检查服务
ollama list
ollama serve

# 检查端口
netstat -tlnp | grep 11434

# 测试连接
curl http://localhost:11434/api/tags

    4.12 本章小结¶

    关键要点¶

    1. 20+ Provider 支持 - 几乎所有主流 LLM 都可用
    2. 灵活切换 - 交互式选择器、命令行、配置文件
    3. 模型 Profile - 自动加载能力信息，支持自动摘要
    4. 路由代理 - OpenRouter/LiteLLM 统一访问多 Provider

    Provider 选择建议¶

    需求 推荐 Provider
    综合最佳 Anthropic / OpenAI
    代码能力 Anthropic Claude
    速度优先 Groq
    成本敏感 Ollama (本地)
    长上下文 Gemini / Claude
    多模态 Gemini
