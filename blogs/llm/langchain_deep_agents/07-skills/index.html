    第七章：技能系统¶

    基于 SKILL.md 规范 | 可复用的能力模块完全指南

    7.1 什么是 Skills？¶

    Skills（技能） 是可复用的能力模块，为 AI Agent 提供专门的工作流程和领域知识。每个技能存储在 Agent 的长期记忆中 (memories/skills/<skill-name>/SKILL.md)。

    核心优势¶

    优势 说明
    🧩 模块化 技能独立开发和测试
    📦 可复用 一次编写，多处使用
    🔌 可扩展 动态添加新技能
    💾 节省 Token 只在需要时加载相关上下文
    🎯 减少幻觉 避免系统提示中上下文过多

    7.2 SKILL.md 规范¶

    基本格式¶

    # Skill: <skill-name>

## Description
<简短描述技能的功能和用途>

## Tools
<技能提供的工具列表>

## Instructions
<详细的使用说明和工作流程>

## Examples
<使用示例>

## Dependencies
<依赖项（可选）>

    完整示例¶

    # Skill: code-review

## Description
代码审查技能，提供代码质量检查、最佳实践建议和安全漏洞扫描。

## Tools
- `lint`: 代码风格检查（使用 black/flake8）
- `security`: 安全漏洞扫描（使用 bandit）
- `performance`: 性能分析（使用 cProfile）
- `suggest`: 提供改进建议

## Instructions
1. 接收代码文件路径作为输入
2. 运行 lint 检查代码风格
3. 运行安全检查查找漏洞
4. 分析性能瓶颈
5. 生成综合审查报告

    7.3 技能类型¶

    Private Skills（私有技能）¶

    仅属于单个 Agent，存储在 Agent 的长期记忆中。

    memories/skills/
└── code-review/
    └── SKILL.md

    特点： - ✅ 仅创建者可用 - ✅ 可包含敏感逻辑 - ✅ 自由编辑 - ❌ 无法共享

    Shared Skills（共享技能）¶

    整个工作区可见，所有 Agent 可用。

    shared-skills/
├── code-review/
│   └── SKILL.md
├── data-analysis/
│   └── SKILL.md
└── web-research/
    └── SKILL.md

    特点： - ✅ 所有 Agent 可用 - ✅ 促进协作 - ✅ 减少重复 - ❌ 仅创建者可编辑

    7.5 技能加载¶

    自动加载¶

    技能在 Agent 启动时自动从 memories/skills/ 加载：

    from deepagents import create_deep_agent
from deepagents.backends import CompositeBackend, StateBackend, StoreBackend

def make_backend(runtime):
    return CompositeBackend(
        default=StateBackend(runtime),
        routes={
            "/memories/": StoreBackend(
                runtime,
                namespace=lambda ctx: (ctx.runtime.context.user_id,),
            ),
        },
    )

agent = create_deep_agent(
    store=InMemoryStore(),
    backend=make_backend,
    system_prompt="""你有以下技能可用：
- /memories/skills/code-review/SKILL.md
- /memories/skills/data-analysis/SKILL.md

在每段对话开始时读取相关技能文件。"""
)

    条件加载¶

    根据任务类型加载相关技能：

    system_prompt="""你是多功能助手。

可用技能：
- /memories/skills/code-review/ - 代码审查
- /memories/skills/data-viz/ - 数据可视化
- /memories/skills/web-search/ - 网络搜索

根据用户请求选择相关技能：
- 如果请求涉及代码 → 加载 code-review
- 如果请求涉及数据 → 加载 data-viz
- 如果请求需要信息 → 加载 web-search"""

    7.8 技能与工具集成¶

    定义工具¶

    在 SKILL.md 中声明工具：

    ## Tools

### lint
检查代码风格。

**参数：**
- `file_path`: 文件路径
- `config`: 配置文件路径（可选）

**返回：**
- 问题列表

### security
扫描安全漏洞。

**参数：**
- `file_path`: 文件路径

**返回：**
- 漏洞列表

    实现工具¶

    # /skills/code-review/tools.py

import subprocess

def lint(file_path: str, config: str = None) -> list:
    """运行 flake8 检查"""
    cmd = ["flake8", file_path]
    if config:
        cmd.extend(["--config", config])

    result = subprocess.run(cmd, capture_output=True, text=True)
    return parse_flake8_output(result.stdout)

def security(file_path: str) -> list:
    """运行 bandit 安全检查"""
    cmd = ["bandit", "-f", "json", file_path]
    result = subprocess.run(cmd, capture_output=True, text=True)
    return parse_bandit_output(result.stdout)

    在 Agent 中使用¶

    from skills.code_review.tools import lint, security

agent = create_deep_agent(
    tools=[lint, security],
    system_prompt="""你有代码审查工具可用。
    当用户请求审查代码时，使用 lint 和 security 工具。"""
)

    7.9 技能最佳实践¶

    1. 单一职责¶

    # ✅ 好的：单一职责
# Skill: code-format
# Skill: code-lint
# Skill: code-security

# ❌ 避免：职责过多
# Skill: code-everything  # 包含格式化、lint、安全、测试...

    2. 清晰接口¶

    ## Tools

### analyze
**输入：** CSV 文件路径
**输出：** 统计摘要字典

**示例：**

    analyze /data/sales.csv { "rows": 1000, "columns": 10, "numeric_cols": 5, "categorical_cols": 3 }

    3. 错误处理¶

    ## Error Handling

- 文件不存在 → 返回错误消息
- 格式不支持 → 建议替代方案
- 处理超时 → 分块处理

    4. 版本控制¶

    # Skill: data-viz
## Version: 1.2.0
## Changelog
- 1.2.0: 添加热力图支持
- 1.1.0: 添加导出 PDF 功能
- 1.0.0: 初始版本

    5. 测试技能¶

    # /skills/code-review/test_skill.py

def test_lint():
    result = lint("/test/sample.py")
    assert len(result) > 0
    assert "line" in result[0]

def test_security():
    result = security("/test/vulnerable.py")
    assert any("injection" in r for r in result)

    7.10 技能与 MCP 对比¶

    特性 Skills MCP Tools
    定义方式 SKILL.md 文件 MCP 服务器
    加载时机 Agent 启动时 连接时自动发现
    执行环境 同 Agent 独立进程
    适用场景 领域知识、工作流 外部 API、数据库
    扩展性 需要重启 Agent 动态添加

    结合使用¶

    // .mcp.json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"]
    }
  }
}

    # Skill: pr-review

## Description
GitHub PR 审查技能，结合 MCP GitHub 工具。

## Tools
- `list_prs`: 列出 PR（来自 MCP）

## Instructions
1. 使用 list_prs 获取待审查 PR
2. 使用 get_diff 获取代码变更

4. 使用 comment 添加审查意见

    # Skill: data-analysis

## Description
数据分析技能，支持数据清洗、探索性分析和统计建模。

## Tools
- `load_data`: 加载数据（CSV/Excel/JSON）
- `clean_data`: 数据清洗

2. 检查质量（缺失值、异常值）
3. 清洗和预处理
4. 探索性分析（分布、相关性）
5. 建模和验证
6. 可视化和报告

## Dependencies
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
