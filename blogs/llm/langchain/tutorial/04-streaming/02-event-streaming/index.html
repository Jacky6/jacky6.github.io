    02 Event Streaming — stream_events v3 API¶

    官方文档：https://docs.langchain.com/oss/python/langchain/event-streaming

    ⭐ 推荐：新应用优先使用 Event Streaming API (version="v3")，类型安全、统一事件格式。

    ✅ 本文已按实测重写（2026-10-30）：所有示例在 langchain 1.3.4 / langgraph 1.2.4 上验证通过。v3 返回的是运行流对象（GraphRunStream），通过类型化投影消费——不是直接迭代 AgentEvent 数据类（旧版文档的错误描述）。

    📚 本章目标¶

    学完本章后，你将掌握：

    • ✅ stream_events(version="v3") 的真实返回形态：运行流对象 + 类型化投影
    • ✅ 四个核心投影：messages / tool_calls / values / output
    • ✅ Token 级打字机效果、工具调用监控、逐步状态追踪
    • ✅ 异步版本 astream_events
    • ✅ v2 vs v3 对比与迁移

    02.1 v3 的真实形态：运行流对象 + 投影¶

    stream_events(version="v3") 返回一个 GraphRunStream 运行流对象。它本身不是事件迭代器，而是暴露多个类型化投影（projection），每个投影是一个独立迭代器，多个消费者可同时读取不同投影、互不消耗：

    stream = agent.stream_events(input, version="v3")

stream.messages    # 模型消息流（含 text 增量、聚合消息）
stream.tool_calls  # 工具调用流（开始/完成/结果）
stream.values      # 每步的完整状态快照
stream.output      # 产出 key（如 "messages"）
stream.subgraphs   # 子图事件
stream.interrupts  # 中断信息（HITL）

    ⚠️ 与旧文档的区别：不要写 for event in agent.stream_events(...) 然后匹配 AgentEvent(type="model_start")——直接迭代得到的是协议事件字典，不是文档描述的数据类。正确姿势是消费投影。

    02.2 基础用法（实测代码）¶

    from langchain.agents import create_agent
from langchain_core.tools import tool

@tool
def get_weather(city: str) -> str:
    """查询城市天气"""
    return "晴，25°C"

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
)

# v3：返回运行流对象
stream = agent.stream_events(
    {"messages": [("user", "北京今天天气怎么样？")]},
    version="v3",
)

# 消费 messages 投影：Token 级增量
for msg in stream.messages:
    if msg.text:          # text 是当前增量
        print(msg.text, end="", flush=True)
print()

    stream.messages 产出 ChatModelStream 对象，关键字段：

    属性 含义
    msg.text 本次增量文本（打字机效果用这个）
    msg.output_message 聚合后的完整消息（含 tool_calls）
    msg.node 产生消息的节点名
    msg.reasoning 推理内容增量（如模型支持）

    02.3 监控工具调用：tool_calls 投影¶

    stream = agent.stream_events(
    {"messages": [("user", "北京今天天气怎么样？")]},
    version="v3",
)

for tc in stream.tool_calls:
    # ToolCallStream 字段
    print(f"工具调用: {tc.tool_name} (id={tc.tool_call_id})")
    print(f"  输入: {tc.input}")
    if tc.completed:
        print(f"  输出: {tc.output}")
    if tc.error:
        print(f"  错误: {tc.error}")

    ToolCallStream 的字段（实测）：

    字段 含义
    tool_call_id 调用 ID（与请求配对）
    tool_name 工具名
    input 参数（流式聚合）
    output 执行结果
    error 错误信息
    completed 是否完成

    02.4 追踪执行进度：values 投影¶

    values 每步产出完整状态快照，适合进度条和调试：

    stream = agent.stream_events(
    {"messages": [("user", "北京今天天气怎么样？")]},
    version="v3",
)

final_state = None
for i, state in enumerate(stream.values):
    final_state = state
    msgs = state["messages"]
    print(f"step {i}: {len(msgs)} 条消息，最新: {type(msgs[-1]).__name__}")
# 实测输出：
# step 0: 1 条消息，最新: HumanMessage
# step 1: 2 条消息，最新: AIMessage      ← 模型请求工具
# step 2: 3 条消息，最新: ToolMessage    ← 工具结果
# step 3: 4 条消息，最新: AIMessage      ← 最终答案

# values 的最后一个就是最终状态
print(final_state["messages"][-1].content)

    02.5 多投影并行消费¶

    多个投影可同时迭代、互不消耗（这是 v3 相对 v2 的核心优势）：

    stream = agent.stream_events(input, version="v3")

# 消费者 1：打字机渲染 text
# 消费者 2：侧栏显示工具调用
# 消费者 3：进度条按 values 步数推进
# 各自独立迭代 stream.messages / stream.tool_calls / stream.values

    注意：同一投影只能消费一次；需要重复消费就重新发起 stream_events。

    02.6 异步版本¶

    # 异步：astream_events
async for msg in agent.astream_events(input, version="v3").messages:
    if msg.text:
        print(msg.text, end="", flush=True)

# 或在异步上下文中消费其他投影
stream = agent.astream_events(input, version="v3")
async for tc in stream.tool_calls:
    print(f"{tc.tool_name}: {tc.input}")

    02.7 SSE Web 输出（FastAPI）¶

    from fastapi import FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()

@app.get("/chat")
async def chat(q: str):
    async def event_generator():
        stream = agent.astream_events(
            {"messages": [("user", q)]}, version="v3"
        )
        async for msg in stream.messages:
            if msg.text:
                yield f"data: {msg.text}\n\n"
        yield "data: [DONE]\n\n"

    return StreamingResponse(event_generator(), media_type="text/event-stream")

    02.8 v2 vs v3 对比¶

    维度 v2（stream(stream_mode=...)) v3（stream_events）
    返回 chunk 字典，需按 key 分支 运行流对象 + 类型化投影
    类型安全 弱（dict） 强（ChatModelStream / ToolCallStream）
    多消费者 手动分发 投影天然隔离
    工具参数聚合 手动拼接 ToolCallStream.input 自动聚合
    状态 beta beta（experimental）

    迁移要点：

    v2 写法 v3 写法
    for chunk in agent.stream(..., stream_mode="messages") for msg in stream.messages
    chunk["messages"][-1] 判断类型 msg.text / msg.output_message
    手动聚合 tool_call 参数分片 stream.tool_calls 的 tc.input
    stream_mode="values" stream.values

    02.9 完整实战示例（可运行）¶

    以下示例用脚本化模型替身，无需 API Key 即可验证（测试姿势见 agent/concepts/08）：

    from langchain.agents import create_agent
from langchain_core.language_models import FakeMessagesListChatModel
from langchain_core.messages import AIMessage
from langchain_core.tools import tool

class ScriptedModel(FakeMessagesListChatModel):
    """脚本化替身：按顺序回放预设响应。"""
    def bind_tools(self, tools, **kwargs):
        return self

@tool
def get_weather(city: str) -> str:
    """查询城市天气"""
    return "晴，25°C"

model = ScriptedModel(responses=[
    AIMessage(content="", tool_calls=[
        {"id": "c1", "name": "get_weather", "args": {"city": "北京"}}
    ]),
    AIMessage(content="北京今天晴，25°C。"),
])
agent = create_agent(model=model, tools=[get_weather])

stream = agent.stream_events(
    {"messages": [("user", "北京天气")]}, version="v3"
)

# ① text 增量
for msg in stream.messages:
    if msg.text:
        print(f"text: {msg.text!r}")

# ② 工具调用
stream = agent.stream_events(
    {"messages": [("user", "北京天气")]}, version="v3"
)
for tc in stream.tool_calls:
    print(f"tool: {tc.tool_name} id={tc.tool_call_id}")

# ③ 逐步状态 + 最终答案
stream = agent.stream_events(
    {"messages": [("user", "北京天气")]}, version="v3"
)
final = None
for state in stream.values:
    final = state
print(f"最终: {final['messages'][-1].content!r}")
# 消息轨迹: HumanMessage → AIMessage → ToolMessage → AIMessage

    📝 本章小结¶

    1. v3 返回运行流对象，通过 messages / tool_calls / values / output 投影消费，不是迭代 AgentEvent。
    2. 打字机效果用 msg.text；完整消息用 msg.output_message。
    3. 工具监控用 stream.tool_calls（input 自动聚合，无需手动拼接参数分片）。
    4. values 最后一个快照即最终状态。
    5. v3 仍是 beta（运行时会打印 experimental 警告），生产使用需锁定版本。
