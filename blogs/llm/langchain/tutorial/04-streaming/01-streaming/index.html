    第 10 章：流式输出 - Streaming¶

    本章内容：Agent 进度流、Token 流、自定义更新、多模式流式、Event Streaming（v1.3+）

    官方文档：https://docs.langchain.com/oss/python/langchain/streaming/

    📚 本章目标¶

    学完本章后，你将掌握：

    • ✅ 使用 agent.stream() 流式获取 Agent 进度
    • ✅ 流式 LLM Token（stream_mode="messages"）
    • ✅ 流式思考/推理 Token（reasoning tokens）
    • ✅ 使用 get_stream_writer() 从工具内发送自定义更新
    • ✅ 多模式同时流式
    • ✅ Event Streaming（v1.3+ 推荐的新 API）
    • ✅ 理解 version="v2" 流式格式

    10.1 流式输出概述¶

    流式输出对于提升基于 LLM 的应用用户体验至关重要。通过渐进式显示输出（即使在完整响应准备好之前），流式显著改善了用户体验，尤其是在处理 LLM 延迟时。

    LangChain 流式能力¶

    能力 说明 Stream Mode
    Agent 进度 每个 Agent 步骤后的状态更新 updates
    LLM Tokens 模型生成的 token 逐字输出 messages
    思考/推理 模型推理过程实时输出 messages
    自定义更新 工具内发送任意数据 custom
    多模式 同时消费多种流 ["updates", "messages", "custom"]

    支持的 Stream Mode¶

    from langchain.agents import create_agent

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
)

# 单模式
for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "SF 天气如何？"}]},
    stream_mode="updates",
    version="v2",
):
    ...

# 多模式
for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "SF 天气如何？"}]},
    stream_mode=["updates", "custom"],
    version="v2",
):
    ...

    提示：推荐使用 Event Streaming（LangChain v1.3+ 引入的类型投影 API）， 它为每种投影提供独立的迭代器，无需在 stream_mode chunk 之间分支判断。

    10.2 Agent 进度流（stream_mode="updates"）¶

    使用 stream_mode="updates" 流式获取 Agent 每个步骤的状态更新。

    典型的单次工具调用流程会输出： - LLM 节点：带工具调用请求的 AIMessage - Tool 节点：带执行结果的 ToolMessage - LLM 节点：最终 AI 响应

    from langchain.agents import create_agent
from langchain_core.utils.uuid import uuid7
from langgraph.checkpoint.memory import InMemorySaver

def get_weather(city: str) -> str:
    """获取指定城市的天气"""
    return f"{city} 永远是晴天！"

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    checkpointer=InMemorySaver(),
)

config = {"configurable": {"thread_id": str(uuid7())}}

for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "旧金山天气怎么样？"}]},
    config=config,
    stream_mode="updates",
    version="v2",
):
    if chunk["type"] == "updates":
        for step, data in chunk["data"].items():
            print(f"step: {step}")
            print(f"content: {data['messages'][-1].content_blocks}")

    输出示例： 

    step: model
content: [{'type': 'tool_call', 'name': 'get_weather', 'args': {'city': 'San Francisco'}, ...}]
step: tools
content: [{'type': 'text', 'text': 'San Francisco 永远是晴天！'}]
step: model
content: [{'type': 'text', 'text': '旧金山天气：永远是晴天！需要实时数据吗？'}]

    注意：使用 thread_id 持久化对话历史需要配置 checkpointer。 LangSmith 部署自动提供 checkpointer；本地使用需显式传入 create_agent(..., checkpointer=InMemorySaver())。

    10.3 LLM Token 流（stream_mode="messages"）¶

    流式获取 LLM 生成的 token：

    from langchain.agents import create_agent

def get_weather(city: str) -> str:
    """获取天气"""
    return f"{city} 晴天，25°C"

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
)

for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "旧金山天气？"}]},
    stream_mode="messages",
    version="v2",
):
    if chunk["type"] == "messages":
        token, metadata = chunk["data"]
        print(f"node: {metadata['langgraph_node']}")
        print(f"content: {token.content_blocks}")

    输出示例： 

    node: model
content: [{'type': 'tool_call_chunk', 'id': 'call_...', 'name': 'get_weather', 'args': '', 'index': 0}]
node: model
content: [{'type': 'tool_call_chunk', ..., 'args': '{"city": "San Francisco"}', 'index': 0}]
node: model
content: []
node: tools
content: [{'type': 'text', 'text': '旧金山 晴天，25°C'}]
node: model
content: [{'type': 'text', 'text': '旧'}]
node: model
content: [{'type': 'text', 'text': '金山'}]
node: model
content: [{'type': 'text', 'text': '天气'}]
...

    流式思考/推理 Token¶

    支持 reasoning 的模型（如 OpenAI o 系列、Anthropic Claude）会自动输出推理 token：

    agent = create_agent(
    model="openai:gpt-5.5",  # 支持 reasoning 的模型
    tools=[complex_analysis_tool],
)

for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "分析这个复杂问题..."}]},
    stream_mode="messages",
    version="v2",
):
    if chunk["type"] == "messages":
        token, metadata = chunk["data"]
        for block in token.content_blocks:
            if block["type"] == "reasoning":
                print(f"[推理] {block.get('reasoning', '')}", end="", flush=True)
            elif block["type"] == "text":
                print(f"[回答] {block.get('text', '')}", end="", flush=True)

    10.4 自定义更新（stream_mode="custom"）¶

    在工具执行期间发送任意实时更新，使用 get_stream_writer()：

    from langchain.agents import create_agent
from langgraph.config import get_stream_writer

def get_weather(city: str) -> str:
    """获取天气"""
    writer = get_stream_writer()
    writer(f"正在查询 {city} 的数据...")
    writer(f"已获取 {city} 的天气信息")
    return f"{city} 晴天，25°C"

agent = create_agent(
    model="anthropic:claude-sonnet-4-6",
    tools=[get_weather],
)

for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "旧金山天气？"}]},
    stream_mode="custom",
    version="v2",
):
    if chunk["type"] == "custom":
        print(chunk["data"])

    输出： 

    正在查询 San Francisco 的数据...
已获取 San Francisco 的天气信息

    注意：如果在工具中使用了 get_stream_writer()，该工具将无法在 LangGraph 执行上下文之外单独调用。

    实时进度示例：下载文件¶

    import time
from langgraph.config import get_stream_writer

def download_file(url: str) -> str:
    """下载文件"""
    writer = get_stream_writer()

    total = 100
    for i in range(total):
        time.sleep(0.05)  # 模拟下载
        progress = (i + 1) / total * 100
        writer(f"下载进度：{progress:.0f}%")

    return "下载完成"

    10.5 多模式流式¶

    同时订阅多种流模式：

    from langchain.agents import create_agent
from langgraph.config import get_stream_writer

def get_weather(city: str) -> str:
    writer = get_stream_writer()
    writer(f"查询中: {city}")
    return f"{city} 晴天"

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
)

for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "旧金山天气？"}]},
    stream_mode=["updates", "custom"],
    version="v2",
):
    print(f"stream_mode: {chunk['type']}")
    print(f"content: {chunk['data']}")

    每个 chunk 是 StreamPart 字典，包含 type、ns、data 键。使用 chunk["type"] 判断流模式，chunk["data"] 获取负载。

    10.6 异步流式¶

    所有流式操作都有异步版本：

    import asyncio
from langchain.agents import create_agent

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
)

async def stream_agent():
    async for chunk in agent.astream(
        {"messages": [{"role": "user", "content": "旧金山天气？"}]},
        stream_mode="updates",
        version="v2",
    ):
        if chunk["type"] == "updates":
            for step, data in chunk["data"].items():
                print(f"step: {step}, content: {data['messages'][-1].content}")

asyncio.run(stream_agent())

    10.7 Model 级别流式输出¶

    除了 Agent 级别流式，你也可以直接在模型上使用 .stream() 和 .astream()：

    from langchain.chat_models import init_chat_model

model = init_chat_model("openai:gpt-5.5")

# 同步流式
for chunk in model.stream("写一首关于春天的诗"):
    print(chunk.content, end="", flush=True)

# 异步流式
async for chunk in model.astream("写一首关于春天的诗"):
    print(chunk.content, end="", flush=True)

# 合并 chunks
from langchain.messages import AIMessageChunk
full_message = None
for chunk in model.stream("写一首关于春天的诗"):
    full_message = chunk if full_message is None else full_message + chunk
print(f"\n完整消息：{full_message.text}")

    带回调的流式¶

    from langchain_core.callbacks import StreamingStdOutCallbackHandler

model = init_chat_model(
    "openai:gpt-5.5",
    streaming=True,
    callbacks=[StreamingStdOutCallbackHandler()],
)

response = model.invoke("你好")  # 自动流式输出

    10.8 Event Streaming（v1.3+ 推荐）¶

    官方推荐：对于新应用，推荐使用 Event Streaming—— LangChain v1.3 引入的类型投影 API。

    Event Streaming 为每种投影提供独立的迭代器，你无需在 stream_mode chunk 之间分支判断：

    from langchain.agents import create_agent

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
)

# 分离的迭代器
for event in agent.stream_events(
    {"messages": [{"role": "user", "content": "旧金山天气？"}]},
    version="v2",
):
    # 每个 event 有明确的类型
    if event["type"] == "message_chunk":
        print(event["data"]["content"], end="", flush=True)
    elif event["type"] == "tool_call_chunk":
        print(f"\n[工具] {event['data']['name']}: {event['data']['args']}")
    elif event["type"] == "custom_event":
        print(f"\n[自定义] {event['data']}")

    支持的投影： - messages — 消息流 - values — 状态值 - tool_calls — 工具调用 - subgraphs — 子图事件

    10.9 实战：流式对话界面¶

    10.9.1 命令行 Agent 对话¶

    from langchain.agents import create_agent
from langchain_core.utils.uuid import uuid7
from langgraph.checkpoint.memory import InMemorySaver
import sys

def get_weather(city: str) -> str:
    """获取天气"""
    return f"{city} 晴天，25°C"

# 创建 Agent
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    checkpointer=InMemorySaver(),
    system_prompt="你是天气助手。",
)

config = {"configurable": {"thread_id": str(uuid7())}}

print("╔══════════════════════════════════════╗")
print("║  流式 Agent 对话助手                  ║")
print("║  输入 'quit' 退出                     ║")
print("╚══════════════════════════════════════╝")

while True:
    try:
        user_input = input("\n👤 你：").strip()
        if not user_input:
            continue
        if user_input.lower() == "quit":
            print("再见！")
            break

        print("🤖 AI: ", end="", flush=True)

        for chunk in agent.stream(
            {"messages": [{"role": "user", "content": user_input}]},
            config=config,
            stream_mode="messages",
            version="v2",
        ):
            if chunk["type"] == "messages":
                token, metadata = chunk["data"]
                # 只输出 text 类型的 content_blocks
                for block in token.content_blocks:
                    if block["type"] == "text":
                        print(block["text"], end="", flush=True)

        print()  # 换行

    except KeyboardInterrupt:
        print("\n\n中断退出")
        break

    10.9.2 Web 流式（Server-Sent Events）¶

    from flask import Flask, Response, request, jsonify, stream_with_context
from langchain.agents import create_agent
from langgraph.config import get_stream_writer
import json

app = Flask(__name__)

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    system_prompt="你是天气助手。",
)

@app.route("/chat", methods=["POST"])
def chat():
    user_input = request.json.get("message", "")

    def generate():
        for chunk in agent.stream(
            {"messages": [{"role": "user", "content": user_input}]},
            stream_mode="messages",
            version="v2",
        ):
            if chunk["type"] == "messages":
                token, _ = chunk["data"]
                for block in token.content_blocks:
                    if block["type"] == "text":
                        yield f"data: {json.dumps({'type': 'token', 'content': block['text']})}\n\n"

        yield f"data: {json.dumps({'type': 'done'})}\n\n"

    return Response(
        stream_with_context(generate()),
        mimetype="text/event-stream",
    )

if __name__ == "__main__":
    app.run(debug=True, port=5000)

    10.10 最佳实践¶

    10.10.1 选择流式模式¶

    场景 推荐模式
    前端打字机效果 stream_mode="messages"
    实时显示 Agent 步骤 stream_mode="updates"
    工具内进度提示 stream_mode="custom" + get_stream_writer()
    新应用开发 Event Streaming (stream_events())
    同时监控多种信号 stream_mode=["updates", "custom"]

    10.10.2 性能优化¶

    • 使用 checkpointer 持久化历史，避免重复计算
    • 异步流式（astream）适合高并发场景
    • Event Streaming 比 stream_mode 更易用，推荐新项目使用

    10.10.3 处理 reasoning token¶

    # 分离输出推理和最终回答
reasoning_buffer = ""
answer_buffer = ""

for chunk in agent.stream(..., stream_mode="messages", version="v2"):
    if chunk["type"] == "messages":
        token, _ = chunk["data"]
        for block in token.content_blocks:
            if block["type"] == "reasoning":
                reasoning_buffer += block.get("reasoning", "")
            elif block["type"] == "text":
                answer_buffer += block.get("text", "")
