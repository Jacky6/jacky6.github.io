    第 02 章：快速开始¶

    5 分钟构建你的第一个 AI Agent | 从零到运行

    本章目标¶

    学完本章后，你将能够：

    • ✅ 10 行代码创建第一个 Agent
    • ✅ 理解 Agent 的基本工作流程
    • ✅ 定义和调用自定义工具
    • ✅ 配置系统提示控制 Agent 行为
    • ✅ 配置对话持久化（checkpointer + thread_id）
    • ✅ 传递运行时上下文（context_schema）
    • ✅ 运行和调试 Agent

    2.1 5 分钟快速上手¶

    最简单的 Agent¶

    # hello_agent.py
from langchain.agents import create_agent

# 1. 定义工具
def get_weather(city: str) -> str:
    """获取天气信息"""
    return f"It's always sunny in {city}!"

# 2. 创建 Agent — 用 provider:model-id 格式
agent = create_agent(
    model="openai:gpt-5.5",  # 或 "anthropic:claude-sonnet-4-6"
    tools=[get_weather],
    system_prompt="你是 helpful assistant"
)

# 3. 运行 Agent
response = agent.invoke({
    "messages": [{"role": "user", "content": "北京天气如何？"}]
})

print(response)

    运行：

    # 确保已配置 API Key（根据所选 Provider）
export OPENAI_API_KEY="sk-..."
# 或
export ANTHROPIC_API_KEY="sk-ant-..."
# 或
export GOOGLE_API_KEY="AIza..."

# 运行
python hello_agent.py

    预期输出：

    {'messages': [...], 'structured_response': '北京现在是晴朗的好天气！...'}

    🎉 恭喜！你已经创建了第一个 Agent！

    2.2 代码详解¶

    让我们逐行分析这段代码：

    第 1 步：导入¶

    from langchain.agents import create_agent
    • create_agent 是 LangChain 的核心函数
    • 它会自动处理模型调用、工具执行、循环推理

    第 2 步：定义工具¶

    def get_weather(city: str) -> str:
    """获取天气信息"""
    return f"It's always sunny in {city}!"

    工具的要求： - ✅ 必须是 Python 函数（或 coroutine） - ✅ 参数要有类型注解（city: str） - ✅ 必须有文档字符串（"""..."""） - ✅ 返回值会被转换为字符串

    工具的作用： - 扩展 Agent 的能力 - 让 Agent 能与外部系统交互 - 每个工具都有名称和描述（从函数名和文档字符串自动提取）

    第 3 步：创建 Agent¶

    agent = create_agent(
    model="openai:gpt-5.5",  # 模型
    tools=[get_weather],         # 工具列表
    system_prompt="你是 helpful assistant"  # 行为指导
)

    参数说明：

    参数 类型 必需 说明
    model str / Model ✅ 模型标识符，推荐 provider:model-id 格式
    tools list ❌ 工具列表，可为空
    system_prompt str ❌ 系统提示词
    name str ❌ Agent 名称（子图嵌入时的节点名）
    response_format Schema ❌ 结构化输出格式
    checkpointer BaseCheckpointSaver ❌ 对话持久化（如 InMemorySaver()）
    context_schema dataclass ❌ per-run 运行时上下文 schema
    state_schema TypedDict ❌ 自定义状态 schema 扩展
    middleware list ❌ 中间件列表

    第 4 步：运行 Agent¶

    response = agent.invoke({
    "messages": [{"role": "user", "content": "北京天气如何？"}]
})

    输入格式： - messages: 消息列表 - 每条消息包含 role 和 content - role 可以是："user", "assistant", "system"

    输出格式： - messages: 完整对话历史 - structured_response: 结构化响应（如果定义了）

    2.3 实战：天气预报 Agent¶

    让我们构建一个更实用的天气预报 Agent。

    完整代码¶

    # weather_agent.py
from langchain.agents import create_agent
from langchain.tools import tool
from dataclasses import dataclass

# ========== 1. 定义工具 ==========

@tool
def get_weather_for_location(city: str) -> str:
    """获取指定城市的天气信息"""
    # 实际应用中调用天气 API
    weather_data = {
        "北京": "晴，25°C，湿度 40%",
        "上海": "多云，22°C，湿度 60%",
        "广州": "小雨，28°C，湿度 80%",
        "深圳": "晴，30°C，湿度 70%",
    }
    return weather_data.get(city, f"{city}: 数据暂缺")

@tool
def get_user_location(user_id: str) -> str:
    """获取用户当前位置"""
    # 实际应用中从数据库获取
    locations = {
        "user1": "北京",
        "user2": "上海",
    }
    return locations.get(user_id, "未知位置")

# ========== 2. 定义系统提示 ==========

SYSTEM_PROMPT = """你是专业天气预报员，说话喜欢用双关语。

你可用两个工具：
- get_weather_for_location: 获取指定城市天气
- get_user_location: 获取用户当前位置

如果用户问天气但没说地点，先获取用户位置。
回答要有趣，多用天气相关的双关语。"""

# ========== 3. 创建 Agent ==========

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather_for_location, get_user_location],
    system_prompt=SYSTEM_PROMPT
)

# ========== 4. 运行测试 ==========

if __name__ == "__main__":
    # 测试 1: 指定城市
    print("=" * 50)
    print("测试 1: 查询北京天气")
    print("=" * 50)
    response = agent.invoke({
        "messages": [{"role": "user", "content": "北京天气如何？"}]
    })
    print(response.get("structured_response", response))

    # 测试 2: 获取当前位置
    print("\n" + "=" * 50)
    print("测试 2: 查询当前位置天气")
    print("=" * 50)
    response = agent.invoke({
        "messages": [{"role": "user", "content": "我这里天气怎么样？"}],
    }, context={"user_id": "user1"})
    print(response.get("structured_response", response))

    2.4 Agent 工作原理¶

    执行流程¶

    用户输入 → Agent 处理 → 输出响应
              ↓
         ┌────┴────┐
         ↓         ↓
    思考推理    调用工具
         ↓         ↓
    观察结果 → 继续推理
         ↓
    最终答案

    详细执行步骤¶

    2.5 定义工具的多种方式¶

    方式 1：简单函数（推荐）¶

    def get_weather(city: str) -> str:
    """获取天气"""
    return f"{city}: Sunny"

agent = create_agent(model, tools=[get_weather])

    方式 2：使用 @tool 装饰器¶

    from langchain.tools import tool

@tool
def get_weather(city: str) -> str:
    """获取指定城市的天气信息"""
    return f"{city}: Sunny"

# @tool 会自动：
# - 提取函数名作为工具名
# - 提取文档字符串作为描述
# - 解析参数类型注解

    方式 3：自定义工具名称和描述¶

    from langchain.tools import tool

@tool("weather_api")  # 自定义名称
def get_weather(city: str) -> str:
    """
    获取指定城市的当前天气状况。

    参数:
        city: 城市名称，如"北京"、"上海"

    返回:
        天气描述字符串
    """
    return f"{city}: Sunny"

    方式 4：异步工具¶

    from langchain.tools import tool
import aiohttp

@tool
async def fetch_weather(city: str) -> str:
    """异步获取天气（调用真实 API）"""
    async with aiohttp.ClientSession() as session:
        async with session.get(f"https://api.weather.com/{city}") as resp:
            data = await resp.json()
            return f"{city}: {data['condition']}"

    方式 5：带运行时的工具¶

    from dataclasses import dataclass
from langchain.tools import tool, ToolRuntime

@dataclass
class Context:
    user_id: str

@tool
def get_user_location(runtime: ToolRuntime[Context]) -> str:
    """获取当前用户位置"""
    # 可以访问运行时上下文
    user_id = runtime.context.user_id
    return lookup_location(user_id)

    2.6 对话持久化（Memory）¶

    Agent 默认不记住之前的对话。使用 checkpointer 可以保存对话历史：

    from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver
from langchain_core.utils.uuid import uuid7

# 创建带 checkpointer 的 Agent
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[],
    system_prompt="你是 helpful assistant",
    checkpointer=InMemorySaver(),
)

# 生成一个 thread_id（每次对话一个 ID）
thread_id = str(uuid7())
config = {"configurable": {"thread_id": thread_id}}

# 第一轮对话
result = agent.invoke(
    {"messages": [{"role": "user", "content": "我叫小智"}]},
    config=config,
)
print(result["messages"][-1].content)
# → 你好小智！很高兴认识你。

# 第二轮对话 — Agent 记得之前说过什么
result = agent.invoke(
    {"messages": [{"role": "user", "content": "我叫什么名字？"}]},
    config=config,  # 用同一个 thread_id
)
print(result["messages"][-1].content)
# → 你叫小智！

    关键点： - 同一 thread_id = 同一对话会话 - 不同 thread_id = 独立对话 - InMemorySaver 数据存在内存中，重启后丢失 - 生产环境可用 AsyncSqliteSaver 或 LangGraphSaver 持久化到磁盘/数据库

    2.7 运行时上下文（Context）¶

    context_schema 让你在每个 Agent 运行中传递自定义配置（如用户 ID、偏好设置）：

    from dataclasses import dataclass
from langchain.agents import create_agent
from langchain.agents import AgentRuntime
from langchain_core.utils.uuid import uuid7

# 1. 定义上下文结构
@dataclass
class Context:
    user_id: str
    language: str = "zh"

# 2. 创建 Agent 时指定 context_schema
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[],
    system_prompt="你是 helpful assistant",
    context_schema=Context,
)

# 3. 在中间件或工具中访问上下文
def get_user_preferences(runtime: AgentRuntime) -> str:
    user_id = runtime.context.user_id
    return f"用户 {user_id} 的偏好设置"

# 4. 调用时传递 context
result = agent.invoke(
    {"messages": [{"role": "user", "content": "你好"}]},
    config={"configurable": {"thread_id": str(uuid7())}},
    context=Context(user_id="user-123", language="zh"),
)

    关键点： - context 在 invoke() 时传入，不同于 config（配置 checkpointer/thread） - runtime.context 在中间件和工具中可用 - 适合传递：用户 ID、租户 ID、权限信息等

行为：如果用户没说地点，先获取位置
注意：不要编造信息，保持友好

    Q3: Agent 不调用工具怎么办？¶

    可能原因： 1. 工具描述不清晰 2. 系统提示没说明可用工具 3. 模型不够强大

    解决方案： 

    # 1. 改进工具描述
@tool
def get_weather(city: str) -> str:
    """
    获取指定城市的当前天气。
    当用户询问天气时使用此工具。
    参数 city 必须是城市名称。
    """
    ...
