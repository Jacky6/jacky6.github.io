    02 Session Memory — 跨会话持久化记忆¶

    官方文档：https://docs.langchain.com/oss/python/langchain/short-term-memory

    本章补充 01-short-term-memory.md 未覆盖的跨会话持久化场景。

    📚 本章目标¶

    学完本章后，你将掌握：

    • ✅ 理解 Short-term Memory vs Session Memory 的区别
    • ✅ 使用 checkpointer 实现跨线程/会话的持久化记忆
    • ✅ SQLite、PostgreSQL 等不同后端的配置
    • ✅ 消息修剪、摘要、TTL 管理
    • ✅ 多用户会话隔离

    02.1 为什么需要 Session Memory¶

    01-short-term-memory.md 覆盖了 单线程内 的消息持久化。但实际应用中：

    场景 Short-term (单线程) Session (跨线程)
    用户刷新页面 ❌ 丢失 ✅ 保留
    多设备切换 ❌ 丢失 ✅ 保留
    长期对话历史 ❌ 上下文爆炸 ✅ 可摘要/修剪
    多用户隔离 ⚠️ 需要手动管理 ✅ 按 user_id 隔离

    02.2 Checkpointer 基础¶

    from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver

# 内存 Checkpointer（重启丢失）
checkpointer = InMemorySaver()

agent = create_agent(
    "openai:gpt-5.5",
    tools=[search],
    checkpointer=checkpointer,
)

# 使用 thread_id 关联同一用户的不同会话
config = {"configurable": {"thread_id": "user-123"}}

# 第一次对话
agent.invoke(
    {"messages": [{"role": "user", "content": "我喜欢吃川菜"}]},
    config,
)

# 第二次对话（刷新页面后，用同一 thread_id）
result = agent.invoke(
    {"messages": [{"role": "user", "content": "我上次说了我喜欢吃什么？"}]},
    config,
)
# ✅ Agent 能记住 "川菜"

    02.3 SQLite 持久化¶

    from langgraph.checkpoint.sqlite import SqliteSaver
import sqlite3

# 持久化到 SQLite 文件
conn = sqlite3.connect("agent_memory.db", check_same_thread=False)
checkpointer = SqliteSaver(conn)

agent = create_agent(
    "openai:gpt-5.5",
    tools=[search],
    checkpointer=checkpointer,
)

config = {"configurable": {"thread_id": "user-123"}}

# 重启后仍能读取历史
result = agent.invoke(
    {"messages": [{"role": "user", "content": "我还记得上次聊了什么吗？"}]},
    config,
)

    多用户隔离¶

    # 用户 A
config_a = {"configurable": {"thread_id": "user-A"}}
agent.invoke({"messages": [{"role": "user", "content": "我是 Alice"}]}, config_a)

# 用户 B（不同 thread_id，隔离）
config_b = {"configurable": {"thread_id": "user-B"}}
agent.invoke({"messages": [{"role": "user", "content": "我是 Bob"}]}, config_b)

# 用户 A 不会看到用户 B 的记忆
result = agent.invoke(
    {"messages": [{"role": "user", "content": "我是谁？"}]},
    config_a,
)
# → "你是 Alice"

    02.5 消息修剪与摘要¶

    消息摘要¶

    from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver

checkpointer = InMemorySaver()

agent = create_agent(
    "openai:gpt-5.5",
    tools=[search],
    checkpointer=checkpointer,
    # 自动摘要旧消息
    summarize=True,
    summary_threshold_tokens=2000,  # 超过 2000 token 时触发摘要
)

    手动管理历史¶

    from langgraph.graph import StateGraph

# 手动获取历史
config = {"configurable": {"thread_id": "user-123"}}
history = checkpointer.get(config)

if history and len(history["messages"]) > 100:
    # 保留最近 20 条 + 摘要
    recent = history["messages"][-20:]
    summary = summarize_messages(history["messages"][:-20])

    # 更新状态
    checkpointer.put(
        config,
        {"messages": [summary] + recent},
    )

    02.6 TTL 与自动清理¶

    import time
from langgraph.checkpoint.memory import InMemorySaver

class TTLCheckpointer(InMemorySaver):
    """带 TTL 的 Checkpointer，自动清理过期会话"""

    def __init__(self, ttl_seconds: int = 86400):
        super().__init__()
        self.ttl = ttl_seconds
        self._last_access = {}

    def get(self, config):
        thread_id = config["configurable"]["thread_id"]
        now = time.time()

        # 检查 TTL
        if thread_id in self._last_access:
            if now - self._last_access[thread_id] > self.ttl:
                self.clear(thread_id)  # 过期清理
                return None

        self._last_access[thread_id] = now
        return super().get(config)

    def clear(self, thread_id: str):
        """手动清理指定线程的记忆"""
        if thread_id in self._last_access:
            del self._last_access[thread_id]
        # 清理内部状态


checkpointer = TTLCheckpointer(ttl_seconds=3600)  # 1 小时 TTL

config = {"configurable": {"thread_id": "user-123"}}
agent = create_agent(
    "openai:gpt-5.5",
    tools=[],
    checkpointer=checkpointer,
)

    02.7 Web 应用集成¶

    FastAPI + Session Cookie¶

    from fastapi import FastAPI, Request, Response
import uuid

app = FastAPI()

# 每个用户一个 Checkpointer（生产环境用共享实例 + thread_id 隔离）
checkpointer = SqliteSaver(sqlite3.connect("memory.db", check_same_thread=False))

agent = create_agent(
    "openai:gpt-5.5",
    tools=[search],
    checkpointer=checkpointer,
)


@app.post("/chat")
async def chat(request: Request, response: Response):
    # 从 Cookie 获取或创建 session_id
    session_id = request.cookies.get("session_id")
    if not session_id:
        session_id = str(uuid.uuid4())
        response.set_cookie("session_id", session_id, max_age=86400 * 30)  # 30 天

    config = {"configurable": {"thread_id": session_id}}

    body = await request.json()
    result = agent.invoke(
        {"messages": [{"role": "user", "content": body["message"]}]},
        config,
    )

    return {"reply": result["messages"][-1].content}

    02.8 Checkpointer 对比¶

    后端 持久化 适用场景 配置复杂度
    InMemorySaver ❌ 重启丢失 开发/测试 零
    SqliteSaver ✅ SQLite 文件 小型应用/本地 低
    PostgresSaver ✅ PostgreSQL 生产环境 中
    MongoDBSaver ✅ MongoDB 已有 MongoDB 的项目 中
    自定义 ✅ 任意后端 特殊需求 高

    02.9 最佳实践¶

    Do ✅¶

    做法 说明
    生产环境用 PostgreSQL SQLite 并发性能有限
    按 user_id 隔离 thread_id 避免用户数据泄露
    设置消息上限或摘要 防止上下文爆炸
    定期清理过期会话 节省存储空间

    Don't ❌¶

    做法 问题
    InMemorySaver 用于生产 重启后数据丢失
    所有用户共享 thread_id 用户看到彼此的对话
    无限制增长历史消息 Token 费用爆炸
    在 Checkpointer 中存敏感数据 应使用加密或 Store

    📝 本章小结¶

    1. Session Memory = Short-term Memory + 跨线程持久化
    2. Checkpointer 是实现 Session Memory 的核心组件
    3. SQLite/PostgreSQL 用于持久化存储
    4. thread_id 实现多用户隔离
    5. 消息修剪/摘要 管理上下文窗口
    6. TTL 清理 自动管理过期数据
