    第 20 章：上下文工程 - Context Engineering¶

    本章内容：上下文工程概念、Model Context、Tool Context、Life-cycle Context、三大数据源（State/Store/Runtime Context）

    官方文档：https://docs.langchain.com/oss/python/langchain/context-engineering/

    📚 本章目标¶

    学完本章后，你将掌握：

    • ✅ 理解上下文工程为什么是 AI 工程师的首要工作
    • ✅ 掌握 Agent 失败的两大原因：模型能力 vs 上下文不当
    • ✅ Model Context：动态 System Prompt、消息注入、工具选择、模型切换
    • ✅ Tool Context：State/Store/Runtime Context 读写、Command 更新状态
    • ✅ Life-cycle Context：中间件串联、生命周期钩子
    • ✅ 三大数据源：State（短期记忆）、Store（长期记忆）、Runtime Context（静态配置）
    • ✅ Transient vs Persistent 上下文更新

    20.1 上下文工程概述¶

    20.1.1 为什么 Agent 会失败？¶

    Agent 失败通常不是因为模型不够强，而是因为传给了 LLM 错误的上下文。

    LLM 失败的两大原因： 1. 底层模型能力不足 → 换更强的模型 2. 传给 LLM 的"正确上下文"缺失 → 这才是最常见原因！

    上下文工程的核心：在正确的时机，以正确的格式，提供正确的信息和工具。 这是 AI 工程师的首要工作。

    20.1.2 Agent 循环¶

    ┌──────────────────────┐
│   用户请求 / 消息     │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│  1. 模型调用           │ ← Model Context 控制
│  (Model Call)         │
└──────────┬───────────┘
           ▼
    返回响应 or 工具调用?
           │
    ┌──────┴──────┐
    │ 响应         │ 工具调用
    │ (结束)       │    │
    │              ▼    │
    │  ┌─────────────────┐
    │  │ 2. 工具执行      │ ← Tool Context 控制
    │  │ (Tool Execute)  │
    │  └────────┬────────┘
    │           ▼
    │    工具结果
    │           │
    └───────────┘
           │
           ▼
    循环直到 LLM 结束

    20.1.3 你可以控制的三个层面¶

    上下文类型 你控制什么 瞬态还是持久？
    Model Context 模型调用中输入什么（指令、历史、工具、输出格式） Transient（瞬态）
    Tool Context 工具能读写什么（State/Store/Runtime Context） Persistent（持久）
    Life-cycle Context 模型和工具调用之间发生什么（摘要、防护、日志等） Persistent（持久）

    瞬态上下文：模型单次调用时看到的内容。修改不会保存到 State。 持久上下文：保存到 State 中，跨轮次保留。

    20.1.4 三大数据源¶

    数据源 也叫 范围 示例
    Runtime Context 静态配置 会话级 用户 ID、API Key、数据库连接、权限、环境设置
    State 短期记忆 会话级 当前消息、上传的文件、认证状态、工具结果
    Store 长期记忆 跨会话 用户偏好、提取的洞察、记忆、历史数据

    20.1.5 实现机制：Middleware¶

    上下文工程的底层实现机制是 Middleware（中间件）。 中间件让你挂钩到 Agent 生命周期的每一步，从而： - 更新上下文 - 跳转到生命周期的不同步骤

    20.2 Model Context¶

    控制每次模型调用输入的内容——指令、可用工具、使用哪个模型、输出格式。

    20.2.1 动态 System Prompt¶

    根据不同数据源动态调整系统提示：

    从 State 读取（基于对话长度调整）： 

    from langchain.agents import create_agent
from langchain.agents.middleware import dynamic_prompt, ModelRequest

@dynamic_prompt
def state_aware_prompt(request: ModelRequest) -> str:
    message_count = len(request.messages)

    base = "你是一个有用的助手。"

    if message_count > 10:
        base += "\n这是一段很长的对话——请格外简洁。"

    return base

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[...],
    middleware=[state_aware_prompt],
)

    从 Store 读取（基于用户偏好）：

    20.2.2 消息注入¶

    从 State 注入文件上下文： 

    from langchain.agents.middleware import wrap_model_call, ModelRequest, ModelResponse
from typing import Callable

@wrap_model_call
def inject_file_context(
    request: ModelRequest,
    handler: Callable[[ModelRequest], ModelResponse]
) -> ModelResponse:
    """注入用户上传文件的上下文"""
    uploaded_files = request.state.get("uploaded_files", [])

    if uploaded_files:
        file_descriptions = []
        for f in uploaded_files:
            file_descriptions.append(
                f"- {f['name']} ({f['type']}): {f['summary']}"
            )

        file_context = f"""当前对话中你可访问的文件：
{chr(10).join(file_descriptions)}

回答问题时请引用这些文件。"""

        messages = [
            *request.messages,
            {"role": "user", "content": file_context},
        ]
        request = request.override(messages=messages)

    return handler(request)

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[...],
    middleware=[inject_file_context],
)

    从 Store 注入写作风格： 

    @wrap_model_call
def inject_writing_style(
    request: ModelRequest,
    handler: Callable[[ModelRequest], ModelResponse]
) -> ModelResponse:
    """注入用户的写作风格"""
    user_id = request.runtime.context.user_id
    store = request.runtime.store
    writing_style = store.get(("writing_style",), user_id)

    if writing_style:
        style = writing_style.value
        style_context = f"""你的写作风格：
- 语气：{style.get('tone', 'professional')}
- 常用问候语："{style.get('greeting', 'Hi')}"
- 常用结束语："{style.get('sign_off', 'Best')}"
"""
        messages = [
            *request.messages,
            {"role": "user", "content": style_context},
        ]
        request = request.override(messages=messages)

    return handler(request)

    注意：wrap_model_call 做瞬态更新（不影响 State 中保存的内容）。 做持久更新需要返回 ExtendedModelResponse + Command，或使用生命周期钩子。

    20.2.3 动态工具选择¶

    不是所有工具在任何时候都合适。太多工具会让模型困惑，太少会限制能力。

    基于 State 的工具筛选： 

    from langchain.agents.middleware import wrap_model_call, ModelRequest, ModelResponse
from typing import Callable

@wrap_model_call
def state_based_tools(
    request: ModelRequest,
    handler: Callable[[ModelRequest], ModelResponse]
) -> ModelResponse:
    """基于认证状态筛选工具"""
    state = request.state
    is_authenticated = state.get("authenticated", False)

    if not is_authenticated:
        # 未认证：只提供公开工具
        tools = [t for t in request.tools if t.name.startswith("public_")]
        request = request.override(tools=tools)

    return handler(request)

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[public_search, private_search, admin_panel],
    middleware=[state_based_tools],
)

    20.2.4 动态模型切换¶

    根据任务复杂度自动选择模型：

    @wrap_model_call
def dynamic_model_selection(
    request: ModelRequest,
    handler: Callable[[ModelRequest], ModelResponse]
) -> ModelResponse:
    """简单问题用轻量模型，复杂任务用强模型"""
    messages = request.messages
    last_user = next(
        (m for m in reversed(messages) if m["role"] == "user"), None
    )

    if last_user and len(last_user["content"]) < 50:
        # 短查询 → 轻量模型
        request = request.override(model="openai:gpt-5.4-mini")
    else:
        # 复杂任务 → 强力模型
        request = request.override(model="openai:gpt-5.5")

    return handler(request)

    20.3 Tool Context¶

    控制工具能访问和产生的内容——读写 State、Store、Runtime Context。

    20.3.1 从 State 读取¶

    工具可以读取 State 中的短期记忆：

    from langchain.tools import ToolRuntime
from langchain.tools import tool

@tool
def get_order_details(
    order_id: str,
    runtime: ToolRuntime = None,
) -> str:
    """获取订单详情"""
    # 从 State 读取当前对话信息
    state_messages = runtime.state.get("messages", [])

    # 检查是否已认证
    authenticated = runtime.state.get("authenticated", False)
    if not authenticated:
        return "请先完成认证才能查看订单详情。"

    # 实际查询逻辑
    return f"订单 {order_id}：已发货，预计明天到达。"

    20.3.2 更新 State（通过 Command）¶

    工具执行后可以更新状态：

    from langchain.tools import ToolRuntime
from langgraph.types import Command
from langchain.tools import tool

@tool
def mark_authenticated(runtime: ToolRuntime = None) -> str:
    """标记用户已认证"""
    return Command(
        update={"authenticated": True}
    )

@tool
def upload_file(
    filename: str,
    filetype: str,
    summary: str,
    runtime: ToolRuntime = None,
) -> Command:
    """上传文件到当前会话"""
    current_files = runtime.state.get("uploaded_files", [])
    new_file = {
        "name": filename,
        "type": filetype,
        "summary": summary,
    }

    return Command(
        update={
            "uploaded_files": [*current_files, new_file]
        }
    )

    20.3.3 从 Store 读取¶

    工具可以跨会话访问长期记忆：

    from dataclasses import dataclass
from langchain.tools import ToolRuntime
from langchain.tools import tool
from langgraph.store.memory import InMemoryStore

@dataclass
class UserContext:
    user_id: str

@tool
def get_personalized_greeting(runtime: ToolRuntime = None) -> str:
    """获取个性化问候"""
    user_id = runtime.context.user_id
    store = runtime.store

    # 读取用户偏好
    prefs = store.get(("preferences",), user_id)

    if prefs:
        name = prefs.value.get("name", "用户")
        preferred_tone = prefs.value.get("tone", "formal")

        if preferred_tone == "casual":
            return f"嘿 {name}！有什么可以帮你的？"
        else:
            return f"您好，{name}。请问有什么可以为您服务？"

    return "您好！有什么可以帮您的？"

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_personalized_greeting],
    context_schema=UserContext,
    store=InMemoryStore(),
)

    20.3.4 写入 Store¶

    工具可以保存洞察到长期记忆：

    @tool
def save_user_preference(
    preference_key: str,
    preference_value: str,
    runtime: ToolRuntime = None,
) -> str:
    """保存用户偏好"""
    user_id = runtime.context.user_id
    store = runtime.store

    # 写入 Store
    store.put(("preferences",), user_id, {
        preference_key: preference_value
    })

    return f"已保存偏好：{preference_key} = {preference_value}"

    20.4.4 自定义生命周期钩子¶

    from langchain.agents.middleware import (
    before_model, after_model, wrap_tool_call,
    ModelRequest, ModelResponse, ToolRequest, ToolResponse,
)
from typing import Callable

@before_model
def log_before_call(request: ModelRequest) -> ModelRequest:
    """模型调用前记录日志"""
    print(f"[LOG] 即将调用模型，消息数：{len(request.messages)}")
    return request

@after_model
def log_after_call(request: ModelRequest, response: ModelResponse) -> ModelResponse:
    """模型调用后记录日志"""
    print(f"[LOG] 模型调用完成，内容长度：{len(str(response.content))}")
    return response

@wrap_tool_call
def retry_on_failure(
    request: ToolRequest,
    handler: Callable[[ToolRequest], ToolResponse]
) -> ToolResponse:
    """工具失败自动重试"""
    try:
        return handler(request)
    except Exception as e:
        print(f"[WARN] 工具 {request.tool_name} 失败：{e}，重试中...")
        return handler(request)

    20.5 实战：智能客服 Agent¶

    from dataclasses import dataclass
from langchain.agents import create_agent
from langchain.agents.middleware import (
    dynamic_prompt, wrap_model_call, ModelRequest, ModelResponse,
    SummarizationMiddleware, TodoListMiddleware,
    ModelCallLimitMiddleware, HumanInTheLoopMiddleware,
)
from langchain.tools import ToolRuntime, tool
from langgraph.store.memory import InMemoryStore
from langgraph.types import Command
from langgraph.checkpoint.memory import InMemorySaver
from langchain_core.utils.uuid import uuid7
from typing import Callable

# === Context Schema ===
@dataclass
class UserContext:
    user_id: str
    user_tier: str  # "free", "premium", "enterprise"

# === Dynamic Prompt ===
@dynamic_prompt
def tier_aware_prompt(request: ModelRequest) -> str:
    tier = request.runtime.context.user_tier

    base = "你是一个专业的客服助手。"

    if tier == "enterprise":
        base += "\n该用户是企业客户，提供优先服务，可以访问所有功能。"
    elif tier == "premium":
        base += "\n该用户是高级会员，可以提供扩展功能。"
    else:
        base += "\n该用户是免费用户，仅提供基础功能。引导升级到会员。"

    return base

# === Tools ===
@tool
def check_order_status(order_id: str, runtime: ToolRuntime = None) -> str:
    """查询订单状态"""
    user_id = runtime.context.user_id

    # 从 Store 读取用户历史
    store = runtime.store
    user_orders = store.get(("orders",), user_id)

    if not user_orders or order_id not in user_orders.value:
        return f"未找到订单 {order_id}。"

    return f"订单 {order_id}：运输中，预计 2 天内到达。"

@tool
def process_refund(
    order_id: str,
    reason: str,
    runtime: ToolRuntime = None,
) -> Command:
    """处理退款（需要审批）"""
    return Command(
        update={"pending_refund": {"order_id": order_id, "reason": reason}},
        goto="__end__",  # 暂停等待 HITL 审批
    )

@tool
def save_interaction(
    topic: str,
    sentiment: str,
    runtime: ToolRuntime = None,
) -> str:
    """保存本次交互到长期记忆"""
    user_id = runtime.context.user_id
    store = runtime.store

    interactions = store.get(("interactions",), user_id)
    history = interactions.value if interactions else []
    history.append({
        "topic": topic,
        "sentiment": sentiment,
        "timestamp": "2026-06-04",
    })
    store.put(("interactions",), user_id, history)
    return "已保存交互记录。"

# === Create Agent ===
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[check_order_status, process_refund, save_interaction],
    checkpointer=InMemorySaver(),
    store=InMemoryStore(),
    context_schema=UserContext,
    middleware=[
        # 上下文工程
        tier_aware_prompt,
        # 生命周期管理
        SummarizationMiddleware(
            model="openai:gpt-5.4-mini",
            trigger=("tokens", 4000),
            keep=("messages", 20),
        ),
        TodoListMiddleware(),
        ModelCallLimitMiddleware(thread_limit=15, run_limit=5),
        # 安全
        HumanInTheLoopMiddleware(interrupt_on={"process_refund": True}),
    ],
)

# === Use ===
config = {
    "configurable": {"thread_id": str(uuid7())},
    "context": UserContext(
        user_id="user-123",
        user_tier="premium",
    ),
}

result = agent.invoke(
    {"messages": [{"role": "user", "content": "帮我查一下订单 ORD-2024-001 的状态"}]},
    config=config,
)

    20.6 Transient vs Persistent 更新¶

    方式 何时使用 影响
    dynamic_prompt 动态系统提示 Transient（不改变 State）
    wrap_model_call + request.override() 注入消息/工具/模型 Transient（不改变 State）
    wrap_model_call + ExtendedModelResponse(Command) 从模型调用层更新 State Persistent（改变 State）
    工具返回 Command(update={...}) 工具执行后更新 State Persistent（改变 State）
    before_model / after_model 生命周期钩子更新 State Persistent（改变 State）

    经验法则：如果只是临时调整（如注入上下文），用 Transient； 如果需要永久记录（如保存用户偏好、认证状态），用 Persistent。

    20.7 最佳实践¶

    20.7.1 上下文工程清单¶

    1. System Prompt：动态化，基于 State/Store/Runtime Context
    2. Messages：注入相关上下文（文件、用户偏好、合规规则）
    3. Tools：动态筛选，基于权限和对话阶段
    4. Model：按任务复杂度切换
    5. Response Format：用 Pydantic schema 约束输出

    20.7.2 数据源选择指南¶

    场景 数据源 示例
    用户身份/API Key Runtime Context context_schema=UserContext
    当前对话状态 State runtime.state.get("messages")
    用户偏好 Store store.get(("preferences",), user_id)
    跨会话记忆 Store store.put(("memories",), user_id, data)

    20.7.3 常见陷阱¶

    • ❌ 把所有工具都传给模型 → 用动态工具选择
    • ❌ 传太多历史消息 → 用 SummarizationMiddleware
    • ❌ 静态 System Prompt → 用 @dynamic_prompt
    • ❌ 不区分 Transient/Persistent → 根据场景选择
