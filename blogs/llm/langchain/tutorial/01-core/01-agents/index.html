    5.2 ReAct 模式详解¶

    什么是 ReAct？¶

    ReAct = Reasoning + Acting

    模型交替进行推理和行动，直到任务完成。

    完整执行流程¶

    示例任务："帮我查北京天气并推荐活动"

Step 1: Reasoning（推理）
═══════════════════════════
模型思考：
"用户想知道北京天气并获取活动推荐。
我需要：
1. 先查询北京天气
2. 根据天气推荐合适的活动"

决策：调用 get_weather("北京")


Step 2: Acting（行动）
═══════════════════════════
执行工具调用：
get_weather(location="北京")

工具返回：
"北京：晴，25°C，湿度 40%，微风"


Step 3: Observation（观察）
═══════════════════════════════
模型接收工具结果：
"好的，北京天气晴朗，25 度，很适合户外活动。
现在我需要推荐合适的活动。"

决策：调用 recommend_activities(weather="sunny", location="北京")


Step 4: Acting（行动）
═══════════════════════════
执行工具调用：
recommend_activities(weather="sunny", location="北京")

工具返回：
"推荐活动：
1. 爬香山 - 天气好，视野佳
2. 颐和园散步 - 温度适宜
3. 奥林匹克公园骑行 - 微风舒适"


Step 5: Final Answer（最终答案）
══════════════════════════════════
模型生成完整回答：

"北京今天天气很好！晴朗，25°C，湿度 40%，有微风。

推荐以下活动：
1. 🏔️ 爬香山 - 天气晴朗，视野会很好
2. 🚶 颐和园散步 - 温度适宜，适合漫步
3. 🚴 奥林匹克公园骑行 - 微风舒适，骑行正好

记得带水和防晒哦！"

    5.3 创建 Agent¶

    最小 Agent¶

    from langchain.agents import create_agent

# 1. 定义工具
def get_weather(city: str) -> str:
    """获取天气"""
    return f"{city}: 晴朗"

# 2. 创建 Agent — 使用 provider:model-id 格式
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    system_prompt="你是 helpful assistant"
)

# 3. 运行
response = agent.invoke({
    "messages": [{"role": "user", "content": "北京天气如何？"}]
})

print(response)

    完整示例¶

    from langchain.agents import create_agent
from langchain.tools import tool

# ========== 1. 定义工具 ==========

@tool
def get_weather(location: str) -> str:
    """获取指定城市的天气信息"""
    # 实际应用中调用天气 API
    weather_data = {
        "北京": "晴，25°C，湿度 40%",
        "上海": "多云，22°C，湿度 60%",
        "广州": "小雨，28°C，湿度 80%",
    }
    return weather_data.get(location, f"{location}: 数据暂缺")

@tool
def search_attractions(location: str) -> str:
    """搜索旅游景点"""
    attractions = {
        "北京": "故宫、长城、颐和园、天坛",
        "上海": "外滩、东方明珠、豫园、迪士尼",
        "广州": "广州塔、长隆、白云山、陈家祠",
    }
    return attractions.get(location, "景点数据暂缺")

@tool
def get_user_location(user_id: str) -> str:
    """获取用户当前位置"""
    locations = {"user1": "北京", "user2": "上海"}
    return locations.get(user_id, "未知位置")

# ========== 2. 定义系统提示 ==========

SYSTEM_PROMPT = """你是专业旅游助手，帮助用户规划旅行。

可用工具：
- get_weather: 获取指定城市天气
- search_attractions: 搜索城市景点
- get_user_location: 获取用户当前位置

行为准则：
1. 如果用户问天气但没说地点，先获取用户位置
2. 推荐景点时考虑天气因素
3. 回答要友好、实用
4. 如果数据暂缺，诚实告知用户

回答格式：
- 使用清晰的段落结构
- 重要信息用粗体标注
- 提供实用建议
"""

# ========== 3. 创建 Agent ==========

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather, search_attractions, get_user_location],
    system_prompt=SYSTEM_PROMPT,
    name="travel_assistant"  # 名称用于子图嵌入和追踪
)

# ========== 4. 运行测试 ==========

if __name__ == "__main__":
    # 测试 1: 指定城市
    print("=" * 60)
    print("测试 1: 查询北京天气")
    print("=" * 60)
    response = agent.invoke({
        "messages": [{"role": "user", "content": "北京天气如何？"}]
    })
    print(response.get("messages", [])[-1].content)

    # 测试 2: 当前位置
    print("\n" + "=" * 60)
    print("测试 2: 查询当前位置天气")
    print("=" * 60)
    response = agent.invoke({
        "messages": [{"role": "user", "content": "我这里天气怎么样？"}],
    }, context={"user_id": "user1"})
    print(response.get("messages", [])[-1].content)

    # 测试 3: 完整规划
    print("\n" + "=" * 60)
    print("测试 3: 旅行规划")
    print("=" * 60)
    response = agent.invoke({
        "messages": [{"role": "user", "content": "我想去北京玩，有什么建议？"}]
    })
    print(response.get("messages", [])[-1].content)

    5.4 create_agent 参数详解¶

    必需参数¶

    from langchain.agents import create_agent

agent = create_agent(
    # 1. model - 模型（必需）
    #    推荐格式：provider:model-id
    model="openai:gpt-5.5",  # 或 ChatModel 实例

    # 2. tools - 工具列表（可选，默认空列表）
    tools=[tool1, tool2],

    # 3. system_prompt - 系统提示（可选，但推荐）
    system_prompt="你是 helpful assistant"
)

    可选参数¶

    from langgraph.checkpoint.memory import InMemorySaver

agent = create_agent(
    model=model,
    tools=tools,

    # name - Agent 名称（子图嵌入时的节点名）
    name="my_assistant",

    # response_format - 结构化输出格式（Pydantic BaseModel）
    response_format=MyOutputSchema,

    # state_schema - 自定义状态 schema（TypedDict 扩展）
    state_schema=CustomState,

    # context_schema - per-run 运行时上下文（dataclass）
    context_schema=MyContext,

    # middleware - 中间件列表
    middleware=[middleware1, middleware2],

    # checkpointer - 对话持久化（推荐 InMemorySaver）
    checkpointer=InMemorySaver(),

    # store - 长期记忆存储
    store=store,

    # prompt - 自定义提示模板
    prompt=custom_prompt_template,

    # before_model - 模型调用前钩子
    before_model=before_hook,

    # after_model - 模型调用后钩子
    after_model=after_hook,
)

    参数类型详解¶

    model 参数¶

    from langchain.chat_models import init_chat_model
from langchain.agents import create_agent

# 方式 1: 字符串（推荐）— 使用 provider:model-id 格式
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[]
)

# 方式 2: ChatModel 实例
model = init_chat_model("openai:gpt-5.5", temperature=0.7)
agent = create_agent(
    model=model,
    tools=[]
)

# 方式 3: 动态模型（根据条件切换）
from langchain.agents import DynamicModel

def model_router(state):
    if "复杂" in state.get("user_input", ""):
        return init_chat_model("openai:o3")  # 最强推理
    else:
        return init_chat_model("openai:gpt-5.4-mini")  # 快速便宜

agent = create_agent(
    model=DynamicModel(model_router),
    tools=[]
)

    tools 参数¶

    from langchain.tools import tool
from langchain.agents import create_agent

# 方式 1: 函数列表
@tool
def tool1(): pass

@tool
def tool2(): pass

agent = create_agent(
    model=model,
    tools=[tool1, tool2]
)

# 方式 2: 空工具（纯聊天）
agent = create_agent(
    model=model,
    tools=[]  # 或省略
)

# 方式 3: 动态工具
def get_tools(state):
    if state.get("user_role") == "admin":
        return [admin_tool1, admin_tool2]
    else:
        return [basic_tool1, basic_tool2]

agent = create_agent(
    model=model,
    tools=get_tools  # 动态返回工具列表
)

    5.5 系统提示最佳实践¶

    好的系统提示结构¶

    角色定义 + 可用工具 + 行为准则 + 输出格式 + 限制条件

    完整示例¶

    SYSTEM_PROMPT = """
【角色定义】
你是专业客服助手，帮助用户解决问题。

【可用工具】
- search_knowledge_base: 搜索知识库获取信息
- create_ticket: 创建工单跟踪问题
- check_order_status: 查询订单状态
- process_refund: 处理退款

【行为准则】
1. 先尝试用知识库回答用户问题
2. 无法解决时，主动提出创建工单
3. 涉及订单问题时，先查询订单状态
4. 保持礼貌和专业，即使用户情绪激动
5. 不要承诺无法实现的事情

【输出格式】
- 使用清晰的段落结构
- 重要信息用**粗体**标注
- 步骤说明用编号列表
- 提供具体的后续行动建议

【限制条件】
- 只能使用提供的工具
- 不要访问外部网站
- 不要处理敏感信息（密码、信用卡等）
- 如果不确定，明确告知用户
- 退款金额超过 1000 元需要主管审批

【示例对话】
用户：我的订单还没到
助手：我来帮您查询订单状态。请问订单号是多少？
用户：12345
助手：[调用 check_order_status]
助手：您的订单正在配送中，预计明天到达。
"""

    5.6 Agent 调用方式¶

    Invoke（同步调用）¶

    # 基础调用
response = agent.invoke({
    "messages": [{"role": "user", "content": "你好"}]
})

# 带上下文
response = agent.invoke({
    "messages": [{"role": "user", "content": "查询天气"}],
}, context={"user_id": "user1", "location": "北京"})

# 带配置
response = agent.invoke(
    {"messages": [...]},
    config={
        "timeout": 60,  # 60 秒超时
        "max_iterations": 10,  # 最多 10 次工具调用
        "recursion_limit": 50  # 递归深度限制
    }
)

    Stream（流式输出）¶

    # 流式输出
for chunk in agent.stream({
    "messages": [{"role": "user", "content": "写一首长诗"}]
}):
    if "messages" in chunk:
        latest = chunk["messages"][-1]
        print(latest.content, end="", flush=True)

# 带事件类型
for event in agent.stream({
    "messages": [{"role": "user", "content": "北京天气"}]
}, stream_mode="updates"):
    print(f"事件：{event}")

    异步调用¶

    # 异步 invoke
response = await agent.ainvoke({
    "messages": [{"role": "user", "content": "你好"}]
})

# 异步 stream
async for chunk in agent.astream({
    "messages": [{"role": "user", "content": "写诗"}]
}):
    print(chunk)

    5.7 多工具协调¶

    顺序调用¶

    from langchain.agents import create_agent
from langchain.tools import tool

@tool
def get_weather(location: str) -> str:
    """获取天气"""
    return f"{location}: 晴朗"

@tool
def recommend_clothes(weather: str) -> str:
    """根据天气推荐服装"""
    if "晴" in weather:
        return "建议穿 T 恤、短裤"
    else:
        return "建议带伞、穿外套"

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather, recommend_clothes],
    system_prompt="""你是穿搭助手。
    1. 先查询天气
    2. 根据天气推荐服装
    3. 给出完整建议"""
)

response = agent.invoke({
    "messages": [{"role": "user", "content": "北京穿什么？"}]
})
# Agent 会自动：查天气 → 推荐服装 → 输出建议

    5.7b 对话持久化（Memory）¶

    默认情况下，Agent 不记得之前的对话。使用 checkpointer 可以让 Agent 记住对话历史：

    from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver
from langchain_core.utils.uuid import uuid7

# 创建带持久化的 Agent
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[],
    system_prompt="你是 helpful assistant",
    checkpointer=InMemorySaver(),
)

# 每个对话使用唯一 thread_id
thread_id = str(uuid7())
config = {"configurable": {"thread_id": thread_id}}

# 第一轮对话
result = agent.invoke(
    {"messages": [{"role": "user", "content": "我叫小智"}]},
    config=config,
)

# 第二轮对话 — Agent 记住了之前的内容
result = agent.invoke(
    {"messages": [{"role": "user", "content": "我叫什么名字？"}]},
    config=config,  # 同一个 thread_id
)
# → 你叫小智！

from langgraph.checkpoint.sqlite.aio import AsyncSqliteSaver

async with AsyncSqliteSaver.from_conn_string("checkpoints.db") as saver:
    agent = create_agent(model, tools, checkpointer=saver)
    result = await agent.ainvoke({...}, config={"configurable": {"thread_id": tid}})

# LangGraph Store（适合分布式）

# 或使用 LangGraph 提供的其他后端

    5.7c 运行时上下文（Context）¶

    context_schema 让你在每次 Agent 运行时传递自定义配置：

    from dataclasses import dataclass
from langchain.agents import create_agent
from langchain.agents import AgentRuntime
from langchain_core.utils.uuid import uuid7

@dataclass
class Context:
    user_id: str
    language: str = "zh"

# 创建 Agent 时指定 context_schema
agent = create_agent(
    model="openai:gpt-5.5",
    tools=[],
    system_prompt="你是 helpful assistant",
    context_schema=Context,
)

# 在中间件/工具中访问上下文
@tool
def get_user_preferences(runtime: AgentRuntime) -> str:
    user_id = runtime.context.user_id
    return f"用户 {user_id} 的偏好"

# 调用时传递 context
result = agent.invoke(
    {"messages": [{"role": "user", "content": "你好"}]},
    config={"configurable": {"thread_id": str(uuid7())}},
    context=Context(user_id="user-123"),
)

    context vs config：

    • config：配置基础设施（thread_id、checkpointer、超时等）
    • context：业务数据（用户 ID、租户信息、权限等）

    5.10 常见问题¶

    Q1: Agent 不调用工具怎么办？¶

    可能原因：

    1. 工具描述不清晰
    2. 系统提示没强调使用工具
    3. 模型不够强大

    解决方案：

    # 1. 改进工具描述
@tool
def get_weather(city: str) -> str:
    """
    获取指定城市的当前天气。
    当用户询问天气时必须使用此工具。
    不要编造天气数据。
    """
    ...

# 2. 在系统提示中强调
SYSTEM_PROMPT = """...
你必须使用可用工具来获取信息。
不要编造数据，总是先调用工具。
如果工具返回错误，告知用户并重试。
..."""

# 3. 使用更强的模型
agent = create_agent(
    model="openai:gpt-5.5",  # 或 "anthropic:claude-sonnet-4-6"
    tools=[...],
    system_prompt="..."
)

    Q2: 如何限制工具调用次数？¶

    # 方式 1: 在调用时设置
response = agent.invoke(
    {...},
    config={"max_iterations": 5}  # 最多 5 次工具调用
)

# 方式 2: 在系统提示中说明
SYSTEM_PROMPT = """...
限制：
- 最多调用 3 次工具
- 如果 3 次后仍无法解决，告知用户
..."""

    Q3: 如何处理长时间运行的任务？¶

    # 增加超时和迭代限制
response = agent.invoke(
    {...},
    config={
        "timeout": 300,  # 5 分钟超时
        "max_iterations": 50,  # 最多 50 次工具调用
        "recursion_limit": 100  # 递归深度 100
    }
)

# 使用持久化 — InMemorySaver（内存）
from langgraph.checkpoint.memory import InMemorySaver

checkpointer = InMemorySaver()
agent = create_agent(
    model=model,
    tools=tools,
    checkpointer=checkpointer  # 启用持久化
)

# 即使进程重启，对话也能继续
config = {"configurable": {"thread_id": "conversation-123"}}
response = agent.invoke({...}, config=config)

    5.11 本章小结¶

    关键要点¶

    1. Agent 架构 - LLM + Tools + ReAct 循环
    2. 创建方式 - create_agent(model, tools, system_prompt)
    3. ReAct 模式 - 推理 → 行动 → 观察 → 循环

    5. 调用方式 - invoke、stream、async
