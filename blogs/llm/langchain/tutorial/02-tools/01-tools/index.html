    第 04 章：工具详解¶

    完整工具创建与使用指南 | 从基础到高级

    本章目标¶

    学完本章后，你将能够：

    • ✅ 使用多种方式定义工具（函数、装饰器、类）
    • ✅ 实现异步工具和动态工具注册
    • ✅ 配置工具元数据（名称、描述、参数、snake_case 规范）
    • ✅ 使用 ToolRuntime 访问 State / Context / Store
    • ✅ 使用 Command 从工具内更新 Agent 状态
    • ✅ 处理工具错误、超时和重试
    • ✅ 实现工具缓存和限流
    • ✅ 服务端工具（Server-side tool use）
    • ✅ 使用 LangChain 内置工具库

    4.1 什么是工具？¶

    工具 = Schema + Function

    • Schema：工具的名称、描述、参数定义
    • Function：实际执行的代码

    工具扩展 Agent 的能力——让 Agent 获取实时数据、执行代码、查询外部数据库，并在现实世界中采取行动。

    底层上，工具是带有明确输入输出的可调用函数，它们被传递给 聊天模型。模型根据对话上下文决定何时调用工具以及提供什么输入参数。

    Agent 工作流：
用户问题 → 模型思考 → 决定调用工具 → 执行函数 → 返回结果 → 最终回答

    提示：模型如何处理工具调用，详见 Tool Calling。使用 LangSmith 追踪工具调用和调试错误。 推荐同时配置 LangSmith Engine，自动检测 trace 中的问题并提议修复。

    4.2 定义工具的 5 种方式¶

    方式 1：简单函数（最常用）¶

    from langchain.tools import tool

@tool
def get_weather(location: str) -> str:
    """获取指定城市的天气信息"""
    # 实际应用中调用天气 API
    return f"{location}: 晴朗，25°C"

# 使用
from langchain.agents import create_agent

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    system_prompt="你是 helpful assistant",
)

    要求： - ✅ 必须有类型注解（location: str） - ✅ 必须有文档字符串（"""..."""） - ✅ 返回值会被转换为字符串

    ⚠️ 命名规范：工具名优先使用 snake_case（如 web_search 而非 Web Search）。 部分模型 Provider 对包含空格或特殊字符的工具名处理不佳甚至报错。 仅使用字母、数字、下划线和连字符可提高跨 Provider 兼容性。

    方式 2：自定义名称和描述¶

    from langchain.tools import tool

@tool("weather_api")  # 自定义工具名
def get_weather(city: str) -> str:
    """
    获取指定城市的当前天气状况。

    参数:
        city: 城市名称，如"北京"、"上海"

    返回:
        天气描述字符串，包含温度、湿度、天气状况
    """
    return f"{city}: 晴朗"

    方式 3：异步工具¶

    from langchain.tools import tool
import aiohttp

@tool
async def fetch_stock_price(symbol: str) -> str:
    """获取股票实时价格"""
    async with aiohttp.ClientSession() as session:
        async with session.get(
            f"https://api.example.com/stock/{symbol}"
        ) as resp:
            data = await resp.json()
            return f"{symbol}: ${data['price']}"

# 异步调用
result = await fetch_stock_price.ainvoke("AAPL")

    方式 4：带 ToolRuntime 的工具（官方推荐）¶

    工具最强大的特性是可以访问运行时信息——对话历史、用户数据、持久化记忆等。

    通过 ToolRuntime 参数，工具可以访问以下运行时组件：

    组件 说明 用途
    State 短期记忆 — 当前对话的可变数据（消息、计数器、自定义字段） 访问对话历史、追踪工具调用次数
    Context 不可变配置 — 调用时传入（user ID、会话信息） 根据用户身份个性化响应
    Store 长期记忆 — 跨对话持久化数据 保存用户偏好、维护知识库
    Stream Writer 工具执行期间发送实时更新 长时间操作显示进度
    Execution Info 当前执行的标识信息（thread ID、run ID、重试次数） 访问 thread/run ID、根据重试状态调整行为
    Config RunnableConfig 访问 callbacks、tags、metadata
    Tool Call ID 当前工具调用的唯一标识 关联日志和模型调用 
    from langchain.tools import tool, ToolRuntime

@tool
def get_last_user_message(runtime: ToolRuntime) -> str:
    """获取用户最近一条消息"""
    from langchain.messages import HumanMessage
    messages = runtime.state["messages"]
    for msg in reversed(messages):
        if isinstance(msg, HumanMessage):
            return msg.content
    return "没有找到用户消息"

    注意：runtime 参数对模型隐藏。上面的例子中，模型只看到 get_last_user_message() 无参数。

    使用 Command 更新状态¶

    from langchain.agents import AgentState
from langchain.messages import ToolMessage
from langchain.tools import ToolRuntime, tool
from langgraph.types import Command

class CustomState(AgentState):
    user_name: str

@tool
def set_user_name(new_name: str, runtime: ToolRuntime[None, CustomState]) -> Command:
    """设置用户名"""
    return Command(
        update={
            "user_name": new_name,
            "messages": [
                ToolMessage(
                    content=f"用户名已设置为 {new_name}。",
                    tool_call_id=runtime.tool_call_id,
                )
            ],
        }
    )

    提示：当工具更新状态变量时，考虑为这些字段定义 reducer。因为 LLM 可能并行调用多个工具，reducer 决定了同一个状态字段被并发更新时的冲突解决策略。

    访问 Context（用户身份）¶

    from dataclasses import dataclass
from langchain.agents import create_agent
from langchain.tools import tool, ToolRuntime
from langchain_core.utils.uuid import uuid7

@dataclass
class UserContext:
    user_id: str

USER_DATABASE = {
    "user123": {"name": "Alice", "balance": 5000},
    "user456": {"name": "Bob", "balance": 1200},
}

@tool
def get_account_info(runtime: ToolRuntime[UserContext]) -> str:
    """获取当前用户账户信息"""
    user_id = runtime.context.user_id
    user = USER_DATABASE.get(user_id)
    if user:
        return f"用户: {user['name']}, 余额: ${user['balance']}"
    return "未找到用户"

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_account_info],
    context_schema=UserContext,
    system_prompt="你是财务助手",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "我的余额是多少？"}]},
    config={"configurable": {"thread_id": str(uuid7())}},
    context=UserContext(user_id="user123"),
)

    方式 5：使用 Tool 类¶

    from langchain.tools import BaseTool
from typing import Type
from pydantic import BaseModel, Field

class WeatherInput(BaseModel):
    """工具输入 schema"""
    location: str = Field(description="城市名称")

class WeatherTool(BaseTool):
    name = "get_weather"
    description = "获取指定城市的天气信息"
    args_schema: Type[BaseModel] = WeatherInput

    def _run(self, location: str) -> str:
        """同步执行"""
        return f"{location}: 晴朗"

    async def _arun(self, location: str) -> str:
        """异步执行"""
        return f"{location}: 晴朗"

# 使用
weather_tool = WeatherTool()
result = weather_tool.invoke({"location": "北京"})

    ⚠️ 保留参数名¶

    以下参数名是保留的，不能作为工具的参数使用。使用这些名称会导致运行时错误。

    参数名 用途
    config 保留用于传递 RunnableConfig
    runtime 保留用于 ToolRuntime 参数（访问 state、context、store）

    迁移提示：如果之前使用了 InjectedState、InjectedStore、get_runtime() 或 InjectedToolCallId， 请迁移到新的 runtime: ToolRuntime 参数模式。

    服务端工具（Server-side tool use）¶

    部分聊天模型内置了服务端工具（如网页搜索、代码解释器），这些工具由模型服务端执行：

    from langchain.chat_models import init_chat_model

# OpenAI 内置工具
model = init_chat_model("openai:gpt-5.5")
model_with_web_search = model.bind_tools([{
    "type": "web_search_preview",  # OpenAI 内置网页搜索
}])

# Anthropic 内置工具
model_anthropic = init_chat_model("anthropic:claude-sonnet-4-6")
model_with_code = model_anthropic.bind_tools([{
    "type": "code_interpreter_20250514",  # Anthropic 内置代码解释器
}])

    内置工具 vs 自定义工具：

    维度 内置工具 自定义工具
    执行位置 模型服务端 你的代码
    可控性 低 完全可控
    适用场景 通用搜索、代码运行 业务逻辑、私有 API
    配置方式 字典声明 @tool 装饰器

def get_weather(location: str, unit: str = "celsius") -> str:

    手动覆盖¶

    from langchain.tools import tool

@tool
def gw(location: str) -> str:
    """简短描述"""
    pass

# 覆盖元数据
gw.name = "get_weather_detailed"
gw.description = """
获取指定城市的详细天气信息，包括：
- 当前温度

    4.5 错误处理¶

    基础错误处理¶

    from langchain.tools import tool

@tool
def safe_divide(a: float, b: float) -> str:
    """安全除法"""
    try:
        result = a / b
        return f"结果：{result}"
    except ZeroDivisionError:
        return "错误：除数不能为零"
    except Exception as e:
        return f"错误：{str(e)}"

    超时处理¶

    from langchain.tools import tool
import time

@tool
def slow_operation(data: str) -> str:
    """可能很慢的操作"""
    time.sleep(10)
    return "完成"

# 设置超时
from langchain.tools import StructuredTool

timeout_tool = StructuredTool.from_function(
    func=slow_operation,
    handle_tool_error=True,
    # 超时配置在调用时设置
)

# 带超时的调用
try:
    result = timeout_tool.invoke(
        {"data": "test"},
        config={"timeout": 5}  # 5 秒超时
    )
except Exception as e:
    print(f"超时：{e}")

    重试机制¶

    from langchain.tools import tool
from tenacity import retry, stop_after_attempt, wait_exponential

@tool
@retry(
    stop=stop_after_attempt(3),  # 最多重试 3 次
    wait=wait_exponential(multiplier=1, min=1, max=10)  # 指数退避
)
def unstable_api(query: str) -> str:
    """不稳定的 API 调用"""
    import random
    if random.random() < 0.7:
        raise ConnectionError("网络错误")
    return "成功"

# 自动重试
result = unstable_api.invoke({"query": "test"})

    4.6 工具缓存¶

    内存缓存¶

    from langchain.tools import tool
from functools import lru_cache

@tool
@lru_cache(maxsize=100)
def get_exchange_rate(currency: str) -> str:
    """获取汇率（缓存结果）"""
    # 实际调用 API
    rates = {"USD": 7.2, "EUR": 7.8, "JPY": 0.05}
    return f"1 {currency} = {rates.get(currency, '未知')} CNY"

# 第一次调用 - 实际执行
result1 = get_exchange_rate.invoke({"currency": "USD"})

# 第二次调用 - 使用缓存
result2 = get_exchange_rate.invoke({"currency": "USD"})  # 秒返回

    TTL 缓存¶

    from langchain.tools import tool
from cachetools import TTLCache, cached

# 5 分钟过期缓存
cache = TTLCache(maxsize=100, ttl=300)  # 5 分钟

@tool
@cached(cache)
def get_stock_price(symbol: str) -> str:
    """获取股票价格（5 分钟缓存）"""
    # 调用 API
    return f"{symbol}: $150.00"

    自定义缓存后端¶

    from langchain.tools import tool
import redis

# Redis 缓存
redis_client = redis.Redis(host='localhost', port=6379)

def cached_tool_call(key: str, func, *args, **kwargs):
    """自定义缓存逻辑"""
    cached = redis_client.get(key)
    if cached:
        return cached.decode()

    result = func(*args, **kwargs)
    redis_client.setex(key, 300, result)  # 5 分钟过期
    return result

@tool
def get_weather_cached(location: str) -> str:
    """带 Redis 缓存的天气查询"""
    def fetch_weather(loc):
        # 实际 API 调用
        return f"{loc}: 晴朗"

    return cached_tool_call(
        f"weather:{location}",
        fetch_weather,
        location
    )

    条件工具¶

    from langchain.tools import tool

def get_tools_for_user(user_role: str):
    """根据用户角色返回可用工具"""
    base_tools = [search]

        @tool
        def delete_user(user_id: str) -> str:

    return base_tools

# 使用
admin_tools = get_tools_for_user("admin")
model_with_tools = model.bind_tools(admin_tools)

    工具路由¶

    from langchain.tools import tool

@tool
def calculator(expression: str) -> str:
    """计算器"""
    return str(eval(expression))

@tool
def unit_converter(value: float, from_unit: str, to_unit: str) -> str:
    """单位转换器"""
    conversions = {
        ("km", "mile"): 0.621371,
        ("kg", "lb"): 2.20462,
    }
    rate = conversions.get((from_unit, to_unit), 1)
    return f"{value * rate} {to_unit}"

# 创建工具路由器
class ToolRouter:
    def __init__(self):
        self.tools = {
            "calculator": calculator,
            "unit_converter": unit_converter
        }

    def route(self, query: str):
        # 简单路由逻辑
        if any(op in query for op in ["+", "-", "*", "/"]):
            return [calculator]
        elif "转换" in query or "convert" in query:
            return [unit_converter]
        else:
            return [calculator, unit_converter]

router = ToolRouter()
tools = router.route("计算 1+1")
model_with_tools = model.bind_tools(tools)

    context = runtime.context    # 新增：访问 context_schema 数据
    return "OK"

    5. 限流和配额¶

    from datetime import datetime, timedelta
from collections import defaultdict

class RateLimiter:
    def __init__(self, calls_per_minute: int = 60):
        self.calls_per_minute = calls_per_minute
        self.call_times = defaultdict(list)

    def check_limit(self, tool_name: str) -> bool:
        now = datetime.now()
        minute_ago = now - timedelta(minutes=1)

        # 清理旧记录
        self.call_times[tool_name] = [
            t for t in self.call_times[tool_name]
            if t > minute_ago
        ]

        # 检查是否超限
        if len(self.call_times[tool_name]) >= self.calls_per_minute:
            return False

        # 记录调用
        self.call_times[tool_name].append(now)
        return True

limiter = RateLimiter(calls_per_minute=10)

@tool
def rate_limited_tool(query: str) -> str:
    """带限流的工具"""
    if not limiter.check_limit("rate_limited_tool"):
        return "错误：调用频率超限，请稍后再试"

    # 正常逻辑
    return f"结果：{query}"

    4.11 本章小结¶

    关键要点¶

    1. 定义方式 - 函数、装饰器、类、异步
    2. 命名规范 - snake_case，避免空格和特殊字符

    4. ToolRuntime - 工具内访问 State / Context / Store
    5. Command - 从工具内更新 Agent 状态
    6. 执行 - 同步、异步、批量
    7. 错误处理 - 超时、重试、降级
    8. 缓存 - 内存、TTL、Redis
    9. 服务端工具 - 内置 web_search、code_interpreter
    10. 动态注册 - 运行时添加、条件工具
    11. 旧模式迁移 - InjectedState/Store → ToolRuntime
    12. 最佳实践 - 清晰描述、合理参数、限流
