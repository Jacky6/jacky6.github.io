    第 09 章：中间件 - Middleware¶

    本章内容：内置中间件、自定义中间件、Agent 循环钩子

    官方文档：https://docs.langchain.com/oss/python/langchain/middleware/

    📚 本章目标¶

    学完本章后，你将掌握：

    • ✅ 理解 Middleware 在 LangChain Agent 中的作用
    • ✅ 使用内置中间件（Summarization、HITL、Model Fallback 等）
    • ✅ 理解 Agent 循环的 4 个钩子（before_model / after_model / before_tool / after_tool）
    • ✅ 创建自定义中间件
    • ✅ 将 Agent 作为子图嵌入 LangGraph 工作流
    • ✅ 配置限流、重试、PII 检测等生产级能力

    9.1 中间件概述¶

    9.1.1 什么是中间件¶

    中间件提供了一种更精细控制 Agent 内部行为的方式。在 LangChain 中，中间件不是独立的运行时——钩子在 create_agent 返回的已编译 LangGraph 内部执行。

    Agent 循环：
调用模型 → 模型选择工具 → 执行工具 → 循环直到不调用工具

    中间件在每个步骤前后暴露钩子：

    钩子 触发时机 用途
    before_model 模型调用前 修改消息、工具选择、添加上下文
    after_model 模型响应后 检查输出、提前终止
    before_tool 工具执行前 人类审批、限流、权限检查
    after_tool 工具执行后 转换结果、日志记录

    9.1.2 使用中间件¶

    from langchain.agents import create_agent
from langchain.agents.middleware import (
    SummarizationMiddleware,
    HumanInTheLoopMiddleware,
)

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[...],
    middleware=[
        SummarizationMiddleware(
            model="openai:gpt-5.4-mini",
            trigger=("tokens", 4000),
            keep=("messages", 20),
        ),
        HumanInTheLoopMiddleware(interrupt_on={"send_email": True}),
    ],
)

    9.1.3 与 LangGraph 集成¶

    中间件在编译后的 LangGraph 中运行。你可以将完整的 Agent（含中间件）作为节点嵌入更大的 StateGraph：

    from langchain.agents import AgentState, create_agent
from langchain.agents.middleware import HumanInTheLoopMiddleware
from langgraph.graph import START, StateGraph

email_agent = create_agent(
    model="anthropic:claude-sonnet-4-6",
    tools=[read_email, send_email],
    middleware=[HumanInTheLoopMiddleware(interrupt_on={"send_email": True})],
)

graph = (
    StateGraph(AgentState)
    .add_node("classify", classify_node)
    .add_node("email_agent", email_agent)
    .add_edge(START, "classify")
    .add_conditional_edges("classify", route)
    .compile()
)

    提示：HITL 中断、摘要、PII 脱敏、重试和所有自定义钩子都会随 Agent 节点一起迁移。

    9.2 内置中间件¶

    LangChain 提供了丰富的生产级内置中间件：

    9.2.1 Summarization — 自动摘要¶

    当对话接近上下文窗口限制时，自动压缩旧消息：

    from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[weather_tool, calculator_tool],
    middleware=[
        SummarizationMiddleware(
            model="openai:gpt-5.4-mini",
            trigger=("tokens", 4000),   # 触发条件
            keep=("messages", 20),      # 保留最近 20 条消息
        ),
    ],
)

    触发条件（OR 逻辑）： - ("fraction", 0.8) — 占用模型上下文 80% - ("tokens", 3000) — 绝对 token 数 - ("messages", 6) — 消息数量

    保留条件（指定一个）： - ("fraction", 0.3) — 保留上下文 30% - ("tokens", 2000) — 保留绝对 token 数 - ("messages", 20) — 保留最近 N 条消息

    注意：摘要是文本导向的上下文压缩。它不会压缩图片/音频/视频 payload。 图片密集的应用建议将媒体存储在文件系统或对象存储中，通过 URL 引用。

    9.2.2 Human-in-the-Loop — 人类审批¶

    在执行特定工具前暂停，等待人类批准：

    from langchain.agents import create_agent
from langchain.agents.middleware import HumanInTheLoopMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[read_email, send_email, delete_account],
    middleware=[
        HumanInTheLoopMiddleware(
            interrupt_on={
                "send_email": True,     # 发邮件需要审批
                "delete_account": True, # 删除账户需要审批
            }
        ),
    ],
)

    提示：工具名来自 @tool 装饰的函数名（snake_case）。TypeScript 中对应 name 参数。

    9.2.3 Model Fallback — 模型降级¶

    主模型失败时自动切换到备选模型：

    from langchain.agents import create_agent
from langchain.agents.middleware import ModelFallbackMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[],
    middleware=[
        ModelFallbackMiddleware(
            "openai:gpt-5.4-mini",              # 第一备选
            "anthropic:claude-sonnet-4-6",       # 第二备选
        ),
    ],
)

    适用于： - 构建弹性 Agent 应对模型停机 - 成本优化（降级到便宜模型） - Provider 冗余

    9.2.4 Model Call Limit — 模型调用限流¶

    限制模型调用次数，防止成本失控：

    from langchain.agents import create_agent
from langchain.agents.middleware import ModelCallLimitMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[search_tool],
    middleware=[
        ModelCallLimitMiddleware(
            thread_limit=5,     # 整个会话最多 5 次
            run_limit=3,        # 单次调用最多 3 次
            exit_behavior="continue",  # 超限后继续（发错误消息给模型）
        ),
    ],
)

    exit_behavior 选项： | 值 | 行为 | |----|------| | "continue" | 阻止超限调用，发错误消息给模型，模型自行决定结束 | | "error" | 立即抛出异常 | | "end" | 发送 ToolMessage 后停止 |

    9.2.5 Tool Call Limit — 工具调用限流¶

    限制工具调用次数：

    from langchain.agents import create_agent
from langchain.agents.middleware import ToolCallLimitMiddleware

global_limiter = ToolCallLimitMiddleware(thread_limit=20, run_limit=10)
search_limiter = ToolCallLimitMiddleware(tool_name="search", thread_limit=5, run_limit=3)
strict_limiter = ToolCallLimitMiddleware(
    tool_name="scrape_webpage",
    run_limit=2,
    exit_behavior="error",
)

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[search_tool, scraper_tool],
    middleware=[global_limiter, search_limiter, strict_limiter],
)

    9.2.6 Tool Retry — 工具自动重试¶

    from langchain.agents import create_agent
from langchain.agents.middleware import ToolRetryMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[flaky_api_tool],
    middleware=[
        ToolRetryMiddleware(
            tool_name="flaky_api_tool",
            max_retries=3,
            backoff_factor=2,  # 指数退避：2s, 4s, 8s
        ),
    ],
)

    9.2.7 Model Retry — 模型自动重试¶

    from langchain.agents import create_agent
from langchain.agents.middleware import ModelRetryMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[],
    middleware=[
        ModelRetryMiddleware(
            max_retries=3,
            backoff_factor=2,
        ),
    ],
)

    9.2.8 PII Detection — 个人信息检测¶

    检测和处理 PII（个人可识别信息）：

    from langchain.agents import create_agent
from langchain.agents.middleware import PIIDetectionMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[],
    middleware=[
        PIIDetectionMiddleware(
            strategy="redact",  # redact | warn | block
        ),
    ],
)

    9.2.9 To-do List — 任务规划¶

    让 Agent 具备任务规划和追踪能力：

    from langchain.agents import create_agent
from langchain.agents.middleware import TodoListMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[search, write_file, run_tests],
    middleware=[TodoListMiddleware()],
)

    9.2.10 LLM Tool Selector — LLM 工具选择器¶

    在调用主模型之前，用 LLM 预筛选相关工具：

    from langchain.agents import create_agent
from langchain.agents.middleware import LLMToolSelectorMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[tool_a, tool_b, tool_c, tool_d, tool_e],
    middleware=[
        LLMToolSelectorMiddleware(
            model="openai:gpt-5.4-mini",
        ),
    ],
)

    9.2.11 其他内置中间件¶

    中间件 用途
    LLMToolEmulatorMiddleware 用 LLM 模拟工具执行（测试用）
    ContextEditingMiddleware 管理对话上下文（裁剪/清除工具使用）
    ShellToolMiddleware 暴露持久 Shell 会话给 Agent
    FileSearchMiddleware 提供 Glob/Grep 文件系统搜索工具
    FilesystemMiddleware 为 Agent 提供文件系统存储上下文和长期记忆
    SubagentMiddleware 支持 Agent 生成子 Agent

    9.3 自定义中间件¶

    9.3.1 中间件基类¶

    from langchain.agents.middleware import BaseMiddleware
from langchain.agents.middleware.types import (
    MiddlewareModelRequest,
    MiddlewareModelResponse,
    MiddlewareToolRequest,
    MiddlewareToolResponse,
)
from typing import Any

class LoggingMiddleware(BaseMiddleware):
    """记录所有 Agent 行为的中间件"""

    def before_model(self, request: MiddlewareModelRequest) -> MiddlewareModelRequest:
        print(f"[before_model] 工具数: {len(request.tools)}")
        return request

    def after_model(
        self, request: MiddlewareModelRequest, response: MiddlewareModelResponse
    ) -> MiddlewareModelResponse:
        ai_msg = response.message
        print(f"[after_model] 文本: {ai_msg.text}")
        if ai_msg.tool_calls:
            print(f"[after_model] 工具调用: {[tc['name'] for tc in ai_msg.tool_calls]}")
        return response

    def before_tool(
        self, request: MiddlewareToolRequest
    ) -> dict[str, Any] | None:
        print(f"[before_tool] 调用 {request.tool_call['name']}")
        return None  # None = 继续执行工具

    def after_tool(
        self,
        request: MiddlewareToolRequest,
        response: MiddlewareToolResponse,
    ) -> MiddlewareToolResponse:
        print(f"[after_tool] {request.tool_call['name']} → {response.tool_result}")
        return response

    9.3.2 修改消息¶

    class AddTimestampMiddleware(BaseMiddleware):
    """在每条用户消息中添加时间戳"""

    def before_model(self, request: MiddlewareModelRequest) -> MiddlewareModelRequest:
        from datetime import datetime
        from langchain.messages import HumanMessage

        messages = list(request.messages)
        for i, msg in enumerate(messages):
            if isinstance(msg, HumanMessage):
                messages[i] = HumanMessage(
                    content=f"[{datetime.now().isoformat()}] {msg.content}"
                )

        return MiddlewareModelRequest(
            messages=messages,
            tools=request.tools,
            model=request.model,
            config=request.config,
        )

    9.3.3 提前终止¶

    from langchain.types import StopMiddleware

class SafetyMiddleware(BaseMiddleware):
    """检测到不安全内容时提前终止"""

    def after_model(
        self, request: MiddlewareModelRequest, response: MiddlewareModelResponse
    ) -> MiddlewareModelResponse:
        if "危险操作" in response.message.text:
            raise StopMiddleware(
                final_message="操作被安全中间件阻止。"
            )
        return response

    9.3.4 转换工具结果¶

    class FormatToolResultMiddleware(BaseMiddleware):
    """格式化工具返回结果"""

    def after_tool(
        self,
        request: MiddlewareToolRequest,
        response: MiddlewareToolResponse,
    ) -> MiddlewareToolResponse:
        original = response.tool_result
        formatted = f"[{request.tool_call['name']} 结果]\n{original}"

        return MiddlewareToolResponse(
            tool_result=formatted,
        )

    9.5 中间件组合¶

    from langchain.agents import create_agent
from langchain.agents.middleware import (
    SummarizationMiddleware,
    ModelFallbackMiddleware,
    ToolCallLimitMiddleware,
    HumanInTheLoopMiddleware,
)

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[search, email, db_write],
    middleware=[
        # 上下文管理
        SummarizationMiddleware(
            model="openai:gpt-5.4-mini",
            trigger=("tokens", 4000),
            keep=("messages", 20),
        ),
        # 模型弹性
        ModelFallbackMiddleware(
            "openai:gpt-5.4-mini",
            "anthropic:claude-sonnet-4-6",
        ),
        # 工具限流
        ToolCallLimitMiddleware(tool_name="db_write", run_limit=5),
        # 人类审批
        HumanInTheLoopMiddleware(interrupt_on={"db_write": True}),
        # 自定义
        LoggingMiddleware(),
    ],
)

    9.6 最佳实践¶

    9.6.1 中间件排序¶

    中间件按列表顺序执行。建议排序： 1. 限流/安全 → 最先执行（快速拒绝） 2. HITL → 在工具执行前拦截 3. 摘要 → 模型调用前裁剪上下文 4. Fallback → 模型失败时兜底 5. 自定义 → 特定业务逻辑

    9.6.2 性能¶

    • 摘要中间件使用更便宜的模型（如 gpt-5.4-mini）
    • 工具选择器可减少不必要的工具传递
    • 限流中间件几乎零开销

    9.6.3 调试¶

    • 使用 LangSmith 追踪每次中间件触发
    • 自定义中间件中打印日志
    • exit_behavior="error" 快速定位问题
