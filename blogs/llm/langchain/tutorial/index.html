    LangChain 核心教程¶

    基于官方文档 https://docs.langchain.com/oss/python/langchain/overview 最后更新：2026-08-07 对齐版本：v1.3+（官方最新 langchain v1.3.0） 章节总数：30 章（9 大模块）

    📚 模块化结构¶

    本教程按 Agent 架构 分模块组织，每个模块是一个独立文件夹。

    tutorial/
├── 00-get-started/         ← 入门（3 章）
├── 01-core/                ← 核心组件（5 章，含 Retrieval/RAG）
├── 02-tools/               ← 工具系统（3 章，含 MCP + Skills）
├── 03-memory/              ← 记忆系统（3 章，含长期记忆）
├── 04-streaming/           ← 流式输出（2 章，含 v3 Event Streaming）
├── 05-middleware/          ← 中间件（2 章，含内置中间件目录）
├── 06-context/             ← 上下文（2 章）
├── 07-advanced/            ← 高级特性（6 章，含多代理/HITL/Guardrails/测试）
├── 08-examples/            ← 实战案例（4 章）
├── README.md
└── PROGRESS.md

    📖 与其他教程的关系¶

    教程 路径 说明
    LangChain OSS ./ 本教程 — 高度可定制的 Agent 框架
    Deep Agents ../deep-agents/ "batteries-included" Agent harness，内置文件系统/子 Agent/记忆/技能（v0.7）
    LangGraph ../langgraph/ 底层编排运行时，结合确定性和 Agent 工作流（v1.0）

    选择指南： - 需要开箱即用的能力 → Deep Agents - 需要高度定制化的 Agent → LangChain (本教程) - 需要结合确定性 + Agent 工作流 → LangGraph

    三组件定位的完整分析见 上层 README。
