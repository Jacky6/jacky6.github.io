    🚀 快速开始¶

    安装 LangChain¶

    # 基础安装
pip install langchain

# 安装特定提供商的集成
pip install langchain-anthropic  # Anthropic
pip install langchain-openai     # OpenAI
pip install langchain-google-genai  # Google

# 一键安装所有
pip install "langchain[all]"

    10 行代码创建 Agent¶

    from langchain.agents import create_agent

def get_weather(city: str) -> str:
    """Get weather for a given city."""
    return f"It's always sunny in {city}!"

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=[get_weather],
    system_prompt="You are a helpful assistant",
)

# 运行 Agent
agent.invoke({"messages": [{"role": "user", "content": "what is the weather in sf"}]})

    🎯 LangChain 核心优势¶

    1. 标准化模型接口¶

    # 无缝切换不同提供商
from langchain_anthropic import ChatAnthropic
from langchain_openai import ChatOpenAI
from langchain_google_genai import ChatGoogleGenerativeAI

# 所有模型使用相同的接口
model = ChatAnthropic(model="claude-sonnet-4-6")
# model = ChatOpenAI(model="gpt-4o")  # 轻松切换
# model = ChatGoogleGenerativeAI(model="gemini-2.0")  # 或这个

response = model.invoke("Hello!")

    优势： - ✅ 避免厂商锁定 - ✅ 轻松测试不同模型 - ✅ 统一的响应格式

    2. 简单易用的 Agent¶

    # 10 行代码创建 Agent
from langchain.agents import create_agent

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=[tool1, tool2, tool3],
    system_prompt="You are a helpful assistant",
)

    特点： - ✅ 快速上手（<10 行代码） - ✅ 灵活定制 - ✅ 支持复杂的上下文工程

    3. 基于 LangGraph 构建¶

    LangChain Agents = LangGraph + 预构建架构

优势：
├── 持久化执行（Durable execution）
├── 流式输出（Streaming）
├── 人机交互（Human-in-the-loop）
├── 状态持久化（Persistence）
└── 无需了解 LangGraph 细节

    ✅ 推荐¶

    # 1. 使用环境变量管理 API 密钥
import os
os.environ["ANTHROPIC_API_KEY"] = os.getenv("ANTHROPIC_API_KEY")

# 2. 为工具编写清晰的文档字符串
def search_web(query: str) -> str:
    """Search the web for current information.

    Args:
        query: The search query string.

    Returns:
        Search results as a string.
    """

# 3. 启用 LangSmith 追踪进行调试
os.environ["LANGSMITH_TRACING"] = "true"

# 4. 使用类型注解
def calculate(expression: str) -> float:
    """Calculate a mathematical expression."""

    ❌ 避免¶

    # 1. 硬编码 API 密钥
os.environ["API_KEY"] = "sk-xxx"  # ❌

# 2. 工具函数缺少文档字符串
def tool(x):  # ❌ 没有文档和类型注解
    return x * 2

# 3. 忽略错误处理
def risky_operation():
    result = do_something()  # ❌ 没有 try-except
    return result

    🎯 适用场景¶

    适合使用 LangChain¶

    ✅ 快速构建 Agent - 原型开发 - 概念验证 - 内部工具

    ✅ 需要多模型支持 - 测试不同 LLM - 避免厂商锁定 - 成本优化

    ✅ 工具集成 - API 调用 - 数据库查询 - 文件操作

    考虑使用 Deep Agents¶

    ✅ 需要完整功能 - 对话压缩 - 虚拟文件系统 - 子 Agent 生成

    考虑使用 LangGraph¶

    ✅ 高度定制需求 - 复杂工作流 - 确定性 + Agent 混合 - 特殊状态管理
