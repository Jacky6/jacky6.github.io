    🚀 LangChain vs Deep Agents vs LangGraph¶

    ┌─────────────────────────────────────────────────────────────┐
│              LangChain 生态系统对比                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  LangChain (本教程)                                         │
│  ├── 定位：快速构建 Agent 和自主应用                        │
│  ├── 代码量：< 10 行代码启动                                 │
│  ├── 特点：预构建 Agent 架构，开箱即用                      │
│  └── 适用：快速原型、标准 Agent 需求                        │
│                                                             │
│  Deep Agents                                                │
│  ├── 定位："batteries-included" 完整框架                    │
│  ├── 特性：自动压缩、虚拟文件系统、子代理                   │
│  ├── 代码量：CLI 驱动，配置驱动                             │
│  └── 适用：复杂任务、长时间运行、深度思考                   │
│                                                             │
│  LangGraph                                                  │
│  ├── 定位：低级代理编排框架                                 │
│  ├── 特性：完全自定义、图结构、状态机                       │
│  ├── 代码量：需要手动构建图                                 │
│  └── 适用：高级需求、确定性和 Agent 工作流混合              │
│                                                             │
│  推荐选择：                                                 │
│  - 快速开始 → LangChain (本教程)                            │
│  - 复杂任务 → Deep Agents                                   │
│  - 高度定制 → LangGraph                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘

    🎯 核心概念速览¶

    什么是 Agent？¶

    Agent = LLM + Tools + 推理循环

    用户输入 → LLM 思考 → 决定使用工具 → 执行工具 → 观察结果
              ↑                                        ↓
              └────────── 循环直到完成 ←───────────────┘
                          ↓
                      输出最终答案

    ReAct 模式¶

    LangChain Agents 遵循 ReAct (Reasoning + Acting) 模式：

    步骤 1: Reasoning - "我需要搜索最新信息"
步骤 2: Acting - 调用 search 工具
步骤 3: Observation - 获取搜索结果
步骤 4: Reasoning - "现在我需要分析这些数据"
步骤 5: Acting - 调用 analyze 工具
...
步骤 N: Final Answer - 输出完整答案

    核心组件¶

    组件 作用 示例
    Model 推理引擎 ChatOpenAI, ChatAnthropic
    Tools 执行能力 搜索、计算、API 调用
    System Prompt 行为指导 "你是专业助手"
    Memory 对话历史 短期/长期记忆
    Middleware 扩展行为 日志、限流、验证

    🛠️ 环境准备¶

    系统要求¶

    • Python: 3.10+
    • 包管理器: pip 或 uv（推荐）

    安装选项¶

    选项 1：基础安装（仅 LangChain 核心）¶

    pip install -U langchain
# 或
uv add langchain

    选项 2：安装 Provider 集成¶

    # OpenAI
pip install -U langchain-openai

# Anthropic
pip install -U langchain-anthropic

# Google
pip install -U langchain-google-genai

# AWS Bedrock
pip install -U langchain-aws

# 多个 Provider
pip install -U "langchain[openai,anthropic]"

    选项 3：完整安装（所有 Provider）¶

    pip install -U "langchain[all]"

    配置 API Keys¶

    # 临时设置（当前终端会话）
export OPENAI_API_KEY="sk-..."
export ANTHROPIC_API_KEY="sk-ant-..."
export GOOGLE_API_KEY="..."

# 永久设置（添加到 shell 配置文件）
echo 'export OPENAI_API_KEY="sk-..."'" >> ~/.bashrc
source ~/.bashrc

# 或使用 .env 文件
cat > .env << EOF
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
EOF

    验证安装¶

    from langchain.chat_models import init_chat_model

# 测试模型初始化
model = init_chat_model("gpt-4o")
response = model.invoke("Hello")
print(response)

    重点掌握： - Model-Tools-Agent 关系 - ReAct 循环原理 - 消息状态管理 - 中间件扩展机制

第 3 周：实战（15-19 章）
