    第四章：工具与 MCP¶

    自定义工具 | 内置 harness 工具 | MCP 集成 | 多模态工具输出 依据官方文档 https://docs.langchain.com/oss/python/deepagents/tools 整理

    4.1 工具系统概览¶

    Deep Agent 的工具分两类：

    ┌──────────────────────────────────────────────────────┐
│                   Agent 的工具集                       │
├────────────────────────┬─────────────────────────────┤
│  你提供的 tools=        │  harness 内置工具            │
├────────────────────────┼─────────────────────────────┤
│  • 普通 Python 函数     │  • 文件工具：ls/read_file/   │
│  • @tool 装饰器         │    write_file/edit_file/    │
│  • 工具字典             │    delete/glob/grep         │
│  • MCP 服务器工具       │  • execute（仅沙箱后端）      │
│  • Provider 内置工具    │  • task（派生子代理）         │
│   （如各家 web search） │  • write_todos（opt-in）     │
└────────────────────────┴─────────────────────────────┘

    都通过 tools= 传入或自动装配：

    from deepagents import create_deep_agent

agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    tools=[search, fetch_url, run_query],
)

    4.2 自定义工具¶

    任何可调用对象都能当工具：普通函数、LangChain @tool 装饰的函数、工具字典。Deep Agents 从函数签名和 docstring 推断工具 schema，大多数情况不用手写 schema：

    import os
from typing import Literal

from tavily import TavilyClient
from deepagents import create_deep_agent

tavily_client = TavilyClient(api_key=os.environ["TAVILY_API_KEY"])


def internet_search(
    query: str,
    max_results: int = 5,
    topic: Literal["general", "news", "finance"] = "general",
    include_raw_content: bool = False,
):
    """Run a web search"""
    return tavily_client.search(
        query,
        max_results=max_results,
        include_raw_content=include_raw_content,
        topic=topic,
    )


agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    tools=[internet_search],
)

    写好工具的要点：

    • 类型标注要全：str、int、Literal[...]、默认值都会进 schema，模型靠它决定怎么传参
    • docstring 写清楚用途：这是模型看到的工具说明
    • 返回值会被塞进上下文：大结果考虑截断或落盘（见 4.6 多模态提示和第 9 章上下文工程）

    工具定义的完整细节（tool dict、StructuredTool、返回类型、错误处理）见 LangChain 的 Tools 文档。

    Provider 内置工具（服务端工具）¶

    Google/OpenAI/Anthropic 提供服务端内置工具（如 web search），直接传工具字典：

    internet_search = {"google_search": {}}                              # Google
internet_search = {"type": "web_search"}                             # OpenAI
internet_search = {"type": "web_search_20260209", "name": "web_search"}  # Anthropic

    4.3 内置 harness 工具全表¶

    每个 Deep Agent 自带一套工具：

    工具 说明 备注
    ls 列目录
    read_file 读文件（分页 + 多模态支持） 必须保留，见下
    write_file 新建或覆盖文件 v0.7 起覆盖不报错
    edit_file 精确字符串替换 支持全局替换
    delete 删除文件或递归删除目录 需 deepagents>=0.7
    glob glob 模式查找文件
    grep 搜索文件内容
    execute 执行 shell 命令 仅沙箱后端提供
    task 派生子代理处理委派任务 见第 10 章

    write_todos（任务规划）不在默认列表——v0.7 起需 opt-in TodoListMiddleware。

    裁剪文件工具¶

    只保留部分工具（allowlist，需 deepagents>=0.7）：传 FilesystemMiddleware 实例到 middleware=，没列出的文件工具从模型工具列表移除：

    from deepagents import create_deep_agent
from deepagents.middleware import FilesystemMiddleware

# Read-only agent: write_file, edit_file, delete, and execute are never shown
agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    middleware=[
        FilesystemMiddleware(backend=backend, tools=["read_file", "ls", "glob", "grep"]),
    ],
)

    注意：

    • read_file 必须在列表里，否则创建 Agent 时抛 ValueError
    • 后端不支持 execute/delete 时它们自动消失，与 allowlist 无关
    • 你在 tools= 里加的自定义工具不受 allowlist 影响
    • 这样替换默认 FilesystemMiddleware 后，主 Agent 和 general-purpose 子代理都继承限制；声明式子代理要在自己的 middleware 字段单独配

    完全隐藏文件工具：注册 harness profile 的 excluded_tools：

    from deepagents import HarnessProfile, register_harness_profile

register_harness_profile(
    "anthropic:claude-sonnet-4-6",
    HarnessProfile(
        excluded_tools=frozenset(
            {"ls", "read_file", "write_file", "edit_file", "delete", "glob", "grep"}
        ),
    ),
)

    ⚠️ 不要通过 excluded_middleware 移除 FilesystemMiddleware 本身——它是默认栈的必需脚手架，会被显式拒绝。移除 task 工具的方法见第 10 章。

    4.4 MCP 工具¶

    Deep Agents 完整支持 Model Context Protocol (MCP)：不写集成代码，直接把任意 MCP 服务器（数据库、API、文件系统、浏览器……）暴露的工具接进来。

    pip install langchain-mcp-adapters

    import asyncio
from langchain_mcp_adapters.client import MultiServerMCPClient
from deepagents import create_deep_agent


async def main():
    client = MultiServerMCPClient(
        {
            "my_server": {
                "transport": "http",
                "url": "http://localhost:8000/mcp",
            }
        }
    )
    tools = await client.get_tools()

    agent = create_deep_agent(
        model="anthropic:claude-sonnet-4-6",
        tools=tools,
    )

    result = await agent.ainvoke(
        {"messages": [{"role": "user", "content": "Use the MCP server to help me."}]},
        config={"configurable": {"thread_id": "1"}},
    )


asyncio.run(main())

    要点：

    • MultiServerMCPClient 可以同时连多个服务器，get_tools() 返回合并的工具列表
    • 支持的 transport：stdio、http、sse
    • stdio 服务器配置、OAuth 认证、工具过滤、有状态会话等细节见官方 MCP guide

    MCP vs 自定义工具怎么选¶

    场景 推荐
    有现成 MCP 服务器（GitHub、Playwright、数据库官方 server） MCP，零集成代码
    业务私有逻辑、需要精细控制 schema/错误处理 自定义函数
    需要跨框架复用同一套工具 MCP（标准协议）

    4.5 工具与子代理的关系¶

    内置 task 工具让主 Agent 把任务委派给子代理（第 10 章）。子代理有自己的工具集——给子代理更窄的工具面（比如研究员子代理只给搜索工具，不给文件写权限）是常见的隔离手段。

    4.6 多模态工具输出¶

    自定义工具可以返回纯文本，或标准 content block 列表（text/image/audio/video/file）——前提是所选模型支持多模态工具结果：

    from langchain.tools import tool


@tool
def capture_screenshot() -> list[dict]:
    """Capture a screenshot of the current page."""
    return [
        {"type": "text", "text": "Screenshot of the current page:"},
        {"type": "image", "url": "https://example.com/page.png"},
    ]

    返回值会转成 ToolMessage 供模型在下一轮读取。

    💡 最佳实践：工具产生图片或大型二进制数据时，把产物存到后端（backend），只返回简短文本描述 + 路径/URL。这让消息历史更小，也和上下文压缩机制配合得更好（详见第 6、9 章）。

    4.7 本章小结¶

    关键要点¶

    1. 工具来源四条路：普通函数 / @tool / 工具字典（含 Provider 服务端工具）/ MCP
    2. schema 自动推断：类型标注 + docstring 就是给模型看的说明书
    3. 内置工具 = 文件操作 × 7 + execute（沙箱）+ task（子代理）+ opt-in 的 write_todos
    4. 裁剪文件工具用 FilesystemMiddleware(tools=[...]) 或 harness profile excluded_tools，不要动 middleware 本身
    5. MCP 用 langchain-mcp-adapters 的 MultiServerMCPClient
    6. 大产物落盘、只回引用，配合上下文压缩
