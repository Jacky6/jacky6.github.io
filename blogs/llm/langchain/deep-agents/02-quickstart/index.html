    第二章：快速开始¶

    5 分钟上手 Deep Agents | 从零构建第一个研究 Agent 依据官方文档 https://docs.langchain.com/oss/python/deepagents/quickstart 整理

    2.1 环境准备¶

    前置条件¶

    • Python: 3.10 或更高版本
    • 一个模型 Provider 的 API key（Gemini / OpenAI / Anthropic / OpenRouter 等）
    • Deep Agents 要求模型支持 tool calling（工具调用）
    python --version   # 应输出 3.10+

    Step 1: 安装¶

    pip install deepagents

    或用 uv（推荐）：

    uv init
uv add deepagents
uv sync

    💡 Google、OpenAI、Anthropic 都提供内置的网络搜索工具，不需要额外安装包或 API key。如果用其他 Provider，或偏好 Tavily，再装 pip install tavily-python。

    Step 2: 配置 API key¶

    # 按你的 Provider 选一个
export GOOGLE_API_KEY="your-api-key"       # Google
export OPENAI_API_KEY="your-api-key"       # OpenAI
export ANTHROPIC_API_KEY="your-api-key"    # Anthropic
export OPENROUTER_API_KEY="your-api-key"   # OpenRouter（另需 TAVILY_API_KEY）

    💡 LangSmith Gateway：可以把主流 Provider 的调用统一路由到 LangSmith，支持自带 key 或用 Gateway Credits（无需各家 key）。

    2.2 Step 3: 创建搜索工具¶

    三种主流 Provider 有服务端内置搜索，直接传一个工具字典即可：

    from deepagents import create_deep_agent

# Google 内置搜索
internet_search = {"google_search": {}}

# OpenAI 内置搜索
internet_search = {"type": "web_search"}

# Anthropic 内置搜索
internet_search = {"type": "web_search_20260209", "name": "web_search"}

    任意 Provider 通用的 Tavily 方案（普通 Python 函数，Deep Agents 会从签名和 docstring 推断工具 schema）：

    import os
from typing import Literal

from tavily import TavilyClient
from deepagents import create_deep_agent

tavily_client = TavilyClient(api_key=os.environ["TAVILY_API_KEY"])


def internet_search(
    query: str,
    max_results: int = 5,
    topic: Literal["general", "news", "finance"] = "general",
    include_raw_content: bool = False,
):
    """Run a web search"""
    return tavily_client.search(
        query,
        max_results=max_results,
        include_raw_content=include_raw_content,
        topic=topic,
    )

    2.3 Step 4: 创建 Deep Agent¶

    把工具和模型传给 create_deep_agent。model 用 provider:model 格式字符串，或传入已初始化的模型实例：

    # System prompt to steer the agent to be an expert researcher
research_instructions = """You are an expert researcher. Your job is to conduct thorough research and then write a polished report.

You have access to an internet search tool as your primary means of gathering information.

## `internet_search`

Use this to run an internet search for a given query. You can specify the max number of results to return, the topic, and whether raw content should be included.
"""

agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",   # 或 openai:gpt-5.5 / google_genai:gemini-3.6-flash
    tools=[internet_search],
    system_prompt=research_instructions,
)

    模型字符串怎么取、怎么调参数 → 第三章；完整定制选项 → 第十二章。

    2.4 Step 5: （可选）接入 LangSmith 追踪¶

    LangSmith 让你可视化 Agent 的执行过程：工具调用、子代理委派、LLM 响应一目了然。注册后创建 API key：

    export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your-langsmith-api-key"

    调试长任务时强烈推荐——Deep Agent 一次运行可能有几十步，没有 trace 根本看不清发生了什么。

    2.5 Step 6: 运行¶

    result = agent.invoke(
    {"messages": [{"role": "user", "content": "What is langgraph?"}]}
)

# Print the agent's response
print(result["messages"][-1].content)

    幕后发生了什么？¶

    这个 Agent 会自动：

    1. 调研：调用 internet_search 工具收集信息
    2. 管理上下文：用文件系统工具（write_file、read_file）卸载大型搜索结果——不塞爆上下文窗口
    3. 派生子代理：需要时把复杂子任务委派给专用子代理
    4. 综合成报告：把发现整合成连贯的回复

    这就是 Deep Agents 与普通 chatbot 的区别：你没写任何流程控制，Agent 自己决定搜几次、存哪些笔记、要不要拆分任务。

    想要结构化任务规划（write_todos），opt-in 传入 TodoListMiddleware（v0.7 起默认关闭）：

    from deepagents import create_deep_agent
from langchain.agents.middleware import TodoListMiddleware

agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    middleware=[TodoListMiddleware()],
)

    2.6 流式输出¶

    Deep Agents 基于 LangGraph 内置流式支持，可以实时观察 Agent 执行：工具调用、工具结果、LLM 响应逐步输出。详见第 6 章（Streaming / Event streaming）。

    2.7 交互式体验：Deep Agents Code¶

    如果你想要的是在终端里直接对话使用 Deep Agents（类似 Claude Code 的体验），官方的答案是 Deep Agents Code (dcode)——基于 Deep Agents SDK 构建的开源编码代理：

    curl -LsSf https://langch.in/dcode | bash
dcode

    ⚠️ 早期版本的 deepagents CLI 已被 dcode 取代，官方文档不再收录旧 CLI。dcode 完整介绍 → 第 13 章。
