    Deep Agents 教程¶

    Deep Agents 是 LangChain 团队推出的开源 agent harness（代理运行框架），基于 LangChain 核心构建块 + LangGraph 运行时，内置文件系统、子代理、记忆、技能等能力，用于构建能完成复杂长任务的 Agent。

    依据官方文档整理：https://docs.langchain.com/oss/python/deepagents/overview 对齐版本：deepagents v0.7（2026-07-24）| 整理时间：2026-08

    章节¶

    按官方文档的四大能力组件组织：

    入门¶

    文件 内容
    01-overview.md 概述：agent harness 定位、四大能力组件、虚拟文件系统、v0.7 变更
    02-quickstart.md 快速开始：安装、配 key、构建第一个研究 Agent
    03-models.md 模型与 Provider：provider:model 格式、Provider profiles、运行时切换

    执行环境¶

    文件 内容
    04-tools.md 工具与 MCP：自定义工具、内置工具全表、MCP 集成
    05-backends.md 后端与沙箱：StateBackend → StoreBackend → 远程沙箱（含 CompositeBackend 恒等挂载实战案例）
    06-execution-advanced.md 权限、多模态、Interpreters (Beta)、流式与事件流
