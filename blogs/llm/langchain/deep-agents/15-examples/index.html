    第十五章：实战案例¶

    把前十四章的能力组合成完整 Agent | 全部基于 deepagents v0.7 API 更多官方示例：https://github.com/langchain-ai/deepagents/tree/main/examples

    15.1 深度研究 Agent¶

    场景：接收研究主题，搜索网络、管理中间笔记、委派子代理并行调研，最终产出结构化报告。

    用到的能力：工具（搜索）、文件系统（笔记）、子代理（并行调研）、任务规划（todos）、结构化输出。

    # research_agent.py
import os
from typing import Literal

from tavily import TavilyClient
from deepagents import create_deep_agent
from langchain.agents.middleware import TodoListMiddleware
from langgraph.checkpoint.memory import InMemorySaver

tavily_client = TavilyClient(api_key=os.environ["TAVILY_API_KEY"])


def internet_search(
    query: str,
    max_results: int = 5,
    topic: Literal["general", "news", "finance"] = "general",
):
    """Run a web search"""
    return tavily_client.search(query, max_results=max_results, topic=topic)


# Specialized subagent: only gets search tools, returns compact findings
research_subagent = {
    "name": "deep-researcher",
    "description": "Researches a single sub-question in depth. Use for parallel investigation of distinct aspects of a topic.",
    "system_prompt": (
        "You are a meticulous researcher. Search thoroughly, take notes in files, "
        "and return a CONCISE summary of findings with sources. "
        "Never return raw search results."
    ),
    "tools": [internet_search],
}

agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    tools=[internet_search],
    subagents=[research_subagent],
    middleware=[TodoListMiddleware()],  # opt-in task planning (v0.7)
    system_prompt="""You are an expert research lead.
1. Break the research topic into sub-questions (write_todos).
2. Delegate distinct sub-questions to the deep-researcher subagent.
3. Save your own notes under /notes/ with write_file.
4. Synthesize a final report with sections, citations, and a conclusion.""",
    checkpointer=InMemorySaver(),
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "Research the state of LLM agents in 2026"}]},
    config={"configurable": {"thread_id": "research-1"}},
)
print(result["messages"][-1].content)

    要点：

    • 子代理只给搜索工具（最小工具集），指令要求返回紧凑摘要（上下文隔离）
    • 主 Agent 的 write_file 笔记让大搜索结果不撑爆上下文（配合自动 offloading）
    • TodoListMiddleware 是 v0.7 的 opt-in——长任务规划很有用

    15.2 编码助手（沙箱 + HITL + 权限）¶

    场景：在隔离沙箱里写代码、跑测试；破坏性操作要人工批准；工作区外路径禁写。

    用到的能力：沙箱后端、execute、permissions、interrupt_on、MCP 工具。

    # coding_assistant.py
import asyncio

from deepagents import FilesystemPermission, create_deep_agent
from deepagents.backends import LangSmithSandbox
from langchain_mcp_adapters.client import MultiServerMCPClient
from langgraph.checkpoint.memory import InMemorySaver
from langsmith.sandbox import SandboxClient


async def main():
    # 1. Sandbox for isolated execution
    client = SandboxClient()
    ls_sandbox = client.create_sandbox()
    backend = LangSmithSandbox(sandbox=ls_sandbox)

    # 2. MCP tools (GitHub) via langchain-mcp-adapters
    mcp_client = MultiServerMCPClient(
        {
            "github": {
                "transport": "stdio",
                "command": "npx",
                "args": ["-y", "@modelcontextprotocol/server-github"],
                "env": {"GITHUB_TOKEN": "***"},
            }
        }
    )
    mcp_tools = await mcp_client.get_tools()

    # 3. Agent with guardrails
    agent = create_deep_agent(
        model="anthropic:claude-sonnet-4-6",
        backend=backend,
        tools=mcp_tools,
        system_prompt=(
            "You are a careful coding assistant. Clone repos, read code, "
            "write fixes under /workspace, and run tests with execute. "
            "Always run the test suite before declaring a fix complete."
        ),
        # Guardrail: pause for approval before deleting anything
        interrupt_on={"delete": True},
        checkpointer=InMemorySaver(),  # required for interrupts
    )

    try:
        result = await agent.ainvoke(
            {"messages": [{"role": "user", "content": "Fix the failing tests in this repo"}]},
            config={"configurable": {"thread_id": "code-1"}},
        )
        print(result["messages"][-1].content)
    finally:
        client.delete_sandbox(ls_sandbox.name)  # sandboxes cost money!


asyncio.run(main())

    要点：

    • 沙箱后端自动提供 execute 工具；权限系统管不住沙箱（能跑任意命令），所以用沙箱隔离本身就是边界
    • 非沙箱场景（如 FilesystemBackend）加 permissions=[...] 限制路径（第 6 章）
    • MCP 工具通过 MultiServerMCPClient 加载后传 tools=——create_deep_agent 没有 mcp_config 参数
    • 沙箱用完必须销毁

    15.3 数据分析 Agent（Interpreter + 按需压缩）¶

    场景：分析 CSV 数据、生成图表、迭代出报告。大量确定性数据变换用解释器而非逐次工具调用。

    用到的能力：沙箱（装 pandas）、Interpreter/PTC、compact_conversation 工具。

    # data_analyst.py
from deepagents import create_deep_agent
from deepagents.backends import LocalShellBackend
from deepagents.middleware.summarization import create_summarization_tool_middleware
from langchain_quickjs import CodeInterpreterMiddleware
from langgraph.checkpoint.memory import InMemorySaver

model = "anthropic:claude-sonnet-4-6"

agent = create_deep_agent(
    model=model,
    # Local dev with shell access; use a sandbox backend in production
    backend=LocalShellBackend(root_dir="./analysis-workspace", virtual_mode=True),
    middleware=[
        CodeInterpreterMiddleware(),   # in-process QuickJS for data transforms
        create_summarization_tool_middleware(model, None),  # on-demand compaction
    ],
    system_prompt="""You are a data analyst.
- Use execute to install pandas/matplotlib and run analysis scripts.
- Save generated charts to /charts/ and reference them by path.
- Use eval for deterministic transforms (grouping, sorting, validation)
  instead of re-reading data through multiple tool calls.
- Between analysis phases, call compact_conversation to keep context lean.""",
    checkpointer=InMemorySaver(),
)

    要点：

    • Interpreter 的 eval 工具处理循环/聚合等确定性工作，中间结果不进模型上下文（第 6 章）
    • 图表存文件、传路径引用（多模态最佳实践，第 6 章）
    • compact_conversation 让 Agent 在阶段之间主动压缩，不等 85% 阈值
    • ⚠️ LocalShellBackend 无隔离，仅限受信本地开发；生产换沙箱

    15.4 多租户客服 Agent（记忆作用域）¶

    场景：SaaS 产品的客服 Agent。每个用户有独立偏好记忆；组织级政策只读；跨会话记住用户。

    用到的能力：CompositeBackend、StoreBackend namespace、memory、permissions、context_schema。

    # support_agent.py
from dataclasses import dataclass

from deepagents import FilesystemPermission, create_deep_agent
from deepagents.backends import CompositeBackend, StateBackend, StoreBackend


@dataclass
class SupportContext:
    user_id: str
    org_id: str


agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    memory=[
        "/memories/preferences.md",   # per-user, writable by the agent
        "/policies/company.md",       # org-level, read-only
    ],
    backend=CompositeBackend(
        default=StateBackend(),        # scratch files stay thread-scoped
        routes={
            "/memories/": StoreBackend(
                namespace=lambda rt: (rt.context.user_id,),  # per-user isolation
            ),
            "/policies/": StoreBackend(
                namespace=lambda rt: (rt.context.org_id,),   # shared per org
            ),
        },
    ),
    permissions=[
        # Org policies: agent can read but never write
        FilesystemPermission(operations=["write"], paths=["/policies/**"], mode="deny"),
    ],
    context_schema=SupportContext,
    system_prompt="""You are a friendly support assistant.
- Read /memories/preferences.md and honor the user's saved preferences.
- When you learn a new durable preference, update that file with edit_file.
- Always comply with /policies/company.md.""",
)

# Each request carries its caller identity
result = agent.invoke(
    {"messages": [{"role": "user", "content": "How do I export my data?"}]},
    context=SupportContext(user_id="user-alice", org_id="acme-corp"),
    config={"configurable": {"thread_id": "support-thread-1"}},
)

    要点：

    • namespace factory 从 runtime context 取 user_id/org_id——Alice 的偏好不会泄漏给 Bob（第 8 章）
    • 组织政策 deny write 防提示注入篡改共享状态（第 6、8 章）
    • 部署到 LangSmith 时 store 自动配置；本地开发需自己传 store=InMemoryStore() 等
    • 生产用 rt.server_info.user.identity（认证用户）代替手工传 user_id

    15.5 通用模式总结¶

    模式 配方
    并行调研 多个子代理 + 紧凑输出指令 + todos 协调
    代码执行 沙箱后端 + execute；生产不用 LocalShellBackend
    大结果处理 落盘传引用（offloading 自动兜底）+ 按需 compact
    多租户 CompositeBackend + namespace factory + permissions
    安全审批 interrupt_on（工具级）+ permissions interrupt 模式（路径级）
    质量保证 RubricMiddleware 迭代到满足标准（第 11 章）
    可观察性 LangSmith tracing 全程开启 + event streaming 前端展示
