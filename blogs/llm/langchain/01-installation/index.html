    第 01 章：安装与配置¶

    完整的环境搭建指南 | 5 分钟开始编码

    本章目标¶

    学完本章后，你将能够：

    • ✅ 正确安装 LangChain 和所需依赖
    • ✅ 配置 API Keys 和环境变量
    • ✅ 验证安装是否成功
    • ✅ 选择适合的包管理器（pip vs uv）
    • ✅ 理解不同安装选项的区别

    1.1 系统要求¶

    前置条件¶

    要求 说明 检查命令
    Python 3.10 或更高版本 python --version
    包管理器 pip 或 uv（推荐） pip --version / uv --version
    操作系统 Windows / macOS / Linux 全部支持

    检查 Python 版本¶

    # 检查 Python 版本
python --version
# 应该显示：Python 3.10.x 或更高

# 如果版本过低，需要升级
# macOS: brew install python@3.11
# Ubuntu: sudo apt install python3.11
# Windows: 从 python.org 下载安装

    推荐：安装 uv 包管理器¶

    uv 是一个超快的 Python 包管理器（Rust 编写），比 pip 快 10-100 倍。

    # macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 验证安装
uv --version

    uv vs pip 对比：

    特性 uv pip
    安装速度 ⚡️ 极快（10-100x） 🐌 较慢
    依赖解析 ✅ 更可靠 ⚠️ 有时冲突
    磁盘空间 ✅ 全局缓存，节省空间 ❌ 重复安装
    虚拟环境 ✅ 内置管理 ❌ 需要 venv
    推荐度 ⭐⭐⭐⭐⭐ ⭐⭐⭐

    1.2 安装 LangChain¶

    选项 1：基础安装（仅核心库）¶

    适合：快速测试，不需要特定 Provider

    # 使用 pip
pip install -U langchain

# 使用 uv
uv add langchain

    包含内容： - ✅ LangChain 核心库 - ✅ 基础工具接口 - ✅ Agent 框架 - ❌ 不包含任何 Provider 集成（需要单独安装）

    选项 2：安装 Provider 集成¶

    适合：使用特定 LLM Provider

    安装单个 Provider¶

    # OpenAI
pip install -U langchain-openai
# 或
uv add langchain-openai

# Anthropic (Claude)
pip install -U langchain-anthropic
# 或
uv add langchain-anthropic

# Google (Gemini)
pip install -U langchain-google-genai
# 或
uv add langchain-google-genai

# AWS Bedrock
pip install -U langchain-aws
# 或
uv add langchain-aws

# Azure OpenAI
pip install -U langchain-openai  # 同一个包
# 配置 Azure 环境变量即可

# Ollama (本地模型)
pip install -U langchain-ollama
# 或
uv add langchain-ollama

# HuggingFace
pip install -U langchain-huggingface
# 或
uv add langchain-huggingface

    安装多个 Provider¶

    # 使用 extras 语法
pip install -U "langchain[openai,anthropic]"
# 或
uv add langchain-openai langchain-anthropic

# 完整列表
pip install -U "langchain[openai,anthropic,google-genai,aws]"

    选项 3：完整安装（所有 Provider）¶

    适合：需要测试多个 Provider，或不确定使用哪个

    # 安装所有 Provider（不推荐，体积较大）
pip install -U "langchain[all]"

# 或安装常用 Provider 组合
uv add langchain-openai langchain-anthropic langchain-google-genai langchain-aws

    推荐安装方案¶

    初学者推荐：

    # 1. 安装 uv（如果还没有）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. 创建项目目录
mkdir my-agent-project
cd my-agent-project

# 3. 初始化项目
uv init

# 4. 安装常用 Provider
uv add langchain langchain-openai langchain-anthropic

# 5. 验证安装
uv run python -c "from langchain.agents import create_agent; print('✅ 安装成功')"

    生产环境推荐：

    # 1. 创建虚拟环境
uv venv --python 3.11

# 2. 激活虚拟环境
source .venv/bin/activate  # macOS/Linux
# 或
.venv\Scripts\activate     # Windows

# 3. 安装精确版本（推荐锁定版本）
uv add langchain==1.0.0 langchain-openai==1.0.0 langchain-anthropic==1.0.0

# 4. 生成依赖锁定文件
uv lock

# 5. 安装生产依赖（不含 dev 依赖）
uv sync --frozen

    1.3 配置 API Keys¶

    为什么需要 API Keys？¶

    LLM Provider 需要认证才能使用其服务。API Key 是你的身份凭证。

    获取 API Keys¶

    Provider 获取地址 免费额度
    OpenAI https://platform.openai.com/api-keys $5 新用户
    Anthropic https://console.anthropic.com/settings/keys 有限免费
    Google https://makersuite.google.com/app/apikey 有限免费
    AWS https://console.aws.amazon.com/bedrock 按量付费

    配置方法¶

    方法 1：环境变量（推荐）¶

    临时设置（仅当前终端会话有效）：

    # macOS / Linux
export OPENAI_API_KEY="sk-..."
export ANTHROPIC_API_KEY="sk-ant-..."
export GOOGLE_API_KEY="..."

# Windows (PowerShell)
$env:OPENAI_API_KEY="sk-..."
$env:ANTHROPIC_API_KEY="sk-ant-..."

# Windows (CMD)
set OPENAI_API_KEY=sk-...

    永久设置（添加到 shell 配置文件）：

    # macOS / Linux - 添加到 ~/.bashrc 或 ~/.zshrc
echo 'export OPENAI_API_KEY="sk-..."' >> ~/.bashrc
echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.bashrc
source ~/.bashrc

# 验证
echo $OPENAI_API_KEY

    方法 2：.env 文件（推荐用于项目）¶

    创建 .env 文件在项目根目录：

    # 创建 .env 文件
cat > .env << EOF
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_API_KEY=...
EOF

# ⚠️ 重要：将 .env 添加到 .gitignore
echo ".env" >> .gitignore

    在 Python 中加载：

    from dotenv import load_dotenv
load_dotenv()  # 自动加载 .env 中的环境变量

# 现在可以使用了
import os
print(os.environ["OPENAI_API_KEY"])

    方法 3：代码中直接设置（不推荐）¶

    import os
os.environ["OPENAI_API_KEY"] = "sk-..."  # ❌ 不要提交到版本控制

    ⚠️ 警告：永远不要将 API Key 硬编码在代码中并提交到 Git！

    安全最佳实践¶

    ✅ 好的做法：
- 使用环境变量
- .env 文件添加到 .gitignore
- 使用密钥管理服务（AWS Secrets Manager 等）
- 定期轮换 API Key

❌ 避免的做法：
- 硬编码在代码中
- 提交到 Git
- 通过邮件/聊天发送
- 使用过期或共享的 Key

    1.4 验证安装¶

    基础验证¶

    # test_install.py
from langchain.chat_models import init_chat_model

# 测试模型初始化
try:
    model = init_chat_model("gpt-4o")
    print("✅ 模型初始化成功")
except Exception as e:
    print(f"❌ 模型初始化失败：{e}")

# 测试工具导入
try:
    from langchain.agents import create_agent
    from langchain.tools import tool
    print("✅ 工具导入成功")
except Exception as e:
    print(f"❌ 工具导入失败：{e}")

    运行测试：

    # 使用 uv
uv run python test_install.py

# 或使用 pip
python test_install.py

    完整功能测试¶

    # test_agent.py
from langchain.agents import create_agent

# 定义简单工具
def get_weather(city: str) -> str:
    """获取天气信息"""
    return f"It's sunny in {city}!"

# 创建 Agent
agent = create_agent(
    model="gpt-4o",  # 或 "claude-sonnet-4-6"
    tools=[get_weather],
    system_prompt="你是 helpful assistant"
)

# 测试运行
response = agent.invoke({
    "messages": [{"role": "user", "content": "北京天气如何？"}]
})

print("✅ Agent 运行成功")
print(response)

    常见问题排查¶

    问题 1：ModuleNotFoundError¶

    ❌ 错误：ModuleNotFoundError: No module named 'langchain'

✅ 解决：
# 确保已安装
pip install -U langchain
# 或
uv add langchain

# 如果在虚拟环境中，确保已激活
source .venv/bin/activate

    问题 2：API Key 无效¶

    ❌ 错误：401 Unauthorized / Invalid API key

✅ 解决：
# 检查环境变量是否设置
echo $OPENAI_API_KEY

# 重新设置
export OPENAI_API_KEY="sk-..."

# 验证 Key 是否有效（在 Provider 官网测试）

    问题 3：版本冲突¶

    ❌ 错误：ImportError: cannot import name 'xxx' from 'langchain'

✅ 解决：
# 升级到最新版本
pip install -U langchain langchain-openai langchain-anthropic
# 或
uv add langchain langchain-openai langchain-anthropic

# 检查版本
pip show langchain

    问题 4：Python 版本过低¶

    ❌ 错误：LangChain requires Python 3.10+

✅ 解决：
# 检查版本
python --version

# 升级 Python
# macOS: brew install python@3.11
# Ubuntu: sudo apt install python3.11
# Windows: 从 python.org 下载

    1.5 项目结构建议¶

    推荐的项目布局¶

    my-agent-project/
├── .venv/                 # 虚拟环境（不要提交）
├── .env                   # 环境变量（不要提交）
├── .gitignore
├── pyproject.toml         # 项目配置和依赖
├── uv.lock               # 依赖锁定文件
├── README.md
├── src/
│   └── my_agent/
│       ├── __init__.py
│       ├── agent.py       # Agent 定义
│       ├── tools.py       # 工具定义
│       └── prompts.py     # 系统提示
├── tests/
│   ├── __init__.py
│   └── test_agent.py      # 测试文件
└── examples/
    └── basic_example.py   # 示例代码

    pyproject.toml 示例¶

    [project]
name = "my-agent"
version = "0.1.0"
description = "My LangChain Agent"
requires-python = ">=3.10"
dependencies = [
    "langchain>=1.0.0",
    "langchain-openai>=1.0.0",
    "langchain-anthropic>=1.0.0",
    "python-dotenv>=1.0.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=7.0.0",
    "black>=23.0.0",
    "ruff>=0.1.0",
]

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

    1.6 开发环境配置¶

    代码编辑器推荐¶

    VS Code 配置¶

    1. 安装扩展：
    2. Python (ms-python.python)
    3. Pylance (ms-python.vscode-pylance)

    4. Black Formatter (ms-python.black-formatter)

    5. settings.json：

    {
    "python.defaultInterpreterPath": ".venv/bin/python",
    "python.formatting.provider": "black",
    "python.linting.enabled": true,
    "python.linting.pylintEnabled": false,
    "python.linting.ruffEnabled": true,
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
        "source.organizeImports": true
    }
}

    代码质量工具¶

    # 安装开发工具
uv add --dev black ruff pytest mypy

# 格式化代码
uv run black src/ tests/

# 代码检查
uv run ruff check src/ tests/

# 类型检查
uv run mypy src/

# 运行测试
uv run pytest tests/

    调试配置¶

    # 启用详细日志
import logging
logging.basicConfig(level=logging.DEBUG)

# LangChain 特定日志
import langchain
langchain.debug = True

# 现在运行 Agent 会显示详细日志
