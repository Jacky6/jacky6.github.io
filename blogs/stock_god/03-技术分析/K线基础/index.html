    K线基础¶

    K线是股市的"表情"，一根K线记录了多空双方一天的战斗结果

    💡 从这里开始进入技术分析。如果还不太熟悉看盘软件的盘面和 K 线图，先回顾一下《开户与看盘》。

    ⚠️ 先泼一盆冷水¶

    K线形态是概率工具，不是预言。任何K线形态的胜率都不是100%， 单根K线意义有限，必须结合所处位置（高位/低位）和成交量一起看。 指望背几张K线图就稳定赚钱，是不现实的。

    一、K线的构成¶

    一根K线记录了四个价格：开盘价、收盘价、最高价、最低价。

            ┬ 上影线：冲高被打回来了
        │
   ┌────┴────┐ ─┬─
   │         │  │ 实体：开盘价和收盘价之间
   │         │  │
   └────┬────┘ ─┴─
        │
        ┴ 下影线：跌下去被拉回来了

    阳线和阴线¶

    类型 条件 颜色（A股习惯） 含义
    阳线 收盘价 > 开盘价 红色 多方胜（收涨）
    阴线 收盘价 < 开盘价 绿色 空方胜（收跌）

    💡 A股红涨绿跌，和欧美（绿涨红跌）正好相反，看美股时别搞混。

    阳线（红）：收盘 > 开盘            阴线（绿）：收盘 < 开盘

          │ 最高价                        │ 最高价
          │                               │
    ┌─────┴─────┐ ← 收盘价（高）     ┌─────┴─────┐ ← 开盘价（高）
    │           │                     │           │
    │    实体   │                     │    实体   │
    │           │                     │           │
    └─────┬─────┘ ← 开盘价（低）     └─────┬─────┘ ← 收盘价（低）
          │                               │
          │ 最低价                        │ 最低价

    影线的含义¶

    • 长上影线：冲高回落，上方抛压重（高位出现是危险信号）
    • 长下影线：探底回升，下方有承接（低位出现可能是止跌信号）

    二、常见单根K线¶

    名称 长相 一般含义
    大阳线 实体很长、几乎无影线 多方强势控盘
    大阴线 实体很长的阴线 空方强势，杀跌凶猛
    十字星 开盘≈收盘，实体几乎为0 多空平衡，变盘前兆
    锤子线 小实体+长下影（2倍以上） 低位出现=可能见底
    倒锤子 小实体+长上影 低位出现=试探反弹
    上吊线 长得像锤子但出现在高位 高位出现=可能见顶 ⚠️

    ⚠️ 同一个形状，在低位和高位含义相反： 锤子线在底部是希望，上吊线在顶部是警告。位置决定一切。

    三、常见K线组合¶

    1. 早晨之星（底部反转）¶

    连跌之后：大阴线 + 十字星（或小实体）+ 大阳线
    - 空方力竭 → 犹豫 → 多方反攻 - 出现在长期下跌后，可能是见底信号

    2. 黄昏之星（顶部反转）¶

    连涨之后：大阳线 + 十字星（或小实体）+ 大阴线
    - 早晨之星的镜像，高位出现要警惕

    3. 吞没形态¶

    • 看涨吞没：阳线实体完全包住前一根阴线 → 低位反转信号
    • 看跌吞没：阴线实体完全包住前一根阳线 → 高位反转信号

    4. 三只乌鸦¶

    高位连续三根阴线，每根开盘都在前一根实体内、收盘创新低
    - 经典的见顶下跌形态，空方持续碾压

    四、K线必须配合的两个东西¶

    1. 位置（趋势中的位置）¶

    同样一根大阳线：

    • 底部横盘很久后出现 → 可能是启动信号
    • 已经涨了 80% 后出现 → 可能是最后的疯狂

    2. 量能（成交量）¶

    • 大阳线 + 放量 → 资金真金白银进场，可信
    • 大阳线 + 缩量 → 可能是无量空涨，持续性存疑

    💡 价是表象，量是底气。 这个下一篇《成交量分析》细讲。

    五、不同周期的K线¶

    周期 用途
    日K 短线、波段最常用
    周K 看中期趋势，过滤日间噪音
    月K 看大级别位置
    分钟K（5/15/30/60分钟） 日内交易，新手别碰

    💡 新手先看日K和周K。周期越小噪音越多，越容易被骗线。

    一句话总结¶

    K线记录多空战斗：阳线多方胜、阴线空方胜，影线暴露攻防痕迹。同样的形态在不同位置含义相反，必须结合位置和成交量看。 它是概率语言，不是确定性预言——新手记住大阳大阴、十字星、早晨/黄昏之星这几个就够用，别迷信形态。
