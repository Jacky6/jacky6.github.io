    趋势线与形态分析¶

    趋势是你最好的朋友，形态是趋势转折的预警信号

    ⚠️ 先打预防针¶

    形态分析是技术分析里主观性最强的部分：事后看图形"清清楚楚"， 事前看"似是而非"。十个图形派可能画出十种结论。 形态只能给出概率倾向，必须配合量能和位置，且永远要设止损。

    一、趋势的三种状态¶

    状态 定义 操作思路
    上升趋势 高点不断抬高，低点也不断抬高 持股为主，回调找买点
    下降趋势 低点不断创新低，高点也上不去 空仓或轻仓，反弹减仓
    横盘（震荡） 高低点在一个区间内波动 高抛低吸，或等突破

    💡 最朴素的趋势定义： higher highs + higher lows = 上升趋势。破坏这个结构（低点跌破前低）就是趋势走坏的信号。

    二、趋势线怎么画¶

    上升趋势线：连接两个或以上的依次抬高的低点
下降趋势线：连接两个或以上的依次降低的高点
    • 触碰次数越多、持续时间越长的趋势线，效力越强
    • 被有效突破（参考《支撑位与压力位》的三标准）= 趋势可能反转

    三、反转形态（趋势要变天了）¶

    1. 头肩顶 / 头肩底¶

    头肩顶（中间峰最高，跌破颈线确认）：

                    /\
                   /  \
                  /头部 \
        /\       /        \       /\
       /  \     /          \     /  \
      /左肩 \  /            \  / 右肩 \
     /      \/              \/        \
    ──────────────────────────────────────── 颈线

头肩底（倒过来，突破颈线确认）：

    ──────────────────────────────────────── 颈线
     \      /\              /\      /
      \    /  \            /  \    /
       \  /左肩 \          / 右肩 \ /
        \/      \          /      \/
                 \        /
                  \ 头部 /
                   \    /
                    \  /
    • 头肩顶：左肩-头-右肩，跌破颈线确认，是经典见顶形态
    • 量度目标：跌破颈线后的跌幅 ≈ 头顶到颈线的距离
    • 头肩底是其镜像，突破颈线看涨

    2. 双重顶（M 头）/ 双重底（W 底）¶

    M 头（两次冲高不过前高，跌破颈线确认）：

        /\        /\
       /  \      /  \
      /    \    /    \
     /      \  /      \
    /        \/        \
   ──────────────────────────── 颈线

W 底（两次探底不破前低，突破颈线确认）：

   ──────────────────────────── 颈线
    \                    /
     \        /\        /
      \      /  \      /
       \    /    \    /
        \  /      \  /
         \/        \/
    • M 头：两次冲高不过前高，跌破颈线确认下跌
    • W 底：两次探底不破前低，突破颈线确认上涨
    • 量度目标同样约为形态高度

    3. 三重顶/底¶

    • M/W 的加强版，三个高点/低点，出现频率低但可靠性更高

    四、持续形态（趋势歇口气，接着走）¶

    1. 三角形¶

    类型 形状 常见方向
    对称三角形 高点下移+低点上移，收敛 原趋势延续概率大
    上升三角形 高点水平+低点上移 偏看涨
    下降三角形 低点水平+高点下移 偏看跌 
    对称三角形（高点下移、低点上移，收敛）：

 \            ↖ 高点逐步下移
  \    /\
   \  /  \
    \/    \         → 收敛到顶点前突破，方向跟随原趋势
    /\    /
   /  \  /
  /    \/
 /              ↙ 低点逐步上移

上升三角形（上边水平、低点上移，偏看涨）：

 上边（水平阻力）─────────────────
        /\     /\
   /\  /  \   /
  /  \/    \ /      → 收敛后向上突破概率较大
      /\   /
     /  \ /
    /     ↙ 低点逐步上移

下降三角形：上升三角形倒过来（下边水平、高点下移），偏看跌。
    • 越接近顶点突破动能越弱，一般在三角形 2/3 处突破最有效
    • 量度目标 ≈ 三角形最宽处的垂直高度，从突破点起算

    2. 旗形 / 楔形¶

    上升旗形（急涨后的短暂向下小通道整理）：

         旗面（向下倾斜的小通道）
            /\   ↗ 突破旗面上沿，延续原趋势
           /  \ /
          /    /
         /  /
        /  /
   ────/  /
      /  /    ← 旗杆（前期急涨段）
     /  /
    /  /
   /  /
    • 急涨（旗杆）后短暂反向小通道整理（旗面），突破后常延续原趋势
    • 旗形整理时间短（1-3 周），量逐步萎缩，突破时放量
    • 量度目标 ≈ 旗杆高度，从突破点起算（下跌旗形反之）

    3. 箱体（矩形整理）¶

    压力位 ─────────────────────────────
       /\    /\    /\
      /  \  /  \  /  \    → 突破上沿追趋势，跌破下沿要止损
     /    \/    \/    \
支撑位 ─────────────────────────────
    • 策略：箱体内高抛低吸，突破箱体上沿追趋势
    • 箱体越久，突破后的行情往往越大
    • 量度目标 ≈ 箱体高度，从突破点起算

    五、量度目标（形态的"测量功能"）¶

    多数形态突破后的目标幅度 ≈ 形态本身的垂直高度：

    例：W 底颈线 10 元，底部最低 8 元 → 形态高度 2 元
突破颈线后理论目标 ≈ 10 + 2 = 12 元

    ⚠️ 量度目标只是统计倾向，不是承诺。到达目标位前随时可能反转。

    六、形态分析的三条纪律¶

    1. 先看大周期：周线形态 > 日线形态 > 分钟线形态
    2. 必须看量：无量突破的形态可信度大打折扣
    3. 必须带止损：形态失败（假突破）时按纪律离场，不硬扛

    一句话总结¶

    趋势三态（上升/下降/横盘）决定大方向，形态是转折的预警：头肩、双顶双底是反转信号，三角形、旗形、箱体是中途休息。量度目标 ≈ 形态高度。但形态识别主观性强、事后清晰事前模糊——把它当"概率地图"而不是"藏宝图"，配合量能、位置和止损使用。
