    成交量分析¶

    价格可以被操纵，但成交量是实打实的钱。量，是价的气门芯

    ⚠️ 风险提示¶

    量价关系是经验总结，不是物理定律。而且量也能造假—— 主力可以用"对倒"（自己卖给自己）制造虚假放量。 永远结合价格位置、市场环境综合判断，别只看量就下结论。

    一、成交量是什么¶

    成交量：一段时间内成交的股票数量（手）。 成交额：成交的金额（元），对大市值股票更有参考性。

    • 看盘软件里，红绿柱子就是每天的量
    • 放量 = 量明显大于近期平均；缩量 = 明显小于

    💡 换手率 = 成交量 / 流通股本，是标准化的"活跃度"指标（见《核心术语》）。

    二、"量在价先"¶

    技术分析的一个核心信条：成交量的变化往往领先于价格的变化。

    逻辑：

    • 大资金进出必然体现在量上
    • 底部悄悄放量 → 可能有资金在吸筹
    • 高位突然放量 → 可能有资金在出货

    ⚠️ 但这只是概率。真正的底部往往是地量，真正的顶部往往也是天量——关键看量出现在什么位置。

    三、量价关系八种组合¶

    组合 形态 常见含义
    放量上涨 价涨 + 量增 多方强势，资金进场（趋势初中期健康）
    缩量上涨 价涨 + 量减 上涨乏力或高度控盘，持续性存疑
    放量下跌 价跌 + 量增 恐慌抛售，空方占优（危险）
    缩量下跌 价跌 + 量减 抛压减轻，跌势可能趋缓
    天量天价 巨量 + 历史高价 可能是见顶信号，主力出货 ⚠️
    地量地价 极小量 + 历史低价 可能是底部区域，但地量之后还有地量
    平量上涨 价涨 + 量持平 温和上涨，关注能否放量确认
    平量下跌 价跌 + 量持平 阴跌，人气涣散

    四、关键位置的量¶

    底部放量 vs 顶部放量¶

    底部放量 顶部放量
    位置 长期下跌后低位横盘 大幅上涨后高位
    可能含义 资金进场吸筹 主力出货、散户接盘
    操作参考 关注，等确认 警惕，考虑减仓

    突破必须放量¶

    股价突破重要压力位（前高、均线、箱体上沿）时：

    • 放量突破 → 突破可信度高
    • 缩量突破 → 可能是假突破，随时回落

    💡 记住：无量突破，十有八九是耍流氓。

    五、换手率配合判断¶

    换手率 状态
    < 1% 冷清，无人问津
    1% - 3% 正常水平
    3% - 7% 活跃
    7% - 15% 高度活跃（有大事发生）
    > 15% 极端活跃，警惕主力对倒出货

    配合位置：

    • 低位温和放量（换手 3-7%）→ 健康吸筹迹象
    • 高位巨量换手（> 15%）→ 出货嫌疑大

    六、警惕：量也能造假¶

    对倒：主力用多个账户自买自卖，制造放量假象，吸引跟风盘。

    常见骗术：

    • 高位对倒放量 → 假装"放量突破"诱多出货
    • 低位对倒放量 → 假装"资金进场"诱多接盘

    ⚠️ 防骗方法： 1. 看持续性——真吸筹是温和持续的，假放量往往一天就没了 2. 看位置——位置比量更重要 3. 看后续——放量后价格能否站稳，次日就见分晓

    一句话总结¶

    量是钱的脚印：放量上涨是资金进场，放量下跌是资金出逃，无量突破不可信，高位天量要警惕，低位温和放量值得跟踪。但位置决定量的性质，同样一个"放量"在底部是蜜糖、在顶部是砒霜；且量也能对倒造假，多看几天再下结论。
