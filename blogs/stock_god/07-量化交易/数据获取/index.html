    数据获取¶

    量化的第一粒扣子：拿到干净、带复权的历史行情数据

    一、三个主流数据源对比¶

    数据源 费用 优点 缺点
    akshare 免费 无需注册，接口丰富，A股/港股/基金/宏观 数据来自公开源，偶尔接口变动
    tushare 积分制（基础免费） 数据规整、字段标准 高级接口要积分（捐赠/贡献获取）
    yfinance 免费 美股/全球市场方便 A股数据质量一般

    💡 A 股学习推荐 akshare：零门槛，够学习用；进阶要稳定数据再考虑 tushare。

    二、akshare：获取 A 股日线（完整示例）¶

    安装¶

    pip install akshare pandas

    拉取贵州茅台近一年日线并存 CSV¶

    import akshare as ak
import pandas as pd
from datetime import datetime, timedelta

# date range: recent one year
end = datetime.now().strftime("%Y%m%d")
start = (datetime.now() - timedelta(days=365)).strftime("%Y%m%d")

# qfq = forward-adjusted (前复权), recommended for backtesting
df = ak.stock_zh_a_hist(
    symbol="600519",        # stock code, no exchange prefix
    period="daily",         # daily / weekly / monthly
    start_date=start,
    end_date=end,
    adjust="qfq",           # qfq=前复权, hfq=后复权, ""=不复权
)

# akshare returns Chinese column names:
# 日期, 股票代码, 开盘, 收盘, 最高, 最低, 成交量, 成交额, 振幅, 涨跌幅, 涨跌额, 换手率
df["日期"] = pd.to_datetime(df["日期"])
df = df.set_index("日期").sort_index()

df.to_csv("600519_daily.csv", encoding="utf-8-sig")
print(df[["开盘", "收盘", "最高", "最低", "成交量"]].tail())

    复权是什么？为什么必须复权¶

    股票分红/送股后，股价会除权（价格突然"变低"）
不复权：K线上出现假缺口，指标全部失真
前复权（qfq）：把历史价格调整到和当前一致 → 回测用这个
后复权（hfq）：把当前价格还原到历史成本 → 算真实收益率用这个

    ⚠️ 回测必须用复权数据，否则分红除权日会产生虚假信号。

    其他常用 akshare 接口¶

    # all A-share realtime snapshot (全市场实时快照)
ak.stock_zh_a_spot_em()

# index daily (指数日线, e.g. 沪深300)
ak.index_zh_a_hist(symbol="000300", period="daily",
                   start_date="20240101", end_date="20260801")

# financial indicators (财务指标)
ak.stock_financial_analysis_indicator(symbol="600519")

# note: akshare interfaces change occasionally;
# if a call fails, check https://akshare.akfamily.xyz/ for the latest usage

    三、tushare：更规整的官方风格数据¶

    import tushare as ts

# token from https://tushare.pro (register & get your own)
pro = ts.pro_api("YOUR_TOKEN")

df = pro.daily(
    ts_code="600519.SH",      # tushare uses code.exchange format
    start_date="20240101",
    end_date="20260801",
)
# columns: ts_code, trade_date, open, high, low, close, vol, amount, ...

# adjusted data needs the pro_bar API
df = ts.pro_bar(ts_code="600519.SH", adj="qfq",
                start_date="20240101", end_date="20260801")
    • 免费积分有限（日线够用），分钟线/财务明细要更高积分
    • 积分获取：捐赠或社区贡献

    四、yfinance：美股¶

    import yfinance as yf

df = yf.download("AAPL", start="2024-01-01", end="2026-08-01", auto_adjust=True)
# columns: Open, High, Low, Close, Volume (auto_adjust=True 已复权)

    A 股代码在 yfinance 上格式为 600519.SS（沪市）/ 000001.SZ（深市），但数据质量不稳定，A 股别用它。

    六、本地数据管理建议¶

    stock_god/
└── data/
    ├── daily/          # 个股日线 CSV（按代码命名）
    ├── index/          # 指数日线
    └── meta/           # 股票列表、行业分类
    • 学习阶段：每次现拉（akshare 速度可接受）
    • 研究阶段：每晚增量更新一次，存本地 CSV/Parquet
    • Parquet 比 CSV 快且小：df.to_parquet("600519.parquet")

    一句话总结¶

    A 股数据用 akshare（免费零门槛，stock_zh_a_hist + adjust="qfq"），进阶用 tushare，美股用 yfinance。回测必须用复权数据，拿到数据先查缺失/停牌/异常值。数据是量化的地基——地基脏了，上面盖的策略全是危房。
