    回测框架¶

    回测 = 用历史数据模拟"如果当时这么交易，结果如何"。量化的核心能力

    一、回测的核心概念¶

    概念 说明
    初始资金 模拟的本金（如 10 万）
    手续费 佣金（万三左右）+ 卖出印花税（万五）
    滑点 下单价和实际成交价的差距（回测容易忽略的坑）
    收益曲线 账户净值随时间的变化
    最大回撤 净值从峰值到谷底的最大跌幅（最重要的风险指标）
    夏普比率 每承担一单位风险赚多少（年化收益/年化波动）

    回测必须包含费用¶

    不算费用的回测是耍流氓：
  双均线策略一年交易 50 次
  每次双边成本约 0.1-0.15%
  → 一年光成本就吃掉 5-7% 的利润

    二、手写最小回测引擎（双均线策略）¶

    50 行左右，麻雀虽小五脏俱全：

    import pandas as pd
import numpy as np

def backtest_ma_cross(df: pd.DataFrame,
                      fast: int = 5,
                      slow: int = 20,
                      init_cash: float = 100_000,
                      fee_rate: float = 0.0003,   # commission, one-way
                      stamp_tax: float = 0.0005,  # sell only
                      slippage: float = 0.001     # 0.1% slippage
                      ) -> pd.DataFrame:
    """Minimal vectorized backtest for MA cross strategy (long only)."""
    close = df["收盘"].copy()

    # signals: 1 = hold, 0 = empty
    ma_fast = close.rolling(fast).mean()
    ma_slow = close.rolling(slow).mean()
    signal = (ma_fast > ma_slow).astype(int)

    # position is shifted by 1 day: signal today -> trade next day
    # (avoid look-ahead bias!)
    position = signal.shift(1).fillna(0)

    # daily returns with slippage cost on position changes
    daily_ret = close.pct_change().fillna(0)
    trade = position.diff().abs().fillna(position.iloc[0])
    cost = trade * (fee_rate + stamp_tax / 2 + slippage)

    strategy_ret = position * daily_ret - cost

    # equity curve
    equity = init_cash * (1 + strategy_ret).cumprod()
    return pd.DataFrame({
        "close": close,
        "position": position,
        "equity": equity,
    })


def report(result: pd.DataFrame, init_cash: float = 100_000):
    """Print key metrics of the backtest."""
    equity = result["equity"]

    total_return = equity.iloc[-1] / init_cash - 1
    days = len(equity)
    annual_return = (1 + total_return) ** (252 / days) - 1

    # max drawdown
    peak = equity.cummax()
    drawdown = equity / peak - 1
    max_dd = drawdown.min()

    # Sharpe ratio (annualized, risk-free = 0 for simplicity)
    daily_ret = equity.pct_change().dropna()
    sharpe = daily_ret.mean() / (daily_ret.std() + 1e-9) * np.sqrt(252)

    # number of trades
    trades = int(result["position"].diff().abs().sum())

    print(f"总收益率:   {total_return:8.2%}")
    print(f"年化收益:   {annual_return:8.2%}")
    print(f"最大回撤:   {max_dd:8.2%}")
    print(f"夏普比率:   {sharpe:8.2f}")
    print(f"交易次数:   {trades:8d}")


# run it
df = pd.read_csv("600519_daily.csv", index_col="日期", parse_dates=True)
result = backtest_ma_cross(df, fast=5, slow=20)
report(result)

    ⚠️ 这段代码里最重要的细节：position = signal.shift(1) —— 今天的信号明天才能交易。不 shift 就是"未来函数"（用了未来数据）， 回测收益会虚高，是新手回测第一大坑。

    三、回测结果怎么看¶

    示例输出（示意结果，自己跑出来的才算数）：

总收益率:   35.20%
年化收益:   11.30%
最大回撤:  -18.60%
夏普比率:    0.85
交易次数:   24

    判断标准（粗略）：

    指标 及格线 说明
    年化收益 跑赢沪深300 跑不赢指数就买指数
    最大回撤 < 20% 超过这个数多数人拿不住
    夏普比率 > 1 低于 1 性价比差
    交易次数 合理 太频繁=给券商打工

    💡 必须和基准对比：策略年化 10% 但同期沪深300 年化 15% → 策略是失败的。

    四、backtrader：工程级回测框架¶

    手写引擎适合学习，真做策略推荐 backtrader：

    import backtrader as bt

class MACross(bt.Strategy):
    params = dict(fast=5, slow=20)

    def __init__(self):
        ma_fast = bt.ind.SMA(period=self.p.fast)
        ma_slow = bt.ind.SMA(period=self.p.slow)
        self.crossover = bt.ind.CrossOver(ma_fast, ma_slow)

    def next(self):
        if not self.position:            # flat
            if self.crossover > 0:       # golden cross
                self.buy()
        elif self.crossover < 0:         # death cross
            self.close()

cerebro = bt.Cerebro()
cerebro.addstrategy(MACross)

# load data (backtrader format)
data = bt.feeds.PandasData(dataname=df, datetime=None)
cerebro.adddata(data)

cerebro.broker.setcash(100_000)
cerebro.broker.setcommission(commission=0.0003)   # commission
cerebro.addsizer(bt.sizers.PercentSizer, percents=95)

# analyzers
cerebro.addanalyzer(bt.analyzers.DrawDown, _name="dd")
cerebro.addanalyzer(bt.analyzers.SharpeRatio, _name="sharpe")

result = cerebro.run()
print(result[0].analyzers.dd.get_analysis())
print(result[0].analyzers.sharpe.get_analysis())
cerebro.plot()

    backtrader 比手写强的地方： - 真实的订单撮合（限价/市价/止损单） - 多标的、多周期、仓位管理 - 内置分析器（回撤/夏普/交易明细）

    五、vnpy 简介¶

    • 国内最流行的开源量化框架，侧重期货/实盘

    一句话总结¶

    回测 = 历史数据上的模拟考：必须算费用、必须 shift(1) 防未来函数、必须和基准（沪深300）对比。学习用手写 50 行引擎（理解本质），实战用 backtrader（订单撮合真实）。看结果四件套：年化、最大回撤、夏普、交易次数——跑不赢指数的策略没有存在价值。
