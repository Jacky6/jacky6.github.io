    指标计算¶

    用 pandas 手写指标——理解原理比调库重要，而且这些代码就是你的武器库

    为什么要手写¶

    • TA-Lib 是 C 库，安装麻烦（Linux 要先装 C 库，Windows 要装预编译 wheel）
    • 手写一遍才真正理解指标在算什么（面试/调参都靠这个理解）
    • pandas 实现的性能对日线级别完全够用

    💡 本文所有代码可直接跑：输入是 close（收盘价 Series），输出是指标 Series。 代码注释用英语（写代码的好习惯）。

    准备数据¶

# load data saved in the previous chapter

    一、MA 简单移动平均¶

    MA(n) = 最近 n 天收盘价的算术平均

    def ma(close: pd.Series, n: int) -> pd.Series:
    """Simple moving average."""
    return close.rolling(n).mean()

df["MA5"] = ma(close, 5)
df["MA20"] = ma(close, 20)

    二、EMA 指数移动平均¶

    EMA(today) = price(today) × k + EMA(yesterday) × (1 - k)
k = 2 / (n + 1)

    越近的价格权重越大，比 MA 对新信息更敏感。

    def ema(close: pd.Series, n: int) -> pd.Series:
    """Exponential moving average."""
    return close.ewm(span=n, adjust=False).mean()

    三、MACD¶

    DIF  = EMA(close, 12) - EMA(close, 26)
DEA  = EMA(DIF, 9)
HIST = (DIF - DEA) × 2

    def macd(close: pd.Series,
         fast: int = 12, slow: int = 26, signal: int = 9):
    """MACD: returns (dif, dea, hist)."""
    dif = ema(close, fast) - ema(close, slow)
    dea = dif.ewm(span=signal, adjust=False).mean()
    hist = (dif - dea) * 2
    return dif, dea, hist

df["DIF"], df["DEA"], df["MACD"] = macd(close)

    金叉死叉信号：

    # golden cross: DIF crosses above DEA
df["macd_golden"] = (df["DIF"] > df["DEA"]) & \
                    (df["DIF"].shift(1) <= df["DEA"].shift(1))

    四、RSI 相对强弱指数¶

    RS  = N 日内平均涨幅 / N 日内平均跌幅
RSI = 100 - 100 / (1 + RS)

    def rsi(close: pd.Series, n: int = 14) -> pd.Series:
    """Relative Strength Index (Wilder's smoothing)."""
    delta = close.diff()
    gain = delta.clip(lower=0)      # only keep positive moves
    loss = -delta.clip(upper=0)     # only keep negative moves

    # Wilder's smoothing == EMA with alpha = 1/n
    avg_gain = gain.ewm(alpha=1/n, adjust=False).mean()
    avg_loss = loss.ewm(alpha=1/n, adjust=False).mean()

    rs = avg_gain / avg_loss
    return 100 - 100 / (1 + rs)

df["RSI14"] = rsi(close, 14)

    五、布林带 BOLL¶

    中轨 MID = MA(close, 20)
上轨 UP  = MID + 2 × std(close, 20)
下轨 LOW = MID - 2 × std(close, 20)

    def boll(close: pd.Series, n: int = 20, k: float = 2.0):
    """Bollinger Bands: returns (upper, mid, lower)."""
    mid = close.rolling(n).mean()
    std = close.rolling(n).std()
    return mid + k * std, mid, mid - k * std

df["BOLL_UP"], df["BOLL_MID"], df["BOLL_LOW"] = boll(close)

    六、KDJ（选学）¶

    RSV = (close - low_n) / (high_n - low_n) × 100
K = RSV 的 3 日 SMA（此处用 ewm 近似）
D = K 的 3 日 SMA
J = 3K - 2D

    def kdj(high: pd.Series, low: pd.Series, close: pd.Series, n: int = 9):
    """KDJ indicator: returns (K, D, J)."""
    low_n = low.rolling(n).min()
    high_n = high.rolling(n).max()
    rsv = (close - low_n) / (high_n - low_n) * 100

    # Chinese convention: SMA(x,3,1) == ewm with alpha=1/3
    k = rsv.ewm(alpha=1/3, adjust=False).mean()
    d = k.ewm(alpha=1/3, adjust=False).mean()
    j = 3 * k - 2 * d
    return k, d, j

df["K"], df["D"], df["J"] = kdj(df["最高"], df["最低"], close)

    一句话总结¶

    五个核心指标的代码模板：MA（rolling.mean）、EMA（ewm）、MACD（快慢EMA之差）、RSI（涨跌幅比）、BOLL（均线±2倍标准差）。手写一遍你就懂了每个指标在算什么——MA 看成本、EMA 看趋势、MACD 看动能、RSI 看过热、BOLL 看波动。TA-Lib 是进阶选项，安装麻烦，日线级别用 pandas 完全够。
