    策略开发实战¶

    完整走一遍：想法 → 规则 → 代码 → 回测 → 分析 → 防过拟合

    一、完整案例：双均线策略¶

    想法¶

    "金叉买、死叉卖"——最经典的入门策略，用它走完整个流程。

    规则化（无歧义）¶

    买入：MA5 上穿 MA20，次日开盘买入
卖出：MA5 下穿 MA20，次日开盘卖出
仓位：全仓（学习用，实盘别这么干）
标的：单只股票（沪深300 ETF 更稳）

    代码 + 回测¶

    用《回测框架》里的引擎：

    import pandas as pd
from itertools import product

df = pd.read_csv("600519_daily.csv", index_col="日期", parse_dates=True)

# run with default params
result = backtest_ma_cross(df, fast=5, slow=20)
report(result)

    ⚠️ 下面所有"示例结果"都是示意，自己跑出来的才算数。

    示意输出：
总收益率:   42.10%
年化收益:   12.80%
最大回撤:  -16.30%
夏普比率:    0.92
交易次数:   22

    结果分析四问¶

    1. 跑赢基准了吗？（对比同期沪深300/买入持有）
2. 钱是怎么赚的？（趋势段吃大肉，还是震荡市小赚累积？）
3. 亏在哪？（震荡市反复止损？单次大回撤？）
4. 逻辑还成立吗？（这个策略赚的钱有没有合理解释）

    💡 第 4 问最重要：说不清为什么赚钱的策略，大概率是过拟合。 双均线能解释：趋势行情中持有，震荡行情小亏离场——赚的是趋势的钱。

    二、参数敏感性：过拟合照妖镜¶

    把参数扫一遍：

    # parameter sweep
rows = []
for fast, slow in product([3, 5, 8, 10, 13], [20, 30, 40, 60]):
    if fast >= slow:
        continue
    r = backtest_ma_cross(df, fast=fast, slow=slow)
    ret = r["equity"].iloc[-1] / 100_000 - 1
    rows.append((fast, slow, round(ret, 3)))

print(pd.DataFrame(rows, columns=["fast", "slow", "total_return"]))

    怎么解读结果¶

    现象 结论
    参数邻域表现接近（都赚或都亏） 策略逻辑可能真实存在 ✓
    只有个别参数大赚，邻居全亏 过拟合，那组参数是运气 ⚠️
    所有参数都亏 策略本身不成立 
    过拟合的典型样子：
  MA(5,20)  +42%   ← 你选了这组
  MA(5,30)  -8%
  MA(8,20)  -3%
  MA(5,40)  -15%
  → 只有 (5,20) 赚钱 = 你挖到的是噪音，不是规律

    ⚠️ 调参调到历史完美 = 给未来挖坑。 好策略应该在参数邻域内表现平稳（参数高原，不是参数尖峰）。

    三、样本外验证¶

    全部数据：2015-2025
  ├── 训练集：2015-2021（调参、开发）
  └── 测试集：2022-2025（只跑一次，不许回头改参数）

    规则：

    train = df[df.index < "2022-01-01"]
test = df[df.index >= "2022-01-01"]

# develop & tune on train
result_train = backtest_ma_cross(train, fast=5, slow=20)

# ONE-shot evaluation on test, no re-tuning allowed
result_test = backtest_ma_cross(test, fast=5, slow=20)
report(result_test)
    • 训练集赚、测试集崩 = 过拟合实锤
    • 两个都赚（哪怕测试集少赚）= 策略有一定真实性

    💡 更严格的做法：滚动窗口（walk-forward）——每年用过去 5 年调参，测下一年，滚动前进。

    四、常见策略类型简介¶

    类型 核心逻辑 例子 特点
    趋势跟踪 涨了才买，顺势持有 双均线、突破、海龟 胜率低盈亏比高，震荡市亏
    均值回归 跌多了会反弹 网格、RSI 超卖 胜率高盈亏比低，单边下跌市亏
    网格交易 固定价位区间高抛低吸 ETF 网格 适合震荡的宽基 ETF，怕单边破网
    轮动策略 定期换到最强的标的 行业轮动、大小盘轮动 逻辑直观，换仓成本要算
    多因子选股 多个指标打分排序选股 ROE+低PE+动量 机构主流，散户可做简化版

    💡 新手第一个完整策略建议：宽基 ETF（沪深300）+ 趋势/网格， 比个股干净（无暴雷、无停牌、流动性好）。

    五、策略开发的完整检查清单¶

    □ 想法有逻辑解释吗？（赚的是什么钱）
□ 规则写成无歧义的 if-else 了吗？
□ 回测有没有 shift(1)？（防未来函数）
□ 算手续费和滑点了吗？
□ 和基准对比了吗？（跑赢指数才值得继续）
□ 参数敏感性如何？（是高原还是尖峰）
□ 样本外测试做了吗？（只测一次不回头）
□ 最大回撤你扛得住吗？
□ 模拟盘跟踪 ≥ 3 个月了吗？

    一句话总结¶

    策略开发五步：规则化 → 回测（防未来函数、算费用）→ 对比基准 → 参数敏感性（防过拟合）→ 样本外验证。过拟合是头号死因：参数调到历史完美 = 给未来挖坑，好策略的参数表现是高原不是尖峰。新手从宽基 ETF + 简单趋势/网格开始，说不清为什么赚钱的策略不要碰。
