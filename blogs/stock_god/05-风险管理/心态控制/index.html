    心态控制¶

    市场不会因为你焦虑就上涨，也不会因为你恐慌就放过你——情绪只伤害你自己

    一、贪婪与恐惧的具体表现¶

    对号入座时间：

    贪婪的样子¶

    • 追涨：涨了 5 个点冲进去，当天被套
    • 该止盈不止盈："还能涨"，坐电梯回到原点
    • 重仓单吊："这次稳了"
    • 借钱/加杠杆想一把翻身

    恐惧的样子¶

    • 杀跌：大跌时割在最低点附近
    • 不敢止损："再等等"，小亏拖成大亏
    • 踏空焦虑：没买到的天天涨，心态失衡后乱买别的
    • 回本执念：死守一只亏损股只等回本，无视更好的机会

    💡 注意这对矛盾：贪婪和恐惧经常同时存在—— 追涨时是贪婪，追完被套不敢卖是恐惧； 割肉时是恐惧，割完马上去追另一只是贪婪。

    二、几个有名有姓的心理陷阱¶

    1. 处置效应（最普遍）¶

    现象：赚的股票拿不住（急着落袋），亏的股票死扛（不愿认错）
正确：截断亏损，让利润奔跑
现实：截断利润，让亏损奔跑
    • 行为金融学反复验证：多数人卖盈利股的速度是卖亏损股的 1.5-2 倍
    • 对策：用规则代替感觉——盈利股用移动止盈持有，亏损股按止损位执行

    2. FOMO（错失恐惧）¶

    看到别人晒收益 / 某板块天天涨 → "再不上车就来不及了"
→ 冲进去 → 往往买在阶段高点
    • 真相：你"看到"赚钱效应时，往往行情已经走了大半
    • 对策：错过不是亏损。市场永远有下一个机会，本金亏完才是真出局

    3. 报复性交易¶

    大亏一笔 → 不甘心 → 当天加大仓位想赚回来 → 通常亏更多
    • 亏损后的你处于情绪化状态，判断力最差
    • 对策：强制冷静期（大亏后 3 天不交易，写进纪律）

    4. 锚定效应¶

    "它曾经到过 30 块" → 所以 15 块是"便宜"
真相：曾经的 30 块和现在的价值毫无关系
    • 对策：只看现在的逻辑值多少钱，忘掉历史最高价

    三、减少情绪干扰的实操方法¶

    1. 减少盯盘¶

    盯盘时间和情绪波动成正比：
  全天盯盘 → 每笔波动都牵动情绪 → 频繁手痒操作
  只看收盘 → 决策质量显著提升

建议：
  - 设价格提醒（到止损/目标价手机推送）
  - 提醒不响，不看盘
  - 盘中决策一律推迟到收盘后

    2. 情绪日记¶

    在交易日志里加一栏（《交易纪律》的模板里有）：

    交易时的情绪：□冷静 □兴奋 □焦虑 □FOMO □报复性 □无聊

    坚持一个月你会发现规律：亏钱的交易几乎都带着后四种标签。 这个发现本身就是最强的老师。

    3. 仓位是情绪的减压阀¶

    晚上睡不着 → 说明仓位太重
总想看盘 → 说明仓位超过你的承受力
降到"跌 10% 也无所谓"的仓位，情绪自然平稳

    4. 远离噪音源¶

    • 退掉荐股群（真赚钱的方法没人会免费分享）
    • 少看股吧（情绪放大器）
    • 警惕任何"老师带单"——那是杀猪盘的入口

    四、最重要的一条原则¶

    ⚠️ 只用亏光了也不影响生活的钱投资。

    • 用生活费炒股 → 每一笔波动都是生存压力 → 必然动作变形
    • 用闲钱 → 才能执行纪律、才能拿得住、才能睡得着

    这不是保守，这是让你能理性思考的前提条件。

    一句话总结¶

    情绪不能靠意志力消灭，只能靠机制隔离：少盯盘（用价格提醒）、记情绪日记（发现亏损交易的情绪标签）、大亏后强制冷静期、仓位降到睡得着的水平、远离荐股群噪音。记住处置效应是人性的出厂设置——赚的拿不住、亏的死扛——你的系统要专门和它对着干。最后：只用闲钱，这是所有心态控制的物理基础。
