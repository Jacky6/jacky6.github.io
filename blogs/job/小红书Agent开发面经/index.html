    小红书 Agent 开发岗位面经¶

    📌 岗位：小红书电商 B 端 AI Agent 开发
    📅 整理日期：2026-04-21
    🔑 核心方向：Agent / Multi-Agent / RAG / LLM 调优 / 多模态 AIGC

    一、岗位定位¶

    负责小红书电商 B 端场景 AI 能力建设，核心业务包括：

    • 商家智能助手
    • 商达撮合
    • 投广智能诊断
    • 商机挖掘
    • 商品智能发布
    • 直播 AI 助手
    • 内容电商 AIGC

    技术栈聚焦：Agent / Multi-Agent / RAG / LLM 调优 / 多模态落地

    二、核心考察方向（按权重排序）¶

    优先级 考察方向
    ⭐⭐⭐⭐⭐ AI Agent / Multi-Agent 实战能力
    ⭐⭐⭐⭐ LLM 调优、Prompt、RAG、SFT
    ⭐⭐⭐⭐ 多模态 AIGC（图文 / 视频 / 数字人）落地经验
    ⭐⭐⭐ 电商 B 端业务理解
    ⭐⭐⭐ 基础代码能力（工程向）

    三、高频面试题 & 参考答案¶

    1. Agent 基础与架构¶

    Q1：什么是 AI Agent？核心组件有哪些？

    AI Agent 是大模型驱动的自主执行单元，核心组件包括： - 感知：意图理解、上下文解析 - 规划（Planning）：任务拆解 - 记忆：短期 / 长期 / 向量库记忆 - 工具调用：API / 插件 / 执行引擎 - 执行与反思：ReAct / Reflexion 机制

    Q2：ReAct、CoT、Plan+Tool 区别是什么？

    方法 特点 适用场景
    ReAct 边思考边调用工具 复杂电商任务
    CoT 纯推理，不调用工具 逻辑推理、数学计算
    Plan+Tool 先拆解任务，再分步执行 批量商家操作

    Q3：常用 Agent 框架？

    LangGraph、LangChain、LlamaIndex。生产环境优先 LangGraph（可控性强、支持状态机）。

    2. RAG、记忆、工具调用¶

    Q1：RAG 怎么做？如何优化？

    标准流程：文档切分 → 向量化 → 检索 → 重排 → 生成

    优化点： - 按业务语义切块（而非固定长度） - 多路召回 + 交叉编码器重排 - 动态上下文管理 - 构建商家专属知识库

    Q2：Agent 记忆如何设计？

    记忆类型 内容 实现方式
    短期记忆 对话上下文 对话历史窗口
    工作记忆 任务状态、中间结果 运行时状态机
    长期记忆 商家档案、商品信息 向量库 + 索引

    控制长度：用 索引 + 摘要 + 检索 机制

    Q3：工具调用失败如何解决？

    • JSON Schema 强校验
    • 重试 + 降级策略
    • 参数合法性检查
    • 反思机制：失败 → 修正 → 重试

    3. Multi-Agent 多智能体¶

    Q：多个 Agent 如何协同？

    • 按业务拆分：商家助手、商品发布、投广诊断、直播助手
    • 通信机制：消息总线、共享内存、中心化调度
    • 调度模式：主从架构、任务路由、冲突消解

    4. LLM、SFT、Prompt¶

    Q1：Prompt 优化技巧？

    结构：角色定义 → 上下文 → 约束条件 → 输出格式 → 少量示例

    电商场景需明确：商家身份、商品信息、业务规则

    Q2：什么时候用 SFT，什么时候用 RAG？

    方案 适用场景
    SFT 通用能力 / 格式规范
    RAG 私有知识 / 实时信息
    RAG + SFT 复杂业务（结合使用）

    5. 多模态 AIGC（小红书必考 🎯）¶

    Q：图文 / 视频生成如何落地电商？

    • 商品图 → 标题 / 文案 / 标签生成
    • 多模态 RAG（图文联合检索）
    • 内容成片、故事化视频、直播数字人
    • 合规、风格、质量统一控制

    6. 电商 B 端业务题（小红书特色）¶

    Q1：商品智能发布助手怎么做？

    全链路：理解商品 → 生成文案 → 选图 → 优化标签 → 预览 → 发布 → 数据反馈 → 迭代

    用 Agent 实现全链路自动化

    Q2：投广智能诊断怎么做？

    拉取投放数据 → 异常分析 → 原因定位 → 给出优化建议 → 自动调整

    用 RAG + 规划 + 工具调用实现

    Q3：商机挖掘 Agent 怎么设计？

    市场监控 → 机会识别 → 策略推荐 → 自动触达

    由 数据 Agent + 分析 Agent + 触达 Agent 协同完成

    四、代码题¶

    考察范围：工具调用参数校验等工程向代码题，无偏题怪题，偏向实际应用。

    五、面试流程¶

    轮次 内容
    一面 基础能力 + 代码 + Agent 基础
    二面 系统设计 + 多模态 + 业务落地
    三面 业务深度 + 团队匹配

    六、备考建议 💡¶

    1. 重点准备 Agent 实战经验 — 这是最高权重，要有真实项目可以讲
    2. 熟悉 LangGraph — 生产环境首选，要能讲清楚状态机设计
    3. RAG 优化是必考 — 不能只停留在基础流程，要知道切块策略、重排、上下文管理等
    4. 多模态 AIGC — 小红书特色，图文/视频生成要能说清落地方案
    5. 电商 B 端场景理解 — 结合具体业务场景（商品发布、投广诊断、商机挖掘）给出方案
    6. 代码准备 — 工具调用校验、API 封装等工程题，刷 LeetCode 不如刷实际场景
