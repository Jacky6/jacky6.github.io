    01 - 核心概念¶

    什么是 Kafka¶

    Kafka 是一个分布式事件流平台（Distributed Event Streaming Platform），三大能力：

    1. 发布/订阅消息系统（像 RabbitMQ）
    2. 持久化消息流（像数据库）
    3. 实时处理流数据（像 Flink/Storm）

    版本现状（2026-08）：当前最新为 Kafka 4.3.x。4.0 起彻底移除 ZooKeeper， 只支持 KRaft 模式；4.2 起 Share Groups（KIP-932，Kafka 原生队列语义）GA。 新集群直接上 4.x，不要再学 ZooKeeper 部署了。

    核心术语¶

    Broker¶

    Kafka 集群中的一个服务器节点。一个集群通常有 3+ 个 Broker。

    Topic（主题）¶

    消息的逻辑分类，类似数据库的"表"。 - 生产者往 Topic 写数据 - 消费者从 Topic 读数据

    Partition（分区）¶

    Topic 的物理分片，是 Kafka 并行度的基本单位。

    Topic: orders
├── Partition 0  →  Broker 1
├── Partition 1  →  Broker 2
└── Partition 2  →  Broker 3

    关键点： - 分区内消息有序 - 分区间消息无序 - 一个分区只能属于一个 Broker（Leader）

    Message（消息）¶

    Kafka 中最小的数据单元：

    ┌─────────┬──────────┬──────────┬──────────┐
│  Key    │  Value   │ Headers  │ Timestamp│
└─────────┴──────────┴──────────┴──────────┘
    • Key：可选，用于决定消息路由到哪个分区
    • Value：消息体，最大 1MB（默认）
    • Headers：元数据，键值对
    • Timestamp：消息时间戳

    Offset（偏移量）¶

    每条消息在分区内的唯一序号，从 0 开始递增。

    Partition 0:
[0] msg_a  [1] msg_b  [2] msg_c  [3] msg_d
                                    ↑
                              consumer 读到这里

    Consumer Group（消费者组）¶

    一组消费者共同消费一个 Topic：

    Topic: orders (3 partitions)

Consumer Group A:
  ├── Consumer A1 → Partition 0
  ├── Consumer A2 → Partition 1
  └── Consumer A3 → Partition 2

Consumer Group B:  （独立消费，互不影响）
  ├── Consumer B1 → Partition 0
  ├── Consumer B2 → Partition 1
  └── Consumer B3 → Partition 2

    规则： - 一个分区只能被组内一个消费者消费 - 消费者数 > 分区数 → 部分消费者空闲 - 消费者数 < 分区数 → 部分消费者消费多个分区

    Producer（生产者）¶

    向 Kafka 发送消息的客户端。

    Consumer（消费者）¶

    从 Kafka 读取消息的客户端。

    快速理解数据流¶

    Producer ──→ Topic ──→ Consumer Group ──→ Consumer
              │
              ├── Partition 0 (有序)
              ├── Partition 1 (有序)
              └── Partition 2 (有序)

    与 C++/Java 类比¶

    Kafka 概念 类比
    Topic 数据库表 / Java 的 List<Message>
    Partition 哈希分桶 / C++ 的 unordered_map 分片
    Offset 数组下标 / 文件指针
    Consumer Group 线程池消费任务队列
    Broker 分布式节点 / RPC Server

    快速上手（Docker 单节点）¶

    Kafka 官方镜像 apache/kafka 默认就是单节点 KRaft 模式，开箱即用：

    # 启动（无需 ZooKeeper）
docker run -d --name kafka -p 9092:9092 apache/kafka:4.2.0

# 创建 Topic
docker exec kafka /opt/kafka/bin/kafka-topics.sh create \
  --bootstrap-server localhost:9092 \
  --topic quickstart --partitions 3 --replication-factor 1

# 生产消息（Ctrl+C 退出）
docker exec -it kafka /opt/kafka/bin/kafka-console-producer.sh \
  --bootstrap-server localhost:9092 --topic quickstart

# 消费消息
docker exec -it kafka /opt/kafka/bin/kafka-console-consumer.sh \
  --bootstrap-server localhost:9092 --topic quickstart --from-beginning

    小结¶

    • Kafka 本质是分布式日志
    • Topic 是逻辑概念，Partition 是物理概念
    • 分区内有序，分区间无序
    • Consumer Group 实现消息的"广播"或"负载均衡"；Share Group（4.2+）实现队列式"竞争消费"
