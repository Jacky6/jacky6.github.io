    Git 速查表¶

    打印出来贴墙上，或者设为浏览器首页。

    日常操作¶

    操作 命令
    初始化仓库 git init
    克隆仓库 git clone <url>
    查看状态 git status
    添加到暂存 git add . / git add <file>
    提交 git commit -m "message"
    修改上次提交 git commit --amend
    推送 git push / git push -u origin <branch>
    拉取 git pull / git pull --rebase
    抓取（不合并） git fetch

    分支¶

    操作 命令
    列出分支 git branch
    创建分支 git branch <name>
    创建并切换 git switch -c <name> / git checkout -b <name>
    切换分支 git switch <name> / git checkout <name>
    删除本地分支 git branch -d <name>
    强制删除 git branch -D <name>
    删除远程分支 git push origin --delete <name>
    重命名分支 git branch -m <old> <new>

    合并 & 变基¶

    操作 命令
    合并分支 git merge <branch>
    合并（禁止快进） git merge --no-ff <branch>
    变基 git rebase <branch>
    交互式变基 git rebase -i <base>
    中止合并 git merge --abort
    中止变基 git rebase --abort
    继续变基 git rebase --continue

    撤销 & 回退¶

    操作 命令
    丢弃工作区修改 git restore <file> / git checkout -- <file>
    取消暂存 git restore --staged <file> / git reset HEAD <file>
    撤销 commit 保留修改 git reset --soft HEAD~1
    撤销 commit 取消暂存 git reset HEAD~1
    撤销 commit 丢弃修改 git reset --hard HEAD~1
    反转提交（安全） git revert <commit>
    强制推送 git push --force-with-lease

    历史 & 搜索¶

    操作 命令
    查看日志 git log
    简洁日志 git log --oneline --graph --all
    查看 diff git diff / git diff --staged
    查看 blame git blame <file>
    搜索提交信息 git log --grep "keyword"
    搜索代码 git grep "keyword"
    查找引入 bug 的 commit git bisect start → bad → good
    后悔药 git reflog

    远程¶

    操作 命令
    查看远程 git remote -v
    添加远程 git remote add origin <url>
    修改远程 URL git remote set-url origin <url>
    推送标签 git push --tags
    清理远程引用 git fetch --prune

    暂存 & 清理¶

    操作 命令
    暂存 git stash / git stash save "msg"
    查看暂存 git stash list
    恢复暂存 git stash pop / git stash apply
    清理未跟踪文件 git clean -fd
    预览清理 git clean -n

    标签¶

    操作 命令
    创建标签 git tag -a v1.0 -m "message"
    列出标签 git tag
    推送标签 git push origin v1.0
    删除标签 git tag -d v1.0

    其他¶

    操作 命令
    挑选提交 git cherry-pick <commit>
    工作区列表 git worktree list
    创建工作区 git worktree add <path> <branch>
    移除工作区 git worktree remove <path>
    导出归档 git archive --format=zip -o out.zip main
    子模块更新 git submodule update --init --recursive
    垃圾回收 git gc
    仓库检查 git fsck

    实用别名¶

    [alias]
    st = status -s
    co = checkout
    br = branch
    ci = commit
    lg = log --oneline --graph --all --decorate
    last = log -1 HEAD --stat
    who = shortlog -sn --
    unstage = reset HEAD --
