    3.1 Claude Code v2.1.323：实验性 Code Mode¶

    • 日期：2026-11-12 | 来源：Claude Code Releases

    4.1【补遗】CAMP-II：文件即记忆的 On-Policy 蒸馏训练¶

    • 提交：2026-11-10 | arXiv:2611.14009
    • CAMG（首期 §4.6 覆盖过）的续作：CAMG-II 环境套件 + CAMP-II，用全异步 on-policy 蒸馏让单一策略学会以「文件即记忆」跨上下文存取，增益达最强 OPD 基线的 2.97 倍，泛化到 Terminal-Bench 2.1 / SWE-Bench Pro V2（40 页长文）。
    • 关注：「记忆动作纳入策略」训练范式的硬核续作——记忆主线从设计模式走向训练方法。

    4.2【补遗】Dependable Long-Horizon LLM Agents：错误从哪进、哪种控制拦得住¶

    • 提交：2026-11-09 | arXiv:2611.13254
    • 对 Who&When/MAD 语料 95 条多智能体失败轨迹全文标注：72% 的失败轨迹中早已存在反驳证据但 88% 无人理会；45% 手工构造失败实为 provider 内容过滤崩溃。
    • 关注：长程 agent 可靠性的归因协议（错误进入点 × 控制拦截率），可直接复用到本库 concepts/06 的可靠性讨论。

    4.3【补遗】Veritas：自动生成 Agent 任务 Verifier 的 Harness¶

    • 提交：2026-11-09 | arXiv:2611.13336
    • 自动生成任务 verifier 的 harness（证据头 + 领域规则库 + 自我改进的创作原则），在 4 个执行评分基准上与官方裁决一致率优于 7 种现有 harness。
    • 关注：自改进系统的「裁判从哪来」问题——对 agentic RL 奖励工程有直接参考价值。

    4.4【补遗】Personalized Memory Rubrics：逐用户的记忆 Credit Assignment¶

    • 提交：2026-11-10（WSDM 2027） | arXiv:2611.14017
    • 把终端反馈经 rubric 分解为逐 step、逐用户的细粒度 credit assignment，rubric 与记忆策略闭环共演化，部署零额外开销。
    • 关注：个性化 agent 记忆「学什么、记什么」的训练信号新解法。

    候补：TreeAgent（层级结构感知记忆，处理 8K~1M token 结构化数据，浙大）。
