    4. 学术前沿¶

    「Wed, 11 Nov 2026」批次已上架（cs.MA 10 条 + cs.AI 248 条，全量分页扫描）；入选 7 篇均为 2026-11-10 提交，逐篇核实 abs 页。

    4.1 Agent Benchmarks Stop Ranking Before They Run Out of Tasks¶

    • 提交：2026-11-10 | arXiv:2611.13541
    • 重评 SWE-bench Verified、Terminal-Bench、MLE-bench、ALE-Bench 等 8 个基准的公开运行记录：「饱和」很大程度出在测量而非任务——单 bit pass/fail 太粗（邻近 top-10 差异小于测试自身误差）、以参考解为上限（ALE-Bench 近半数运行超过中位人类却并列）。提出带日期锚点的截断对数比分 + 成本独立轴；Terminal-Bench 重跑中 pass/fail 并列的模型在被丢弃的量化指标上相差超 10 倍。
    • 关注：直接影响如何解读所有「榜单打满」新闻，与《Benchmarks as Software》（11-09 期）组成基准反思双璧。

    4.2 Agency 之后的服务侧：前缀缓存 Agent 服务的亚稳态崩溃¶

    • 提交：2026-11-10 | arXiv:2611.13412
    • 揭示前缀缓存的 agent 服务是亚稳态的：几分钟额外突发即可让 vLLM 落入命中率 ~10%、吞吐减半、积压持续 70 分钟的退化态（12 对中 9 对复现，SGLang 同样出现）；限流新会话基本无效，暂停已准入会话 + 容量上限可数分钟内恢复；无需调参的 KV 预算器在所有测试运行中阻止了崩溃。
    • 关注：agent 工作负载（上下文每轮增长、闭环会话）击穿推理服务的机制级分析与可落地修复——agent 基础设施规模化的关键一课。

    4.3 WikiTrace：给经验记忆装上「出处溯源」¶

    • 提交：2026-11-10 | arXiv:2611.14320（ACL ARR 在审）
    • 指出经验蒸馏式记忆会引发「记忆诱导退化」（agent 做错本能做对的任务），根因是教训与来源轨迹脱钩。WikiTrace 将每条教训链接到成败原因摘要与原始轨迹，细节不足/相互冲突/来自失败任务时沿链接下探取证再行动；5 个 agent 基准上持续优于现有记忆方法（代码开源）。
    • 关注：直击经验记忆可信性痛点，与 Anthropic「dreaming 拿 transcript 当 ground truth」思路同源。

    4.4 FGSE：记忆写入的可证伪准入门控¶

    • 提交：2026-11-10 | arXiv:2611.14326
    • 把「经验是否写入持久状态」建模为假设检验：每条候选教训带前置条件、行为变更、预期效果与验证器，先在临时状态中对迁移/证伪/回归三类探针测试，再决定提交/精炼/拒绝。WebArena 39.8、AppWorld 78.8，有害写入降至 3.6%。
    • 关注：与 WikiTrace 互补，从「准入门槛」侧给出可证伪的记忆自进化框架——agent 自我改进安全性的新基线。

    4.5 ReTrace：把工具型 Agent 蒸馏成无规划器工作流¶

    • 提交：2026-11-10 | arXiv:2611.14492
    • 从 agent 工具调用附带的推理说明中抽取条件、跨运行合并为紧凑规则文档，再编译为「由代码而非 LLM 选下一步」的可执行流程。79 个生产流程上完成率 93.8%（agent 96.8%）且单任务成本降 24%；τ²-Bench 单次 1.3 秒（agent 170 秒）。
    • 关注：量化回答「重复性业务流程还需不需要每步过 LLM」——agent→workflow 蒸馏的实用路径。

    4.6 Contrastive Discovery：科学发现 Agent 的「对比集」机制¶

    • 提交：2026-11-10（NeurIPS 2026） | arXiv:2611.14514
    • 针对发现型 agent 逐点检验假设（h vs ¬h）导致「只知否定、不知何者可信」的问题，把科学问题配上一组互斥且穷尽的竞争解释，按实验对信念的重新分配评分。六个领域上对比集将 73% 被否决候选解析到具体替代解释，同预算多解决 67% 问题；38 位专家盲评一致率 78%。

    4.7 PARLEY：信息不对称合作谜题评估多 Agent 协作¶

    • 提交：2026-11-10 | arXiv:2611.14242
    • 四类信息不对称合作谜题（指称沟通、联合协调、视角采择、空间推理）；GPT-4o 对 400 局成功率 60.5%，归纳 PAC 失败分类（感知/适应/协调），「不采纳外部反馈」是失败关键信号，按分类引导干预可将成功率提升至 70.5%。

    候补：Synapse-Control（经验复用的轻量运行时控制面，1.7B 分类器，AppWorld/WebShop +29.8%）。
