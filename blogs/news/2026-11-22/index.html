    4.1【补遗】CompAct-Bench：上下文压缩对长程任务的下游影响（复旦 NLP 组）¶

    • 提交：2026-11-19 | arXiv:2611.25673
    • 首个系统评测「工作上下文压缩 → 长程 agent 任务完成率」的 benchmark（BrowseComp / SWE-bench / 自建 CompanyBench，统一 retention ratio 公平比较）。关键发现：即使前沿模型，激进压缩下任务准确率显著退化；失败主因常是任务状态失真（未决问题被写成"已结论"、遗忘已建立结果）而非单纯信息遗漏。
    • 关注：上下文工程主线（CarryOn、SUMONE 之后）的测量基础设施。

    4.2【补遗】Pandora's Toolbox：Agent 安全为何不可判定¶

    • 提交：2026-11-19 | arXiv:2611.25325
    • 理论结果：LLM + 通用计算设备的耦合使 agent 安全不可判定；guardrails/黑白名单/认证注定不完备；有限约束下可判定但 PSPACE-complete；且安全性不可组合——各自安全的 agent 组合后仍可能不安全。
    • 关注：agent 安全治理的理论基线，与本周密集的安全实证（SEAM、risky fallback、AGENTS.md 投毒）形成「理论上限」对照。

    • 日期：2026-11-20 | 来源：Anthropic 官方公告

    • 关注：七大芯片/云厂商同时入股是新增量——Anthropic 与算力供应链深度绑定。

    5.2 Anthropic×Theorem：Claude 为 123 个开源库写出汇编级安全证明¶

    • 日期：2026-11-20 | 来源：Anthropic Research
    • Claude 自主为 OSS-Fuzz 的 123 个库、239 个 fuzz 入口证明「任意 <64MB 输入不崩溃」，产出约 1.8 亿行 Rocq 证明，途中发现并修补潜伏多年的 bug（含 libexpat CVE-2026-56132）；多 Agent 共享工作区复用证明省 17% token；证明与语义已开源。
    • 关注：与黎曼猜想新闻（上期）同源不同事——Agent 自主形式化验证首次在生产级软件规模化。

    5.3 前 DeepSeek V1 作者 Tony Zhang 创业：开源本地 Personal Agent「Linger」¶

    • 日期：2026-11-21 | 来源：量子位
    • Simplex AI 发布 Linger：直接操作已登录的浏览器/邮箱/日历，本地记忆中枢（LoCoMo 95%，超 Mem0/MemOS），「隐式强化」从反馈自学规则，可组 Agent 团队；自研 PolyStrata MoE 分层推理引擎，12GB RTX 3060 跑 125B 的 Qwen3.8-Flash-Next（45.5 tokens/s）。
    • 关注：DeepSeek 系人才外溢；「数据不出本机、不按 token 付费」的 Personal Agent 本地化路线标志性项目。

    5.4 MachinePulse 开源 Karpo Decision 31B + karpo-browser¶

    • 日期：2026-11-21 | 来源：量子位
    • 0.8B~31B 六款决策模型（Decision Index 总榜 73.9 分登顶，中位响应 94ms）；System1+System2 浏览器 Agent 框架 + 27B Act 模型 + KBB 评测集；Browserbase Benchmark v2 上 89% 成功率、单任务 $0.096，比 Claude Fable 5.2+Claude Code 快 1.9 倍、成本 1/13，可经 MCP 接入 Claude Code/Codex。
    • 关注：「决策模型」作为 Agent 独立一层开源落地——从 TypeSafe AI 到 Gemini Decisions API 再到开源实现，赛道完整。

    5.5 腾讯元宝×KCL 发布 GroupAssistBench：首个真实群聊 Agent 记忆基准¶

    • 日期：2026-11-21 | 来源：量子位（arXiv:2611.04867，代码/数据集开源）
    • 50 个真实群聊、80,299 条消息、2,395 题，区分「记忆召回（L1）」与「记忆服务（L2）」；发现外部记忆系统「更会回忆 ≠ 更会服务」，36% 已召回记忆根本没进入服务输入——戳破记忆「记得住≠用得好」。
