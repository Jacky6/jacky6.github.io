    1. 框架与工程实践¶

    1.1 deepagents 0.7.33/0.7.34 + deepagents-code 0.2.5 连发¶

    • 日期：2026-11-05 | 来源：deepagents Releases
    • 0.7.33：默认对模型拒答抛错并向父 agent 上报子 agent 拒答，rubric 中间件移出 beta，异步子 agent 通知增加元数据；0.7.34 修复 summarization 截断锚定；deepagents-code 0.2.5 让 compaction 输入预算匹配所选模型。
    • 关注：拒答处理与压缩稳定性持续打磨，配合 langchain 1.4.9 形成跨包一致的拒答语义。

    1.2 langchain 1.4.9 + core 1.7.6 + typesafe 0.0.2¶

    • 日期：2026-11-04/05 | 来源：langchain Releases
    • 1.4.9 标准化模型拒答（refusal）内容块（要求 core≥1.7.5）；core 1.7.6 优化流式 chunk 合并与 parse_partial_json 性能；typesafe 0.0.2 实验中间件接受 classifier 参数。
    • 关注：模型拒答成为一等公民内容类型。

    1.3 官方叙事：LangChain 博客《Agents Are Going Async》¶

    • 日期：2026-11-05 | 来源：LangChain 博客

    4. 学术前沿¶

    本期均为 2026-11-04 提交、11-05 上架的新论文，已逐篇打开 abs 页核实；arXiv API 当日 429，改用列表页 + 网页高级搜索检索。

    4.1 Baya：「编译后执行」范式同时提升 Web Agent 安全性与效用¶

    • 提交：2026-11-04 | arXiv:2611.06039
    • UC Berkeley（Raluca Popa、David Wagner 等）：先把用户请求编译成调用 Trusted Website API 的 Python 程序再执行，规划模型全程看不到网页内容，从设计上免疫提示注入导致的控制流劫持。WebArena Verified 效用 77.8%（ReAct 55.1%），WASP 安全基准攻击成功率 0%（ReAct 25.5%）。
    • 关注：少见地同时提升安全性与效用的架构，「compile-then-execute」或成安全 agent 新范式。

    4.2 LifeVal：OpenAI 发布个性化 Agentic 消费任务基准¶

    • 提交：2026-11-04 | arXiv:2611.06687
    • OpenAI（含 Noam Brown）：基于 3800+ 人支付意愿调查覆盖 148 类生活任务（理财、搬家、求职、育儿等，对应年支付意愿超 1.7 万亿美元），任务用真实 ChatGPT 对话与记忆个性化构造，经三轮人工质控。
    • 关注：头部实验室对「个人超级助理」价值量化与评测标准的定调之作，与产品端 Personal Finance 同日呼应。

    4.3 HarnessFlow：MCTS 自动搜索 Agent Harness¶

    • 提交：2026-11-04 | arXiv:2611.06254
    • 固定模型与任务环境，用 MCTS 在 refinement tree 上自动搜索完整可执行 harness（coding agent 负责改写）；6 个基准平均 69.48%，比初始 harness 高 10.89 个点、比 Meta-Harness 高 3.95 个点且执行成本更低。
    • 关注：「优化 harness 而非模型」方向出现结构化、预算可控的自动搜索方案——与产业侧 harness 化趋势互为印证。

    4.4 Latent Context Compression：工具输出不必以文本进上下文¶

    • 提交：2026-11-04 | arXiv:2611.06500
    • 将工具观测压缩为 latent token 嵌入 agent 输入空间，Action-Preserving Training 对齐压缩前后下一动作分布；web 搜索 agent 上 token 消耗降 70~89%、端到端耗时降 24~56% 且性能不降反升（清华，代码已开源）。
    • 关注：连续潜空间压缩可能成为长程 agent 降本新路径。

    4.5 Turn-Level Best-of-N：回合级推理时扩展¶

    • 提交：2026-11-04 | arXiv:2611.06868
    • 每步由 generator 生成 N 个候选动作、selector 选一个执行，长程终端任务准确率提升 5~10% 且多次尝试更一致；轨迹分析显示调试、测试、指令遵循行为改善（Eric Xing 等）。
    • 关注：开源权重模型做 turn 级自选即可免费获得 agent 推理扩展收益。

    4.6 SUMONE：即插即用的 Agent 记忆摘要器¶

    • 提交：2026-11-04 | arXiv:2611.06445
    • 「掩码重建」自监督训练独立摘要器：以重建质量 + 长度惩罚作 GRPO 奖励，无需参考摘要或下游任务执行；DeepSearchQA / SWE-bench Verified 推理成本分别降约 78%/75%，同一 checkpoint 可跨模型、跨 harness 即插即用。
    • 关注：agent 记忆压缩走向任务无关、可迁移的通用组件。
