    4. 学术前沿¶

    「Fri, 20 Nov 2026」批次已上架（北京时间 08:00 核实），本期正常覆盖（主体为 11-19 提交）；7 篇均逐篇核实 abs 页。

    4.1 How Much Should an Agent Remember?：自蒸馏记忆的部署实战（IBM，IAAI 2027 Oral）¶

    • 提交：2026-11-19 | arXiv:2611.26361
    • 从 agent 自身轨迹挖掘「教训」合并为带计数的指南（已开源 altk-evolve，部署于 CUGA agent 与 watsonx Orchestrate）；核心发现「该记多少取决于模型而非记忆」：强模型 DeepSeek-V3.2 用全部 191 条指南 +9.5 分，弱模型 gpt-oss-120b 反而用约 29 条精选子集更优（55.4% vs 51.2%）。
    • 关注：少有的记忆部署实战教训，含大量失败案例分析——记忆容量应按模型能力标定。

    4.2 Beyond Weight Updates：冻结权重、进化 Harness 做领域适配¶

    • 提交：2026-11-19 | arXiv:2611.25380
    • 冻结权重，把 harness（系统提示、工具 schema、技能库、规划脚手架）当 RL 式外层优化对象（GEPA 反射式进化）；SWE-bench Verified/OfficeBench/Terminal-Bench 上以极小算力恢复权重更新的大部分收益，二者结合最优，且规避 SFT 导致的推理链变短问题。
    • 关注：「改 harness 而非改权重」的垂直领域适配路径——与 ModHarness-RL、Agency 主线持续推进。

    4.3 无反馈自我改写技能的反例研究 + SkillDiff 修复¶

    • 提交：2026-11-19 | arXiv:2611.25534
    • 系统研究「无反馈自我改写技能文档」：30 轮后所有模型在 SkillsBench 上平均掉 15 分——改写会把技能拉向模型先验、先丢掉先验之外的知识；SkillDiff 原地标注「模型自己写不出来的知识」，零反馈平均 +4.8 分。
    • 关注：给「Agent 技能自我进化」叙事的反例证据与可操作修复（开源）。

    4.4 TwinLab-Bench：实验室数字孪生作环境的 AI 科学家基准¶

    • 提交：2026-11-19 | arXiv:2611.26248
    • 52 个任务覆盖物理/化学/生物湿实验/材料/工程，TwinLab agent 充当环境执行被测 agent 设计的实验并对照真实实验室记录评分；最强模型 Claude Fable 5.2 仅 45.0 分——「实验室数字孪生 agent 作环境」的新评测范式，对前沿模型区分度高。

    4.5 DriftGuard：记忆漂移的在线因果归因检测¶

    • 提交：2026-11-19 | arXiv:2611.25583
    • 离线用成对反事实回放构建因果监督（记忆漂移分数 MDS），在线阶段仅从动作前信息估计风险、标记致漂移记忆，无需在线反事实滚动——把「哪条记忆导致 agent 跑偏」做成可在线部署的检测器（接 MemoryDojo 攻击面主线）。

    4.6 AutoMaster：Agent 自主完成后训练闭环（人大 RUCAIBox）¶

    • 提交：2026-11-19 | arXiv:2611.26510
    • Skill-FT：LLM agent 自主完成轨迹分析、技能设计、数据筛选与反馈迭代，用自然语言技能抑制教师 rollout 不良习惯；4B/9B 目标模型较 Vanilla SFT 提升 1.42~8.99 个百分点；发现 SFT 时保留技能指令反而更好（代码/模型/网站全开）。

    4.7 BuggyMLE：MLE 基准难度可控扩展¶

    • 提交：2026-11-18（UTC，边界情况已标注） | arXiv:2611.25088
    • 代码复杂度指数 CCI（对 8 个公开编码基准解题率预测 R²=0.951）+ agent 向仓库注入受控 bug 合成 6600+ 变体；14 个模型在最难档解题率从 95% 跌至 9%；三级课程微调 Qwen3.5-9B 逼近前沿模型并迁移提升 SWE-bench Lite（24%→33%）。
