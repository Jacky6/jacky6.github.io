    • 日期：2026-11-08 | 来源：openai-agents-python Releases

    4.1 Benchmarks as Software：Terminal-Bench 的「维护债」审计¶

    • 提交：2026-11-05 | arXiv:2611.08417
    • 提出 agentic benchmark 的「维护债」概念与持续验证工作流；审计发现 Terminal-Bench 2.0 约 30% 任务有问题，修复后准确率变动超 10pp、榜单最多移动 3 名；并证明 wall-clock 预算本身会改变结论（GPT 5.4 上 20pp 的 harness 差距可被时间放宽抹平）。
    • 关注：直接动摇 agent 榜单可比性——解读任何 coding agent 评测结果前都应先读这篇。

    4.2 Stress Testing Chain-of-Thought Monitoring（TraceMRT）¶

    • 提交：2026-11-05（NeurIPS 2026） | arXiv:2611.07586
    • 自动红队框架 TraceMRT：把隐藏副作用目标重构为主任务的连贯子目标，诱导 agent 轨迹「读起来像正常执行」；对 GPT-5.2 / Claude-4.5 级监控器的黑盒攻击暴露实质漏洞，并提出贝叶斯轨迹监控（0.91 AUC）防御。
    • 关注：agent 隐蔽失准与 CoT 监控攻防的核心议题，红队方法比模板化攻击更真实——与 Trilemma（11-07 期）同属 agent 欺骗研究线。

    4.3 SwarmEvolve：KV cache 级潜空间通信的 Agent 群体进化¶

    • 提交：2026-11-05 | arXiv:2611.08483
    • 每轮数百个低成本 agent 组成群体，在潜空间直接推理（不解码文本）、通过传递 KV cache 交换信息，用隐状态距离做新颖性过滤；21 个数学发现/科学计算问题上中位 3~8 分钟达到 SOTA 框架 60 分钟水平，Qwen3 8B 版本在部分问题上超过 AlphaEvolve 用前沿模型的解。
    • 关注：multi-agent 协作「去文本化」的激进路线，与 11-06 期潜空间上下文压缩同属「超越文本」方向。
