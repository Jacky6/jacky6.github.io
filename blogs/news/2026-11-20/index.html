    1. 框架与工程实践¶

    1.1 ⚠️ Microsoft Agent Framework PyPI 包遭供应链投毒（本期头条）¶

    • 日期：2026-11-17 晚（报道 11-18） | 来源：Wiz 披露 · GHSA-764m-3ppc-5m73
    • PyPI 官方包 agent-framework 被劫持发布恶意版本 1.26.1/1.26.2（相隔 33 分钟），通过 .pth hook 在每次 Python 启动时窃取 Azure/Azure DevOps/GitHub Actions 凭据；该包月下载量约 19.2 万。恶意版本已被 PyPI 隔离，最新回退至 1.26.0。
    • 上期 404 之谜揭晓：github.com/microsoft/agent-framework 确认 404 且无重定向，候选新地址均不存在——仓库疑似因投毒事件被下架/转私有；PyPI 页确认已回退。
    • 关注：主流 Agent 框架首次遭遇官方包供应链攻击，直接影响 CI/CD 环境凭据安全——所有近期装过 agent-framework>=1.26.1 的环境都应轮换凭据。

    1.2 Google ADK v2.15.0：Maps 工具集 + BigQuery 跨项目发现¶

    4. 学术前沿¶

    「Thu, 19 Nov 2026」批次已正常上架（北京时间 08:00 核实）；入选 8 篇均为 11-17 晚~11-18 提交，逐篇核实 abs 页。

    4.1 AnyS1：技能文档炼出通用 System-1，Agent 成本降 75~91%¶

    • 提交：2026-11-18 | arXiv:2611.23751
    • 把 1000+ 个人类编写的技能文档挖掘为领域通用的「决策点」数据集 Any-DP，训练单个 4B 指针型 System-1 模型一次性前向解决常规决策、低置信度回退 System-2；3 个未见基准上保持可靠性，episode 成本降 75~91%、模型调用时间降 63~92%。
    • 关注：双系统 Agent 首次摆脱逐环境手写 hook——「技能文档→决策点」的通用化降本路径。

    4.2 GUARD：用方向性 Regret 稳住递归自我改进（Google Cloud AI）¶

    • 提交：2026-11-17 晚 | arXiv:2611.23476
    • 无评分器的 RSI 闭环：任务分解为执行前自检，用方向性 regret 区分「新改坏的」与「一直没解决的」，Soft-HURT 门控只在收益大于回退时晋级编辑——直指自改进 agent 最痛的「越改越差/技能遗忘/记忆膨胀」（Chen-Yu Lee 等，38 页）。
    • 关注：与 11-19 期 Resolution Hypothesis（识别改进难）互补：一个给诊断、一个给门控机制。

    4.3 Where the Tokens Go：Coding Agent 的「软件热力学」¶

    • 提交：2026-11-17 晚 | arXiv:2611.23375（Aspuru-Guzik 跨界）
    • token 成本分为功与热，测试套件是软件版麦克斯韦妖；成功 run 约 80% token 是「热」，改动自由能仅为平均成本的 14~22%——coding agent 成本分析的可量化理论框架，话题性极强。

    4.4 ARISE：自进化记忆跑赢 GEPA 且更省 token¶

    • 提交：2026-11-17 晚 | arXiv:2611.23588
    • 不动权重/工具/流程：归因失败→存为微记忆→固化为宏规则（held-out 验证通过才接受）；SOP-Bench/τ²-bench 14 个企业域提升 10.9pp/5.8pp 且调用数与 token 反而更少。

    4.5 Vanguard：看截图的免训练步级投机判定¶

    • 提交：2026-11-18 | arXiv:2611.23917
    • 决策模型看屏幕截图给每个候选步打分，2B 草稿模型在 web/手机/具身 agent 上至少追平 8B 目标模型；校准阈值可零样本迁移到新网站——投机解码升级为「看截图选对步」。

    4.6 Depth Before Breadth：反向课程 + 优势分解解长程 RL 信用分配¶

    • 提交：2026-11-18 | arXiv:2611.24697
    • 「策略能力域」概念 + 成对 advantage 分别监督「到达更可解状态」与「从该状态完成任务」；ALFWorld/WebShop 上 Qwen2.5-1.5B/7B 达 90.1%/96.1%、80.2%/82.6%。

    4.7 OpenKAGE：Agent 群体知识共享演化（Minecraft）¶

    • 提交：2026-11-18 | arXiv:2611.24302
    • 双层知识表示（情境记忆 + 可迁移经验/技能）+ 知识共享（文本经验凝入共享知识图谱、可执行技能逐字共享）；积累的知识可迁移到不同 backbone 的新 agent 群体——从单体自改进扩展到群体演化。

    4.8 MLE Agents：工业级推荐系统上的自主 ML 工程（NeurIPS AutoMLR Oral）¶

    • 提交：2026-11-18 | arXiv:2611.23910
    • human-on-the-loop MLE Agent 一轮 campaign 跑 1097 个实验、接受 325 个（29.6% vs 此前 15.6%），最佳模型大流量 A/B 提升搜索量 0.23%，若干改进是团队从未尝试过的架构变更——证明自主 Agent 能在真实工业系统（而非 benchmark）做 ML 工程。

    候补：Intent Contracts（agent 授权新机制）；Timeout Cascades（SWE-bench 省 33% GPU 时）；PIPETTE（提示注入紫队）；TRACE-MAS（多智能体协作失败诊断）。

    • 日期：2026-11-19 | 来源：The Guardian · AP · CNBC（多源交叉一致）
    • $83 定价之上首日开盘 $111.50（+34%），盘中区间 $92.72~$111.50，收盘 $97.17（+17.07%）；募资约 810 亿美元，超越 SpaceX 纪录成史上最大 IPO；当日大盘明显收跌背景下仍守住两位数涨幅。
    • 关注：公开市场给前沿 AI 定价的首个真实信号；开盘冲高后回吐近半涨幅值得玩味。

    5.2 Amodei 开盘钟演讲重申「按节奏发展 AI」¶

    • 日期：2026-11-19 | 来源：TechCrunch 演讲 · 慈善测算 · 循环融资分析
    • 重申无论商业/政治压力都将 pacing AI 开发；公益基金 + 员工捐赠 + 公司配捐合计可达 1560 亿美元；上市把「亚马逊/谷歌既是投资方又是算力供应方」的循环融资模式置于公开市场检验之下。

    5.3 Google 在 Gemini API 推出 Tool Retrieval（预览）¶

    • 日期：2026-11-19 | 来源：Google 官方博客
    • 让 agent 可访问数百个工具、同时显著减少 token 消耗——直击工具调用的成本与规模痛点，Gemini API agent 能力栈的重要拼图。

    5.4 Gemini Mac 应用上线 computer use¶

    • 日期：2026-11-19 | 来源：Google 官方博客 · TechCrunch
    • Mac 版 Gemini 可替用户整理文件、填写表单、执行多步工作流——computer-use agent 推向消费级桌面端，与 Claude computer use 正面竞争。

    5.5 Genie 4 登陆 Gemini API¶

    • 日期：2026-11-19 | 来源：Google 官方博客
    • 开发者可用 Genie 4 生成 720p 可交互世界（原生音频 + 实时控制）——区别于 11-18 消费端订阅开放，这是开发者/API 侧。

    5.6 Meta Muse 被曝串话、推送他人私人数据（未经官方确认）¶

    • 日期：2026-11-19 | 来源：TechCrunch 引述第三方报道

    • 日期：2026-11-19 | 来源：TechCrunch
