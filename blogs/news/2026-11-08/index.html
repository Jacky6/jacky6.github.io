    1. 框架与工程实践¶

    1.1 Microsoft Agent Framework Python 1.25.0：密集安全与破坏性变更¶

    • 日期：2026-11-07 | 来源：agent-framework Releases
    • 全包移除 Python 3.10 支持（要求 3.11+）；MCP 工具/prompt 发现限制为 100 页/1000 条、默认 30s 超时；修复跨 workflow MCP 会话共享的安全问题（每次调用新建协议会话）；AG-UI workflow 执行器绑定单一授权域；OTel span 对齐 GenAI 语义约定；支持可调用 MCP 发现审批策略。
    • 关注：昨日预告的 1.25.0 如期而至，是一次以 MCP 安全模型为核心的密集变更，存量用户升级前需评估破坏性项。

    1.2 Google ADK v2.14.0：A2A 集成与沙箱环境转正¶

    • 日期：2026-11-07 | 来源：adk-python Releases
    • 执行环境/沙箱（Local、Daytona、E2B）、A2A 集成、评估模块从 experimental 毕业为 stable；新增 adk eval --num_runs 多轮并行评估、adk generate_agent_card CLI、TeamsRunner（接 Microsoft Teams）、OpenAIDecisionsClassifier；长多轮 workflow 性能提升 23%、峰值内存降 9%；破坏性变更中堵了一个 prompt 注入可执行任意 shell 的洞。
    • 关注：Google 系 agent 栈走向生产可用的标志性版本；A2A 转正是协议生态的重要采用信号。

    1.3 CrewAI 1.15.37¶

    • 日期：2026-11-07 | 来源：CrewAI Releases
    • crewai-files 支持 agent 读取电子表格；支持脚手架和加载独立（standalone）agent 项目。常规迭代。

    次要：langchain-quickjs 0.3.12（deepagents 子包，代码解释器中间件修复）。

    5. 产品与公司动态¶

    5.1 AGENTS.md 成新型攻击载体：「下载目录投毒」攻击链披露¶

    • 日期：2026-11-07 | 来源：Forever Security 原始披露 · 量子位报道
    • 安全机构披露：攻击者通过网页向用户 ~/Downloads 静默投放恶意 AGENTS.md，用户在下载目录启动 Codex/Claude Code 后，Agent 会「忠实执行」伪装成开发规范的恶意指令（改全局配置、关沙箱、装恶意 npm 包、外泄 API Token）；实测对 Codex 攻击成功率超 90%，对 Claude Code 约 50%。
    • 关注：Coding Agent 时代首个大规模演示的「文档即病毒」攻击范式，厂商无法靠补丁根治——直接影响 Agent 产品默认安全策略，也与上期 AGENTS.md 入 AAIF 的生态扩张形成安全对照。

    5.2 OpenAI 拟收购代码托管公司 Pierre，代码基础设施成 Agent 军备新战场¶

    • 日期：2026-11-07（Axios 原文 11-04） | 来源：量子位综合 · Axios（交易未经官方确认）
    • OpenAI 拟收购代码托管工具商 Pierre（其 Trees/Diffs 组件已内置 Codex，Code Storage 业务单为 Lovable 每周新建 800 万+ Git 仓库）。同时 OpenAI 公开自研 Git 后端 Pando（推送中位耗时降近 80%）；Anthropic 披露自研版本控制系统 Scion（工程博客，7 名工程师 + Claude 花 5 个月建成，内部日合并改动从 5 月 2500 项飙至 9 月 3 万+项）。
    • 关注：AI 写码速度压垮 GitHub 类基础设施，OpenAI/Anthropic/Cursor 同时垂直整合代码托管——Agent 工作负载开始重塑开发工具链。

    5.3 OpenAI 110 亿美元融资首笔交割，规模较原计划缩水过半（对上期条目的更新）¶

    • 日期：2026-11-07（彭博 11-06 报道） | 来源：量子位
    • 相对上一期的增量：① 首笔 110 亿美元已交割（估值 1.25 万亿美元），Coatue、普信领投；② 原计划以 1.4 万亿估值融至少 300 亿，现缩水至最高 200 亿；③ Anthropic 潜在 IPO 估值讨论从 1.5 万亿降至 1.2~1.3 万亿美元，据 CNBC 其争取 11 月中旬登陆纳斯达克、抢在 OpenAI 前挂牌；④ OpenAI 从 Anthropic 挖走 Claude Code 产品负责人 Cat Wu 与增长骨干 Austin Lau。
    • 关注：融资缩水 + Anthropic IPO 估值下修 + 上期 Ramp 企业支出停滞，共同指向一级市场对 AI 估值的重新定价——本周最重要的资本面信号。

    5.4 OpenAI 同日双发：FMF 越狱评级框架 + BioBasicsBench¶

    • 日期：2026-11-07 | 来源：量子位
    • OpenAI 联合前沿模型论坛（含 Anthropic、Google DeepMind、微软、亚马逊）发布越狱风险评级框架 1.0（按解锁能力/覆盖范围/易用性/复现性四维打分，12-21 前公开征求意见）；并与生物公司 Ligo 推出 BioBasicsBench（100 道真实生物实验题，GPT-6 Astra 最高推理档 66.7% vs GPT-5.6 Sol 43.8%）。另有网友通过隐藏接口扒出疑似 GPT-6.2 Astra 数据（未经官方确认）。

    5.5 硅谷华人团队 AFK AI 的 Comma 被称为「抢跑 DeepSeek」的 Super-agent¶

    • 日期：2026-11-07 | 来源：量子位（含产品推广性质，效果未经第三方验证）
    • Comma 采用「单 Router + 多 Worker」架构，与 DeepSeek 的 Super-agent 四标准（连续、高效、主动、持久）路线一致；4 月起落地主 Agent 调度多 Worker、跨微信/Signal/iMessage/Linear 执行、7×24 值守唤醒、任务反馈训练专属小模型；9 月 30 日已开源。
