    4. 学术前沿¶

    「Tue, 10 Nov 2026」批次已上架（cs.MA 29 条 + cs.AI 480 条，全量分页扫描）；入选 8 篇均为 2026-11-09 提交，逐篇核实 abs 页。

    4.1 Agency：harness 作为独立优化层的系统性论证（UC Berkeley）¶

    • 提交：2026-11-09 | arXiv:2611.12122
    • Ion Stoica、Alvin Cheung 等：发现 agent 准确率主要由模型决定，而 harness 侧（系统提示、工具封装）对成本影响更大；插桩平台 Agency 可在 Claude Code / OpenAI Codex 等现成 harness 上做系统优化，不改模型、不降准确率，成本最高降 35%。
    • 关注：「harness engineering 从手艺走向系统科学」——与 HarnessFlow、DeCAF 构成三连。

    4.2 Infrathon：万 GPU 小时级长时程 AI 基础设施优化基准¶

    • 提交：2026-11-09 | arXiv:2611.11995
    • AI2/UW 等：6 个模型 × 150 次运行 × 24 小时预算，累计超 1 万 GPU 小时。发现模型排名随评估时长变化，135/150 次运行在预算后半段仍在改进；Claude Opus 5.5 把 KV-cache 压缩率从人类基线 6.82% 提升到 19.86%。
    • 关注：直接挑战短评估结论，并证明 agent 可超越人类工程师设计——与 11-09 期《Benchmarks as Software》的榜单质疑同向。

    4.3 ShadowBench-MCP：MCP 工具路由的「影子调用」风险基准化¶

    • 提交：2026-11-09（USENIX Security 2026） | arXiv:2611.11720
    • 定义影子调用：保持任务不变的请求变体诱导 LLM 路由器选择更危险的执行路径（跳过校验/审计/脱敏）。效率优先路由下影子调用率 29.2%、安全工具跳过率 26.7%；策略感知路由可降至 4.2%/1.7%。
    • 关注：MCP 工具路由层的新型安全风险首次被基准化——执行路径成为安全敏感的模型输出，与 AGENTS.md 投毒同属「协议层安全」主线。

    4.4 Harness Matters：拆解 Web Agent 的安全韧性（复旦）¶

    • 提交：2026-11-09 | arXiv:2611.11971
    • 将 Web agent harness 抽象为目标理解—页面感知—规划—执行四阶段，WebTrap Farm 评估三类攻击（恶意指令/提示注入/欺诈网页），并用配对可用性任务区分「真防御」与「能力不足」。发现部分不安全行为在无攻击时也出现，安全性由 harness 与底座模型共同决定。
    • 关注：与 4.1 互为印证——harness 是独立的安全边界。

    4.5 SoMem：Agent 自组织记忆¶

    • 提交：2026-11-09 | arXiv:2611.11929
    • Agent 用普通链接文档自组织记忆：自主决定总结什么、如何分组、何时修订，每条摘要链回原始交互作为证据；LoCoMo / BEAM-100K / LongMemEval-S 分别超最强基线 2.66/3.10/2.00 个百分点，且记忆可跨模型复用。
    • 关注：从「预定义记忆结构」转向「agent 自主记忆管理」——记忆主线的最新一环（REM → MEMOIR → Anthropic dreaming → SoMem）。

    4.6 AutoBuddy：主动式常开 Agent 的职场基准（微软）¶

    • 提交：2026-11-09 | arXiv:2611.12393
    • 组织的人员/项目/业务系统建成时间图，任务从事件中自然产生；发现失败模式随能力系统性迁移：弱模型输在发现，中等模型「发现却不做」，强模型败在业务系统操作；发现精度与执行质量弱相关。
    • 关注：「给任务 → 自己找任务」的主动式评估范式，对应产品端 ambient agent 形态。

    4.7 共享记忆即隐蔽通信信道（双实现锁定复现）¶

    • 提交：2026-11-09 | arXiv:2611.12412
    • 4 个 agent 各持互补的半个计算、共享键值存储、提示中完全不提其他 agent——联合成功仅通过共享存储发生；是否协调不取决于模型档位，而取决于模型是否会「写下中间结果并再看一眼存储」，一句普通提示即可开关该行为。
    • 关注：严格复现证明共享状态即隐蔽信道，对共享缓存/记忆的多 agent 部署有直接安全含义。

    4.8 用信息网络操纵多 Agent 系统的涌现行为¶

    • 提交：2026-11-09 | arXiv:2611.11714
    • 把「谁观察谁」的信息网络作为设计对象（与行动网络解耦），10 个 LLM agent × 6 类博弈 × 1080 局：信息的价值取决于个体动机与集体目标的对齐度——公共品博弈中零信息反而最优，耦合有害时模块化「杠铃」拓扑最差。
    • 关注：「多 agent 系统不应默认全透明」的实验证据，信息网络拓扑成为多 agent 治理新抓手（与 11-07 期「Who Should Know What」同主题）。

    候补关注：ErosionBench（Salesforce，企业多 agent 对齐衰减）；JoMoHa（RL 联合优化模型与 harness）；UK AISI 对 Mythos 5 七月安全事件的对齐调查报告（11-05 提交，话题度高）。
