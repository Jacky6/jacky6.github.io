    4. 学术前沿¶

    「Mon, 9 Nov 2026」批次（覆盖周五~周日提交）已上架：cs.AI 220 条 / cs.MA 14 条全量扫描，入选 8 篇，均逐篇核实 abs 页。

    4.1 MemoryDojo：Agent 记忆投毒基准（微软安全团队参与）¶

    • 提交：2026-11-06 | arXiv:2611.09721
    • 155 条多会话长程轨迹、4 个领域、支持 5 种记忆系统，追踪毒化信息在记忆中的全生命周期：所有记忆系统均可被投毒，并提出记忆感知的毒化优化流程进一步放大攻击。
    • 关注：与 11-08 期 AGENTS.md 投毒攻击同属「写入路径即攻击面」——记忆架构选型的风险参照。

    4.2 Flex-RSI：前沿 Agent 递归自我改进基准¶

    • 提交：2026-11-06 | arXiv:2611.08946
    • 固定预算下评测 RSI：executor 改进任务解法，improver 修订 harness（含其自身），隐藏测试集评分；发现自建解法时自改进收益最大，仅记录成败的反馈会拖累开源权重模型。
    • 关注：直接量化「Agent 改自己的 harness」——与今日 Fable/Mythos 的 RSI 发布叙事、百度 ERNIE Evolve 披露形成三方呼应。

    4.3 Test-Time Compute Scales Better with Parallel Agent Teams¶

    • 提交：2026-11-06 | arXiv:2611.09798
    • 并行采样多个小团队、取最优团队结果，兼具 Best-of-N 的方差收益与大团队高均值；27B 模型 + 100 agent 预算下，12 项长程任务（GPU kernel、形式化证明、漏洞开发）中 10 项胜过并行单 agent，等美元成本下半数任务胜过前沿模型（代码开源）。
    • 关注：test-time scaling 在多 agent 设定下的清晰缩放律。

    4.4 s³：合作式多智能体 RL 让组织从共享目标中涌现¶

    • 提交：2026-11-05（UTC，周一上架批次） | arXiv:2611.08615
    • 首个让 agent 自行决定何时独立工作、何时分享/阅读队友信息的多智能体 RL 方法，无预定义角色；2 倍训练规模的 swarm 在协调问题上比最强基线多解 25 倍，探索场景减少近 50% 重复劳动（Noah A. Smith、Yulia Tsvetkov、Natasha Jaques 等）。

    4.5 ENGRAM：把 Agent 经验「经核验地」固化进权重¶

    • 提交：2026-11-06 | arXiv:2611.09472
    • demonstration-aware 准入门控决定训练哪些经验，验证门控比较固化后模型与带检索基座后才允许外部记录退出检索；持续提升的同时降低输入 token 与调用量。
    • 关注：正面回答「经验该留在记忆还是写进参数」——与 Anthropic 记忆架构文章（11-09 期）的产业实践互为参照。

    4.6 CPU-ARC：把推理轨迹编译为 CPU 可执行的「推理缓存」（NVIDIA）¶

    • 提交：2026-11-06 | arXiv:2611.09891
    • 任务推理过一次后，新实例可极低成本复用编译后的推理缓存；数学/科学难题上性能对齐前沿 LLM，调用成本降低 16~291 倍，完全可解释、可持续训练。
    • 关注：「求解」与「执行解法」解耦，Agent 推理成本工程化新思路。

    4.7 Knowing When to Intervene：Agent 干预的因果评估¶

    • 提交：2026-11-06 | arXiv:2611.09792
    • Stanford 等：首个在 Agent 轨迹内评估随机干预（核验、筛查、转向）因果效应的框架，用少量随机干预轨迹估计上下文干预策略效果，可构建动作风险安全排行榜（τ-bench Retail、ToolSandbox、ImpossibleBench 验证）。
    • 关注：把 Agent 评估从静态基准推向「部署期何时该介入」，对监控/审计落地有直接意义。

    4.8 DeCAF：分维度优化 Agentic Pipeline 与 Harness（Adobe）¶

    • 提交：2026-11-05（UTC，周一上架批次） | arXiv:2611.08723
    • 按基准自适应拆分 prompt/拓扑/模型选择/工具策略等优化维度，独立 coding-agent 会话分维优化并留痕，最终综合；比最强基线任务表现 +2.58pp、推理成本 −4.30%、端到端时延 −42.45%。
    • 关注：pipeline 优化从「整体调参」走向「分维度、可解释」，延续 HarnessFlow（11-06 期）的 harness 自动搜索主线。
