    批次勘误：上期标注「周四批次未上架」，经本期核实——「Thu, 12 Nov」批次从未独立存在，11-11 提交并入了「Fri, 13 Nov」批次上架（cs.AI 321 条，约为常日 1.3 倍，符合两日合并特征）。本期覆盖 11-11 + 11-12 两天提交，7 篇均逐篇核实 abs 页。周末无新批次，下周一批次（11-13 提交）预计北京时间周一 ~09:00 上架。

    4.1 Singularity-Bench：Can Agents Build Agents?¶

    • 提交：2026-11-12 | arXiv:2611.16591
    • 开放式「自主 AI 研发」基准：6 个端到端任务覆盖预训练/中训/后训/推理/agent harness/集群编排，同硬件对标人类工程基线；并对 Harbor 框架做 OWASP Agentic Top-10 红队后给出加固版 Breakwater。11 个 agent 中 Opus 5.5 + Claude Code 六项全达/超人类基线（Singularity-Index 1.25），其余平均仅 0.58。
    • 关注：把「agent 能否端到端自动化 AI 研发」变成可追踪的量化基准——RSI 主线的测量工具。

    4.2 MULTILOOP：多智能体 Harness 的自动进化（Google）¶

    • 提交：2026-11-11 | arXiv:2611.15754（NeurIPS 2026 CL4FMAgents）
    • coding agent 迭代「分析-评估-编辑」多智能体 harness，DeepSearchQA 上仅 10 个训练样本即超基座 harness 4.6%、超最佳单 agent 系统 3.2%；但诚实刻画了边界：编排类失败优化后基本仍在。
    • 关注：harness 自动优化从单 agent 扩展到多 agent 的首个系统案例（接 HarnessFlow/DeCAF/Agency 主线）。

    4.3 DecArena：去中心化多 Agent 协作的大规模缺口研究¶

    • 提交：2026-11-11 | arXiv:2611.15521
    • 图约束通信（只能看邻居）+ 10 万+ 分布式工具调用：前沿 LLM agent 难以发现非本地资源，标准 RL 也无法可靠弥补；GraphHarness（拓扑感知 warmup + 自改进路由）任务成功 +48.5、协作质量 +30.6。
    • 关注：个人 agent 互联/无中心编排场景的首个大规模量化缺口——A2A 生态的学术对照。

    4.4 LEAD-RL：多智能体 Deep Research 的信用按贡献门控¶

    • 提交：2026-11-12 | arXiv:2611.17041
    • 主-子 agent 联合 RL：训练期 rubric 评估子 agent 报告效用，门控其继承团队 advantage（最终答案正确性仍是唯一团队奖励）；BrowseComp 较共享信用方案 +2.49pt、关键路径成本 −24.5%。

    4.5 OMA：多轮 Agentic RL 的两个隐蔽「记账错误」¶

    • 提交：2026-11-12 | arXiv:2611.16816
    • 逐步组相对训练中的结果统计多重性与目标质量失衡；OMA 不改底层优化器，ALFWorld GRPO 端点成功率 +7.0~9.4pt，WebShop-SOL 成功 nAUC 0.399→0.511，兼容 GiGPO/GSPO——即插即用的修正。

    4.6 MemCredit：记忆选择从「相关性」转向「决策效用」¶

    • 提交：2026-11-11 | arXiv:2611.15600
    • 用受控反事实干预估计单条记忆对决策的条件边际贡献，蒸馏为轻量效用估计器；ALFWorld 500-token 预算下 SR@50 86.57 vs BM25 65.67——记忆主线（REM/MEMOIR/SoMem 之后）的「效用派」新原则。

    4.7 JudgeMix：按模型实际困难按需引入专家数据（Apple）¶

    • 提交：2026-11-12 | arXiv:2611.16174
    • 针对 agent SFT 训练-推理分布失配，judge 按步语义评估决定何时引入专家 rollout、并按步重加权；AppWorld/AutomationBench 最高 +10 pass@1。

    候补：OPSD4MAS（多智能体通信转 token 级信用，pass@4 +20pt）；Bait（Georgia Tech：$20 即可经有害 agentic RL 颠覆安全对齐，奖励函数探测防御）；DISCERN（企业持久记忆：recall 已饱和，瓶颈在实体消解与拒答校准）。
