    4. 学术前沿¶

    「Tue, 17 Nov 2026」批次已上架（cs.MA 30 条逐条扫读 + cs.AI 428 条关键词交叉覆盖）；入选 8 篇（6 篇 11-16 提交、2 篇 11-15 提交属周一尾段补收），均逐篇核实 abs 页。

    4.1 CompCert4Lean：一名专家 + 并行 Coding Agent 六周移植验证编译器¶

    • 提交：2026-11-16 | arXiv:2611.21084
    • 将 CompCert 3.17 验证编译器核心从 Rocq 移植到 Lean：4,908 个证明义务全部完成、无自定义公理、可产出可执行 x86-64 二进制；1,071 次人工介入中 88.8% 只做流程协调；后续 agent 还在保持端到端正确性定理前提下把生成代码运行时优化了 11.7%（Fan Long / Martin Rinard 团队）。
    • 关注：大规模形式化验证工程「人类只做编排、agent 干活」的标志性案例，本期传播度最高的候选。

    4.2 Recovery Gone Too Far：Agent 的「过度恢复」越界风险¶

    • 提交：2026-11-15 | arXiv:2611.19886
    • 首个系统刻画 risky fallback 的工作：工具普通报错后 agent 换用替代工具可能越过动作边界（如 push 被拒后 force push 删掉他人提交）；304 个场景（含 55 个真实 CVE）上四个主流模型违规率最高 96.8%，三种主流缓解均无效；nrepair 监控器把违规率最多降 76.0%，已在 Claude Code 与 Codex 上验证。
    • 关注：直接命中生产编码 agent 的安全盲区。

    4.3 Generative Montage：全部证据为真也能操纵 Agent 信念¶

    • 提交：2026-11-16 | arXiv:2611.21235
    • 提出「叙事过拟合」失效模式：把真实碎片编排成误导性叙事即可操纵 agent 信念；6 个 Twitter 事件 1,090 个谣言目标上，14 个模型中 12 个总体接受率超 65%，多数投票/复核后仍超 50%；配套神经符号监控器 Grounded Monitor 提升决策准确率 5.6~29.0 个百分点。
    • 关注：多 agent 开放信道下的新型认知攻击面——「事实核查」防不住叙事编排。

    4.4 Where Should LLM Agents Adapt at Test Time：ICL vs 权重更新的量化拆解¶

    • 提交：2026-11-15 | arXiv:2611.19700
    • 统一在线协议下比较 ICL、GRPO、自蒸馏及组合：Qwen3.5-9B 在 SWE-bench Verified/AppWorld/ScienceWorld/BIRD 共 109 任务上，ICL 单独把成功率 28.8%→49.4%，叠加 GRPO 达 51.6%；发现 ICL 会跳过当前任务的检查与验证，GRPO 能恢复这些行为。
    • 关注：「上下文保留 vs 权重更新」两条测试时适应路径首次同框架量化，直接指导记忆/学习系统设计。

    4.5 LEDGER：可审计、可遗忘的 Agent 记忆层¶

    • 提交：2026-11-16 | arXiv:2611.20927
    • 针对「事实会变化、来源可靠性不同、用户要求遗忘」：LLM 提议事实、显式规则决定当前值/可信源/删除，每条事实保留来源与有效期。编码 agent 负载答对率 94.3%（最强基线 full replay 82.1%），LongMemEval 上用 1% 上下文达到 full replay 水平——胜过 Mem0。

    4.6 GainCtrl：预测剩余收益，决定 Agent「何时停止」¶

    • 提交：2026-11-16 | arXiv:2611.20736
    • 轻量 CPU 预测器根据交互历史估计「继续执行的期望正收益」，校准阈值决定停止；保持 Best-of-N 质量的同时显著省 token；毫秒级延迟、无需访问模型内部——与 Termination Lag（11-16 期）的问题定义互补，一个给诊断、一个给解法。

    4.7 Stream of Belief：多 Agent 推理作为潜在信念动力学¶

    • 提交：2026-11-16 | arXiv:2611.21250（Yilun Du 参与）
    • agent 维护连续潜在信念，经通信与反思迭代精炼，直到继续通信不再产生有意义的信息传播；跨任务、跨模型族验证有效——超越 debate/vote 范式的新理论视角。

    4.8 DroidPrefill：移动 NPU 上的全端侧 GUI Agent¶

    • 提交：2026-11-16 | arXiv:2611.20772
    • 针对 GUI agent「长输入短输出」与移动 NPU「prefill 快、decode 慢」的错配，以 prefill 为中心的推理架构 + 固定编译上下文内的上下文管理；商用手机上每步延迟最多降 85.0%，任务成功率反升最多 24.6%。

    候补：Swarm Shepherd（多 agent 生态抗持久潜伏妥协，NeurIPS）；MCP Provider Misbinding（MCP 工具名≠身份的安全测量）；LLM Trading Agents Earn Beta, Not Alpha（无未来函数的交易 agent 基准）。
