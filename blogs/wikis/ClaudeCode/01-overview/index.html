    Claude Code 教程 01：概述与快速入门¶

    Claude Code 是 Anthropic 推出的编程代理（Agentic）工具，它能阅读你的代码库、编辑文件、运行命令，并与开发工具链集成。支持终端、IDE、桌面应用和浏览器多种使用方式。

    官方文档参考： https://code.claude.com/docs/en/overview

    什么是 Claude Code？¶

    Claude Code 不是一个普通的代码补全工具——它是一个自主代理（Agent）。当你给它一个任务，它会：

    1. 理解上下文 — 阅读你的代码库，理解项目结构和依赖关系
    2. 采取行动 — 编辑文件、运行命令、搜索内容
    3. 验证结果 — 执行测试、检查输出、必要时修正方案

    这个循环会自主重复，直到任务完成。你可以随时中断、引导方向或提供额外信息。

    Claude Code 能做什么？¶

    能力 示例
    代码理解 "这个函数是干什么的？" "这段代码的性能瓶颈在哪？"
    多文件分析 "auth 模块在哪些地方被调用了？"
    工程级修改 "把所有 var 改成 let" "拆分这个 200 行的函数"
    运行命令 构建、测试、lint、Git 操作
    Bug 修复 "修复测试失败" "解决这个 lint 报错"
    重构 "把这段代码提取为独立模块"
    文档生成 "给这个模块写 JSDoc 注释"
    网页搜索 查找 API 文档、错误信息解决方案

    Claude Code 不能做什么？¶

    • ❌ 替你做技术决策的最终判断
    • ❌ 保证代码 100% 无 Bug
    • ❌ 理解你没有明确说明的业务语义
    • ❌ 在你完全不理解的情况下全自动接管项目

    💡 最佳心态：让 Claude Code 提供高质量候选方案，而不是期待绝对正确答案。

    安装方式¶

    方式一：官方脚本（推荐）¶

    macOS / Linux / WSL： 

    curl -fsSL https://claude.ai/install.sh | bash

    安装过程会：

    1. 下载最新版本的 Claude Code 二进制文件
    2. 将其安装到 ~/.local/bin/claude
    3. 自动更新你的 $PATH（如果需要，会提示你运行 source ~/.bashrc 或 source ~/.zshrc）

    安装完成后验证： 

    claude --version
# 输出示例: Claude Code 1.0.x

    Windows (PowerShell)： 

    irm https://claude.ai/install.ps1 | iex

    Windows (CMD)： 

    curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

    方式二：Homebrew（macOS）¶

    brew install --cask claude-code

    验证： 

    claude --version

    更新： 

    brew upgrade claude-code

    方式三：WinGet（Windows）¶

    winget install Anthropic.ClaudeCode

    更新： 

    winget upgrade Anthropic.ClaudeCode

    方式四：npm（备选）¶

    npm install -g @anthropic-ai/claude-code

    国内网络慢时使用镜像： 

    npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com

    ⚠️ npm 安装不是官方推荐方式，可能获取到稍旧版本。

    方式五：IDE 集成¶

    VS Code：

    • 从 Marketplace 安装
    • 或命令行安装： 
      code --install-extension anthropic.claude-code

    JetBrains（IntelliJ / PyCharm / WebStorm 等）：

    • 从插件市场安装

    桌面应用：

    • 从 claude.com/download 下载

    卸载¶

    # 脚本安装
rm -f ~/.local/bin/claude
rm -rf ~/.local/share/claude

# Homebrew
brew uninstall --cask claude-code

# WinGet
winget uninstall Anthropic.ClaudeCode

# npm
npm uninstall -g @anthropic-ai/claude-code

# 彻底清除配置（⚠️ 不可恢复）
rm -rf ~/.claude
rm ~/.claude.json

    常见问题排查¶

    问题 原因 解决方案
    command not found 未正确安装或 PATH 未更新 重新运行安装脚本，或执行 export PATH="$HOME/.local/bin:$PATH"
    permission denied 无执行权限 chmod +x ~/.local/bin/claude
    安装速度慢 网络访问境外源 使用 --registry=https://registry.npmmirror.com

    首次启动¶

    登录¶

    在项目目录中运行：

    cd your-project
claude

    首次启动会引导你登录。支持的账号类型：

    类型 说明
    Claude Pro 个人专业版
    Claude Max 最高级别订阅
    Claude Teams 团队版
    Claude Enterprise 企业版
    Claude Console API 访问，按 Token 预付费

    登录后也可以随时切换： 

    /login

    第一次对话¶

    启动后试试这些对话：

    # 让 Claude 了解你的项目
这个项目是做什么的？
使用了哪些技术栈？
入口文件在哪里？
解释一下目录结构

# 让 Claude 查看 Git 状态
我改了哪些文件？
最近的提交历史是什么？

# 让 Claude 帮忙写代码
写一个快速排序函数
给这个项目添加一个 README

    第一次代码修改¶

    在 test.py 中添加一个 hello_world 函数

    Claude Code 会：

    1. 定位需要修改的文件
    2. 展示代码差异（diff）
    3. 请求你的确认
    4. 确认后写入文件

    命令行模式¶

    除了交互模式，Claude Code 还支持多种命令行用法：

    # 交互模式（默认）
claude

# 一次性任务，完成后退出
claude "修复构建错误"

# 单次查询，不进入交互
claude -p "解释这个函数的作用"

# 继续最近一次对话
claude -c

# 选择并恢复历史对话
claude -r

# 自动生成 Git 提交信息
claude commit

# 指定模型启动
claude --model claude-sonnet-4-6

# 添加额外工作目录（monorepo 场景）
claude --add-dir ../shared-lib

    命令前缀语法¶

    在交互会话中使用这些前缀：

    / 斜杠命令 — 触发内置或自定义命令¶

    /help        # 查看帮助
/compact     # 压缩上下文
/model       # 切换模型

    ! 感叹号前缀 — 直接执行 Shell 命令¶

    > !git status
> !npm test
> !cat logs/error.log | tail -50
> !ls -la src/

    @ 艾特前缀 — 将文件注入上下文¶

    > 对比 @src/auth/v1.ts 和 @src/auth/v2.ts 的实现差异
> 审查 @src/api/users.ts 中的错误处理逻辑
> 参考 @docs/architecture.md 来实现新功能

    常用内置命令速查¶

    命令 功能 使用场景
    /help 查看所有可用命令 忘记命令时
    /init 自动生成 CLAUDE.md 新项目首次使用
    /doctor 诊断安装问题 遇到异常时
    /model 切换模型 需要更强/更快模型时
    /permissions 管理权限规则 配置工具访问控制
    /mcp 管理 MCP 服务器 连接外部工具
    /agents 管理子代理 配置专用 Agent
    /compact 压缩上下文窗口 上下文快满时
    /resume 恢复历史会话 继续未完成的工作
    /memory 编辑 CLAUDE.md 修改项目指令
    /clear 清除对话历史 开始新话题
    /context 查看上下文使用量 监控 Token 消耗
    /todos 列出 TODO 项 跟踪 Claude 记录的待办
    /diff 查看文件变更差异 审查修改内容

    模型选择¶

    Claude Code 支持多种 Claude 模型：

    模型 定位 适用场景 速度
    Sonnet 均衡型（默认） 日常编程、代码修改、Bug 修复 ⚡⚡⚡
    Opus 高能力旗舰 复杂架构规划、深度推理 ⚡⚡
    Haiku 快速轻量 简单查询、只读探索、节省 Token ⚡⚡⚡⚡⚡

    切换模型：

    # 会话中交互切换
/model

# 启动时指定
claude --model claude-sonnet-4-6
claude --model claude-opus-4-6
claude --model claude-haiku-4-5

    💡 建议： 日常开发用 Sonnet 即可；复杂架构问题切换到 Opus；只读探索任务（如代码搜索、文件分析）用 Haiku 更省成本。
