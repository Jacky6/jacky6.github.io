    Claude Code 教程 06：MCP 协议集成¶

    通过 Model Context Protocol (MCP) 连接 Claude Code 到外部工具、数据库和 API。

    官方文档参考： https://code.claude.com/docs/en/mcp

    什么是 MCP？¶

    MCP（Model Context Protocol）是 Anthropic 推出的开源标准协议，用于 AI 工具集成。通过 MCP 服务器，Claude Code 可以访问你的工具、数据库和 API，而不需要你手动复制粘贴数据。

    核心理念¶

    不要让 AI 学习每个工具的使用规则，而是让所有工具提供统一接口。

    类比理解¶

    类比 说明
    USB 接口 不同设备（键盘、鼠标、U 盘）通过统一 USB 接口连接电脑
    MCP 协议 不同工具（GitHub、数据库、Slack）通过统一 MCP 接口连接 Claude

    MCP 能做什么？¶

    连接 MCP 服务器后，你可以让 Claude：

    场景 示例指令
    Issue 管理 "查看 JIRA 问题 ENG-4521 并实现它描述的功能"
    PR 创建 "把当前分支的改动创建一个 GitHub PR"
    数据库查询 "从 PostgreSQL 中随机抽 10 个活跃用户"
    监控分析 "检查 Sentry 中最近的错误"
    文档搜索 "在 Notion 知识库中搜索 API 文档"
    消息通知 "把部署结果发送到 Slack #deploy 频道"
    浏览器操作 "用 Puppeteer 打开页面截图"
    文件存储 "把构建产物上传到 S3"

    MCP 传输方式¶

    MCP 支持三种传输协议：

    方式 说明 适用场景 推荐度
    Stdio 通过标准输入/输出与本地进程通信 本地工具、npm 包 ✅ 最常用
    HTTP (Streamable) 通过 HTTP 连接到远程服务器 云服务 API ✅ 推荐用于云服务
    SSE Server-Sent Events 流式传输 旧版兼容 ⚠️ 逐渐被 HTTP 取代

    安装 MCP 服务器¶

    方式一：Stdio（本地进程）¶

    最常用的方式，通过 npx 运行 npm 包：

    # 基本语法
claude mcp add --transport stdio <名称> -- npx -y <npm包名>

# 示例：连接 GitHub
claude mcp add --transport stdio github -- npx -y @modelcontextprotocol/server-github

# 带环境变量（认证 Token）
claude mcp add --transport stdio github \
  --env GITHUB_TOKEN=$GITHUB_TOKEN \
  -- npx -y @modelcontextprotocol/server-github

# 示例：连接 PostgreSQL 数据库
claude mcp add --transport stdio postgres \
  --env DATABASE_URL="postgresql://user:pass@localhost:5432/mydb" \
  -- npx -y @modelcontextprotocol/server-postgres

# 示例：连接文件系统
claude mcp add --transport stdio filesystem \
  -- npx -y @modelcontextprotocol/server-filesystem /path/to/allowed/dir

    方式二：HTTP（远程服务器）¶

    推荐用于云服务类工具：

    # 基本语法
claude mcp add --transport http <名称> <URL>

# 示例：连接 Notion
claude mcp add --transport http notion https://mcp.notion.com/mcp

# 带 Bearer Token
claude mcp add --transport http secure-api https://api.example.com/mcp \
  --header "Authorization: Bearer $API_TOKEN"

# 示例：连接 Slack
claude mcp add --transport http slack https://mcp.slack.com/mcp

    方式三：SSE¶

    claude mcp add --transport sse <名称> <SSE-URL>

    管理 MCP 服务器¶

    查看已连接的服务器¶

    # 在 Claude Code 会话中
/mcp

# 通过命令行
claude mcp list

    输出示例： 

    MCP Servers:
  github      (stdio)    ✅ Connected
  notion      (http)     ✅ Connected
  postgres    (stdio)    ❌ Disconnected

    添加/删除/修改¶

    # 添加
claude mcp add --transport stdio github -- npx -y @modelcontextprotocol/server-github

# 删除
claude mcp remove github

# 修改（先删除再添加）
claude mcp remove notion
claude mcp add --transport http notion https://mcp.notion.com/mcp

    在会话中管理¶

    # 查看所有服务器
/mcp

# 添加新服务器
/mcp add --transport stdio github -- npx -y @modelcontextprotocol/server-github

# 删除服务器
/mcp remove github

# 重新连接所有服务器
/mcp reconnect

    MCP 安装作用域¶

    作用域 加载范围 团队共享 存储位置 示例场景
    Local（本地） 当前项目 ❌ 否 ~/.claude.json（项目路径下） 个人开发服务器
    Project（项目） 当前项目 ✅ 是（通过 Git） 项目根目录 .mcp.json 团队共享 GitHub 连接
    User（用户） 所有项目 ❌ 否 ~/.claude.json 个人通用工具

    Local 作用域（默认）¶

    # 默认就是本地作用域
claude mcp add --transport http stripe https://mcp.stripe.com

# 显式指定
claude mcp add --scope local --transport http stripe https://mcp.stripe.com

    适合：个人开发工具、实验性配置、含有敏感凭证的服务器。

    Project 作用域¶

    claude mcp add --scope project --transport stdio github \
  --env GITHUB_TOKEN=\${GITHUB_TOKEN} \
  -- npx -y @modelcontextprotocol/server-github

    这会在项目根目录创建 .mcp.json：

    {
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "${GITHUB_TOKEN}"
      }
    }
  }
}

    注意事项：

    • 使用 ${GITHUB_TOKEN} 环境变量引用，Token 不会硬编码到文件中
    • 将此文件提交到版本控制，团队成员克隆项目后即可使用
    • 每个团队成员需要有自己的 GITHUB_TOKEN 环境变量

    User 作用域¶

    claude mcp add --scope user --transport http notion https://mcp.notion.com/mcp

    适合：个人通用工具（如 Notion、个人笔记），在所有项目中都可用。

    MCP 权限控制¶

    MCP 工具受权限系统管理。每个 MCP 工具的名称格式为 mcp__服务器名__工具名：

    {
  "permissions": {
    "allow": [
      "mcp__github__create_issue",
      "mcp__github__list_issues",
      "mcp__github__get_pull_request",
      "mcp__github__list_repositories"
    ],
    "deny": [
      "mcp__github__delete_repository",
      "mcp__github__delete_issue"
    ]
  }
}

    通配符控制¶

    {
  "permissions": {
    "allow": [
      "mcp__github__*"       // 允许 github 服务器的所有工具
    ],
    "deny": [
      "mcp__github__delete_*" // 但禁止所有删除操作
    ]
  }
}

    注意：Deny 优先。mcp__github__* 允许所有操作，但 mcp__github__delete_* 会阻止删除。

    只读模式¶

    如果你只想让 Claude 查看 GitHub 但不修改：

    {
  "permissions": {
    "allow": [
      "mcp__github__list_*",
      "mcp__github__get_*",
      "mcp__github__search_*"
    ],
    "deny": [
      "mcp__github__create_*",
      "mcp__github__update_*",
      "mcp__github__delete_*"
    ]
  }
}

    常用 MCP 服务器推荐¶

    GitHub¶

    claude mcp add --transport stdio github \
  --env GITHUB_TOKEN=$GITHUB_TOKEN \
  -- npx -y @modelcontextprotocol/server-github

    可用工具：

    • 列出仓库、Issues、Pull Requests
    • 创建/编辑 Issue
    • 创建 PR
    • 搜索代码
    • 管理 Labels、Milestones

    PostgreSQL¶

    claude mcp add --transport stdio postgres \
  --env DATABASE_URL="postgresql://user:pass@localhost:5432/mydb" \
  -- npx -y @modelcontextprotocol/server-postgres

    可用工具：

    • 执行 SQL 查询
    • 列出表结构
    • 查看索引

    文件系统¶

    claude mcp add --transport stdio filesystem \
  -- npx -y @modelcontextprotocol/server-filesystem ~/Documents ~/Projects

    可用工具：

    • 读取文件
    • 搜索文件
    • 获取文件元信息

    Notion¶

    claude mcp add --transport http notion https://mcp.notion.com/mcp \
  --header "Authorization: Bearer $NOTION_TOKEN"

    Slack¶

    claude mcp add --transport http slack https://mcp.slack.com/mcp \
  --header "Authorization: Bearer $SLACK_TOKEN"

    Puppeteer（浏览器自动化）¶

    claude mcp add --transport stdio puppeteer \
  -- npx -y @modelcontextprotocol/server-puppeteer

    可用工具：

    • 打开网页
    • 截图
    • 提取页面内容

    MCP 消息通道¶

    MCP 服务器不仅可以提供工具，还可以作为消息通道向 Claude 推送消息：

    {
  "mcpServers": {
    "telegram": {
      "command": "npx",
      "args": ["-y", "@your-org/mcp-telegram"],
      "env": {
        "TELEGRAM_BOT_TOKEN": "${TELEGRAM_BOT_TOKEN}"
      }
    }
  }
}

    连接后，Telegram 消息会实时推送到你的 Claude Code 会话，Claude 可以主动回复。

    常见 MCP 问题¶

    MCP 服务器连接失败¶

    /mcp

    查看服务器状态，如果是 ❌ Disconnected：

    1. 检查环境变量是否正确设置
    2. 确认网络连接正常
    3. 重新添加服务器

    MCP 工具不被 Claude 使用¶

    Claude 可能不知道有哪些 MCP 工具可用。你可以：

    我现在连接了哪些 MCP 工具？

    或者直接指定使用：

    通过 GitHub MCP 创建一个新的 Issue

    安全注意事项¶

    ⚠️ 使用第三方 MCP 服务器需自行承担风险 — Anthropic 未验证这些服务器的正确性或安全性。

    建议：

    1. 只使用可信来源的 MCP 服务器
    2. 用权限规则限制 MCP 工具的访问
    3. 小心可能获取不受信任内容的服务器（提示词注入风险）
    4. 敏感凭证使用环境变量，不要硬编码
