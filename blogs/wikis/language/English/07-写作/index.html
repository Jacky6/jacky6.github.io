    07 · 写作：从句子到篇章¶

    写作是最容易被忽视的技能——它不像口语有即时反馈，但恰恰是倒逼语法内化、暴露表达短板的最佳训练。写不出来说明想不清楚，写作同时训练语言和思维。

    1. 写作的三个层次¶

    层次 问题 本教程对应
    句子层 语法错误、中式表达 第 2-3 节
    段落层 结构松散、逻辑跳跃 第 4 节
    篇章层 文体不对、语气不当 第 5-6 节

    写作的第一原则：清晰 > 华丽。母语者评判好写作的标准是 clear and concise（清晰简洁），不是大词长句。

    2. 句子层：先写对¶

    2.1 中式英语（Chinglish）修正¶

    ❌ 中式 ✅ 地道 说明
    The price is very expensive The price is too high / It's expensive 价格高，东西贵
    I with my friend went My friend and I went 介词误用
    According to me In my opinion according to 接来源不接人
    We discussed about it We discussed it discuss 及物
    It has three people There are three people 存在句用 there be
    I very like I really like very 不修饰动词
    open the light turn on the light 动词搭配

    2.2 句子升级：从"能懂"到"地道"¶

    原句：The weather is good. I am happy.
升级：The weather is so nice that it puts me in a good mood.

原句：He is a good student. He studies hard.
升级：He is a hard-working student.（合并，动词化）

原句：Because I was tired, so I went to bed early.
修正：I was tired, so I went to bed early.（because/so 二选一）

    升级三板斧：

    1. 动词化：make a decision → decide、give consideration to → consider
    2. 合并句子：用从句/分词把碎句连成有层次的复合句
    3. 具体化：good → considerate / efficient / mouth-watering（拒绝万能形容词）

    2.3 标点与格式基础¶

    • 逗号不能连接两个完整句（需加 and/but/so 或用分号）：
    • ❌ I was tired, I went to bed. → ✅ I was tired, so I went to bed.
    • 句首大写、专有名词大写
    • 英文无书名号《》，书名用斜体或引号
    • 段落之间空一行（block format），段首不缩进（现代商务惯例）

    3. 句型库：拿来就能用¶

    3.1 表达观点¶

    I would argue that... / It could be argued that...
There is no denying that... / It is widely believed that...
From my perspective, ... / As far as I'm concerned, ...

    3.2 表达因果¶

    This is largely because... / The main reason for this is...
As a result, ... / Consequently, ... / This, in turn, leads to...
... , which explains why ...

    3.3 表达对比与让步¶

    In contrast, ... / By comparison, ...
Despite the fact that... / Although... / While it is true that..., ...
On the one hand... On the other hand...

    3.4 举例与总结¶

    A case in point is... / Take ... for example / To illustrate,
In conclusion, ... / To sum up, ... / All things considered, ...

    4. 段落层：汉堡包结构¶

    英文段落的标准结构（topic paragraph）：

    ┌─────────────────────────────┐
│ 主题句 Topic Sentence        │  ← 一句话点明本段观点
├─────────────────────────────┤
│ 支撑 1（解释/原因）           │
│ 支撑 2（例子/数据）           │  ← 展开 2-4 句
│ 支撑 3（细节/引述）           │
├─────────────────────────────┤
│ 小结/过渡句（可选）            │  ← 收束或引出下段
└─────────────────────────────┘

    示例：

    Remote work has significantly improved my productivity.（主题句） Without the noise of open offices, I can focus deeply for hours at a time.（解释） For example, I now finish my coding tasks by 3 p.m., which used to take a full day.（例证） Clearly, the flexibility of working from home suits my working style.（小结）

    英文写作是"演绎式"：观点先行，证据随后。中文习惯"铺垫后升华"，直接搬到英文里会被认为"重点不明"。

    5. 篇章层一：议论文（Essay）模板¶

    5.1 经典五段式¶

    第 1 段 引言：背景 + 争议 + 亮明观点（thesis statement）
第 2 段 论点 1：主题句 + 解释 + 例子
第 3 段 论点 2：主题句 + 解释 + 例子
第 4 段 反方回应：承认对方观点 + 反驳
第 5 段 结论：重申观点 + 升华/建议

    5.2 引言写法（漏斗结构）¶

    宽：In recent years, remote work has become increasingly common.
窄：Companies debate whether it helps or hurts productivity.
观点：This essay argues that remote work improves productivity
      by reducing distractions and saving commuting time.

    5.3 衔接词（Cohesion）¶

    功能 词汇
    递进 moreover, furthermore, in addition, what's more
    转折 however, nevertheless, on the contrary, that said
    因果 therefore, thus, consequently, as a result
    举例 for instance, namely, to illustrate
    总结 in conclusion, to summarize, all in all

    ⚠️ 衔接词是"路标"不是"装饰"，每段开头堆砌 firstly/secondly 会显得机械。高级衔接靠内容呼应（重复关键词、指代上文名词）。

    6. 篇章层二：实用文体¶

    6.1 邮件（Email）万能模板¶

    Subject: Request for Feedback on Q3 Report Draft

Hi Sarah,

I hope this email finds you well.（可选寒暄）

I'm writing to ask if you could review the Q3 report draft
(attached) before Friday.（开门见山说明来意）

The main sections I'd like your input on are the market
analysis and the budget forecast.（具体化请求）

Please let me know if you need any additional information.
Thank you for your time!（礼貌收尾）

Best regards,
Yixiu

    邮件礼仪要点：

    • Subject 精准概括（Request for... / Update on... / Invitation to...）
    • 首段即说明目的，不绕弯
    • 请求用 Would you / Could you，不用 Please do
    • 回复时效：24 小时内，哪怕只是 "Received, will get back to you by Friday."

    6.2 常用场景句型¶

    跟进：I'm following up on my previous email about...
道歉：I apologize for the delay in getting back to you.
确认：Just to confirm, we're meeting at 3 p.m. on Thursday, right?
拒绝：Unfortunately, I won't be able to make it due to...
请求延期：Would it be possible to extend the deadline to...?

    7. 训练流程与批改¶

    7.1 每周写作计划¶

    频率 任务 时长
    每天 仿写 3 个好句子（从精读中摘） 10 分钟
    每周 2 次 段落写作（汉堡包结构） 20 分钟/次
    每周 1 次 完整文章（议论文/邮件） 40 分钟

    7.2 批改方案¶

    工具 用法
    Grammarly 语法、拼写、简洁度（免费版够用）
    DeepL Write 整句改写建议，看地道表达
    ChatGPT / Claude 最推荐：贴上文章，用下面提示词

    AI 批改提示词模板：

    You are an English writing tutor. Please review my essay below:
1. Fix grammar and spelling errors (list them with explanations).
2. Point out Chinglish expressions and suggest natural alternatives.
3. Comment on paragraph structure and logical flow.
4. Rewrite one paragraph to show how a native writer would express it.
Keep my level in mind — don't over-polish it into something I couldn't have written.

[粘贴你的文章]

    7.3 建立个人错误库¶

    每次批改后，把错误归类登记：

    日期 原句 修正 错误类型
    10-30 I very like this book I really like this book 副词误用
    10-30 discuss about the plan discuss the plan 及物动词

    每月回看：同类错误是否在减少？这是写作进步最直观的度量。

    8. 本节小结¶

    • 写作第一原则：清晰 > 华丽。
    • 句子层消灭中式表达，段落层用汉堡包结构，篇章层按文体选模板。
    • 英文写作是观点先行的演绎式结构，与中文"铺垫升华"相反。
    • AI 批改 + 个人错误库 = 免费的私人写作教练。
