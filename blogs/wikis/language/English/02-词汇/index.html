    02 · 词汇：高频优先，语境记忆¶

    词汇量决定输入输出的上限。但"背单词"是英语学习中效率损耗最大的环节——大多数人败在方法上，不是败在记忆力上。

    1. 词汇量的真相¶

    1.1 词频分布（Zipf 定律）¶

    英语词汇出现频率极度不均：

    词汇范围 覆盖日常文本 说明
    前 1000 词 ~85% 最核心，必须滚瓜烂熟
    前 2000 词 ~90% 日常交流的骨架
    前 3000 词 ~95% 看懂大部分非专业内容
    前 5000 词 ~97% 舒适阅读大众读物
    前 8000 词 ~98%+ 无障碍看剧、读小说

    结论：从 0 到 3000 是"雪中送炭"，3000 到 8000 是"锦上添花"。先确保高频词的主动运用（会说会写），再追求量的扩张。

    1.2 词汇量分级目标¶

    目标 建议词汇量
    日常旅游、简单交流 3000
    看美剧（带字幕）、读大众文章 5000
    工作、无字幕看剧、读原版小说 8000
    学术阅读、专业深度讨论 12000+

    2. 三大背单词误区¶

    误区 为什么低效
    只背中文释义 中英词义很少一一对应（见 4.1），形成"翻译脑"
    抄写 N 遍 手动重复≠大脑提取，提取练习（recall）才有效
    一次背 100 个新词 遗忘曲线下，一周后剩不到 10 个；小批量多轮次远胜大批量单轮

    3. 科学方法：间隔重复 + 主动提取¶

    3.1 间隔重复（Spaced Repetition）¶

    遗忘是正常的，关键在即将遗忘时复习：

    记忆保持率
100% ┤●
     │ ╲
     │  ╲        复习①    复习②    复习③
80% ┤   ╲        ●        ●        ●
     │    ╲      ╱ ╲      ╱ ╲      ╱ ╲
60% ┤     ╲    ╱   ╲    ╱   ╲    ╱
     │      ╲  ╱     ╲  ╱     ╲  ╱
40% ┤       ╲╱       ╲╱       ╲╱
     └──┬────┬────┬────┬────┬────┬──→ 时间
      学完  1天  3天  7天  14天  30天
    • 复习节点参考：1 天 → 3 天 → 7 天 → 14 天 → 30 天
    • 工具化方案：Anki（算法自动安排，见 3.3）

    3.2 主动提取（Active Recall）¶

    测试自己比重复看有效 2-3 倍：

    • ❌ 反复看 "abandon v. 放弃"
    • ✅ 看中文"放弃"回忆英文 / 听英文想场景 / 造一个句子

    3.3 Anki 使用方案¶

    卡片类型 正面 背面
    认知卡 英文单词 + 例句（挖空） 中文释义 + 发音
    产出卡 中文场景："房间太吵了，你想说'我受不了了'" I can't stand it.
    搭配卡 make a ___（决定） decision（固定搭配）
    词根卡 -spect（看） inspect / respect / prospect / spectator

    设置建议： - 每天新词 10-20 个（复习量会自动滚到 50-100） - 卡片必须带例句，孤立单词卡价值有限 - 记不住的卡果断删掉，别让"僵尸卡"拖垮复习队列

    4. 语境记忆：词不是孤岛¶

    4.1 中英词义错位¶

    英文 直觉中文 实际差异
    wear 穿 穿衣服、戴眼镜、涂香水、留胡子都用 wear
    借 lend / borrow 英文按方向区分：lend 借出，borrow 借入
    老的 old / elder 英文按人/物、比较级区分
    actually 实际上 更多用于纠正对方："其实……"
    available 可用的 也指"有空、单身"，含义远比中文宽

    学一个词 = 学它的典型场景 + 常见搭配，而不是中文标签。

    4.2 搭配（Collocation）优先¶

    母语者的地道感来自搭配：

    • ❌ make a crime → ✅ commit a crime
    • ❌ strong rain → ✅ heavy rain
    • ❌ do a mistake → ✅ make a mistake
    • ❌ very tired → ✅ exhausted / worn out（升级表达）

    工具：Ozdic、Ludwig.guru、SkELL（查真实语料中的搭配）

    4.3 从阅读中收词（最推荐的主路径）¶

    1. 读文章时只查影响理解的词（猜得出的跳过）
    2. 查词时记录原句，不是孤立释义
    3. 每天从当天阅读中挑 5-10 个进 Anki
    4. 一周后回看这篇文章，验证词汇是否"存活"

    5. 词根词缀：批量记忆的杠杆¶

    掌握 100 个高频词根词缀，可以撬动数千词汇。

    5.1 高频前缀¶

    前缀 含义 例子
    un- / in- / im- / il- / ir- 否定 unhappy, incorrect, impossible, illegal, irregular
    re- 再次 return, rebuild, review
    pre- 预先 preview, predict, prevent
    post- 之后 postpone, postwar
    inter- 之间 international, interrupt
    over- / under- 过度/不足 overwork, underestimate
    dis- 相反 disagree, disappear
    mis- 错误 misunderstand, misspell
    sub- 下面 subway, subtitle
    trans- 跨越 transfer, transport, translate

    5.2 高频后缀¶

    后缀 词性/含义 例子
    -tion / -sion 名词 action, decision
    -ment 名词 development, movement
    -ness 名词 happiness, darkness
    -ity 名词 ability, possibility
    -able / -ible 形容词（可…的） readable, visible
    -ful / -less 有/无 helpful, careless
    -ive 形容词 active, creative
    -ly 副词 quickly, sadly
    -er / -or 人/工具 teacher, actor
    -ist 主义者/专家 scientist, tourist
    -ize / -ise 动词 realize, organize
    -fy 动词 simplify, classify

    5.3 高频词根¶

    词根 含义 例子
    spect 看 inspect 检查、respect 尊重、prospect 前景
    port 搬运 import 进口、export 出口、transport 运输
    dict 说 predict 预言、dictionary 词典、contradict 矛盾
    struct 建造 construct 建造、instruct 指导、structure 结构
    ject 扔 reject 拒绝、project 项目、inject 注射
    form 形 reform 改革、transform 转变、informal 非正式
    duc / duct 引导 introduce 介绍、produce 生产、conduct 引导
    vis / vid 看 visible 可见、video 视频、evident 明显
    cred 相信 credit 信用、incredible 难以置信
    fer 带来 transfer 转移、prefer 更喜欢、offer 提供

    注意：词根词缀适合批量扩展（3000 词之后），不适合零基础阶段。前期靠高频词 + 语境，后期用词根杠杆。

    6. 分阶段词汇计划¶

    阶段一：核心 2000（1-2 个月）¶

    • 材料：COCA 高频 2000 词表 / 《英语词汇的奥秘》入门部分 / 直接用 Anki 牌组 "English 5000 by frequency"
    • 目标：见词 1 秒内反应含义，能造简单句

    阶段二：3000 → 5000（3-4 个月）¶

    • 主路径：分级读物中收词（见 06-阅读）
    • 辅助：词根词缀系统学习
    • 目标：读大众文章生词率 < 3%

    阶段三：5000 → 8000（长期）¶

    • 主路径：原版书、美剧、播客中收词
    • 开始区分：主动词汇（能产出）vs 被动词汇（能认识）
    • 每周挑 10 个被动词"升级"为主动词（造句、口语中使用）

    7. 工具推荐¶

    工具 用途
    Anki / AnkiDroid 间隔重复核心工具（免费）
    欧路词典 自定义词库、导入词典文件、查词收藏
    Ludwig.guru 查搭配是否地道（语料库验证）
    Youglish 听单词在真实视频中的发音
    Vocabulary.com 游戏化练习 + 自适应
    COCA 词频表 按频率背词的依据

    8. 本节小结¶

    • 高频优先：前 3000 词决定 95% 的理解，先深后广。
    • 间隔重复 + 主动提取是记忆的科学解，抄写和狂刷是反效率的。
    • 单词必须带语境（例句、搭配、场景）入库，否则只是"认识"而非"会用"。
    • 词根词缀是 3000 词之后的批量杠杆。
