    Nginx 教程（一）：安装与基础入门¶

    参考： nginx.org/en/docs

    一、Nginx 是什么？¶

    Nginx（发音 "engine-x"）是一个高性能的 HTTP 和反向代理服务器。它的核心特点：

    • ⚡ 高并发能力强（单台轻松处理万级并发连接）
    • 💾 内存占用极低（轻量级事件驱动架构）
    • 🔄 支持反向代理、负载均衡、HTTP 缓存
    • 📁 可用作静态文件服务器
    • 🔒 支持 HTTPS、WebSocket、gRPC 等

    二、安装¶

    Ubuntu / Debian¶

    sudo apt update
sudo apt install nginx

    CentOS / RHEL¶

    sudo yum install epel-release
sudo yum install nginx

    macOS¶

    brew install nginx

    验证安装¶

    nginx -v        # 查看版本
nginx -V        # 查看版本及编译参数
nginx -t        # 测试配置文件语法

    三、启动、停止、重载¶

    基本命令¶

    sudo systemctl start nginx     # 启动
sudo systemctl stop nginx      # 停止
sudo systemctl restart nginx   # 重启
sudo systemctl reload nginx    # 重载配置（推荐，不中断服务）
sudo systemctl enable nginx    # 开机自启
sudo systemctl status nginx    # 查看状态

    直接用 nginx 命令¶

    nginx                    # 启动
nginx -s stop            # 快速关闭
nginx -s quit            # 优雅关闭（等当前请求处理完）
nginx -s reload          # 重载配置
nginx -s reopen          # 重新打开日志文件

    reload 的优雅之处： 主进程先检查新配置语法 → 启动新 worker → 通知旧 worker 停止接收新连接 → 旧 worker 处理完当前请求后退出。整个过程零宕机。

    四、进程模型¶

    Nginx 采用 Master-Worker 架构：

    进程类型 职责
    Master 进程 读取配置、维护 Worker 进程、接收信号
    Worker 进程 实际处理请求，采用事件驱动模型 
                        ┌─────────┐
                    │ Master  │
                    └────┬────┘
                         │ 分发
            ┌────────────┼────────────┐
            ▼            ▼            ▼
        ┌──────┐    ┌──────┐    ┌──────┐
        │Worker│    │Worker│    │Worker│
        └──────┘    └──────┘    └──────┘

    配置 Worker 数量（推荐设为 CPU 核心数）：

    worker_processes auto;  # 自动根据 CPU 核心数设置

    五、配置文件结构¶

    默认配置文件位置¶

    /etc/nginx/nginx.conf

    配置文件的层级结构¶

    main（全局）
  └── events（连接处理）
  └── http（HTTP 服务器）
        └── server（虚拟主机）
              └── location（路由匹配）

    最小可用配置¶

    # nginx.conf
worker_processes auto;

events {
    worker_connections 1024;
}

http {
    include       mime.types;
    default_type  application/octet-stream;
    sendfile      on;
    keepalive_timeout 65;

    server {
        listen      80;
        server_name localhost;

        location / {
            root   /usr/share/nginx/html;
            index  index.html index.htm;
        }
    }
}

    指令类型说明¶

    类型 格式 示例
    简单指令 名称 参数;（分号结尾） worker_processes auto;
    块指令 名称 { ... }（花括号内可嵌套） http { ... }、server { ... }
    注释 # 后面的内容 # 这是一行注释

    六、核心指令速览¶

    指令 作用域 说明
    worker_processes main Worker 进程数
    worker_connections events 每个 Worker 最大连接数
    listen server 监听端口
    server_name server 服务器域名
    root http/server/location 静态文件根目录
    location server URL 路由匹配
    index http/server/location 默认首页文件
    error_page http/server/location 自定义错误页
    include 任意 引入其他配置文件

    七、日志文件¶

    日志类型 默认路径 用途
    访问日志 /var/log/nginx/access.log 记录所有请求
    错误日志 /var/log/nginx/error.log 记录错误信息

    八、最佳实践¶

    1. 永远先测试配置：nginx -t
    2. 用 reload 而非 restart：零宕机更新配置
    3. 拆分配置文件：把 server 块放到 /etc/nginx/conf.d/ 目录下
    4. 限制 worker_connections：根据服务器资源合理设置
    5. 定期轮转日志：使用 logrotate 防止日志文件过大
