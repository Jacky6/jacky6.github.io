    以下是使用 Frp（Fast Reverse Proxy） 将内网 SSH 端口（22） 透出到公网的详细教程：

    1. 环境准备¶

    • 公网服务器（Frp 服务端）：
    • IP 地址：42.121.162.247（示例）
    • 安装 Frp 服务端（frps）。
    • 内网设备（Frp 客户端）：
    • IP 地址：192.168.1.100（示例）
    • 运行 SSH 服务（默认端口 22）。

    2. 安装 Frp¶

    (1) 下载 Frp¶

    从 GitHub 仓库 下载最新版本（以 v0.45.0 为例）： 

    wget https://github.com/fatedier/frp/releases/download/v0.45.0/frp_0.45.0_linux_amd64.tar.gz
tar -zxvf frp_0.45.0_linux_amd64.tar.gz
cd frp_0.45.0_linux_amd64

    3. 配置 Frp 服务端（公网服务器）¶

    (1) 编辑服务端配置文件 frps.ini¶

    [common]
bind_port = 7000
dashboard_port = 7500
token = 123456
    token 是客户端认证密钥

    (2) 启动 Frp 服务端¶

    ./frps -c ./frps.ini

    4. 配置 Frp 客户端（内网设备）¶

    (1) 编辑客户端配置文件 frpc.ini¶

    [common]
server_addr = 42.121.162.247  # 公网服务器IP
server_port = 7000
token = 123456

[ssh]
type = tcp
local_ip = 192.168.1.100  # 内网设备IP
local_port = 22
remote_port = 2222  # 公网暴露的端口（可自定义）

    (2) 启动 Frp 客户端¶

    ./frpc -c ./frpc.ini

    5. 验证 SSH 连接¶

    (1) 通过公网服务器访问内网 SSH¶

    ssh user@1.1.1.1 -p 2222
    - 1.1.1.1：公网服务器 IP。 - 2222：Frp 客户端配置的 remote_port。

    (2) 检查 Frp 日志¶

    • 服务端日志：nohup.out（查看是否成功连接）。
    • 客户端日志：nohup.out（查看是否成功注册 SSH 服务）。

    6. 高级配置（可选）¶

    (1) 自定义域名（可选）¶

    1. 在 DNS 服务商（如阿里云、Cloudflare）添加 CNAME 记录： 
      yourdomain.com  -> 1.1.1.1
    2. 修改 frpc.ini： 
      [ssh]
type = tcp
local_ip = 192.168.1.100
local_port = 22
remote_port = 2222
custom_domain = yourdomain.com

    (2) 加密通信¶

    修改 frpc.ini 添加加密配置： 

    [common]
use_encryption = true
use_compression = true

    7. 常见问题排查¶

    (1) 无法连接 SSH¶

    • 原因：
    • 公网服务器防火墙未开放 7000（Frp 服务端端口）和 2222（SSH 端口）。
    • 内网设备 SSH 服务未启动。
    • 解决：
    • 开放端口： 
      sudo ufw allow 7000
sudo ufw allow 2222
    • 检查内网 SSH 服务： 
      systemctl status ssh

    (2) Frp 客户端无法连接服务端¶

    • 原因：
    • server_addr 配置错误。
    • token 不匹配。
    • 解决：
    • 检查 frpc.ini 中的 server_addr 和 token。

    (3) 自定义域名无法访问¶

    • 原因：
    • 域名未正确解析到公网服务器 IP。
    • 解决：
    • 使用 nslookup yourdomain.com 验证解析。

    8. 安全建议¶

    1. 修改默认配置：
    2. 更改 token 为复杂密码。
    3. 禁用默认的 dashboard_port（可选）。
    4. 限制端口：
      在 frps.ini 中配置 allow_ports 限制允许的端口范围： 
      allow_ports = 2222, 80, 443

    9. 总结¶

    通过 Frp，你可以将内网的 SSH 服务（22 端口）安全地暴露到公网。只需配置服务端和客户端的 frps.ini 和 frpc.ini 文件，即可实现远程 SSH 连接。如果遇到问题，检查防火墙、日志和配置文件即可快速定位原因。

    升级成 systemd 服务¶

    • 现在这样跑太原始了，重启得手动搞。用 systemd 管理就爽多了
    sudo vim /etc/systemd/system/frpc.service

    [Unit]
Description=frp client
After=network.target
Wants=network.target

[Service]
Type=simple
User=yixiu
WorkingDirectory=/home/yixiu/frp_0.65.0_linux_amd64
ExecStart=/home/yixiu/frp_0.65.0_linux_amd64/frpc -c /home/yixiu/frp_0.65.0_linux_amd64/frpc.ini
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target

    # 2. 先停止旧的 frpc 进程 
pkill frpc
# 3. 启用 systemd 服务
sudo systemctl daemon-reload
sudo systemctl enable frpc
sudo systemctl start frpc
# 4. 查看状态
sudo systemctl status frpc

# 5. 以后管理就超简单了
sudo systemctl restart frpc   # 重启
sudo systemctl stop frpc      # 停止
sudo journalctl -u frpc -f    # 看日志
