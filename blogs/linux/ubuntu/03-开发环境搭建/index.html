    03. Ubuntu 开发环境搭建¶

    1. 通用开发工具¶

    sudo apt update
sudo apt install build-essential git curl wget ca-certificates \
  unzip zip jq tree ripgrep fd-find shellcheck pkg-config

    Ubuntu 中 fd-find 的命令名可能是 fdfind。如需统一为 fd，可在用户目录创建符号链接：

    mkdir -p ~/.local/bin
ln -s "$(command -v fdfind)" ~/.local/bin/fd

    查看编译工具版本：

    gcc --version
make --version
git --version

    2. Git 配置¶

    git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main
git config --global pull.ff only
git config --global core.autocrlf input

    推荐使用 SSH 密钥访问代码托管平台，并用 ~/.ssh/config 为不同账户配置独立密钥。不要把令牌写进仓库、脚本或 Shell 历史。

    3. Python¶

    安装系统 Python 开发组件：

    sudo apt install python3 python3-venv python3-pip pipx python3-dev
pipx ensurepath

    每个项目使用独立虚拟环境：

    cd ~/code/example
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

    退出虚拟环境：

    deactivate

    注意：

    • 不要使用 sudo pip install 修改系统 Python。
    • CLI 工具适合通过 pipx install <工具> 隔离安装。
    • 项目可选择 uv、Poetry 等工具，但应提交锁文件并固定团队用法。

    4. Node.js¶

    Ubuntu 仓库适合安装对版本要求不高的工具：

    sudo apt install nodejs npm
node --version
npm --version

    多个项目需要不同 Node.js 版本时，推荐使用 nvm、fnm 等用户级版本管理器，并遵循其官方安装文档。项目中提交 .nvmrc 或 .node-version：

    22

    安装依赖时优先使用锁文件对应命令：

    npm ci

    不要对 npm 执行全局 sudo npm install -g；版本管理器可将全局工具保存在用户目录。

    5. Java¶

    安装 Ubuntu 默认支持的 JDK：

    sudo apt install default-jdk maven
java -version
javac -version
mvn -version

    如项目明确要求指定 LTS 版本，可安装仓库中存在的包，例如：

    sudo apt install openjdk-21-jdk

    管理多个 JDK：

    sudo update-alternatives --config java
sudo update-alternatives --config javac

    项目应使用 Maven Wrapper（mvnw）或 Gradle Wrapper（gradlew）固定构建工具版本。

    6. Go¶

    Ubuntu 仓库安装方式：

    sudo apt install golang-go
go version

    若项目需要比发行版仓库更新的版本，从 Go 官方下载页 获取匹配架构的安装包，并校验 SHA256。不要混用多个来源覆盖 /usr/local/go。

    常用环境检查：

    go env GOPATH GOMODCACHE GOPROXY

    7. C/C++ 调试工具¶

    sudo apt install gdb cmake ninja-build clang clang-format valgrind

    构建示例：

    cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
ctest --test-dir build --output-on-failure

    8. 数据库客户端¶

    sudo apt install postgresql-client mysql-client redis-tools sqlite3

    只需要连接远程数据库时，无需在开发机安装完整数据库服务。连接凭据应放入权限受限的环境文件或密钥管理系统，不能提交到 Git。

    9. 验证开发环境¶

    git --version
python3 --version
node --version
java -version
go version

    只验证项目实际使用的运行时。团队项目应在 README.md 中记录版本要求，并通过锁文件、Wrapper、容器或版本管理器实现可复现构建。
