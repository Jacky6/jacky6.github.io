    Linux 文本查看与处理常用命令¶

    Linux 中配置、日志和命令输出大多是文本。推荐先用只读命令查看，再使用过滤、排序和替换工具处理。

    1. cat：输出与拼接¶

    cat -n file.txt

         1  first line
     2  second line
     3  third line

    -n 在每行前显示行号，适合对照报错信息中的行号定位内容。

    cat -A file.txt

    first line$
second   line$  ^I$

    $ 标记行尾，^I 表示 Tab。怀疑文件混入 Windows 换行符（^M$）或不可见字符时，用 -A 一眼可见。

    cat 适合短文件；大文件应使用 less，实时日志应使用 tail -F。

    避免无用写法：

    # 可以工作，但多启动一个进程
cat file.txt | grep pattern

# 更直接
grep pattern file.txt

    2. less：分页查看¶

    less file.txt
command | less
less +F app.log

    常用按键：

    按键 作用
    Space / b 下一页 / 上一页
    g / G 文件开头 / 末尾
    /text 向后搜索
    ?text 向前搜索
    n / N 下一个 / 上一个匹配
    F 持续追踪增长内容
    Ctrl+C 退出追踪模式
    q 退出

    常用选项：

    less -N file.txt       # 显示行号
less -S file.txt       # 不自动换行，可左右滚动
less -R colored.log    # 保留 ANSI 颜色

    3. head 与 tail¶

    head -n 3 file.txt

    line 1
line 2
line 3

    只输出文件开头 3 行，适合快速预览文件结构。

    tail -n 3 file.txt

    line 98
line 99
line 100

    只输出文件末尾 3 行，适合查看日志最新内容。

    tail -n +11 file.txt

    从第 11 行开始输出到文件末尾，相当于“跳过前 10 行”。

    实时查看日志：

    tail -F /var/log/app.log

    ==> /var/log/app.log <==
10:00:01 INFO  server started
10:00:05 INFO  request handled

    命令不会退出，持续输出新写入的行，按 Ctrl+C 停止。

    • -f：持续读取当前文件描述符。
    • -F：按文件名持续追踪，日志轮转后会尝试重新打开，更适合日志。

    4. wc：计数¶

    wc file.txt

     100  450 3200 file.txt

    依次是行数、单词数、字节数。只想要其中一个数字时：

    wc -l file.txt

    100 file.txt

    配合输入重定向可去掉文件名，只输出数字：

    wc -l < file.txt

    100
    选项 含义
    -l 行数
    -w 单词数
    -c 字节数
    -m 字符数
    -L 最长行长度

    统计目录内普通文件数量：

    find . -type f -printf '.' | wc -c

    这种写法不会被包含换行的文件名干扰。

    5. sort 与 uniq¶

    排序¶

    sort names.txt
sort -n scores.txt
sort -nr scores.txt
sort -k2,2n data.txt
sort -t, -k3,3nr data.csv
sort -u names.txt
sort -h sizes.txt
    选项 含义
    -n 按数值排序
    -h 识别 K、M、G 等单位
    -r 降序
    -u 排序并去重
    -t 指定字段分隔符
    -k 指定排序键

    sort -k2,2n 中，2,2 限定只使用第 2 字段，n 表示数值排序。

    相邻行去重与计数¶

    sort names.txt | uniq -c

          2 alice
      1 bob
      3 carol

    第一列是出现次数，第二列是内容。uniq 只处理相邻重复行，所以通常先 sort。

    按出现次数从高到低排列：

    sort names.txt | uniq -c | sort -nr

          3 carol
      2 alice
      1 bob

    6. cut、paste 与 tr¶

    cut：按列或字符提取¶

    cut -d: -f1,7 /etc/passwd

    root:/bin/bash
daemon:/usr/sbin/nologin
alice:/bin/bash

    -d: 指定冒号为分隔符，-f1,7 取第 1 和第 7 个字段。/etc/passwd 的第 1 字段是用户名，第 7 字段是登录 Shell。

    cut 只能使用单字符分隔符；复杂字段处理使用 awk。

    paste：横向合并¶

    paste names.txt scores.txt
paste -d, names.txt scores.txt

    tr：字符转换¶

    tr '[:lower:]' '[:upper:]' < input.txt
tr -d '\r' < windows.txt > unix.txt
tr -s '[:space:]' ' ' < input.txt
    • -d：删除字符。
    • -s：压缩连续重复字符。

    tr 处理字符集合，不处理正则表达式。

    7. sed：流式编辑¶

    基本语法：

    sed [选项] '地址 命令' 文件

    查看指定行¶

    sed -n '10,20p' file.txt

    输出第 10 到 20 行。-n 抑制默认输出，p 只打印匹配范围，两者配合才能精确控制输出。

    sed -n '/ERROR/p' app.log

    只输出包含 ERROR 的行，作用类似 grep ERROR。

    替换¶

    printf 'path=/old/dir\n' | sed 's|/old/dir|/new/dir|'

    path=/new/dir

    s|old|new| 使用 | 作分隔符，避免路径中的 / 与默认分隔符冲突。不加 g 时每行只替换第一处匹配。

    删除和插入¶

    sed '/^[[:space:]]*#/d' config.conf

    删除以 # 开头（允许前导空白）的注释行，输出中不再包含它们。

    sed '1i\header' file.txt

    在第 1 行前插入一行 header。i\ 在行前插入，a\ 在行后追加。这是 GNU sed 写法，BSD/macOS sed 要求 i\ 后换行，跨平台脚本建议改用 awk 或临时文件方式。

    修改文件¶

    GNU sed：

    sed -i.bak 's/old/new/g' config.txt

    这会修改 config.txt 并保留 config.txt.bak。BSD/macOS sed -i 的参数规则不同，编写跨平台脚本时应使用临时文件：

    sed 's/old/new/g' config.txt > config.txt.tmp &&
mv config.txt.tmp config.txt

    重要文件修改前先检查输出并创建备份。

    8. tee：同时显示并写入文件¶

    printf '%s\n' a b c | tee output.log

    a
b
c

    内容同时出现在终端和 output.log 中，适合“既要看到执行过程，又要留档”的场景。

    -a 表示追加，不覆盖：

    command | tee -a output.log

    需要以管理员权限写文件时：

    printf '%s\n' 'value' | sudo tee /etc/example.conf > /dev/null

    sudo command > file 中的重定向仍由当前 Shell 执行，因此不会自动获得管理员权限；sudo tee 可解决这一问题。

    9. xargs：把标准输入转为参数¶

    printf '%s\n' file1 file2 | xargs ls -l --
find . -type f -name '*.log' -print0 | xargs -0 grep -n -- 'ERROR'

    常用选项：

    选项 作用
    -0 使用 NUL 分隔输入，安全处理空格和换行
    -n N 每次最多传 N 个参数
    -P N 最多并行运行 N 个进程
    -I {} 使用占位符，每条输入执行一次
    -r 无输入时不运行命令，GNU 选项

    示例：

    printf '%s\n' a b c | xargs -n 1 printf 'item=%s\n'

    涉及文件名时优先使用 find -print0 | xargs -0，或者直接使用 find -exec ... {} +。

    10. diff 与 cmp¶

    diff -u old.conf new.conf

    --- old.conf    2026-10-12 10:00:00
+++ new.conf    2026-10-12 10:05:00
@@ -1,3 +1,3 @@
 port=8080
-timeout=30
+timeout=60
 loglevel=info

    - 开头的行是旧文件独有，+ 开头是新文件独有，@@ 行标注双方各自的行号范围。示例表示 timeout 从 30 改成了 60。

    cmp file1.bin file2.bin

    file1.bin file2.bin differ: byte 5, line 1

    cmp 按字节比较，输出第一个差异的位置；无输出且退出码为 0 表示文件完全相同。

    11. 常用组合¶

    查看出现次数最多的值¶

    cut -d, -f3 data.csv | sort | uniq -c | sort -nr | head

         42 beijing
     31 shanghai
     18 guangzhou

    管道依次完成：提取第 3 列 → 排序使重复相邻 → 计数 → 按次数降序 → 取前几名。

    去除注释和空行¶

    sed '/^[[:space:]]*#/d; /^[[:space:]]*$/d' config.conf

    输出中不再有注释行和空行，便于查看配置实际生效的键值对。

    实时过滤日志¶

    tail -F app.log | grep --line-buffered -E 'ERROR|WARN'

    10:00:05 ERROR connection refused
10:00:08 WARN retrying request

    --line-buffered 让 grep 逐行刷新输出，保证实时性；不加时 grep 可能缓冲，导致日志延迟显示。

    查看第 100 到 120 行¶

    sed -n '100,120p' file.txt

    12. 工具选择¶

    任务 优先工具
    查看短文件 cat
    分页查看大文件 less
    查看开头或末尾 head、tail
    正则搜索 grep
    简单替换 sed
    字段统计和报表 awk
    排序与相邻去重 sort、uniq
    安全批量传递文件名 find -exec 或 NUL 管道
