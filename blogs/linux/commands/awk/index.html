    awk 文本处理教程¶

    awk 是按“记录”和“字段”处理文本的工具，适合列提取、条件过滤、统计汇总和报表输出。默认情况下，一行是一条记录，空白字符分隔字段。

    1. 基本语法¶

    awk [选项] '条件 { 动作 }' 文件

    awk '{ print $1 }' access.log

    假设 access.log 内容：

    192.168.1.50 GET /index.html 200
192.168.1.60 POST /api/login 401

    输出：

    192.168.1.50
192.168.1.60

    每行按空白分成 4 个字段，$1 是第一个字段（客户端 IP）。awk 逐行读取，对每行执行一次 { 动作 }。

    常用内置变量：

    变量 含义
    $0 当前整行
    $1、$2 第 1、2 个字段
    NF 当前行的字段数
    $NF 当前行最后一个字段
    NR 已读取的总行数
    FNR 当前文件内的行号
    FS 输入字段分隔符
    OFS 输出字段分隔符
    RS 输入记录分隔符，默认换行
    ORS 输出记录分隔符，默认换行
    FILENAME 当前文件名

    Shell 会解释 $，所以 awk 程序通常使用单引号包裹。

    2. 字段与分隔符¶

    输出指定字段¶

    awk '{ print $1, $3 }' data.txt

    假设 data.txt 内容：

    alice 90 beijing
bob 75 shanghai

    输出：

    alice beijing
bob shanghai

    print 中使用逗号时，字段由 OFS 分隔（默认空格）；直接拼接则不添加分隔符：

    awk '{ print $1 ":" $2 }' data.txt

    alice:90
bob:75

    指定输入分隔符¶

    awk -F: '{ print $1, $7 }' /etc/passwd

    root /bin/bash
daemon /usr/sbin/nologin
alice /bin/bash

    -F: 按冒号分列，取第 1 字段（用户名）和第 7 字段（登录 Shell）。

    多个相邻分隔符可使用正则表达式：

    awk -F'[,:]' '{ print $1, $2 }' data.txt

    指定输出分隔符¶

    awk -F: 'BEGIN { OFS="\t" } { print $1, $7 }' /etc/passwd

    简单 CSV 可以用 -F, 处理；包含引号、逗号转义或换行的标准 CSV 应使用专门的 CSV 工具或语言库。

    3. 条件过滤¶

    比较与正则匹配¶

    awk '$3 >= 80 { print $1, $3 }' scores.txt

    假设 scores.txt 内容：

    alice 90
bob 75
carol 82

    输出：

    alice 90
carol 82

    条件 $3 >= 80 不满足的行（bob）被跳过，动作完全不执行。注意：没有匹配行时输出为空，不代表命令失败。

    awk '/timeout/ { print NR, $0 }' app.log

    42 10:00:05 WARN request timeout
87 10:05:12 ERROR upstream timeout

    NR 是当前行号，配合正则 /timeout/ 可以直接定位日志中的问题行。

    常用运算符：

    类型 运算符
    比较 ==、!=、>、>=、<、<=
    正则 ~、!~
    逻辑 &&、||、!
    算术 +、-、*、/、%

    行范围¶

    awk 'NR >= 10 && NR <= 20' file.txt
awk '/START/,/END/' file.txt

    第二种写法会输出从匹配 START 到匹配 END 的所有行；之后若再次匹配 START，会开始新的区间。

    4. BEGIN、END 与变量¶

    BEGIN 在读取输入前执行，END 在全部输入处理完后执行：

    awk 'BEGIN { print "name total" }
     { sum += $2 }
     END { print "sum", sum }' sales.txt

    假设 sales.txt 内容：

    alice 100
bob 200
carol 150

    输出：

    name total
sum 450

    BEGIN 块先打印表头（此时还没读任何数据）；中间块对每行累加 $2；END 块在全部行处理完后输出合计。

    通过 -v 安全地从 Shell 传入变量：

    threshold=80
awk -v min="$threshold" '$3 >= min { print $1, $3 }' scores.txt

    不要把不可信变量直接拼进 awk 程序文本。

    5. 统计与数组¶

    求和、平均值、最大值¶

    awk '{ sum += $2 } END { print sum }' data.txt

awk '{ sum += $2; count++ }
     END { if (count) print sum / count }' data.txt

awk 'NR == 1 || $2 > max { max=$2; row=$0 }
     END { print max, row }' data.txt

    按字段分组计数¶

    awk '{ count[$1]++ }
     END { for (key in count) print key, count[key] }' data.txt

    假设 data.txt 内容：

    beijing alice
shanghai bob
beijing carol
beijing dave

    输出：

    beijing 3
shanghai 1

    count[$1]++ 以第 1 列为键累加出现次数，END 块遍历数组输出统计结果。数组遍历顺序不固定，需要稳定顺序时交给 sort 处理。

    6. 格式化输出¶

    printf 不会自动换行：

    awk '{ printf "%-10s %6.2f\n", $1, $2 }' prices.txt

    假设 prices.txt 内容：

    apple 3.5
banana 12.25

    输出：

    apple        3.50
banana      12.25

    %-10s 左对齐占 10 个字符宽度，%6.2f 右对齐共 6 位、保留 2 位小数。两列因此自动对齐，适合生成报表。

    常见格式：

    格式 含义
    %s 字符串
    %d 十进制整数
    %f 浮点数
    %.2f 保留 2 位小数
    %-20s 左对齐、宽度 20
    %08d 用零补齐到 8 位

    7. 字符串与字段处理¶

    awk '{ print length($0) }' file.txt
awk '{ print toupper($1), tolower($2) }' data.txt
awk '{ print substr($1, 1, 4) }' data.txt
awk '{ sub(/old/, "new"); print }' file.txt
awk '{ gsub(/[[:space:]]+/, " "); print }' file.txt

    常用函数：

    • length(s)：字符串长度。
    • substr(s, start, length)：截取字符串，起始位置从 1 开始。
    • index(s, target)：返回子串位置，未找到返回 0。
    • split(s, array, regex)：拆分字符串。
    • sub(regex, replacement, target)：替换第一个匹配。
    • gsub(regex, replacement, target)：替换全部匹配。

    不指定 target 时，sub 和 gsub 修改 $0。

    8. 实用场景¶

    统计访问日志状态码¶

    常见访问日志中状态码为第 9 字段：

    awk '{ count[$9]++ }
     END { for (code in count) print code, count[code] }' access.log |
sort -k2,2nr

    输出示例：

    200 15230
404 231
500 12

    每行是“状态码 出现次数”，按次数降序。200 占绝大多数属正常；404 偏多要检查链接或路由；500 出现说明服务端报错，应结合应用日志继续排查。

    统计某列总容量¶

    awk 'NR > 1 { sum += $3 }
     END { printf "total: %.2f\n", sum }' report.txt

    查看磁盘使用率超过 80% 的文件系统¶

    df -P | awk 'NR > 1 {
  usage=$5
  sub(/%$/, "", usage)
  if (usage >= 80) print $6, usage "%"
}'

    输出示例：

    /var 86%
/data 93%

    NR > 1 跳过表头；sub(/%$/,"") 去掉 86% 中的百分号再比较数值。输出为空表示所有分区都在 80% 以下。

    处理键值配置¶

    awk -F= '
  /^[[:space:]]*#/ || /^[[:space:]]*$/ { next }
  { print $1, $2 }
' app.conf

    多文件处理¶

    awk 'FNR == 1 { print "==> " FILENAME " <==" } { print }' *.log

    FNR 每进入一个新文件都会从 1 重新计数，NR 则持续累计。

    9. awk 脚本文件¶

    复杂逻辑可保存为 report.awk：

    BEGIN { FS=","; OFS="\t" }
NR == 1 { next }
$3 >= 80 { total += $3; count++ }
END {
    print "count", count
    print "total", total
}

    执行：

    awk -f report.awk scores.csv

    10. 常见问题¶

    表头参与了计算¶

    使用 NR > 1 或 FNR > 1 跳过表头：

    awk 'NR > 1 { sum += $2 } END { print sum }' data.txt

    空格与 Tab 混用¶

    默认 FS 会把连续空白视为一个分隔区间。若必须只按 Tab 分隔：

    awk -F'\t' '{ print $2 }' data.tsv

    原地修改文件¶

    可移植做法是写临时文件并在成功后替换：

    awk '{ gsub(/old/, "new"); print }' config.txt > config.txt.tmp &&
mv config.txt.tmp config.txt

    修改重要文件前先备份，并检查临时文件内容。

    11. 命令速查¶

    需求 命令
    打印第一列 awk '{print $1}' file
    按冒号分列 awk -F: '{print $1}' file
    输出行号 awk '{print NR, $0}' file
    打印最后一列 awk '{print $NF}' file
    条件过滤 awk '$3 > 80' file
    列求和 awk '{s+=$2} END{print s}' file
    分组计数 awk '{c[$1]++} END{for(k in c) print k,c[k]}' file

    选择工具时：固定字符串或正则查找优先用 grep，简单替换优先用 sed，需要字段、条件和统计时使用 awk。
