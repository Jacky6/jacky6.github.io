    Linux 文件与目录常用命令¶

    Linux 使用单一目录树组织文件。根目录是 /，用户主目录通常是 /home/<用户名>，当前用户主目录可写为 ~。

    1. 路径基础¶

    写法 含义
    /etc/hosts 从根目录开始的绝对路径
    docs/readme.md 相对于当前目录的路径
    . 当前目录
    .. 上一级目录
    ~ 当前用户主目录
    ~user 指定用户的主目录
    - cd 中表示上一次所在目录

    路径包含空格或特殊字符时需要引用：

    cd -- "project files"

    -- 表示选项结束，可防止以 - 开头的文件名被当作选项。

    2. 查看和切换目录¶

    pwd：显示当前位置¶

    pwd

    /home/alice/projects

    pwd -P

    /home/alice/projects/current

    -P 显示解析符号链接后的物理路径。若当前目录是通过符号链接进入的，pwd 默认显示链接路径，-P 显示真实位置。

    ls：列出目录内容¶

    ls -lah

    total 28K
drwxr-xr-x  3 alice alice 4.0K Oct  9 10:00 .
drwxr-xr-x 12 alice alice 4.0K Oct  9 09:30 ..
drwxr-xr-x  4 alice alice 4.0K Oct  8 18:12 .git
-rw-r-----  1 alice alice  220 Oct  9 09:58 secret.txt
-rw-r--r--  1 alice alice 5.3K Oct  9 10:00 report.md
-rwxr-xr-x  1 alice alice  312 Oct  8 16:40 deploy.sh
    • total 28K：目录内所有条目占用的数据块总量。
    • 第一列是权限：d 开头是目录，- 开头是普通文件。
    • 随后是硬链接数、所有者、所属组、大小、修改时间、文件名。
    • 以 . 开头的条目（如 .git）是隐藏项，需要 -a 才显示。
    • deploy.sh 的权限以 rwx 开头，表示所有者可执行。
    ls -lt

    按修改时间从新到旧排序，最近改动的文件在最上面，适合快速找到刚编辑过的文件。

    ls -d */ 只列出目录本身，不展开目录内容，常用于快速查看当前目录下有哪些子目录。

    cd：切换目录¶

    cd /var/log
cd ..
cd ~
cd -

    cd - 会切换到上一次所在目录，适合在两个目录之间往返。

    3. 创建文件和目录¶

    mkdir：创建目录¶

    mkdir reports
mkdir -p data/raw/2026
mkdir -m 750 private-dir

    -p 会创建缺失的父目录，目录已存在时不报错。

    touch：创建空文件或更新时间¶

    touch notes.txt

    文件不存在时创建空文件（大小为 0）；已存在时只更新时间戳：

    ls -l notes.txt

    -rw-r--r-- 1 alice alice 0 Oct 12 10:00 notes.txt

    大小列显示 0，说明是新创建的空文件，内容不会被清空。

    mktemp：安全创建临时项¶

    tmp_file=$(mktemp)
tmp_dir=$(mktemp -d)

    脚本中应优先使用 mktemp，不要用可预测的固定临时文件名。

    4. 复制与移动¶

    cp：复制¶

    cp source.txt backup.txt
cp source.txt /tmp/
cp -a project/ project-backup/
cp -i config.example config
    选项 说明
    -a 归档复制，递归并尽量保留属性和链接
    -r/-R 递归复制目录
    -i 覆盖前询问
    -n 不覆盖已有目标
    -v 显示处理过程
    -u 仅在源文件较新或目标不存在时复制

    目录末尾 / 的语义容易混淆。复制前可先创建测试目录验证结果，重要数据建议使用 cp -a 或 rsync 并检查目标。

    mv：移动或重命名¶

    mv old.txt new.txt
mv report.pdf archive/
mv -i config.new config

    同一文件系统内移动通常只是更新目录项；跨文件系统移动需要复制后删除，耗时和失败模式不同。

    5. 删除¶

    rm：删除文件或目录树¶

    rm -- old.log
rm -i important.txt
rm -r old-directory/
    选项 说明
    -r/-R 递归删除目录
    -i 每次删除前询问
    -I 删除多个文件或递归删除前统一确认一次
    -f 忽略不存在的文件并且不询问

    rm 通常不经过回收站。不要组合使用未经检查的变量、通配符、sudo 和 rm -rf。

    检查通配符会匹配什么：

    printf '%s\n' ./*.log

    删除空目录：

    rmdir empty-directory

    6. 链接¶

    创建硬链接¶

    ln source.txt hard-link.txt

    硬链接指向同一个 inode，通常不能跨文件系统，也不能用于目录。

    创建符号链接¶

    ln -s /opt/app/current app-current
ln -sfn /opt/app/releases/v2 app-current

    符号链接保存目标路径，可以跨文件系统。相对链接的目标是相对于“链接所在目录”解析，不是相对于创建命令时的当前目录。

    查看链接：

    ls -l app-current

    lrwxrwxrwx 1 alice alice 22 Oct 12 10:00 app-current -> /opt/app/releases/v2

    权限首字符 l 表示符号链接，-> 后是目标路径。

    readlink -f app-current

    /opt/app/releases/v2

    readlink -f 会一路解析到最终的非链接目标，常用于确认“当前版本”实际指向哪里。

    7. 查看文件信息¶

    file download.bin

    download.bin: ELF 64-bit LSB pie executable, x86-64, dynamically linked, ...

    file 根据内容特征判断类型，不受扩展名影响。

    stat report.txt

      File: report.txt
  Size: 5423        Blocks: 16        IO Block: 4096   regular file
Device: 802h/2050d  Inode: 1329123     Links: 1
Access: (0644/-rw-r--r--)  Uid: ( 1000/alice)   Gid: ( 1000/alice)
Modify: 2026-10-12 10:00:00.123456789 +0800

    Size 是逻辑大小（字节），Blocks 是实际占用的 512 字节块数；Inode 是文件系统内的唯一编号；Modify 是内容修改时间。

    basename /var/log/app.log
dirname /var/log/app.log

    app.log
/var/log

    basename 提取文件名，dirname 提取目录部分，常用于脚本中拆分路径。

    8. find：查找文件¶

    基本语法：

    find <起始路径> <条件> <动作>

    按名称和类型¶

    find . -type f -name '*.log'

    ./app/logs/access.log
./app/logs/error.log
./test/mock.log

    结果默认相对于起始路径 .。-name 后的模式要加引号，避免先被 Shell 展开。

    按大小和时间¶

    find . -type f -size +100M

    ./data/dump.sql

    只列出大于 100 MiB 的普通文件，适合快速定位占空间的文件。

    find . -type f -mtime -7

    列出最近 7 天内修改过的文件，常用于确认“刚才改了哪些东西”。

    • -mtime -7：修改时间不足 7 个 24 小时。
    • -mtime +7：修改时间超过 7 个 24 小时。
    • -size +100M：大于 100 MiB。

    排除目录¶

    find . -path './.git' -prune -o -type f -name '*.md' -print

    对结果执行命令¶

    find . -type f -name '*.tmp' -print
find . -type f -name '*.tmp' -exec rm -i -- {} +

    先将动作写成 -print 检查结果，再执行修改。-exec ... {} + 会批量传参，比每个文件执行一次的 {} \; 更高效。

    安全处理任意文件名：

    find . -type f -print0 | xargs -0 command

    9. 常见组合¶

    创建备份副本¶

    cp -a config.yml "config.yml.$(date +%Y%m%d-%H%M%S).bak"

    找出最近修改的文件¶

    find . -type f -printf '%T@ %p\0' |
sort -z -nr |
head -z -n 10 |
tr '\0' '\n'

    以上 GNU 工具写法可安全处理包含空格的文件名，但换行仍会影响最终显示。

    批量创建目录¶

    mkdir -p project/{src,test,docs,build}

    花括号展开由 Shell 完成，会创建四个子目录。

    10. 命令速查¶

    需求 命令
    当前路径 pwd
    详细列出全部文件 ls -lah
    创建多级目录 mkdir -p a/b/c
    保留属性复制目录 cp -a src/ backup/
    重命名 mv old new
    创建符号链接 ln -s target link
    查看文件元数据 stat file
    按名称查找 find . -type f -name '*.log'
    查找大文件 find . -type f -size +1G
    删除空目录 rmdir dir

    对文件执行批量修改前，先用 find ... -print 或 printf 检查目标列表。
