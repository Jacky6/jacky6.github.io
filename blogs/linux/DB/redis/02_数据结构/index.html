    02_数据结构¶

    Redis 的核心价值在于其丰富的数据结构。本章详解 5 种基本数据结构。

    1. 数据结构概览¶

    Redis 提供 11 种核心数据结构，分为：

    1.1 基本数据结构（5 种）¶

    数据结构 说明 典型场景
    String 字符串（二进制安全） 缓存、计数器、Session
    List 列表（双向链表） 队列、栈、消息流
    Hash 哈希（字段 - 值映射） 对象存储、购物车
    Set 集合（去重、无序） 标签、好友关系
    Sorted Set 有序集合（带分数） 排行榜、优先级队列

    1.2 高级数据结构¶

    数据结构 说明 典型场景
    Bitmap 位图 签到、状态标记
    HyperLogLog 基数统计 UV 统计
    Geo 地理位置 附近的人
    Stream 流 消息队列、事件日志
    JSON JSON 文档 文档存储
    Vector Set 向量集合 AI 向量搜索

    2. String（字符串）¶

    2.1 概述¶

    String 是 Redis 最基本的数据类型，二进制安全，最大能存储 512MB。

    内部编码：
┌─────────────────────────────────────┐
│  SDS (Simple Dynamic String)        │
│  ┌─────┬───────────┬─────────────┐  │
│  │ len │ allocated │    data     │  │
│  │ 5   │    10     │ "hello"\0   │  │
│  └─────┴───────────┴─────────────┘  │
└─────────────────────────────────────┘

    2.2 基本命令¶

    # ===== 设置/获取 =====
SET key value                    # 设置字符串
GET key                          # 获取字符串
MSET key1 val1 key2 val2         # 批量设置
MGET key1 key2                   # 批量获取
SETNX key value                  # 不存在则设置
SETEX key seconds value          # 设置带过期时间
SET key value EX 60              # 60 秒过期
GETSET key value                 # 设置并返回旧值
GETRANGE key start end           # 获取子串
SETRANGE key offset value        # 设置子串
APPEND key value                 # 追加
STRLEN key                       # 获取长度

# ===== 数值操作 =====
INCR key                         # 自增 1
INCRBY key N                     # 自增 N
INCRBYFLOAT key N                # 自增浮点数
DECR key                         # 自减 1
DECRBY key N                     # 自减 N

# ===== 位操作 =====
SETBIT key offset value          # 设置位
GETBIT key offset                # 获取位
BITCOUNT key                     # 统计 1 的数量
BITOP AND|OR|XOR|NOT dst src...  # 位运算

    2.3 实战示例¶

    # ===== 场景 1：缓存用户信息 =====
127.0.0.1:6379> SET user:1001:name "张三"
OK
127.0.0.1:6379> SETEX user:1001:session 1800 "session_abc123"
OK
127.0.0.1:6379> TTL user:1001:session
(integer) 1795

# ===== 场景 2：计数器 =====
127.0.0.1:6379> SET article:1001:views 0
OK
127.0.0.1:6379> INCR article:1001:views
(integer) 1
127.0.0.1:6379> INCRBY article:1001:views 100
(integer) 102

# ===== 场景 3：分布式锁 =====
127.0.0.1:6379> SET lock:order:1001 "worker-1" NX EX 30
OK
127.0.0.1:6379> SET lock:order:1001 "worker-2" NX EX 30
(nil)  # 获取锁失败

# ===== 场景 4：位图签到 =====
127.0.0.1:6379> SETBIT user:1001:checkin 0 1
(integer) 0
127.0.0.1:6379> SETBIT user:1001:checkin 2 1
(integer) 0
127.0.0.1:6379> BITCOUNT user:1001:checkin
(integer) 3  # 签到 3 天

    2.4 内部编码¶

    编码 条件 说明
    int 字符串是整数 8 字节长整型
    embstr 字符串 ≤ 44 字节 嵌入字符串
    raw 字符串 > 44 字节 简单动态字符串（SDS） 
    127.0.0.1:6379> SET number 100
OK
127.0.0.1:6379> OBJECT ENCODING number
"int"

127.0.0.1:6379> SET short "hello"
OK
127.0.0.1:6379> OBJECT ENCODING short
"embstr"

    3. List（列表）¶

    3.1 概述¶

    List 是字符串列表，按插入顺序排序，底层是双向链表。

    双向链表：NULL ←→ [val1] ←→ [val2] ←→ [val3] ←→ NULL
操作：LPUSH(左插) RPUSH(右插) LPOP(左出) RPOP(右出)

    3.2 基本命令¶

    # ===== 插入 =====
LPUSH key val [val ...]          # 左侧插入
RPUSH key val [val ...]          # 右侧插入
LPUSHX key val                   # 左侧插入（仅当 key 存在）
RPUSHX key val                   # 右侧插入（仅当 key 存在）
LINSERT key BEFORE|AFTER pivot val  # 在指定值前/后插入

# ===== 弹出 =====
LPOP key [count]                 # 左侧弹出
RPOP key [count]                 # 右侧弹出
BLPOP key [key ...] timeout      # 阻塞式左侧弹出
BRPOP key [key ...] timeout      # 阻塞式右侧弹出

# ===== 查询 =====
LRANGE key start stop            # 获取范围
LINDEX key index                 # 获取指定索引
LLEN key                         # 获取长度

# ===== 修改 =====
LSET key index value             # 设置指定索引的值
LREM key count value             # 删除指定值
LTRIM key start stop             # 截取列表
LMOVE src dst LEFT|RIGHT LEFT|RIGHT  # 移动元素

    3.3 实战示例¶

    # ===== 场景 1：消息队列 =====
127.0.0.1:6379> RPUSH queue:emails "email1" "email2" "email3"
(integer) 3
127.0.0.1:6379> LPOP queue:emails
"email1"
127.0.0.1:6379> BLPOP queue:emails 5  # 阻塞等待

# ===== 场景 2：栈（LIFO） =====
127.0.0.1:6379> LPUSH stack:browser "page1" "page2" "page3"
(integer) 3
127.0.0.1:6379> LPOP stack:browser
"page3"  # 后进先出

# ===== 场景 3：最新文章 =====
127.0.0.1:6379> LPUSH articles:latest "article:100" "article:99"
(integer) 2
127.0.0.1:6379> LTRIM articles:latest 0 9  # 保持最新 10 篇
OK

# ===== 场景 4：优先级队列 =====
127.0.0.1:6379> LPUSH tasks:priority "task:high:1"  # 高优先级
(integer) 1
127.0.0.1:6379> RPUSH tasks:priority "task:normal:1"  # 普通
(integer) 2
127.0.0.1:6379> LPOP tasks:priority
"task:high:1"  # 先处理高优先级

    3.4 内部编码¶

    编码 条件 说明
    ziplist 元素<512 且每个<64 字节 压缩列表
    linkedlist 不满足 ziplist 双向链表

    4. Hash（哈希）¶

    4.1 概述¶

    Hash 是字段 - 值映射，适合存储对象。

    user:1001 → {name: 张三，email: zhangsan@..., age: 25, city: 北京}

    4.2 基本命令¶

    # ===== 字段操作 =====
HSET key field value             # 设置单个字段
HMSET key f1 v1 f2 v2            # 设置多个字段
HGET key field                   # 获取单个字段
HMGET key f1 f2                  # 获取多个字段
HGETALL key                      # 获取所有字段
HKEYS key                        # 获取所有字段名
HVALS key                        # 获取所有值
HLEN key                         # 获取字段数量
HEXISTS key field                # 判断字段是否存在
HDEL key field [field ...]       # 删除字段

# ===== 数值操作 =====
HINCRBY key field increment      # 字段自增
HINCRBYFLOAT key field inc       # 字段自增浮点数

# ===== 其他 =====
HSETNX key field value           # 不存在则设置
HSTRLEN key field                # 获取字段值长度
HRANDFIELD key [count] [WITHVALUES]  # 随机获取字段

    4.3 实战示例¶

    # ===== 场景 1：用户信息 =====
127.0.0.1:6379> HSET user:1001 name "张三" email "zhangsan@example.com" age 25
(integer) 3
127.0.0.1:6379> HGET user:1001 name
"张三"
127.0.0.1:6379> HMGET user:1001 name email
1) "张三"
2) "zhangsan@example.com"
127.0.0.1:6379> HGETALL user:1001
1) "name"  2) "张三"  3) "email"  4) "zhangsan@example.com"  5) "age"  6) "25"

# ===== 场景 2：购物车 =====
127.0.0.1:6379> HSET cart:user1001 product:1001 2 product:1002 1
(integer) 2
127.0.0.1:6379> HINCRBY cart:user1001 product:1001 3
(integer) 5  # 数量变为 5
127.0.0.1:6379> HDEL cart:user1001 product:1002
(integer) 1

# ===== 场景 3：文章统计 =====
127.0.0.1:6379> HINCRBY article:1001:stats views 1
(integer) 1
127.0.0.1:6379> HINCRBY article:1001:stats likes 1
(integer) 1
127.0.0.1:6379> HGETALL article:1001:stats
1) "views"  2) "1"  3) "likes"  4) "1"

    4.4 内部编码¶

    编码 条件 说明
    ziplist 字段<512 且每个值<64 字节 压缩列表
    hashtable 不满足 ziplist 哈希表

    5. Set（集合）¶

    5.1 概述¶

    Set 是无序、去重的字符串集合，支持集合运算。

    5.2 基本命令¶

    # ===== 成员操作 =====
SADD key member [member ...]     # 添加成员
SREM key member [member ...]     # 删除成员
SPOP key [count]                 # 随机弹出
SRANDMEMBER key [count]          # 随机获取（不删除）
SISMEMBER key member             # 判断是否存在
SMEMBERS key                     # 获取所有成员
SCARD key                        # 获取集合大小

# ===== 集合运算 =====
SDIFF key [key ...]              # 差集
SDIFFSTORE dst key [key ...]     # 差集并存储
SINTER key [key ...]             # 交集
SINTERSTORE dst key [key ...]    # 交集并存储
SUNION key [key ...]             # 并集
SUNIONSTORE dst key [key ...]    # 并集并存储
SMOVE src dst member             # 移动成员

    5.3 实战示例¶

    # ===== 场景 1：文章标签 =====
127.0.0.1:6379> SADD tags:article:1001 "python" "redis" "database"
(integer) 3
127.0.0.1:6379> SADD tags:article:1001 "python"  # 重复，自动去重
(integer) 0
127.0.0.1:6379> SMEMBERS tags:article:1001
1) "python"  2) "redis"  3) "database"
127.0.0.1:6379> SISMEMBER tags:article:1001 "python"
(integer) 1

# ===== 场景 2：共同好友 =====
127.0.0.1:6379> SADD friends:A "B" "C" "D"
(integer) 3
127.0.0.1:6379> SADD friends:B "A" "C" "E"
(integer) 3
127.0.0.1:6379> SINTER friends:A friends:B  # 共同好友
1) "C"
127.0.0.1:6379> SDIFF friends:A friends:B  # A 有 B 没有
1) "D"
127.0.0.1:6379> SUNION friends:A friends:B  # 所有好友
1) "A"  2) "B"  3) "C"  4) "D"  5) "E"

# ===== 场景 3：抽奖 =====
127.0.0.1:6379> SADD lottery "user1" "user2" "user3" "user4" "user5"
(integer) 5
127.0.0.1:6379> SRANDMEMBER lottery 3  # 随机抽 3 个
1) "user3"  2) "user1"  3) "user5"
127.0.0.1:6379> SPOP lottery 2  # 随机抽 2 个并删除
1) "user2"  2) "user4"

# ===== 场景 4：在线用户 =====
127.0.0.1:6379> SADD online:users "user1" "user2" "user3"
(integer) 3
127.0.0.1:6379> SCARD online:users
(integer) 3  # 在线人数
127.0.0.1:6379> SREM online:users "user2"
(integer) 1  # 用户下线

    5.4 内部编码¶

    编码 条件 说明
    intset 所有成员都是整数 整数集合
    hashtable 不满足 intset 哈希表

    6. Sorted Set（有序集合）¶

    6.1 概述¶

    Sorted Set（ZSet）是带分数的集合，元素按分数排序。

    leaderboard → {Alice:100(1st), Charlie:92(2nd), Bob:85(3rd)}

    6.2 基本命令¶

    # ===== 成员操作 =====
ZADD key [NX|XX] [GT|LT] [CH] score member [score member ...]
ZREM key member [member ...]     # 删除成员
ZSCORE key member                # 获取分数
ZRANK key member                 # 获取排名（从低到高）
ZREVRANK key member              # 获取排名（从高到低）
ZCARD key                        # 获取成员数量
ZCOUNT key min max               # 统计分数范围内数量

# ===== 范围查询 =====
ZRANGE key start stop [WITHSCORES]           # 按排名（低→高）
ZREVRANGE key start stop [WITHSCORES]        # 按排名（高→低）
ZRANGEBYSCORE key min max [WITHSCORES] [LIMIT o c]  # 按分数
ZREVRANGEBYSCORE key min max [WITHSCORES]    # 按分数（高→低）

# ===== 数值操作 =====
ZINCRBY key increment member     # 增加分数

# ===== 集合运算 =====
ZINTER key1 key2 [WEIGHTS w1 w2] [AGGREGATE SUM|MIN|MAX]
ZINTERSTORE dst numkeys key [key ...] [WEIGHTS ...] [AGGREGATE ...]
ZUNION key1 key2 [WEIGHTS w1 w2] [AGGREGATE SUM|MIN|MAX]
ZUNIONSTORE dst numkeys key [key ...] [WEIGHTS ...] [AGGREGATE ...]

# ===== 其他 =====
ZRANDMEMBER key [count] [WITHSCORES]  # 随机获取
ZREMRANGEBYRANK key min max      # 删除排名范围
ZREMRANGEBYSCORE key min max     # 删除分数范围

    6.3 实战示例¶

    # ===== 场景 1：游戏排行榜 =====
127.0.0.1:6379> ZADD leaderboard 9500 "Alice" 8700 "Bob" 9200 "Charlie" 9800 "David"
(integer) 4
127.0.0.1:6379> ZREVRANGE leaderboard 0 2 WITHSCORES  # 前 3 名
1) "David"   2) "9800"
3) "Alice"   4) "9500"
5) "Charlie" 6) "9200"
127.0.0.1:6379> ZREVRANK leaderboard "Bob"
(integer) 3  # 第 4 名
127.0.0.1:6379> ZSCORE leaderboard "Alice"
"9500"
127.0.0.1:6379> ZINCRBY leaderboard 500 "Bob"
"9200"  # Bob 分数增加

# ===== 场景 2：优先级队列 =====
127.0.0.1:6379> ZADD tasks 10 "urgent:1" 5 "normal:1" 1 "low:1"
(integer) 3
127.0.0.1:6379> ZREVRANGE tasks 0 0  # 获取最高优先级
1) "urgent:1"
127.0.0.1:6379> ZREM tasks "urgent:1"
(integer) 1

# ===== 场景 3：延时队列 =====
# 分数=执行时间戳
127.0.0.1:6379> ZADD queue:delayed 1711353600 "task1" 1711353660 "task2"
(integer) 2
127.0.0.1:6379> ZRANGEBYSCORE queue:delayed 0 1711353650  # 可执行任务
1) "task1"

# ===== 场景 4：多维度排行榜 =====
# 创建各维度分数
127.0.0.1:6379> ZADD rank:math 95 "Alice" 88 "Bob" 92 "Charlie"
127.0.0.1:6379> ZADD rank:english 90 "Alice" 95 "Bob" 85 "Charlie"

# 计算总分（权重：数学 60%，英语 40%）
127.0.0.1:6379> ZINTERSTORE rank:total 2 rank:math rank:english WEIGHTS 0.6 0.4 AGGREGATE SUM
(integer) 3
127.0.0.1:6379> ZREVRANGE rank:total 0 -1 WITHSCORES
1) "Alice"   2) "93"    # 95*0.6 + 90*0.4
3) "Bob"     4) "90.8"  # 88*0.6 + 95*0.4
5) "Charlie" 6) "89.2"  # 92*0.6 + 85*0.4

    6.4 内部编码¶

    编码 条件 说明
    ziplist 元素<128 且每个值<64 字节 压缩列表
    skiplist 不满足 ziplist 跳表 + 字典

    跳表结构： 

    Level 4:   ──────────────────────────────────▶
Level 3:   ────────▶─────────────────────────▶
Level 2:   ────▶───▶───────▶─────────────────▶
Level 1:   ──▶─▶─▶─▶─▶─▶─▶─▶─▶─▶─▶─▶─▶─▶─▶─▶
          head  10  20  30  40  50  60  70  tail

    7. 数据结构选择指南¶

    需求 推荐数据结构 理由
    简单缓存 String 最简单，支持过期
    计数器 String INCR 原子操作
    对象存储 Hash 字段级操作，节省内存
    队列/栈 List LPUSH/RPOP 实现
    消息队列 List/Stream BLPOP 阻塞消费
    去重集合 Set 自动去重
    共同好友 Set SINTER 交集
    排行榜 Sorted Set 自动排序，范围查询
    优先级队列 Sorted Set 分数=优先级
    签到统计 Bitmap 节省空间
    UV 统计 HyperLogLog 近似但高效
    地理位置 Geo 内置地理计算

    8. 本章小结¶

    核心知识点¶

    ✅ String：缓存、计数器、分布式锁
    ✅ List：队列、栈、最新消息
    ✅ Hash：对象存储、购物车
    ✅ Set：标签、好友、抽奖
    ✅ Sorted Set：排行榜、优先级队列

    时间复杂度速查¶

    数据结构 操作 时间复杂度
    String GET/SET O(1)
    List LPUSH/RPOP O(1)
    List LINDEX O(N)
    Hash HGET/HSET O(1)
    Set SADD/SISMEMBER O(1)
    Set SINTER O(N*M)
    ZSet ZADD/ZSCORE O(logN)
    ZSet ZRANGE O(logN+M)
