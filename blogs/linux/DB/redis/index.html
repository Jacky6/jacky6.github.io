    📋 前置知识¶

    • Linux 基础操作
    • 网络基础（TCP/IP、HTTP）
    • 至少一门编程语言（Python/Java/Go）
    • 数据库基础概念

    🛠️ 环境准备¶

    推荐配置¶

    组件 版本 说明
    Redis 7.x 最新稳定版
    OS Linux Ubuntu/CentOS
    内存 4GB+ 本地学习足够
    Docker 20.x 可选，用于多实例测试

    快速安装¶

    # Ubuntu/Debian
sudo apt update
sudo apt install redis-server

# CentOS/RHEL
sudo yum install redis

# macOS
brew install redis

# Docker
docker run -d -p 6379:6379 --name redis redis:latest

    🎓 学习建议¶

    1. 动手实践：每个命令都要亲自执行
    2. 理解原理：不要死记硬背，理解背后的设计思想
    3. 场景驱动：结合实际应用场景学习
    4. 循序渐进：按顺序学习，不要跳章节
    5. 定期复习：Redis 知识点较多，需要反复巩固
