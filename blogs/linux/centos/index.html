    CentOS 开发环境使用教程¶

    面向日常开发与服务器开发环境，主要基于 CentOS Stream 9。CentOS Stream 10 的 DNF 版本和部分软件包名称可能不同，执行前请先核对系统版本。

    教程目录¶

    # 文件 内容
    01 系统初始化与安全配置 版本检查、更新、用户与权限、SSH、时间同步、SELinux 基础
    02 DNF 软件包管理 软件安装、仓库、EPEL、模块流、版本锁定和历史回滚
    03 开发环境搭建 Git、编译工具、Python、Node.js、Java、Go 与数据库客户端
    04 服务、网络与安全策略 systemd、journald、NetworkManager、firewalld 与 SELinux
    05 容器开发环境 Podman、Compose、Docker、rootless 容器与数据持久化
    06 排错与命令速查 资源、进程、端口、日志、权限、SELinux 和排障流程

    推荐学习路线¶

    新机器：01 → 02 → 03
服务开发：04 → 05
日常维护：06

    版本说明¶

    • CentOS Stream 9/10 是位于 Fedora 与 RHEL 之间的持续交付发行版，适合开发、测试和参与 RHEL 生态。
    • CentOS Linux 7 已于 2024-06-30 结束维护。
    • CentOS Linux 8 已于 2021-12-31 结束维护。
    • 不应继续把已停止维护的 CentOS Linux 作为新生产环境基础镜像；可根据兼容性与支持需求评估 CentOS Stream、RHEL、Rocky Linux 或 AlmaLinux。

    使用约定¶

    • 命令默认在 Bash 中执行。
    • 需要管理员权限时使用 sudo，不建议长期以 root 登录。
    • 不以关闭 SELinux 或 firewalld 作为排错方案，应根据日志配置正确的安全策略。
    • 修改 SSH、防火墙前保留已登录终端，确认新连接可用后再退出。
    • 第三方仓库和安装步骤可能变化，生产环境使用前应核对项目官方文档和软件包签名。

    查看系统版本：cat /etc/os-release；查看 CentOS RPM 版本：rpm -q centos-stream-release。
