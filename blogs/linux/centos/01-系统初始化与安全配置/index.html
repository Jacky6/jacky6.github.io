    01. CentOS 系统初始化与安全配置¶

    1. 确认系统信息¶

    cat /etc/os-release
rpm -q centos-stream-release
uname -a
uname -m
hostnamectl

    常见架构为 x86_64 和 aarch64。安装第三方 RPM 或二进制文件时必须匹配系统架构和发行版主版本。

    2. 更新系统¶

    sudo dnf check-update
sudo dnf upgrade --refresh
sudo dnf autoremove

    dnf check-update 在发现可更新软件包时可能返回退出码 100，不代表命令执行失败。

    安装重启检查工具：

    sudo dnf install dnf-plugins-core
sudo dnf needs-restarting -r

    涉及内核、glibc、systemd 的更新应安排维护窗口，并在重启后确认服务与监控正常。

    3. 设置主机名、时区与时间同步¶

    sudo hostnamectl set-hostname dev-server
sudo timedatectl set-timezone Asia/Shanghai
timedatectl status

    CentOS 默认使用 chrony：

    sudo systemctl enable --now chronyd
chronyc tracking
chronyc sources -v

    4. 创建开发用户¶

    sudo useradd -m -s /bin/bash developer
sudo passwd developer
sudo usermod -aG wheel developer
id developer

    wheel 组默认拥有 sudo 权限。检查规则：

    sudo visudo

    权限原则：

    • 日常开发使用普通用户，需要时通过 sudo 提权。
    • 使用 visudo 修改 sudoers，避免语法错误导致无法提权。
    • 不执行 chmod -R 777，应配置正确的用户、组和 SELinux 上下文。
    • 新增附加组后重新登录，使组权限生效。

    5. SSH 密钥登录¶

    在本地生成并复制密钥：

    ssh-keygen -t ed25519 -C "developer@workstation"
ssh-copy-id developer@server-ip

    确认密钥登录成功后，在服务器创建加固配置：

    sudoedit /etc/ssh/sshd_config.d/99-hardening.conf

    PermitRootLogin no
PubkeyAuthentication yes
PasswordAuthentication no

    校验并重载：

    sudo sshd -t
sudo systemctl reload sshd

    查看日志：

    sudo journalctl -u sshd --since today
sudo tail -f /var/log/secure

    禁用密码登录前，必须在另一个终端验证密钥登录；同时确保 firewalld 和云安全组已放行 SSH。

    6. SELinux 基础检查¶

    getenforce
sestatus
ls -Z /etc/ssh/sshd_config

    推荐保持 Enforcing。临时关闭 SELinux 只会隐藏策略问题，还会降低系统安全性。遇到权限问题时应检查 AVC 日志：

    sudo ausearch -m AVC -ts recent

    SELinux 的具体处理方式见服务、网络与安全策略。

    7. 规划开发目录¶

    mkdir -p "$HOME/code" "$HOME/bin" "$HOME/.local/bin"
printf '\nexport PATH="$HOME/.local/bin:$HOME/bin:$PATH"\n' >> ~/.bashrc
source ~/.bashrc

    推荐目录：

    路径 用途
    ~/code 当前用户的项目源码
    ~/.local/bin 当前用户安装的命令行工具
    /opt/<app> 独立第三方应用或部署包
    /srv/<app> 服务数据或站点内容
    /etc/<app> 系统级配置
    /var/lib/<app> 应用持久化状态
    /var/log/<app> 应用日志

    移动服务目录后，应同时检查 Unix 权限和 SELinux 上下文。
