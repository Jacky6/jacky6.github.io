    08_代理模式¶

    1. 代理模式概述¶

    知识点： - 代理模式：为其他对象提供替身以控制访问 - 代理与真实对象实现同一接口，客户端无感知 - ⭐ 应用：Spring AOP、MyBatis Mapper、RPC 远程调用、事务控制

    1.1 什么是代理模式¶

    代理模式（Proxy Pattern）为其他对象提供一种代理以控制对这个对象的访问。

    适用场景： - ✅ 远程代理（RPC） - ✅ 虚拟代理（延迟加载） - ✅ 保护代理（权限控制） - ✅ 智能代理（日志、缓存）

    1.2 生活中的例子¶

    经纪人代理明星：
- 客户 → 经纪人 → 明星
- 经纪人处理预约、合同等事务

公司前台：
- 访客 → 前台 → 员工
- 前台过滤、登记访客

    2. 实现方式¶

    知识点： - 静态代理：编译期写好代理类（每个被代理类都要写一个） - ⭐ JDK 动态代理：基于接口（Proxy + InvocationHandler） - ⭐ CGLIB：基于继承生成子类（无接口的类用它，final 方法不能代理）

    2.1 静态代理¶

    // 主题接口
public interface Subject {
    void request();
}

// 真实主题
public class RealSubject implements Subject {
    @Override
    public void request() {
        System.out.println("真实请求");
    }
}

// 代理
public class Proxy implements Subject {
    private RealSubject realSubject;

    @Override
    public void request() {
        // 前置处理
        beforeRequest();

        // 创建或获取真实主题
        if (realSubject == null) {
            realSubject = new RealSubject();
        }

        // 调用真实主题
        realSubject.request();

        // 后置处理
        afterRequest();
    }

    private void beforeRequest() {
        System.out.println("前置处理：权限验证");
    }

    private void afterRequest() {
        System.out.println("后置处理：日志记录");
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Subject proxy = new Proxy();
        proxy.request();
        // 输出：
        // 前置处理：权限验证
        // 真实请求
        // 后置处理：日志记录
    }
}

    2.2 动态代理（JDK）¶

    import java.lang.reflect.*;

// 主题接口
public interface Subject {
    void request();
}

// 真实主题
public class RealSubject implements Subject {
    @Override
    public void request() {
        System.out.println("真实请求");
    }
}

//  InvocationHandler
public class ProxyHandler implements InvocationHandler {
    private Object target;

    public ProxyHandler(Object target) {
        this.target = target;
    }

    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        // 前置处理
        System.out.println("前置处理");

        // 调用真实方法
        Object result = method.invoke(target, args);

        // 后置处理
        System.out.println("后置处理");

        return result;
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        RealSubject realSubject = new RealSubject();

        // 创建代理
        Subject proxy = (Subject) Proxy.newProxyInstance(
            realSubject.getClass().getClassLoader(),
            realSubject.getClass().getInterfaces(),
            new ProxyHandler(realSubject)
        );

        proxy.request();
    }
}

    2.3 动态代理（CGLIB）¶

    // CGLIB 不需要接口，通过继承实现
// 需要引入 cglib 依赖

import net.sf.cglib.proxy.*;

public class CglibProxy implements MethodInterceptor {
    @Override
    public Object intercept(Object obj, Method method, Object[] args, 
                           MethodProxy proxy) throws Throwable {
        System.out.println("前置处理");
        Object result = proxy.invokeSuper(obj, args);
        System.out.println("后置处理");
        return result;
    }

    public static <T> T createProxy(Class<T> clazz) {
        Enhancer enhancer = new Enhancer();
        enhancer.setSuperclass(clazz);
        enhancer.setCallback(new CglibProxy());
        return (T) enhancer.create();
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        RealService service = CglibProxy.createProxy(RealService.class);
        service.doSomething();
    }
}

    3. 代理类型¶

    知识点： - 远程代理（RPC stub）、虚拟代理（延迟加载）、保护代理（权限）、智能代理（附加逻辑）

    3.1 远程代理¶

    // RPC 框架中的代理
public interface UserService {
    User getUserById(Long id);
}

// 客户端代理
public class UserServiceProxy implements UserService {
    private String serverUrl = "http://api.example.com";

    @Override
    public User getUserById(Long id) {
        // 发送 HTTP 请求
        String response = HttpClient.get(serverUrl + "/users/" + id);

        // 解析响应
        return JSON.parseObject(response, User.class);
    }
}

    3.2 虚拟代理（延迟加载）¶

    public interface Image {
    void display();
}

// 真实图片
public class RealImage implements Image {
    private String filename;

    public RealImage(String filename) {
        this.filename = filename;
        loadImage();  // 耗时操作
    }

    private void loadImage() {
        System.out.println("加载图片：" + filename);
    }

    @Override
    public void display() {
        System.out.println("显示图片：" + filename);
    }
}

// 代理（延迟加载）
public class ProxyImage implements Image {
    private String filename;
    private RealImage realImage;

    public ProxyImage(String filename) {
        this.filename = filename;
    }

    @Override
    public void display() {
        // 第一次使用时才加载
        if (realImage == null) {
            realImage = new RealImage(filename);
        }
        realImage.display();
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Image image = new ProxyImage("large.jpg");

        // 此时不会加载图片
        System.out.println("创建完成");

        // 此时才会加载
        image.display();
    }
}

    3.3 保护代理¶

    public interface Document {
    void read();
    void write(String content);
}

public class ConfidentialDocument implements Document {
    @Override
    public void read() {
        System.out.println("阅读文档");
    }

    @Override
    public void write(String content) {
        System.out.println("写入文档：" + content);
    }
}

// 保护代理
public class DocumentProxy implements Document {
    private Document document;
    private String userRole;

    public DocumentProxy(String userRole) {
        this.document = new ConfidentialDocument();
        this.userRole = userRole;
    }

    @Override
    public void read() {
        if ("admin".equals(userRole) || "user".equals(userRole)) {
            document.read();
        } else {
            System.out.println("无权阅读");
        }
    }

    @Override
    public void write(String content) {
        if ("admin".equals(userRole)) {
            document.write(content);
        } else {
            System.out.println("无权写入");
        }
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Document adminProxy = new DocumentProxy("admin");
        adminProxy.read();   // 可以
        adminProxy.write("内容");  // 可以

        Document guestProxy = new DocumentProxy("guest");
        guestProxy.read();   // 无权
        guestProxy.write("内容");  // 无权
    }
}

    3.4 智能代理¶

    // 缓存代理
public class CacheProxy implements Subject {
    private RealSubject realSubject;
    private Map<String, Object> cache = new HashMap<>();

    @Override
    public Object request(String key) {
        // 检查缓存
        if (cache.containsKey(key)) {
            System.out.println("从缓存获取");
            return cache.get(key);
        }

        // 缓存未命中，调用真实主题
        if (realSubject == null) {
            realSubject = new RealSubject();
        }

        Object result = realSubject.request(key);
        cache.put(key, result);
        return result;
    }
}

// 日志代理
public class LoggingProxy implements Subject {
    private RealSubject realSubject;

    @Override
    public void request() {
        long start = System.currentTimeMillis();

        if (realSubject == null) {
            realSubject = new RealSubject();
        }

        realSubject.request();

        long end = System.currentTimeMillis();
        System.out.println("耗时：" + (end - start) + "ms");
    }
}

    4. 实战示例¶

    4.1 Spring AOP（代理模式应用）¶

    // Spring 使用动态代理实现 AOP

@Service
public class UserService {
    @Transactional
    public void createUser(User user) {
        // 业务逻辑
    }
}

// Spring 会创建代理对象，在方法前后添加事务处理
// 相当于：
UserService proxy = new TransactionProxy(new UserService());
proxy.createUser(user);

    4.2 MyBatis Mapper 代理¶

    // Mapper 接口
public interface UserMapper {
    User findById(Long id);
}

// MyBatis 使用动态代理实现接口
SqlSession session = sqlSessionFactory.openSession();
UserMapper mapper = session.getMapper(UserMapper.class);

    4.3 RPC 框架代理¶

    // 定义服务接口
public interface OrderService {
    Order createOrder(OrderRequest request);
}

// 客户端代理
public class OrderServiceProxy implements OrderService {
    private RpcClient rpcClient;

    @Override
    public Order createOrder(OrderRequest request) {
        // 序列化请求
        byte[] data = serialize(request);

        // 发送 RPC 请求
        byte[] response = rpcClient.send("orderService.createOrder", data);

        // 反序列化响应
        return deserialize(response, Order.class);
    }
}

// 使用
OrderService orderService = new OrderServiceProxy(rpcClient);
Order order = orderService.createOrder(request);

    5. 代理模式对比¶

    类型 实现方式 特点
    静态代理 手动编写代理类 简单、代码量大
    JDK 动态代理 InvocationHandler 需要接口
    CGLIB 动态代理 继承 不需要接口

    6. 优缺点¶

    知识点： - 优点：职责清晰、扩展横切逻辑不侵入业务 - 缺点：增加间接层（性能略降）、动态代理调试复杂

    6.1 优点¶

    • ✅ 控制访问：可以添加权限、日志等
    • ✅ 解耦：客户端不需要知道真实主题
    • ✅ 符合开闭原则：新增代理无需修改原有代码
    • ✅ 智能引用：延迟加载、缓存等

    6.2 缺点¶

    • ❌ 增加复杂度：引入额外的代理层
    • ❌ 性能开销：动态代理有反射开销
    • ❌ 调试困难：代理层增加调试难度

    7. 练习题¶

    1. 静态代理：ImageLoader 接口（load(path)），RealImageLoader 模拟耗时加载；编写 ImageLoaderProxy 增加缓存（同一路径只真实加载一次）和调用计数。
    2. JDK 动态代理：编写 PerformanceHandler 实现 InvocationHandler，统计任意接口方法的执行耗时；用 Proxy.newProxyInstance 创建代理，并以 UserService 接口验证。

    参考答案¶

    import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Method;
import java.lang.reflect.Proxy;
import java.util.HashMap;
import java.util.Map;

// ========== 练习 1：静态代理实现图片缓存 ==========

// 主题接口
public interface ImageLoader {
    void load(String path);
}

// 真实主题：模拟耗时的图片加载
public class RealImageLoader implements ImageLoader {
    @Override
    public void load(String path) {
        System.out.println("【真实加载】正在从磁盘加载图片：" + path);
        try {
            Thread.sleep(100);  // 模拟耗时操作
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}

// 静态代理：增加缓存 + 调用计数
public class ImageLoaderProxy implements ImageLoader {
    private final RealImageLoader realLoader = new RealImageLoader();
    private final Map<String, Boolean> cache = new HashMap<>();  // 已加载缓存
    private int callCount = 0;                                   // 调用计数

    @Override
    public void load(String path) {
        callCount++;
        if (cache.containsKey(path)) {
            // 命中缓存，直接返回，不再真实加载
            System.out.println("【缓存命中】" + path + "（跳过加载）");
            return;
        }
        realLoader.load(path);   // 未命中才委托真实对象
        cache.put(path, true);
    }

    public int getCallCount() { return callCount; }
}

// ========== 练习 2：JDK 动态代理统计方法耗时 ==========

// 示例业务接口
public interface UserService {
    String findUser(Long id);
}

// 真实实现
public class UserServiceImpl implements UserService {
    @Override
    public String findUser(Long id) {
        try {
            Thread.sleep(50);  // 模拟数据库查询
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        return "用户-" + id;
    }
}

// 动态代理的 InvocationHandler：统计任意方法耗时
public class PerformanceHandler implements InvocationHandler {
    private final Object target;  // 被代理的真实对象

    public PerformanceHandler(Object target) {
        this.target = target;
    }

    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        long start = System.currentTimeMillis();
        Object result = method.invoke(target, args);   // 反射调用真实方法
        long cost = System.currentTimeMillis() - start;
        System.out.println(method.getName() + "() 耗时：" + cost + " ms");
        return result;
    }

    // 工具方法：为任意接口创建性能代理
    @SuppressWarnings("unchecked")
    public static <T> T createProxy(T target, Class<T> interfaceType) {
        return (T) Proxy.newProxyInstance(
            interfaceType.getClassLoader(),
            new Class<?>[]{interfaceType},
            new PerformanceHandler(target));
    }
}

// ========== 验证 ==========
public class Main {
    public static void main(String[] args) {
        // 练习 1：同一图片只真实加载一次
        ImageLoaderProxy proxy = new ImageLoaderProxy();
        proxy.load("cat.png");   // 真实加载
        proxy.load("dog.png");   // 真实加载
        proxy.load("cat.png");   // 缓存命中
        System.out.println("总调用次数：" + proxy.getCallCount());  // 3

        // 练习 2：JDK 动态代理
        UserService userService = PerformanceHandler.createProxy(
            new UserServiceImpl(), UserService.class);
        System.out.println("查询结果：" + userService.findUser(1L));
    }
}

    8. 本章小结¶

    核心知识点¶

    ✅ 静态代理：手动编写代理类
    ✅ JDK 动态代理：InvocationHandler
    ✅ CGLIB 动态代理：继承实现
    ✅ 代理类型：远程、虚拟、保护、智能

    最佳实践¶

    1. 优先 JDK 动态代理：无需额外依赖
    2. 无接口用 CGLIB：Spring 默认策略
    3. 明确代理目的：权限、缓存、日志等
    4. 避免过度代理：不要滥用
