    05. 依赖注入¶

    什么是依赖注入？¶

    依赖注入（Dependency Injection, DI） 是一种设计模式，用于实现控制反转（Inversion of Control, IoC）。

    传统方式 vs 依赖注入¶

    // ❌ 传统方式：对象自己创建依赖
public class UserService {
    private UserRepository repository = new UserRepository();
    private EmailService email = new EmailService();

    // 问题：
    // 1. 紧耦合，难以替换实现
    // 2. 难以单元测试
    // 3. 职责不清晰
}

// ✅ 依赖注入：由容器注入依赖
public class UserService {
    private final UserRepository repository;
    private final EmailService email;

    // 通过构造函数注入
    public UserService(UserRepository repository, EmailService email) {
        this.repository = repository;
        this.email = email;
    }

    // 优点：
    // 1. 松耦合，容易替换实现
    // 2. 易于测试（可以注入 Mock）
    // 3. 职责清晰
}

    BeanFactory vs ApplicationContext¶

    特性 BeanFactory ApplicationContext
    定位 基础容器 高级容器（推荐）
    Bean 初始化 懒加载 预加载单例 Bean
    功能 基础 DI DI + AOP + 事件 + 国际化
    使用场景 资源受限环境 企业应用（默认）

    Bean 的作用域¶

    六种作用域¶

    // 1. singleton - 单例（默认）
// 整个应用中只有一个实例
@Scope("singleton")
@Component
public class UserService { ... }

// 2. prototype - 原型
// 每次请求都创建新实例
@Scope("prototype")
@Component
public class StatefulBean { ... }

// 3. request - 请求作用域（Web）
// 每个 HTTP 请求一个实例
@Scope(value = WebApplicationContext.SCOPE_REQUEST)
@Component
public class RequestBean { ... }

// 4. session - 会话作用域（Web）
// 每个 HTTP Session 一个实例
@Scope(value = WebApplicationContext.SCOPE_SESSION)
@Component
public class SessionBean { ... }

// 5. application - 应用作用域（Web）
// 每个 ServletContext 一个实例
@Scope(value = WebApplicationContext.SCOPE_APPLICATION)
@Component
public class ApplicationBean { ... }

// 6. websocket - WebSocket 作用域
@Scope(value = WebApplicationContext.SCOPE_WEBSOCKET)
@Component
public class WebSocketBean { ... }

    定义 Bean 的方式¶

    方式 1：组件扫描（推荐）¶

    // 自动扫描并注册为 Bean
@Component  // 通用组件
public class MyComponent { ... }

@Service    // 服务层
public class UserService { ... }

@Repository // 数据访问层
public class UserRepository { ... }

@Controller // MVC 控制器
public class HomeController { ... }

@RestController // REST 控制器
public class UserController { ... }

    配置扫描包： 

    @SpringBootApplication(scanBasePackages = {"com.example.demo", "com.example.lib"})
public class DemoApplication { ... }

    方式 2：@Bean 方法¶

    @Configuration
public class AppConfig {

    @Bean  // 方法返回值注册为 Bean
    public DataSource dataSource() {
        HikariDataSource ds = new HikariDataSource();
        ds.setJdbcUrl("jdbc:mysql://localhost:3306/mydb");
        ds.setUsername("root");
        ds.setPassword("password");
        return ds;
    }

    @Bean
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }

    // Bean 之间可以互相调用
    @Bean
    public ServiceA serviceA() {
        return new ServiceA(repository());
    }

    @Bean
    public Repository repository() {
        return new Repository();
    }
}

    方式 3：@Import 导入配置¶

    @Configuration
@Import({DataSourceConfig.class, SecurityConfig.class})
public class AppConfig {
    // 导入其他配置类
}

    依赖注入的方式¶

    1. 构造函数注入（推荐）¶

    @Service
public class UserService {
    private final UserRepository repository;
    private final EmailService email;

    // 构造函数注入
    public UserService(UserRepository repository, EmailService email) {
        this.repository = repository;
        this.email = email;
    }
}

    优点： - ✅ 依赖不可变（可以使用 final） - ✅ 保证依赖不为 null - ✅ 易于测试 - ✅ 清晰展示所有依赖

    2. Setter 注入¶

    @Service
public class UserService {
    private UserRepository repository;

    // Setter 注入
    @Autowired
    public void setRepository(UserRepository repository) {
        this.repository = repository;
    }
}

    适用场景： - 可选依赖 - 循环依赖

    3. 字段注入（不推荐）¶

    @Service
public class UserService {
    // 字段注入
    @Autowired
    private UserRepository repository;
}

    缺点： - ❌ 依赖可变 - ❌ 难以测试 - ❌ 隐藏了依赖关系 - ❌ 不符合单一职责原则

    @Autowired 详解¶

    自动装配¶

    @Service
public class UserService {

    // 按类型自动注入
    @Autowired
    private UserRepository repository;

    // 构造函数注入（Spring 4.3+ 可省略 @Autowired）
    public UserService(UserRepository repository) {
        this.repository = repository;
    }

    // Setter 注入
    @Autowired
    public void setRepository(UserRepository repository) {
        this.repository = repository;
    }
}

    按名称注入（@Qualifier）¶

    // 定义多个实现
public interface PaymentService {
    void pay();
}

@Service
@Qualifier("alipay")
public class AlipayService implements PaymentService {
    public void pay() { System.out.println("Alipay"); }
}

@Service
@Qualifier("wechat")
public class WechatService implements PaymentService {
    public void pay() { System.out.println("Wechat"); }
}

// 使用时指定名称
@Service
public class OrderService {
    private final PaymentService paymentService;

    public OrderService(@Qualifier("alipay") PaymentService paymentService) {
        this.paymentService = paymentService;
    }
}

    @Primary 首选 Bean¶

    @Service
@Primary  // 默认使用这个实现
public class AlipayService implements PaymentService { ... }

@Service
public class WechatService implements PaymentService { ... }

// 注入时不指定 @Qualifier 会使用 @Primary 标注的 Bean
@Service
public class OrderService {
    private final PaymentService paymentService;

    // 自动注入 AlipayService
    public OrderService(PaymentService paymentService) {
        this.paymentService = paymentService;
    }
}

    可选依赖¶

    @Service
public class UserService {

    // 使用 Optional
    private final Optional<EmailService> emailService;

    public UserService(Optional<EmailService> emailService) {
        this.emailService = emailService;
    }

    public void sendEmail() {
        emailService.ifPresent(service -> service.send());
    }

    // 使用 @Autowired(required = false)
    @Autowired(required = false)
    private NotificationService notificationService;

    // 使用 @Nullable
    @Nullable
    private NotificationService notificationService;
}

    生命周期回调¶

    @Component
public class MyBean {

    @PostConstruct  // 初始化后
    public void init() {
        System.out.println("Bean initialized");
    }

    @PreDestroy  // 销毁前
    public void cleanup() {
        System.out.println("Bean destroyed");
    }
}

// 或使用接口
public class MyBean implements InitializingBean, DisposableBean {
    public void afterPropertiesSet() { ... }  // 初始化
    public void destroy() { ... }              // 销毁
}

    条件化 Bean¶

    @Conditional¶

    @Configuration
public class AppConfig {

    // 当 classpath 中存在指定类时创建 Bean
    @Bean
    @ConditionalOnClass(name = "com.example.MyService")
    public MyService myService() {
        return new MyService();
    }

    // 当配置文件中存在指定属性时创建 Bean
    @Bean
    @ConditionalOnProperty(name = "my.feature.enabled", havingValue = "true")
    public FeatureService featureService() {
        return new FeatureService();
    }

    // 当环境中存在指定 Bean 时创建
    @Bean
    @ConditionalOnBean(DataSource.class)
    public JdbcTemplate jdbcTemplate(DataSource ds) {
        return new JdbcTemplate(ds);
    }

    // 当环境中不存在指定 Bean 时创建
    @Bean
    @ConditionalOnMissingBean
    public MyService myService() {
        return new MyService();
    }
}

    属性注入¶

    @Value¶

    @Component
public class MyComponent {

    // 注入简单属性
    @Value("${app.name}")
    private String appName;

    // 注入带默认值
    @Value("${app.port:8080}")
    private int port;

    // 注入列表
    @Value("${app.servers:server1,server2}")
    private List<String> servers;

    // 注入数组
    @Value("#{'${app.ids}'.split(',')}")
    private String[] ids;

    // SpEL 表达式
    @Value("#{systemProperties['user.name']}")
    private String userName;

    @Value("#{T(java.lang.Math).random() * 100}")
    private double random;
}

    @ConfigurationProperties（推荐）¶

    // 1. 定义配置类
@Component
@ConfigurationProperties(prefix = "app")
public class AppProperties {
    private String name;
    private int port;
    private List<String> servers;
    private Database database;

    // Getter 和 Setter
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    // ...

    // 嵌套配置
    public static class Database {
        private String url;
        private String username;
        private String password;
        // Getter 和 Setter
    }
}

// 2. application.yml
app:
  name: MyApp
  port: 8080
  servers:
    - server1
    - server2
  database:
    url: jdbc:mysql://localhost:3306/mydb

// 3. 使用

    Bean 的初始化和销毁¶

    生命周期¶

    实例化 → 属性注入 → 初始化 → 使用 → 销毁
           ↓           ↓              ↓
      @Autowired  @PostConstruct  @PreDestroy

    完整示例¶

    @Component
@Scope("singleton")
public class MyBean implements InitializingBean, DisposableBean {

    private final String name;

    // 构造器
    public MyBean() {
        this.name = "MyBean";
        System.out.println("1. 构造函数");
    }

    // 属性注入
    @Autowired
    public void setDependency(Dependency dep) {
        System.out.println("2. Setter 注入");
    }

    // InitializingBean
    @Override
    public void afterPropertiesSet() {
        System.out.println("3. afterPropertiesSet");
    }

    // @PostConstruct
    @PostConstruct
    public void postConstruct() {
        System.out.println("4. @PostConstruct");
    }

    // 业务方法
    public void doWork() {
        System.out.println("5. 执行业务");
    }

    // DisposableBean
    @Override
    public void destroy() {
        System.out.println("6. destroy");
    }

    // @PreDestroy
    @PreDestroy
    public void preDestroy() {
        System.out.println("7. @PreDestroy");
    }
}

    循环依赖¶

    问题示例¶

    @Service
public class ServiceA {
    private final ServiceB serviceB;

    public ServiceA(ServiceB serviceB) {
        this.serviceB = serviceB;
    }
}

@Service
public class ServiceB {
    private final ServiceA serviceA;  // 循环依赖！

    public ServiceB(ServiceA serviceA) {
        this.serviceA = serviceA;
    }
}

    解决方案¶

    方案 1：使用 Setter 注入 

    @Service
public class ServiceB {
    private ServiceA serviceA;

    @Autowired  // Setter 注入可以解决循环依赖
    public void setServiceA(ServiceA serviceA) {
        this.serviceA = serviceA;
    }
}

    方案 2：使用 @Lazy 

    @Service
public class ServiceA {
    private final ServiceB serviceB;

    public ServiceA(@Lazy ServiceB serviceB) {  // 懒加载
        this.serviceB = serviceB;
    }
}

    方案 3：重构代码（推荐） 

    // 提取公共逻辑到第三个服务
@Service
public class CommonService {
    // 公共逻辑
}

@Service
public class ServiceA {
    private final CommonService common;
    public ServiceA(CommonService common) {
        this.common = common;
    }
}

@Service
public class ServiceB {
    private final CommonService common;
    public ServiceB(CommonService common) {
        this.common = common;
    }
}

    最佳实践¶

    ✅ 推荐¶

    // 1. 优先使用构造函数注入
@Service
public class UserService {
    private final UserRepository repository;

    public UserService(UserRepository repository) {
        this.repository = repository;
    }
}

// 2. 使用 final 保证不可变
private final UserRepository repository;

// 3. 使用 @ConfigurationProperties 管理配置
@ConfigurationProperties(prefix = "app")
public class AppProperties { ... }

// 4. 使用 @Primary 标注默认实现
@Primary
@Service
public class DefaultService implements MyService { ... }

// 5. 保持 Bean 职责单一
@Service
public class UserService { ... }  // 只负责用户相关

@Service
public class EmailService { ... }  // 只负责邮件相关

    ❌ 避免¶

    // 1. 避免字段注入
@Autowired  // ❌
private UserRepository repository;

// 2. 避免循环依赖
// 重构代码而不是使用 @Lazy  workaround

// 3. 避免在 Bean 中保存可变状态
@Scope("singleton")
public class MyBean {
    private int count;  // ❌ 单例中保存可变状态
}

// 4. 避免过度使用 @ComponentScan
@ComponentScan(basePackages = "com")  // ❌ 范围太大
@ComponentScan(basePackages = "com.example.demo")  // ✅
