    02. Spring Boot 入门¶

    什么是 Spring Boot？¶

    Spring Boot 是 Spring 团队于 2014 年推出的项目，目的是简化 Spring 应用的创建和部署。

    Spring vs Spring Boot¶

    特性 Spring Framework Spring Boot
    配置 大量 XML 或 Java 配置 自动配置，约定优于配置
    依赖管理 手动管理版本 Starter 依赖，版本自动兼容
    部署 需要外部 Tomcat 内嵌服务器，可执行 JAR
    监控 需要额外配置 Actuator 提供生产就绪功能
    学习曲线 陡峭 平缓，新手友好

    Spring Boot 的核心特性¶

    ┌────────────────────────────────────────────┐
│          Spring Boot 核心特性               │
├────────────────────────────────────────────┤
│                                            │
│  1. 自动配置 (Auto-configuration)          │
│     根据 classpath 自动配置 Bean            │
│                                            │
│  2. Starter 依赖                            │
│     一键引入所需依赖                        │
│                                            │
│  3. 内嵌服务器                              │
│     Tomcat/Jetty/Undertow 内嵌             │
│                                            │
│  4. 生产就绪                                │
│     Actuator 提供监控和管理端点             │
│                                            │
│  5. 无代码生成                              │
│     纯 Java 配置，无需 XML                   │
│                                            │
└────────────────────────────────────────────┘

    创建第一个 Spring Boot 应用¶

    步骤 1：使用 Spring Initializr¶

    访问 https://start.spring.io 创建项目：

    Project: Maven
Language: Java
Spring Boot: 3.2.x
Group: com.example
Artifact: demo
Package Name: com.example.demo
Packaging: Jar
Java: 17

Dependencies:
  - Spring Web

    点击 "Generate" 下载并解压项目。

    步骤 2：查看项目结构¶

    demo/
├── src/main/java/com/example/demo/
│   └── DemoApplication.java    # 主应用类
├── src/main/resources/
│   └── application.properties  # 配置文件
├── pom.xml                     # Maven 配置
└── ...

    步骤 3：理解主应用类¶

    package com.example.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class DemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}

    @SpringBootApplication 解析：

    // 这个注解是三个注解的组合：
@SpringBootConfiguration  // 标识为配置类
@EnableAutoConfiguration  // 启用自动配置
@ComponentScan            // 启用组件扫描

    步骤 4：创建第一个 Controller¶

    在 src/main/java/com/example/demo/ 下创建 controller/HelloController.java：

    package com.example.demo.controller;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloController {

    @GetMapping("/hello")
    public String hello() {
        return "Hello, Spring Boot!";
    }
}

    步骤 5：运行应用¶

    # MacOS/Linux
./mvnw spring-boot:run

# Windows
.\mvnw.cmd spring-boot:run

    启动成功后，访问 http://localhost:8080/hello

    配置文件¶

    application.properties¶

    # 服务器端口
server.port=8080

# 应用名称
spring.application.name=demo

# 日志级别
logging.level.com.example.demo=DEBUG

    application.yml（推荐）¶

    server:
  port: 8080

spring:
  application:
    name: demo

logging:
  level:
    com.example.demo: DEBUG

    多环境配置¶

    src/main/resources/
├── application.yml          # 通用配置
├── application-dev.yml      # 开发环境
├── application-test.yml     # 测试环境
└── application-prod.yml     # 生产环境

    application.yml： 

    spring:
  profiles:
    active: dev  # 激活开发环境

    application-dev.yml： 

    server:
  port: 8080

spring:
  datasource:
    url: jdbc:h2:mem:devdb

    application-prod.yml： 

    server:
  port: 80

spring:
  datasource:
    url: jdbc:mysql://prod-db:3306/mydb

    激活特定环境： 

    # 命令行参数
./mvnw spring-boot:run -Dspring-boot.run.profiles=prod

# 或环境变量
export SPRING_PROFILES_ACTIVE=prod

    Starter 依赖¶

    Starter 是一组预配置的依赖描述符，让你一键引入所需功能。

    常用 Starter¶

    Starter 依赖 用途
    spring-boot-starter-web Spring MVC + Tomcat Web 应用
    spring-boot-starter-data-jpa Hibernate + Spring Data 数据访问
    spring-boot-starter-security Spring Security 安全认证
    spring-boot-starter-test JUnit + Mockito 测试
    spring-boot-starter-validation Hibernate Validator 参数校验
    spring-boot-starter-actuator Actuator 监控端点
    spring-boot-starter-thymeleaf Thymeleaf 模板引擎
    spring-boot-starter-webflux WebFlux + Netty 响应式 Web

    在 pom.xml 中添加¶

    <dependencies>
    <!-- Web 应用 -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>

    <!-- 数据访问 -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-data-jpa</artifactId>
    </dependency>

    <!-- 数据库驱动 -->
    <dependency>
        <groupId>com.h2database</groupId>
        <artifactId>h2</artifactId>
        <scope>runtime</scope>
    </dependency>
</dependencies>

    自动配置原理¶

    Spring Boot 根据 classpath 中的依赖自动配置 Bean。

    示例：Web 自动配置¶

    当你引入 spring-boot-starter-web：

    classpath 中有：
  - spring-webmvc.jar
  - tomcat-embed-core.jar
  - jackson-databind.jar

自动配置：
  - DispatcherServlet
  - Embedded Tomcat
  - HttpMessageConverters
  - ...

    查看自动配置报告¶

    # 启用调试模式
./mvnw spring-boot:run -Ddebug

# 或在配置文件中
debug: true

    启动日志中会显示：

    Positive matches: (匹配成功的配置)
-----------------
   DispatcherServletAutoConfiguration matched:
      - @ConditionalOnClass found required class 'org.springframework.web.servlet.DispatcherServlet'

Negative matches: (未匹配的配置)
----------------
   SecurityAutoConfiguration did not match:
      - @ConditionalOnClass did not find required class 'org.springframework.security.config.annotation.web.configuration.WebSecurityConfigurerAdapter'

    内嵌服务器¶

    Spring Boot 支持三种内嵌服务器：

    Tomcat（默认）¶

    <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
    <!-- 默认包含 Tomcat -->
</dependency>

    切换到 Jetty¶

    <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
    <exclusions>
        <exclusion>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-tomcat</artifactId>
        </exclusion>
    </exclusions>
</dependency>

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-jetty</artifactId>
</dependency>

    切换到 Undertow¶

    <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
    <exclusions>
        <exclusion>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-tomcat</artifactId>
        </exclusion>
    </exclusions>
</dependency>

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-undertow</artifactId>
</dependency>

    配置服务器¶

    server:
  port: 8080
  servlet:
    context-path: /api
  tomcat:
    max-threads: 200
    accept-count: 100

    打包和部署¶

    可执行 JAR¶

    # 打包
./mvnw package

# 运行
java -jar target/demo-0.0.1-SNAPSHOT.jar

    pom.xml 配置： 

    <build>
    <plugins>
        <plugin>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-maven-plugin</artifactId>
        </plugin>
    </plugins>
</build>

    WAR 部署到外部服务器¶

    <!-- pom.xml -->
<packaging>war</packaging>

<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-tomcat</artifactId>
        <scope>provided</scope>
    </dependency>
</dependencies>

    // 主类继承 SpringBootServletInitializer
@SpringBootApplication
public class DemoApplication extends SpringBootServletInitializer {

    @Override
    protected SpringApplicationBuilder configure(SpringApplicationBuilder builder) {
        return builder.sources(DemoApplication.class);
    }

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}

    开发工具¶

    DevTools（热部署）¶

    <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <scope>runtime</scope>
    <optional>true</optional>
</dependency>

    效果： - 代码修改后自动重启 - 模板文件修改后自动刷新 - 生产环境自动禁用

    配置 IDEA 自动编译¶

    1. File → Settings → Build → Compiler
    2. 勾选 "Build project automatically"
    3. Ctrl+Shift+A → 输入 "Registry"
    4. 勾选 "compiler.automake.allow.when.app.running"

    常用注解速查¶

    注解 说明 示例
    @SpringBootApplication 主应用类 @SpringBootApplication
    @RestController REST 控制器 @RestController
    @GetMapping GET 请求映射 @GetMapping("/users")
    @PostMapping POST 请求映射 @PostMapping("/users")
    @PutMapping PUT 请求映射 @PutMapping("/users/{id}")
    @DeleteMapping DELETE 请求映射 @DeleteMapping("/users/{id}")
    @PathVariable 路径参数 @PathVariable Long id
    @RequestParam 查询参数 @RequestParam String name
    @RequestBody 请求体 @RequestBody User user
    @ResponseBody 响应体 @ResponseBody

    完整示例¶

    package com.example.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.web.bind.annotation.*;

@SpringBootApplication
@RestController
public class DemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }

    @GetMapping("/hello")
    public String hello() {
        return "Hello, World!";
    }

    @GetMapping("/greet")
    public String greet(@RequestParam String name) {
        return String.format("Hello, %s!", name);
    }

    @GetMapping("/user/{id}")
    public String getUser(@PathVariable Long id) {
        return "User ID: " + id;
    }
}

    测试： 

    curl http://localhost:8080/hello
curl http://localhost:8080/greet?name=Amy
curl http://localhost:8080/user/123
