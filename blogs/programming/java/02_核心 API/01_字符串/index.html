    1. String 类¶

    知识点：

    • String 是不可变字符序列，所有"修改"操作都返回新对象，原对象不变
    • ⭐ 字面量字符串共享常量池中的同一对象；new 出来的在堆上另建对象
    • ⚠️ new String("Hello") 创建 1 个或 2 个对象（取决于常量池是否已有）
    • ⭐ == 比较引用，equals 比较内容；字符串比较内容永远用 equals

    1.1 String 概述¶

    String 是 Java 中最常用的类，用于表示不可变的字符序列。

    ⭐ String 为什么设计成不可变？（必考） 1. 安全：字符串大量用于类加载、网络连接、文件路径。若可变，传进来的参数中途被改，系统就被攻破了 2. 字符串常量池的前提：只有不可变才能放心共享——多处引用同一个 "Hello" 对象，谁也不怕谁改 3. 哈希缓存：String 的 hashCode 算一次就缓存起来（常用作 HashMap 的 key），可变的话哈希就失效了 4. 天然线程安全：不可变对象无需同步

    实现方式：内部字符数组用 final 修饰且 private，所有"修改"操作（replace/substring/toUpperCase）都返回新对象，原对象不变。

    与 C++ 对比：C++ 的 std::string 是可变的；Java 把"不可变字符串 + 可变 StringBuilder"分成两个类。

    特点：

    • ✅ 不可变性：创建后不能修改
    • ✅ 线程安全：不可变所以线程安全
    • ✅ 字符串常量池：节省内存
    • ✅ 基于 char 数组（Java 8）或 byte 数组（Java 9+）
    String str1 = "Hello";
String str2 = "Hello";
String str3 = new String("Hello");

System.out.println(str1 == str2);      // true（同一对象）
System.out.println(str1 == str3);      // false（不同对象）
System.out.println(str1.equals(str3)); // true（内容相同）

    ⚠️ new String("Hello") 创建了几个对象？（经典考题）

    答案：1 个或 2 个。

    • 字面量 "Hello"：若常量池中没有，先在常量池创建 1 个
    • new：在堆中必然创建 1 个新对象
    • 所以：常量池已有 → 1 个（堆里的）；常量池没有 → 2 个（池里 + 堆里）

    ⚠️ == 与 equals 的分工（贯穿整个 Java 学习）：

    • ==：比较引用（是否同一对象）；基本类型比较值
    • equals()：Object 默认也是比引用，但 String 等类重写为比内容
    • 字符串比较内容永远用 equals()，== 只在需要判断"是不是同一个对象"时用

    ⚠️ 字符串拼接的底层（JDK 8 vs 9+）：

    String s = "a" + "b" + "c";
// 编译期优化：常量直接拼成 "abc"，不产生中间对象（等价于写 "abc"）

String x = "a";
String s2 = x + "b";
// 含变量：JDK 8 编译成 StringBuilder.append 链；
// JDK 9+ 用 invokedynamic（StringConcatFactory），原理类似但更高效
// 注意：循环里拼接每轮都新建 StringBuilder，务必手动复用（见 2.1）

    2. StringBuilder 和 StringBuffer¶

    知识点：

    • 循环中用 + 拼接会创建大量临时对象，可变字符串类专为高效拼接而生
    • StringBuilder 可变、非线程安全、性能高；StringBuffer 方法加 synchronized，线程安全但性能略低
    • 常用方法：append/insert/delete/replace/reverse，默认容量 16
    • ⚠️ 大量拼接场景务必用 StringBuilder/StringBuffer 代替 String 的 +

    2.1 为什么需要可变字符串¶

    // ❌ 低效：每次 + 都创建新对象
String str = "";
for (int i = 0; i < 1000; i++) {
    str += i;  // 创建 1000 个临时对象
}

// ✅ 高效：只使用一个对象
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}
String result = sb.toString();

    2.2 StringBuilder¶

    特点：

    • ✅ 可变字符序列
    • ✅ 非线程安全
    • ✅ 性能高（单线程推荐）
    StringBuilder sb = new StringBuilder();

// 追加
sb.append("Hello");
sb.append(", ");
sb.append("World");
sb.append("!");

// 插入
sb.insert(5, " Java");  // "Hello Java, World!"

// 删除
sb.delete(5, 10);  // "Hello, World!"

// 替换
sb.replace(7, 12, "Java");  // "Hello, Java!"

// 反转
sb.reverse();  // "!dlraW ,olleH"

// 长度
int len = sb.length();  // 13

// 容量
int cap = sb.capacity();  // 默认 16

// 转字符串
String str = sb.toString();

    2.3 StringBuffer¶

    特点：

    • ✅ 可变字符序列
    • ✅ 线程安全（方法有 synchronized）
    • ❌ 性能略低
    StringBuffer sb = new StringBuffer();
sb.append("Hello");
sb.append(" World");

// 方法同 StringBuilder
String str = sb.toString();

    2.4 三者对比¶

    特性 String StringBuilder StringBuffer
    可变性 不可变 可变 可变
    线程安全 ✅ ❌ ✅
    性能 低 高 中
    使用场景 少量操作 单线程多操作 多线程多操作

    3. 字符串常量池¶

    知识点：

    • 字面量字符串共享常量池中的同一对象；new String 在堆中另建对象
    • intern() 返回常量池中对应对象的引用
    • ⚠️ 常量拼接编译期折叠成常量；含变量的运行期拼接会创建新对象

    3.1 常量池原理¶

    String str1 = "Hello";
String str2 = "Hello";
String str3 = new String("Hello");

// str1 和 str2 指向常量池中的同一对象
// str3 在堆中创建新对象

System.out.println(str1 == str2);      // true
System.out.println(str1 == str3);      // false
System.out.println(str1.equals(str3)); // true

// intern() 方法
String str4 = str3.intern();
System.out.println(str1 == str4);      // true

    3.2 常量池优化¶

    // ✅ 推荐：使用字面量
String str1 = "Hello";

// ❌ 不推荐：无意义地 new
String str2 = new String("Hello");

// 字符串拼接
String a = "Hello";
String b = "World";

// 编译期优化（常量拼接）
String c = "Hello" + "World";  // 等效于 "HelloWorld"

// 运行期拼接（创建新对象）
String d = a + b;  // 使用 StringBuilder

    4. 字符串格式化¶

    知识点：

    • String.format() 按占位符格式化并返回字符串；printf 格式化输出到控制台
    • 常用占位符：%s 字符串、%d 整数、%f 浮点、%.2f 保留 2 位小数、%05d 补零、%tY-%tm-%td 日期

    4.1 String.format()¶

    // 格式化字符串
String str1 = String.format("Hello, %s!", "World");
// "Hello, World!"

// 数字格式化
String str2 = String.format("Price: %.2f", 19.99);
// "Price: 19.99"

// 整数格式化
String str3 = String.format("Count: %05d", 42);
// "Count: 00042"

// 日期格式化
String str4 = String.format("Date: %tY-%tm-%td", new Date());
// "Date: 2026-03-26"

    4.2 printf¶

    System.out.printf("Name: %s, Age: %d%n", "Alice", 25);
System.out.printf("Price: $%.2f%n", 19.99);

    5.1 反转字符串¶

    public String reverseString(String s) {
    char[] chars = s.toCharArray();
    int left = 0, right = chars.length - 1;
    while (left < right) {
        char temp = chars[left];
        chars[left] = chars[right];
        chars[right] = temp;
        left++;
        right--;
    }
    return new String(chars);
}

// 使用 StringBuilder
public String reverseString2(String s) {
    return new StringBuilder(s).reverse().toString();
}

    5.2 验证回文串¶

    public boolean isPalindrome(String s) {
    s = s.toLowerCase().replaceAll("[^a-z0-9]", "");
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s.charAt(left) != s.charAt(right)) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

    5.3 字符串转整数¶

    public int myAtoi(String s) {
    s = s.trim();
    if (s.isEmpty()) return 0;

    int sign = 1, index = 0;
    if (s.charAt(0) == '-') {
        sign = -1;
        index++;
    } else if (s.charAt(0) == '+') {
        index++;
    }

    long result = 0;
    while (index < s.length() && Character.isDigit(s.charAt(index))) {
        result = result * 10 + (s.charAt(index) - '0');
        if (result * sign > Integer.MAX_VALUE) return Integer.MAX_VALUE;
        if (result * sign < Integer.MIN_VALUE) return Integer.MIN_VALUE;
        index++;
    }

    return (int) result * sign;
}

    5.4 最长公共前缀¶

    public String longestCommonPrefix(String[] strs) {
    if (strs == null || strs.length == 0) return "";

    String prefix = strs[0];
    for (int i = 1; i < strs.length; i++) {
        while (strs[i].indexOf(prefix) != 0) {
            prefix = prefix.substring(0, prefix.length() - 1);
            if (prefix.isEmpty()) return "";
        }
    }
    return prefix;
}

    参考答案¶

    import java.util.LinkedHashMap;
import java.util.Map;

// 练习 1
public static String countChars(String str) {
    // LinkedHashMap 保持字符首次出现的顺序
    Map<Character, Integer> map = new LinkedHashMap<>();
    for (char c : str.toCharArray()) {
        // getOrDefault：键不存在时返回默认值 0
        map.put(c, map.getOrDefault(c, 0) + 1);
    }
    StringBuilder sb = new StringBuilder();
    for (Map.Entry<Character, Integer> e : map.entrySet()) {
        sb.append(e.getKey()).append("=").append(e.getValue()).append(" ");
    }
    return sb.toString().trim();
}
// countChars("hello") → "h=1 e=1 l=2 o=1"

// 练习 2
public static String join(String[] words) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < words.length; i++) {
        sb.append(words[i]);        // 追加单词
        if (i < words.length - 1) {
            sb.append(",");         // 除最后一个外追加分隔符
        }
    }
    return sb.toString();
}
// join(new String[]{"Java", "Python", "Go"}) → "Java,Python,Go"

// 练习 3 答案：
// (1) true —— "a"+"b"+"c" 是编译期常量折叠，直接优化为 "abc"，
//     与 s1 指向常量池中的同一对象
// (2) false —— new String() 在堆中新建对象，与常量池对象不是同一个引用
// (3) true —— intern() 返回常量池中 "abc" 的引用，与 s1 相同
// (4) true —— equals 比较内容，两者都是 "abc"

    7. 本章小结¶

    核心知识点¶

    ✅ String：不可变、常用方法、常量池
    ✅ StringBuilder：可变、非线程安全、高性能
    ✅ StringBuffer：可变、线程安全
    ✅ 字符串格式化：format、printf

    最佳实践¶

    1. 少量操作用 String：代码简洁
    2. 单线程多操作用 StringBuilder：性能最优
    3. 多线程多操作用 StringBuffer：线程安全
    4. 字符串比较用 equals：不用 ==
    5. 注意空指针：先判断 null 和 empty

    性能对比¶

    // 场景：拼接 10000 次字符串
