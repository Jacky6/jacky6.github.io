    1. IO 流概述¶

    知识点：

    • IO = 程序与外部（文件/网络/控制台）之间的数据传输，"流"是单向顺序的数据序列
    • ⭐ 两大分类轴：按方向分输入/输出流；按单位分字节流（一切文件）/字符流（文本）
    • 字节流基类 InputStream/OutputStream，字符流基类 Reader/Writer
    • 节点流直连数据源，处理流（缓冲/转换）套在节点流外面增强功能

    1.1 什么是 IO¶

    IO（Input/Output）是输入/输出的缩写，用于程序与外部设备（文件、网络、控制台等）之间的数据传输。

    流（Stream）的定义：数据在两个端点（程序 ↔ 文件/网络/内存）之间按顺序、单向传输的抽象。想象成水管：数据像水一样流动，读是"抽水"，写是"注水"。流是一次性消费的——读过的位置不能回头（除非用特殊流）。

    ⭐ 字节流 vs 字符流的本质区别（必考）： - 字节流：一次读/写 1 个字节（8 位），不关心内容含义——图片、音频、视频、任意文件都能传 - 字符流：一次读/写 1 个字符，内部负责编码转换（字节 ↔ Unicode 字符）——只适合文本 - 根本原因：中文在 UTF-8 里占 3 个字节，用字节流按字节截断会把汉字切成乱码；字符流按字符边界读写，天然解决这个问题 - 选择口诀：纯文本（尤其含中文）用字符流，其他一律字节流

    流的分类：

    按流向：
├── 输入流（Input）- 读取数据
└── 输出流（Output）- 写入数据

按数据类型：
├── 字节流（Byte）- 所有文件
│   ├── InputStream
│   └── OutputStream
└── 字符流（Char）- 文本文件
    ├── Reader
    └── Writer

按功能：
├── 节点流 - 直接操作数据源
└── 处理流 - 增强功能（缓冲、转换等）

    ⭐ read() 为什么返回 int 而不是 byte？（考点）

    read() 返回 0~255 的字节值或 -1（文件结束标记）。Java 的 byte 是有符号的（-128~127），装不下 255，也无法用 -1 之外的负数区分"数据"和"结束"，所以提升为 int。

    ⚠️ 编码陷阱（真实事故高发区）：

    // ❌ 逐字节读取中文文本 → 乱码（UTF-8 的汉字占 3 字节，被切断了）
try (FileInputStream fis = new FileInputStream("中文.txt")) {
    int b;
    while ((b = fis.read()) != -1) {
        System.out.print((char) b);  // 乱码！
    }
}

// ✅ 方式 1：字符流（内部按 UTF-8 解码成字符）
try (BufferedReader br = new BufferedReader(
        new InputStreamReader(new FileInputStream("中文.txt"), StandardCharsets.UTF_8))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
}

// ✅ 方式 2：NIO.2 一行搞定（Java 7+，小文件推荐）
// ⚠️ Path.of 是 Java 11+；Java 7/8 要用 Paths.get(...)
List<String> lines = Files.readAllLines(Path.of("中文.txt"), StandardCharsets.UTF_8);

    ⚠️ 字符输出流记得 flush：Writer 带缓冲区，数据先攒在内存里，close() 会自动 flush；但如果忘了 close（没用 try-with-resources），最后一段数据可能没写进文件。

    2. 字节流¶

    知识点：

    • 字节流以 1 字节（8 位） 为单位读写，适合图片/音频/视频等一切文件
    • ⭐ read() 返回 int（0~255 或 -1 结束标记）；写入用 write(byte[])
    • ⚠️ 用字节流读中文会乱码（UTF-8 汉字占 3 字节，按字节切断）——文本用字符流
    • 务必用 try-with-resources 关闭流

    2.1 FileInputStream¶

    import java.io.*;

// 方式 1：基础用法
FileInputStream fis = null;
try {
    fis = new FileInputStream("file.txt");
    int data = fis.read();  // 读取一个字节
    while (data != -1) {
        System.out.print((char) data);
        data = fis.read();
    }
} catch (IOException e) {
    e.printStackTrace();
} finally {
    if (fis != null) {
        try {
            fis.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

// 方式 2：try-with-resources（推荐）
try (FileInputStream fis = new FileInputStream("file.txt")) {
    int data = fis.read();
    while (data != -1) {
        System.out.print((char) data);
        data = fis.read();
    }
} catch (IOException e) {
    e.printStackTrace();
}

// 方式 3：读取到字节数组
// ⚠️ 此写法仅适用于"纯字节"场景：new String(buffer, 0, len) 每块独立解码，
//    多字节 UTF-8 字符跨两次 read 时会产生替换字符（）。
//    读文本请用方式 1/2 的字符流；确需分块解码时要用 CharsetDecoder 维护跨块状态。
try (FileInputStream fis = new FileInputStream("file.txt")) {
    byte[] buffer = new byte[1024];
    int len;
    while ((len = fis.read(buffer)) != -1) {
        String str = new String(buffer, 0, len);
        System.out.print(str);
    }
}

    2.2 FileOutputStream¶

    // 写入文件（覆盖）
try (FileOutputStream fos = new FileOutputStream("output.txt")) {
    fos.write("Hello".getBytes());
    fos.write('A');
    fos.write("World".getBytes());
} catch (IOException e) {
    e.printStackTrace();
}

// 追加写入
try (FileOutputStream fos = new FileOutputStream("output.txt", true)) {
    fos.write("\n追加内容".getBytes());
}

    2.3 文件复制¶

    public static void copyFile(String src, String dest) {
    try (FileInputStream fis = new FileInputStream(src);
         FileOutputStream fos = new FileOutputStream(dest)) {

        byte[] buffer = new byte[1024];
        int len;
        while ((len = fis.read(buffer)) != -1) {
            fos.write(buffer, 0, len);
        }
    } catch (IOException e) {
        e.printStackTrace();
    }
}

    3. 字符流¶

    知识点：

    • 字符流以 1 个字符 为单位读写，内部自动做字节↔字符的编码转换
    • ⭐ 只适合文本文件；Reader 的 read() 返回字符的 Unicode 码点（int）
    • BufferedReader.readLine() 按行读最方便（NIO.2 的 Files.readAllLines 更简洁）
    • ⚠️ Writer 有缓冲，写完必须 flush 或 close，否则数据可能丢失

    3.1 FileReader¶

    // 读取文本文件
try (FileReader fr = new FileReader("file.txt");
     BufferedReader br = new BufferedReader(fr)) {

    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    e.printStackTrace();
}

    3.2 FileWriter¶

    // 写入文本文件
try (FileWriter fw = new FileWriter("output.txt");
     BufferedWriter bw = new BufferedWriter(fw)) {

    bw.write("Hello, World!");
    bw.newLine();  // 换行
    bw.write("第二行");
} catch (IOException e) {
    e.printStackTrace();
}

    3.3 字符流 vs 字节流¶

    特性 字节流 字符流
    处理单元 字节（8 位） 字符（16 位）
    适用场景 所有文件 文本文件
    缓冲 需手动 自动
    类名后缀 InputStream/OutputStream Reader/Writer

    4. 缓冲流¶

    知识点：

    • 缓冲流套在节点流外面，用内存缓冲区减少系统调用次数，显著提升 IO 性能
    • 四件套：BufferedInputStream/BufferedOutputStream/BufferedReader/BufferedWriter
    • ⭐ BufferedReader.readLine() 按行读取文本最常用
    • 关闭外层缓冲流会自动关闭内层节点流

    4.1 BufferedInputStream¶

    try (FileInputStream fis = new FileInputStream("file.txt");
     BufferedInputStream bis = new BufferedInputStream(fis)) {

    byte[] buffer = new byte[1024];
    int len;
    while ((len = bis.read(buffer)) != -1) {
        System.out.write(buffer, 0, len);
    }
} catch (IOException e) {
    e.printStackTrace();
}

    4.2 BufferedReader¶

    try (FileReader fr = new FileReader("file.txt");
     BufferedReader br = new BufferedReader(fr)) {

    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    e.printStackTrace();
}

    4.3 BufferedWriter¶

    try (FileWriter fw = new FileWriter("output.txt");
     BufferedWriter bw = new BufferedWriter(fw)) {

    bw.write("第一行");
    bw.newLine();
    bw.write("第二行");
    bw.flush();  // 刷新缓冲区
} catch (IOException e) {
    e.printStackTrace();
}

    5. 转换流¶

    知识点：

    • InputStreamReader/OutputStreamWriter 是字节流↔字符流的桥梁
    • ⭐ 构造时指定字符集（如 UTF-8），解决读写编码问题
    • FileReader/FileWriter 本质是它们的便捷子类（用平台默认编码，易出乱码）

    5.1 InputStreamReader¶

    // 字节流转字符流
try (FileInputStream fis = new FileInputStream("file.txt");
     InputStreamReader isr = new InputStreamReader(fis, "UTF-8");
     BufferedReader br = new BufferedReader(isr)) {

    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    e.printStackTrace();
}

    5.2 OutputStreamWriter¶

    try (FileOutputStream fos = new FileOutputStream("output.txt");
     OutputStreamWriter osw = new OutputStreamWriter(fos, "UTF-8");
     BufferedWriter bw = new BufferedWriter(osw)) {

    bw.write("中文内容");
} catch (IOException e) {
    e.printStackTrace();
}

    6. 数据流¶

    知识点：

    • DataInputStream/DataOutputStream 读写 Java 基本类型（int/double/boolean/UTF 字符串）
    • ⭐ 写入顺序 = 读取顺序，否则数据错乱；适合固定格式的二进制文件
    • DataOutputStream 写的是二进制，不是文本——用记事本打开是乱码

    6.1 DataOutputStream¶

    import java.io.*;

// 写入基本类型到二进制文件
try (DataOutputStream dos = new DataOutputStream(
        new FileOutputStream("data.bin"))) {
    dos.writeInt(42);           // 4 字节
    dos.writeDouble(3.14);      // 8 字节
    dos.writeBoolean(true);     // 1 字节
    dos.writeUTF("你好");       // UTF-8 编码字符串（带长度前缀）
    dos.writeChar('A');         // 2 字节
    dos.writeLong(1000L);       // 8 字节
} catch (IOException e) {
    e.printStackTrace();
}

    6.2 DataInputStream¶

    // 读取基本类型——顺序必须和写入时一致！
try (DataInputStream dis = new DataInputStream(
        new FileInputStream("data.bin"))) {
    int i = dis.readInt();         // 42
    double d = dis.readDouble();   // 3.14
    boolean b = dis.readBoolean(); // true
    String s = dis.readUTF();      // "你好"
    char c = dis.readChar();       // 'A'
    long l = dis.readLong();       // 1000
    System.out.printf("%d %f %b %s %c %d%n", i, d, b, s, c, l);
} catch (IOException e) {
    e.printStackTrace();
}

    ⚠️ 顺序陷阱：写入时 writeInt → writeDouble，读取时必须 readInt → readDouble。如果顺序反了，readInt 会把 double 的 4 字节当整数读，结果完全错误且不报错。

    7. 打印流与标准流¶

    知识点：

    • PrintStream/PrintWriter 是最常用的输出流，System.out 就是 PrintStream
    • ⭐ println/print/printf 都来自打印流；PrintWriter 可以指定编码，比 PrintStream 更灵活
    • 打印流不抛 IOException（内部吞异常，用 checkError() 检查）
    • System.setIn/setOut/setErr 可以重定向标准流到文件/管道

    7.1 PrintStream¶

    import java.io.*;

// System.out 的真身就是 PrintStream
PrintStream ps = System.out;
ps.println("Hello");           // println 的来源
ps.print("不换行");
ps.printf("格式化：%d %s%n", 42, "Java");

// 写入文件（PrintStream 默认用平台编码，建议用 PrintWriter 指定编码）
try (PrintStream ps2 = new PrintStream(
        new FileOutputStream("log.txt"), true, "UTF-8")) {  // autoFlush=true
    ps2.println("第一行");
    ps2.println("第二行");
    ps2.printf("数字：%05d%n", 42);  // 00042
} catch (FileNotFoundException | UnsupportedEncodingException e) {
    // ⚠️ 该构造器除 FileNotFoundException 外还声明 UnsupportedEncodingException；
    // Java 10+ 更推荐用接受 Charset 的重载，配合 StandardCharsets.UTF_8 无需捕获编码异常：
    // new PrintStream(new FileOutputStream("log.txt"), true, StandardCharsets.UTF_8)
    e.printStackTrace();
}

    7.2 PrintWriter¶

    import java.io.*;

// PrintWriter 比 PrintStream 更灵活：可指定编码、可包装 Writer
try (PrintWriter pw = new PrintWriter(
        new FileWriter("output.txt"), true)) {  // autoFlush=true
    pw.println("Hello, World!");
    pw.printf("姓名：%s，年龄：%d%n", "张三", 25);
    pw.write("直接写入字符串");
} catch (IOException e) {
    e.printStackTrace();
}

// PrintWriter 指定编码（推荐方式）
try (PrintWriter pw = new PrintWriter(
        new OutputStreamWriter(new FileOutputStream("output.txt"), "UTF-8"))) {
    pw.println("中文内容");
}

    7.3 标准流重定向¶

    Java 有三个标准流，都是 public static final 字段：

    标准流 类型 默认指向 用途
    System.in InputStream 键盘 标准输入
    System.out PrintStream 控制台 标准输出
    System.err PrintStream 控制台（红色） 标准错误 
    import java.io.*;

// 把 System.out 重定向到文件（日志场景）
// ⚠️ 重定向创建的流要自己管理：保存引用、用完关闭，否则文件句柄泄漏
PrintStream originalOut = System.out;  // 先保存原始流
try (PrintStream fileOut = new PrintStream(new FileOutputStream("console.log"), true, StandardCharsets.UTF_8)) {
    System.setOut(fileOut);
    System.out.println("这行会写入 console.log，不在控制台显示");
    System.setOut(originalOut);  // 恢复（在 try 内恢复，确保异常路径也能恢复）
}
System.out.println("这行回到控制台");

// 把 System.in 重定向为从文件读（同样记得关闭创建的流）
try (FileInputStream fileIn = new FileInputStream("input.txt");
     Scanner scanner = new Scanner(fileIn)) {
    System.setIn(fileIn);
    while (scanner.hasNextLine()) {
        System.out.println(scanner.nextLine());
    }
}

    实际场景：标准流重定向常用于日志收集（把 stdout 重定向到日志文件）、自动化测试（模拟 stdin 输入）、批处理脚本。

    8. Scanner¶

    知识点：

    • java.util.Scanner 是实际开发中最常用的文本读取方式，基于正则分隔符解析输入
    • ⭐ hasNextXxx/nextXxx 按类型读取（nextInt/nextDouble/nextLine）
    • 默认分隔符是空白（空格/Tab/换行），可用 useDelimiter 自定义
    • 可读 System.in、文件、字符串、流

    8.1 从控制台读取¶

    import java.util.Scanner;

Scanner sc = new Scanner(System.in);
System.out.print("请输入姓名：");
String name = sc.nextLine();      // 读整行
System.out.print("请输入年龄：");
int age = sc.nextInt();           // 读整数
System.out.print("请输入身高：");
double height = sc.nextDouble();  // 读浮点数
System.out.printf("%s，%d 岁，%.1f cm%n", name, age, height);
sc.close();

    8.2 从文件读取¶

    import java.util.Scanner;
import java.io.File;

// 按行读取文件
try (Scanner sc = new Scanner(new File("data.txt"), "UTF-8")) {
    while (sc.hasNextLine()) {
        String line = sc.nextLine();
        System.out.println(line);
    }
} catch (FileNotFoundException e) {
    e.printStackTrace();
}

// 按分隔符解析（CSV 场景）
try (Scanner sc = new Scanner(new File("data.csv"), "UTF-8")) {
    sc.useDelimiter(",|\\n");  // 逗号或换行
    while (sc.hasNext()) {
        System.out.println(sc.next().trim());
    }
}

    8.3 按类型读取¶

    Scanner sc = new Scanner("42 3.14 true hello");

// hasNextXxx 判断 + nextXxx 读取
while (sc.hasNext()) {
    if (sc.hasNextInt()) {
        System.out.println("整数：" + sc.nextInt());
    } else if (sc.hasNextDouble()) {
        System.out.println("浮点：" + sc.nextDouble());
    } else if (sc.hasNextBoolean()) {
        System.out.println("布尔：" + sc.nextBoolean());
    } else {
        System.out.println("字符串：" + sc.next());
    }
}
// 输出：整数：42 / 浮点：3.14 / 布尔：true / 字符串：hello
sc.close();

    ⚠️ nextLine 坑：nextInt() 读取后不消费换行符，紧接着 nextLine() 会读到空字符串。解决：在 nextInt() 后多加一个 nextLine() 消费换行符。

    int age = sc.nextInt();
sc.nextLine();  // 消费残留的换行符
String name = sc.nextLine();  // 正确读取

    8.4 Scanner vs BufferedReader¶

    对比项 Scanner BufferedReader
    功能 按类型/分隔符解析 按行读取
    性能 较慢（正则解析开销） 快（纯缓冲读取）
    编码 构造时指定 需配 InputStreamReader
    适用 交互输入、CSV 解析 大文件逐行读

    选择建议：控制台交互输入用 Scanner；大文件逐行读取用 BufferedReader + InputStreamReader；一行搞定用 Files.readAllLines。

    9. 对象序列化¶

    知识点：

    • 序列化 = 把对象转成字节流以便存储/传输；反序列化是还原
    • 类必须实现 Serializable 标记接口；字段用 transient 排除不序列化的部分
    • ⭐ serialVersionUID 版本不一致会反序列化失败（详见 序列化 专章）

    9.1 Serializable¶

    import java.io.Serializable;

public class Person implements Serializable {
    private static final long serialVersionUID = 1L;

    private String name;
    private int age;
    private transient String password;  // 不序列化

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

    Person person = new Person("张三", 25);

// 序列化（对象 → 字节）
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("person.dat"))) {
    oos.writeObject(person);

    10. File 类¶

    知识点：

    • File 代表文件/目录的路径信息，不操作内容（读写内容要用流）
    • 常用：exists/mkdirs/delete/listFiles/isDirectory/getName
    • ⚠️ 遍历大目录树用递归或 Files.walk（NIO.2），注意 File 操作不抛 IOException 而是返回 boolean

    10.1 创建和删除¶

    File file = new File("test.txt");

// 创建文件
if (!file.exists()) {
    file.createNewFile();
}

// 创建目录
File dir = new File("mydir");
dir.mkdir();  // 创建单级目录
dir.mkdirs(); // 创建多级目录

// 删除
file.delete();
dir.delete();

    10.2 获取信息¶

    File file = new File("test.txt");

String name = file.getName();      // 文件名
String path = file.getPath();      // 路径
String parent = file.getParent();  // 父目录
long size = file.length();         // 大小
long time = file.lastModified();   // 最后修改时间

boolean isFile = file.isFile();    // 是否文件
boolean isDir = file.isDirectory();// 是否目录

    10.3 遍历目录¶

    File dir = new File(".");

// 列出所有文件
File[] files = dir.listFiles();
for (File f : files) {
    System.out.println(f.getName());
}

// 过滤文件
File[] txtFiles = dir.listFiles((d, name) -> name.endsWith(".txt"));
for (File f : txtFiles) {
    System.out.println(f.getName());
}

// 递归遍历
void listAllFiles(File dir) {
    File[] files = dir.listFiles();
    if (files != null) {
        for (File f : files) {
            if (f.isDirectory()) {
                listAllFiles(f);
            } else {
                System.out.println(f.getAbsolutePath());
            }
        }
    }
}

    11. Java 7+ NIO.2¶

    知识点：

    • NIO.2（java.nio.file）提供 Path/Files 现代文件 API，比 File+流简洁得多
    • ⭐ 小文件一行搞定：Files.readAllLines/readAllBytes/write/copy/move/delete
    • Files.walk 流式遍历目录树；大文件仍建议用流式读写避免占内存
    • 注意：NIO.2 文件 API ≠ 第 12 章的 Channel/Buffer 网络 IO 模型

    11.1 Files 类¶

    Files 提供了静态方法直接操作文件，小文件一行搞定，无需手动创建流。注意 Files.write() 默认是覆盖模式，追加写入必须传 StandardOpenOption.APPEND。

    import java.nio.file.*;
import java.nio.charset.StandardCharsets;

Path path = Paths.get("file.txt");

// 读取所有行（小文件推荐，大文件用 Files.lines 流式读取避免 OOM）
List<String> lines = Files.readAllLines(path, StandardCharsets.UTF_8);

// 写入所有行（默认覆盖！每次调用都会清空文件重写）
Files.write(path, Arrays.asList("Line 1", "Line 2"), 
            StandardCharsets.UTF_8);

// 追加写入（关键：StandardOpenOption.APPEND）
// CREATE + APPEND 是最常用组合：文件不存在则创建，存在则在末尾追加
Files.write(path, Arrays.asList("Line 3", "Line 4"),
            StandardCharsets.UTF_8,
            StandardOpenOption.CREATE,      // 文件不存在则创建
            StandardOpenOption.APPEND);     // 追加到末尾（不加则覆盖）

// 写入字节数组（适合写二进制数据）
Files.write(path, "原始字节".getBytes(StandardCharsets.UTF_8),
            StandardOpenOption.CREATE,
            StandardOpenOption.APPEND);

// 复制（REPLACE_EXISTING：目标存在则覆盖，不加则报错）
Files.copy(Paths.get("src.txt"), Paths.get("dest.txt"), 
           StandardCopyOption.REPLACE_EXISTING);

// 移动（也可用于重命名）
Files.move(Paths.get("old.txt"), Paths.get("new.txt"));

// 删除（文件不存在会抛 NoSuchFileException，建议先 exists 判断）
Files.delete(Paths.get("file.txt"));

// 判断
boolean exists = Files.exists(path);
boolean isDir = Files.isDirectory(path);
boolean isRegular = Files.isRegularFile(path);

    ⭐ StandardOpenOption 常用选项：

    选项 作用 说明
    CREATE 文件不存在则创建 已存在不报错
    APPEND 追加到文件末尾 不加则默认覆盖
    CREATE + APPEND 不存在创建，存在追加 日志场景最常用
    TRUNCATE_EXISTING 清空文件再写 默认行为
    CREATE_NEW 创建新文件，已存在则报错 防止覆盖

    ⚠️ APPEND 和 TRUNCATE_EXISTING 互斥，不能同时传。

    11.2 遍历文件¶

    Path dir = Paths.get(".");

// ⚠️ Files.list/walk 返回的 Stream 持有目录句柄，必须用 try-with-resources 关闭，
//    否则目录资源泄漏（尤其在 Windows 上会锁住目录）

// 遍历当前目录
try (var stream = Files.list(dir)) {
    stream.forEach(System.out::println);
}

// 递归遍历
try (var stream = Files.walk(dir)) {
    stream.forEach(System.out::println);
}

// 过滤遍历
try (var stream = Files.walk(dir)) {
    stream.filter(Files::isRegularFile)
        .filter(p -> p.toString().endsWith(".txt"))
        .forEach(System.out::println);
}

    12. 练习题¶

    练习 1（文件复制）：使用缓冲字节流实现 copyFile(String src, String dest) 方法，要求使用 try-with-resources 自动关闭流。

    练习 2（按行统计）：使用 BufferedReader 逐行读取文本文件，统计文件的总行数和总字符数（不含换行符）。

    练习 3（序列化）：定义 User 类（name 为普通字段、password 用 transient 修饰），将其序列化到文件后再反序列化，观察输出并解释原因。

    练习 4（数据流）：用 DataOutputStream 写入 3 个学生信息（姓名 String、年龄 int、成绩 double），再用 DataInputStream 读回并打印，验证读写顺序必须一致。

    练习 5（Scanner 解析 CSV）：用 Scanner 读取 CSV 文件（逗号分隔），解析每行的姓名和分数，计算平均分。

    参考答案¶

    import java.io.*;

public class IoExercises {

    // 练习 1：缓冲字节流复制文件
    public static void copyFile(String src, String dest) throws IOException {
        // try-with-resources：流用完自动关闭，无需手写 finally
        try (BufferedInputStream in = new BufferedInputStream(new FileInputStream(src));
             BufferedOutputStream out = new BufferedOutputStream(new FileOutputStream(dest))) {
            byte[] buffer = new byte[8192]; // 8KB 缓冲区，减少磁盘 IO 次数
            int len;
            while ((len = in.read(buffer)) != -1) {
                out.write(buffer, 0, len);
            }
        }
    }

    // 练习 2：按行统计行数和字符数
    public static void countLinesAndChars(String path) throws IOException {
        // 转换流：字节流 → 字符流，并指定 UTF-8 编码
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(new FileInputStream(path), "UTF-8"))) {
            int lines = 0;
            int chars = 0;
            String line;
            while ((line = reader.readLine()) != null) {
                lines++;
                chars += line.length(); // readLine 返回的内容不含换行符
            }
            System.out.println("总行数：" + lines + "，总字符数：" + chars);
        }
    }

    // 练习 3：transient 字段不参与序列化
    static class User implements Serializable {
        private static final long serialVersionUID = 1L;
        String name;
        transient String password; // transient：序列化时被忽略

        User(String name, String password) {
            this.name = name;
            this.password = password;
        }
    }

    public static void main(String[] args) throws Exception {
        // 练习 1 + 2：复制文件并统计
        copyFile("source.txt", "copy.txt");
        countLinesAndChars("copy.txt");

        // 练习 3：序列化与反序列化
        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("user.dat"))) {
            oos.writeObject(new User("张三", "123456"));
        }
        try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("user.dat"))) {
            User u = (User) ois.readObject();
            // 输出：name=张三, password=null
            // password 被 transient 修饰，序列化时被跳过，反序列化后恢复为默认值 null
            System.out.println("name=" + u.name + ", password=" + u.password);
        }

        // 练习 4：数据流读写基本类型
        try (DataOutputStream dos = new DataOutputStream(new FileOutputStream("students.bin"))) {
            String[] names = {"张三", "李四", "王五"};
            int[] ages = {20, 21, 22};
            double[] scores = {90.5, 85.0, 92.3};
            for (int i = 0; i < names.length; i++) {
                dos.writeUTF(names[i]);   // 写入顺序：姓名→年龄→成绩
                dos.writeInt(ages[i]);
                dos.writeDouble(scores[i]);
            }
        }
        try (DataInputStream dis = new DataInputStream(new FileInputStream("students.bin"))) {
            // 读取顺序必须和写入完全一致！
            for (int i = 0; i < 3; i++) {
                String name = dis.readUTF();
                int age = dis.readInt();
                double score = dis.readDouble();
                System.out.printf("姓名：%s，年龄：%d，成绩：%.1f%n", name, age, score);
            }
        }

        // 练习 5：Scanner 解析 CSV
        try (Scanner sc = new Scanner(new File("scores.csv"), "UTF-8")) {
            double total = 0;
            int count = 0;
            while (sc.hasNextLine()) {
                String line = sc.nextLine();
                String[] parts = line.split(",");
                // CSV 格式：姓名,分数
                String name = parts[0].trim();
                double score = Double.parseDouble(parts[1].trim());
                total += score;
                count++;
                System.out.printf("%s：%.1f%n", name, score);
            }
            System.out.printf("平均分：%.1f%n", total / count);
        }
    }
}

    13. 高频面试题¶

    Q1：字节流和字符流的区别？怎么选？

    字节流（InputStream/OutputStream）按 8 位字节读写，处理一切数据（图片、视频、序列化）；字符流（Reader/Writer）按字符读写，内部用 StreamDecoder 按编码（默认 UTF-8）转换，只适合文本。原则：文本文件用字符流，其他一律字节流。

    Q2：为什么需要缓冲流？原理？

    磁盘/网络 IO 每次系统调用开销大，逐字节读写会产生海量调用。BufferedInputStream 等内部维护数组缓冲区（默认 8KB），一次系统调用读一块进内存，后续从内存取——减少系统调用次数。包装流模式：new BufferedReader(new FileReader(...))。

    Q3：IO 流的装饰器模式体现在哪？

    流体系是装饰器模式的经典应用：FileReader（具体组件）→ BufferedReader（装饰，加缓冲）→ LineNumberReader（装饰，加行号）。每层只增强功能不改接口，自由组合。面试能答出这个例子是加分项。

    Q4：BIO、NIO、AIO 的区别？

    BIO：同步阻塞，一连接一线程；NIO：同步非阻塞 + IO 多路复用（Selector 一个线程管多个连接），面向 Buffer/Channel；AIO：异步，IO 完成后回调。服务器连接数大用 NIO（Netty 基础），简单场景 BIO 足够。详见 13_NIO 与网络编程。

    Q5：close 和 flush 的作用？

    flush 把缓冲区数据强制写出（缓冲写流的最后一段可能还在缓冲里）；close 释放系统资源，关闭前会自动 flush。try-with-resources 自动处理，手写时 close 放 finally。

    Q6：System.out 是什么类型？PrintStream 和 PrintWriter 的区别？

    System.out 是 PrintStream 类型，所以 println/printf 方法都来自 PrintStream。区别：PrintStream 继承自 FilterOutputStream（字节流），只能用平台默认编码；PrintWriter 继承自 Writer（字符流），构造时可指定编码，更灵活。实际开发中写文件推荐 PrintWriter + UTF-8。

    Q7：DataInputStream 和 ObjectInputStream 的区别？

    DataInputStream 读写基本类型（int/double/boolean/UTF 字符串），按固定字节长度读写，不包含对象信息；ObjectInputStream 读写整个对象，包含类信息、字段名和值，需要类实现 Serializable。简单数据用 DataStream，复杂对象用 ObjectStream。

    Q8：Scanner 的 nextLine 坑是什么？

    nextInt() 读取整数后不消费换行符，紧接着调用 nextLine() 会读到空字符串（残留的换行符）。解决：在 nextInt() 后多加一个 nextLine() 消费换行符。

    14. 本章小结¶

    核心知识点¶

    ✅ 字节流：FileInputStream、FileOutputStream
    ✅ 字符流：FileReader、FileWriter、BufferedReader
    ✅ 缓冲流：BufferedInputStream、BufferedOutputStream
    ✅ 转换流：InputStreamReader、OutputStreamWriter
    ✅ 数据流：DataInputStream、DataOutputStream
    ✅ 打印流：PrintStream、PrintWriter
    ✅ Scanner：控制台输入、文件解析
    ✅ 序列化：ObjectOutputStream、ObjectInputStream
    ✅ File 类：创建、删除、遍历
    ✅ NIO.2：Files、Path

    最佳实践¶

    1. 使用 try-with-resources：自动关闭资源
    2. 使用缓冲流：提高 IO 性能
    3. 文本文件用字符流：处理编码更方便
    4. 二进制文件用字节流：通用性强
    5. 注意编码：统一使用 UTF-8
    6. 控制台交互用 Scanner：最便捷的文本读取方式
    7. 日志输出用 PrintWriter：指定编码，避免乱码
