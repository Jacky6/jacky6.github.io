    04_Lambda 表达式¶

    1. 函数式接口¶

    知识点：

    • 函数式接口 = 只有一个抽象方法的接口（默认/静态/私有方法不计入）
    • ⭐ 函数式接口是 Lambda 的"目标类型"——Lambda 只能赋给函数式接口
    • @FunctionalInterface 注解让编译器校验，加错直接编译报错
    • 内置四大接口：Consumer（消费）、Supplier（供给）、Function（转换）、Predicate（判断）

    1.1 什么是函数式接口¶

    函数式接口是只有一个抽象方法的接口。

    @FunctionalInterface
interface MyFunctionalInterface {
    void method();  // 唯一的抽象方法

    default void defaultMethod() {}  // 默认方法不影响
    static void staticMethod() {}    // 静态方法不影响
}

    常见函数式接口：

    接口 方法 用途
    Runnable void run() 无参数无返回
    Consumer<T> void accept(T) 消费数据
    Supplier<T> T get() 供应数据
    Function<T,R> R apply(T) 函数转换
    Predicate<T> boolean test(T) 判断

    ⭐ Lambda 的本质（考点）：Lambda 是匿名内部类的语法糖，把"传递一段行为"简化成一行。它只能用于函数式接口（编译器根据目标接口推断参数类型和返回类型，这就是"类型推断"）。底层实现不是生成匿名内部类字节码，而是 invokedynamic + LambdaMetafactory，比匿名内部类更轻量。

    ⭐ Lambda vs 匿名内部类： - 匿名内部类可以有多个方法、字段，Lambda 只能是单个抽象方法 - 匿名内部类的 this 指向自己，Lambda 的 this 指向外围类 - 能写 Lambda 就写 Lambda（简洁），需要复杂逻辑或访问 this 时用匿名内部类

    ⚠️ 变量捕获：只能引用 final 或 effectively final（考点）：

    int num = 10;
Runnable r = () -> System.out.println(num);  // ✅ num 没被修改

int count = 0;
// Runnable r2 = () -> System.out.println(count++);  // ❌ 编译错误
// 原因同匿名内部类：Lambda 捕获的是局部变量的副本，要求不可变

    2. Lambda 语法¶

    知识点：

    • 语法：(参数列表) -> { 方法体 }，本质是"匿名内部类的简写"
    • ⭐ 省略规则：单参数可省括号、单语句可省大括号和 return、类型可推断省略
    • ⚠️ Lambda 只能捕获effectively final 的局部变量（不能中途修改）
    • 底层不是生成匿名类文件，而是 invokedynamic + LambdaMetafactory（更轻量）

    2.1 基本语法¶

    // 传统匿名内部类
new Thread(new Runnable() {
    @Override
    public void run() {
        System.out.println("Hello");
    }
}).start();

// Lambda 表达式
new Thread(() -> System.out.println("Hello")).start();

    2.2 语法格式¶

    // 完整格式
(parameters) -> { statements }

// 省略类型（类型推断）
(x, y) -> { return x + y; }

// 单参数省略括号
x -> { return x * 2; }

// 单语句省略花括号和 return
x -> x * 2

// 无参数
() -> System.out.println("Hello")

    2.3 示例对比¶

    // 1. 无参数无返回
Runnable r1 = () -> System.out.println("Hi");

// 2. 单参数
Consumer<String> c1 = s -> System.out.println(s);

// 3. 多参数
BiFunction<Integer, Integer, Integer> f1 = (a, b) -> a + b;

// 4. 多语句
Comparator<String> c1 = (s1, s2) -> {
    int result = s1.length() - s2.length();
    return result != 0 ? result : s1.compareTo(s2);
};

    3. 方法引用 ⭐¶

    知识点：

    • 方法引用是 Lambda 的进一步简写：方法体只是"调用已有方法"时用 :: 替代
    • ⭐ 四种形式：类::静态方法、对象::实例方法、类::实例方法、类::new（构造引用）
    • 触发条件：Lambda 参数原封不动传给目标方法时才能替换

    3.1 静态方法引用¶

    // Lambda
Function<String, Integer> f1 = s -> Integer.parseInt(s);

// 方法引用
Function<String, Integer> f2 = Integer::parseInt;

// 使用
Integer result = f2.apply("123");  // 123

    3.2 实例方法引用¶

    // Lambda
BiFunction<String, String, Boolean> f1 = (s1, s2) -> s1.equals(s2);

// 方法引用
BiFunction<String, String, Boolean> f2 = String::equals;

// 使用
Boolean result = f2.apply("abc", "abc");  // true

    3.3 对象方法引用¶

    PrintStream ps = System.out;

// Lambda
Consumer<String> c1 = s -> ps.println(s);

// 方法引用
Consumer<String> c2 = ps::println;

// 使用
c2.accept("Hello");  // Hello

    3.4 构造方法引用¶

    // Lambda
Function<String, Person> f1 = name -> new Person(name);

// 方法引用
Function<String, Person> f2 = Person::new;

// 使用
Person p = f2.apply("张三");

// 数组构造方法引用
Function<Integer, String[]> f3 = String[]::new;
String[] arr = f3.apply(10);  // new String[10]

    4. 函数式接口详解¶

    知识点：

    • ⭐ 四大内置接口记语义：Consumer 消费（有参无返回）、Supplier 供给（无参有返回）、Function 转换（有参有返回）、Predicate 判断（返回 boolean）
    • 都有组合方法：Consumer.andThen 串联、Function.andThen/compose 组合、Predicate.and/or/negate 逻辑组合
    • 专用变体减少装箱：IntConsumer、ToLongFunction 等（参数或返回值是基本类型时用）

    4.1 Consumer（消费型）¶

    import java.util.function.Consumer;

// 消费数据，无返回
Consumer<String> printer = s -> System.out.println(s);
printer.accept("Hello");  // Hello

// andThen 链式调用
Consumer<String> c1 = s -> System.out.print(s);
Consumer<String> c2 = s -> System.out.println(s.toUpperCase());

c1.andThen(c2).accept("hello");  // helloHELLO

    4.2 Supplier（供给型）¶

    import java.util.function.Supplier;

// 供应数据，无参数
Supplier<Double> random = () -> Math.random();
Double value = random.get();

// 创建对象
Supplier<Person> personSupplier = Person::new;
Person p = personSupplier.get();

    4.3 Function（函数型）¶

    import java.util.function.Function;

// 转换数据
Function<String, Integer> parser = Integer::parseInt;
Integer result = parser.apply("123");  // 123

// andThen 组合
Function<String, Integer> f1 = Integer::parseInt;
Function<Integer, String> f2 = String::valueOf;

Function<String, String> composed = f1.andThen(f2);
String r = composed.apply("456");  // "456"

    4.4 Predicate（断言型）¶

    import java.util.function.Predicate;

// 判断
Predicate<String> notEmpty = s -> s != null && !s.isEmpty();
boolean result = notEmpty.test("hello");  // true

// and/or/negate
Predicate<String> hasA = s -> s.contains("a");
Predicate<String> hasB = s -> s.contains("b");

Predicate<String> hasAAndB = hasA.and(hasB);
Predicate<String> hasAOrB = hasA.or(hasB);
Predicate<String> notHasA = hasA.negate();

    5. Stream API 中的 Lambda¶

    知识点：

    • Stream 的每个操作参数都是一个函数式接口：filter 收 Predicate、map 收 Function、forEach 收 Consumer
    • 方法引用在 Stream 里最常用（String::toUpperCase 优于 s -> s.toUpperCase()）
    • 完整 Stream 用法见 Stream API

    5.1 filter + map + collect¶

    List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

// 过滤 + 转换 + 收集
List<String> result = names.stream()
    .filter(s -> s.startsWith("A"))           // Predicate
    .map(String::toUpperCase)                 // Function
    .collect(Collectors.toList());

// 结果：["ALICE"]

    5.2 forEach¶

    List<String> list = Arrays.asList("A", "B", "C");

// 遍历
list.forEach(System.out::println);

    5.3 reduce¶

    List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

// 求和
Integer sum = numbers.stream()
    .reduce(0, (a, b) -> a + b);

// 方法引用
Integer sum2 = numbers.stream()
    .reduce(0, Integer::sum);

// 最大值
Optional<Integer> max = numbers.stream()
    .reduce(Integer::max);

    5.4 sorted¶

    List<String> list = Arrays.asList("C", "A", "B");

// 自然排序
list.stream().sorted().collect(Collectors.toList());

// 自定义排序
list.stream()
    .sorted((a, b) -> b.compareTo(a))  // 降序
    .collect(Collectors.toList());

    6. 实战示例¶

    6.1 集合操作¶

    List<Person> people = Arrays.asList(
    new Person("Alice", 25),
    new Person("Bob", 30),
    new Person("Charlie", 25)
);

// 提取所有姓名
List<String> names = people.stream()
    .map(Person::getName)
    .collect(Collectors.toList());

// 过滤年龄>25
List<Person> adults = people.stream()
    .filter(p -> p.getAge() > 25)
    .collect(Collectors.toList());

// 按年龄分组
Map<Integer, List<Person>> byAge = people.stream()
    .collect(Collectors.groupingBy(Person::getAge));

// 年龄求和
int totalAge = people.stream()
    .mapToInt(Person::getAge)
    .sum();

    6.2 比较器¶

    List<Person> people = ...;

// Lambda 写法
people.sort((p1, p2) -> p1.getName().compareTo(p2.getName()));

// 方法引用
people.sort(Comparator.comparing(Person::getName));

// 链式比较
people.sort(Comparator.comparing(Person::getAge)
    .thenComparing(Person::getName));

    7. 注意事项¶

    知识点：

    • ⚠️ Lambda 捕获的局部变量必须 effectively final（赋值后不再修改）
    • ⚠️ Lambda 的 this 指向外围类，匿名内部类的 this 指向自己——行为不同
    • 复杂逻辑（多语句、需要字段）用匿名内部类，简单逻辑用 Lambda

    7.1 有效 final¶

    int x = 10;

// ✅ 正确：x 相当于 final
Runnable r1 = () -> System.out.println(x);

// ❌ 错误：x 被修改
x = 20;
Runnable r2 = () -> System.out.println(x);  // 编译错误

    7.2 this 关键字¶

    class MyClass {
    void method() {
        Runnable r = () -> {
            // this 指向外层类，不是 Runnable
            System.out.println(MyClass.this);
        };
    }
}

    8. 练习题¶

    练习 1（Lambda 改写）：给定 List<String>，用 Stream + Lambda 实现：过滤长度大于 3 的字符串，转为大写，按长度升序排序并输出。

    练习 2（函数式接口组合）：使用 Function 的 andThen / compose 和 Predicate 的 and 方法组合多个逻辑。

    练习 3（方法引用）：分别用 Lambda 和等价的方法引用实现：字符串转整数、打印字符串、创建 ArrayList。

    参考答案¶

    import java.util.*;
import java.util.function.*;

public class LambdaExercises {

    public static void main(String[] args) {
        // 练习 1：filter + map + sorted + forEach
        List<String> words = Arrays.asList("go", "java", "python", "c", "kotlin");
        words.stream()
                .filter(w -> w.length() > 3)                       // 过滤长度 > 3
                .map(String::toUpperCase)                          // 方法引用：转大写
                .sorted(Comparator.comparingInt(String::length))   // 按长度升序
                .forEach(System.out::println);                     // JAVA、KOTLIN、PYTHON

        // 练习 2：函数组合
        Function<Integer, Integer> plusOne = x -> x + 1;
        Function<Integer, Integer> doubleIt = x -> x * 2;
        System.out.println(plusOne.andThen(doubleIt).apply(3)); // 先 +1 再 *2 → 8
        System.out.println(plusOne.compose(doubleIt).apply(3)); // 先 *2 再 +1 → 7

        Predicate<Integer> positive = x -> x > 0;
        Predicate<Integer> even = x -> x % 2 == 0;
        Predicate<Integer> positiveAndEven = positive.and(even); // 组合两个断言
        System.out.println(positiveAndEven.test(4));  // true
        System.out.println(positiveAndEven.test(-4)); // false

        // 练习 3：Lambda 与方法引用等价写法
        Function<String, Integer> parse1 = s -> Integer.parseInt(s);
        Function<String, Integer> parse2 = Integer::parseInt;   // 静态方法引用
        System.out.println(parse2.apply("42")); // 42

        Consumer<String> print1 = s -> System.out.println(s);
        Consumer<String> print2 = System.out::println;          // 对象的方法引用
        print2.accept("方法引用更简洁");

        Supplier<List<String>> factory1 = () -> new ArrayList<>();
        Supplier<List<String>> factory2 = ArrayList::new;       // 构造方法引用
        System.out.println(factory2.get()); // []
    }
}

    9. 高频面试题¶

    Q1：Lambda 表达式的本质是什么？

    匿名函数，用于实现函数式接口（只有一个抽象方法的接口）。编译后不是匿名内部类——JDK 8 用 invokedynamic + LambdaMetaFactory 在运行期动态生成实现类（比匿名内部类少一次对象分配，且可被 JVM 优化）。

    Q2：什么是函数式接口？@FunctionalInterface 的作用？

    只有一个抽象方法的接口（Object 的方法不算）。@FunctionalInterface 是编译期校验注解：加了它若接口有两个抽象方法会编译报错。它本身不是必需的，但表达意图 + 防止后人破坏。

    Q3：JDK 内置的核心函数式接口有哪些？

    Function<T,R>（转换）、Consumer<T>（消费）、Supplier<T>（生产）、Predicate<T>（判断）、UnaryOperator/BinaryOperator（一元/二元运算），以及基本类型特化版 IntFunction 等（避免装箱）。

    Q4：Lambda 和普通匿名内部类的区别？

    ① this 指向：匿名内部类的 this 指向自己，Lambda 的 this 指向外围类实例；② 编译产物：匿名内部类生成 Outer$1.class，Lambda 用 invokedynamic 动态生成；③ 变量访问：两者都要求捕获的局部变量 effectively final。

    Q5：什么是方法引用？四种形式？

    Lambda 的简写形式，用 :: 连接：① 静态方法 Integer::parseInt；② 实例方法 System.out::println；③ 特定对象实例方法 user::getName；④ 构造器 User::new。能写成方法引用就不写 Lambda。

    10. 本章小结¶

    核心知识点¶

    ✅ Lambda 语法：参数、箭头、函数体
    ✅ 方法引用：静态、实例、构造方法
    ✅ 函数式接口：Consumer、Supplier、Function、Predicate
    ✅ Stream 集成：filter、map、reduce、sorted

    最佳实践¶

    1. 优先使用方法引用：更简洁、性能更好
    2. 保持 Lambda 简洁：复杂逻辑提取为方法
    3. 使用标准函数式接口：java.util.function 包
    4. 注意有效 final：Lambda 捕获的变量不能修改
