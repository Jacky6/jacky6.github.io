    3 字符&字符串

    1. String 类¶

    1.1 声明字符串¶

    • java 中字符串必须包含在一对双引号（""）之内。

    • java 中由双引号包围的字符串，不能作为其他数据类型来使用。

    • 可以通过以下语法声明字符串变量：
    String str_name:

    1.2 创建字符串¶

    1. String(char a[]) :用一个字符数组 a 创建 String 对象。
    char a[] = {'g', 'o', 'o', 'd'};
String s = new String(a);
// 等价于
String s = new String("good");
    1. String(char a[], int offset, int length)
    2. 提取字符串数组 a 的一部分创建一个字符串对象。参数 offset 表示开始截取字符串的位置，length表示截取字符串的长度。
    char a[] = {'s','t','u','d','e','t'};
String s = new String(a, 2, 4);
// 等价于
String s = new String("udent")
    1. String(char[] value)
    2. 该构造方法可分配一个新的 String 对象，使其表示字符数组参数中所有元素连接的结果。
    char a[] = {'s','t','u','d','e','t'};
String s = new String(a);
// 等价于
String s = new String("student")

    2. 连接字符串¶

    2.1 连接多个字符串¶

    ​ 使用 + 运算符可以连接多个运算符并产生一个 String 对象。

    public class Join{
    public static void main(String args[]) {
        String s1 = new String("hello");
        String s2 = new String("world");
        String s = s1 + " " + s2;
        System.out.println(s);
    }
}

    2.2 连接其他数据类型¶

    ​ 字符串也可以和其他基本数据类型进行连接。如果将字符串同这些数据类型进行连接，会将这些数据直接转换成字符串。

    public class Link {
    public static void main(String args[]) {
        int booktime = 4;
        float practice = 2.5f;
        System.out.println("我每天花费" + booktime +"小时看书；"
                          + practice + "小时上机练习")；
    }
}

    ​ String 类提供了 indexOf() 和 lastIndexOf() 方法在字符串中搜索指定条件的字符或字符串。

    • indexOf(tarStr) 返回的是 搜索的字符或字符串首次出现的位置。
    • lastIndexOf(tarStr) 返回的是搜索的字符或字符串最后一次出现的位置。

    4. 字符串操作¶

    4.1 获取子字符串¶

    • substring() 该方法有两种不同的方式重载，满足不同需求
    • substring(int beginIndex) 返回从指定的索引位置开始截取到该字符串结尾的子串。
    • substring(int beginIndex, int endIndex) 返回的是从字符串 beginIndex 索引开始到 endIndex 索引结束为止的子串。（闭区间）

    4.2 去除空格 --- trim()¶

    • trim() 方法返回字符串的副本，忽略前导空格和尾部空格。

    4.3 字符串替换 --- replace()¶

    • replace(char oldChar, char newChar) 方法可实现将指定的字符或字符串替换成新的字符或字符串。
    • 该方法返回的结果是一个新的字符串。

    4.4 判断字符串的开始与结尾¶

    • startsWith(String prefix) 方法，用于判断当前字符串对象的前缀是否为参数指定的字符串。

    • endsWith(String suffix) 方法，用于判断当前字符串是否为以给定的子字符串结尾。

    4.5 判断字符串是否相等¶

    ​ 对字符串对象进行比较不能简单地使用比较运算符 == ，因为比较运算符比较的是两个字符串的地址是否相同。因此，要比较两个字符串的内容是否相等，需要使用 equals() 和 equalsIgnoreCase()方法：

    • 如果两个字符串具有相同的字符和长度， 则str1.equals(str2) 方法返回 true。

    • 使用 equals()方法对字符串进行比较时是区分大小写的，而使用 equalsIgnoreCase()方法是在忽略了大小写的情况下比较两个字符串是否相等，返回结果仍然是 boolean 类型.

    4.6 按照字典顺序比较两个字符串¶

    ​ compareTo() 方法为按字典顺序比较两个字符串，该比较基于字符串中各个字符的Unicode值，按字典顺序将此String对象表示的字符序列与参数字符串所表示的字符序列进行比较。如果按字典顺序此String对象位于参数字符串之前，则比较结果为一个负整数；如果按字典顺序此String对象位于参数字符串之后，则比较结果为一个正整数；如果这两个字符串相等，则结果为0。

    str.compareTo(String str2)

    4.7 字母大小写转换¶

    • 字符串的 toLowerCase() 方法可将字符串中的所有字符从大写字母改写成小写字母。

    • 字符串的 toUpperCase() 方法可以将字符串的所有字符从小写字符改写成大写字母。

    4.8 字符串分割¶

    • split(String sign) 可以根据给定的分割符对字符串进行拆分。
    • split(String sign, int limit) 可根据给定的分割符对字符串拆分，并限定拆分的次数。

    5. 格式化字符串¶

    ​ String 类的静态 format() 方法用于创建格式化的字符串，format() 方法有两种重载形式。

    （1） format(String format, Object...args)

    ​ 该方法使用指定的格式字符串和参数返回一个格式化字符串，格式化后的新字符串使用本地默认的语言环境。语法如下

    str.format(String format, Object ...args)

    • format : 格式化字符串

    • args： 格式字符串中由格式说明符引用的参数。如果还有格式说明符意外的参数，则忽略这些额外的参数，此参数的数目是可变的，可以为0.

    （2）format(Local l, String format, Object ... args)

    • Local l: 格式化过程中要应用的语言环境。如果为 null，则不进行本地化。
    • format: 格式化字符串。
    • args: 格式字符串中由格式说明符引用的参数。如果还有格式说明符意外的参数，则忽略这些额外的参数，此参数的数目是可变的，可以为0.
