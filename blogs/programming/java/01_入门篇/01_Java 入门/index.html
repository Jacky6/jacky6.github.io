    1. Java 简介¶

    1.1 知识点¶

    知识点 1：Java 语言特点

    Java 是 1995 年由 Sun（现 Oracle）发布的高级、面向对象、跨平台编程语言。

    • ✅ 面向对象：封装、继承、多态
    • ✅ 跨平台：Write Once, Run Anywhere（一次编写，到处运行）
    • ✅ 健壮安全：强类型、无指针运算、数组越界检查、异常机制
    • ✅ 自动内存管理：垃圾回收（GC），无需手动 new/delete
    • ✅ 多线程内置支持

    与 C++ 对比：Java 砍掉了 C++ 的指针运算、手动内存管理、多重类继承、运算符重载等复杂特性，换取安全性和简单性；代价是运行速度和底层控制力不如 C++。

    知识点 2：跨平台原理 ⭐⭐⭐

    Java 跨平台的关键是字节码 + JVM：

    Java 源码 (.java) ──javac 编译──→ 字节码 (.class) ──各平台的 JVM──→ Windows / Linux / macOS
                                  （一份字节码，处处运行）
    • 字节码是平台无关的中间格式，不是任何 CPU 的机器码
    • 每个操作系统有自己的 JVM 实现，负责把字节码翻译成当前平台的机器指令
    • 本质：字节码跨平台，JVM 不跨平台——换平台只需安装对应平台的 JVM

    知识点 3：JDK / JRE / JVM ⭐⭐⭐⭐（必考）

    JDK（Java Development Kit，开发工具包）
├── JRE（Java Runtime Environment，运行环境）
│   ├── JVM（虚拟机：加载并执行字节码）
│   └── 核心类库（java.lang、java.util 等）
└── 开发工具（javac 编译器、javadoc、调试工具等）

JDK ⊃ JRE ⊃ JVM
    概念 作用 谁需要
    JVM 执行字节码的虚拟机 —
    JRE JVM + 核心类库，只能运行不能编译 只运行 Java 程序的用户
    JDK JRE + 编译/调试工具，能开发 开发者 ⭐

    注：JDK 11 之后官方发行版不再单独提供 JRE，运行和开发统一用 JDK。

    知识点 8：版本与 LTS 选择

    版本 年份 重要特性
    Java 8 2014 Lambda、Stream、Optional ⭐（存量最大）
    Java 11 2018 LTS、var、HTTP Client
    Java 17 2021 LTS、sealed、record、模式匹配 instanceof
    Java 21 2023 LTS、虚拟线程、switch 模式匹配

    LTS = Long Term Support（长期支持）。学习和生产优先用 LTS 版本（新项目推荐 17/21）。详细新特性见 Java9-21 新特性。

    2. 环境搭建¶

    2.1 知识点¶

    • 开发只需装 JDK（含编译器和运行环境）
    • 配置 JAVA_HOME 指向 JDK 目录，Path 加入 %JAVA_HOME%/bin
    • IDE 推荐 IntelliJ IDEA（Community 版免费够用）

    2.2 示例¶

    Windows：

    1. 下载 Oracle JDK 或 OpenJDK
    2. 安装到如 C:\Program Files\Java\jdk-17
    3. 配置环境变量： 
      JAVA_HOME = C:\Program Files\Java\jdk-17
Path = %JAVA_HOME%\bin
    4. 验证：java -version 和 javac -version

    macOS：

    brew install openjdk@17
export JAVA_HOME=/usr/local/opt/openjdk@17
export PATH=$JAVA_HOME/bin:$PATH
java -version

    Linux：

    sudo apt update
sudo apt install openjdk-17-jdk
java -version

    3. HelloWorld 与程序结构¶

    3.1 知识点¶

    知识点 4：main 方法签名 ⭐⭐⭐

    public static void main(String[] args)
│      │      │    │       │
│      │      │    │       └─ 命令行参数（String 数组）
│      │      │    └─ 方法名必须叫 main
│      │      └─ 无返回值
│      └─ 静态方法：JVM 不创建对象就能调用
└─ 公开的：JVM 在类外部调用
    • 签名写错：能编译，但运行时报 Main method not found
    • String[] args：接收命令行参数，java Hello a b 时 args = ["a", "b"]

    知识点 5：Java 程序基本结构

    package com.example.demo;   // 1. 包声明（可选，必须在第一行非注释位置）
import java.util.Scanner;   // 2. 导入语句（可选）

public class MyClass {      // 3. 类定义（public 类名必须与文件名一致）
    private int value;      // 4. 成员变量

    public MyClass() {}     // 5. 构造方法

    public void doSomething() {}   // 6. 成员方法

    public static void main(String[] args) {  // 7. 程序入口
        MyClass obj = new MyClass();
        obj.doSomething();
    }
}

    关键规则： - 一个 .java 文件最多一个 public 类，且类名必须与文件名完全一致（含大小写） - Java 区分大小写，每条语句以 ; 结尾 - // 单行注释、/* */ 多行注释、/** */ Javadoc 文档注释

    3.2 示例¶

    public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

    知识点 6：编译运行流程

    # 1. 编写代码 HelloWorld.java
# 2. 编译：源码 → 字节码
javac HelloWorld.java     # 生成 HelloWorld.class

# 3. 运行：JVM 执行字节码（注意不带 .class 后缀）
java HelloWorld           # 输出：Hello, Java!

    Java 11+ 支持单文件直接运行：java HelloWorld.java（免编译步骤，学习期方便）。

    4. 命名规范¶

    4.1 知识点¶

    元素 规范 示例
    包名 全小写，域名反写 com.example.demo
    类名/接口名 大驼峰（PascalCase） Person, StudentInfo
    方法名/变量名 小驼峰（camelCase） getName(), totalCount
    常量 全大写 + 下划线 MAX_VALUE, DEFAULT_SIZE

    规则底线：以字母/下划线/$ 开头，不能用关键字（class、int...），不能以数字开头。

    4.2 示例¶

    // ✅ 好的命名：见名知义
public class StudentInfo {
    private String studentName;
    public static final int MAX_SCORE = 100;

    public void calculateGrade() {}
}

// ❌ 不好的命名
public class student_info {   // 类名应大驼峰
    private String sName;     // 缩写含义不明
    public static final int max = 100;  // 常量应全大写
    public void calc() {}     // 动词太笼统
}

    5. 常见问题排查¶

    错误信息 原因 解决
    Could not find or load main class 运行目录不对 / 类名与文件名不一致 cd 到 .class 所在目录，检查类名
    'javac' 不是内部或外部命令 环境变量没配好 配置 JAVA_HOME 和 Path
    Main method not found main 签名写错 对照 3.1 节逐词检查
    编码 GBK 的不可映射字符 源码含中文但编码不匹配 javac -encoding UTF-8 Xxx.java

    6. 练习题¶

    1. Hello World：编写程序输出 "Hello, World!"，命令行编译并运行。
    2. 个人信息：输出你的姓名、年龄、城市。
    3. 简单计算：计算 1+2+3+...+100 的和。
    4. 简答题：JDK、JRE、JVM 分别是什么？只运行别人写好的 Java 程序需要装什么？

    参考答案¶

    // 练习 1
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

// 练习 2
public class MyInfo {
    public static void main(String[] args) {
        System.out.println("姓名：张三");
        System.out.println("年龄：25");
        System.out.println("城市：北京");
    }
}

// 练习 3
public class Sum {
    public static void main(String[] args) {
        int sum = 0;
        for (int i = 1; i <= 100; i++) {
            sum += i;
        }
        System.out.println("1 到 100 的和：" + sum);  // 5050
    }
}

// 练习 4：
// JVM：执行字节码的虚拟机
// JRE = JVM + 核心类库，只能运行程序
// JDK = JRE + 开发工具（javac 等），能开发程序
// 只运行程序：JRE 即可（JDK 11+ 直接装 JDK）

    7. 本章小结¶

    核心知识点¶

    ✅ 跨平台原理：字节码 + 各平台 JVM，"字节码跨平台，JVM 不跨平台"
    ✅ JDK ⊃ JRE ⊃ JVM：开发装 JDK
    ✅ main 签名：public static void main(String[] args)，缺一不可
    ✅ 程序结构：package → import → class；public 类名 = 文件名
    ✅ 编译运行：javac 生成 .class，java 执行字节码
    ✅ 命名规范：类大驼峰、方法/变量小驼峰、常量全大写

    最佳实践¶

    1. 类名与文件名一致：public 类必须相同
    2. 遵循命名规范：见名知义
    3. 用 IDE 开发：IntelliJ IDEA 提升效率
    4. 多动手：从 HelloWorld 开始逐行敲代码
