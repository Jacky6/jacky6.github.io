    07_访问修饰符¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 四种权限范围 private < default < protected < public ⭐⭐⭐
    2 private 仅本类可见，封装的基础 ⭐⭐⭐
    3 default（包私有） 不写修饰符的默认权限，同包可见 ⭐⭐

    1. 访问修饰符概述¶

    1.1 知识点¶

    访问修饰符：控制类、字段、方法可见范围的关键字，是封装的实现手段。

    四种权限从小到大：private（本类）→ default（同包）→ protected（同包+子类）→ public（所有）。完整权限表见下方 1.2。

    1.2 什么是访问修饰符¶

    访问修饰符（Access Modifier）用于控制类、方法、字段的访问权限。

    四种访问级别：

    修饰符 同类 同包 子类 其他包
    private ✅ ❌ ❌ ❌
    default ✅ ✅ ❌ ❌
    protected ✅ ✅ ✅ ❌
    public ✅ ✅ ✅ ✅ 
    访问权限范围：

private < default < protected < public

┌─────────────────────────────────────┐
│          public (所有类)             │
│  ┌─────────────────────────────┐    │
│  │     protected (子类)         │    │
│  │  ┌──────────────────────┐   │    │
│  │  │   default (同包)      │   │    │
│  │  │  ┌──────────────┐    │   │    │
│  │  │  │  private     │    │   │    │
│  │  │  │  (同类)      │    │   │    │
│  │  │  └──────────────┘    │   │    │
│  │  └──────────────────────┘   │    │
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘

    2. private 私有¶

    知识点： - private 仅本类内可见，是四种权限中最严格的，也是封装的基础 - 常见用法：字段私有 + public getter/setter、内部辅助方法、单例模式的私有构造器 - ⚠️ 子类也不能直接访问父类的 private 成员，必须经由公共 getter/setter

    2.1 特点¶

    • ✅ 只能在本类中访问
    • ✅ 封装性最强
    • ❌ 子类和外部类无法访问

    2.2 使用示例¶

    public class Person {
    // 私有字段
    private String name;
    private int age;

    // 私有构造方法（单例模式）
    private Person() {
    }

    // 私有方法
    private void validateAge(int age) {
        if (age < 0 || age > 150) {
            throw new IllegalArgumentException("年龄不合法");
        }
    }

    // 公共 getter/setter
    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        validateAge(age);  // 内部调用私有方法
        this.age = age;
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Person p = new Person();

        // ✅ 可以通过公共方法访问
        p.setName("张三");
        String name = p.getName();

        // ❌ 不能直接访问私有成员
        // p.name = "张三";  // 编译错误
        // p.validateAge(25);  // 编译错误
    }
}

    2.3 使用场景¶

    1. 字段封装：所有字段应设为 private
    2. 内部辅助方法：不对外暴露的方法
    3. 单例模式：私有构造方法

    3. default 默认（包私有）¶

    知识点： - 不写任何修饰符即为 default（包私有），同包内可访问，跨包不可访问 - ⚠️ default 是"不写修饰符"的默认级别，没有对应的关键字 - 适用场景：包内工具类、包内协作、测试类

    3.1 特点¶

    • ✅ 同包内可访问
    • ✅ 不写修饰符即为 default
    • ❌ 不同包无法访问

    3.2 使用示例¶

    // 文件：com/example/demo/Animal.java
package com.example.demo;

// default 访问级别（不写修饰符）
class Animal {
    void eat() {
        System.out.println("吃东西");
    }
}

// 文件：com/example/demo/Dog.java
package com.example.demo;

// 同包可访问
public class Dog extends Animal {
    public void bark() {
        eat();  // ✅ 可以访问
    }
}

// 文件：com/example/other/Cat.java
package com.example.other;

import com.example.demo.Animal;

// 不同包无法访问
public class Cat extends Animal {
    public void meow() {
        // eat();  // ❌ 编译错误
    }
}

    3.3 使用场景¶

    1. 包内工具类：只在本包使用
    2. 测试类：测试代码与被测试类同包
    3. 内部协作：包内类之间协作

    4. protected 受保护¶

    知识点： - protected = 同包可见 + 跨包子类可见，介于 default 和 public 之间 - ⭐ 易错考点：跨包子类只能通过"子类自身类型的对象"访问父类 protected 成员，通过父类类型对象访问编译报错（见 4.4） - 适用场景：继承体系中供子类重写的扩展点、模板方法模式

    4.1 特点¶

    • ✅ 同包内可访问
    • ✅ 子类可访问（即使在不同包）
    • ❌ 其他包的非子类无法访问

    4.2 使用示例¶

    // 文件：com/example/demo/Person.java
package com.example.demo;

public class Person {
    protected String name;
    protected int age;

    protected void showInfo() {
        System.out.println(name + ", " + age);
    }
}

// 文件：com/example/demo/Student.java（同包）
package com.example.demo;

public class Student extends Person {
    public void study() {
        System.out.println(name);  // ✅ 同包可访问
        showInfo();  // ✅ 同包可访问
    }
}

// 文件：com/example/other/Employee.java（不同包，子类）
package com.example.other;

import com.example.demo.Person;

public class Employee extends Person {
    public void work() {
        System.out.println(name);  // ✅ 子类可访问
        showInfo();  // ✅ 子类可访问
    }
}

// 文件：com/example/other/Other.java（不同包，非子类）
package com.example.other;

import com.example.demo.Person;

public class Other {
    public void test() {
        Person p = new Person();
        // p.name = "张三";  // ❌ 编译错误
        // p.showInfo();  // ❌ 编译错误
    }
}

    4.3 使用场景¶

    1. 继承体系：父类希望子类访问
    2. 模板方法模式：子类需要重写的方法
    3. 框架设计：提供扩展点

    4.4 protected 跨包访问的精确规则 ⭐⭐⭐（易错考点）¶

    跨包子类访问父类 protected 成员，只能通过"子类自己类型的对象"访问，不能通过父类类型的对象访问：

    // 包 com.a
package com.a;
public class Parent {
    protected void method() {}
}

// 包 com.b
package com.b;
import com.a.Parent;

public class Child extends Parent {
    public void test() {
        method();                          // ✅ 通过 this（Child 类型）
        Child c = new Child();
        c.method();                        // ✅ 通过 Child 类型对象
        Parent p = new Parent();
        // p.method();                     // ❌ 编译错误！通过父类类型对象不行
        Parent p2 = new Child();
        // p2.method();                   // ❌ 编译错误！看声明类型，是 Parent
    }
}

    记忆：protected 的跨包访问权是"给子类自己的"，不是"给子类去操作任意父类对象的"。这条规则很少用到但偶尔作为笔试题出现。

    5. public 公共¶

    知识点： - public 任何地方都可访问，是权限最宽泛的级别，用于对外公开 API - 遵循最小权限原则：只把必要的 API 设为 public，过度使用会破坏封装 - 典型用法：对外 API 方法、工具类方法、入口类

    5.1 特点¶

    • ✅ 任何地方都可访问
    • ✅ 公开 API
    • ❌ 过度使用破坏封装

    5.2 使用示例¶

    // 文件：com/example/demo/UserService.java
package com.example.demo;

public class UserService {
    // 公共方法 - 对外 API
    public void createUser(String name) {
        // ...
    }

    public void deleteUser(Long id) {
        // ...
    }

    // 内部方法 - 不应公开
    private void validateName(String name) {
        // ...
    }
}

// 任何地方都可使用
public class Main {
    public static void main(String[] args) {
        UserService service = new UserService();
        service.createUser("张三");  // ✅ 可访问
    }
}

    5.3 使用场景¶

    1. 对外 API：提供给外部调用的方法
    2. 工具类方法：通用的工具方法
    3. 入口类：main 方法所在类

    6. 类的访问修饰符¶

    知识点： - 顶层类只能用 public 或 default（不写），不能用 private/protected（编译错误） - ⭐ 内部类（成员内部类）四种修饰符都能用，包括 private - public 顶层类任何包可访问，default 顶层类仅同包可见

    6.1 顶层类¶

    // ✅ public - 任何地方可访问
public class PublicClass {
}

// ✅ default - 同包可访问
class DefaultClass {
}

// ❌ private - 顶层类不能用 private
// private class PrivateClass {}  // 编译错误

// ❌ protected - 顶层类不能用 protected
// protected class ProtectedClass {}  // 编译错误

    6.2 内部类¶

    public class Outer {
    // 内部类可以使用所有访问修饰符
    public class PublicInner {}
    protected class ProtectedInner {}
    class DefaultInner {}
    private class PrivateInner {}
}

    7. 访问修饰符对比¶

    7.1 完整对比表¶

    修饰符 类 字段 方法 构造器 说明
    public ✅ ✅ ✅ ✅ 完全公开
    protected ❌ ✅ ✅ ✅ 子类 + 同包
    default ✅ ✅ ✅ ✅ 仅同包
    private ❌ ✅ ✅ ✅ 仅本类

    7.2 选择指南¶

    设计原则：最小权限原则

1. 字段：优先 private + getter/setter
2. 方法：
   - 对外 API → public
   - 子类扩展 → protected
   - 包内使用 → default
   - 内部辅助 → private
3. 构造器：
   - 正常创建 → public
   - 单例模式 → private
   - 工厂模式 → protected/default
4. 类：
   - 对外暴露 → public
   - 包内使用 → default

    8. 最佳实践¶

    8.1 封装原则¶

    // ✅ 推荐：字段私有，通过方法访问
public class Person {
    private String name;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}

// ❌ 不推荐：字段公开
public class Person {
    public String name;  // 破坏封装
}

    8.2 API 设计¶

    // ✅ 推荐：最小暴露
public class UserService {
    // 公共 API
    public User createUser(String name) {
        validate(name);
        return doCreate(name);
    }

    // 内部实现
    private void validate(String name) {
        // ...
    }

    private User doCreate(String name) {
        // ...
    }
}

    9. 练习题¶

    1. 封装练习：定义 Student 类，字段全部 private，通过 getter/setter 访问，并在 setScore() 中校验分数必须在 0~100 之间，否则抛出 IllegalArgumentException。
    2. 判断输出：下面哪些语句可以编译通过？说明原因。
    package com.example.demo;

public class Account {
    private double balance;
    void transfer() {}          // default（包私有）
    protected void deposit() {}
    public void withdraw() {}
}

// 同包下的其他类中：
Account acc = new Account();
acc.balance = 100;   // (1)
acc.transfer();      // (2)
acc.deposit();       // (3)
acc.withdraw();      // (4)
    1. 最小权限原则：解释为什么字段应该声明为 private，通过 public 的 getter/setter 访问。

    参考答案¶

    // 练习 1
public class Student {
    private String name;   // 私有字段，外部不能直接访问
    private int score;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getScore() {
        return score;
    }

    public void setScore(int score) {
        if (score < 0 || score > 100) {  // 入口处校验，防止非法数据
            throw new IllegalArgumentException("分数必须在 0~100 之间：" + score);
        }
        this.score = score;
    }
}

// 练习 2 答案：
// (1) 编译错误 —— balance 是 private，只能在 Account 类内部访问
// (2) 通过 —— transfer 是 default（包私有），同包可访问
// (3) 通过 —— protected 同包可访问（跨包的子类也可以）
// (4) 通过 —— public 任何地方都可以访问

// 练习 3 答案（要点）：
// 1. 隐藏内部实现：外部无法直接改字段，必须经过 setter 的校验逻辑
// 2. 控制读写权限：可以只提供 getter 不提供 setter（只读字段）
// 3. 便于修改内部结构：字段改名/拆分时，只要 getter/setter 签名不变，
//    外部代码不受影响

    10. 本章小结¶

    核心知识点¶

    ✅ private：仅本类访问，封装性最强
    ✅ default：同包访问，默认级别
    ✅ protected：子类 + 同包访问
    ✅ public：完全公开

    最佳实践¶

    1. 字段永远 private：通过 getter/setter 访问
    2. 方法按需暴露：优先 private，必要时 public
    3. 类最少暴露：内部类用 default 或 private
    4. 遵循最小权限：只暴露必要的接口
