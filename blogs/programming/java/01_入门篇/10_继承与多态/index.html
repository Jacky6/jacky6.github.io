    1. 继承概述¶

    知识点： - 继承 = 子类获得父类的属性和方法，实现代码复用，体现 is-a 关系 - ⭐ Java 是单继承（只能有一个直接父类），但可多层继承；所有类都继承 Object - ⚠️ 构造方法不被继承（用 super 调用）；private 成员存在于子类对象中但不能直接访问

    1.1 什么是继承¶

    继承（Inheritance）允许一个类（子类）获得另一个类（父类）的属性和方法，实现代码复用。

    生活类比：

    父亲：有房子、有车、会做饭
儿子：继承父亲的房子、车、做饭技能，还会打游戏

    儿子不用自己买房买车，直接"继承"父亲的东西，同时还可以有自己的新东西。

    1.2 为什么需要继承¶

    没有继承时：

    public class Dog {
    private String name;
    private int age;
    public void eat() { System.out.println(name + "在吃东西"); }
    public void sleep() { System.out.println(name + "在睡觉"); }
}

public class Cat {
    private String name;   // 重复！
    private int age;       // 重复！
    public void eat() { System.out.println(name + "在吃东西"); }   // 重复！
    public void sleep() { System.out.println(name + "在睡觉"); }   // 重复！
}

    使用继承后：

    public class Animal {
    protected String name;
    protected int age;

    public void eat() { System.out.println(name + "在吃东西"); }
    public void sleep() { System.out.println(name + "在睡觉"); }
}

public class Dog extends Animal {
    // 自动拥有 name、age、eat()、sleep()
    public void bark() { System.out.println(name + "汪汪叫"); }
}

public class Cat extends Animal {
    // 自动拥有 name、age、eat()、sleep()
    public void catchMouse() { System.out.println(name + "抓老鼠"); }
}

    ✅ 好处：

    • 代码复用：公共逻辑只写一次
    • 层次清晰：体现 is-a 关系（Dog is a Animal）
    • 为多态打基础

    1.3 Java 继承的特点¶

    特点 说明
    单继承 一个类只能有一个直接父类
    多层继承 A → B → C 可以层层继承
    所有类都继承 Object Object 是所有类的根
    构造方法不被继承 但可以通过 super 调用
    private 成员不被继承 子类无法直接访问父类 private 成员 
    // ❌ Java 不允许多继承（避免菱形继承问题）
public class Dog extends Animal, Pet { }

// ✅ 但可以多层继承
public class Animal { }
public class Dog extends Animal { }
public class GuideDog extends Dog { }   // 导盲犬也是狗，也是动物

    为什么不能多继承？ 如果 A 和 B 都有 eat() 方法，C 同时继承两者，调用 c.eat() 时无法确定用哪个。Java 用接口多实现解决这个问题（见 08_抽象类与接口）。

    2. 继承的基本语法¶

    知识点： - 语法：public class 子类 extends 父类；子类可直接访问父类 public/protected/同包成员 - ⚠️ private 成员会被继承（占子类对象内存）但不能直接访问，需通过父类 getter - 继承应体现 is-a 关系（Dog is a Animal）；has-a 关系应用组合

    2.1 extends 关键字¶

    public class 子类 extends 父类 {
    // 子类特有的成员
}

    2.2 子类能访问什么¶

    public class Parent {
    public int a = 1;        // ✅ 子类可访问
    protected int b = 2;     // ✅ 子类可访问
    int c = 3;               // ✅ 同包子类可访问
    private int d = 4;       // ❌ 子类不可访问（但内存中仍存在）
}

public class Child extends Parent {
    public void show() {
        System.out.println(a);  // 1 ✅
        System.out.println(b);  // 2 ✅
        System.out.println(c);  // 3 ✅
        // System.out.println(d);  // ❌ 编译错误
    }

    // 想访问 d，需要父类提供 getter
}

    注意：private 成员会被继承（占用子类对象的内存），只是不能直接访问，必须通过父类的 public/protected 方法。

    2.3 is-a 关系判断¶

    继承应该体现 is-a（是一种）关系：

    // ✅ 合理的继承
Dog extends Animal       // 狗是一种动物
Student extends Person   // 学生是一种人
ArrayList extends List   // ArrayList 是一种 List

// ❌ 不合理的继承
Car extends Engine       // 车不是发动机（应该是 has-a，用组合）
Person extends Hand      // 人不是手

    has-a 关系用组合（成员变量持有对象），is-a 关系才用继承。详见第 8 节。

    3. super 关键字¶

    知识点： - super 是父类引用：super.成员 访问被隐藏的父类成员，super.方法() 调用被重写的父类版本 - ⭐ super(...) 调用父类构造，必须是子类构造的第一条语句；不写时编译器自动插入无参 super() - ⚠️ 父类只有有参构造时，子类必须显式 super(参数)，否则编译错误 - this = 当前对象，super = 父类；this(...) 与 super(...) 不能同时出现在第一行

    super 代表父类的引用，用于访问被隐藏/重写的父类成员。

    3.1 访问父类成员和方法¶

    public class Parent {
    protected String name = "父亲";

    public void sayHello() {
        System.out.println("Hello from Parent");
    }
}

public class Child extends Parent {
    protected String name = "儿子";   // 隐藏了父类的 name

    public void show() {
        System.out.println(name);        // 儿子（本类的）
        System.out.println(super.name);  // 父亲（父类的）
    }

    @Override
    public void sayHello() {
        System.out.println("Hello from Child");
    }

    public void callParent() {
        sayHello();       // Hello from Child（本类的）
        super.sayHello(); // Hello from Parent（父类的）
    }
}

    3.2 调用父类构造方法¶

    public class Animal {
    protected String name;

    public Animal(String name) {
        System.out.println("Animal 构造：" + name);
        this.name = name;
    }
}

public class Dog extends Animal {
    private String breed;

    public Dog(String name, String breed) {
        super(name);  // ⭐ 调用父类构造，必须是第一条语句
        this.breed = breed;
        System.out.println("Dog 构造：" + breed);
    }
}

// 输出：
// Animal 构造：旺财
// Dog 构造：金毛

    规则：

    • super(...) 必须放在子类构造方法的第一行
    • 不写时编译器自动插入 super()（无参）
    • 如果父类没有无参构造，子类必须显式调用 super(参数)，否则编译错误
    public class Parent {
    public Parent(int x) { }   // 只有有参构造
}

public class Child extends Parent {
    // public Child() { }      // ❌ 编译错误：找不到 Parent 的无参构造
    public Child() { super(10); }  // ✅ 必须显式调用
}

    3.3 this vs super¶

    关键字 含义 用途
    this 当前对象引用 访问本类成员、调用本类构造
    super 父类引用 访问父类成员、调用父类构造 
    public void method() {
    this.name;    // 本类的 name
    super.name;   // 父类的 name
}

public Child() {
    this(1, 2);    // 调用本类其他构造
    super(1, 2);   // 调用父类构造
    // 两者不能同时出现在第一行
}

    4. 方法重写（Override）¶

    知识点： - 重写 = 子类重新实现父类方法，方法签名（方法名 + 参数列表）必须相同 - ⭐ 重写规则：返回类型相同或子类（协变）、访问权限不能更严、不能抛更大的受检异常 - ⚠️ static/private/final 方法不能被重写；务必加 @Override 让编译器检查

    4.1 什么是重写¶

    子类对父类的方法重新实现，方法签名必须相同。

    public class Animal {
    public void eat() {
        System.out.println("动物吃东西");
    }
}

public class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("狗吃骨头");   // 重写了父类的 eat()
    }
}

public class Cat extends Animal {
    @Override
    public void eat() {
        System.out.println("猫吃鱼");
    }
}

    4.2 重写规则 ⭐⭐⭐¶

    规则 说明
    方法签名相同 方法名 + 参数列表必须一致
    返回值兼容 相同或是其子类（协变返回）
    访问权限不能更严 父类 public → 子类不能 private
    不能重写 static 方法 只能隐藏（见 4.4）
    不能重写 private 方法 父类 private 方法对子类不可见
    不能重写 final 方法 final 方法禁止重写 
    public class Parent {
    public Number calc() { return 1; }
}

public class Child extends Parent {
    @Override
    public Integer calc() { return 2; }   // ✅ Integer 是 Number 的子类（协变返回）
}

public class Child2 extends Parent {
    @Override
    protected Number calc() { return 2; } // ❌ public → protected 权限变严，编译错误
}

    4.3 @Override 注解¶

    @Override  // ⭐ 强烈建议加上
public void eat() { }

    作用：让编译器检查是否真的构成重写。

    public class Dog extends Animal {
    @Override
    public void eat(String food) { }  // ❌ 编译错误：父类没有 eat(String)
    // 如果不加 @Override，这会被当成一个新方法，bug 悄悄引入
}

    4.4 重载 vs 重写¶

    对比项 重载 Overload 重写 Override
    位置 同一个类中 父子类之间
    参数列表 必须不同 必须相同
    返回值 无要求 相同或协变
    异常 无要求 不能抛更大受检异常
    绑定时机 编译期 运行期（多态）

    4.5 重写与异常¶

    public class Parent {
    public void work() throws IOException { }
}

public class Child extends Parent {
    @Override
    public void work() throws FileNotFoundException { }  // ✅ 更具体的异常
    // public void work() throws Exception { }           // ❌ 不能抛更大的受检异常
}

    记忆口诀：重写只能"变窄"，不能"变宽"——返回值更具体、异常更小、权限更宽。

    5. 构造方法与初始化顺序 ⭐⭐⭐¶

    知识点： - ⭐ 初始化顺序：父静态 → 子静态 → 父代码块 → 父构造 → 子代码块 → 子构造 - 记忆口诀：静态优先 → 父类优先 → 代码块优先于构造方法 - 静态代码块类加载时只执行一次，再次创建对象不再执行 - 原因：子类构造第一行隐式调用 super()，父类必须先初始化完成

    5.1 创建子类对象时发生了什么¶

    public class Parent {
    static { System.out.println("1. Parent 静态代码块"); }
    { System.out.println("3. Parent 实例代码块"); }

    public Parent() {
        System.out.println("4. Parent 构造方法");
    }
}

public class Child extends Parent {
    static { System.out.println("2. Child 静态代码块"); }
    { System.out.println("5. Child 实例代码块"); }

    public Child() {
        System.out.println("6. Child 构造方法");
    }
}

new Child();
// 输出：
// 1. Parent 静态代码块     ← 类加载时，父类优先
// 2. Child 静态代码块      ← 类加载时（只执行一次）
// 3. Parent 实例代码块
// 4. Parent 构造方法
// 5. Child 实例代码块
// 6. Child 构造方法

    5.2 记忆口诀¶

    静态优先 → 父类优先 → 代码块优先于构造方法

完整顺序：
父静态 → 子静态 → 父代码块 → 父构造 → 子代码块 → 子构造

    原因：子类构造方法第一行隐式/显式调用 super()，所以父类一定先初始化完成——保证子类使用父类成员时它们已就绪。

    5.3 静态只执行一次¶

    new Child();
new Child();  // 第二次：静态代码块不再执行
// 输出：3 4 5 6（只有实例部分）

    6. 多态 ⭐⭐⭐⭐¶

    知识点： - ⭐ 多态三条件：继承（或接口实现）+ 方法重写 + 父类引用指向子类对象（向上转型） - 动态绑定：编译看声明类型（左边），运行看实际类型（右边）——编译看左边，运行看右边 - ⚠️ 向上转型自动，向下转型需强转；不用 instanceof 检查可能抛 ClassCastException - ⚠️ 只有实例方法有多态；成员变量和静态方法看声明类型，不动态绑定

    6.1 什么是多态¶

    多态（Polymorphism）：同一个方法调用，作用在不同对象上，表现出不同行为。

    Animal dog = new Dog();
Animal cat = new Cat();

dog.eat();  // 狗吃骨头
cat.eat();  // 猫吃鱼

    同样是 eat()，具体执行哪个版本由对象的实际类型决定。

    6.2 多态的三个条件¶

    1. 有继承关系（或接口实现）
    2. 有方法重写
    3. 父类引用指向子类对象（向上转型）
    Animal animal = new Dog();  // ⭐ 向上转型（upcasting）
animal.eat();               // 运行的是 Dog 的 eat()

    6.3 动态绑定原理¶

    Animal animal = new Dog();
animal.eat();
    • 编译期：编译器看声明类型 Animal，检查 Animal 有没有 eat() 方法
    • 运行期：JVM 看实际类型 Dog，执行 Dog 的 eat()

    口诀：编译看左边，运行看右边。

    6.4 向上转型与向下转型¶

    // 向上转型：子类 → 父类（自动，安全）
Animal animal = new Dog();

// 向下转型：父类 → 子类（强制，有风险）
Dog dog = (Dog) animal;      // ✅ 实际类型确实是 Dog

Animal cat = new Cat();
Dog d2 = (Dog) cat;          // ❌ ClassCastException！cat 实际是 Cat

    安全做法：转型前用 instanceof 检查。

    if (animal instanceof Dog) {
    Dog dog = (Dog) animal;
    dog.bark();
}

    JDK 16+ 模式匹配（更简洁）：

    if (animal instanceof Dog dog) {   // 判断 + 转型 + 声明一步完成
    dog.bark();
}

    6.5 多态的经典应用¶

    public class AnimalClinic {
    // 一个方法处理所有动物
    public static void feed(Animal animal) {
        animal.eat();   // 传 Dog 就吃骨头，传 Cat 就吃鱼
    }

    public static void main(String[] args) {
        feed(new Dog());   // 狗吃骨头
        feed(new Cat());   // 猫吃鱼
        feed(new Duck());  // 鸭子吃谷物（新增 Duck 无需改 feed 方法）
    }
}

    ✅ 多态的价值：方法只依赖父类类型，新增子类不用改已有代码——开闭原则的基础。

    6.6 多态的边界：成员变量与静态方法¶

    public class Parent {
    public int num = 10;
    public static void staticMethod() { System.out.println("Parent static"); }
}

public class Child extends Parent {
    public int num = 20;
    public static void staticMethod() { System.out.println("Child static"); }
}

Parent p = new Child();
System.out.println(p.num);         // 10 ⚠️ 成员变量看声明类型！
p.staticMethod();                  // Parent static ⚠️ 静态方法看声明类型！
    成员类型 看谁的 原因
    成员变量 声明类型（编译期确定） 字段没有重写，只有隐藏
    静态方法 声明类型 属于类，不属于对象
    实例方法 实际类型（运行期确定） 动态绑定 → 多态

    只有实例方法有多态，成员变量和静态方法都是"编译看左边"。

    7. final 关键字¶

    知识点： - 三种用法：final 变量不可重新赋值、final 方法不能被重写、final 类不能被继承（String 就是 final 类） - ⚠️ final 字段必须在构造时赋值，之后不可变 - 不可变对象模式：final 类 + 私有 final 字段 + 只提供 getter，天然线程安全（String、Integer 等）

    7.1 三种用法¶

    // 1. final 变量：赋值后不可改
final int MAX = 100;
// MAX = 200;  // ❌ 编译错误

// 2. final 方法：不能被重写
public class Parent {
    public final void method() { }
}
public class Child extends Parent {
    // public void method() { }  // ❌ 编译错误
}

// 3. final 类：不能被继承
public final class String { }   // String 就是 final 类
// public class MyString extends String { }  // ❌ 编译错误

    7.2 final 与不可变对象¶

    public class ImmutablePoint {
    private final int x;   // final 字段必须在构造时赋值
    private final int y;

    public ImmutablePoint(int x, int y) {
        this.x = x;
        this.y = y;
    }
    // 只提供 getter，不提供 setter → 对象创建后状态不可变
}

    String、Integer 等包装类都是 final + 私有字段 + 无 setter 的不可变类，天然线程安全。

    8. 组合 vs 继承¶

    知识点： - is-a 关系用继承（Dog is a Animal），has-a 关系用组合（Car 有一个 Engine） - ⭐ 继承耦合高（父类改动影响子类）且编译期固定；组合耦合低、运行期可替换 - 设计原则：组合优于继承；只有明确 is-a 且需要多态时才用继承

    8.1 has-a 用组合¶

    // ❌ 错误示范：Car 不是 Engine
public class Car extends Engine { }

// ✅ 正确：Car 有一个 Engine（组合）
public class Car {
    private Engine engine;   // has-a
    private List<Wheel> wheels;

    public Car(Engine engine) {
        this.engine = engine;
    }
}

    8.2 对比¶

    对比项 继承 is-a 组合 has-a
    关系 是一种 有一个
    耦合度 高（父类改动影响子类） 低
    灵活性 编译期固定 运行期可替换
    建议 谨慎使用 ⭐ 优先使用

    设计原则：优先使用组合，而不是继承（Composition over Inheritance）。只有明确的 is-a 关系、且需要多态时才用继承。

    9. 综合实战：图形系统¶

    // 抽象父类
public abstract class Shape {
    protected String color;

    public Shape(String color) {
        this.color = color;
    }

    // 抽象方法：子类必须实现
    public abstract double area();

    // 普通方法：复用
    public void describe() {
        System.out.printf("%s色图形，面积 %.2f%n", color, area());
    }
}

// 圆形
public class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }
}

// 矩形
public class Rectangle extends Shape {
    private double width, height;

    public Rectangle(String color, double width, double height) {
        super(color);
        this.width = width;
        this.height = height;
    }

    @Override
    public double area() {
        return width * height;
    }
}

// 利用多态：统一处理
public class ShapeDemo {
    public static double totalArea(Shape[] shapes) {
        double total = 0;
        for (Shape s : shapes) {
            total += s.area();   // 多态：各算各的
        }
        return total;
    }

    public static void main(String[] args) {
        Shape[] shapes = {
            new Circle("红", 2),
            new Rectangle("蓝", 3, 4)
        };
        for (Shape s : shapes) {
            s.describe();
        }
        System.out.printf("总面积：%.2f%n", totalArea(shapes));
    }
}

    10. 常见面试题¶

    Q1：为什么 Java 是单继承？

    避免菱形继承的歧义：若 B、C 都继承 A 并重写了方法，D 同时继承 B、C 时无法确定用哪个版本。接口可以多实现，因为接口方法要么没实现、要么用 default 且冲突时强制重写。

    Q2：new Child() 时构造方法的调用顺序？

    父类静态块 → 子类静态块 → 父类代码块/构造 → 子类代码块/构造。核心：super() 保证父类先初始化。

    Q3：重载和重写的区别？

    重载是同一个类中方法名相同参数不同（编译期）；重写是子类重新实现父类方法（运行期多态）。

    Q4：成员变量有多态吗？

    没有。成员变量在编译期按声明类型确定；只有实例方法动态绑定。

    Q5：Object 类的作用？

    所有类的根父类，提供 equals、hashCode、toString 等基础方法。详见 11_Object 类详解。

    11.3 参考答案¶

    // 练习 1
public class Employee {
    protected String name;
    protected double salary;

    public Employee(String name, double salary) {
        this.name = name;
        this.salary = salary;
    }

    public double getSalary() { return salary; }
}

public class Manager extends Employee {
    private double bonus;

    public Manager(String name, double salary, double bonus) {
        super(name, salary);
        this.bonus = bonus;
    }

    @Override
    public double getSalary() { return salary + bonus; }
}

// 练习 2 答案：
// a.method(a) → B-A
//   编译期：A 有 method(A)，✅；运行期：实际类型 B，method(A) 被重写 → B-A
// a.method(b) → A-B
//   编译期：按声明类型 A 选最匹配的 method(B)；运行期：B 没有重写 method(B)
//   （B 的 method(B) 是新增的重载，不是重写）→ 执行 A 的 method(B)

    12. 本章小结¶

    核心知识点¶

    ✅ 继承语法：extends、单继承、访问规则
    ✅ super：访问父类成员、调用父类构造
    ✅ 方法重写：规则、@Override、与重载的区别
    ✅ 初始化顺序：静态优先、父类优先
    ✅ 多态：向上转型、动态绑定、instanceof
    ✅ final：变量/方法/类
    ✅ 组合优于继承

    最佳实践¶

    1. 重写必加 @Override：让编译器帮你检查
    2. 转型前用 instanceof：避免 ClassCastException
    3. 优先组合，谨慎继承：只有 is-a 且需要多态时才继承
    4. 父类构造放第一行：理解 super() 的隐式调用
    5. 不可变类用 final：final 类 + final 字段 + 无 setter
