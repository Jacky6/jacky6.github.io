    本章知识点清单¶

    1. 枚举概述¶

    1.1 知识点¶

    枚举（Enum）是一种特殊的数据类型，用于定义一组固定的常量。

    ⭐ 枚举的本质（高频考点）：枚举不是新发明，而是语法糖包装的类—— - 每个 enum 隐式继承 java.lang.Enum，不能再继承其他类 - 每个枚举常量（如 MONDAY）都是该枚举类的一个实例，且是 public static final 的，在类加载时创建，全局唯一 - 所以枚举可以用 == 比较（比较的就是引用），也能实现接口、带字段和方法

    与 C++ 对比：C++ 的 enum 本质是整数（类型不安全，MONDAY 可以和任意 int 比较/赋值）；Java 枚举是真正的类型，DayOfWeek.MONDAY 不能赋给 int，传参类型错误编译期就报错——这就是"类型安全"的含义。

    使用场景：

    • ✅ 固定的状态（星期、月份、季节）
    • ✅ 固定的类型（订单状态、用户角色）
    • ✅ 替代 int 常量（类型安全）

    1.2 为什么需要枚举¶

    // ❌ 使用 int 常量（不推荐）
public class Constants {
    public static final int MONDAY = 1;
    public static final int TUESDAY = 2;
}

// ✅ 使用枚举（推荐）
public enum DayOfWeek {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

    2. 枚举定义和使用¶

    2.1 知识点¶

    • 枚举常量全大写下划线命名，逗号分隔，分号或换行结束
    • 四个常用方法：values()（所有值数组）、valueOf(str)（按名查找）、name()（常量名）、ordinal()（序号，从 0 起）
    • 枚举可以放在 switch 中使用（case 不带类名）

    2.2 示例：基本定义¶

    public enum DayOfWeek {
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY,
    SUNDAY
}

// 使用
public class Main {
    public static void main(String[] args) {
        DayOfWeek today = DayOfWeek.MONDAY;

        // 比较
        if (today == DayOfWeek.MONDAY) {
            System.out.println("今天是周一");
        }

        // 打印
        System.out.println(today);  // MONDAY
        System.out.println(today.name());  // MONDAY
        System.out.println(today.ordinal());  // 0（索引）
    }
}

    ⚠️ 两个易错点：

    // 1. 枚举用于 switch 时，case 里不能带枚举类名
switch (today) {
    case MONDAY:    // ✅
    // case DayOfWeek.MONDAY:  // ❌ 编译错误
}

// 2. valueOf 找不到时抛异常（不是返回 null）
Status s = Status.valueOf("PENDING");      // ✅
// Status x = Status.valueOf("UNKNOWN");   // ❌ IllegalArgumentException
// 安全写法：先遍历 values() 或用 try-catch

// 3. name() 不可重写，toString() 可以重写——需要自定义展示文本时重写 toString()

    2.3 常用方法¶

    public enum Status {
    PENDING, PROCESSING, COMPLETED, CANCELLED
}

public class Main {
    public static void main(String[] args) {
        // values() - 获取所有枚举值
        Status[] statuses = Status.values();
        for (Status s : statuses) {
            System.out.println(s);
        }

        // valueOf() - 字符串转枚举
        Status status = Status.valueOf("PENDING");

        // ordinal() - 获取索引
        int index = Status.COMPLETED.ordinal();  // 2

        // compareTo() - 比较顺序
        int cmp = Status.PENDING.compareTo(Status.COMPLETED);  // -2
    }
}

    3. 枚举的字段和方法¶

    3.1 知识点¶

    枚举本质是类，所以可以有字段、方法、构造器。构造器必须是 private（枚举实例只能在定义时创建，不允许外部 new）。

    3.2 示例：带字段的枚举¶

    public enum Season {
    SPRING("春", "春暖花开"),
    SUMMER("夏", "烈日炎炎"),
    AUTUMN("秋", "秋高气爽"),
    WINTER("冬", "白雪皑皑");

    // 字段
    private final String chineseName;
    private final String description;

    // 构造方法（必须 private）
    Season(String chineseName, String description) {
        this.chineseName = chineseName;
        this.description = description;
    }

    // getter 方法
    public String getChineseName() {
        return chineseName;
    }

    public String getDescription() {
        return description;
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Season spring = Season.SPRING;
        System.out.println(spring.getChineseName());  // 春
        System.out.println(spring.getDescription());  // 春暖花开
    }
}

    3.3 带方法的枚举¶

    public enum Operation {
    PLUS("+") {
        @Override
        public double apply(double x, double y) {
            return x + y;
        }
    },
    MINUS("-") {
        @Override
        public double apply(double x, double y) {
            return x - y;
        }
    },
    TIMES("*") {
        @Override
        public double apply(double x, double y) {
            return x * y;
        }
    },
    DIVIDE("/") {
        @Override
        public double apply(double x, double y) {
            return x / y;
        }
    };

    private final String symbol;

    Operation(String symbol) {
        this.symbol = symbol;
    }

    // 抽象方法
    public abstract double apply(double x, double y);

    public String getSymbol() {
        return symbol;
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        double result = Operation.PLUS.apply(10, 5);  // 15.0
        System.out.println(result);
    }
}

    4. 枚举实现接口¶

    知识点：

    • 枚举已隐式继承 java.lang.Enum，不能再继承其他类，但可以实现接口
    • 枚举实现接口时，每个常量可用匿名类体（ALIPAY { ... }）各自实现方法
    • 也可以在枚举类中定义公共方法，供所有常量共享
    // 接口
public interface Payable {
    void pay(BigDecimal amount);
}

// 枚举实现接口
public enum PaymentMethod implements Payable {
    ALIPAY {
        @Override
        public void pay(BigDecimal amount) {
            System.out.println("支付宝支付：" + amount);
        }
    },
    WECHAT {
        @Override
        public void pay(BigDecimal amount) {
            System.out.println("微信支付：" + amount);
        }
    },
    CREDIT_CARD {
        @Override
        public void pay(BigDecimal amount) {
            System.out.println("信用卡支付：" + amount);
        }
    };

    // 公共方法
    public boolean isValid() {
        return true;
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        PaymentMethod method = PaymentMethod.ALIPAY;
        method.pay(new BigDecimal("100.00"));
    }
}

    5. EnumSet 和 EnumMap¶

    知识点：

    • EnumSet/EnumMap 是专为枚举键优化的集合，内部用位向量/数组实现，比 HashSet/HashMap 快得多
    • EnumSet 常用工厂方法：of、range（范围）、allOf（全部）、complementOf（补集）
    • EnumMap 构造时需传入枚举类的 Class 对象：new EnumMap<>(Status.class)

    5.1 EnumSet¶

    import java.util.EnumSet;

public enum DayOfWeek {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

public class Main {
    public static void main(String[] args) {
        // 创建 EnumSet
        EnumSet<DayOfWeek> weekdays = EnumSet.of(
            DayOfWeek.MONDAY,
            DayOfWeek.TUESDAY,
            DayOfWeek.WEDNESDAY,
            DayOfWeek.THURSDAY,
            DayOfWeek.FRIDAY
        );

        // 范围
        EnumSet<DayOfWeek> range = EnumSet.range(
            DayOfWeek.MONDAY, 
            DayOfWeek.FRIDAY
        );

        // 全部
        EnumSet<DayOfWeek> all = EnumSet.allOf(DayOfWeek.class);

        // 补集
        EnumSet<DayOfWeek> weekend = EnumSet.complementOf(weekdays);
    }
}

    5.2 EnumMap¶

    import java.util.EnumMap;
import java.util.Map;

public enum Status {
    PENDING, PROCESSING, COMPLETED
}

public class Main {
    public static void main(String[] args) {
        // 创建 EnumMap
        Map<Status, String> map = new EnumMap<>(Status.class);

        // 添加
        map.put(Status.PENDING, "待处理");
        map.put(Status.PROCESSING, "处理中");
        map.put(Status.COMPLETED, "已完成");

        // 获取
        String desc = map.get(Status.PENDING);
    }
}

    6. 枚举单例¶

    知识点：

    • ⭐ 枚举单例是《Effective Java》推荐的最佳写法：一行代码，天然线程安全
    • 天然免疫反射攻击（JVM 禁止反射创建枚举实例）和序列化破坏
    • 详见 单例模式

    ⭐ 为什么枚举是最佳单例？（Effective Java 推荐，必考）

    public enum Singleton {
    INSTANCE;  // 唯一实例

    public void doSomething() { }
}

    对比双重检查锁等写法，枚举单例天然免疫两种破坏：

    1. 反射攻击：JVM 禁止反射创建枚举实例（抛 IllegalArgumentException）
    2. 序列化攻击：枚举的序列化机制保证反序列化后仍是同一实例

    详见 单例模式。

    // 枚举实现单例（推荐）
public enum Singleton {
    INSTANCE;

    public void doSomething() {
        System.out.println("单例方法");
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Singleton s1 = Singleton.INSTANCE;
        Singleton s2 = Singleton.INSTANCE;

        System.out.println(s1 == s2);  // true

        s1.doSomething();
    }
}

    优点：

    • ✅ 线程安全
    • ✅ 防止反射攻击
    • ✅ 防止序列化破坏
    • ✅ 代码简洁

    7.1 订单状态¶

    public enum OrderStatus {
    PENDING(1, "待支付"),
    PAID(2, "已支付"),
    SHIPPED(3, "已发货"),
    DELIVERED(4, "已送达"),
    COMPLETED(5, "已完成"),
    CANCELLED(6, "已取消");

    private final int code;
    private final String description;

    OrderStatus(int code, String description) {
        this.code = code;
        this.description = description;
    }

    public int getCode() {
        return code;
    }

    public String getDescription() {
        return description;
    }

    // 根据 code 获取枚举
    public static OrderStatus fromCode(int code) {
        for (OrderStatus status : values()) {
            if (status.code == code) {
                return status;
            }
        }
        throw new IllegalArgumentException("Unknown code: " + code);
    }
}

// 使用
public class Order {
    private OrderStatus status;

    public void updateStatus(OrderStatus newStatus) {
        // 状态流转验证
        if (!canTransitionTo(newStatus)) {
            throw new IllegalStateException("Invalid status transition");
        }
        this.status = newStatus;
    }

    private boolean canTransitionTo(OrderStatus newStatus) {
        // 定义状态流转规则
        return true;  // 简化
    }
}

    7.2 用户角色¶

    public enum Role {
    ADMIN("管理员", 1),
    MANAGER("经理", 2),
    USER("普通用户", 3),
    GUEST("访客", 4);

    private final String name;
    private final int level;

    Role(String name, int level) {
        this.name = name;
        this.level = level;
    }

    public boolean hasPermission(Role required) {
        return this.level <= required.level;
    }
}

// 使用
public class User {
    private Role role;

    public boolean canAccess(Resource resource) {
        return role.hasPermission(resource.getRequiredRole());
    }
}

    8. 练习题¶

    1. 带字段的枚举：定义枚举 Level（LOW/MEDIUM/HIGH），每个等级带中文名和分值字段，提供 getter。
    2. 枚举 switch：写一个方法，用 switch 根据 Level 返回对应评语（LOW → "继续加油"、MEDIUM → "表现不错"、HIGH → "非常优秀"）。
    3. 判断输出：说出下面代码的输出并解释原因。
    enum Season { SPRING, SUMMER, AUTUMN, WINTER }

System.out.println(Season.SUMMER.ordinal());                  // (1)
System.out.println(Season.valueOf("AUTUMN"));                 // (2)
System.out.println(Season.WINTER.compareTo(Season.SPRING));   // (3)
for (Season s : Season.values()) {
    System.out.print(s + " ");                                // (4)
}

    参考答案¶

    // 练习 1
public enum Level {
    LOW("低", 1),
    MEDIUM("中", 3),
    HIGH("高", 5);

    private final String chineseName;  // 枚举字段必须是 final
    private final int score;

    // 构造方法必须是 private（枚举实例只能在枚举内部创建）
    Level(String chineseName, int score) {
        this.chineseName = chineseName;
        this.score = score;
    }

    public String getChineseName() {
        return chineseName;
    }

    public int getScore() {
        return score;
    }
}

// 练习 2
public static String comment(Level level) {
    switch (level) {  // switch 直接支持枚举
        case LOW:
            return "继续加油";
        case MEDIUM:
            return "表现不错";
        case HIGH:
            return "非常优秀";
        default:
            return "未知等级";
    }
}
// comment(Level.HIGH) → 非常优秀

// 练习 3 答案：
// (1) 1 —— ordinal() 返回声明顺序索引（从 0 开始），SUMMER 是第 2 个
// (2) AUTUMN —— valueOf() 按名称字符串查找枚举常量，找不到会抛异常
// (3) 3 —— compareTo() 返回 ordinal 之差：3 - 0 = 3
// (4) SPRING SUMMER AUTUMN WINTER —— values() 按声明顺序返回所有枚举值

    9. 本章小结¶

    核心知识点¶

    ✅ 枚举定义：enum 关键字，固定常量
    ✅ 枚举字段和方法：构造方法、getter、抽象方法
    ✅ 枚举实现接口：支持接口实现
    ✅ EnumSet/EnumMap：专用集合
    ✅ 枚举单例：最安全的单例实现

    最佳实践¶

    1. 用枚举替代 int 常量：类型安全
    2. 枚举带字段：存储更多信息
    3. 状态流转用枚举：清晰的狀態管理
    4. 单例用枚举：最安全简洁
