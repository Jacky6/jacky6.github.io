    1. 面向对象概述¶

    1.1 知识点¶

    面向对象编程（OOP - Object Oriented Programming）是一种编程思想，将现实世界抽象为对象。

    类（Class）：对一类事物的抽象描述/模板，定义这类事物共有的属性和行为。类本身不是具体事物——"人类"是一个概念，"张三"才是具体的人。 对象（Object）：根据类创建出来的具体实例（Instance）。同一个类可以创建无数个对象，每个对象有自己的属性值。

    与 C++ 对比：概念上完全一致，但 Java 的对象只能在堆上创建（new 出来），没有 C++ 的栈对象和值语义；变量保存的是引用（可以类比 C++ 的指针，但更安全、不能做指针运算）。

    三大特性： - ✅ 封装：隐藏实现细节，暴露公共接口 - ✅ 继承：子类继承父类的属性和方法 - ✅ 多态：同一接口，不同实现

    面向对象 vs 面向过程：

    特性 面向过程 面向对象
    核心 过程/步骤 对象/类
    优点 流程清晰 易维护、易扩展
    缺点 不易维护 复杂度略高
    场景 简单任务 复杂系统 
    面向过程：把大象装进冰箱
1. 打开冰箱门
2. 把大象放进去
3. 关上冰箱门

面向对象：
冰箱对象：打开 ()、关闭 ()、放入 (大象)
大象对象：进入 (冰箱)

    2. 类的定义¶

    2.1 知识点¶

    • 类 = 成员变量（属性/状态）+ 成员方法（行为）
    • 字段分两种：实例变量（每对象一份）和静态变量（static，全类共享）
    • 加 static final 就是类常量

    2.2 示例：类的基本结构¶

    public class Person {
    // 1. 成员变量（属性）
    private String name;
    private int age;

    // 2. 构造方法
    public Person() {
    }

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 3. 成员方法（行为）
    public void sayHello() {
        System.out.println("Hello, I'm " + name);
    }

    public void setAge(int age) {
        if (age > 0 && age < 150) {
            this.age = age;
        }
    }

    public int getAge() {
        return age;
    }
}

    2.3 成员变量¶

    静态（static）：属于类本身，所有对象共享一份，类加载时初始化；实例（非 static）：属于每个对象，每个对象独立一份。

    与 C++ 对比：等价于 C++ 的 static 类成员。区别是 Java 更强调"用类名访问静态成员"（Person.count 而非 p.count）。

    public class Person {
    // 实例变量（每个对象独立）
    private String name;
    private int age;

    // 静态变量（所有对象共享）
    private static int count = 0;

    // 常量（不能修改）
    private static final String SPECIES = "Homo sapiens";
}

    ⚠️ 静态方法不能访问实例成员（必考）：

    public class Demo {
    private int x = 1;
    private static int y = 2;

    public static void staticMethod() {
        System.out.println(y);  // ✅ 静态访问静态
        // System.out.println(x);  // ❌ 编译错误：静态方法里没有 this，
        //                            不知道访问哪个对象的 x
    }

    public void instanceMethod() {
        System.out.println(x);  // ✅ 实例方法两类都能访问
        System.out.println(y);  // ✅
    }
}
// 记忆：静态先于对象存在，此时可能根本没有对象 → 不能访问实例成员
// main 方法是 static 的，所以里面要用对象必须先 new

    2.4 成员方法¶

    public class Person {
    // 无参无返回
    public void sayHello() {
        System.out.println("Hello");
    }

    // 有参无返回
    public void setName(String name) {
        this.name = name;
    }

    // 有参有返回
    public int add(int a, int b) {
        return a + b;
    }

    // 静态方法
    public static void printCount() {
        System.out.println("Count: " + count);
    }
}

    3. 对象的创建和使用¶

    3.1 知识点¶

    • new 三件事：分配堆内存 → 成员变量默认值 → 调构造方法
    • 赋值传递的是引用（共享对象），不是对象副本
    • 引用可以为 null，对 null 调用方法抛 NullPointerException
    • == 比引用（是否同一对象），equals 比内容（需重写，见 Object 类详解）

    3.2 示例：创建对象¶

    new 做了三件事：① 在堆内存中为对象分配空间；② 成员变量初始化为默认值；③ 调用构造方法完成初始化，最后返回对象的引用。

    ⭐ 内存位置（考点）： - 栈：局部变量（包括引用变量本身）——方法调用时创建，方法结束即销毁 - 堆：new 出来的对象——由垃圾回收器（GC）管理生命周期 - 与 C++ 对比：C++ 的 Person p; 在栈上，new Person 在堆上；Java 只有后者

    // 方式 1：使用 new 关键字
Person p1 = new Person();
Person p2 = new Person("张三", 25);

// 方式 2：使用反射（后续章节）
Class<?> clazz = Class.forName("com.example.Person");
Person p3 = (Person) clazz.newInstance();

    ⚠️ 引用语义（初学者第一大坑）：

    Person a = new Person("张三", 25);
Person b = a;          // b 和 a 指向【同一个对象】（复制的是引用，不是对象！）
b.setAge(30);
System.out.println(a.getAge());  // 30 ⚠️ a 看到的也变了

Person c = null;       // 引用可以为 null，表示"不指向任何对象"
// c.sayHello();       // ❌ NullPointerException：对 null 调用方法直接崩溃

    3.3 访问成员¶

    Person p = new Person("张三", 25);

// 访问属性（通过 getter/setter）
String name = p.getName();
p.setAge(26);

// 调用方法
p.sayHello();  // Hello, I'm 张三
int result = p.add(10, 20);  // 30

// 访问静态成员
Person.printCount();

    3.4 对象比较¶

    Person p1 = new Person("张三", 25);
Person p2 = new Person("张三", 25);
Person p3 = p1;

// == 比较引用
System.out.println(p1 == p2);  // false（不同对象）
System.out.println(p1 == p3);  // true（同一对象）

// equals 比较内容
System.out.println(p1.equals(p2));  // 默认 false（比较引用）
                                   // 重写后 true（比较内容）

    4. 构造方法¶

    构造方法（Constructor）：创建对象时自动调用的特殊方法，负责初始化新对象。它不是普通方法——没有返回值、不能用对象调用、只能由 new 触发。

    与 C++ 对比：规则基本一致（同名、无返回值、可重载、默认构造）。Java 额外提供 this(...) 在一个构造里调用另一个构造（对应 C++11 的委托构造）。

    构造方法四特点：① 与类同名 ② 无返回值类型（连 void 都没有）③ new 时自动调用 ④ 可重载。

    默认构造规则 ⚠️：一个构造方法都没写时，编译器提供无参默认构造；只要写了任何一个构造，默认构造就消失——需要无参构造必须手动补上（很多框架反序列化依赖无参构造）。

    4.1 示例：构造方法定义¶

    public class Person {
    private String name;
    private int age;

    // 无参构造
    public Person() {
        System.out.println("无参构造");
    }

    // 有参构造
    public Person(String name, int age) {
        System.out.println("有参构造");
        this.name = name;
        this.age = age;
    }

    // 构造方法重载
    public Person(String name) {
        this(name, 0);  // 调用其他构造
    }
}

    4.2 构造方法特点¶

    public class Person {
    // 特点：
    // 1. 方法名与类名相同
    // 2. 没有返回值类型（连 void 都没有）
    // 3. 创建对象时自动调用
    // 4. 可以重载

    public Person() {
    }
}

    4.3 默认构造¶

    // 如果没有定义任何构造方法，编译器会提供默认无参构造
public class Person {
    // 编译器自动添加：
    // public Person() {}
}

// 如果定义了构造方法，编译器不再提供默认构造
public class Person {
    public Person(String name) {
    }

    // 需要无参构造必须手动定义
    public Person() {
    }
}

    5. this 关键字¶

    5.1 知识点¶

    this 三个用途：① 指代当前对象（this.name 区分成员变量和局部变量）② this(...) 调用本类其他构造（必须在构造方法第一行）③ 返回当前对象实现链式调用。

    5.2 示例¶

    public class Person {
    private String name;

    // 区分成员变量和局部变量
    public void setName(String name) {
        this.name = name;  // this.name 是成员变量
    }                      // name 是局部变量

    // 调用其他构造方法
    public Person() {
        this("未知", 0);
    }

    public Person(String name) {
        this(name, 0);
    }

    // 返回当前对象
    public Person build() {
        return this;
    }
}

    5.3 链式调用¶

    public class Person {
    private String name;
    private int age;

    public Person setName(String name) {
        this.name = name;
        return this;  // 返回当前对象
    }

    public Person setAge(int age) {
        this.age = age;
        return this;
    }
}

// 使用
Person p = new Person()
    .setName("张三")
    .setAge(25);

    6. 代码块¶

    6.1 知识点¶

    执行顺序 ⭐⭐⭐⭐（必考）：

    类加载时：静态代码块（只执行一次，按书写顺序）
每次 new：实例代码块 → 构造方法（按书写顺序）

    口诀：静态优先、父类优先、代码块优先于构造。

    6.2 示例：代码块类型¶

    public class Person {
    // 1. 静态代码块（类加载时执行，只执行一次）
    static {
        System.out.println("静态代码块");
    }

    // 2. 实例代码块（创建对象时执行）
    {
        System.out.println("实例代码块");
    }

    // 3. 构造代码块（构造方法中）
    public Person() {
        System.out.println("构造方法");
    }
}

// 执行顺序：
// 静态代码块 → 实例代码块 → 构造方法

    6.3 执行顺序¶

    public class Test {
    static {
        System.out.println("1. 静态代码块");
    }

    {
        System.out.println("2. 实例代码块");
    }

    public Test() {
        System.out.println("3. 构造方法");
    }

    public static void main(String[] args) {
        System.out.println("4. main 方法");
        new Test();
        new Test();
    }
}

// 输出：
// 1. 静态代码块（只执行一次）
// 4. main 方法
// 2. 实例代码块
// 3. 构造方法
// 2. 实例代码块
// 3. 构造方法

    7. 经典示例¶

    7.1 学生类¶

    public class Student {
    // 成员变量
    private String id;
    private String name;
    private int age;
    private double score;

    // 静态变量
    private static int count = 0;

    // 构造方法
    public Student() {
        count++;
    }

    public Student(String id, String name, int age, double score) {
        this.id = id;
        this.name = name;
        this.age = age;
        this.score = score;
        count++;
    }

    // getter/setter
    public String getId() { return id; }
    public void setId(String id) { this.id = id; }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }

    public double getScore() { return score; }
    public void setScore(double score) { this.score = score; }

    // 成员方法
    public void study() {
        System.out.println(name + " 正在学习");
    }

    public void showInfo() {
        System.out.println("学号：" + id);
        System.out.println("姓名：" + name);
        System.out.println("年龄：" + age);
        System.out.println("分数：" + score);
    }

    // 静态方法
    public static int getCount() {
        return count;
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Student s1 = new Student("001", "张三", 20, 95.5);
        Student s2 = new Student("002", "李四", 21, 88.0);

        s1.showInfo();
        s2.showInfo();

        System.out.println("学生总数：" + Student.getCount());
    }
}

    7.2 矩形类¶

    public class Rectangle {
    private double width;
    private double height;

    public Rectangle() {
    }

    public Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    public double getArea() {
        return width * height;
    }

    public double getPerimeter() {
        return 2 * (width + height);
    }
}

// 使用
Rectangle rect = new Rectangle(5, 10);
System.out.println("面积：" + rect.getArea());  // 50
System.out.println("周长：" + rect.getPerimeter());  // 30

    public class Demo {

    参考答案¶

    // 练习 1 + 练习 2
public class BankAccount {
    private String name;      // 私有字段，封装
    private double balance;

    public BankAccount(String name, double balance) {
        this.name = name;        // this 区分成员变量与参数
        this.balance = balance;
    }

    // 练习 2：返回 this，支持链式调用
    public BankAccount deposit(double amount) {
        if (amount <= 0) {
            System.out.println("存款金额必须大于 0");
            return this;
        }
        balance += amount;
        return this;
    }

    public void withdraw(double amount) {
        if (amount > balance) {   // 余额不足校验
            System.out.println("余额不足，当前余额：" + balance);
            return;
        }
        balance -= amount;
    }

    public double getBalance() {
        return balance;
    }

    public BankAccount setName(String name) {
        this.name = name;
        return this;
    }
}

// 使用示例
// BankAccount acc = new BankAccount("张三", 100);
// acc.setName("李四").deposit(100);  // 链式调用
// acc.withdraw(500);                 // 余额不足

// 练习 3 答案：
// 静态代码块（类加载时执行，仅一次）
// main 开始
// 实例代码块（第一次 new）
// 构造方法
// 实例代码块（第二次 new）
// 构造方法
// 规律：静态代码块最先且只执行一次；每次 new 都是 实例代码块 → 构造方法

    9. 本章小结¶

    核心知识点¶

    ✅ 类的定义：成员变量、构造方法、成员方法
    ✅ 对象创建：new 关键字、访问成员
    ✅ 构造方法：无参/有参、重载、默认构造
    ✅ this 关键字：区分变量、调用构造、返回当前对象
    ✅ 代码块：静态、实例、构造

    最佳实践¶

    1. 成员变量私有化：使用 getter/setter 访问
    2. 提供无参构造：方便框架使用
    3. 构造方法调用：使用 this() 减少重复代码
    4. 静态变量计数：跟踪对象创建数量
    5. 链式调用：返回 this 实现流畅 API
