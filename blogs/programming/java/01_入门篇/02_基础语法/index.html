    1. 变量与常量¶

    1.1 知识点¶

    变量（Variable）：内存中一块有名字的存储空间，用于保存程序运行期间需要使用的数据。理解变量要记住三要素：类型（决定占多少内存、能做什么运算）、名字（访问入口）、值（存储的内容）。

    与 C++ 对比：Java 是静态强类型语言——每个变量必须先声明类型，且类型不匹配直接编译报错（C++ 中 int 和 double 混用往往只是警告）。Java 没有 unsigned 类型，也没有 C++ 的 auto 推导（Java 10 才引入受限的 var）。

    1.2 变量定义¶

    // 语法：数据类型 变量名 = 值;
int age = 25;
String name = "张三";
double salary = 50000.50;
boolean isStudent = false;

// 先声明后赋值
int count;
count = 10;

// 多个同类型变量
int a = 1, b = 2, c = 3;

    1.3 命名规则¶

    // ✅ 正确的命名
int studentAge;
String userName;
double totalAmount;

// ❌ 错误的命名
int 1stPlace;      // 不能以数字开头
String user-name;  // 不能有连字符
int class;         // 不能使用关键字

    1.4 常量¶

    // 使用 final 关键字
final double PI = 3.14159;
final int MAX_SIZE = 100;

// 常量命名规范：全大写，下划线分隔
final String DEFAULT_NAME = "Unknown";

// 常量一旦赋值不能修改
// PI = 3.14;  // ❌ 编译错误

    2. 数据类型¶

    2.1 知识点¶

    八大基本类型速查表见下。核心记忆：整数字面量默认 int、小数字面量默认 double；金额计算必须 BigDecimal；成员变量有默认值、局部变量没有。

    2.2 八大基本数据类型¶

    类型 关键字 大小 范围 默认值
    字节型 byte 8 位 -128 ~ 127 0
    短整型 short 16 位 -32768 ~ 32767 0
    整型 int 32 位 -2³¹ ~ 2³¹-1 0
    长整型 long 64 位 -2⁶³ ~ 2⁶³-1 0L
    浮点型 float 32 位 3.4E-38 ~ 3.4E38 0.0f
    双精度 double 64 位 4.9E-324 ~ 1.8E308 0.0d
    字符型 char 16 位 '\u0000' ~ '\uffff' '\u0000'
    布尔型 boolean - true/false false

    2.3 示例¶

    // 整型
byte b = 127;
short s = 32767;
int i = 2147483647;
long l = 9223372036854775807L;  // 必须加 L

// 浮点型
float f = 3.14f;    // 必须加 f/F
double d = 3.14159;

// 字符型
char c1 = 'A';
char c2 = '\u0041';  // Unicode

// 布尔型
boolean flag = true;

    ⚠️ 字面量陷阱（高频考点）：

    // 1. 整数字面量默认是 int，超出 int 范围必须加 L
long l1 = 2147483648L;   // ✅
// long l2 = 2147483648; // ❌ 编译错误：字面量本身已超出 int 范围

// 2. 小数字面量默认是 double，赋给 float 必须加 f
float f1 = 3.14f;        // ✅
// float f2 = 3.14;      // ❌ 编译错误：double 不能隐式转 float

// 3. 整数溢出：int 最大 2147483647，加 1 直接绕到最小值（不报错！）
int max = Integer.MAX_VALUE;  // 2147483647
System.out.println(max + 1);  // -2147483648 ⚠️

// 4. 浮点数精度问题：double 用二进制表示十进制小数有误差
System.out.println(0.1 + 0.2);          // 0.30000000000000004 ⚠️
System.out.println(1.0 - 0.9);          // 0.09999999999999998 ⚠️
// ⭐ 涉及金额计算必须用 BigDecimal（见包装类/工具类章节），绝不用 double

    ⭐ 默认值规则（考点）：

    • 成员变量（类里的字段）有默认值：数值 0、boolean false、引用 null
    • 局部变量（方法里的变量）没有默认值，不初始化直接使用会编译错误（与 C++ 局部变量是"不确定的垃圾值"不同，Java 直接拒绝编译，更安全）

    2.4 引用数据类型¶

    // 类
String name = "Java";
Person person = new Person();

// 数组
int[] numbers = new int[10];

// 接口
List<String> list = new ArrayList<>();

    2.5 类型转换¶

    类型转换：把一种数据类型的值转换为另一种类型。Java 分两种：自动转换（小→大，安全）和强制转换（大→小，可能丢精度或溢出）。

    与 C++ 对比：Java 没有 C++ 的 static_cast/reinterpret_cast 那套，强制转换统一用 (类型)值。但 Java 对数值转换的规则更严格——byte/short/char 参与运算会先提升为 int。

    ⭐ 自动转换的提升规则（考点）：

    // byte/short/char 参与算术运算，结果自动提升为 int
byte a = 1, b = 2;
// byte c = a + b;   // ❌ 编译错误：a+b 是 int 类型
byte c = (byte)(a + b);  // ✅ 需要强转

// char 本质是整数（Unicode 码点），可以参与运算
char ch = 'A';
System.out.println(ch + 1);   // 66（提升为 int 运算）
System.out.println((char)(ch + 1));  // B

    自动类型转换（隐式）¶

    // 小范围 → 大范围
int i = 100;
long l = i;      // int → long
double d = l;    // long → double

// 表达式自动提升
int a = 10;
double b = 3.0;
double result = a + b;  // int 自动转为 double

    强制类型转换（显式）¶

    // 大范围 → 小范围
double d = 3.14;
int i = (int) d;  // 3（丢失小数部分）

long l = 100L;
int j = (int) l;

// 注意精度丢失
int x = 1000;
byte y = (byte) x;  // -24（超出 byte 范围）

    String 与其他类型转换¶

    // 其他类型 → String
int num = 123;
String s1 = String.valueOf(num);
String s2 = num + "";

// String → 其他类型
String str = "123";
int i = Integer.parseInt(str);
double d = Double.parseDouble(str);
long l = Long.parseLong(str);
boolean b = Boolean.parseBoolean(str);

    3. 运算符¶

    3.1 知识点¶

    • 整数除法截断小数：10 / 3 == 3
    • ++i 先加后用，i++ 先用后加
    • &&/|| 短路，&/| 非短路
    • 三元运算符：条件 ? 值1 : 值2

    3.2 示例：算术运算符¶

    int a = 10, b = 3;

// 基本运算
int sum = a + b;      // 13
int diff = a - b;     // 7
int product = a * b;  // 30
int quotient = a / b; // 3（整数除法）
int remainder = a % b; // 1（取模）

// 自增自减
int x = 5;
x++;  // 6
++x;  // 7

// 前缀 vs 后缀
int m = 5;
int n = ++m;  // n=6, m=6（先加后赋值）
int p = m++;  // p=6, m=7（先赋值后加）

    3.3 关系运算符¶

    int a = 10, b = 5;

boolean r1 = a == b;   // false
boolean r2 = a != b;   // true
boolean r3 = a > b;    // true
boolean r4 = a < b;    // false

    3.4 逻辑运算符¶

    boolean a = true, b = false;

boolean r1 = a && b;   // false（逻辑与）
boolean r2 = a || b;   // true（逻辑或）
boolean r3 = !a;       // false（逻辑非）

// 短路特性
int x = 0;
if (false && (x = 5) > 0) {
    // 不会执行
}
System.out.println(x);  // 0（右边未执行）

    ⭐ 短路 vs 非短路（考点）：

    • && / ||：短路——左边能确定结果时，右边不执行（常用，可防止空指针）
    • & / |：非短路——两边都执行（位运算也用这两个符号，操作数是整数时是位运算）
    // 短路的实际应用：防 NullPointerException
String s = null;
if (s != null && s.length() > 0) { ... }  // ✅ s==null 时右边不执行
// if (s != null & s.length() > 0) { ... }  // ❌ 右边仍会执行 → NPE

    3.5 三元运算符¶

    // 语法：条件？值 1 : 值 2
int age = 20;
String status = age >= 18 ? "成年" : "未成年";

// 嵌套
int score = 85;
String grade = score >= 90 ? "A" : 
               score >= 80 ? "B" : "C";

// 求最大值
int a = 10, b = 20;
int max = a > b ? a : b;

    4. 流程控制¶

    4.1 知识点¶

    • 三种循环选择：知道次数用 for，不知道次数用 while，至少执行一次用 do-while
    • break 跳出整个循环，continue 跳过本次迭代
    • switch 不写 break 会穿透到下一个 case

    4.2 示例：if-else 语句¶

    int score = 85;

// 简单 if
if (score >= 60) {
    System.out.println("及格");
}

// if-else
if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}

// if-else if-else
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");
} else if (score >= 70) {
    System.out.println("中等");
} else {
    System.out.println("不及格");
}

    4.3 switch 语句¶

    switch：根据表达式的值跳转到匹配的 case 分支执行。

    ⚠️ 穿透现象（case fall-through，必考）：每个 case 结尾如果不写 break，会继续执行下一个 case 的代码，直到遇到 break 或 switch 结束。这既是易错点，也是可以刻意利用的特性。

    // ❌ 经典错误：忘写 break
int day = 1;
switch (day) {
    case 1:
        System.out.println("星期一");
        // 忘写 break → 穿透！
    case 2:
        System.out.println("星期二");
        break;
}
// 输出：星期一 换行 星期二（两个都打印了！）

// ✅ 刻意利用穿透：合并多个 case
int month = 3;
switch (month) {
    case 3: case 4: case 5:
        System.out.println("春季");
        break;
    case 6: case 7: case 8:
        System.out.println("夏季");
        break;
}

    ⭐ switch 支持的类型（考点）：byte/short/char/int、它们的包装类、String（Java 7+）、枚举。不支持 long、float、double、boolean。

    int day = 3;
String dayName;

switch (day) {
    case 1:
        dayName = "星期一";
        break;
    case 2:
        dayName = "星期二";
        break;
    case 3:
        dayName = "星期三";
        break;
    default:
        dayName = "周末";
        break;
}

// Java 14+ 新语法
String dayName2 = switch (day) {
    case 1 -> "星期一";
    case 2 -> "星期二";
    case 3 -> "星期三";
    default -> "周末";
};

    4.4 for 循环¶

    // 基本 for 循环
for (int i = 0; i < 5; i++) {
    System.out.println(i);  // 0, 1, 2, 3, 4
}

// 增强 for 循环（for-each）
int[] numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    System.out.println(num);
}

// 嵌套循环（九九乘法表）
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "*" + i + "=" + (i*j) + " ");
    }
    System.out.println();
}

    4.5 while 循环¶

    // while 循环
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}

// do-while 循环（至少执行一次）
int j = 0;
do {
    System.out.println(j);
    j++;
} while (j < 5);

    4.6 跳转语句¶

    // break - 跳出循环
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // 跳出整个循环
    }
    System.out.println(i);  // 0, 1, 2, 3, 4
}

// continue - 跳过本次
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;  // 跳过偶数
    }
    System.out.println(i);  // 1, 3, 5, 7, 9
}

    5.2 判断素数¶

    public static boolean isPrime(int n) {
    if (n <= 1) return false;
    for (int i = 2; i <= Math.sqrt(n); i++) {
        if (n % i == 0) return false;
    }
    return true;
}

    5.3 斐波那契数列¶

    int a = 1, b = 1;
System.out.print(a + " " + b + " ");
for (int i = 3; i <= 20; i++) {
    int c = a + b;
    System.out.print(c + " ");
    a = b;
    b = c;
}

    5.4 水仙花数¶

    for (int i = 100; i <= 999; i++) {
    int hundreds = i / 100;
    int tens = i / 10 % 10;
    int units = i % 10;

    if (hundreds*hundreds*hundreds + 
        tens*tens*tens + 
        units*units*units == i) {
        System.out.println(i);
    }
}
// 输出：153, 370, 371, 407

int y = 0;

double result2 = (double) a / b;  // ✅ 3.333...

    7. 练习题¶

    1. 闰年判断：输入年份，判断是否为闰年（能被 4 整除且不能被 100 整除，或能被 400 整除）。
    2. 九九乘法表：用嵌套循环打印九九乘法表。
    3. 判断输出：说出下面代码的输出并解释原因。
    int a = 5;
int b = a++;
int c = ++a;
System.out.println(a + ", " + b + ", " + c);

    参考答案¶

    // 练习 1
public class LeapYear {
    public static void main(String[] args) {
        int year = 2024;
        boolean isLeap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
        System.out.println(year + (isLeap ? " 是闰年" : " 不是闰年"));  // 是闰年
    }
}

// 练习 2
public class MultiTable {
    public static void main(String[] args) {
        for (int i = 1; i <= 9; i++) {          // 行
            for (int j = 1; j <= i; j++) {      // 列：只打印到下三角
                System.out.printf("%d×%d=%d\t", j, i, i * j);
            }
            System.out.println();               // 换行
        }
    }
}

// 练习 3 答案：7, 5, 7
// a++ 后置自增：b 先拿到 a 的旧值 5，然后 a 变成 6
// ++a 前置自增：a 先自增到 7，c 拿到 7
