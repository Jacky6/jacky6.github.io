    1. 方法概述¶

    1.1 知识点¶

    方法（Method）是执行特定功能的代码块，可以重复使用。

    作用：

    • ✅ 代码复用：避免重复代码
    • ✅ 模块化：将复杂问题分解
    • ✅ 可维护：修改一处即可
    // 方法定义
public static int add(int a, int b) {
    return a + b;
}

// 方法调用
int result = add(10, 20);

    1.2 方法的组成¶

    修饰符  返回值类型  方法名 (参数列表)  throws 异常
 public   static    int    add(int a, int b)  throws Exception
   │       │         │           │              │
   │       │         │           │              └─ 异常声明
   │       │         │           └─ 形式参数
   │       │         └─ 方法名
   │       └─ 返回值类型
   └─ 修饰符

方法体：
{
    return a + b;  // 返回语句
}

    2. 方法定义和调用¶

    知识点：

    • 方法定义四要素：修饰符、返回值类型、方法名、参数列表（如 public static int add(int a, int b)）
    • 按"有无参数 × 有无返回值"共四种组合：无参无返回、有参无返回、有参有返回、无参有返回
    • void 方法无需 return 语句；有返回值的方法必须保证所有分支都有 return

    2.1 无参无返回¶

    public static void sayHello() {
    System.out.println("Hello");
}

// 调用
sayHello();

    2.2 有参无返回¶

    public static void printName(String name) {
    System.out.println("Name: " + name);
}

// 调用
printName("张三");

    2.3 有参有返回¶

    public static int add(int a, int b) {
    return a + b;
}

// 调用
int result = add(10, 20);
System.out.println(result);  // 30

    2.4 无参有返回¶

    public static int getRandom() {
    return (int)(Math.random() * 100);
}

// 调用
int num = getRandom();

    3. 参数传递¶

    3.1 知识点¶

    Java 只有值传递（全章最重要结论，见下方详解）。可变参数 T... 本质是数组，必须放在参数列表最后。

    3.2 示例：值传递¶

    ⭐ Java 只有值传递（必考结论）：调用方法时，实参把值的副本传给形参—— - 基本类型：副本是数值本身，方法内改形参不影响实参 - 引用类型：副本是引用的拷贝（两个引用指向同一个对象），方法内改不了实参指向，但能通过引用改对象内容

    与 C++ 对比：C++ 有 & 引用传递（形参是实参别名）和指针传值；Java 没有引用传递，"传对象"本质是传引用的值。很多教材说"引用传递"是不准确的。

    // 基本类型：值传递
public static void changeValue(int x) {
    x = 100;
}

int a = 10;
changeValue(a);
System.out.println(a);  // 10（不变）

// 引用类型：传递引用的副本
public static void changeArray(int[] arr) {
    arr[0] = 100;    // ✅ 通过引用副本修改了原数组内容
}

public static void reassignArray(int[] arr) {
    arr = new int[]{9, 9, 9};  // ❌ 只改了形参副本的指向，原数组不受影响
}

int[] nums = {1, 2, 3};
changeArray(nums);
System.out.println(nums[0]);  // 100（内容被改）

reassignArray(nums);
System.out.println(nums[0]);  // 100（重新赋值没生效，还是原数组）

    3.3 可变参数¶

    // 可变参数语法
public static int sum(int... numbers) {
    int total = 0;
    for (int num : numbers) {
        total += num;
    }
    return total;
}

// 调用
sum(1);           // 1
sum(1, 2, 3);     // 6
sum(1, 2, 3, 4);  // 10

// 可变参数必须是最后一个参数
public static void print(String prefix, int... numbers) {
    // ✅ 正确
}

public static void print(int... numbers, String prefix) {
    // ❌ 错误：可变参数必须在最后
}

    4. 方法重载¶

    4.1 知识点¶

    重载（Overload）：同一类中，方法名相同，参数列表不同。

    重载成立的三种方式：参数个数不同、参数类型不同、参数顺序不同。仅返回值不同不是重载（编译错误）。

    4.2 示例：重载定义¶

    方法签名（Signature）：方法名 + 参数列表（类型、个数、顺序）。返回值不属于签名——这就是"只有返回值不同不构成重载"的根本原因。

    与 C++ 对比：与 C++ 重载规则一致。注意 Java 的 println 就是重载的典型例子——同一个名字有 10 种参数类型版本。

    public class Calculator {
    // 两个整数相加
    public int add(int a, int b) {
        return a + b;
    }

    // 三个整数相加
    public int add(int a, int b, int c) {
        return a + b + c;
    }

    // 两个浮点数相加
    public double add(double a, double b) {
        return a + b;
    }

    // 字符串拼接
    public String add(String a, String b) {
        return a + b;
    }
}

// 调用
Calculator calc = new Calculator();
calc.add(1, 2);        // 调用第一个
calc.add(1, 2, 3);     // 调用第二个
calc.add(1.5, 2.5);    // 调用第三个
calc.add("Hello", "World");  // 调用第四个

    4.3 重载规则¶

    public class Test {
    // ✅ 重载：参数个数不同
    public void method(int a) {}
    public void method(int a, int b) {}

    // ✅ 重载：参数类型不同
    public void method(int a) {}
    public void method(double a) {}

    // ✅ 重载：参数顺序不同
    public void method(int a, double b) {}
    public void method(double b, int a) {}

    // ❌ 不是重载：仅返回值不同
    public int method1(int a) {}
    public double method1(int a) {}  // 编译错误

    // ❌ 不是重载：仅修饰符不同
    public void method2(int a) {}
    private void method2(int a) {}  // 编译错误
}

    5. 递归¶

    5.1 知识点¶

    递归：方法调用自身。三要素：① 明确的终止条件 ② 终止时的处理 ③ 递推公式。

    ⚠️ 递归 vs 循环：递归代码简洁但每层调用占栈帧，深度过大会 StackOverflowError；循环性能更好。简单递推（阶乘、斐波那契）优先循环，树形结构遍历天然适合递归。

    5.2 示例：递归¶

    // 1. 求阶乘
public static int factorial(int n) {
    if (n == 1) {  // 终止条件
        return 1;
    }
    return n * factorial(n - 1);  // 递归公式
}

// 2. 斐波那契数列
public static int fibonacci(int n) {
    if (n == 1 || n == 2) {
        return 1;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}

// 3. 递归求和
public static int sum(int n) {
    if (n == 1) {
        return 1;
    }
    return n + sum(n - 1);
}

// 4. 递归遍历目录
public static void listFiles(File dir) {
    File[] files = dir.listFiles();
    if (files != null) {
        for (File file : files) {
            if (file.isDirectory()) {
                listFiles(file);  // 递归调用
            } else {
                System.out.println(file.getAbsolutePath());
            }
        }
    }
}

    5.3 递归 vs 循环¶

    // 递归实现
public static int factorialRecursive(int n) {
    if (n == 1) return 1;
    return n * factorialRecursive(n - 1);
}

// 循环实现
public static int factorialIterative(int n) {
    int result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}

// 对比：
// 递归：代码简洁，但可能栈溢出
// 循环：代码略长，但性能更好

    6. 方法设计原则¶

    知识点：

    • 单一职责：一个方法只做一件事，避免验证、保存、发邮件混在一起
    • 命名见名知义：动词开头（isValid、calculateTotal、getUserName），避免 check、doSomething 等含糊名字
    • 控制方法长度：超过 50 行考虑拆分成多个小方法组合调用

    6.1 单一职责¶

    // ❌ 不好：一个方法做多件事
public void processUser(String name, int age, String email) {
    // 验证
    if (name == null || age < 0) {
        throw new IllegalArgumentException();
    }
    // 保存数据库
    // 发送邮件
}

// ✅ 好：每个方法做一件事
public void validateUser(String name, int age) {
    if (name == null || age < 0) {
        throw new IllegalArgumentException();
    }
}

public void saveUser(User user) {
    // 保存数据库
}

public void sendEmail(String email) {
    // 发送邮件
}

    6.2 方法命名¶

    // ✅ 好的命名
public boolean isValid() {}
public void calculateTotal() {}
public String getUserName() {}
public void setAge(int age) {}

// ❌ 不好的命名
public boolean check() {}  // 检查什么？
public void doSomething() {}  // 做什么？
public int get() {}  // 获取什么？

    6.3 方法长度¶

    // ❌ 不好：方法太长（超过 50 行）
public void process() {
    // 100 行代码...
}

// ✅ 好：拆分成多个小方法
public void process() {
    validate();
    transform();
    save();
}

private void validate() {}
private void transform() {}
private void save() {}

    7. 经典示例¶

    7.1 数学工具类¶

    public class MathUtils {

    // 判断素数
    public static boolean isPrime(int n) {
        if (n <= 1) return false;
        for (int i = 2; i <= Math.sqrt(n); i++) {
            if (n % i == 0) return false;
        }
        return true;
    }

    // 最大公约数
    public static int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    // 最小公倍数
    public static int lcm(int a, int b) {
        return a * b / gcd(a, b);
    }

    // 判断闰年
    public static boolean isLeapYear(int year) {
        return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
    }
}

    7.2 数组工具类¶

    public class ArrayUtils {

    // 求最大值
    public static int max(int[] arr) {
        int max = arr[0];
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > max) {
                max = arr[i];
            }
        }
        return max;
    }

    // 求平均值
    public static double average(int[] arr) {
        int sum = 0;
        for (int num : arr) {
            sum += num;
        }
        return (double) sum / arr.length;
    }

    // 数组反转
    public static void reverse(int[] arr) {
        for (int i = 0, j = arr.length - 1; i < j; i++, j--) {
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
    }
}

    8. 练习题¶

    1. 可变参数求和：写一个方法 sum(int... numbers) 返回所有参数之和，并分别用 0 个、2 个、4 个参数调用验证。
    2. 递归求阶乘：用递归实现 factorial(int n)，并说明递归终止条件。
    3. 判断输出：说出下面代码的输出并解释原因。
    public static void swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

public static void changeFirst(int[] arr) {
    arr[0] = 100;
}

int x = 1, y = 2;
swap(x, y);
System.out.println(x + ", " + y);  // ?

int[] nums = {1, 2, 3};
changeFirst(nums);
System.out.println(nums[0]);  // ?

    参考答案¶

    // 练习 1
public static int sum(int... numbers) {
    int total = 0;
    for (int num : numbers) {  // 可变参数当作数组遍历
        total += num;
    }
    return total;
}
// System.out.println(sum());            // 0
// System.out.println(sum(1, 2));        // 3
// System.out.println(sum(1, 2, 3, 4));  // 10

// 练习 2
public static int factorial(int n) {
    if (n < 0) {
        throw new IllegalArgumentException("n 不能为负数");
    }
    if (n == 0 || n == 1) {  // 终止条件：0! = 1! = 1
        return 1;
    }
    return n * factorial(n - 1);  // 递归公式：n! = n * (n-1)!
}
// factorial(5) → 120

// 练习 3 答案：
// swap 后输出 → 1, 2：基本类型是值传递，swap 内交换的是副本，不影响 x、y
// changeFirst 后输出 → 100：数组是引用类型，传递的是地址副本，
// 方法内通过该地址修改了原数组的元素

    9. 本章小结¶

    核心知识点¶

    ✅ 方法定义：修饰符、返回值、参数、方法体
    ✅ 参数传递：值传递、可变参数
    ✅ 方法重载：方法名相同，参数列表不同
    ✅ 递归：方法调用自身，注意终止条件
    ✅ 设计原则：单一职责、合理命名、控制长度

    最佳实践¶

    1. 方法要短小：一个方法只做一件事
    2. 命名要清晰：见名知意
    3. 参数要少：不超过 5 个参数
    4. 避免副作用：方法不应修改外部状态
    5. 优先使用静态方法：工具类方法
