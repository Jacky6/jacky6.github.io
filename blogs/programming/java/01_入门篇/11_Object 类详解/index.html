    1. Object 类概述¶

    知识点： - Object 是所有类的根父类，任何类都直接/间接继承它，数组也不例外 - ⭐ 任何对象都能传给 Object 类型的参数；所有类都继承 Object 的方法（equals/hashCode/toString 等） - ⚠️ getClass/wait/notify 是 final 不能重写；finalize 已废弃，不要用

    1.1 什么是 Object 类¶

    Object 是 Java 所有类的根父类。任何类都直接/间接继承自它。

    // 以下两行等价
public class Person { }
public class Person extends Object { }

    意义：

    • ✅ 任何对象都能传给 Object 类型的参数
    • ✅ 所有类都拥有 Object 的方法（equals、hashCode、toString 等）
    • ✅ 这是 Java 统一的基石
    Object obj = "字符串";      // String 是 Object 子类
obj = new ArrayList<>();   // ArrayList 也是 Object 子类
obj = new int[10];         // 数组也是 Object

    1.2 Object 的方法一览¶

    方法 作用 是否需要重写
    equals(Object) 判断对象是否相等 ⭐ 经常
    hashCode() 返回哈希码 ⭐ 与 equals 一起
    toString() 转字符串表示 ⭐ 经常
    clone() 克隆对象 偶尔
    getClass() 获取运行时类型 不重写（final）
    wait()/notify()/notifyAll() 线程通信 不重写（final）
    finalize() 回收前回调（已废弃） 不要用

    2. equals() 方法 ⭐⭐⭐¶

    知识点： - ⭐ Object 默认 equals 就是 ==，比较内存地址；String 等类重写后比较内容 - ⭐ 重写必须满足五性：自反、对称、传递、一致、非空（x.equals(null) == false） - 标准模板：先判同一引用，再判 null/类型，最后转型逐字段比较 - ⚠️ 对象字段用 Objects.equals(a, b) 防 null，不要用 a.equals(b)

    2.1 默认行为¶

    public boolean equals(Object obj) {
    return (this == obj);   // 默认比较引用地址
}

    默认 equals 就是 ==，比较的是内存地址。

    String s1 = new String("abc");
String s2 = new String("abc");

System.out.println(s1 == s2);       // false（不同对象）
System.out.println(s1.equals(s2));  // true（String 重写了 equals，比较内容）

    2.2 为什么 String 能比较内容¶

    因为 String 重写了 equals：

    // String 类的源码（简化）
public boolean equals(Object anObject) {
    if (this == anObject) return true;
    if (anObject instanceof String aString) {
        return value.equals(aString.value);  // 逐字符比较内容
    }
    return false;
}

    2.3 重写 equals 的规则¶

    重写必须满足五个条件（自反、对称、传递、一致、非空）：

    性质 说明
    自反性 x.equals(x) == true
    对称性 x.equals(y) == y.equals(x)
    传递性 x.equals(y) && y.equals(z) → x.equals(z)
    一致性 多次调用结果一致
    非空性 x.equals(null) == false

    2.4 标准重写模板¶

    public class Person {
    private String name;
    private int age;

    // 构造方法省略

    @Override
    public boolean equals(Object o) {
        // 1. 同一引用，直接 true
        if (this == o) return true;

        // 2. null 或类型不同，false
        if (o == null || getClass() != o.getClass()) return false;

        // 3. 转型后逐字段比较
        Person person = (Person) o;
        return age == person.age 
            && Objects.equals(name, person.name);
    }
}

    关键点：

    • 用 Objects.equals(a, b) 而不是 a.equals(b)，避免空指针
    • 基本类型用 ==，对象类型用 Objects.equals()
    • 用 getClass() 或 instanceof 判断类型

    3. hashCode() 方法 ⭐⭐⭐¶

    知识点： - 哈希码是对象的整数"指纹"，用于 HashMap/HashSet 快速定位 - ⭐ 核心约定：equals 相等 → hashCode 必须相等；hashCode 相等 → equals 不一定相等（哈希冲突） - ⭐ 铁律：重写 equals 必须重写 hashCode，否则 HashMap/HashSet 判重失效 - 最简重写写法：Objects.hash(字段1, 字段2, ...)

    3.1 什么是哈希码¶

    哈希码（hashCode）是对象的整数"指纹"，用于哈希集合（HashMap、HashSet）快速定位。

    Object obj = new Object();
System.out.println(obj.hashCode());  // 例如 366712642

    3.2 核心约定 ⭐⭐⭐¶

    约定 说明
    1 equals 相等 → hashCode 必须相等
    2 hashCode 相等 → equals 不一定相等（哈希冲突）
    3 equals 不等 → hashCode 最好不等（性能）

    铁律：重写 equals 必须重写 hashCode，否则放入 HashMap/HashSet 会出 bug。

    3.3 违反约定的后果¶

    public class User {
    private String name;

    @Override
    public boolean equals(Object o) {
        // 只重写 equals，忘记 hashCode
        if (this == o) return true;
        if (!(o instanceof User)) return false;
        return Objects.equals(name, ((User) o).name);
    }
}

Set<User> set = new HashSet<>();
set.add(new User("张三"));
System.out.println(set.contains(new User("张三")));  // false！❌

// 原因：HashSet 先按 hashCode 找桶，两个对象 hashCode 不同
//       （默认按内存地址），落在不同桶，根本不会调 equals 比较

    3.4 标准重写模板¶

    public class Person {
    private String name;
    private int age;

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Person person = (Person) o;
        return age == person.age && Objects.equals(name, person.name);
    }

    @Override
    public int hashCode() {
        return Objects.hash(name, age);   // ⭐ 最简洁的写法
    }
}

    IDE（IDEA/Eclipse）可以一键生成 equals + hashCode，实际开发推荐用 IDE 生成。

    4. toString() 方法 ⭐¶

    知识点： - 默认返回"类名@十六进制哈希码"，无实际意义，重写后才能输出有意义的内容 - ⭐ System.out.println(对象) 和字符串拼接会自动调用 toString()

    4.1 默认行为¶

    // Object 默认实现
public String toString() {
    return getClass().getName() + "@" + Integer.toHexString(hashCode());
}
// 输出示例：com.example.Person@15db9742

    4.2 为什么要重写¶

    默认的 类名@哈希 没有实际意义，重写后便于调试和打印。

    public class Person {
    private String name;
    private int age;

    @Override
    public String toString() {
        return "Person{name='" + name + "', age=" + age + "}";
    }
}

Person p = new Person("张三", 25);
System.out.println(p);           // Person{name='张三', age=25}
System.out.println(p.toString()); // 同上（自动调用）

    注意：字符串拼接、println 会自动调用 toString。

    System.out.println("用户：" + p);   // 自动调用 p.toString()

    5. getClass() 方法¶

    知识点： - 返回对象的运行时类型（Class 对象），是反射的入口 - obj.getClass() == Person.class 判断实际类型，比 instanceof 更精确 - ⚠️ getClass 是 final 方法，不能重写

    5.1 获取运行时类型¶

    Person p = new Person();
Class<?> clazz = p.getClass();
System.out.println(clazz.getName());  // com.example.Person

    5.2 常见用途¶

    // 判断实际类型（比 instanceof 更精确）
if (obj.getClass() == Person.class) { }

// 反射（详见 03_进阶特性/02_反射.md）
Object instance = clazz.newInstance();

    getClass 是 final 方法，不能重写。

    6. clone() 方法 ⭐⭐¶

    知识点： - ⭐ 浅拷贝只复制对象本身，引用字段共享同一对象；深拷贝连引用的对象一起复制，完全独立 - ⚠️ 默认 super.clone() 是浅拷贝；类必须实现 Cloneable 接口，否则抛 CloneNotSupportedException - clone 用法繁琐（接口 + 异常处理），实际推荐拷贝构造方法 new Person(old) 或静态工厂

    6.1 浅拷贝 vs 深拷贝 ⭐⭐⭐¶

    浅拷贝：复制对象本身，但引用字段共享同一对象。 深拷贝：复制对象及其引用的所有对象，完全独立。

    原对象 person：name="张三", address=Address@123
├── 浅拷贝：新对象 address 也指向 Address@123（共享）
└── 深拷贝：新对象 address 指向新的 Address@456（独立）

    6.2 浅拷贝示例¶

    public class Address {
    String city;
}

public class Person implements Cloneable {
    private String name;
    private Address address;   // 引用类型

    @Override
    protected Object clone() throws CloneNotSupportedException {
        return super.clone();   // 默认浅拷贝
    }
}

Person p1 = new Person("张三", new Address("北京"));
Person p2 = (Person) p1.clone();

System.out.println(p1 == p2);                   // false（对象不同）
System.out.println(p1.address == p2.address);  // true ⚠️ 共享 address

    6.3 深拷贝示例¶

    public class Person implements Cloneable {
    private String name;
    private Address address;

    @Override
    protected Object clone() throws CloneNotSupportedException {
        Person cloned = (Person) super.clone();
        // 关键：把引用字段也克隆一份
        cloned.address = new Address(this.address.city);
        return cloned;
    }
}

    6.4 clone 的替代方案¶

    clone 用法繁琐（要 Cloneable、要处理异常），实际开发更推荐：

    方案 说明
    拷贝构造方法 new Person(old)
    静态工厂方法 Person.copy(old)
    序列化/反序列化 深拷贝，见 02_核心 API/10_序列化.md 
    // 拷贝构造方法（推荐）
public Person(Person other) {
    this.name = other.name;
    this.address = new Address(other.address.city);  // 深拷贝
}

    7. wait/notify（简介）¶

    知识点： - wait()/notify()/notifyAll() 是线程间通信的方法，定义在 Object 上、所有对象都可调用 - ⚠️ 必须在 synchronized 块中调用，否则抛 IllegalMonitorStateException

    这些方法用于线程间通信，详见 03_进阶特性/01_多线程基础.md。

    synchronized (lock) {
    lock.wait();     // 当前线程等待
    lock.notify();   // 唤醒一个等待线程
}

    必须在 synchronized 块中调用，否则抛 IllegalMonitorStateException。

    8. Objects 工具类¶

    知识点： - java.util.Objects 提供静态工具方法：isNull/nonNull/requireNonNull 判空 - ⭐ Objects.equals(a, b) 空安全，避免 a 为 null 时 a.equals(b) 抛 NPE - Objects.hash(...) 是生成 hashCode 的标准写法

    java.util.Objects 提供静态工具方法，简化判空和比较。

    import java.util.Objects;

// 判空
Objects.isNull(obj);       // obj == null
Objects.nonNull(obj);      // obj != null
Objects.requireNonNull(obj, "不能为空");  // null 则抛异常

// 比较（防 NPE）
Objects.equals(a, b);      // a、b 可能为 null

// 生成 hashCode
Objects.hash(a, b, c);

    对比：

    // ❌ 传统写法，可能 NPE
if (a.equals(b)) { }

// ✅ Objects 写法，安全
if (Objects.equals(a, b)) { }

    9. 综合示例¶

    import java.util.Objects;

public class Student {
    private String id;
    private String name;
    private int score;

    public Student(String id, String name, int score) {
        this.id = id;
        this.name = name;
        this.score = score;
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Student s = (Student) o;
        return score == s.score
            && Objects.equals(id, s.id)
            && Objects.equals(name, s.name);
    }

    @Override
    public int hashCode() {
        return Objects.hash(id, name, score);
    }

    @Override
    public String toString() {
        return "Student{id='" + id + "', name='" + name + "', score=" + score + "}";
    }
}

// 验证
Student s1 = new Student("001", "张三", 90);
Student s2 = new Student("001", "张三", 90);
System.out.println(s1.equals(s2));            // true
System.out.println(s1.hashCode() == s2.hashCode());  // true
System.out.println(s1);                       // Student{id='001', ...}

    10. 常见面试题¶

    Q1：== 和 equals 的区别？

    == 对基本类型比值，对引用类型比地址。equals 默认也是比地址，但 String/Integer 等重写了它来比内容。

    Q2：为什么重写 equals 必须重写 hashCode？

    HashMap/HashSet 先用 hashCode 定位桶，再用 equals 确认。只重写 equals 会导致逻辑相等的对象落在不同桶，集合判重失效。

    Q3：String 的 equals 为什么安全？

    String 重写了 equals 逐字符比较内容，且 String 不可变，equals 结果稳定。

    Q4：浅拷贝和深拷贝的区别？

    浅拷贝只复制对象本身，引用字段共享；深拷贝连引用的对象一起复制，完全独立。

    2. 验证哈希约定：创建两个 equals 相等的 Book，验证 hashCode 相等。

    11.2 参考答案¶

    // 练习 1
import java.util.Objects;

public class Book {
    private String title;
    private String author;
    private double price;

    public Book(String title, String author, double price) {
        this.title = title;
        this.author = author;
        this.price = price;
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Book book = (Book) o;
        return Double.compare(price, book.price) == 0
            && Objects.equals(title, book.title)
            && Objects.equals(author, book.author);
    }

    @Override
    public int hashCode() {
        return Objects.hash(title, author, price);
    }

    @Override
    public String toString() {
        return "Book{title='" + title + "', author='" + author + "', price=" + price + "}";
    }
}

// 练习 2
Book b1 = new Book("Java 编程", "Bob", 59.0);
Book b2 = new Book("Java 编程", "Bob", 59.0);
System.out.println(b1.equals(b2));                    // true
System.out.println(b1.hashCode() == b2.hashCode());  // true
