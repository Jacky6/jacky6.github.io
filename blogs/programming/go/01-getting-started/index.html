    01 环境搭建与第一个程序¶

    安装 Go、配置开发环境、理解 go mod、写出第一个程序。

    1. 安装 Go¶

    1.1 官方安装包（推荐）¶

    # Linux
wget https://go.dev/dl/go1.23.0.linux-amd64.tar.gz
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.23.0.linux-amd64.tar.gz

# 配置环境变量（写入 ~/.bashrc 或 ~/.zshrc）
export PATH=$PATH:/usr/local/go/bin
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin

source ~/.bashrc
go version

    # Windows：下载 MSI 安装包，一路下一步
# https://go.dev/dl/go1.23.0.windows-amd64.msi

    # macOS
brew install go
# 或官方 pkg 安装包

    1.2 版本管理工具¶

    # 官方多版本管理（推荐）
go install golang.org/dl/go1.22.0@latest
go1.22.0 download
go1.22.0 version

# 第三方工具
brew install gvm        # macOS/Linux

    2. 开发环境配置¶

    2.1 VS Code¶

    # 安装 Go 扩展后，按提示安装工具
go install golang.org/x/tools/gopls@latest
go install github.com/go-delve/delve/cmd/dlv@latest
go install github.com/golangci/golangci-lint/cmd/golangci-lint@latest

    2.2 GoLand¶

    JetBrains 出品，开箱即用，适合大型项目。

    2.3 环境变量一览¶

    变量 作用 默认值
    GOROOT Go 安装目录 /usr/local/go
    GOPATH 工作区（存放下载的依赖与 go install 的二进制） ~/go
    GOPROXY 模块代理 https://proxy.golang.org,direct
    GOPRIVATE 私有仓库，不走代理 -
    GOSUMDB 校验和数据库 sum.golang.org
    GOTOOLCHAIN 工具链自动切换 auto 
    # 国内加速
go env -w GOPROXY=https://goproxy.cn,direct

    3. 第一个程序¶

    mkdir hello && cd hello
go mod init hello

    main.go：

    package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}

    go run main.go        # 编译并运行
go build              # 编译为二进制
./hello               # 运行

    4. 程序结构解析¶

    package main          // 包声明：main 包是程序入口

import "fmt"          // 导入标准库

func main() {         // main 函数：程序从这里开始执行
    fmt.Println("Hello, Go!")
}

    规则：

    • 每个 .go 文件必须以 package 声明开头
    • 可执行程序：必须有 package main + func main()
    • 库：包名任意，供其他包导入使用
    • import 必须使用导入的包，否则编译报错
    • { 必须与函数声明同行，不能另起一行（Go 自动插入分号的规则决定）

    5. go mod 模块管理¶

    go mod init <module-path>   # 初始化模块，如 github.com/user/repo
go mod tidy                 # 添加缺失依赖、删除未用依赖（最常用）
go mod download             # 下载依赖到本地缓存
go mod vendor               # 将依赖复制到 vendor/ 目录
go mod graph                # 打印依赖图
go mod why <pkg>            # 解释为什么需要某个依赖
go get github.com/pkg/errors@v1.0.0  # 添加/升级依赖
go get -u ./...             # 升级所有依赖
go get foo@none             # 降级/移除依赖
go list -m all              # 列出所有依赖版本

    go.mod 文件解析：

    module github.com/user/repo

go 1.23

require (
    github.com/pkg/errors v0.9.1
    golang.org/x/sync v0.8.0
)

    6. 常用命令速查¶

    命令 作用
    go run 编译并立即运行
    go build 编译（检查编译错误）
    go install 编译并安装到 $GOPATH/bin
    go test 运行测试
    go fmt / gofmt 格式化代码
    go vet 静态检查可疑代码
    go doc 查看文档
    go env 查看/设置环境变量
    go clean 清理缓存
    go generate 运行 //go:generate 指令

    7. 交叉编译¶

    Go 的杀手锏：在一台机器上编译出任意平台的二进制。

    CGO_ENABLED=0 GOOS=linux   GOARCH=amd64 go build -o app-linux
CGO_ENABLED=0 GOOS=darwin  GOARCH=arm64 go build -o app-mac
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -o app.exe
    GOOS GOARCH
    linux amd64, arm64, 386, arm
    darwin amd64, arm64
    windows amd64, arm64, 386
    js wasm

    8. 小结¶

    • Go 安装简单，单二进制工具链
    • go mod init → 写代码 → go run，三步起步
    • go mod tidy 是日常最常用命令
    • 交叉编译零成本，部署极简
