    06 结构体与接口¶

    结构体、嵌入、接口的隐式实现、类型断言、空接口。

    1. 结构体¶

    type User struct {
    Name string
    Age  int
}

// 创建方式
u1 := User{"Alice", 30}          // 按顺序（不推荐）
u2 := User{Name: "Bob", Age: 25} // 按字段名（推荐）
u3 := new(User)                  // 返回 *User，字段为零值
var u4 User                      // 零值结构体

// 访问与修改
u2.Age = 26
p := &u2
p.Name = "Bobby"   // 自动解引用

// 结构体是值类型：赋值即拷贝
u5 := u2
u5.Age = 99
fmt.Println(u2.Age)   // 26，不受影响

    1.1 构造函数惯例¶

    Go 没有构造函数，惯用 NewXxx 函数：

    func NewUser(name string, age int) *User {
    return &User{Name: name, Age: age}
}

    1.2 结构体比较与拷贝¶

    // 所有字段都可比较 → 结构体可比较
type Point struct{ X, Y int }
p1, p2 := Point{1, 2}, Point{1, 2}
p1 == p2   // true

// 含 slice/map 字段 → 不可比较
type T struct{ S []int }
// T{} == T{}   // 编译错误

// 深拷贝：结构体赋值是浅拷贝，指针字段仍共享
import "cmp"
b := a   // 浅拷贝

    1.3 标签¶

    type User struct {
    Name string `json:"name" validate:"required"`
    Age  int    `json:"age" xml:"age"`
    Pass string `json:"-"`              // 序列化时忽略
}

    通过反射读取，广泛用于 JSON、ORM、参数校验。

    1.4 内存对齐¶

    // 字段顺序影响内存占用
type Bad struct {
    a bool   // 1 字节 + 7 填充
    b int64  // 8 字节
    c bool   // 1 字节 + 7 填充
}            // 共 24 字节

type Good struct {
    b int64  // 8 字节
    a bool   // 1 字节
    c bool   // 1 字节 + 6 填充
}            // 共 16 字节

    经验：字段按大小降序排列可减少填充（fieldalignment 分析器可检查）。

    2. 嵌入¶

    Go 没有"继承"，用嵌入实现代码复用：

    type Animal struct{ Name string }

func (a Animal) Speak() { fmt.Println(a.Name, "speaks") }

type Dog struct {
    Animal          // 嵌入（不是字段名，是类型名）
    Breed string
}

d := Dog{Animal{"Rex"}, "Lab"}
d.Name        // 提升字段：等价 d.Animal.Name
d.Speak()     // 提升方法：等价 d.Animal.Speak()

    2.1 嵌入不是继承¶

    type Base struct{}
func (b Base) Who() string { return "Base" }
func (b Base) Hello()      { fmt.Println("Hello from", b.Who()) }

type Child struct{ Base }
func (c Child) Who() string { return "Child" }

c := Child{}
c.Hello()   // "Hello from Base"  ← 不是 "Child"！
// Hello 的接收者是 Base，方法内调用的 b.Who() 绑定到 Base
// Go 没有虚函数表，没有动态派发（除接口外）

    2.2 嵌入接口¶

    type Reader interface{ Read(p []byte) (n int, err error) }

// 结构体嵌入接口：获得接口所有方法（默认 nil panic，需覆盖）
type LogReader struct {
    Reader   // 嵌入接口
}

    3. 接口¶

    接口是方法签名的集合。Go 的接口是隐式实现（duck typing）：

    type Speaker interface {
    Speak() string
}

type Dog struct{}
func (d Dog) Speak() string { return "Woof" }

type Cat struct{}
func (c Cat) Speak() string { return "Meow" }

// Dog、Cat 都实现了 Speaker，无需 implements 声明
func MakeItSpeak(s Speaker) {
    fmt.Println(s.Speak())
}

MakeItSpeak(Dog{})   // Woof
MakeItSpeak(Cat{})   // Meow

    3.1 接口值的结构¶

    // 接口变量 = (动态类型, 动态值) 二元组
var s Speaker
s = Dog{}        // (Dog, Dog{})
s = Cat{}        // (Cat, Cat{})

// nil 接口 vs 含 nil 指针的接口（经典陷阱！）
type MyErr struct{}
func (e *MyErr) Error() string { return "err" }

var err *MyErr = nil
var e error = err
fmt.Println(e == nil)   // false！接口有类型信息 (*MyErr, nil)

    3.2 标准接口¶

    // fmt 包
type Stringer interface { String() string }
type GoStringer interface { GoString() string }

// error
type error interface { Error() string }

// sort
type sort.Interface interface {
    Len() int
    Less(i, j int) bool
    Swap(i, j int)
}

// io
type Reader interface { Read(p []byte) (n int, err error) }
type Writer interface { Write(p []byte) (n int, err error) }

    3.3 类型断言与类型 switch¶

    var i any = "hello"

// 单目标类型断言
s := i.(string)        // 失败 panic
s, ok := i.(string)    // comma-ok，失败不 panic

// 类型 switch
switch v := i.(type) {
case string:
    fmt.Println("string:", v)
case int:
    fmt.Println("int:", v)
case nil:
    fmt.Println("nil")
default:
    fmt.Println("other")
}

    3.4 接口组合¶

    type ReadWriter interface {
    Reader
    Writer
}

// 标准库大量使用
io.ReadWriter = io.Reader + io.Writer
io.ReadWriteCloser = io.Reader + io.Writer + io.Closer

    3.5 接口设计原则¶

    • 小接口：1-2 个方法最佳（io.Reader/io.Writer 只有 1 个）
    • 接受接口，返回具体类型（函数参数用接口，返回值用结构体）
    • 在使用者处定义接口（Go proverb: "The bigger the interface, the weaker the abstraction"）
    • 不要为了接口而接口：没有多个实现需求时直接用结构体
    // ✅ 消费者侧定义小接口
type Store interface {
    Get(ctx context.Context, key string) ([]byte, error)
}

func Handler(s Store) { ... }   // 只依赖需要的方法

    4. any 与空接口¶

    // any 是 interface{} 的别名（Go 1.18+）
func Print(v any) { fmt.Println(v) }

// 处理 JSON 任意结构
var data map[string]any
json.Unmarshal([]byte(`{"a":1}`), &data)
// 数字默认解析为 float64！

    5. 小结¶

    • 结构体是值类型，嵌入实现复用而非继承
    • 接口隐式实现，接口值 = (类型, 值) 二元组
    • nil 指针赋给接口后 != nil，是经典陷阱
    • 小接口优于大接口，消费者侧定义接口
    • 类型断言用 comma-ok 避免 panic
