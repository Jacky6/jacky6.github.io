    02 基本语法：变量、类型、运算符¶

    声明变量的 N 种方式、基本类型、类型转换、常量与 iota、指针。

    1. 变量声明¶

    1.1 四种方式¶

    // 1. var + 类型（零值初始化）
var name string
var age int

// 2. var + 初始值（类型可省略，编译器推断）
var name string = "Alice"
var age = 25              // 推断为 int

// 3. 短变量声明（只能在函数内）
count := 10               // 推断为 int
message := "hello"

// 4. 批量声明
var (
    host   string = "localhost"
    port   int    = 8080
    debug  bool   = true
)

    1.2 零值¶

    未初始化的变量不会被置为随机值，而是拥有确定的零值：

    类型 零值
    int, float64 等 0
    bool false
    string ""（空字符串，不是 nil）
    指针、切片、map、chan、func、接口 nil
    数组、结构体 每个元素/字段的零值 
    var s []int          // nil 切片，len=0，可直接 append
var m map[string]int // nil map，可读不可写！
fmt.Println(m["k"])  // 0（读 nil map 安全）
m["k"] = 1           // panic: assignment to entry in nil map

    1.3 变量声明规则¶

    • 函数外只能用 var，不能用 :=
    • := 左侧至少有一个新变量，否则编译错误
    • 同一作用域内变量不能重复声明（:= 重新声明例外见下）
    x := 1
x := 2        // 错误：no new variables on left side of :=

// 多变量时，只要有一个是新的即可
x, y := 1, 2
x, z := 3, 4  // 正确：z 是新变量，x 被赋值

    2. 基本类型¶

    2.1 数值类型¶

    分类 类型 说明
    有符号整数 int8, int16, int32, int64, int int 在 64 位系统为 64 位
    无符号整数 uint8, uint16, uint32, uint64, uint uint8 = byte
    浮点数 float32, float64 默认推荐 float64
    复数 complex64, complex128 科学计算用
    其他 byte（=uint8）, rune（=int32，表示 Unicode 码点） 
    var b byte = 'A'        // 65
var r rune = '中'       // 20013（Unicode 码点）
var f float64 = 3.14
var big int64 = 9_223_372_036_854_775_807  // 数字可用 _ 分隔

    2.2 字符串¶

    Go 字符串是不可变的字节序列（通常存放 UTF-8 文本）：

    s := "hello"
s[0] = 'H'              // 编译错误：字符串不可变

// 索引访问的是字节
s := "中文"
len(s)                  // 6（UTF-8 中每个汉字 3 字节）
s[0]                    // 228（第一个字节的值）

// 遍历
for i, b := range []byte(s) {}   // 按字节
for i, r := range s {}           // 按 rune（自动解码 UTF-8）

    常用操作：

    import (
    "strings"
    "strconv"
)

strings.Contains(s, "ell")       // 是否包含
strings.HasPrefix(s, "he")       // 前缀
strings.HasSuffix(s, "lo")       // 后缀
strings.Index(s, "l")            // 查找位置，-1 表示未找到
strings.Replace(s, "l", "L", 1)  // 替换 n 次
strings.Split(s, ",")            // 切分
strings.Join([]string{"a","b"}, "-")  // 连接
strings.TrimSpace(s)             // 去首尾空白
strings.ToLower(s) / strings.ToUpper(s)
strings.Repeat("ab", 3)          // "ababab"
strings.Builder                  // 高效拼接（见 12 章）

strconv.Itoa(42)                 // int → string
strconv.Atoi("42")               // string → int (返回 int, error)
strconv.FormatFloat(3.14, 'f', 2, 64)
strconv.ParseFloat("3.14", 64)

    2.3 类型转换¶

    Go 没有隐式类型转换，必须显式：

    var i int = 42
var f float64 = float64(i)   // 必须显式
var j int = int(f)           // 截断小数

// 字符串与其他类型互转必须用 strconv
s := strconv.Itoa(i)         // 不是 string(i)！

    3. 常量与 iota¶

    // 常量在编译期确定，不可修改
const Pi = 3.14159
const (
    StatusOK = 200
    StatusNotFound = 404
)

// iota：常量计数器，从 0 开始，每个 const 行自动 +1
const (
    Sunday = iota    // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)

// 经典用法：跳值
const (
    _ = iota             // 0，丢弃
    KB = 1 << (10 * iota) // 1 << 10
    MB                    // 1 << 20
    GB                    // 1 << 30
)

// 自增类型
const (
    Read = 1 << iota    // 1
    Write               // 2
    Execute             // 4
)

    4. 指针¶

    Go 有指针但没有指针运算（除了 unsafe 包）：

    x := 42
p := &x         // p 是 *int，指向 x
*p = 100        // 解引用赋值
fmt.Println(x)  // 100

// new 分配零值并返回指针
p2 := new(int)  // *int，*p2 == 0

    与 C 的区别：

    特性 C Go
    指针运算 p++ ❌ 不支持
    取地址 &x ✅
    解引用 *p ✅
    多级指针 **p ✅（但少用）
    自动解引用访问字段 p->field p.field（自动等价 (*p).field） 
    type User struct{ Name string }

u := User{Name: "Alice"}
p := &u
p.Name = "Bob"     // 自动解引用，等价 (*p).Name = "Bob"

    5. 运算符与控制表达式¶

    5.1 算术与比较¶

    +  -  *  /  %        // 算术
== != < > <= >=      // 比较运算返回 bool

    注意：

    • 整数除法向零截断：7/2 == 3，-7/2 == -3
    • ++/-- 是语句不是表达式：x++ 合法，y = x++ 非法
    • 字符串可用 ==、< 比较（按字节字典序）

    5.2 位运算¶

    &   |   ^   &^   // 位与、位或、异或、位清除（AND NOT）
<<  >>           // 左移、右移（无符号数逻辑右移，有符号数算术右移）

    6. 作用域¶

    // 块作用域：if/for 内声明的变量只在块内可见
if v := compute(); v > 0 {
    fmt.Println(v)   // v 在 if 和 else 块内可见
}

// for 循环变量
for i := 0; i < 10; i++ {
    // i 只在循环内可见
}

    7. 小结¶

    • 变量：函数内 :=，函数外 var
    • 零值确定，nil map 只读不可写
    • 无隐式类型转换，字符串与数字互转用 strconv
    • iota 实现优雅的常量枚举
    • 指针无运算，结构体指针自动解引用
