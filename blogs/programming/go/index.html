    Go 是什么？¶

    Go（又称 Golang）是 Google 于 2009 年推出的开源编程语言，由 Robert Griesemer、Rob Pike、Ken Thompson 设计。

    核心特点：

    简洁     ← 25 个关键字，语法刻意保持精简
编译型   ← 直接编译为静态二进制，无运行时依赖
并发     ← Goroutine + Channel，CSP 并发模型
快速编译 ← 增量编译 + 编译缓存，大型项目秒级构建
工程友好 ← gofmt 统一格式、内置测试、单一标准项目布局
GC       ← 低延迟并发垃圾回收，无需手动管理内存

    快速开始¶

    # 安装（Linux/macOS，官方推荐方式）
wget https://go.dev/dl/go1.23.0.linux-amd64.tar.gz
sudo rm -rf /usr/local/go && sudo tar -C /usr/local -xzf go1.23.0.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin

# 验证
go version

# 创建项目
mkdir hello && cd hello
go mod init hello
cat > main.go <<'EOF'
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
EOF
go run main.go

    环境说明¶
