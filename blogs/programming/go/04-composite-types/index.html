    04 复合类型：数组、切片、映射¶

    数组与切片的本质区别、切片扩容、map 底层、拷贝语义。

    1. 数组¶

    数组是固定长度、值类型的序列：

    var a [3]int              // [0 0 0]
b := [3]int{1, 2, 3}
c := [...]int{1, 2, 3}    // 长度自动推断为 3
d := [5]int{1: 10, 3: 30} // [0 10 0 30 0]，指定下标初始化

// 数组是值类型：赋值即完整拷贝！
e := b
e[0] = 100
fmt.Println(b[0])   // 1（b 不受影响）

    实际开发中数组很少直接使用，因为长度是类型的一部分（[3]int 和 [4]int 是不同类型），函数传参拷贝整个数组。

    2. 切片¶

    切片是 Go 最核心的数据结构：对底层数组的动态视图。

    2.1 结构¶

    // 切片头（运行时结构）
type slice struct {
    array unsafe.Pointer // 指向底层数组
    len   int            // 元素个数
    cap   int            // 底层数组容量
}

    // 创建方式
s := []int{1, 2, 3}              // 字面量
s := make([]int, 5)              // len=5, cap=5，全零值
s := make([]int, 0, 100)         // len=0, cap=100，预分配避免扩容
s := arr[1:4]                    // 从数组切片，共享底层数组！

// nil 切片 vs 空切片
var s []int      // nil 切片：s == nil, len=0
s := []int{}     // 空切片：s != nil, len=0
// 两者对 len、append、range 行为一致，JSON 序列化时 nil → null，空 → []

    2.2 共享底层数组的陷阱¶

    a := []int{1, 2, 3, 4, 5}
b := a[1:3]        // [2 3]

b[0] = 100
fmt.Println(a)     // [1 100 3 4 5]  ← a 被修改了！

b = append(b, 999)
fmt.Println(a)     // [1 100 3 999 5]  ← append 写入了 a[3]！
// 只有当 append 超出 cap 触发扩容时才会分配新数组

    安全做法：三索引切片或显式拷贝。

    b := a[1:3:3]      // len=2, cap=3-1=2，append 必然扩容，不再影响 a
b := append([]int(nil), a[1:3]...)   // 完整拷贝
b := slices.Clone(a[1:3])            // Go 1.21+ 标准库

    2.3 扩容机制¶

    s := make([]int, 0)
for i := 0; i < 10; i++ {
    s = append(s, i)
    fmt.Printf("len=%d cap=%d\n", len(s), cap(s))
}
// cap 变化：1 2 4 8 16 ...（小切片翻倍）
// 超过 256 后约 1.25 倍增长（Go 1.18+ 阈值调整）
    • append 可能返回新的切片头，必须接收返回值：s = append(s, x)
    • 预知大小时用 make([]T, 0, n) 预分配，避免多次扩容拷贝

    2.4 常用操作¶

    import "slices"

len(s), cap(s)
s[i]                    // 索引（越界 panic）
s = append(s, x)        // 追加
s = append(s, t...)     // 追加另一个切片
copy(dst, src)          // 复制，返回复制个数（取两者 len 较小值）
slices.Equal(s1, s2)    // 深比较
slices.Contains(s, x)   // 是否包含
slices.Index(s, x)      // 查找下标
slices.Sort(s)          // 排序（数字/字符串）
slices.SortFunc(s, cmp) // 自定义排序
slices.Reverse(s)       // 反转
slices.Clone(s)         // 克隆
slices.Delete(s, i, j)  // 删除 [i,j) 元素
slices.Insert(s, i, v...)  // 插入

// 手动删除下标 i（老写法）
s = append(s[:i], s[i+1:]...)

// 去重（需先排序）
slices.Sort(s)
compacted := slices.Compact(s)

    2.5 切片作函数参数¶

    切片传递的是切片头的拷贝，但底层数组共享：

    func modify(s []int) {
    s[0] = 100          // ✅ 影响外部（共享底层数组）
    s = append(s, 1)    // ❌ 不影响外部（可能扩容，局部变量指向新数组）
}

    3. 映射¶

    3.1 基本操作¶

    // 创建：必须用 make 或字面量（nil map 不可写）
m := make(map[string]int)
m := map[string]int{"a": 1, "b": 2}

m["c"] = 3              // 增/改
v := m["a"]             // 查：不存在返回零值
v, ok := m["x"]         // comma-ok 惯用法
delete(m, "a")          // 删
len(m)                  // 元素个数

// 遍历（顺序随机，每次运行都不同）
for k, v := range m {}

    3.2 不可寻址¶

    m := map[string][2]int{}
m["a"][0] = 1   // 编译错误：map 元素不可寻址
// 解决：整体替换
m["a"] = [2]int{1, 0}

// slice 元素可以（因为 slice 底层是指针）
s := make([][2]int, 1)
s[0][0] = 1     // ✅

    3.3 key 的要求¶

    key 必须是可比较类型（== 可用）：

    • ✅ int、string、bool、float、指针、channel、接口
    • ✅ 只含可比较字段的结构体
    • ❌ slice、map、function
    type Point struct{ X, Y int }
m := map[Point]string{}   // ✅ 结构体作 key

    3.4 标准库增强（Go 1.21+）¶

    import "maps"

maps.Keys(m)             // 返回迭代器（Go 1.23+）
maps.Values(m)           // 返回迭代器
maps.Copy(dst, src)      // 批量复制
maps.Equal(m1, m2)       // 深比较
maps.EqualFunc(m1, m2, func(a, b int) bool { return a == b })
maps.DeleteFunc(m, func(k string, v int) bool { return v < 0 })

    3.5 线程安全¶

    map 不是并发安全的，并发读写直接 panic（fatal error: concurrent map read and map write，无法 recover）：

    // 方案 1：sync.RWMutex
var mu sync.RWMutex
mu.Lock(); m[k] = v; mu.Unlock()
mu.RLock(); v := m[k]; mu.RUnlock()

// 方案 2：sync.Map（读多写少场景）
var sm sync.Map
sm.Store("k", 1)
v, ok := sm.Load("k")
sm.Range(func(k, v any) bool { return true })

    4. 值语义 vs 引用语义¶

    类型 赋值行为 传参
    数组 完整拷贝 拷贝
    结构体 完整拷贝 拷贝
    切片 拷贝切片头，共享底层数组 半引用
    map 拷贝指针，完全共享 引用
    channel / 函数 拷贝指针 引用 
    // 经典面试题
func modifyM(m map[string]int) { m["k"] = 1 }        // ✅ 外部可见
func modifyS(s []int) { s[0] = 1 }                    // ✅ 外部可见
func modifyA(a [3]int) { a[0] = 1 }                   // ❌ 外部不可见
func appendS(s []int) { s = append(s, 1) }            // ❌ 外部不可见

    5. 小结¶

    • 数组是值类型、长度是类型的一部分，实际很少用
    • 切片 = 指针 + len + cap，append 必须接收返回值
    • 子切片共享底层数组，必要时用三索引或 slices.Clone
    • map 遍历顺序随机、元素不可寻址、并发读写会 fatal
    • slices/maps 标准库包（Go 1.21+）大幅减少手写代码
