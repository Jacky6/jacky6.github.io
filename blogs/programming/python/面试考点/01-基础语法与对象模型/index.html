    基础语法与对象模型¶

    1. Python 中的变量是什么？¶

    变量名是对象的引用（或名称绑定），赋值通常是让名称指向对象，而不是把对象内容复制一份。

    a = [1, 2]
b = a
b.append(3)
print(a)  # [1, 2, 3]

    a 和 b 指向同一个列表。id(obj) 可用于观察对象身份，但不应依赖具体的 ID 数值。

    2. == 和 is 有什么区别？¶

    • == 比较值是否相等，调用对象的相等比较逻辑。
    • is 比较是否为同一个对象。

    比较数值、字符串等值时通常使用 ==；判断单例（例如 value is None）时使用 is。不要用 is 判断两个值是否相等。

    3. 可变对象和不可变对象有什么区别？¶

    可变对象可在原对象上修改，例如 list、dict、set；不可变对象不能原地修改，例如 int、str、tuple。不可变容器若包含可变对象，其内部对象仍可能被修改。

    items = ([1],)
items[0].append(2)  # 可以：修改内部列表
# items[0] = [3]    # 不可以：不能给元组元素重新赋值

    4. Python 函数参数是值传递还是引用传递？¶

    更准确的说法是“对象引用按值传递”：函数收到对象引用的副本。函数可以通过该引用修改可变对象，但在函数内重新绑定参数，不会改变调用方变量的绑定。

    def update(values):
    values.append(2)  # 修改共享列表

def rebind(values):
    values = [9]       # 只重新绑定局部参数

    5. 浅拷贝和深拷贝有什么区别？¶

    • 浅拷贝创建新的外层容器，但其中的元素仍引用原对象。
    • 深拷贝递归复制嵌套对象（通过 copy.deepcopy），但遇到自定义对象、资源句柄或特殊复制约定时仍需检查行为。
    • 赋值只增加一个引用，不会创建副本。

    6. 为什么可变对象不能作为字典键？¶

    字典键必须可哈希：对象的哈希值在其生命周期内应保持稳定，并且相等的对象必须有相同哈希值。可变对象改变内容后可能改变哈希值，破坏哈希表查找，因此 list、dict、set 不能作为键；满足哈希约定的不可变对象通常可以。

    7. 字典和集合的查找为什么通常很快？¶

    dict 和 set 基于哈希表，查找、插入和删除的平均时间复杂度通常为 O(1)，发生大量哈希冲突时最坏情况会变差。键需要可哈希；自定义类若重写相等比较，应同时保证哈希实现满足一致性约定。

    8. list 和 tuple 如何选择？¶

    需要增删改时通常用 list；数据应保持不可变，或需要作为满足哈希条件的键时考虑 tuple。元组是否可哈希取决于其所有元素是否都可哈希。

    9. None、False 和空容器有什么区别？¶

    它们都是假值，但含义不同：None 通常表示缺失或无结果，False 是布尔值，空列表/字典表示一个存在但为空的容器。需要区分“未提供”和“值为空”时，不要只写 if not value，应显式比较或使用哨兵值。

    10. 什么是 LEGB 作用域规则？¶

    名称查找顺序是 Local（局部）、Enclosing（闭包外层）、Global（模块全局）、Built-in（内置）。global 声明名称来自模块全局作用域，nonlocal 声明名称来自最近的外层函数作用域。
