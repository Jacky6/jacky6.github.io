    函数与面向对象¶

    1. 为什么不建议用可变对象作为默认参数？¶

    默认参数在函数定义时求值一次，后续调用共享同一个默认对象。若在函数中修改它，状态会跨调用保留。

    def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

    2. *args 和 **kwargs 是什么？¶

    • *args 收集额外的位置参数为元组。
    • **kwargs 收集额外的关键字参数为字典。
    • 调用时也可用 *iterable 和 **mapping 解包参数。

    Python 还支持仅限位置参数（/）和仅限关键字参数（*），用于明确 API 的调用方式。

    3. 什么是闭包？什么是延迟绑定？¶

    闭包是函数及其捕获的外层作用域名称。闭包读取的是名称，循环中创建的函数通常会在调用时读取循环变量的最终值，即延迟绑定。

    funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])  # [2, 2, 2]

    若要保存创建函数时的值，可用默认参数绑定：

    funcs = [lambda i=i: i for i in range(3)]

    4. 装饰器是什么？¶

    装饰器接收函数或类并返回替代对象，常用于日志、计时、缓存和权限检查。用 functools.wraps 保留被装饰函数的名称、文档字符串等元信息；装饰器有参数时通常需要再增加一层函数。

    5. 实例方法、类方法和静态方法有什么区别？¶

    • 实例方法第一个参数通常是 self，可访问实例及类状态。
    • @classmethod 第一个参数通常是 cls，可访问类状态，常用于替代构造器。
    • @staticmethod 不自动接收实例或类，适合逻辑上属于该类命名空间的工具函数。

    6. Python 如何处理多重继承中的方法查找？¶

    Python 使用方法解析顺序（MRO）查找属性。可通过 ClassName.__mro__ 或 ClassName.mro() 查看。协作式多重继承中，继承链上的实现通常使用 super()，并保持方法签名兼容，使调用能按 MRO 继续传递。

    7. __new__ 和 __init__ 有什么区别？¶

    __new__ 创建并返回实例，__init__ 在实例创建后初始化它且不负责返回实例。不可变类型的子类有时需要在 __new__ 中控制创建值；普通初始化逻辑放在 __init__。

    8. 什么是属性（property）和描述符？¶

    property 将方法包装为属性接口，可在读取、设置或删除属性时执行逻辑。描述符是定义了 __get__、__set__ 或 __delete__ 中至少一个方法的对象，常用于属性管理、ORM 字段和校验；property 本身就是描述符的一种。

    9. __repr__ 和 __str__ 的区别？¶

    __str__ 面向用户，提供易读表示；__repr__ 面向开发者和调试，尽量提供无歧义的表示。未定义 __str__ 时，str(obj) 会回退到 __repr__。
