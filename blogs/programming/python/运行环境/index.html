    pyenv¶

    ​ pyenv 主要功能

    • 安装多个 Python 版本：可以在同一台机器上安装 Python 2.7、3.6、3.8、3.9、3.11、3.12 等。
    • 按项目设置 Python 版本：通过 .python-version 文件指定项目使用的 Python 版本。
    • 全局/局部版本切换：可设置全局默认版本，也可为特定目录设置局部版本。
    • 与 pyenv-virtualenv 插件集成：支持创建和管理虚拟环境（类似 venv 或 virtualenv）。
    • 非侵入式：不会修改系统 Python，所有操作通过 shims 实现。

    1. 安装¶

    # linux
curl -LsSf https://astral.sh/uv/install.sh | sh
# macos
brew install pyenv

    2. 基本使用¶

    1. 查看可安装的 Python 版本
pyenv install --list

2. 安装指定版本python
pyenv install 3.11.6

3. 查看已经安装的版本
pyenv versions

4. 设置全局 python 版本
pyenv global 3.11.6

5. 设置局部文件夹 python 版本（仅对当前目录和子目录生效）
cd ~/dir
pyenv local 3.11.6

6. 临时设置shell python 版本

pyenv shell 3.11.6

    3. 虚拟环境管理工具 pyenv-virtualenv¶

    ​ pyenv-virtualenv 是一个插件，用于创建独立的 Python 虚拟环境。

    ## 1. 安装
git clone https://github.com/pyenv/pyenv-virtualenv.git $(pyenv root)/plugins/pyenv-virtualenv

# 添加到 shell 配置文件
echo 'eval "$(pyenv virtualenv-init -)"' >> ~/.zshrc  # 或 .bashrc

## 2. 创建虚拟环境
pyenv virtualenv 3.11.6 myproject-3.11

## 3. 激活虚拟环境
pyenv activate myproject-3.11

## 4. 局部使用虚拟环境
cd /path/to/project
pyenv local myproject-3.11

## 5. 退出虚拟环境
pyenv deactivate

    例子：

    # 进入项目目录
cd my_django_project

# 设置该项目使用 Python 3.10
pyenv local 3.10.12

# 创建虚拟环境
pyenv virtualenv 3.10.12 django-env

# 设置项目使用该虚拟环境
pyenv local django-env

# 此时 python、pip 都指向虚拟环境
python --version    # Python 3.10.12
pip install django

    UV¶

    uv 是一个极快的 Python 包安装器、依赖解析器和虚拟环境管理工具，由 Astral（即 Ruff 的开发团队）推出，使用 Rust 编写，目标是替代 pip、pip-tools 和 virtualenv 的部分功能，成为现代 Python 开发中的高效工具链。

    一、什么是 uv¶

    • 官方定位：“The ultrafast Python package installer and resolver”
    • 官网：https://docs.astral.sh/uv/
    • GitHub：https://github.com/astral-sh/uv
    • 语言：Rust（性能极高）
    • 兼容性：完全兼容 PyPI、PEP 标准（如 PEP 508, PEP 621, PEP 660 等）

    二、核心功能¶

    功能 对应传统工具
    ⚡ 超快安装依赖 替代 pip install
    🧩 高性能依赖解析 替代 pip-tools / pip-resolve
    🐍 创建虚拟环境 替代 python -m venv 或 virtualenv
    🔁 同步依赖（install/dev/uninstall） 类似 poetry install 或 pip-sync
    📦 支持 requirements.txt, pyproject.toml, setup.py 全格式支持

    三、为什么选择 uv？（优势）¶

    优势 说明
    ⚡ 速度极快 比 pip 快 10-100 倍，尤其在解析复杂依赖时
    🧱 纯 Rust 实现 启动快、内存安全、无 GIL 限制
    🔁 确定性解析 生成可重复的 requirements.lock（类似 Cargo.lock）
    🐍 无缝集成 Python 生态 支持 wheels、sdist、editable installs、VCS 依赖等
    🧰 一体化工具 不需要额外安装 pip-tools, virtualenv 等

    四、安装¶

    方法 1：使用官方脚本（推荐）¶

    # Linux/macOS
curl -LsSf https://astral.sh/uv/install.sh | sh

# 或仅下载
curl -L -o uv.zip https://github.com/astral-sh/uv/releases/latest/download/uv-x86_64-unknown-linux-gnu.zip

    方法 2：通过 pipx（如果已安装）¶

    pipx install uv

    方法 3：Homebrew（macOS/Linux）¶

    brew install uv

    验证安装¶

    uv --version

    五、基本用法示例¶

    0. uv 更换依赖源¶

    UV 支持在项目级别、用户级别和系统级别使用配置文件。
    用户级别配置文件¶
    文件路径 `~/.uv/uv.toml`, 在该文件中添加以下内容：

    [[index]] url = "https://pypi.tuna.tsinghua.edu.cn/simple" default = true

    项目级别配置文件：¶
    文件路径：项目目录下的 `pyproject.toml` 或 `uv.toml`

    在 pyproject.toml 中添加 [[tool.uv.index]] url = "https://pypi.tuna.tsinghua.edu.cn/simple" default = true 或在 uv.toml 中添加 [[index]] url = "https://pypi.tuna.tsinghua.edu.cn/simple" default = true

    通过命令行临时指定¶
    在命令行中运行 uv 命令时，可以直接制定镜像源：

    uv add --default-index https://pypi.tuna.tsinghua.edu.cn/simple requests

    1. 创建虚拟环境¶

    uv venv <path> --python <version-or-path>

uv venv myenv
# 默认创建在当前目录下的 myenv/

    激活环境：

    source myenv/bin/activate  # Linux/macOS
# 或
myenv\Scripts\activate     # Windows

    💡 uv venv 比 python -m venv 更快，并支持更多选项（如指定 Python 版本）。

    2. 安装包（替代 pip）¶

    2.1 uv pip install —— 快速安装依赖（推荐替代 pip）¶

    用途： + 安装 Python 包到当前环境或虚拟环境中 + 兼容 pip 的所有常见用法 + 极速安装（基于 Rust 实现，并行下载、智能缓存）

    # 安装单个包
uv pip install requests

# 安装多个包
uv pip install flask pandas numpy

# 从 requirements.txt 安装
uv pip install -r requirements.txt

# 安装可编辑包（开发模式）
uv pip install -e .

# 指定 Python 环境或创建 venv 后安装
uv pip install --python 3.11 django
uv pip install --python .venv flask

    ✅ 比 pip install 快得多，尤其是首次解析。

    💡 特点： + 不会修改项目的配置文件（如 pyproject.toml） + 更像是“一次性”安装操作 + 适合脚本、临时环境、CI/CD 使用

    2.2 uv add —— 现代化依赖管理（像 npm/yarn/poetry）¶

    用途： + 将包添加为项目的正式依赖 + 自动写入 pyproject.toml 文件中的 [project.dependencies] + 支持 --dev 添加开发依赖（写入 [project.optional-dependencies] 或 [tool.uv.dev-dependencies]） + 需要先初始化项目：uv init

    示例流程¶

    1. 初始化项目 

      uv init myproject
cd myproject
      会生成 pyproject.toml： 
      [project]
name = "myproject"
version = "0.1.0"
dependencies = []

    2. 添加运行时依赖

    uv add requests httpx
    更新后的 pyproject.toml： 
    [project]
name = "myproject"
version = "0.1.0"
dependencies = [
    "requests",
    "httpx",
]

    1. 添加开发依赖（dev dependencies） 
      uv add pytest flake8 --dev
      结果 
      [tool.uv]
dev-dependencies = [
    "pytest",
    "flake8",
]

    注意：目前 uv 使用 [tool.uv.dev-dependencies] 存储 dev 依赖，而不是标准的 optional-dependencies（未来可能变化）。

    1. 同步所有依赖（安装） 
      uv sync
# 等价于
uv pip install -r <(uv pip list --format=freeze)

    3. 同步依赖（类似 pip-sync）¶

    uv sync
# 自动读取 requirements.txt 或 pyproject.toml 并安装/卸载以保持一致

    常用于 CI/CD 中确保环境纯净。

    4. 生成锁文件（lock file）¶

    uv lock

    会生成 requirements.lock 文件（类似 pip-compile），包含所有精确版本。

    然后你可以：

    uv sync  # 根据 lock 文件安装

    5. 添加开发依赖¶

    uv add pytest --dev
uv add debugpy jupyter --dev

    会自动更新 pyproject.toml（如果你用的是 Poetry 风格项目结构）。

    注意：目前 uv 主要用于“扁平依赖管理”，对 pyproject.toml 的完整支持正在完善中。

    6. 卸载包¶

    uv remove requests

    六、最佳实践¶

    # 1. 创建项目
uv init hello-web
cd hello-web

# 2. 添加生产依赖
uv add flask requests

# 3. 添加开发依赖
uv add pytest coverage --dev

# 4. 查看当前依赖
uv project add-list

# 5. 安装所有依赖
uv sync

# 6. 激活环境（可选）
source .venv/bin/activate  # Linux/macOS
# 或
.venv\Scripts\activate     # Windows

# 7. 运行应用
python app.py
