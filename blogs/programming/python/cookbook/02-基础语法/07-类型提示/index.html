    2.7 类型提示 (Type Hints)¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 类型提示概念 3.5+ 引入的标注语法，不强制运行检查，提升可读性 ⭐⭐⭐
    2 基本语法 变量 name: str，函数参数加类型、-> 标返回值 ⭐⭐⭐⭐
    3 容器类型 3.9+ 直接用 list[int]/dict[str, int]，旧版用 typing.List ⭐⭐⭐
    4 Optional/Union 可能为 None 用 Optional 或 str | None（3.10+） ⭐⭐⭐⭐
    5 Callable/Any 函数作参数用 Callable[[参数类型], 返回类型]，Any 表示任意类型 ⭐⭐⭐
    6 泛型 TypeVar + Generic[T] 编写类型无关的容器类 ⭐⭐⭐
    7 mypy 静态类型检查工具，运行前发现类型错误 ⭐⭐⭐
    8 最佳实践 公共 API 加提示，避免滥用 Any，提示与实现保持一致 ⭐⭐⭐

    📝 什么是类型提示？¶

    类型提示是 Python 3.5+ 引入的功能，用于标注变量和函数的类型，提高代码可读性和可维护性。

    知识点：

    • 类型提示是 Python 3.5+ 的标注语法，用于标明变量/参数/返回值类型
    • ⭐ 类型提示不强制执行，运行时不检查，靠 mypy 等工具静态检查
    • 好处：提高可读性、IDE 补全更准、提前发现 bug
    # 没有类型提示
def greet(name):
    return f"Hello, {name}"

# 有类型提示
def greet(name: str) -> str:
    return f"Hello, {name}"

    🔧 基本语法¶

    知识点：

    • 变量标注 name: str = "Alice"，可只标注不初始化（count: int）
    • ⭐ 函数标注：参数加类型，返回值用 -> 标注，如 def add(a: int, b: int) -> int
    • 多返回值标 tuple[str, int]，带默认值参数照常标注

    变量类型提示¶

    # 基本类型
name: str = "Alice"
age: int = 25
height: float = 1.75
is_student: bool = True

# 特殊值
nothing: None = None

# 可以不初始化
count: int

    函数类型提示¶

    # 参数和返回值
def add(a: int, b: int) -> int:
    return a + b

# 多个返回值
def get_user(user_id: int) -> tuple[str, int]:
    return ("Alice", 25)

# 可选参数
def greet(name: str, greeting: str = "Hello") -> str:
    return f"{greeting}, {name}"

    📦 typing 模块¶

    知识点：

    • ⭐ Python 3.9+ 可直接写内置泛型：list[int]、dict[str, int]、set[int]、tuple[int, int]，旧版用 typing.List 等
    • ⭐ Optional[X] 等价于 X | None（3.10+ 管道语法）；Union[int, str] 等价于 int | str
    • Any 表示任意类型；Callable[[int, int], int] 标注"接受函数作参数"

    容器类型¶

    from typing import List, Dict, Set, Tuple

# 列表
names: List[str] = ["Alice", "Bob"]
numbers: list[int] = [1, 2, 3]  # Python 3.9+ 可以直接用 list

# 字典
scores: Dict[str, int] = {"Alice": 90, "Bob": 85}
scores: dict[str, int] = {"Alice": 90}  # Python 3.9+

# 集合
unique_ids: Set[int] = {1, 2, 3}
unique_ids: set[int] = {1, 2, 3}  # Python 3.9+

# 元组
point: Tuple[int, int] = (10, 20)
coordinate: tuple[int, int] = (10, 20)  # Python 3.9+

    可选类型和联合类型¶

    from typing import Optional, Union

# 可选类型（可以是类型或 None）
def find_user(user_id: int) -> Optional[str]:
    """可能返回 None"""
    if user_id == 1:
        return "Alice"
    return None

# Python 3.10+ 可以用 | 语法
def find_user(user_id: int) -> str | None:
    if user_id == 1:
        return "Alice"
    return None

# 联合类型（可以是多种类型之一）
def process(value: Union[int, str]) -> str:
    return str(value)

# Python 3.10+ 语法
def process(value: int | str) -> str:
    return str(value)

    任意类型¶

    from typing import Any

# 接受任何类型
def log(message: Any) -> None:
    print(message)

# 返回值类型不确定
def get_data(query: str) -> Any:
    # 可能返回 dict, list, 或其他
    pass

    可调用类型¶

    from typing import Callable

# 接受函数作为参数
def apply(func: Callable[[int, int], int], a: int, b: int) -> int:
    return func(a, b)

def add(x: int, y: int) -> int:
    return x + y

result = apply(add, 3, 5)  # 8

    🎯 实际例子¶

    知识点：

    • 数据处理函数：List[float] 参数、Optional[Dict] 返回值标注查找结果
    • 类中标注：init 参数、实例属性（self.email: Optional[str] = None）、方法返回值 -> None
    • ⭐ 泛型：T = TypeVar('T') + class Stack(Generic[T])，实例化时 Stackint 指定类型

    1. 数据处理函数¶

    from typing import List, Dict, Optional

def calculate_average(scores: List[float]) -> float:
    """计算平均分"""
    if not scores:
        return 0.0
    return sum(scores) / len(scores)

def find_student(students: List[Dict[str, any]], name: str) -> Optional[Dict[str, any]]:
    """查找学生"""
    for student in students:
        if student.get("name") == name:
            return student
    return None

    2. 类类型提示¶

    from typing import List, Optional

class Person:
    def __init__(self, name: str, age: int) -> None:
        self.name: str = name
        self.age: int = age
        self.email: Optional[str] = None

    def set_email(self, email: str) -> None:
        self.email = email

    def get_info(self) -> str:
        return f"{self.name}, {self.age}岁"

class Company:
    def __init__(self) -> None:
        self.employees: List[Person] = []

    def add_employee(self, person: Person) -> None:
        self.employees.append(person)

    3. 泛型¶

    from typing import TypeVar, Generic, List

T = TypeVar('T')

class Stack(Generic[T]):
    """泛型栈"""

    def __init__(self) -> None:
        self.items: List[T] = []

    def push(self, item: T) -> None:
        self.items.append(item)

    def pop(self) -> T:
        return self.items.pop()

    def is_empty(self) -> bool:
        return len(self.items) == 0

# 使用
int_stack = Stack[int]()
int_stack.push(1)
int_stack.push(2)

str_stack = Stack[str]()
str_stack.push("hello")

    🔍 类型检查工具¶

    知识点：

    • ⭐ mypy 是最常用的静态检查器：pip install mypy 后运行 mypy 文件名.py
    • mypy 能在运行前发现"传 str 给 int 参数"这类错误
    • VS Code 可通过 settings.json 开启 mypy 和 typeCheckingMode

    mypy¶

    # 安装
pip install mypy

# 使用
mypy your_file.py

# 示例
# $ cat example.py
def add(a: int, b: int) -> int:
    return a + b

result = add(3, "5")  # 类型错误！

# $ mypy example.py
# example.py:4: error: Argument 2 to "add" has incompatible type "str"; expected "int"

    VS Code 集成¶

    // settings.json
{
    "python.linting.enabled": true,
    "python.linting.mypyEnabled": true,
    "python.analysis.typeCheckingMode": "basic"
}

    ⚠️ 最佳实践¶

    知识点：

    • ✅ 公共 API、复杂函数、类属性优先添加类型提示
    • ⚠️ 避免过度使用 Any（失去检查意义）、避免提示与实现不符（标注 -> str 却 return None）

    ✅ 推荐¶

    # 1. 公共 API 添加类型提示
def public_function(name: str, age: int) -> dict[str, any]:
    return {"name": name, "age": age}

# 2. 复杂函数添加提示
def process_data(
    items: list[str],
    config: dict[str, any] | None = None
) -> list[dict[str, any]]:
    pass

# 3. 类属性添加提示
class User:
    name: str
    age: int
    email: str | None

    ❌ 避免¶

    # 1. 过度使用 Any
def process(data: Any) -> Any:  # 失去类型检查意义
    return data

# 2. 忽略明显的类型
def add(a, b):  # 应该添加类型提示
    return a + b

# 3. 类型提示与实现不符
def get_name() -> str:
    return None  # 类型检查会报错

    📊 类型提示的好处¶

    知识点：

    • 五大好处：可读性、IDE 支持、早期发现 bug、自带文档作用、重构更安全
    • ⭐ 对 C++/Java 背景：类型提示带来熟悉的静态类型体验，但 Python 仍是动态类型
    好处 说明
    代码可读性 一眼看出函数接受什么、返回什么
    IDE 支持 更好的自动补全和错误提示
    早期发现 bug 类型检查器在运行前发现错误
    文档作用 类型提示本身就是文档
    重构安全 修改代码时更容易发现影响范围

    📝 练习题¶

    1. 为以下函数添加类型提示
    2. 创建一个泛型队列类
    3. 使用 Union 类型创建一个能处理多种输入的函数

    示例答案： 

    # 练习 1
from typing import List, Optional

def find_max(numbers: List[float]) -> Optional[float]:
    if not numbers:
        return None
    return max(numbers)

def merge_dicts(dict1: dict[str, int], dict2: dict[str, int]) -> dict[str, int]:
    result = dict1.copy()
    result.update(dict2)
    return result

# 练习 2
from typing import Generic, TypeVar, List, Optional

T = TypeVar('T')

class Queue(Generic[T]):
    def __init__(self) -> None:
        self._items: List[T] = []

    def enqueue(self, item: T) -> None:
        self._items.append(item)

    def dequeue(self) -> T | None:
        if self._items:
            return self._items.pop(0)
        return None

    def is_empty(self) -> bool:
        return len(self._items) == 0

    本章小结¶

    核心知识点¶

    ✅ 基本语法：变量 name: str，函数 def f(a: int) -> int
    ✅ 版本演进：3.9+ 内置泛型 list[int]，3.10+ 管道联合 int | str
    ✅ Optional/Union：可能返回 None 必须标注，避免调用方踩坑
    ✅ 泛型：TypeVar + Generic[T] 编写通用容器类
    ✅ 工具链：mypy 静态检查，公共 API 必标注、避免滥用 Any

    类型提示是现代 Python 的重要特性，建议在编写代码时养成添加类型提示的习惯！
