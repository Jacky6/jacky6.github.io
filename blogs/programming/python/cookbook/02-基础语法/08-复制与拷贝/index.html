    2.8 复制与拷贝¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 赋值即引用 b = a 不复制对象，两个变量指向同一对象 ⭐⭐⭐⭐
    2 浅拷贝 copy()/[:]/list()/copy.copy 新建外层，嵌套对象仍共享 ⭐⭐⭐⭐
    3 深拷贝 copy.deepcopy 递归复制所有层级，副本完全独立 ⭐⭐⭐⭐
    4 id() 验证 id 相同即同一对象，用于判断赋值/拷贝行为 ⭐⭐⭐
    5 解包拷贝陷阱 {**d} 和切片一样只是浅拷贝 ⭐⭐⭐
    6 性能差异 深拷贝递归复制远慢于浅拷贝，大数据慎用 ⭐⭐
    7 决策树 不复制用赋值、单层用浅拷贝、嵌套用深拷贝 ⭐⭐⭐

    🎯 核心概念¶

    知识点： - ⭐ 赋值 ≠ 复制：list2 = list1 只是新建一个引用，指向同一个对象 - 修改任一变量，另一个也跟着变（引用传递） - 用 id(list1) == id(list2) 可验证两者是否同一对象

    在 Python 中，赋值 ≠ 复制。理解这一点对于避免 bugs 至关重要！

    赋值只是引用¶

    # ❌ 这不是复制！
list1 = [1, 2, 3]
list2 = list1  # 只是创建了一个新的引用

list2.append(4)
print(list1)  # [1, 2, 3, 4]  ← 原列表也被修改了！
print(list2)  # [1, 2, 3, 4]

# 验证：它们指向同一个对象
print(id(list1) == id(list2))  # True

    关键点： - list2 = list1 只是让 list2 指向 list1 同一个对象 - 修改任何一个，另一个也会变 - 这叫引用传递，不是复制

    📋 三种复制方式¶

    知识点： - ⭐ 三种方式对比：赋值共享一切、浅拷贝只复制第一层、深拷贝递归完全独立 - 选型看数据结构：单层数据浅拷贝够用，有嵌套必须深拷贝

    方式 语法 适用场景 嵌套对象
    赋值 b = a 不需要复制时 共享引用 ❌
    浅拷贝 b = a.copy() / b = a[:] 只有一层数据 共享引用 ❌
    深拷贝 b = copy.deepcopy(a) 有嵌套结构 完全独立 ✅

    🔍 浅拷贝（Shallow Copy）¶

    知识点： - ⭐ 列表浅拷贝四写法：copy()、[:] 切片、list()、copy.copy()，外层 id 不同 - ⚠️ 嵌套对象仍是共享引用：修改内层子列表，原列表也被修改 - 字典浅拷贝：copy()、dict()、{**d} 解包，嵌套字典同样互相影响 - 集合元素必须不可变，通常没有嵌套问题

    浅拷贝创建一个新的对象，但嵌套的对象仍然是引用。

    列表的浅拷贝¶

    # 方法 1: 使用 copy() 方法
list1 = [1, 2, 3]
list2 = list1.copy()

# 方法 2: 使用切片
list3 = list1[:]

# 方法 3: 使用 list() 构造函数
list4 = list(list1)

# 方法 4: 使用 copy 模块
import copy
list5 = copy.copy(list1)

# 验证：外层是独立的
print(id(list1) == id(list2))  # False

    ⚠️ 浅拷贝的陷阱¶

    import copy

# 嵌套列表
list1 = [1, 2, [3, 4]]
list2 = list1.copy()  # 浅拷贝

# 修改外层 - 没问题
list2.append(5)
print(list1)  # [1, 2, [3, 4]]      ← 不受影响
print(list2)  # [1, 2, [3, 4], 5]

# 修改内层 - 出问题！
list2[2].append(5)
print(list1)  # [1, 2, [3, 4, 5]]   ← 原列表也被修改了！
print(list2)  # [1, 2, [3, 4, 5]]

# 验证：嵌套对象是同一个
print(id(list1[2]) == id(list2[2]))  # True

    字典的浅拷贝¶

    # 方法 1: 使用 copy() 方法
dict1 = {"a": 1, "b": 2}
dict2 = dict1.copy()

# 方法 2: 使用 dict() 构造函数
dict3 = dict(dict1)

# 方法 3: 使用解包
dict4 = {**dict1}

# 方法 4: 使用 copy 模块
import copy
dict5 = copy.copy(dict1)

# ⚠️ 嵌套字典同样有问题
dict1 = {"user": {"name": "Alice", "age": 25}}
dict2 = dict1.copy()

dict2["user"]["age"] = 26
print(dict1["user"]["age"])  # 26  ← 原字典也被修改了！

    集合的浅拷贝¶

    set1 = {1, 2, 3}
set2 = set1.copy()
set3 = set(set1)

# 集合通常没有嵌套问题（元素必须不可变）

    🛡️ 深拷贝（Deep Copy）¶

    知识点： - ⭐ copy.deepcopy() 递归复制所有嵌套层级，副本与原对象完全独立 - 验证：外层和所有内层的 id 都不同 - 复杂嵌套（字典套列表套字典）任意层级修改都不影响原数据

    深拷贝会递归地复制所有嵌套对象，创建完全独立的副本。

    使用 copy.deepcopy()¶

    import copy

# 嵌套列表
list1 = [1, 2, [3, 4]]
list2 = copy.deepcopy(list1)

# 修改内层 - 完全独立
list2[2].append(5)
print(list1)  # [1, 2, [3, 4]]      ← 不受影响
print(list2)  # [1, 2, [3, 4, 5]]

# 验证：所有对象都是独立的
print(id(list1) == id(list2))          # False
print(id(list1[2]) == id(list2[2]))    # False

    复杂嵌套结构¶

    import copy

# 复杂的嵌套结构
data = {
    "users": [
        {"name": "Alice", "scores": [90, 85, 88]},
        {"name": "Bob", "scores": [78, 92, 80]},
    ],
    "metadata": {
        "created": "2024-01-01",
        "tags": ["python", "tutorial"]
    }
}

# 深拷贝
data_copy = copy.deepcopy(data)

# 任意修改都不会影响原数据
data_copy["users"][0]["scores"].append(100)
data_copy["metadata"]["tags"].append("deep-copy")

print(data["users"][0]["scores"])  # [90, 85, 88]  ← 不受影响
print(data["metadata"]["tags"])    # ['python', 'tutorial']

    📊 对比演示¶

    知识点： - 同一份嵌套数据 [1, 2, [3, 4]] 分别用赋值、浅拷贝、深拷贝后修改内层 - ⭐ 结论：前两种原对象都被修改，只有深拷贝的原对象保持不变

    import copy

print("=" * 50)
print("原始数据")
print("=" * 50)

original = [1, 2, [3, 4]]
print(f"original = {original}")

print("\n" + "=" * 50)
print("1. 赋值（引用）")
print("=" * 50)

assigned = original
assigned[2].append(5)
print(f"assigned = {assigned}")
print(f"original = {original}  ← 被修改了！")

print("\n" + "=" * 50)
print("2. 浅拷贝")
print("=" * 50)

original = [1, 2, [3, 4]]  # 重置
shallow = original.copy()
shallow[2].append(5)
print(f"shallow  = {shallow}")
print(f"original = {original}  ← 也被修改了！")

print("\n" + "=" * 50)
print("3. 深拷贝")
print("=" * 50)

original = [1, 2, [3, 4]]  # 重置
deep = copy.deepcopy(original)
deep[2].append(5)
print(f"deep     = {deep}")
print(f"original = {original}  ← 完全独立！")

    🎯 实用场景¶

    知识点： - ⭐ 函数内先 deepcopy 再修改，保护调用方的原始数据不被副作用污染 - 配置管理：从 DEFAULT_CONFIG 深拷贝出各环境配置，独立修改互不影响 - 游戏存档：deepcopy 保存状态快照实现"读档"

    1. 函数参数保护¶

    import copy

def process_data(data):
    """处理数据而不修改原始数据"""
    # 深拷贝保护原始数据
    data_copy = copy.deepcopy(data)

    # 安全地修改
    data_copy["processed"] = True
    data_copy["items"].append("new_item")

    return data_copy

# 使用
original = {"items": [1, 2, 3]}
result = process_data(original)

print(original)  # {'items': [1, 2, 3]}  ← 未被修改
print(result)    # {'items': [1, 2, 3, 'new_item'], 'processed': True}

    2. 配置管理¶

    import copy

# 默认配置
DEFAULT_CONFIG = {
    "database": {
        "host": "localhost",
        "port": 5432,
        "credentials": {
            "user": "admin",
            "password": "secret"
        }
    },
    "features": ["feature1", "feature2"]
}

# 创建环境特定配置

dev_config["database"]["host"] = "dev-server"

prod_config = copy.deepcopy(DEFAULT_CONFIG)

# 默认配置保持不变
print(DEFAULT_CONFIG["database"]["host"])  # localhost

    3. 游戏状态保存¶

    import copy

class GameState:
    def __init__(self):
        self.player = {"hp": 100, "inventory": ["sword", "potion"]}
        self.enemies = [{"hp": 50}, {"hp": 75}]
        self.level = 1

    def save(self):
        """保存当前状态（深拷贝）"""
        return copy.deepcopy(self.__dict__)

    def load(self, saved_state):
        """恢复状态"""
        self.__dict__ = copy.deepcopy(saved_state)

# 使用
game = GameState()
saved = game.save()

# 玩游戏...
game.player["hp"] = 50
game.player["inventory"].append("shield")

# 读档
game.load(saved)
print(game.player["hp"])  # 100  ← 恢复到保存时的状态

    4. 缓存结果¶

    import copy

class DataCache:
    def __init__(self):
        self._cache = {}

    def get(self, key):
        """返回缓存的深拷贝，防止外部修改"""
        if key in self._cache:
            return copy.deepcopy(self._cache[key])
        return None

    def set(self, key, value):
        """存储深拷贝，防止外部修改影响缓存"""
        self._cache[key] = copy.deepcopy(value)

# 使用
cache = DataCache()
data = {"users": [{"id": 1, "name": "Alice"}]}

cache.set("data", data)
data["users"][0]["name"] = "Bob"  # 修改原数据

cached = cache.get("data")
print(cached["users"][0]["name"])  # Alice  ← 缓存未受影响

    ⚡ 性能对比¶

    知识点： - ⚠️ 深拷贝要递归复制所有嵌套对象，数据量大时明显慢于浅拷贝 - 性能与安全性需权衡：能用浅拷贝解决就不要用深拷贝

    import copy
import time

# 大数据结构
large_list = [[i, i+1, i+2] for i in range(10000)]

# 浅拷贝
start = time.time()
shallow = large_list.copy()
print(f"浅拷贝耗时：{time.time() - start:.4f}秒")

# 深拷贝
start = time.time()
deep = copy.deepcopy(large_list)
print(f"深拷贝耗时：{time.time() - start:.4f}秒")

    典型输出： 

    浅拷贝耗时：0.0001秒
深拷贝耗时：0.0500秒  ← 慢约 500 倍！

    结论： - 浅拷贝非常快（只复制引用） - 深拷贝较慢（递归复制所有对象） - 只在需要时深拷贝

    ⚠️ 常见错误¶

    知识点： - ⚠️ 函数内直接修改传入的列表参数，会意外改动调用方数据，先 copy 再改 - ⚠️ 切片 [:] 和字典解包 {**d} 都只是浅拷贝，嵌套结构仍共享 - ⚠️ 对数字、字符串、纯不可变元组做 deepcopy 纯属浪费

    1. 误用赋值当复制¶

    # ❌ 错误
def add_item(items, item):
    items.append(item)
    return items

original = [1, 2, 3]
result = add_item(original, 4)
print(original)  # [1, 2, 3, 4]  ← 被意外修改！

# ✅ 正确
def add_item(items, item):
    result = items.copy()  # 或 copy.deepcopy(items)
    result.append(item)
    return result

    2. 切片不是深拷贝¶

    import copy

# ❌ 错误 - 切片只是浅拷贝
list1 = [1, 2, [3, 4]]
list2 = list1[:]
list2[2].append(5)
print(list1)  # [1, 2, [3, 4, 5]]  ← 被修改！

# ✅ 正确
list3 = copy.deepcopy(list1)

    3. 字典解包不是深拷贝¶

    import copy

# ❌ 错误
dict1 = {"a": [1, 2, 3]}
dict2 = {**dict1}
dict2["a"].append(4)
print(dict1)  # {'a': [1, 2, 3, 4]}  ← 被修改！

# ✅ 正确
dict3 = copy.deepcopy(dict1)

    4. 对不可变类型深拷贝（没必要）¶

    import copy

# 不可变类型不需要深拷贝
number = 42
copy_number = copy.deepcopy(number)  # 浪费！

string = "hello"
copy_string = copy.deepcopy(string)  # 浪费！

tuple_immutable = (1, 2, 3)
copy_tuple = copy.deepcopy(tuple_immutable)  # 浪费！

    📝 最佳实践¶

    知识点： - ⭐ 决策树：不复制→赋值；单层数据→浅拷贝；有嵌套→深拷贝 - 不可变类型（数字、字符串、纯元组）直接赋值即可 - 函数内修改输入前先拷贝；注意深拷贝的性能开销

    1. 默认用浅拷贝 - 如果只有一层数据
    2. 嵌套用深拷贝 - 有列表/字典嵌套时
    3. 不可变类型直接赋值 - 数字、字符串、元组
    4. 函数内修改前先拷贝 - 保护输入参数
    5. 注意性能 - 深拷贝在大数据时很慢

    快速决策树¶

    需要复制吗？
├── 否 → 直接赋值 (b = a)
└── 是 → 有嵌套对象吗？
    ├── 否 → 浅拷贝 (b = a.copy() / b = a[:])
    └── 是 → 深拷贝 (b = copy.deepcopy(a))

# 练习 2
def unique(items):
    """返回去重后的新列表，不修改原列表"""
    return list(set(items.copy()))

original = [1, 2, 2, 3, 3, 3]
result = unique(original)
print(original)  # [1, 2, 2, 3, 3, 3]  ← 未被修改
print(result)    # [1, 2, 3]

# 练习 3
import copy

class UndoManager:
    def __init__(self):
        self._history = []
        self._current = None

    def set(self, data):
        if self._current is not None:
            self._history.append(copy.deepcopy(self._current))
        self._current = copy.deepcopy(data)

    def undo(self):
        if self._history:
            self._current = self._history.pop()
        return copy.deepcopy(self._current)

# 使用
manager = UndoManager()
manager.set([1, 2, 3])
manager.set([1, 2, 3, 4])
manager.set([1, 2, 3, 4, 5])

print(manager.undo())  # [1, 2, 3, 4]
print(manager.undo())  # [1, 2, 3]

    本章小结¶

    核心知识点¶

    ✅ 赋值即引用：b = a 只是新引用，改一个两个都变，用 id() 验证
    ✅ 浅拷贝：copy()/[:]/list()/{d} 只复制第一层，嵌套对象仍共享
    ✅     深拷贝：copy.deepcopy() 递归复制所有层级，副本完全独立
    ✅     场景应用：函数保护原始数据、多环境配置、游戏存档快照
    ✅     决策树**：单层用浅拷贝，嵌套用深拷贝，不可变类型直接赋值
