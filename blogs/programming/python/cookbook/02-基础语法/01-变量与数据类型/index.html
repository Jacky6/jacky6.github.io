    2.1 变量与数据类型¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 变量本质 变量是带标签的盒子，赋值即创建，无需声明类型 ⭐⭐⭐
    2 命名规则 不能数字开头、不能有连字符、不能用关键字，推荐 snake_case ⭐⭐⭐
    3 int 整数 无大小限制，支持 0b/0o/0x 进制前缀 ⭐⭐⭐
    4 float 浮点数 存在精度问题，0.1+0.2≠0.3 ⭐⭐⭐⭐
    5 bool 布尔值 0、空字符串、空容器均为 False ⭐⭐⭐
    6 type()/isinstance() type() 查类型，isinstance() 检查类型更推荐 ⭐⭐⭐
    7 类型转换 显式 int()/float()/str()/bool()，混合运算自动隐式转换 ⭐⭐⭐⭐

    📦 什么是变量？¶

    变量是存储数据的容器，可以理解为带标签的盒子：

    知识点： - 变量是存储数据的容器（带标签的盒子），用 = 赋值创建 - Python 是动态类型语言：变量无需声明类型，赋值即定义

    # 创建一个变量
name = "Python"
age = 34

# 使用变量
print(name)  # 输出：Python
print(age)   # 输出：34

    🏷️ 变量命名规则¶

    知识点： - ⚠️ 非法命名：数字开头（123age）、含连字符（user-name）、使用关键字（class） - ⭐ 最佳实践：变量用 snake_case（user_name），常量全大写（MAX_SIZE） - 名称要有意义，避免 x、n 这类无意义命名

    ✅ 合法的变量名¶

    name = "Alice"
user_name = "Bob"      # 下划线分隔（推荐）
userName = "Charlie"   # 驼峰命名
_age = 25
age123 = 30

    ❌ 非法的变量名¶

    123age = 30      # 不能以数字开头
user-name = "A"  # 不能有连字符
class = "Math"   # 不能用关键字

    💡 命名最佳实践¶

    # 推荐：使用小写字母和下划线（snake_case）
user_name = "Alice"
total_count = 100

# 避免：无意义的名称
x = 10      # ❌ 不知道是什么
n = 5       # ❌ 不清楚含义

# 推荐：有意义的名称
age = 10
count = 5

# 常量：全大写
MAX_SIZE = 100
PI = 3.14159

    🔢 Python 的基本数据类型¶

    知识点： - int 无大小限制，支持 0b 二进制、0o 八进制、0x 十六进制字面量 - ⚠️ float 有精度问题：0.1 + 0.2 = 0.30000000000000004 - bool 真值测试：0、""、[]、{} 等空值为 False，其余为 True - str 用单/双/三引号创建，三引号支持多行，\n \t 等为转义字符

    1. 整数（int）¶

    表示整数，没有大小限制：

    # 整数
age = 25
count = -10
big_number = 1000000000000000000000  # Python 整数可以很大！

# 不同进制
decimal = 10      # 十进制
binary = 0b1010   # 二进制 = 10
octal = 0o12      # 八进制 = 10
hexadecimal = 0xA # 十六进制 = 10

print(type(age))  # <class 'int'>

    2. 浮点数（float）¶

    表示小数：

    # 浮点数
price = 19.99
pi = 3.14159
negative = -0.5

# 科学计数法
avogadro = 6.022e23  # 6.022 × 10^23
small = 1.6e-19      # 1.6 × 10^-19

print(type(price))  # <class 'float'>

# ⚠️ 浮点数精度问题
print(0.1 + 0.2)  # 0.30000000000000004 (不是 0.3!)

    3. 布尔值（bool）¶

    表示真或假：

    # 布尔值
is_active = True
is_deleted = False

# 布尔运算
print(True and False)   # False
print(True or False)    # True
print(not True)         # False

# 真值测试
print(bool(0))          # False
print(bool(1))          # True
print(bool(""))         # False (空字符串)
print(bool("hello"))    # True
print(bool([]))         # False (空列表)
print(bool([1, 2]))     # True

    4. 字符串（str）¶

    表示文本：

    # 字符串
name = "Python"
greeting = 'Hello, World!'

# 多行字符串
message = """
这是一段多行字符串
可以跨越多行
保留格式和换行
"""

# 转义字符
text = "He said, \"Hello!\""
newline = "Line 1\nLine 2"
tab = "Col1\tCol2"

print(type(name))  # <class 'str'>

    🔍 查看数据类型¶

    使用 type() 函数：

    知识点： - type() 返回对象的类型（如 ） - ⭐ isinstance() 检查类型更灵活：可传元组同时检查多种类型

    x = 10
y = 3.14
z = "hello"
b = True

print(type(x))  # <class 'int'>
print(type(y))  # <class 'float'>
print(type(z))  # <class 'str'>
print(type(b))  # <class 'bool'>

    使用 isinstance() 检查类型：

    age = 25

print(isinstance(age, int))    # True
print(isinstance(age, float))  # False
print(isinstance(age, str))    # False

# 检查多种类型
print(isinstance(age, (int, float)))  # True

    🔄 类型转换¶

    知识点： - 显式转换：int() 截断小数、float()、str()、bool() - ⚠️ int(True)=1、int(False)=0；bool("")=False、bool(0)=False - 隐式转换：整数+浮点数得浮点数，/ 真除得 float，// 整除得 int

    显式转换¶

    # 转换为整数
int("123")      # 123
int(3.14)       # 3 (截断小数)
int(True)       # 1
int(False)      # 0

# 转换为浮点数
float("3.14")   # 3.14
float(10)       # 10.0

# 转换为字符串
str(123)        # "123"
str(3.14)       # "3.14"
str(True)       # "True"

# 转换为布尔值
bool(1)         # True
bool(0)         # False
bool("")        # False
bool("hello")   # True

    隐式转换¶

    Python 会自动在某些情况下转换类型：

    # 整数 + 浮点数 = 浮点数
result = 10 + 3.14  # 13.14 (float)

# 整数除法 = 浮点数
result = 10 / 3     # 3.333... (float)

# 整数整除 = 整数
result = 10 // 3    # 3 (int)

    📊 实际例子¶

    知识点： - 综合演练：不同类型变量参与计算并用 f-string 输出 - 三元表达式 '是' if is_student else '否' 可嵌入 f-string

    # 用户信息
user_name = "Alice"
user_age = 25
user_height = 1.65  # 米
is_student = True

# 计算
birth_year = 2026 - user_age
height_cm = user_height * 100

# 输出
print(f"姓名：{user_name}")
print(f"年龄：{user_age} 岁")
print(f"身高：{height_cm} 厘米")
print(f"学生：{'是' if is_student else '否'}")
print(f"出生年份：约 {birth_year} 年")

    ⚠️ 常见错误¶

    知识点： - ⚠️ TypeError：字符串不能与整数直接 + 拼接，用 str() 转换或 f-string - NameError：变量未定义先使用；SyntaxError：变量名与关键字冲突

    1. 类型错误¶

    # ❌ 错误
age = 25
print("我今年" + age + "岁")  # TypeError

# ✅ 正确
print("我今年" + str(age) + "岁")
print(f"我今年{age}岁")  # 推荐

    2. 未定义变量¶

    # ❌ 错误
print(x)  # NameError: name 'x' is not defined

# ✅ 正确
x = 10
print(x)

    3. 关键字冲突¶

    # ❌ 错误
class = "Math"  # SyntaxError: class 是关键字

# ✅ 正确
class_name = "Math"

    本章小结¶

    核心知识点¶

    ✅ 变量：动态类型，赋值即创建，命名用 snake_case、常量全大写
    ✅ 四大基本类型：int 无上限、float 有精度问题、bool 空值为假、str 不可变
    ✅ 类型检查：type() 查类型，isinstance() 支持多类型判断
    ✅ 类型转换：int/float/str/bool 显式转换，混合运算自动隐式转换
    ✅ 常见坑：str+int 报 TypeError、浮点精度、关键字不能作变量名
