    📝 字符串基础¶

    字符串是用来表示文本的数据类型，在 Python 中用引号包围：

    知识点：

    • 单引号和双引号完全等价，可互相包含对方（"It's"、'He said "Hi"'）
    • 三引号（"""..."""）用于多行字符串，保留换行格式
    # 单引号
name = 'Alice'

# 双引号
greeting = "Hello"

# 单双引号等价，可以混用
text1 = "It's a beautiful day"  # 包含单引号
text2 = 'He said "Hi"'          # 包含双引号

# 三引号 - 多行字符串
poem = """
床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。
"""

    🔧 字符串操作¶

    知识点：

      • 拼接、* 重复；索引从 0 开始，负数从末尾倒数
    • ⭐ 切片 s[start:end:step] 不含 end，s[::-1] 反转字符串
    • ⭐ 高频方法：strip 去空白、upper/lower 大小写、find 找不到返回 -1、replace 替换、split 分割、join 连接
    • isalpha/isdigit/startswith/endswith 等内容判断方法返回布尔值

    拼接和重复¶

    # 拼接
first = "Hello"
second = "World"
result = first + ", " + second + "!"
print(result)  # Hello, World!

# 重复
line = "-" * 20
print(line)  # --------------------

pattern = "ab" * 3
print(pattern)  # ababab

    索引和切片¶

    text = "Python"

# 索引（从 0 开始）
print(text[0])    # P
print(text[1])    # y
print(text[-1])   # n (负数从末尾开始)
print(text[-2])   # o

# 切片 [start:end:step]
print(text[0:3])    # Pyt (不包含 end)
print(text[:3])     # Pyt (从头开始)
print(text[3:])     # hon (到末尾)
print(text[1:5])    # ytho
print(text[:])      # Python (完整拷贝)

# 步长
print(text[::2])    # Pto (每隔一个)
print(text[::-1])   # nohtyP (反转字符串)

# 负数切片
print(text[-3:])    # hon
print(text[:-3])    # Pyt

    常用字符串方法¶

    text = "  Hello, World!  "

# 去除空白
print(text.strip())    # "Hello, World!"
print(text.lstrip())   # 去除左边空白
print(text.rstrip())   # 去除右边空白

# 大小写转换
name = "alice"
print(name.upper())     # ALICE
print(name.lower())     # alice
print(name.capitalize())  # Alice
print(name.title())     # Alice (每个单词首字母大写)

# 查找
message = "Hello, World!"
print(message.find("World"))   # 7 (位置)
print(message.find("Python"))  # -1 (未找到)
print(message.index("World"))  # 7 (未找到时抛出异常)
print("World" in message)      # True

# 替换
text = "I like cats"
print(text.replace("cats", "dogs"))  # "I like dogs"
print(text.replace("l", "L", 1))     # "I Like cats" (只替换 1 次)

# 分割和连接
csv = "apple,banana,orange"
fruits = csv.split(",")
print(fruits)  # ['apple', 'banana', 'orange']

text = "one-two-three"
parts = text.split("-")
print(parts)  # ['one', 'two', 'three']

# 连接
words = ["Hello", "World", "Python"]
result = " ".join(words)
print(result)  # "Hello World Python"

path = "/".join(["home", "user", "docs"])
print(path)  # "home/user/docs"

    字符串判断¶

    text = "Hello123"

# 检查内容
print(text.isalpha())    # False (包含数字)
print(text.isdigit())    # False (包含字母)
print(text.isalnum())    # True (字母或数字)
print(text.isspace())    # False (不是空白)

# 检查大小写
print("HELLO".isupper())   # True
print("hello".islower())   # True
print("Hello".istitle())   # True

# 检查开头结尾
url = "https://example.com"
print(url.startswith("https"))  # True
print(url.endswith(".com"))     # True

    🎨 字符串格式化¶

    知识点：

    • ⭐ f-string（3.6+）是推荐方式：{表达式}、{pi:.2f} 保留小数、{name:>10} 对齐、{num:,} 千分位、{rate:.1%} 百分比
    • format() 支持位置/索引/命名参数，% 格式化是旧式写法不推荐
    • ⚠️ 忘写 f 前缀时 "{name}" 会原样输出

    方法 1: f-string（推荐 ⭐）¶

    Python 3.6+ 最现代的格式化方式：

    name = "Alice"
age = 25
height = 1.65

# 基本用法
print(f"My name is {name}")
print(f"I am {age} years old")

# 表达式
print(f"Next year I will be {age + 1}")

# 格式化数字
pi = 3.1415926535
print(f"Pi: {pi:.2f}")      # 3.14 (保留 2 位小数)
print(f"Pi: {pi:.4f}")      # 3.1416

# 对齐
print(f"{name:>10}")        # "     Alice" (右对齐)
print(f"{name:<10}")        # "Alice     " (左对齐)
print(f"{name:^10}")        # "  Alice   " (居中)

# 填充
print(f"{name:*^10}")       # "**Alice***"

# 千位分隔
num = 1000000
print(f"{num:,}")           # 1,000,000

# 百分比
rate = 0.876
print(f"{rate:.1%}")        # 87.6%

# 十六进制
num = 255
print(f"{num:x}")           # ff
print(f"{num:X}")           # FF
print(f"{num:#x}")          # 0xff

    方法 2: format()¶

    name = "Alice"
age = 25

# 位置参数
print("My name is {}, I am {}".format(name, age))

# 索引
print("My name is {0}, I am {1}".format(name, age))
print("I am {1}, my name is {0}".format(name, age))

# 命名参数
print("My name is {name}, I am {age}".format(name="Alice", age=25))

# 格式化
print("Pi: {:.2f}".format(3.14159))
print("{:*^20}".format("centered"))

    方法 3: % 格式化（旧式，不推荐）¶

    name = "Alice"
age = 25
pi = 3.14159

print("My name is %s" % name)
print("I am %d years old" % age)
print("Pi is %.2f" % pi)
print("Name: %s, Age: %d" % (name, age))

    🔍 转义字符¶

    知识点：

    • 常用转义：\n 换行、\t 制表符、\" \' 引号、\ 反斜杠
    • ⭐ 原始字符串 r"..." 不处理转义，Windows 路径和正则表达式必用
    # 常见转义字符
text1 = "He said, \"Hello!\""   # 双引号
text2 = 'It\'s a test'           # 单引号
text3 = "Line 1\nLine 2"         # 换行
text4 = "Col1\tCol2"             # 制表符
text5 = "C:\\Users\\docs"        # 反斜杠
text6 = "Hello\rWorld"           # 回车

print(text3)
# 输出:
# Line 1
# Line 2

# 原始字符串（不转义）
path = r"C:\Users\Documents"
print(path)  # C:\Users\Documents

regex = r"\d+\.\d+"  # 正则表达式常用

    📊 字符串编码¶

    知识点：

    • Python 字符串是 Unicode，天然支持中文和 emoji
    • encode('utf-8') 编码为字节，decode('utf-8') 解码回字符串
    • ord() 字符转 Unicode 码点，chr() 反向转换
    # Unicode 字符串
chinese = "你好，世界"
emoji = "🐍🎉"

# 编码和解码
text = "Hello"
encoded = text.encode('utf-8')     # 字节
decoded = encoded.decode('utf-8')  # 字符串

# 字符和 Unicode 码
char = 'A'
code = ord(char)      # 65
back = chr(code)      # 'A'

# 中文
print(ord('中'))      # 20013
print(chr(20013))     # '中'

    🎯 实用例子¶

    知识点：

    • 综合运用：endswith 校验邮箱、split+sum 统计文本、strip+lower+replace 清理文本
    • ⭐ 切片脱敏：phone[:3] + "****" + phone[7:] 隐藏手机号中间 4 位

    1. 验证邮箱格式¶

    def is_valid_email(email):
    if "@" not in email:
        return False
    if not email.endswith((".com", ".cn", ".org", ".net")):
        return False
    return True

print(is_valid_email("test@example.com"))  # True
print(is_valid_email("invalid"))           # False

    2. 统计文本信息¶

    text = "Hello, World! Python is awesome."

print(f"长度：{len(text)}")
print(f"单词数：{len(text.split())}")
print(f"大写字母：{sum(1 for c in text if c.isupper())}")
print(f"小写字母：{sum(1 for c in text if c.islower())}")
print(f"数字：{sum(1 for c in text if c.isdigit())}")

    3. 文本清理¶

    def clean_text(text):
    # 去除空白
    text = text.strip()
    # 转小写
    text = text.lower()
    # 移除标点
    for char in ".,!?;:":
        text = text.replace(char, "")
    return text

print(clean_text("  Hello, World!  "))  # "hello world"

    4. 敏感信息脱敏¶

    def mask_phone(phone):
    """将手机号中间 4 位替换为 *"""
    if len(phone) == 11:
        return phone[:3] + "****" + phone[7:]
    return phone

print(mask_phone("13812345678"))  # 138****5678

    ⚠️ 常见错误¶

    知识点：

    • ⚠️ 字符串不可变：text[0] = "H" 报 TypeError，需创建新字符串
    • ⚠️ 引号不匹配导致 SyntaxError
    • ⚠️ f-string 忘写 f 前缀，{name} 原样输出

    1. 字符串不可变¶

    # ❌ 错误
text = "hello"
text[0] = "H"  # TypeError: 'str' object does not support item assignment

# ✅ 正确
text = "hello"
text = "H" + text[1:]  # 创建新字符串

    2. 引号不匹配¶

    # ❌ 错误
text = "Hello'  # SyntaxError

# ✅ 正确
text = "Hello"
text = 'Hello'
text = """Hello"""

    3. 忘记 f-string 的 f¶

    name = "Alice"

# ❌ 错误
print("{name}")  # 输出：{name}

# ✅ 正确
print(f"{name}")  # 输出：Alice

    3. 将 "hello_world" 转换为 "HelloWorld"（驼峰命名）

    示例答案： 

    # 练习 1
text = "Hello, World!"
print(text[::-1])  # !dlroW ,olleH

# 练习 4
def is_palindrome(s):
    return s == s[::-1]

print(is_palindrome("level"))   # True
print(is_palindrome("hello"))   # False

    本章小结¶

    核心知识点¶

    ✅ 引号规则：单双引号等价，三引号写多行
    ✅ 切片：s[::-1] 反转，切片不含 end 索引
    ✅ 格式化首选 f-string：支持表达式、对齐、千分位、百分比
    ✅ 原始字符串：r"..." 不转义，路径和正则必用
    ✅ 不可变性：字符串元素不能修改，只能生成新字符串
