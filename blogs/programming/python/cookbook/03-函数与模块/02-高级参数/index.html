    3.2 高级参数¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 位置/关键字参数 按位置或按名称传参，位置参数须在前 ⭐⭐⭐⭐
    2 默认参数 有默认值可省略，⚠️禁用可变对象作默认值 ⭐⭐⭐⭐
    3 *args 收集任意数量位置参数为元组 ⭐⭐⭐⭐
    4 **kwargs 收集任意数量关键字参数为字典 ⭐⭐⭐⭐
    5 仅限位置参数 / Python 3.8+，/ 之前的参数只能按位置传 ⭐⭐⭐
    6 仅限关键字参数 * * 之后的参数只能按关键字传 ⭐⭐⭐
    7 参数解包 *列表 解包位置参数、**字典 解包关键字参数 ⭐⭐⭐
    8 参数声明顺序 位置 → 默认 → args → 仅限关键字 → *kwargs ⭐⭐⭐⭐

    📦 参数类型¶

    Python 函数支持多种参数类型：

    知识点： - 完整签名顺序：/ 前仅限位置 → 标准参数 → *args → 仅限关键字 → **kwargs - ⭐面试重点：能写出并解释完整参数声明顺序

    def func(positional, /, standard, *args, keyword, **kwargs):
    pass

    🔢 位置参数和关键字参数¶

    知识点： - 位置参数按顺序传；关键字参数按名称传，可不按顺序 - 位置参数必须写在关键字参数之前 - ⚠️易错点：关键字在位置之前会 SyntaxError

    def greet(first_name, last_name):
    return f"Hello, {first_name} {last_name}!"

# 位置参数
print(greet("Alice", "Smith"))  # Hello, Alice Smith!

# 关键字参数
print(greet(first_name="Bob", last_name="Jones"))  # Hello, Bob Jones!

# 混合使用
print(greet("Charlie", last_name="Brown"))  # Hello, Charlie Brown!

# ❌ 错误：位置参数必须在关键字参数之前
# greet(first_name="David", "Wilson")  # SyntaxError

    📋 默认参数¶

    知识点： - 默认参数在定义时给出默认值，调用时可省略 - 可用关键字参数只覆盖部分默认值 - ⚠️易错点（⭐面试高频）：可变默认参数会被多次调用共享，应使用 None 哨兵

    def greet(name, greeting="Hello", punctuation="!"):
    return f"{greeting}, {name}{punctuation}"

print(greet("Alice"))              # Hello, Alice!
print(greet("Bob", "Hi"))          # Hi, Bob!
print(greet("Charlie", "Hey", "?"))  # Hey, Charlie?

# 只覆盖部分默认值
print(greet("David", punctuation="."))  # Hello, David.

    ⚠️ 可变默认参数陷阱¶

    # ❌ 错误
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item(1))  # [1]
print(add_item(2))  # [1, 2] - 共享了同一个列表!

# ✅ 正确
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item(1))  # [1]
print(add_item(2))  # [2] - 独立的列表

    ⭐ *args - 可变位置参数¶

    接收任意数量的位置参数：

    知识点： - *args 收集任意数量的位置参数，函数内是元组 - 可与普通参数组合，普通参数在前 - ⭐面试重点：args 的类型是 tuple

    def sum_all(*args):
    """计算所有参数的和"""
    return sum(args)

print(sum_all(1, 2, 3))        # 6
print(sum_all(1, 2, 3, 4, 5))  # 15

# args 是元组
def print_args(*args):
    print(f"类型：{type(args)}")
    print(f"内容：{args}")

print_args(1, 2, 3)
# 类型：<class 'tuple'>
# 内容：(1, 2, 3)

# 与其他参数组合
def greet(greeting, *names):
    for name in names:
        print(f"{greeting}, {name}!")

greet("Hello", "Alice", "Bob", "Charlie")
# Hello, Alice!
# Hello, Bob!
# Hello, Charlie!

    🔑 **kwargs - 可变关键字参数¶

    接收任意数量的关键字参数：

    知识点： - **kwargs 收集任意数量的关键字参数，函数内是字典 - ⭐面试重点：kwargs 的类型是 dict，用 .items() 遍历

    def print_info(**kwargs):
    """打印所有关键字参数"""
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=25, city="Beijing")
# name: Alice
# age: 25
# city: Beijing

# kwargs 是字典
def create_user(**kwargs):
    return kwargs

user = create_user(name="Bob", age=30)
print(user)  # {'name': 'Bob', 'age': 30}
print(type(user))  # <class 'dict'>

    🎯 组合所有参数类型¶

    知识点： - 声明顺序固定：仅限位置 → 标准 → args → 仅限关键字 → *kwargs - / 之前仅限位置（Python 3.8+）；* 之后仅限关键字 - ⭐面试重点：解释 def f(a, b, /, c, *args, d, **kwargs) 各段含义 - ⚠️易错点：仅限位置参数用关键字传递会 TypeError

    def complex_func(pos1, pos2, /, standard1, standard2="default", 
                 *args, keyword1, keyword2="kw_default", **kwargs):
    """
    pos1, pos2: 仅限位置参数
    standard1, standard2: 标准参数
    *args: 可变位置参数
    keyword1, keyword2: 仅限关键字参数
    **kwargs: 可变关键字参数
    """
    print(f"位置参数：{pos1}, {pos2}")
    print(f"标准参数：{standard1}, {standard2}")
    print(f"可变位置：{args}")
    print(f"仅限关键字：{keyword1}, {keyword2}")
    print(f"可变关键字：{kwargs}")

complex_func(1, 2, "std1", "std2", "extra1", "extra2",
             keyword1="kw1", keyword2="kw2", extra_kw="value")

    仅限位置参数（Python 3.8+）¶

    def divide(a, b, /):
    """a 和 b 只能作为位置参数"""
    return a / b

print(divide(10, 2))      # 5.0
# divide(a=10, b=2)       # ❌ TypeError

    仅限关键字参数¶

    def create_user(*, name, age, city="Beijing"):
    """所有参数只能作为关键字参数"""
    return {"name": name, "age": age, "city": city}

user = create_user(name="Alice", age=25)
print(user)  # {'name': 'Alice', 'age': 25, 'city': 'Beijing'}

# create_user("Alice", 25)  # ❌ TypeError

    📦 参数解包¶

    列表/元组解包¶

    知识点： - *列表/元组 解包为位置参数 - **字典 解包为关键字参数 - 两者可混合使用 - ⚠️易错点：解包出的参数个数/名称必须与函数签名匹配

    def add(a, b, c):
    return a + b + c

numbers = [1, 2, 3]
print(add(*numbers))  # 6 (等价于 add(1, 2, 3))

# 混合使用
def greet(greeting, name, punctuation):
    return f"{greeting}, {name}{punctuation}"

args = ["Hello", "Alice"]
print(greet(*args, "!"))  # Hello, Alice!

    字典解包¶

    def create_user(name, age, city):
    return {"name": name, "age": age, "city": city}

user_data = {"name": "Bob", "age": 30, "city": "Shanghai"}
user = create_user(**user_data)
print(user)  # {'name': 'Bob', 'age': 30, 'city': 'Shanghai'}

# 混合使用
def func(a, b, c, d):
    return a + b + c + d

args = [1, 2]
kwargs = {"c": 3, "d": 4}
print(func(*args, **kwargs))  # 10

    🎯 实用例子¶

    1. 灵活的打印函数¶

    知识点： - *args + 默认参数可实现灵活的自定义 print - dict.copy() + update(**kwargs) 实现配置覆盖 - 装饰器用 wrapper(*args, **kwargs) 透传任意参数 - ⭐面试重点：装饰器内层函数的签名要能接收任意参数

    def print_formatted(*args, separator=" ", end="\n", prefix=""):
    """自定义打印函数"""
    output = prefix + separator.join(str(arg) for arg in args)
    print(output, end=end)

print_formatted("Hello", "World", prefix=">>> ")
# >>> Hello World

print_formatted(1, 2, 3, separator="-", end="!\n")
# 1-2-3!

    2. 配置函数¶

    def create_config(defaults, **overrides):
    """创建配置，覆盖默认值"""
    config = defaults.copy()
    config.update(overrides)
    return config

default_db_config = {
    "host": "localhost",
    "port": 5432,
    "user": "admin",
    "password": "secret"
}

config = create_config(default_db_config, port=3306, user="root")
print(config)
# {'host': 'localhost', 'port': 3306, 'user': 'root', 'password': 'secret'}

    3. 函数装饰器基础¶

    def timer(func):
    """简单的计时装饰器"""
    import time
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__} 耗时：{end - start:.4f}秒")
        return result
    return wrapper

@timer
def slow_function():
    time.sleep(1)

# slow_function()  # 会打印耗时

    4. 参数验证¶

    def validate_positive(func):
    """验证所有数值参数为正数"""
    def wrapper(*args, **kwargs):
        all_args = args + tuple(kwargs.values())
        for arg in all_args:
            if isinstance(arg, (int, float)) and arg <= 0:
                raise ValueError("所有数值参数必须为正数")
        return func(*args, **kwargs)
    return wrapper

@validate_positive
def calculate_area(width, height):
    return width * height

print(calculate_area(5, 10))  # 50
# calculate_area(-5, 10)  # ValueError!

    📊 参数类型总结¶

    语法 名称 说明
    param 位置参数 按位置传递
    param=value 默认参数 有默认值
    *args 可变位置 接收额外位置参数
    **kwargs 可变关键字 接收额外关键字参数
    param, / 仅限位置 只能按位置传递
    *, param 仅限关键字 只能按关键字传递

    ⚠️ 常见错误¶

    1. 参数顺序¶

    知识点： - ⚠️默认参数不能写在非默认参数之前（SyntaxError） - ⚠️同一参数不能既按位置又按关键字传值（TypeError） - ⚠️可变默认参数陷阱：默认列表/字典在多次调用间共享 - ⭐面试高频：用 to=None 哨兵修复可变默认参数

    # ❌ 错误
def func(a=1, b):  # SyntaxError: 默认参数不能在非默认参数之前
    pass

# ✅ 正确
def func(b, a=1):
    pass

    2. 重复参数¶

    def func(a, b):
    pass

# ❌ 错误
# func(1, a=2)  # TypeError: got multiple values for 'a'

    3. 可变默认参数（再次强调）¶

    # ❌ 错误
def append_to(element, to=[]):
    to.append(element)
    return to

# ✅ 正确
def append_to(element, to=None):
    if to is None:
        to = []
    to.append(element)
    return to

    📝 练习题¶

    1. 编写函数，接受任意数量的数字并返回平均值
    2. 编写函数，接受任意数量的关键字参数并返回格式化字符串
    3. 编写函数，同时接受位置参数和关键字参数，合并后返回
    4. 实现一个函数，可以链式调用：add(1)(2)(3)() 返回 6

    示例答案： 

    # 练习 1
def average(*numbers):
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)

print(average(1, 2, 3, 4, 5))  # 3.0

# 练习 2
def format_info(**kwargs):
    return ", ".join(f"{k}={v}" for k, v in kwargs.items())

print(format_info(name="Alice", age=25))  # name=Alice, age=25

# 练习 4
def add(value=0):
    values = [value]
    def inner(next_value=None):
        if next_value is None:
            return sum(values)
        values.append(next_value)
        return inner
    return inner

print(add(1)(2)(3)())  # 6

    本章小结¶

    核心知识点¶

    ✅ 六种参数形式：位置、默认、args、kwargs、仅限位置（/）、仅限关键字（） ✅ args 是元组，kwargs 是字典，二者可组合接收任意参数 ✅ 声明顺序固定：位置 → 默认 → args → 仅限关键字 → **kwargs ✅ 参数解包：*列表 传位置参数、**字典 传关键字参数，可混用 ✅ 调用规则：位置参数在前，关键字参数在后；同一参数不可重复传值 ✅ 高频陷阱：可变默认参数共享问题，用 None 哨兵解决
