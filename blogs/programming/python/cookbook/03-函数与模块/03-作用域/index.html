    3.3 作用域¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 LEGB 规则 变量查找顺序：局部 → 外层 → 全局 → 内置 ⭐⭐⭐⭐
    2 局部作用域 函数内定义的变量只在函数内可见 ⭐⭐⭐
    3 全局作用域 模块级变量，函数内可读 ⭐⭐⭐
    4 global 关键字 在函数内修改全局变量必须先声明 ⭐⭐⭐⭐
    5 nonlocal 关键字 在嵌套函数内修改外层函数变量 ⭐⭐⭐⭐
    6 闭包 内层函数携带外层变量，可保持独立状态 ⭐⭐⭐⭐
    7 闭包循环变量陷阱 闭包延迟绑定，循环中捕获变量需用默认参数 ⭐⭐⭐

    📍 什么是作用域？¶

    作用域是变量可访问的区域。Python 有四种作用域（LEGB 规则）：

    知识点： - 作用域是变量可访问的区域 - Python 有四种作用域：Local、Enclosing、Global、Built-in（LEGB） - ⭐面试重点：说出 LEGB 四个字母的含义和查找顺序

    L - Local: 函数内部
E - Enclosing: 外层函数
G - Global: 模块级别
B - Built-in: 内置作用域

    🏠 作用域类型¶

    1. 局部作用域（Local）¶

    函数内部定义的变量：

    知识点： - 局部变量只在函数内可见，外部访问报 NameError - 函数内可以读取全局变量 - 内置名称（len、sum 等）位于 builtins 模块 - ⚠️易错点：不要用变量名覆盖内置名称（如 list、str）

    def my_function():
    x = 10  # 局部变量
    print(x)

my_function()  # 10
# print(x)  # ❌ NameError: x 不在作用域内

    2. 全局作用域（Global）¶

    模块级别定义的变量：

    x = 100  # 全局变量

def my_function():
    print(x)  # 可以访问全局变量

my_function()  # 100
print(x)  # 100

    3. 内置作用域（Built-in）¶

    Python 内置的名称：

    print(len([1, 2, 3]))  # len 是内置函数
print(sum([1, 2, 3]))  # sum 是内置函数

# 查看内置名称
import builtins
print(dir(builtins))

    🔍 LEGB 规则¶

    Python 按以下顺序查找变量：

    知识点： - 变量查找顺序：Local → Enclosing → Global → Built-in - 找到即停止；都找不到报 NameError - ⭐面试重点：嵌套函数中变量按 LEGB 逐层向外查找

    x = "global"

def outer():
    x = "enclosing"

    def inner():
        x = "local"
        print(x)

    inner()

outer()  # local
print(x)  # global

    查找示例¶

    x = "global"

def outer():
    x = "enclosing"

    def inner():
        print(x)  # 找不到 local，找 enclosing

    inner()

outer()  # enclosing

    x = "global"

def outer():
    # 没有 x

    def inner():
        # 没有 x
        print(x)  # 找不到 local 和 enclosing，找 global

    inner()

outer()  # global

    🔄 global 关键字¶

    在函数内修改全局变量：

    知识点： - 函数内给变量赋值默认创建局部变量 - 修改全局变量需先 global x 声明 - ⚠️易错点：不声明就 count = count + 1 会 UnboundLocalError

    count = 0

def increment():
    global count  # 声明使用全局变量
    count += 1

increment()
print(count)  # 1

increment()
print(count)  # 2

    ⚠️ 不使用 global 的问题¶

    count = 0

def increment():
    # ❌ 错误：会创建新的局部变量
    count = count + 1  # UnboundLocalError

# ✅ 正确
def increment():
    global count
    count += 1

    📦 nonlocal 关键字¶

    在嵌套函数中修改外层函数的变量：

    知识点： - 在嵌套函数中修改外层函数变量需 nonlocal 声明 - ⭐面试重点：闭包（closure）= 内层函数 + 携带的外层变量 - 每次调用工厂函数都会创建独立的状态（如独立计数器）

    def outer():
    count = 0

    def inner():
        nonlocal count  # 声明使用外层变量
        count += 1
        print(count)

    return inner

counter = outer()
counter()  # 1
counter()  # 2
counter()  # 3

    实际应用：闭包¶

    def make_counter():
    """创建计数器"""
    count = 0

    def increment():
        nonlocal count
        count += 1
        return count

    return increment

counter1 = make_counter()
counter2 = make_counter()

print(counter1())  # 1
print(counter1())  # 2
print(counter2())  # 1 (独立的计数器)
print(counter1())  # 3

    🎯 实际例子¶

    1. 配置管理¶

    知识点： - 闭包典型应用：缓存、函数工厂、状态保持（累加器） - 全局配置字典可在函数间共享，但应谨慎使用 - ⭐面试重点：用闭包实现带私有状态的函数，替代类

    # 全局配置
config = {
    "debug": False,
    "version": "1.0.0"
}

def set_debug(value):
    """修改全局配置"""
    global config
    config["debug"] = value

def get_config():
    return config

set_debug(True)
print(get_config())  # {'debug': True, 'version': '1.0.0'}

    2. 缓存¶

    def make_cache():
    """创建带缓存的函数"""
    cache = {}

    def get_or_compute(key, compute_func):
        if key not in cache:
            cache[key] = compute_func()
        return cache[key]

    return get_or_compute

cache = make_cache()

def expensive_operation():
    print("计算中...")
    return 42

print(cache("result", expensive_operation))  # 计算中... 42
print(cache("result", expensive_operation))  # 42 (从缓存)

    3. 函数工厂¶

    def make_multiplier(factor):
    """创建乘法器"""
    def multiply(x):
        return x * factor
    return multiply

double = make_multiplier(2)
triple = make_multiplier(3)

print(double(5))  # 10
print(triple(5))  # 15

    4. 状态保持¶

    def make_accumulator():
    """创建累加器"""
    total = 0

    def add(value):
        nonlocal total
        total += value
        return total

    def get_total():
        return total

    def reset():
        nonlocal total
        total = 0

    return add, get_total, reset

add, get_total, reset = make_accumulator()

print(add(10))    # 10
print(add(20))    # 30
print(get_total())  # 30
reset()
print(get_total())  # 0

    📊 作用域最佳实践¶

    ✅ 推荐做法¶

    知识点： - 优先使用局部变量和参数传递，避免依赖全局变量 - 需要封装状态时优先用类 - ⚠️避免：过度使用全局变量、覆盖内置名称、深层嵌套

    # 1. 优先使用局部变量
def calculate_total(items):
    total = 0  # 局部变量
    for item in items:
        total += item
    return total

# 2. 使用参数传递，避免全局变量
def process_data(data, config):
    # 使用传入的配置
    pass

# 3. 使用类封装状态
class Counter:
    def __init__(self):
        self.count = 0

    def increment(self):
        self.count += 1

    ❌ 避免的做法¶

    # 1. 过度使用全局变量
global_data = {}  # 不推荐

def modify_data():
    global global_data
    global_data["key"] = "value"

# 2. 隐藏内置名称
list = [1, 2, 3]  # 覆盖了内置的 list
str = "hello"     # 覆盖了内置的 str

# 3. 深层嵌套
def level1():
    x = 1
    def level2():
        def level3():
            def level4():
                nonlocal x  # 难以追踪

    ⚠️ 常见错误¶

    1. 意外创建局部变量¶

    知识点： - ⚠️函数内先读后赋值同一变量：整个函数中该变量都被视为局部变量（UnboundLocalError） - ⚠️多个函数修改同一全局可变对象，状态难以追踪 - ⚠️闭包延迟绑定：循环中创建的闭包共享循环变量，用默认参数 x=i 捕获当前值 - ⭐面试高频：解释为什么循环闭包输出全是最后一个值

    x = 10

def func():
    print(x)  # 可以访问
    x = 20    # 创建局部变量，影响上面的 print!
    print(x)

# func()  # UnboundLocalError

    2. 可变对象的全局状态¶

    # ❌ 危险
shared_list = []

def add_item(item):
    shared_list.append(item)

# 多个函数修改同一个全局列表，难以追踪

# ✅ 更好
class ItemManager:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    3. 闭包中的循环变量¶

    # ❌ 错误
functions = []
for i in range(3):
    def func():
        return i
    functions.append(func)

print([f() for f in functions])  # [2, 2, 2] - 都是 2!

# ✅ 正确
functions = []
for i in range(3):
    def func(x=i):  # 捕获当前值
        return x
    functions.append(func)

print([f() for f in functions])  # [0, 1, 2]

    示例答案： 

    # 练习 1
def make_counter():
    count = 0
    def increment():
        nonlocal count
        count += 1
        return count
    return increment

counter = make_counter()
print(counter())  # 1
print(counter())  # 2

# 练习 4 - 修复
x = 10
def func():
    global x  # 声明使用全局变量
    print(x)
    x = 20

func()
print(x)  # 20

    本章小结¶

    核心知识点¶

    ✅ LEGB 规则：变量按 局部 → 外层 → 全局 → 内置 顺序查找 ✅ global：在函数内修改全局变量必须先声明 ✅ nonlocal：在嵌套函数内修改外层函数变量 ✅ 闭包：内层函数携带外层变量，可实现缓存、工厂、状态保持 ✅ 赋值即局部：函数内给变量赋值会使整个函数中该变量成为局部变量 ✅ 闭包循环陷阱：循环中创建闭包用默认参数捕获当前值
