    📦 什么是函数？¶

    函数是一段可重复使用的代码块，用于执行特定任务。

    知识点： - 函数是可重复使用的代码块，用 def 定义、用函数名加括号调用 - 先定义后调用，定义时不执行函数体 - ⭐面试重点：函数是 Python 的一等公民对象

    # 定义函数
def greet():
    print("Hello, World!")

# 调用函数
greet()  # Hello, World!

    🔧 函数定义语法¶

    知识点： - 语法：def 函数名(参数): + 缩进函数体 - 文档字符串放在函数体首行，描述函数功能 - 参数按位置绑定，调用时按顺序传值 - ⚠️易错点：函数体必须缩进，否则 IndentationError

    def function_name(parameters):
    """文档字符串 - 描述函数功能"""
    # 函数体
    return value  # 可选

    示例¶

    def say_hello(name):
    """向指定的人打招呼"""
    print(f"Hello, {name}!")

say_hello("Alice")  # Hello, Alice!

    📤 返回值¶

    知识点： - return 返回结果并结束函数 - 返回多个值实际是返回元组，可用解包接收 - ⚠️易错点：没有 return 的函数返回 None

    # 返回单个值
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8

# 返回多个值（实际上是元组）
def get_point():
    x = 10
    y = 20
    return x, y

point = get_point()
print(point)      # (10, 20)
print(type(point))  # <class 'tuple'>

# 解包返回值
x, y = get_point()
print(x, y)  # 10 20

# 没有 return 返回 None
def no_return():
    print("没有返回值")

result = no_return()
print(result)  # None

    📝 文档字符串（Docstring）¶

    知识点： - 三引号字符串放在函数体第一行 - 通过 函数.__doc__ 或 help(函数) 查看 - 良好习惯：写明参数、返回值和示例

    def calculate_area(radius):
    """
    计算圆的面积

    参数:
        radius (float): 圆的半径

    返回:
        float: 圆的面积

    示例:
        >>> calculate_area(5)
        78.53981633974483
    """
    import math
    return math.pi * radius ** 2

# 查看文档
print(calculate_area.__doc__)
help(calculate_area)

    🎯 函数示例¶

    1. 简单函数¶

    知识点： - 常见函数模式：数学计算、字符串处理、列表处理、数据验证 - 防御式编程：先检查边界（如空列表）再计算 - 列表推导式可简洁实现过滤类逻辑 - ⭐面试重点：any/all 配合生成器表达式做条件校验

    def greet(name, greeting="Hello"):
    """打招呼"""
    return f"{greeting}, {name}!"

print(greet("Alice"))           # Hello, Alice!
print(greet("Bob", "Hi"))       # Hi, Bob!

    2. 数学计算¶

    def power(base, exponent):
    """计算幂"""
    return base ** exponent

def factorial(n):
    """计算阶乘"""
    if n <= 1:
        return 1
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

print(power(2, 10))    # 1024
print(factorial(5))    # 120

    3. 字符串处理¶

    def reverse_string(text):
    """反转字符串"""
    return text[::-1]

def is_palindrome(text):
    """判断是否为回文"""
    cleaned = text.lower().replace(" ", "")
    return cleaned == cleaned[::-1]

print(reverse_string("hello"))  # olleh
print(is_palindrome("A man a plan a canal Panama"))  # True

    4. 列表处理¶

    def find_max(numbers):
    """找出列表中的最大值"""
    if not numbers:
        return None
    max_val = numbers[0]
    for num in numbers[1:]:
        if num > max_val:
            max_val = num
    return max_val

def filter_even(numbers):
    """过滤出偶数"""
    return [n for n in numbers if n % 2 == 0]

print(find_max([3, 1, 4, 1, 5, 9]))  # 9
print(filter_even([1, 2, 3, 4, 5, 6]))  # [2, 4, 6]

    5. 数据验证¶

    def is_valid_email(email):
    """简单验证邮箱格式"""
    if "@" not in email:
        return False
    if "." not in email.split("@")[1]:
        return False
    return True

def is_valid_password(password):
    """验证密码强度"""
    if len(password) < 8:
        return False
    has_upper = any(c.isupper() for c in password)
    has_lower = any(c.islower() for c in password)
    has_digit = any(c.isdigit() for c in password)
    return has_upper and has_lower and has_digit

print(is_valid_email("test@example.com"))  # True
print(is_valid_password("Weak1"))          # False
print(is_valid_password("Strong123"))      # True

    🎨 Lambda 函数¶

    匿名函数，用于简单操作：

    知识点： - 匿名函数：lambda 参数: 表达式，只能写单个表达式 - 常作为 sorted 的 key、map/filter 的参数 - ⭐面试重点：sorted(key=lambda x: -x) 实现降序 - ⚠️易错点：lambda 不能包含语句（如赋值、循环）

    # 基本语法
square = lambda x: x ** 2
print(square(5))  # 25

# 多参数
add = lambda x, y: x + y
print(add(3, 5))  # 8

# 作为参数传递
numbers = [5, 2, 9, 1, 7]
sorted_nums = sorted(numbers, key=lambda x: -x)
print(sorted_nums)  # [9, 7, 5, 2, 1]

# 与 map/filter 配合使用
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x**2, numbers))
print(squared)  # [1, 4, 9, 16, 25]

evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4]

    🔍 函数作为对象¶

    在 Python 中，函数是一等公民：

    知识点： - 函数可赋值给变量、作为参数传递、作为返回值 - 函数是一等公民（first-class citizen） - ⭐面试重点：高阶函数（接收或返回函数的函数）

    def greet(name):
    return f"Hello, {name}!"

# 赋值给变量
say_hello = greet
print(say_hello("Alice"))  # Hello, Alice!

# 作为参数传递
def call_function(func, arg):
    return func(arg)

print(call_function(greet, "Bob"))  # Hello, Bob!

# 作为返回值
def make_greeter(greeting):
    def greeter(name):
        return f"{greeting}, {name}!"
    return greeter

hi_greeter = make_greeter("Hi")
print(hi_greeter("Alice"))  # Hi, Alice!

    ⚠️ 常见错误¶

    1. 可变默认参数¶

    知识点： - ⚠️可变默认参数：默认值在定义时只求值一次，多次调用共享同一对象 - ⚠️忘记 return：表达式不写 return 不会返回值，函数返回 None - ⚠️参数顺序：位置参数按位置绑定，可用关键字参数避免传错 - ⭐面试高频：默认参数用 None 哨兵代替可变对象

    # ❌ 错误
def add_item(item, items=[]):  # 危险！
    items.append(item)
    return items

print(add_item(1))  # [1]
print(add_item(2))  # [1, 2] - 不是预期的 [2]!

# ✅ 正确
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item(1))  # [1]
print(add_item(2))  # [2]

    2. 忘记 return¶

    # ❌ 错误
def add(a, b):
    a + b  # 没有 return!

result = add(1, 2)
print(result)  # None

# ✅ 正确
def add(a, b):
    return a + b

    3. 参数顺序错误¶

    def create_user(name, age, city="Beijing"):
    return {"name": name, "age": age, "city": city}

# ❌ 错误
# user = create_user(25, "Alice")  # 参数位置错了!

# ✅ 正确
user = create_user("Alice", 25)
user = create_user(age=25, name="Alice")  # 使用关键字参数

    📝 练习题¶

    1. 编写函数，计算两个数的最大公约数
    2. 编写函数，判断一个年份是否为闰年
    3. 编写函数，统计列表中每个元素出现的次数
    4. 编写函数，将华氏温度转换为摄氏温度（C = (F-32) × 5/9）

    示例答案： 

    # 练习 1
def gcd(a, b):
    """计算最大公约数（欧几里得算法）"""
    while b:
        a, b = b, a % b
    return a

print(gcd(48, 18))  # 6

# 练习 2
def is_leap_year(year):
    return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)

print(is_leap_year(2024))  # True
print(is_leap_year(2100))  # False

# 练习 4
def fahrenheit_to_celsius(f):
    return (f - 32) * 5 / 9

print(fahrenheit_to_celsius(100))  # 37.78

    本章小结¶

    核心知识点¶

    ✅ 函数定义：def 函数名(参数): 定义，缩进函数体，先定义后调用 ✅ 返回值：return 返回结果；多值返回实为元组；无 return 返回 None ✅ 文档字符串：函数体首行三引号，__doc__/help() 查看 ✅ Lambda：匿名单表达式函数，常用作 sorted/map/filter 的参数 ✅ 一等公民：函数可赋值、可传参、可返回，支持高阶函数 ✅ 易错点：可变默认参数用 None 哨兵；别忘写 return
