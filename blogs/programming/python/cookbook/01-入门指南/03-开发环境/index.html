    1.3 开发环境¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 编辑器选择 VS Code 轻量免费推荐，PyCharm 功能最全，Thonny 适合教学 ⭐⭐
    2 venv 虚拟环境 python -m venv venv 创建，activate/deactivate 激活退出，隔离项目依赖 ⭐⭐⭐⭐
    3 conda 科学计算场景的环境管理器，可指定 Python 版本 ⭐⭐
    4 项目结构 src/tests/docs + requirements.txt + .gitignore 的标准布局 ⭐⭐⭐
    5 代码质量工具 Black 格式化、flake8/pylint 风格检查、mypy 类型检查 ⭐⭐⭐
    6 requirements.txt 版本说明符 == 精确、>= 最小、~= 兼容，pip freeze 导出 ⭐⭐⭐⭐

    🛠️ 选择合适的工具¶

    Python 开发有很多工具可选，从简单到复杂：

    知识点： - 工具光谱：文本编辑器（轻量）→ IDE（功能全）→ 专业工具（特定场景） - 按项目规模和学习阶段选择，初学不必追求重型 IDE

    文本编辑器 → IDE → 专业工具
   ↓           ↓        ↓
 轻量级     功能全    特定场景

    📝 文本编辑器（轻量级）¶

    知识点： - ⭐ VS Code 是首选：免费开源跨平台，装 Microsoft Python 扩展后功能完整 - 关键操作：Ctrl+Shift+P 命令面板选择 Python 解释器，Ctrl+F5 运行、F5 调试 - Sublime Text、Vim/Neovim 适合有特定偏好的用户

    VS Code（推荐 ⭐）¶

    优点： - 免费、开源、跨平台 - 丰富的 Python 扩展 - 轻量但功能强大

    安装配置： 1. 下载：code.visualstudio.com 2. 安装 Python 扩展（Microsoft 出品） 3. 选择 Python 解释器：Ctrl+Shift+P → "Python: Select Interpreter"

    常用快捷键： 

    Ctrl+S     保存
Ctrl+F5    运行
F5         调试
Ctrl+`     打开终端
Ctrl+Shift+P  命令面板

    Sublime Text¶

    • 快速、简洁
    • 需要配置 Python 构建系统

    Vim/Neovim¶

    • 终端编辑器，适合高级用户
    • 需要配置插件（如 coc.nvim）

    💻 集成开发环境（IDE）¶

    知识点： - PyCharm 社区版免费，提供补全、重构、调试、版本控制集成；专业版增加 Web/数据库支持 - Thonny 内置 Python 解释器，可视化调试，专为教学设计

    PyCharm（功能最全）¶

    社区版（免费）： - 完整的 Python 开发功能 - 代码补全、重构、调试 - 版本控制集成

    专业版（付费）： - Web 开发支持（Django、Flask） - 数据库工具 - 科学计算工具

    下载地址： jetbrains.com/pycharm

    Thonny（初学者友好）¶

    • 专为教学设计
    • 内置 Python，无需单独安装
    • 可视化调试

    🐍 虚拟环境¶

    知识点： - ⭐ 虚拟环境隔离不同项目的依赖，避免包版本冲突，便于部署 - venv 是内置方案：python -m venv venv 创建，activate 激活（提示符出现 (venv)），deactivate 退出 - conda 适合科学计算：conda create -n 环境名 python=版本，conda activate 激活

    为什么需要虚拟环境？ - 隔离不同项目的依赖 - 避免包版本冲突 - 便于项目部署

    使用 venv（内置）¶

    # 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows (cmd)
venv\Scripts\activate

# Windows (PowerShell)
venv\Scripts\Activate.ps1

# Linux/macOS
source venv/bin/activate

# 退出虚拟环境
deactivate

    激活后，命令行前会有 (venv) 标识： 

    (venv) $ python --version
(venv) $ pip install requests

    使用 virtualenv（第三方）¶

    # 安装
pip install virtualenv

# 创建
virtualenv venv

# 激活（同上）

    使用 conda（科学计算推荐）¶

    # 创建环境
conda create -n myenv python=3.14

# 激活
conda activate myenv

# 安装包
conda install numpy pandas

# 退出
conda deactivate

    📁 项目结构¶

    推荐的项目组织方式：

    知识点： - 推荐布局：src/ 源码、tests/ 测试、docs/ 文档、requirements.txt 依赖、README.md 说明 - ⚠️ venv/ 不要提交到 git，用 .gitignore 排除 - .gitignore 还应排除 pycache/、IDE 配置（.vscode/.idea）等

    my_project/
├── venv/              # 虚拟环境（不提交到 git）
├── src/               # 源代码
│   └── my_module/
│       ├── __init__.py
│       └── main.py
├── tests/             # 测试代码
│   └── test_main.py
├── docs/              # 文档
├── requirements.txt   # 依赖列表
├── README.md          # 项目说明
└── .gitignore         # Git 忽略文件

    .gitignore 示例¶

    🔧 常用工具¶

    知识点： - 格式化：Black（主流）或 autopep8 自动统一代码风格 - 检查：flake8 风格检查、pylint 更严格 - ⭐ mypy 做静态类型检查，配合类型提示提前发现 bug

    代码格式化¶

    # Black - 代码格式化
pip install black
black your_file.py

# autopep8 - 自动格式化
pip install autopep8
autopep8 --in-place your_file.py

    代码检查¶

    # flake8 - 代码风格检查
pip install flake8
flake8 your_file.py

# pylint - 更严格的检查
pip install pylint
pylint your_file.py

    类型检查¶

    # mypy - 静态类型检查
pip install mypy
mypy your_file.py

    📦 依赖管理¶

    知识点： - ⭐ pip freeze > requirements.txt 导出当前环境依赖，pip install -r requirements.txt 恢复 - 版本说明符：== 精确版本、>= 最小版本、~= 兼容版本（~=2.0 等价 >=2.0, <3.0）

    requirements.txt¶

    # 生成依赖列表
pip freeze > requirements.txt

# 安装依赖
pip install -r requirements.txt

    示例 requirements.txt： 

    requests==2.31.0
numpy>=1.24.0
pandas~=2.0.0

    版本说明符¶

    • == 精确版本
    • >= 最小版本
    • <= 最大版本
    • ~= 兼容版本（如 ~=2.0 等价于 >=2.0, <3.0）

    进阶用户¶

    1. PyCharm 专业版 或 VS Code

    📝 练习题¶

    1. 安装 VS Code 或 PyCharm
    2. 配置 Python 解释器
    3. 为当前项目创建虚拟环境
    4. 安装以下包：requests, black, flake8
    5. 配置 .gitignore 文件
