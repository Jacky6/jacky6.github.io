    1.1 安装与配置¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 Python 安装 从 python.org 下载或用 Homebrew/apt 安装，Windows 务必勾选 Add Python to PATH ⭐⭐⭐
    2 PATH 环境变量 PATH 决定命令行能否直接找到 python/pip，忘勾选需手动添加安装路径 ⭐⭐⭐
    3 pip 包管理器 pip install/uninstall/list/freeze 管理第三方库 ⭐⭐⭐⭐
    4 国内镜像源 用清华/阿里云镜像加速下载，-i 临时使用或 pip.conf 永久配置 ⭐⭐
    5 验证安装 python --version + pip --version 确认安装成功 ⭐⭐
    6 python vs python3 Linux/macOS 常用 python3/pip3，Windows 的 python 通常即 Python 3 ⭐⭐

    📥 安装 Python¶

    知识点： - 安装来源：Windows 从 python.org 下载安装包，macOS 推荐 Homebrew，Linux 用 apt/yum - ⚠️ Windows 安装时必须勾选 "Add Python to PATH"，否则命令行找不到 python - 验证方式：python --version（Windows）或 python3 --version（macOS/Linux）

    Windows 系统¶

    1. 下载安装包
    2. 访问 python.org

    3. 下载最新版本的 Windows 安装程序

    4. 运行安装程序 

      ⚠️ 重要：勾选 "Add Python to PATH" 选项！

    5. 这样可以在命令行直接使用 python 命令

    6. 验证安装 

      # 打开命令提示符 (cmd) 或 PowerShell
python --version
# 应该显示：Python 3.x.x

    macOS 系统¶

    1. 使用 Homebrew（推荐） 

      # 先安装 Homebrew (如果还没有)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Python
brew install python

    2. 验证安装 

      python3 --version

    Linux 系统¶

    大多数 Linux 发行版已预装 Python：

    # Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip

# CentOS/RHEL
sudo yum install python3 python3-pip

# 验证安装
python3 --version

    🔧 配置环境变量¶

    知识点： - PATH 是系统查找可执行命令的目录列表，python 命令依赖它 - ⚠️ 忘记勾选 Add to PATH 时，需手动把 Python 安装路径和 Scripts 目录加入系统变量 Path - 配置完成后用 python --version 和 pip --version 验证

    Windows PATH 配置¶

    如果安装时忘记勾选 "Add to PATH"：

    1. 右键"此电脑" → "属性" → "高级系统设置"
    2. 点击"环境变量"
    3. 在"系统变量"中找到 Path
    4. 添加 Python 安装路径，例如： 
      C:\Python314\
C:\Python314\Scripts\

    验证配置¶

    # 应该能看到 Python 版本
python --version

# 应该能看到 pip 版本
pip --version

    📦 pip - Python 包管理器¶

    知识点： - pip 是 Python 官方包管理工具，用于安装/升级/卸载第三方库 - ⭐ 核心命令：pip install、pip list、pip freeze > requirements.txt（导出依赖）、pip install -r requirements.txt（恢复依赖） - 国内用清华/阿里云镜像加速：-i 参数临时使用，pip.conf/pip.ini 永久配置

    pip 是 Python 的包管理工具，用于安装第三方库。

    常用命令¶

    # 安装包
pip install 包名

# 安装指定版本
pip install 包名==1.2.3

# 升级包
pip install --upgrade 包名

# 卸载包
pip uninstall 包名

# 查看已安装的包
pip list

# 导出依赖列表
pip freeze > requirements.txt

# 从文件安装依赖
pip install -r requirements.txt

    配置国内镜像（加速下载）¶

    # 临时使用镜像
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名

# 永久配置（Linux/macOS）
mkdir -p ~/.pip
cat > ~/.pip/pip.conf << EOF
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
EOF

# 永久配置（Windows）
# 在 %APPDATA%\pip\pip.ini 中添加：
# [global]
# index-url = https://pypi.tuna.tsinghua.edu.cn/simple

    常用镜像源： - 清华：https://pypi.tuna.tsinghua.edu.cn/simple - 阿里云：https://mirrors.aliyun.com/pypi/simple/ - 中科大：https://pypi.mirrors.ustc.edu.cn/simple/

    🧪 测试安装¶

    创建一个测试文件：

    知识点： - 写一个最小 .py 文件并用 python 文件名.py 运行，是验证安装的最直接方式 - import('sys').version 可动态导入模块查看解释器版本信息

    # test_install.py
print("Hello, Python!")
print(f"Python 版本：{__import__('sys').version}")

    运行它： 

    python test_install.py

    如果看到输出，说明安装成功！✅

    ❓ 常见问题¶

    知识点： - 命令不识别 → 检查 PATH；Python 2/3 共存 → Linux/macOS 用 python3/pip3 - ⚠️ 权限错误可用 pip install --user 安装到用户目录，避免污染系统环境

    Q: python 命令不识别？¶

    A: 检查 PATH 环境变量是否正确配置

    Q: 同时有 Python 2 和 Python 3？¶

    A: - Linux/macOS: 使用 python3 和 pip3 - Windows: Python 3 通常使用 python，Python 2 使用 python2

    Q: 权限错误？¶

    A: - Linux/macOS: 使用 pip install --user 包名 或 sudo pip install 包名 - Windows: 以管理员身份运行命令提示符

    📝 练习题¶

    1. 在你的电脑上安装 Python 3.14+
    2. 配置环境变量，使 python 命令可用
    3. 使用 pip 安装一个包（如 requests）
    4. 配置 pip 使用国内镜像源

    本章小结¶

    核心知识点¶

    ✅ 安装方式：Windows 官网安装包、macOS Homebrew、Linux apt/yum，装完用 --version 验证
    ✅ PATH 配置：决定 python 命令是否可用，Windows 安装时务必勾选 Add Python to PATH
    ✅ pip 用法：install/uninstall/list 管理包，freeze 导出、-r 安装 requirements.txt
    ✅ 镜像加速：国内用清华/阿里云镜像，-i 临时或 pip.conf 永久配置
    ✅ 命令差异：Linux/macOS 用 python3/pip3 区分 Python 2 与 3
