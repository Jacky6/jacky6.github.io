    4.5 dataclass 数据类（Python 3.7+）¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 dataclass 是什么 装饰器自动生成 init/repr/eq，专注数据 ⭐⭐⭐⭐
    2 默认值与 default_factory 可变默认值必须用 field(default_factory=...) ⚠️ ⭐⭐⭐⭐
    3 frozen 不可变 frozen=True 让实例只读，可哈希（可做字典 key） ⭐⭐⭐
    4 order 比较 order=True 自动生成 <、<=、>、>= 比较方法 ⭐⭐
    5 slots Python 3.10+，节省内存、防动态加属性 ⭐⭐
    6 post_init 构造后钩子，做参数校验/派生字段 ⭐⭐⭐
    7 asdict/astuple 实例转 dict/tuple，配合 JSON 序列化 ⭐⭐
    8 kw_only Python 3.10+，强制字段以关键字传参，避免长参数列表传错位置 ⭐⭐
    9 InitVar 只参与 init/post_init 的"伪字段"，不存为实例属性 ⭐⭐

    1. 什么是 dataclass¶

    知识点： - ⭐ @dataclass 装饰器根据类型注解自动生成 __init__、__repr__、__eq__ 等样板方法 - 定位：只承载数据的类（DTO/VO/配置对象），替代手写几十行样板或普通 dict - 对比：普通类要手写构造器和 repr；namedtuple 不可变且不能加默认方法；dataclass 两全

    # ❌ 普通类：一堆样板代码
class User:
    def __init__(self, name: str, age: int = 0):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"User(name={self.name!r}, age={self.age})"

    def __eq__(self, other):
        return isinstance(other, User) and (self.name, self.age) == (other.name, other.age)

# ✅ dataclass：一行装饰器搞定
from dataclasses import dataclass

@dataclass
class User:
    name: str
    age: int = 0

u1 = User("Alice", 25)
u2 = User("Alice", 25)
print(u1)        # User(name='Alice', age=25)  ← 自动 __repr__
print(u1 == u2)  # True                          ← 自动 __eq__（按字段值比较）

    2. 默认值与 default_factory ⚠️¶

    知识点： - ⭐ 可变默认值（list/dict/set）禁止直接写 = []（会报 ValueError），必须用 field(default_factory=list) - 原因：默认值在类定义时只求值一次，直接写可变对象会让所有实例共享同一份（和默认参数陷阱同源） - 带默认值的字段必须放在无默认值字段后面（和函数参数规则一致）

    from dataclasses import dataclass, field

@dataclass
class User:
    name: str
    age: int = 0
    tags: list = field(default_factory=list)   # ✅ 每个实例独立的 list

    # tags: list = []   # ❌ ValueError: mutable default ... use default_factory

u1 = User("Alice")
u2 = User("Bob")
u1.tags.append("vip")
print(u1.tags)  # ['vip']
print(u2.tags)  # []  ← 互不影响

    3. frozen：不可变数据类¶

    知识点： - ⭐ frozen=True：实例创建后字段只读，赋值抛 FrozenInstanceError - frozen 类自动获得 __hash__，可以放进 set、做字典 key - 适用：配置对象、缓存 key、坐标点等不该被修改的数据

    from dataclasses import dataclass

@dataclass(frozen=True)
class Point:
    x: int
    y: int

p = Point(1, 2)
# p.x = 10          # ❌ FrozenInstanceError: cannot assign to field 'x'

# 可哈希 → 可做 set 元素/字典 key
points = {Point(1, 2), Point(1, 2), Point(3, 4)}
print(len(points))   # 2（重复的合并了）

    4. order：自动生成比较方法¶

    知识点： - order=True：按字段顺序生成 <、<=、>、>=（元组式逐字段比较） - ⭐ 不想参与比较的字段用 field(compare=False)（如名字字段，只按分数排序）

    from dataclasses import dataclass, field

@dataclass(order=True)
class Score:
    total: int
    name: str = field(compare=False)   # 比较时忽略 name

scores = [Score(90, "Alice"), Score(85, "Bob"), Score(95, "Carol")]
for s in sorted(scores):
    print(s.total, s.name)   # 85 Bob → 90 Alice → 95 Carol

    5. slots 与 post_init¶

    知识点： - ⭐ slots=True（Python 3.10+）：自动生成 __slots__，节省内存、禁止动态添加属性 - ⭐ __post_init__：__init__ 结束后自动调用的钩子，做参数校验或计算派生字段 - ⚠️ frozen 类里修改字段要用 object.__setattr__(self, ...)（绕过冻结检查）

    from dataclasses import dataclass, field

# slots：禁止动态加属性
@dataclass(slots=True)
class Vec:
    x: float
    y: float

v = Vec(1.0, 2.0)
# v.z = 3.0   # ❌ AttributeError: 'Vec' object has no attribute 'z'

# __post_init__：构造后校验
@dataclass
class Config:
    host: str
    port: int = 8080

    def __post_init__(self):
        if not (0 < self.port < 65536):
            raise ValueError(f"invalid port: {self.port}")

Config("localhost", 99999)   # ❌ ValueError: invalid port: 99999

    6. 序列化：asdict / astuple¶

    知识点： - asdict(obj)：递归转成 dict（嵌套 dataclass 也会展开），常用于转 JSON - astuple(obj)：递归转成 tuple - 配合 json.dumps(asdict(obj)) 是最常用的"对象转 JSON"套路

    from dataclasses import dataclass, asdict, astuple
import json

@dataclass
class User:
    name: str
    age: int = 0

u = User("Alice", 25)
print(asdict(u))    # {'name': 'Alice', 'age': 25}
print(astuple(u))   # ('Alice', 25)
print(json.dumps(asdict(u)))   # {"name": "Alice", "age": 25}

    7. 进阶：kw_only 与 InitVar（Python 3.10+）¶

    知识点： - ⭐ kw_only=True（类级或字段级）：强制字段用关键字传参，位置传参会抛 TypeError——字段多的配置类防传错位置 - InitVar[T]：只出现在 __init__ 参数里的"伪字段"，通过 __post_init__ 接收使用，不存为实例属性 - field(repr=False)：敏感字段（如密码）不显示在 repr 输出里 - ⚠️ kw_only 是 Python 3.10+ 特性，低版本不可用

    from dataclasses import dataclass, field, InitVar

# kw_only：整个类所有字段强制关键字传参
@dataclass(kw_only=True)
class Config:
    host: str
    port: int = 8080

c = Config(host="localhost")     # ✅
# Config("localhost")            # ❌ TypeError: takes 1 positional argument but 2 were given

# InitVar：只参与初始化，不存为实例字段
@dataclass
class Circle:
    radius: float
    unit: InitVar[str] = "m"     # 伪字段：进 __init__，不进实例

    def __post_init__(self, unit):
        self.label = f"{self.radius}{unit}"   # 用它派生 label

cir = Circle(3.0, "cm")
print(cir.label)        # 3.0cm
print(vars(cir))        # {'radius': 3.0, 'label': '3.0cm'} ← 没有 unit！

# repr=False：敏感字段不打印
@dataclass
class Account:
    username: str
    password: str = field(repr=False)

print(Account("alice", "p@ss"))   # Account(username='alice')

    8. dataclass vs 其他选择 ⭐¶

    方案 可变 默认值 方法 类型提示 适用
    dict ✅ ✅ ❌ ❌ 临时/动态数据
    namedtuple ❌ ⚠️ 麻烦 ⚠️ 受限 ❌ 轻量不可变元组
    dataclass ✅（可选 frozen） ✅ ✅ ✅ 首选：结构化数据
    TypedDict ✅ — ❌ ✅ JSON 字典的类型标注 
    # namedtuple 对比：不可变、不能加实例方法默认实现
from collections import namedtuple
Point = namedtuple("Point", ["x", "y"])   # 没有类型提示，没有默认值支持

    📝 练习题¶

    1. 基础 dataclass：定义 Book（title、author、price、tags），tags 用 default_factory，创建两本相同书验证 == 和打印输出。
    2. frozen + 排序：定义 frozen 的 Student（score、name，compare=False 排除 name），创建 3 个学生排序输出，并验证字段不可修改。
    3. post_init 校验：定义 Rectangle（width、height），在 __post_init__ 中校验边长必须为正数，负数时抛 ValueError。

    参考答案¶

    from dataclasses import dataclass, field

# 练习 1
@dataclass
class Book:
    title: str
    author: str
    price: float
    tags: list = field(default_factory=list)

b1 = Book("Python 入门", "Alice", 59.0)
b2 = Book("Python 入门", "Alice", 59.0)
print(b1 == b2)   # True（字段值相同）
print(b1)         # Book(title='Python 入门', author='Alice', price=59.0, tags=[])

# 练习 2
@dataclass(frozen=True, order=True)
class Student:
    score: int
    name: str = field(compare=False)

students = [Student(85, "Bob"), Student(92, "Alice"), Student(78, "Carol")]
for s in sorted(students):
    print(s.score, s.name)   # 78 Carol → 85 Bob → 92 Alice

# s = Student(90, "Dave"); s.score = 100  # ❌ FrozenInstanceError

# 练习 3
@dataclass
class Rectangle:
    width: float
    height: float

    def __post_init__(self):
        if self.width <= 0 or self.height <= 0:
            raise ValueError("边长必须为正数")

    def area(self):
        return self.width * self.height

print(Rectangle(3, 4).area())   # 12
# Rectangle(-1, 2)              # ❌ ValueError: 边长必须为正数

    本章小结¶

    核心知识点¶

    ✅ dataclass：类型注解驱动，自动生成构造/repr/eq
    ✅ default_factory：可变默认值的正确写法
    ✅ frozen/order/slots：不可变、自动比较、内存优化
    ✅ post_init：构造后校验钩子
    ✅ asdict/astuple：转 dict/tuple，配合 JSON 序列化
    ✅ 进阶（3.10+）：kw_only 强制关键字传参防传错，InitVar 伪字段只参与初始化，repr=False 隐藏敏感字段

    最佳实践¶

    1. 纯数据类一律用 dataclass，不手写样板
    2. 可变字段用 field(default_factory=...)
    3. 配置/缓存 key 用 frozen=True
    4. 参数校验放 post_init
