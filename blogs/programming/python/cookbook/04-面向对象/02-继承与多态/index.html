    4.2 继承与多态¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 继承 子类获得父类的属性和方法，class 子类(父类) ⭐⭐⭐⭐
    2 super() 调用父类方法，常用于 init 中初始化父类 ⭐⭐⭐⭐
    3 方法重写 子类定义同名方法覆盖父类实现 ⭐⭐⭐⭐
    4 多态 同一接口、不同实现，统一调用各自响应 ⭐⭐⭐⭐
    5 继承类型 单继承、多继承、多层继承 ⭐⭐⭐
    6 isinstance / issubclass 检查实例与类、类与子类的关系 ⭐⭐⭐
    7 组合优于继承 is-a 用继承，has-a 用组合 ⭐⭐⭐

    🔗 什么是继承？¶

    继承允许一个类（子类）获取另一个类（父类）的属性和方法。

    知识点：

    • 子类自动获得父类的属性和方法
    • 子类可以重写父类方法提供自己的实现
    • ⭐面试重点：继承实现代码复用，是多态的基础
    # 父类（基类）
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "Some sound"

# 子类（派生类）
class Dog(Animal):  # Dog 继承 Animal
    def speak(self):
        return "Woof!"

class Cat(Animal):
    def speak(self):
        return "Meow!"

# 使用
dog = Dog("Buddy")
cat = Cat("Kitty")

print(dog.name)   # Buddy (继承自 Animal)
print(dog.speak())  # Woof! (重写)
print(cat.speak())  # Meow!

    📐 继承语法¶

    知识点：

    • class 子类(父类): 声明继承
    • 子类可访问父类的属性和方法
    • 子类 init 中用 super().__init__() 初始化父类部分
    • ⚠️易错点：忘记 super().init() 会导致父类属性不存在（AttributeError）
    class Parent:
    def __init__(self):
        self.parent_attr = "I'm parent"

    def parent_method(self):
        return "Parent method"

class Child(Parent):
    def __init__(self):
        super().__init__()  # 调用父类构造方法
        self.child_attr = "I'm child"

    def child_method(self):
        return "Child method"

child = Child()
print(child.parent_attr)  # I'm parent (继承)
print(child.child_attr)   # I'm child (自己的)
print(child.parent_method())  # Parent method (继承)
print(child.child_method())   # Child method (自己的)

    🔄 方法重写（Override）¶

    知识点：

    • 子类定义与父类同名的方法即覆盖父类实现
    • 调用时按对象的实际类型执行对应版本
    • ⭐面试重点：遍历父类引用列表调用同名方法 → 各自执行子类实现（多态）
    class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name} makes a sound"

class Dog(Animal):
    def speak(self):  # 重写父类方法
        return f"{self.name} barks: Woof!"

class Cat(Animal):
    def speak(self):  # 重写父类方法
        return f"{self.name} meows: Meow!"

animals = [Dog("Buddy"), Cat("Kitty"), Animal("Generic")]
for animal in animals:
    print(animal.speak())
# Buddy barks: Woof!
# Kitty meows: Meow!
# Generic makes a sound

    🔍 super() 函数¶

    调用父类的方法：

    知识点：

    • super() 返回父类代理，用于调用父类方法
    • 常用于 init 中先初始化父类再补充子类属性
    • 也可先调父类方法再扩展子类逻辑
    • ⭐面试重点：super() 不是直接指向父类，而是按 MRO 解析
    class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"I'm {self.name}, {self.age} years old"

class Student(Person):
    def __init__(self, name, age, student_id):
        super().__init__(name, age)  # 调用父类构造方法
        self.student_id = student_id

    def introduce(self):
        # 先调用父类方法，再添加自己的信息
        base_intro = super().introduce()
        return f"{base_intro}, ID: {self.student_id}"

student = Student("Alice", 20, "2024001")
print(student.introduce())
# I'm Alice, 20 years old, ID: 2024001

    🎭 多态（Polymorphism）¶

    不同类的对象对同一消息做出不同响应：

    知识点：

    • 不同类的对象对同一方法调用做出不同响应
    • 调用方无需知道具体类型，统一接口调用
    • ⭐面试重点：Python 多态基于鸭子类型——会像鸭子一样嘎嘎叫就是鸭子
    class Shape:
    def area(self):
        pass

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14159 * self.radius ** 2

class Triangle(Shape):
    def __init__(self, base, height):
        self.base = base
        self.height = height

    def area(self):
        return 0.5 * self.base * self.height

# 多态：同一个接口，不同实现
shapes = [
    Rectangle(5, 10),
    Circle(7),
    Triangle(6, 8)
]

for shape in shapes:
    print(f"面积：{shape.area():.2f}")
# 面积：50.00
# 面积：153.94
# 面积：24.00

    🏗️ 继承类型¶

    单继承¶

    知识点：

    • 单继承：一个子类一个父类
    • 多继承：class C(A, B) 继承多个父类
    • 多层继承：孙子类继承链
    • ⚠️易错点：多继承的方法查找按 MRO 顺序
    class A:
    pass

class B(A):  # B 继承 A
    pass

    多继承¶

    class A:
    def method_a(self):
        return "A"

class B:
    def method_b(self):
        return "B"

class C(A, B):  # C 继承 A 和 B
    pass

c = C()
print(c.method_a())  # A
print(c.method_b())  # B

    多层继承¶

    class Grandparent:
    pass

class Parent(Grandparent):
    pass

class Child(Parent):
    pass

    🔎 检查继承关系¶

    知识点：

    • isinstance(obj, 类)：检查对象是否是类（或其子类）的实例
    • issubclass(子类, 父类)：检查类间继承关系
    • type(obj) 获取精确类型，不认子类
    • ⭐面试重点：isinstance 认子类，type 不认——类型判断优先用 isinstance
    class Animal:
    pass

class Dog(Animal):
    pass

dog = Dog()

# isinstance - 检查对象是否是类的实例
print(isinstance(dog, Dog))    # True
print(isinstance(dog, Animal)) # True (Dog 是 Animal 的子类)
print(isinstance(dog, object)) # True (所有类都继承 object)

# issubclass - 检查类是否是另一个类的子类
print(issubclass(Dog, Animal))  # True
print(issubclass(Animal, Dog))  # False

# type - 获取对象的类型
print(type(dog))       # <class '__main__.Dog'>
print(type(dog) == Dog)  # True

    🎯 实际例子¶

    1. 员工系统¶

    知识点：

    • 员工系统：子类重写 get_pay() 实现不同薪资算法
    • 支付系统：基类方法 raise NotImplementedError 强制子类实现
    • 文件系统：目录递归汇总子项大小（组合模式）
    • ⭐面试重点：模板方法/策略思想的落地写法
    class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def get_pay(self):
        return self.salary

    def __str__(self):
        return f"{self.__class__.__name__}: {self.name}"

class Manager(Employee):
    def __init__(self, name, salary, bonus):
        super().__init__(name, salary)
        self.bonus = bonus

    def get_pay(self):
        return self.salary + self.bonus

class Developer(Employee):
    def __init__(self, name, salary, projects=0):
        super().__init__(name, salary)
        self.projects = projects

    def get_pay(self):
        return self.salary + self.projects * 1000

class Intern(Employee):
    def __init__(self, name, salary):
        super().__init__(name, salary)

    def get_pay(self):
        return self.salary * 0.8  # 实习生 8 折

# 使用
employees = [
    Manager("Alice", 10000, 5000),
    Developer("Bob", 8000, 3),
    Intern("Charlie", 3000),
]

for emp in employees:
    print(f"{emp} - 薪资：{emp.get_pay()}")
# Manager: Alice - 薪资：15000
# Developer: Bob - 薪资：11000
# Intern: Charlie - 薪资：2400

    2. 支付系统¶

    class PaymentMethod:
    def pay(self, amount):
        raise NotImplementedError

class CreditCard(PaymentMethod):
    def __init__(self, card_number):
        self.card_number = card_number

    def pay(self, amount):
        return f"刷卡支付 {amount}元，卡号：****{self.card_number[-4:]}"

class PayPal(PaymentMethod):
    def __init__(self, email):
        self.email = email

    def pay(self, amount):
        return f"PayPal 支付 {amount}元，邮箱：{self.email}"

class WeChatPay(PaymentMethod):
    def pay(self, amount):
        return f"微信支付 {amount}元"

class PaymentProcessor:
    def process(self, method: PaymentMethod, amount):
        print(method.pay(amount))

# 使用
processor = PaymentProcessor()
processor.process(CreditCard("1234567890123456"), 100)
processor.process(PayPal("user@example.com"), 200)
processor.process(WeChatPay(), 300)

    3. 文件系统¶

    class FileSystemItem:
    def __init__(self, name):
        self.name = name

    def get_size(self):
        return 0

    def get_path(self):
        return self.name

class File(FileSystemItem):
    def __init__(self, name, size):
        super().__init__(name)
        self.size = size

    def get_size(self):
        return self.size

class Directory(FileSystemItem):
    def __init__(self, name):
        super().__init__(name)
        self.children = []

    def add_child(self, item):
        self.children.append(item)

    def get_size(self):
        return sum(child.get_size() for child in self.children)

    def list_contents(self, indent=0):
        result = "  " * indent + f"[{self.name}]\n"
        for child in self.children:
            if isinstance(child, Directory):
                result += child.list_contents(indent + 1)
            else:
                result += "  " * (indent + 1) + f"{child.name} ({child.get_size()} bytes)\n"
        return result

# 使用
root = Directory("root")
docs = Directory("docs")
file1 = File("readme.txt", 1024)
file2 = File("notes.txt", 2048)

docs.add_child(file1)
docs.add_child(file2)
root.add_child(docs)
root.add_child(File("config.ini", 512))

print(root.list_contents())
print(f"总大小：{root.get_size()} bytes")

    ⚠️ 常见错误¶

    1. 忘记调用 super().init()¶

    知识点：

    • ⚠️忘记 super().init()：父类属性未初始化 → AttributeError
    • ⚠️继承层次过深，难以维护
    • ⚠️混淆 is-a 和 has-a：Car 有 Engine 应使用组合而非继承
    • ⭐面试重点：组合优于继承的适用场景
    class Parent:
    def __init__(self):
        self.value = 10

class Child(Parent):
    def __init__(self):
        # ❌ 忘记调用 super().__init__()
        self.child_value = 20

c = Child()
# print(c.value)  # AttributeError!

# ✅ 正确
class Child(Parent):
    def __init__(self):
        super().__init__()
        self.child_value = 20

    2. 过度使用继承¶

    # ❌ 过度继承
class Animal: pass
class Mammal(Animal): pass
class Dog(Mammal): pass
class PetDog(Dog): pass
class SmallPetDog(PetDog): pass  # 太深了!

# ✅ 优先使用组合
class Dog:
    def __init__(self, size, is_pet):
        self.size = size
        self.is_pet = is_pet

    3. 混淆 is-a 和 has-a¶

    # ❌ 错误：Car 不是 Engine
class Engine:
    pass

class Car(Engine):  # 错误继承
    pass

# ✅ 正确：Car 有 Engine
class Car:
    def __init__(self):
        self.engine = Engine()  # 组合

    📝 练习题¶

    1. 创建 Animal → Bird → Sparrow 的继承层次
    2. 创建 Shape → Rectangle/Square/Circle，每个类实现 area() 方法
    3. 创建 Person → Student/Teacher，添加各自特有的属性和方法
    4. 使用多态创建一个简单的图形绘制系统

    示例答案： 

    # 练习 1
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Bird(Animal):
    def speak(self):
        return "Chirp!"

    def fly(self):
        return f"{self.name} is flying"

class Sparrow(Bird):
    def speak(self):
        return "Tweet!"

sparrow = Sparrow("Sparrow")
print(sparrow.speak())  # Tweet!
print(sparrow.fly())    # Sparrow is flying

# 练习 2
class Shape:
    def area(self):
        pass

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

class Square(Rectangle):
    def __init__(self, side):
        super().__init__(side, side)

shapes = [Rectangle(5, 10), Square(5)]
for s in shapes:
    print(f"面积：{s.area()}")

    本章小结¶

    核心知识点¶

    ✅ 继承：class 子类(父类)，子类复用并可重写父类方法 ✅ super()：调用父类方法，init 中先初始化父类部分 ✅ 多态：同一接口不同实现，调用方无需关心具体类型 ✅ 类型检查：isinstance 认子类，type 只认精确类型 ✅ 继承类型：单继承、多继承（MRO）、多层继承 ✅ 设计原则：is-a 用继承，has-a 用组合；避免过深继承层次
