    5.6 并发编程¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度
    1 并发 vs 并行 并发是交替执行，并行是同时执行 ⭐⭐⭐
    2 threading 线程 Thread(target, args) + start/join，适合 IO 密集型 ⭐⭐⭐
    3 线程同步原语 Lock 互斥、Semaphore 限流、Event 通知、Condition 条件变量 ⭐⭐⭐
    4 multiprocessing 多进程 Process 独立内存空间绕过 GIL，Pool 进程池批量任务 ⭐⭐⭐
    5 进程间通信 Queue 队列、Value/Array 共享内存 ⭐⭐
    6 asyncio 异步 IO async/await 单线程协程，gather 并发等待，适合高并发 IO ⭐⭐⭐⭐
    7 GIL 与选型 GIL 限制多线程跑 CPU 任务：CPU 密集用多进程，IO 密集用线程或 asyncio ⭐⭐⭐⭐
    8 线程安全与死锁 共享数据加锁保护，按固定顺序获取锁避免死锁 ⭐⭐⭐

    🔄 并发 vs 并行¶

    知识点：

    • 并发（Concurrent）：多个任务交替执行，宏观上同时推进

    • 并行（Parallel）：多个任务在同一时刻真正同时执行（需要多核）

    • 并发（Concurrent）：多个任务交替执行

    • 并行（Parallel）：多个任务同时执行

    🧵 threading - 线程¶

    知识点：

    • threading.Thread(target=函数, args=参数元组) 创建线程，start() 启动，join() 等待结束
    • 同步原语：Lock 互斥锁（with lock 自动获取/释放）、Semaphore 限制并发数、Event 事件通知、Condition 生产者-消费者条件变量
    • ⭐ 面试重点：共享数据的读写必须加锁，否则结果不可预期
    • ⚠️ 同一进程内的线程共享内存，数据竞争是常见 bug 来源

    基本使用¶

    import threading
import time

def worker(name, delay):
    for i in range(3):
        time.sleep(delay)
        print(f"{name}: {i}")

# 创建线程
t1 = threading.Thread(target=worker, args=("Thread-1", 1))
t2 = threading.Thread(target=worker, args=("Thread-2", 1))

# 启动线程
t1.start()
t2.start()

# 等待线程完成
t1.join()
t2.join()

print("所有线程完成")

    线程同步¶

    import threading

# 锁
lock = threading.Lock()
counter = 0

def increment():
    global counter
    with lock:  # 自动获取和释放锁
        counter += 1

# 信号量
semaphore = threading.Semaphore(3)  # 最多 3 个线程访问

def limited_access():
    with semaphore:
        # 临界区代码
        pass

# 事件
event = threading.Event()

def waiter():
    print("等待事件...")
    event.wait()  # 阻塞直到事件被设置
    print("事件已触发")

def setter():
    event.set()  # 触发事件

# 条件变量
condition = threading.Condition()

def producer():
    with condition:
        condition.notify()  # 通知消费者

def consumer():
    with condition:
        condition.wait()  # 等待通知

    🚀 multiprocessing - 多进程¶

    知识点：

    • 每个进程有独立的内存空间和进程 ID（os.getpid() 可验证），绕过 GIL
    • ⚠️ 多进程代码必须放在 if name == "main": 保护块内
    • Pool 进程池：pool.map(func, iterable) 批量并行，apply_async 异步提交单任务
    • 进程间通信：Queue 队列（put/get，None 作结束标志）、Value/Array 共享内存
    from multiprocessing import Process, Pool
import os

def worker(name):
    print(f"{name}: 进程 ID = {os.getpid()}")

if __name__ == "__main__":
    # 创建进程
    processes = []
    for i in range(3):
        p = Process(target=worker, args=(f"Process-{i}",))
        processes.append(p)
        p.start()

    for p in processes:
        p.join()

    进程池¶

    from multiprocessing import Pool

def square(x):
    return x ** 2

if __name__ == "__main__":
    with Pool(processes=4) as pool:
        # 映射
        results = pool.map(square, range(10))
        print(results)  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

        # 异步
        result = pool.apply_async(square, (10,))
        print(result.get())  # 100

    进程间通信¶

    from multiprocessing import Process, Queue, Pipe, Value, Array

# 队列
def producer(queue):
    for i in range(5):
        queue.put(i)
    queue.put(None)  # 结束标志

def consumer(queue):
    while True:
        item = queue.get()
        if item is None:
            break
        print(f"收到：{item}")

queue = Queue()
p1 = Process(target=producer, args=(queue,))
p2 = Process(target=consumer, args=(queue,))
p1.start()
p2.start()

# 共享值
num = Value('i', 0)  # 'i' 表示整数

# 共享数组
arr = Array('i', [1, 2, 3, 4, 5])

    ⚡ asyncio - 异步 IO¶

    知识点：

    • async def 定义协程，await 非阻塞等待；asyncio.run(main()) 启动事件循环
    • asyncio.gather() 并发等待多个协程并收集结果，顺序执行则逐个 await
    • 异步上下文管理器 async with、异步迭代器 async for（生成器内含 await 即成异步生成器）
    • ⭐ 面试重点：asyncio 是单线程并发，靠事件循环在 IO 等待时切换任务

    基础¶

    import asyncio

async def hello(name, delay):
    print(f"{name}: 开始")
    await asyncio.sleep(delay)  # 非阻塞等待
    print(f"{name}: 结束")
    return f"{name} 完成"

async def main():
    # 顺序执行
    await hello("A", 1)
    await hello("B", 1)

    # 并发执行
    results = await asyncio.gather(
        hello("A", 1),
        hello("B", 1),
        hello("C", 1)
    )
    print(results)

asyncio.run(main())

    异步上下文管理器¶

    import asyncio
import aiofiles

async def read_file(filename):
    async with aiofiles.open(filename, 'r') as f:
        content = await f.read()
        return content

async def write_file(filename, content):
    async with aiofiles.open(filename, 'w') as f:
        await f.write(content)

    异步迭代器¶

    async def async_range(n):
    for i in range(n):
        await asyncio.sleep(0.1)
        yield i

async def main():
    async for num in async_range(5):
        print(num)

asyncio.run(main())

    🎯 实际例子¶

    知识点：

    • 并发下载：aiohttp.ClientSession + gather 并发抓取多个 URL
    • ThreadPoolExecutor：concurrent.futures 线程池，executor.map 映射任务
    • 生产者-消费者：queue.Queue(maxsize) 有界缓冲，None 作结束标志
    • 定时任务：daemon 线程 + 循环 sleep；并行计算：Pool.map 对比串行耗时

    1. 并发下载¶

    import asyncio
import aiohttp

async def fetch(session, url):
    async with session.get(url) as response:
        return await response.text()

async def main():
    urls = [
        "https://www.example.com",
        "https://www.python.org",
        "https://www.github.com",
    ]

    async with aiohttp.ClientSession() as session:
        tasks = [fetch(session, url) for url in urls]
        results = await asyncio.gather(*tasks)

        for url, content in zip(urls, results):
            print(f"{url}: {len(content)} bytes")

# asyncio.run(main())

    2. 线程池执行器¶

    from concurrent.futures import ThreadPoolExecutor
import requests

def fetch_url(url):
    response = requests.get(url)
    return len(response.content)

urls = [
    "https://www.example.com",
    "https://www.python.org",
    "https://www.github.com",
]

with ThreadPoolExecutor(max_workers=3) as executor:
    results = list(executor.map(fetch_url, urls))
    print(results)

    3. 生产者 - 消费者¶

    import threading
import queue
import time

class ProducerConsumer:
    def __init__(self, buffer_size=10):
        self.queue = queue.Queue(maxsize=buffer_size)
        self.stop_flag = False

    def producer(self, items):
        for item in items:
            self.queue.put(item)
            print(f"生产：{item}")
        self.queue.put(None)  # 结束标志

    def consumer(self):
        while True:
            item = self.queue.get()
            if item is None:
                break
            print(f"消费：{item}")
            time.sleep(0.1)

    def run(self, items):
        producer_thread = threading.Thread(target=self.producer, args=(items,))
        consumer_thread = threading.Thread(target=self.consumer)

        producer_thread.start()
        consumer_thread.start()

        producer_thread.join()
        consumer_thread.join()

# 使用
pc = ProducerConsumer()
pc.run(range(10))

    4. 定时任务¶

    import threading
import time

class Timer:
    def __init__(self, interval, callback):
        self.interval = interval
        self.callback = callback
        self.thread = None
        self.stop_flag = False

    def _run(self):
        while not self.stop_flag:
            time.sleep(self.interval)
            if not self.stop_flag:
                self.callback()

    def start(self):
        self.thread = threading.Thread(target=self._run)
        self.thread.daemon = True
        self.thread.start()

    def stop(self):
        self.stop_flag = True

# 使用
def print_time():
    print(f"当前时间：{time.strftime('%H:%M:%S')}")

timer = Timer(1, print_time)
timer.start()
time.sleep(5)
timer.stop()

    5. 并行计算¶

    from multiprocessing import Pool
import time

def compute_square(x):
    time.sleep(0.1)  # 模拟计算
    return x ** 2

if __name__ == "__main__":
    data = range(20)

    # 串行
    start = time.time()
    results1 = [compute_square(x) for x in data]
    print(f"串行：{time.time() - start:.2f}秒")

    # 并行
    start = time.time()
    with Pool(processes=4) as pool:
        results2 = pool.map(compute_square, data)
    print(f"并行：{time.time() - start:.2f}秒")

    ⚠️ 注意事项¶

    知识点：

    • ⭐ 面试重点：GIL 使同一时刻只有一个线程执行 Python 字节码——CPU 密集用 multiprocessing，IO 密集用 threading/asyncio
    • 线程安全：共享数据操作用 with lock 保护
    • ⚠️ 死锁：多个线程以不同顺序获取多把锁会互相等待，必须按相同顺序获取锁

    1. GIL（全局解释器锁）¶

    # Python 的 GIL 限制同一时刻只有一个线程执行 Python 字节码
# CPU 密集型任务：使用 multiprocessing
# IO 密集型任务：使用 threading 或 asyncio

    2. 线程安全¶

    # 共享数据需要保护
lock = threading.Lock()
shared_data = []

def safe_append(item):
    with lock:
        shared_data.append(item)

    3. 死锁¶

    # ❌ 可能导致死锁
lock1 = threading.Lock()
lock2 = threading.Lock()

def thread1():
    with lock1:
        with lock2:
            pass

def thread2():
    with lock2:  # 可能死锁
        with lock1:
            pass

# ✅ 避免：总是按相同顺序获取锁

    📝 练习题¶

    1. 使用 threading 创建一个程序，同时下载多个文件
    2. 使用 multiprocessing 并行计算大列表的平方和
    3. 使用 asyncio 创建一个简单的 HTTP 服务器
    4. 实现一个线程安全的计数器

    示例答案： 

    # 练习 4
import threading

class ThreadSafeCounter:
    def __init__(self):
        self._value = 0
        self._lock = threading.Lock()

    def increment(self):
        with self._lock:
            self._value += 1
            return self._value

    def get(self):
        with self._lock:
            return self._value

counter = ThreadSafeCounter()

def worker():
    for _ in range(1000):
        counter.increment()

threads = [threading.Thread(target=worker) for _ in range(10)]
for t in threads:
    t.start()
for t in threads:
    t.join()

print(f"最终值：{counter.get()}")  # 应该是 10000

    核心知识点¶

    ✅ 选型铁律：GIL 下 CPU 密集型用 multiprocessing，IO 密集型用 threading 或 asyncio ✅ threading：Thread + start/join；Lock/Semaphore/Event/Condition 四大同步原语 ✅ multiprocessing：独立内存绕过 GIL，代码放 main 保护块，Pool.map 批量并行 ✅ asyncio：单线程协程，async/await + gather 并发，适合高并发 IO ✅ 线程安全：共享数据必须加锁；按固定顺序获取锁避免死锁
