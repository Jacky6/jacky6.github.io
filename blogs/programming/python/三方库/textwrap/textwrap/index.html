    Textwrap

    textwrap 是 Python 标准库中的一个模块，用于对文本进行格式化处理，特别是自动换行（折行）、去除缩进、填充文本等操作。它非常适合处理多行字符串的排版问题，比如生成帮助信息、日志、文档等。

    一、常用函数介绍¶

    1. textwrap.wrap(text, width=70, **kwargs)¶

    • 功能：将长文本按指定宽度拆分成多行列表。
    • 返回值：列表（每行是一个字符串）。
    • 参数：
    • width：每行最大字符数（默认 70）。
    • 其他可选参数如 break_long_words, break_on_hyphens 等。
    import textwrap

text = "This is a very long sentence that needs to be wrapped into multiple lines."
wrapped = textwrap.wrap(text, width=20)
print(wrapped)
# 输出：
# ['This is a very long',
#  'sentence that needs',
#  'to be wrapped into',
#  'multiple lines.']

    2. textwrap.fill(text, width=70, **kwargs)¶

    • 功能：与 wrap() 类似，但直接返回一个用换行符连接的字符串（更常用）。
    • 等价于："\n".join(wrap(text, ...))
    filled = textwrap.fill(text, width=20)
print(filled)
# 输出：
# This is a very long
# sentence that needs
# to be wrapped into
# multiple lines.

    3. textwrap.dedent(text)¶

    • 功能：去除多行字符串的公共前导空白（缩进），常用于三引号字符串。
    • 用途：让代码中的多行字符串保持美观缩进，但输出时不带多余空格。
    code = """
    def hello():
        print("Hello, world!")
"""
print(repr(code))
# '\n    def hello():\n        print("Hello, world!")\n'

cleaned = textwrap.dedent(code)
print(repr(cleaned))
# '\ndef hello():\n    print("Hello, world!")\n'

    ✅ 非常适合写 docstring 或帮助文本！

    4. textwrap.indent(text, prefix, predicate=None)¶

    • 功能：给文本的每一行添加前缀（如缩进）。
    • prefix：要添加的字符串（如 " "）。
    • predicate：可选函数，决定哪些行需要加前缀（默认所有非空行）。
    text = "Line 1\nLine 2\n\nLine 4"
indented = textwrap.indent(text, ">>> ")
print(indented)
# 输出：
# >>> Line 1
# >>> Line 2
# >>>
# >>> Line 4

    5. textwrap.shorten(text, width, **kwargs)¶

    • 功能：将文本缩短到指定宽度，并在末尾加省略号（...）。
    • 会先去除多余空白，再截断。
    long_text = "This is a very long description that should be shortened."
short = textwrap.shorten(long_text, width=30, placeholder="...")
print(short)
# 输出：This is a very long...

    二、常用参数说明（适用于 wrap, fill, shorten）¶

    参数 说明
    width 每行最大字符数（默认 70）
    expand_tabs 是否将 tab 转为空格（默认 True）
    replace_whitespace 是否将空白字符（如 \t, \n）替换为空格（默认 True）
    drop_whitespace 是否丢弃行首尾的空白（默认 True）
    break_long_words 是否允许在单词中间断开（默认 True）
    break_on_hyphens 是否在连字符 - 处断行（默认 True）
    max_lines 最大行数（shorten 和 fill 支持）
    placeholder 截断时使用的占位符（默认 '...'）

    三、实际应用示例¶

    示例 1：生成帮助信息¶

    help_text = """
    This tool does something useful.
    It supports multiple options:
      -v: verbose mode
      -o: output file
"""
print(textwrap.dedent(help_text).strip())

    示例 2：格式化日志或消息¶

    message = "Error: The configuration file is missing or invalid. Please check the path and permissions."
formatted = textwrap.fill(message, width=50, initial_indent="ERROR: ", subsequent_indent="       ")
print(formatted)
    输出： 
    ERROR: Error: The configuration file is
       missing or invalid. Please check the
       path and permissions.

    💡 initial_indent 和 subsequent_indent 可用于首行和其他行不同缩进。

    四、总结¶

    函数 用途
    wrap() 拆分为行列表
    fill() 自动换行并返回字符串（最常用）
    dedent() 去除公共缩进
    indent() 添加统一前缀
    shorten() 截断并加省略号

    ✅ 推荐组合使用：dedent() + fill() 是处理多行文本的黄金搭档！
