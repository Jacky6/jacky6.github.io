    33_工厂模式¶

    1. 工厂模式概述¶

    1.1 什么是工厂模式¶

    工厂模式（Factory Pattern）是一种创建型设计模式，提供创建对象的接口，而不暴露创建逻辑。

    优点： - ✅ 解耦：客户端不需要知道具体类的创建 - ✅ 扩展性好：新增产品不需要修改客户端代码 - ✅ 集中管理：对象创建逻辑集中管理

    类型： - 简单工厂（Simple Factory） - 工厂方法（Factory Method） - 抽象工厂（Abstract Factory）

    2. 简单工厂¶

    2.1 实现方式¶

    // 产品接口
public interface Animal {
    void speak();
}

// 具体产品
public class Dog implements Animal {
    @Override
    public void speak() {
        System.out.println("汪汪汪");
    }
}

public class Cat implements Animal {
    @Override
    public void speak() {
        System.out.println("喵喵喵");
    }
}

// 工厂类
public class AnimalFactory {
    public static Animal createAnimal(String type) {
        if ("dog".equals(type)) {
            return new Dog();
        } else if ("cat".equals(type)) {
            return new Cat();
        }
        throw new IllegalArgumentException("Unknown animal type");
    }
}

// 使用
Animal dog = AnimalFactory.createAnimal("dog");
dog.speak();  // 汪汪汪

    2.2 特点¶

    优点 缺点
    客户端不需要知道创建逻辑 工厂类职责过重
    简单易懂 违反开闭原则
    新增产品需修改工厂

    3. 工厂方法¶

    3.1 实现方式¶

    // 产品接口
public interface Animal {
    void speak();
}

// 具体产品
public class Dog implements Animal {
    @Override
    public void speak() {
        System.out.println("汪汪汪");
    }
}

public class Cat implements Animal {
    @Override
    public void speak() {
        System.out.println("喵喵喵");
    }
}

// 工厂接口
public interface AnimalFactory {
    Animal createAnimal();
}

// 具体工厂
public class DogFactory implements AnimalFactory {
    @Override
    public Animal createAnimal() {
        return new Dog();
    }
}

public class CatFactory implements AnimalFactory {
    @Override
    public Animal createAnimal() {
        return new Cat();
    }
}

// 使用
AnimalFactory factory = new DogFactory();
Animal dog = factory.createAnimal();
dog.speak();  // 汪汪汪

    3.2 特点¶

    优点 缺点
    符合开闭原则 类数量翻倍
    解耦 系统复杂度增加
    扩展性好

    4. 抽象工厂¶

    4.1 实现方式¶

    // 产品族 A
public interface Dog {
    void speak();
}

public interface Cat {
    void speak();
}

// 产品族 B（不同品种）
public class Husky implements Dog {
    @Override
    public void speak() {
        System.out.println("哈士奇在叫");
    }
}

public class Persian implements Cat {
    @Override
    public void speak() {
        System.out.println("波斯猫在叫");
    }
}

public class Labrador implements Dog {
    @Override
    public void speak() {
        System.out.println("拉布拉多在叫");
    }
}

public class British implements Cat {
    @Override
    public void speak() {
        System.out.println("英短在叫");
    }
}

// 抽象工厂
public interface AnimalFactory {
    Dog createDog();
    Cat createCat();
}

// 具体工厂
public class PetShopA implements AnimalFactory {
    @Override
    public Dog createDog() {
        return new Husky();
    }

    @Override
    public Cat createCat() {
        return new Persian();
    }
}

public class PetShopB implements AnimalFactory {
    @Override
    public Dog createDog() {
        return new Labrador();
    }

    @Override
    public Cat createCat() {
        return new British();
    }
}

// 使用
AnimalFactory shop = new PetShopA();
Dog dog = shop.createDog();
Cat cat = shop.createCat();

    4.2 特点¶

    优点 缺点
    产品族一致性好 产品等级扩展困难
    隔离具体类 接口修改影响大
    符合开闭原则

    5. 三种工厂对比¶

    特性 简单工厂 工厂方法 抽象工厂
    结构 一个工厂类 工厂接口 + 多个实现 工厂接口 + 产品族
    扩展产品 修改工厂 新增工厂类 新增工厂类
    扩展产品族 不支持 不支持 支持
    复杂度 低 中 高
    适用场景 简单场景 单一产品等级 产品族场景

    6. 实战示例¶

    6.1 数据库连接工厂¶

    // 产品接口
public interface Connection {
    void connect();
}

// 具体产品
public class MySqlConnection implements Connection {
    @Override
    public void connect() {
        System.out.println("连接 MySQL 数据库");
    }
}

public class OracleConnection implements Connection {
    @Override
    public void connect() {
        System.out.println("连接 Oracle 数据库");
    }
}

// 工厂类
public class ConnectionFactory {
    public static Connection getConnection(String type) {
        if ("mysql".equals(type)) {
            return new MySqlConnection();
        } else if ("oracle".equals(type)) {
            return new OracleConnection();
        }
        throw new IllegalArgumentException("Unknown database type");
    }
}

// 使用
Connection conn = ConnectionFactory.getConnection("mysql");
conn.connect();

    6.2 日志工厂¶

    // 产品接口
public interface Logger {
    void log(String message);
}

// 具体产品
public class FileLogger implements Logger {
    @Override
    public void log(String message) {
        System.out.println("写入文件：" + message);
    }
}

public class ConsoleLogger implements Logger {
    @Override
    public void log(String message) {
        System.out.println("控制台输出：" + message);
    }
}

public class DatabaseLogger implements Logger {
    @Override
    public void log(String message) {
        System.out.println("写入数据库：" + message);
    }
}

// 工厂接口
public interface LoggerFactory {
    Logger createLogger();
}

// 具体工厂
public class FileLoggerFactory implements LoggerFactory {
    @Override
    public Logger createLogger() {
        return new FileLogger();
    }
}

public class ConsoleLoggerFactory implements LoggerFactory {
    @Override
    public Logger createLogger() {
        return new ConsoleLogger();
    }
}

// 使用
LoggerFactory factory = new ConsoleLoggerFactory();
Logger logger = factory.createLogger();
logger.log("Hello World");

    7. 本章小结¶

    核心知识点¶

    ✅ 简单工厂：一个工厂类创建所有产品
    ✅ 工厂方法：工厂接口 + 多个具体工厂
    ✅ 抽象工厂：创建产品族
    ✅ 三种工厂对比：适用场景不同

    最佳实践¶

    1. 简单工厂：产品少、变化少的场景
    2. 工厂方法：单一产品等级，需要扩展
    3. 抽象工厂：产品族场景，需要一致性
    4. 结合 Spring：使用 Spring IOC 容器
    5. 避免过度设计：简单场景直接用 new
