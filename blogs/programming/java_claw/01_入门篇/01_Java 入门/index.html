    01_Java 入门¶

    1. Java 简介¶

    1.1 什么是 Java¶

    Java 是一种高级、面向对象、跨平台的编程语言，由 Sun Microsystems（现 Oracle）于 1995 年发布。

    特点： - ✅ 面向对象：封装、继承、多态 - ✅ 跨平台：Write Once, Run Anywhere（WORA） - ✅ 简单性：语法简洁，易于学习 - ✅ 安全性：沙箱机制、字节码验证 - ✅ 多线程：内置线程支持 - ✅ 健壮性：强类型、异常处理、垃圾回收

    1.2 Java 版本历史¶

    版本 发布时间 重要特性
    Java 8 2014 Lambda、Stream API、Optional ⭐
    Java 11 2018 LTS 版本、var 局部变量
    Java 17 2021 LTS 版本、sealed classes
    Java 21 2023 LTS 版本、虚拟线程

    建议：学习使用 Java 8、11 或 17（LTS 长期支持版）

    3. HelloWorld¶

    3.1 第一个 Java 程序¶

    public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

    3.2 代码解析¶

    public class HelloWorld {          // 1. 定义公共类，类名与文件名一致
    public static void main(String[] args) {  // 2. 主方法，程序入口
        System.out.println("Hello, Java!");   // 3. 打印输出
    }
}

    关键点： - public class：公共类，一个文件只能有一个 public 类 - main 方法：程序入口，签名固定 - System.out.println：标准输出 - 每条语句以 ; 结尾 - Java 区分大小写

    3.3 编译和运行¶

    命令行方式¶

    # 1. 编写代码（HelloWorld.java）
# 2. 编译
javac HelloWorld.java

# 3. 运行
java HelloWorld

# 输出：Hello, Java!

    IDE 方式¶

    1. 创建 Java 文件
    2. 编写代码
    3. 点击运行按钮（或 Shift+F10）

    4. Java 程序结构¶

    4.1 基本结构¶

    // 1. 包声明（可选）
package com.example.demo;

// 2. 导入语句（可选）
import java.util.Scanner;

// 3. 类定义
public class MyClass {
    // 4. 成员变量
    private int value;

    // 5. 构造方法
    public MyClass() {
    }

    // 6. 成员方法
    public void doSomething() {
        System.out.println("Doing something");
    }

    // 7. main 方法（程序入口）
    public static void main(String[] args) {
        MyClass obj = new MyClass();
        obj.doSomething();
    }
}

    5. 命名规范¶

    5.1 命名规则¶

    元素 规范 示例
    类名 大驼峰（PascalCase） Person, StudentInfo
    方法名 小驼峰（camelCase） getName(), calculateTotal()
    变量名 小驼峰 userName, totalCount
    常量名 全大写，下划线分隔 MAX_VALUE, DEFAULT_SIZE
    包名 全小写，域名反写 com.example.demo

    5.2 最佳实践¶

    // ✅ 好的命名
public class StudentInfo {
    private String studentName;
    private int studentAge;
    public static final int MAX_SCORE = 100;

    }

// ❌ 不好的命名

    }

    6. 常见问题¶

    6.1 编译错误¶

    错误 1：找不到类 

    Error: Could not find or load main class HelloWorld
    解决：确保在正确的目录运行，类名与文件名一致

    错误 2：javac 不是内部命令 

    'javac' 不是内部或外部命令
    解决：配置 JAVA_HOME 和 Path 环境变量

    6.2 运行错误¶

    错误：主方法未找到 

    Error: Main method not found in class HelloWorld
    解决：检查 main 方法签名是否正确 
    public static void main(String[] args)  // ✅ 正确
public static void main(String[] arg)   // ❌ 错误
