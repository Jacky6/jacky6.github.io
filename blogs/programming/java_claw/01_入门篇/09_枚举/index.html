    09_枚举¶

    1. 枚举概述¶

    1.1 什么是枚举¶

    枚举（Enum）是一种特殊的数据类型，用于定义一组固定的常量。

    使用场景： - ✅ 固定的状态（星期、月份、季节） - ✅ 固定的类型（订单状态、用户角色） - ✅ 替代 int 常量（类型安全）

    1.2 为什么需要枚举¶

    // ❌ 使用 int 常量（不推荐）
public class Constants {
    public static final int MONDAY = 1;
    public static final int TUESDAY = 2;
}

// ✅ 使用枚举（推荐）
public enum DayOfWeek {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

    2. 枚举定义和使用¶

    2.1 基本定义¶

    public enum DayOfWeek {
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY,
    SUNDAY
}

// 使用
public class Main {
    public static void main(String[] args) {
        DayOfWeek today = DayOfWeek.MONDAY;

        // 比较
        if (today == DayOfWeek.MONDAY) {
            System.out.println("今天是周一");
        }

        // 打印
        System.out.println(today);  // MONDAY
        System.out.println(today.name());  // MONDAY
        System.out.println(today.ordinal());  // 0（索引）
    }
}

    2.2 常用方法¶

    public enum Status {
    PENDING, PROCESSING, COMPLETED, CANCELLED
}

public class Main {
    public static void main(String[] args) {
        // values() - 获取所有枚举值
        Status[] statuses = Status.values();
        for (Status s : statuses) {
            System.out.println(s);
        }

        // valueOf() - 字符串转枚举
        Status status = Status.valueOf("PENDING");

        // ordinal() - 获取索引
        int index = Status.COMPLETED.ordinal();  // 2

        // compareTo() - 比较顺序
        int cmp = Status.PENDING.compareTo(Status.COMPLETED);  // -2
    }
}

    3. 枚举的字段和方法¶

    3.1 带字段的枚举¶

    public enum Season {
    SPRING("春", "春暖花开"),
    SUMMER("夏", "烈日炎炎"),
    AUTUMN("秋", "秋高气爽"),
    WINTER("冬", "白雪皑皑");

    // 字段
    private final String chineseName;
    private final String description;

    // 构造方法（必须 private）
    Season(String chineseName, String description) {
        this.chineseName = chineseName;
        this.description = description;
    }

    // getter 方法
    public String getChineseName() {
        return chineseName;
    }

    public String getDescription() {
        return description;
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Season spring = Season.SPRING;
        System.out.println(spring.getChineseName());  // 春
        System.out.println(spring.getDescription());  // 春暖花开
    }
}

    3.2 带方法的枚举¶

    public enum Operation {
    PLUS("+") {
        @Override
        public double apply(double x, double y) {
            return x + y;
        }
    },
    MINUS("-") {
        @Override
        public double apply(double x, double y) {
            return x - y;
        }
    },
    TIMES("*") {
        @Override
        public double apply(double x, double y) {
            return x * y;
        }
    },
    DIVIDE("/") {
        @Override
        public double apply(double x, double y) {
            return x / y;
        }
    };

    private final String symbol;

    Operation(String symbol) {
        this.symbol = symbol;
    }

    // 抽象方法
    public abstract double apply(double x, double y);

    public String getSymbol() {
        return symbol;
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        double result = Operation.PLUS.apply(10, 5);  // 15.0
        System.out.println(result);
    }
}

    5. EnumSet 和 EnumMap¶

    5.1 EnumSet¶

    import java.util.EnumSet;

public enum DayOfWeek {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

public class Main {
    public static void main(String[] args) {
        // 创建 EnumSet
        EnumSet<DayOfWeek> weekdays = EnumSet.of(
            DayOfWeek.MONDAY,
            DayOfWeek.TUESDAY,
            DayOfWeek.WEDNESDAY,
            DayOfWeek.THURSDAY,
            DayOfWeek.FRIDAY
        );

        // 范围
        EnumSet<DayOfWeek> range = EnumSet.range(
            DayOfWeek.MONDAY, 
            DayOfWeek.FRIDAY
        );

        // 全部
        EnumSet<DayOfWeek> all = EnumSet.allOf(DayOfWeek.class);

        // 补集
        EnumSet<DayOfWeek> weekend = EnumSet.complementOf(weekdays);
    }
}

    5.2 EnumMap¶

    import java.util.EnumMap;
import java.util.Map;

public enum Status {
    PENDING, PROCESSING, COMPLETED
}

public class Main {
    public static void main(String[] args) {
        // 创建 EnumMap
        Map<Status, String> map = new EnumMap<>(Status.class);

        // 添加
        map.put(Status.PENDING, "待处理");
        map.put(Status.PROCESSING, "处理中");
        map.put(Status.COMPLETED, "已完成");

        // 获取
        String desc = map.get(Status.PENDING);
    }
}

    6. 枚举单例¶

    // 枚举实现单例（推荐）
public enum Singleton {
    INSTANCE;

    public void doSomething() {
        System.out.println("单例方法");
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Singleton s1 = Singleton.INSTANCE;
        Singleton s2 = Singleton.INSTANCE;

        System.out.println(s1 == s2);  // true

        s1.doSomething();
    }
}

    优点： - ✅ 线程安全 - ✅ 防止反射攻击 - ✅ 防止序列化破坏 - ✅ 代码简洁

    7.2 用户角色¶

    public enum Role {
    ADMIN("管理员", 1),
    MANAGER("经理", 2),
    USER("普通用户", 3),
    GUEST("访客", 4);

    private final String name;
    private final int level;

    Role(String name, int level) {
        this.name = name;
        this.level = level;
    }

    public boolean hasPermission(Role required) {
        return this.level <= required.level;
    }
}

// 使用
public class User {
    private Role role;

    public boolean canAccess(Resource resource) {
        return role.hasPermission(resource.getRequiredRole());
    }
}

    8. 本章小结¶

    核心知识点¶

    ✅ 枚举定义：enum 关键字，固定常量
    ✅ 枚举字段和方法：构造方法、getter、抽象方法
    ✅ 枚举实现接口：支持接口实现
    ✅ EnumSet/EnumMap：专用集合
    ✅ 枚举单例：最安全的单例实现

    最佳实践¶

    1. 用枚举替代 int 常量：类型安全
    2. 枚举带字段：存储更多信息
    3. 状态流转用枚举：清晰的狀態管理
    4. 单例用枚举：最安全简洁
