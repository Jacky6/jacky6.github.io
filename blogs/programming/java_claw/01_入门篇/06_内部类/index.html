    06_内部类¶

    1. 内部类概述¶

    1.1 什么是内部类¶

    内部类（Inner Class）是定义在另一个类内部的类。

    优点： - ✅ 更好的封装性 - ✅ 访问外部类的私有成员 - ✅ 逻辑分组，代码更清晰 - ✅ 实现多重继承的效果

    1.2 内部类分类¶

    内部类
├── 成员内部类（Member Inner Class）
├── 静态内部类（Static Inner Class）
├── 局部内部类（Local Inner Class）
└── 匿名内部类（Anonymous Inner Class）

    2. 成员内部类¶

    2.1 定义和使用¶

    public class Outer {
    private String outerField = "外部类字段";

    // 成员内部类
    public class Inner {
        private String innerField = "内部类字段";

        public void show() {
            // 访问外部类成员
            System.out.println(outerField);
            System.out.println(innerField);
        }
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        // 创建外部类实例
        Outer outer = new Outer();

        // 创建内部类实例
        Outer.Inner inner = outer.new Inner();
        inner.show();
    }
}

    2.2 访问外部类¶

    public class Outer {
    private String name = "Outer";

    public class Inner {
        private String name = "Inner";

        public void show() {
            String name = "Local";

            // 访问局部变量
            System.out.println(name);  // Local

            // 访问内部类成员
            System.out.println(this.name);  // Inner

            // 访问外部类成员
            System.out.println(Outer.this.name);  // Outer
        }
    }
}

    3. 静态内部类¶

    3.1 定义和使用¶

    public class Outer {
    private static String staticField = "静态字段";

    // 静态内部类
    public static class StaticInner {
        public void show() {
            // 只能访问外部类的静态成员
            System.out.println(staticField);
        }
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        // 不需要外部类实例
        Outer.StaticInner inner = new Outer.StaticInner();
        inner.show();
    }
}

    3.3 静态内部类 vs 成员内部类¶

    特性 成员内部类 静态内部类
    外部类实例 需要 不需要
    访问外部类 所有成员 仅静态成员
    创建方式 outer.new Inner() new Outer.Inner()
    使用场景 需要访问实例成员 工具类、辅助类

    4. 局部内部类¶

    4.1 定义在方法中¶

    public class Outer {
    private String outerField = "外部类";

    public void method() {
        String localVar = "局部变量";

        // 局部内部类
        class LocalInner {
            public void show() {
                System.out.println(outerField);
                System.out.println(localVar);  // Java 8+ 要求 final 或 effectively final
            }
        }

        // 使用
        LocalInner inner = new LocalInner();
        inner.show();
    }
}

    4.2 使用场景¶

    // 用于复杂逻辑的封装
public class Calculator {
    public int calculate(int a, int b) {
        // 局部内部类
        class Operation {
            int add(int x, int y) {
                return x + y;
            }
        }

        Operation op = new Operation();
        return op.add(a, b);
    }
}

    5. 匿名内部类 ⭐⭐⭐¶

    5.1 定义和使用¶

    // 实现接口
interface Animal {
    void speak();
}

public class Main {
    public static void main(String[] args) {
        // 匿名内部类
        Animal dog = new Animal() {
            @Override
            public void speak() {
                System.out.println("汪汪汪");
            }
        };

        dog.speak();  // 汪汪汪
    }
}

    5.2 继承类¶

    abstract class Person {
    abstract void sayHello();
}

public class Main {
    public static void main(String[] args) {
        Person p = new Person() {
            @Override
            void sayHello() {
                System.out.println("Hello");
            }
        };

        p.sayHello();
    }
}

    5.3 作为方法参数¶

    // 线程创建
new Thread(new Runnable() {
    @Override
    public void run() {
        System.out.println("线程执行");
    }
}).start();

// Lambda 简化（Java 8+）
new Thread(() -> System.out.println("线程执行")).start();

// 事件监听
button.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent e) {
        System.out.println("按钮点击");
    }
});

// Lambda 简化
button.addActionListener(e -> System.out.println("按钮点击"));

    5.4 匿名内部类特点¶

    • ✅ 没有类名
    • ✅ 只能创建一个实例
    • ✅ 不能定义静态成员（除了常量）
    • ✅ 只能访问 final 或 effectively final 的局部变量

    6. 内部类应用¶

    6.1 单例模式（静态内部类）¶

    public class Singleton {
    private Singleton() {}

    // 静态内部类
    private static class Holder {
        private static final Singleton INSTANCE = new Singleton();
    }

    public static Singleton getInstance() {
        return Holder.INSTANCE;
    }
}

    优点： - ✅ 线程安全（JVM 保证） - ✅ 延迟加载 - ✅ 无锁开销

    6.2 构建者模式¶

    public class Person {
    private String name;
    private int age;
    private String address;

    private Person(Builder builder) {
        this.name = builder.name;
        this.age = builder.age;
        this.address = builder.address;
    }

    // 静态内部类作为 Builder
    public static class Builder {
        private String name;
        private int age;
        private String address;

        public Builder setName(String name) {
            this.name = name;
            return this;
        }

        public Builder setAge(int age) {
            this.age = age;
            return this;
        }

        public Builder setAddress(String address) {
            this.address = address;
            return this;
        }

        public Person build() {
            return new Person(this);
        }
    }
}

// 使用
Person p = new Person.Builder()
    .setName("张三")
    .setAge(25)
    .setAddress("北京")
    .build();

    7. 内部类对比¶

    类型 定义位置 访问外部类 创建方式 使用场景
    成员内部类 类内部 所有成员 outer.new Inner() 需要访问实例成员
    静态内部类 类内部（static） 静态成员 new Outer.Inner() 工具类、单例
    局部内部类 方法内部 所有成员 方法内创建 复杂逻辑封装
    匿名内部类 方法/表达式 所有成员 new Interface() {} 一次性使用

    8. 本章小结¶

    核心知识点¶

    ✅ 成员内部类：访问外部类所有成员
    ✅ 静态内部类：独立于外部类实例
    ✅ 局部内部类：定义在方法中
    ✅ 匿名内部类：一次性使用的简化写法

    最佳实践¶

    1. 优先使用静态内部类：不需要访问实例成员时
    2. 匿名内部类用 Lambda 替代：Java 8+
    3. 避免过度使用内部类：保持代码清晰
    4. 单例推荐静态内部类：线程安全、延迟加载
