    08_抽象类与接口¶

    1. 抽象类¶

    1.1 什么是抽象类¶

    抽象类（Abstract Class）是用 abstract 修饰的类，不能被实例化，只能被继承。

    特点： - ✅ 可以包含抽象方法和具体方法 - ✅ 不能被实例化 - ✅ 用于代码复用和模板设计

    1.2 抽象方法¶

    // 抽象类
public abstract class Animal {
    // 普通字段
    protected String name;

    // 构造方法
    public Animal(String name) {
        this.name = name;
    }

    // 抽象方法（没有方法体）
    public abstract void speak();

    // 具体方法
    public void sleep() {
        System.out.println(name + " 在睡觉");
    }
}

// 子类实现抽象方法
public class Dog extends Animal {
    public Dog(String name) {
        super(name);
    }

    @Override
    public void speak() {
        System.out.println(name + " 汪汪汪");
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        // ❌ 不能实例化抽象类
        // Animal a = new Animal("动物");

        // ✅ 可以实例化子类
        Animal dog = new Dog("旺财");
        dog.speak();  // 旺财 汪汪汪
        dog.sleep();  // 旺财 在睡觉
    }
}

    1.3 抽象类特点¶

    public abstract class AbstractDemo {
    // ✅ 可以有构造方法（供子类调用）
    public AbstractDemo() {
    }

    // ✅ 可以有字段
    private String field;

    // ✅ 可以有抽象方法
    public abstract void abstractMethod();

    // ✅ 可以有具体方法
    public void concreteMethod() {
        System.out.println("具体方法");
    }

    // ✅ 可以有静态方法
    public static void staticMethod() {
        System.out.println("静态方法");
    }

    // ❌ 不能有 final 方法（final 不能重写）
    // public final void finalMethod() {}
}

    2. 接口¶

    2.1 什么是接口¶

    接口（Interface）是完全抽象的类型，定义行为规范。

    特点： - ✅ 所有方法默认是 public abstract - ✅ 所有字段默认是 public static final - ✅ 支持多实现 - ✅ Java 8+ 支持默认方法和静态方法

    2.2 接口定义¶

    // 接口定义
public interface Flyable {
    // 常量（public static final）
    int MAX_HEIGHT = 1000;

    // 抽象方法（public abstract）
    void fly();

    // Java 8+ 默认方法
    default void land() {
        System.out.println("降落");
    }

    // Java 8+ 静态方法
    static void showInfo() {
        System.out.println("这是 Flyable 接口");
    }

    // Java 9+ 私有方法
    private void helper() {
        // 辅助默认方法
    }
}

// 实现接口
public class Bird implements Flyable {
    @Override
    public void fly() {
        System.out.println("鸟儿飞翔");
    }

    // 可以重写默认方法
    @Override
    public void land() {
        System.out.println("鸟儿降落");
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Bird bird = new Bird();
        bird.fly();   // 鸟儿飞翔
        bird.land();  // 鸟儿降落

        // 调用静态方法
        Flyable.showInfo();
    }
}

    2.3 多实现¶

    public interface Swimmable {
    void swim();
}

public interface Flyable {
    void fly();
}

// 实现多个接口
public class Duck implements Flyable, Swimmable {
    @Override
    public void fly() {
        System.out.println("鸭子飞翔");
    }

    @Override
    public void swim() {
        System.out.println("鸭子游泳");
    }
}

    3. 抽象类 vs 接口 ⭐⭐⭐¶

    3.1 对比表¶

    特性 抽象类 接口
    实例化 ❌ 不能 ❌ 不能
    继承/实现 单继承 多实现
    构造方法 ✅ 可以有 ❌ 不能有
    字段 任意类型 public static final
    方法 任意类型 public abstract（默认）
    默认方法 ✅ 可以有 ✅ Java 8+
    静态方法 ✅ 可以有 ✅ Java 8+
    设计目的 代码复用 行为规范

    3.2 选择指南¶

    何时使用抽象类：
- 需要共享代码（具体方法）
- 需要非 public 成员
- 需要字段状态
- 单继承层次结构

何时使用接口：
- 需要多实现
- 定义行为规范
- 不相关的类实现相同行为
- API 设计（对外暴露）

    3.3 组合使用¶

    // 接口定义行为
public interface Payment {
    void pay(BigDecimal amount);
}

// 抽象类提供通用实现
public abstract class AbstractPayment implements Payment {
    protected String merchantId;

    public AbstractPayment(String merchantId) {
        this.merchantId = merchantId;
    }

    // 模板方法
    @Override
    public final void pay(BigDecimal amount) {
        validate(amount);
        doPay(amount);
        log(amount);
    }

    // 抽象方法，子类实现
    protected abstract void doPay(BigDecimal amount);

    // 具体方法
    protected void validate(BigDecimal amount) {
        if (amount.compareTo(BigDecimal.ZERO) <= 0) {
            throw new IllegalArgumentException("金额必须大于 0");
        }
    }

    protected void log(BigDecimal amount) {
        System.out.println("支付记录：" + amount);
    }
}

// 具体实现
public class Alipay extends AbstractPayment {
    public Alipay(String merchantId) {
        super(merchantId);
    }

    @Override
    protected void doPay(BigDecimal amount) {
        System.out.println("支付宝支付：" + amount);
    }
}

    4. 函数式接口 ⭐⭐⭐¶

    4.1 什么是函数式接口¶

    函数式接口：只有一个抽象方法的接口。

    特点： - ✅ 可以用 Lambda 表达式实现 - ✅ 使用 @FunctionalInterface 注解

    4.2 内置函数式接口¶

    import java.util.function.*;

public class FunctionalDemo {
    public static void main(String[] args) {
        // Consumer - 消费型（有参无返回）
        Consumer<String> printer = s -> System.out.println(s);
        printer.accept("Hello");

        // Supplier - 供给型（无参有返回）
        Supplier<Double> random = () -> Math.random();
        Double num = random.get();

        // Function - 函数型（有参有返回）
        Function<String, Integer> parser = Integer::parseInt;
        Integer result = parser.apply("123");

        // Predicate - 断言型（有参返回 boolean）
        Predicate<String> isEmpty = String::isEmpty;
        boolean blank = isEmpty.test("");

        // UnaryOperator - 一元操作符（同类型）
        UnaryOperator<Integer> square = x -> x * x;
        Integer squared = square.apply(5);

        // BinaryOperator - 二元操作符
        BinaryOperator<Integer> add = (a, b) -> a + b;
        Integer sum = add.apply(3, 4);
    }
}

    4.3 自定义函数式接口¶

    @FunctionalInterface
public interface Converter<T, R> {
    R convert(T source);
}

// 使用
public class Main {
    public static void main(String[] args) {
        Converter<String, Integer> converter = Integer::parseInt;
        Integer result = converter.convert("123");
    }
}

    5. 接口继承¶

    5.1 接口继承接口¶

    public interface A {
    void methodA();
}

public interface B {
    void methodB();
}

// 接口多继承
public interface C extends A, B {
    void methodC();
}

// 实现类需要实现所有方法
public class Impl implements C {
    @Override
    public void methodA() {}

    @Override
    public void methodB() {}

    @Override
    public void methodC() {}
}

    5.2 默认方法冲突¶

    public interface A {
    default void show() {
        System.out.println("A");
    }
}

public interface B {
    default void show() {
        System.out.println("B");
    }
}

// 解决冲突
public class C implements A, B {
    @Override
    public void show() {
        // 方式 1：自己实现
        System.out.println("C");

        // 方式 2：调用特定接口
        // A.super.show();
        // B.super.show();
    }
}

    6. 实战示例¶

    6.1 模板方法模式¶

    // 抽象类定义模板
public abstract class DataProcessor {

    // 模板方法（final 防止重写）
    public final void process(String file) {
        loadData(file);
        validate();
        transform();
        save();
    }

    // 抽象方法
    protected abstract void loadData(String file);
    protected abstract void validate();
    protected abstract void transform();
    protected abstract void save();
}

// CSV 处理器
public class CsvProcessor extends DataProcessor {
    @Override
    protected void loadData(String file) {
        System.out.println("加载 CSV：" + file);
    }

    @Override
    protected void validate() {
        System.out.println("验证 CSV 格式");
    }

    @Override
    protected void transform() {
        System.out.println("转换 CSV 数据");
    }

    @Override
    protected void save() {
        System.out.println("保存到数据库");
    }
}

// JSON 处理器

public class MergeSortStrategy implements SortStrategy {

        System.out.println("归并排序");
        // 实现...
    }
}

// 上下文
public class Sorter {
    private SortStrategy strategy;

    public void setStrategy(SortStrategy strategy) {
        this.strategy = strategy;
    }

    public <T extends Comparable<T>> void sort(List<T> list) {
        strategy.sort(list);
    }
}

    7. 本章小结¶

    核心知识点¶

    ✅ 抽象类：abstract 修饰，单继承，代码复用
    ✅ 接口：行为规范，多实现，Java 8+ 默认方法
    ✅ 抽象类 vs 接口：设计目的不同
    ✅ 函数式接口：Lambda 表达式基础

    最佳实践¶

    1. 优先使用接口：定义行为规范
    2. 抽象类用于复用：共享代码实现
    3. 组合优于继承：接口 + 抽象类组合
    4. 函数式接口用 Lambda：代码更简洁
