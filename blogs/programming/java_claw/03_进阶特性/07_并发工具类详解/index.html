    07_并发工具类详解¶

    1. CountDownLatch¶

    1.1 概述¶

    CountDownLatch 允许一个或多个线程等待其他线程完成操作。

    特点： - ✅ 倒计时器，不可重用 - ✅ 一个或多个线程等待 - ✅ 其他线程执行后倒计数

    1.2 基本使用¶

    import java.util.concurrent.CountDownLatch;

public class CountDownLatchDemo {
    public static void main(String[] args) throws InterruptedException {
        CountDownLatch latch = new CountDownLatch(3);

        // 3 个工作线程
        for (int i = 0; i < 3; i++) {
            new Thread(() -> {
                System.out.println(Thread.currentThread().getName() + " 执行任务");
                try {
                    Thread.sleep(1000);
                } catch (InterruptedException e) {}
                latch.countDown();  // 计数减 1
                System.out.println(Thread.currentThread().getName() + " 完成");
            }).start();
        }

        // 主线程等待
        latch.await();  // 等待计数为 0
        System.out.println("所有任务完成，继续执行");
    }
}

    1.3 使用场景¶

    // 场景 1：等待多个服务启动
public class ServiceStarter {
    private CountDownLatch latch = new CountDownLatch(3);

    public void startAll() throws InterruptedException {
        startService("DB", latch);
        startService("Cache", latch);
        startService("MQ", latch);

        latch.await();  // 等待所有服务启动
        System.out.println("所有服务启动完成");
    }

    private void startService(String name, CountDownLatch latch) {
        new Thread(() -> {
            System.out.println(name + " 启动中...");
            try { Thread.sleep(1000); } catch (InterruptedException e) {}
            System.out.println(name + " 启动完成");
            latch.countDown();
        }).start();
    }
}

// 场景 2：并发测试
public class PerformanceTest {
    public static void test(List<Runnable> tasks) throws InterruptedException {
        CountDownLatch startLatch = new CountDownLatch(1);
        CountDownLatch endLatch = new CountDownLatch(tasks.size());

        for (Runnable task : tasks) {
            new Thread(() -> {
                try {
                    startLatch.await();  // 等待开始信号
                    task.run();
                } catch (InterruptedException e) {}
                finally {
                    endLatch.countDown();
                }
            }).start();
        }

        Thread.sleep(100);  // 确保所有线程就绪
        startLatch.countDown();  // 同时开始
        endLatch.await();  // 等待所有完成
    }
}

    2. CyclicBarrier¶

    2.1 概述¶

    CyclicBarrier 让一组线程互相等待，到达屏障点后再一起继续。

    特点： - ✅ 可重用（循环使用） - ✅ 多个线程互相等待 - ✅ 可执行屏障动作

    2.2 基本使用¶

    import java.util.concurrent.CyclicBarrier;

public class CyclicBarrierDemo {
    public static void main(String[] args) {
        CyclicBarrier barrier = new CyclicBarrier(3, () -> {
            System.out.println("所有线程到达，执行屏障动作");
        });

        for (int i = 0; i < 3; i++) {
            new Thread(() -> {
                System.out.println(Thread.currentThread().getName() + " 到达屏障");
                try {
                    barrier.await();  // 等待其他线程
                    System.out.println(Thread.currentThread().getName() + " 继续执行");
                } catch (Exception e) {}
            }).start();
        }
    }
}

    2.3 使用场景¶

    // 场景：多线程计算后合并结果
public class DataProcessor {
    private CyclicBarrier barrier;
    private List<Result> results = new ArrayList<>();

    public DataProcessor(int threadCount) {
        barrier = new CyclicBarrier(threadCount, () -> {
            // 所有线程完成后合并结果
            mergeResults();
        });
    }

    public void process(List<Data> dataList) {
        int chunkSize = dataList.size() / 3;

        for (int i = 0; i < 3; i++) {
            int start = i * chunkSize;
            int end = (i == 2) ? dataList.size() : start + chunkSize;
            List<Data> chunk = dataList.subList(start, end);

            new Thread(() -> {
                Result result = processChunk(chunk);
                synchronized (results) {
                    results.add(result);
                }
                try {
                    barrier.await();
                } catch (Exception e) {}
            }).start();
        }
    }

    private void mergeResults() {
        System.out.println("合并结果：" + results.size() + " 个");
    }
}

    3. Semaphore¶

    3.1 概述¶

    Semaphore（信号量）控制同时访问特定资源的线程数量。

    特点： - ✅ 限流 - ✅ 控制并发访问数 - ✅ 公平/非公平模式

    3.2 基本使用¶

    import java.util.concurrent.Semaphore;

public class SemaphoreDemo {
    private Semaphore semaphore = new Semaphore(3);  // 允许 3 个并发

    public void access() {
        try {
            semaphore.acquire();  // 获取许可
            System.out.println(Thread.currentThread().getName() + " 开始访问");
            Thread.sleep(1000);
            System.out.println(Thread.currentThread().getName() + " 结束访问");
        } catch (InterruptedException e) {
            e.printStackTrace();
        } finally {
            semaphore.release();  // 释放许可
        }
    }

    public static void main(String[] args) {
        SemaphoreDemo demo = new SemaphoreDemo();

        for (int i = 0; i < 10; i++) {
            new Thread(() -> demo.access()).start();
        }
    }
}

    3.3 使用场景¶

    // 场景 1：数据库连接池限流
public class DatabasePool {
    private Semaphore connections = new Semaphore(10);

    public Connection getConnection() throws InterruptedException {
        connections.acquire();
        return createConnection();
    }

    public void releaseConnection(Connection conn) {
        closeConnection(conn);
        connections.release();
    }
}

// 场景 2：API 限流
public class RateLimiter {
    private Semaphore semaphore = new Semaphore(100);  // 每秒 100 请求

    public Response handleRequest(Request request) {
        try {
            semaphore.acquire();
            return processRequest(request);
        } catch (InterruptedException e) {
            throw new RuntimeException(e);
        } finally {
            semaphore.release();
        }
    }
}

    4. Exchanger¶

    4.1 概述¶

    Exchanger 用于两个线程之间交换数据。

    特点： - ✅ 仅支持两个线程 - ✅ 双向数据交换 - ✅ 屏障点交换

    4.2 基本使用¶

    import java.util.concurrent.Exchanger;

public class ExchangerDemo {
    public static void main(String[] args) {
        Exchanger<String> exchanger = new Exchanger<>();

        new Thread(() -> {
            try {
                String data = "数据 A";
                System.out.println("线程 1 发送：" + data);
                String received = exchanger.exchange(data);
                System.out.println("线程 1 接收：" + received);
            } catch (InterruptedException e) {}
        }).start();

        new Thread(() -> {
            try {
                String data = "数据 B";
                System.out.println("线程 2 发送：" + data);
                String received = exchanger.exchange(data);
                System.out.println("线程 2 接收：" + received);
            } catch (InterruptedException e) {}
        }).start();
    }
}

    5. Phaser¶

    5.1 概述¶

    Phaser 是更灵活的屏障工具，支持动态注册/注销。

    特点： - ✅ 动态调整线程数 - ✅ 多阶段屏障 - ✅ 可重用

    5.2 基本使用¶

    import java.util.concurrent.Phaser;

public class PhaserDemo {
    public static void main(String[] args) {
        Phaser phaser = new Phaser(1);  // 初始 1 个（主线程）

        for (int i = 0; i < 3; i++) {
            phaser.register();  // 注册新线程
            new Thread(() -> {
                System.out.println(Thread.currentThread().getName() + " 阶段 1");
                phaser.arriveAndAwaitAdvance();  // 等待所有线程

                System.out.println(Thread.currentThread().getName() + " 阶段 2");
                phaser.arriveAndAwaitAdvance();

                phaser.arriveAndDeregister();  // 注销
            }).start();
        }

        phaser.arriveAndDeregister();  // 主线程注销
    }
}

    6. 工具类对比¶

    工具类 可重用 线程数 主要用途
    CountDownLatch ❌ 任意 等待其他线程完成
    CyclicBarrier ✅ 固定 线程互相等待
    Semaphore ✅ 任意 限流、控制并发
    Exchanger ✅ 2 数据交换
    Phaser ✅ 动态 多阶段屏障

    7. 本章小结¶

    核心知识点¶

    ✅ CountDownLatch：等待其他线程完成
    ✅ CyclicBarrier：线程互相等待
    ✅ Semaphore：限流、控制并发
    ✅ Exchanger：数据交换
    ✅ Phaser：灵活的多阶段屏障

    最佳实践¶

    1. CountDownLatch：一次性等待场景
    2. CyclicBarrier：循环屏障、多轮计算
    3. Semaphore：资源限流、连接池
    4. 选择合适工具：根据场景选择
