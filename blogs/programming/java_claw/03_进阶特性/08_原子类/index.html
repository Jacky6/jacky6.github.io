    08_原子类¶

    1. 原子类概述¶

    1.1 什么是原子操作¶

    原子操作（Atomic Operation）是不可中断的操作，要么全部执行成功，要么全部不执行。

    为什么需要原子类： - ✅ 线程安全 - ✅ 无需 synchronized - ✅ 性能更好（CAS 机制）

    1.2 CAS 原理¶

    CAS (Compare-And-Swap)：

1. 读取内存值 V
2. 比较 V 是否等于预期值 A
3. 如果是，更新为新值 B
4. 如果否，重试

┌─────────┐     ┌──────────┐     ┌─────────┐
│ 线程 1   │────▶│  主内存   │◀────│ 线程 2   │
│ 读取 A   │     │  值：A    │     │ 读取 A   │
└─────────┘     └──────────┘     └─────────┘
     │                                  │
     │ 比较 A==A，更新为 B               │ 比较 A==A，更新失败
     ▼                                  ▼
┌─────────┐                      ┌──────────┐
│ 成功     │                      │ 重试      │
└─────────┘                      └──────────┘

    2. AtomicInteger¶

    2.1 基本使用¶

    import java.util.concurrent.atomic.AtomicInteger;

AtomicInteger atomic = new AtomicInteger(0);

// 获取
int value = atomic.get();  // 0

// 设置
atomic.set(10);

// 增加
atomic.incrementAndGet();  // 11（先加后返回）
atomic.getAndIncrement();  // 11（先返回后加）

atomic.addAndGet(5);  // 16
atomic.getAndAdd(5);  // 16

// 比较并设置
boolean success = atomic.compareAndSet(16, 20);  // true

    2.2 实战：线程安全计数器¶

    public class SafeCounter {
    private AtomicInteger count = new AtomicInteger(0);

    public void increment() {
        count.incrementAndGet();
    }

    public int getCount() {
        return count.get();
    }

    public static void main(String[] args) throws InterruptedException {
        SafeCounter counter = new SafeCounter();

        // 10 个线程，每个线程加 1000 次
        List<Thread> threads = new ArrayList<>();
        for (int i = 0; i < 10; i++) {
            threads.add(new Thread(() -> {
                for (int j = 0; j < 1000; j++) {
                    counter.increment();
                }
            }));
        }

        for (Thread t : threads) t.start();
        for (Thread t : threads) t.join();

        System.out.println("最终计数：" + counter.getCount());  // 10000
    }
}

    4. AtomicReference¶

    4.1 基本使用¶

    import java.util.concurrent.atomic.AtomicReference;

class Person {
    private String name;
    private int age;
    // getter/setter
}

AtomicReference<Person> ref = new AtomicReference<>();

// 设置
ref.set(new Person("张三", 25));

// 获取
Person p = ref.get();

// CAS
Person oldPerson = new Person("张三", 25);
Person newPerson = new Person("李四", 26);
boolean success = ref.compareAndSet(oldPerson, newPerson);

    4.2 实战：乐观锁¶

    public class OptimisticLock {
    private AtomicReference<Integer> balance = new AtomicReference<>(1000);

    public boolean withdraw(int amount) {
        Integer currentBalance;
        Integer newBalance;

        do {
            currentBalance = balance.get();

            if (currentBalance < amount) {
                return false;  // 余额不足
            }

            newBalance = currentBalance - amount;

        } while (!balance.compareAndSet(currentBalance, newBalance));

        return true;
    }
}

    6. 字段更新器¶

    6.1 AtomicIntegerFieldUpdater¶

    import java.util.concurrent.atomic.AtomicIntegerFieldUpdater;

class Account {
    volatile int balance = 1000;  // 必须 volatile
}

public class Main {
    static AtomicIntegerFieldUpdater<Account> updater = 
        AtomicIntegerFieldUpdater.newUpdater(Account.class, "balance");

    public static void main(String[] args) {
        Account account = new Account();

        // 增加
        updater.incrementAndGet(account);

        // CAS
        boolean success = updater.compareAndSet(account, 1001, 900);
    }
}

    7. LongAdder（高性能计数器）¶

    7.1 为什么需要 LongAdder¶

    // AtomicInteger 在高并发下性能下降
// 因为所有线程竞争同一个变量

// LongAdder 使用分段累加，减少竞争

    7.2 基本使用¶

    import java.util.concurrent.atomic.LongAdder;

LongAdder adder = new LongAdder();

// 增加
adder.increment();
adder.add(10);

// 获取
long sum = adder.sum();

// 重置
adder.reset();

    7.3 性能对比¶

    // 高并发场景性能对比

// AtomicInteger
AtomicInteger atomicInt = new AtomicInteger(0);
// 10 线程，100 万次：约 500ms

// LongAdder
LongAdder longAdder = new LongAdder();
// 10 线程，100 万次：约 100ms

// LongAdder 性能更好，适合高并发计数场景

    8. 实战示例¶

    8.1 线程安全 ID 生成器¶

    public class IdGenerator {
    private static final AtomicLong idCounter = new AtomicLong(0);

    public static long generateId() {
        return idCounter.incrementAndGet();
    }
}

    8.2 限流器¶

    public class RateLimiter {
    private final AtomicInteger counter = new AtomicInteger(0);
    private final int limit;

    public RateLimiter(int limit) {
        this.limit = limit;
    }

    public boolean tryAcquire() {
        int current = counter.get();
        if (current >= limit) {
            return false;
        }
        return counter.compareAndSet(current, current + 1);
    }

    public void release() {
        counter.decrementAndGet();
    }
}

    8.3 自旋锁¶

    public class SpinLock {
    private AtomicReference<Thread> owner = new AtomicReference<>();

    public void lock() {
        Thread current = Thread.currentThread();
        while (!owner.compareAndSet(null, current)) {
            // 自旋等待
        }
    }

    public void unlock() {
        Thread current = Thread.currentThread();
        owner.compareAndSet(current, null);
    }
}

    9. 本章小结¶

    核心知识点¶

    ✅ AtomicInteger：原子整数
    ✅ AtomicLong/Boolean：原子长整型/布尔型
    ✅ AtomicReference：原子引用
    ✅ 数组原子类：AtomicIntegerArray
    ✅ 字段更新器：AtomicIntegerFieldUpdater
    ✅ LongAdder：高性能计数器

    最佳实践¶

    1. 计数器用 LongAdder：高并发性能更好
    2. 状态标志用 AtomicBoolean：线程安全
    3. ID 生成用 AtomicLong：简单高效
    4. 复杂对象用 AtomicReference：CAS 操作
    5. 避免ABA 问题：使用 AtomicStampedReference
