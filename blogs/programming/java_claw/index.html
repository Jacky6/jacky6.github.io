    Java 学习教程¶

    系统化的 Java 学习路线，从入门到进阶，涵盖核心语法、框架和设计模式

    📚 教程目录¶

    第一阶段：入门篇（1-2 周）¶

    序号 教程 内容 难度
    01 Java 入门 JDK 安装、HelloWorld、环境配置 ⭐
    02 基础语法 变量、数据类型、运算符、流程控制 ⭐
    03 数组 一维/二维数组、Arrays 工具类 ⭐⭐
    04 类与对象 类定义、对象创建、this 关键字 ⭐⭐
    05 方法 方法定义、重载、递归 ⭐⭐
    06 内部类 成员/静态/局部/匿名内部类 ⭐⭐⭐
    07 访问修饰符 private/protected/public/default ⭐⭐
    08 抽象类与接口 abstract、interface、函数式接口 ⭐⭐⭐
    09 枚举 enum 定义、字段方法、EnumSet ⭐⭐

    第二阶段：核心 API（3-4 周）¶

    序号 教程 内容 难度
    01 字符串 String、StringBuilder、常量池 ⭐⭐
    02 集合框架 List、Set、Map、工具类 ⭐⭐⭐
    03 泛型 泛型类、泛型方法、通配符 ⭐⭐⭐
    04 异常处理 try-catch、自定义异常 ⭐⭐
    05 IO 流 字节流、字符流、NIO ⭐⭐⭐
    06 日期时间 LocalDate、LocalDateTime、格式化 ⭐⭐
    07 包装类 Integer、自动装箱拆箱、BigDecimal ⭐⭐
    08 常用工具类 Random、UUID、Objects、System ⭐⭐
    09 正则表达式 Pattern、Matcher、常用模式 ⭐⭐⭐

    第三阶段：进阶特性（5-6 周）¶

    序号 教程 内容 难度
    01 多线程基础 线程创建、同步、线程池 ⭐⭐⭐⭐
    02 反射 Class 对象、字段/方法访问 ⭐⭐⭐⭐
    03 注解 元注解、自定义注解 ⭐⭐⭐
    04 Lambda 表达式 函数式接口、方法引用 ⭐⭐⭐
    05 Stream API Stream 操作、收集器 ⭐⭐⭐
    06 Optional 空值处理、最佳实践 ⭐⭐
    07 并发工具类详解 CountDownLatch、CyclicBarrier、Semaphore ⭐⭐⭐⭐
    08 原子类 AtomicInteger、CAS、LongAdder ⭐⭐⭐⭐
    09 CompletableFuture 异步编程、链式调用 ⭐⭐⭐⭐

    第四阶段：开发工具（7 周）¶

    序号 教程 内容 难度
    01 Maven 安装配置、POM、依赖管理 ⭐⭐

    第五阶段：主流框架（8-10 周）¶

    序号 教程 内容 难度
    01 Spring 基础 IOC、AOP、事务管理 ⭐⭐⭐⭐
    02 SpringBoot 自动配置、起步依赖 ⭐⭐⭐⭐
    03 MyBatis SQL 映射、动态 SQL ⭐⭐⭐

    第六阶段：设计模式（11-12 周）¶

    序号 教程 内容 难度
    01 单例模式 饿汉式、懒汉式、枚举 ⭐⭐⭐
    02 工厂模式 简单工厂、工厂方法、抽象工厂 ⭐⭐⭐
    03 观察者模式 发布 - 订阅、Spring 事件 ⭐⭐⭐
    04 策略模式 算法封装、运行时切换 ⭐⭐⭐
    05 建造者模式 复杂对象构建、链式调用 ⭐⭐⭐
    06 适配器模式 接口转换、对象适配器 ⭐⭐⭐
    07 装饰器模式 动态增强功能、IO 流 ⭐⭐⭐⭐
    08 代理模式 静态代理、动态代理、AOP ⭐⭐⭐⭐

    ✅ 学习检查清单¶

    入门篇¶

    • 能独立安装 JDK 和配置环境变量
    • 理解变量、数据类型和运算符
    • 掌握数组的创建和使用
    • 掌握类和对象的概念
    • 理解构造方法、this 关键字
    • 掌握方法定义、重载和递归
    • 理解内部类的分类和使用
    • 掌握访问修饰符的权限范围
    • 理解抽象类和接口的区别
    • 掌握枚举的定义和使用

    核心 API¶

    • 理解 String 不可变性和常量池
    • 掌握 List、Set、Map 的使用
    • 理解泛型的原理和使用
    • 掌握异常处理机制
    • 理解 IO 流的分类和使用
    • 掌握 Java 8 日期时间 API
    • 理解包装类和自动装箱/拆箱
    • 掌握常用工具类的使用
    • 理解正则表达式的基本语法

    进阶特性¶

    • 理解线程创建和同步机制
    • 掌握反射的基本使用
    • 理解注解的定义和使用
    • 掌握 Lambda 表达式语法
    • 熟练使用 Stream API
    • 理解 Optional 的最佳实践
    • 掌握并发工具类的使用
    • 理解原子类和 CAS 原理
    • 掌握 CompletableFuture 异步编程

    主流框架¶

    • 理解 IOC 和依赖注入
    • 掌握 AOP 和切面编程
    • 理解 SpringBoot 自动配置
    • 掌握 MyBatis 的 SQL 映射
    • 能独立搭建 SpringBoot 项目

    设计模式¶

    • 理解单例模式的各种实现
    • 掌握工厂模式的应用场景
    • 理解观察者模式的原理
    • 掌握策略模式的使用
    • 理解建造者模式的优势
    • 掌握适配器模式的实现
    • 理解装饰器模式的动态增强
    • 掌握代理模式的 AOP 应用
