    13_集合框架¶

    1. 集合框架概述¶

    1.1 什么是集合¶

    集合（Collection）是用于存储和操作一组对象的容器。

    数组 vs 集合：

    特性 数组 集合
    大小 固定 动态
    类型 基本类型/对象 只能存储对象
    功能 基础 丰富（增删改查）

    1.2 集合体系结构¶

    Collection（接口）
├── List（接口）- 有序、可重复
│   ├── ArrayList - 数组实现，随机访问快
│   ├── LinkedList - 链表实现，插入删除快
│   └── Vector - 线程安全（已过时）
├── Set（接口）- 无序、不可重复
│   ├── HashSet - 哈希表实现
│   ├── LinkedHashSet - 保持插入顺序
│   └── TreeSet - 红黑树实现，有序
└── Queue（接口）- 队列

Map（接口）- 键值对
├── HashMap - 哈希表实现
├── LinkedHashMap - 保持插入顺序
├── TreeMap - 红黑树实现，有序
└── Hashtable - 线程安全（已过时）

    2. List 接口¶

    2.1 ArrayList¶

    特点： - ✅ 基于动态数组 - ✅ 随机访问快 O(1) - ❌ 插入删除慢 O(n) - ❌ 非线程安全

    import java.util.ArrayList;
import java.util.List;

public class ArrayListDemo {
    public static void main(String[] args) {
        // 创建
        List<String> list = new ArrayList<>();

        // 添加
        list.add("Java");
        list.add("Python");
        list.add(1, "C++");  // 指定位置插入

        // 获取
        String item = list.get(0);  // "Java"

        // 修改
        list.set(0, "Go");

        // 删除
        list.remove(0);
        list.remove("Python");

        // 遍历
        for (String s : list) {
            System.out.println(s);
        }

        // 判断
        boolean contains = list.contains("Go");
        boolean isEmpty = list.isEmpty();
    }
}

    扩容机制： - 默认容量：10 - 扩容：原容量的 1.5 倍 - 优化：创建时指定容量 new ArrayList<>(100)

    2.2 LinkedList¶

    特点： - ✅ 基于双向链表 - ✅ 插入删除快 O(1) - ❌ 随机访问慢 O(n)

    import java.util.LinkedList;

LinkedList<String> list = new LinkedList<>();

// 添加
list.add("A");
list.addFirst("First");
list.addLast("Last");

// 作为栈使用
list.push("Stack");
String pop = list.pop();

// 作为队列使用
list.offer("Queue");
String poll = list.poll();

    2.3 ArrayList vs LinkedList¶

    场景 推荐 原因
    随机访问多 ArrayList get(i) O(1)
    插入删除多 LinkedList add/remove O(1)
    遍历多 ArrayList 缓存友好

    3. Set 接口¶

    3.1 HashSet¶

    特点： - ✅ 基于 HashMap 实现 - ✅ 无序、不可重复 - ✅ 允许一个 null

    import java.util.HashSet;
import java.util.Set;

Set<String> set = new HashSet<>();

// 添加
set.add("Java");      // true
set.add("Python");    // true
set.add("Java");      // false（重复）

// 遍历（无序）
for (String s : set) {
    System.out.println(s);
}

    3.2 LinkedHashSet¶

    特点：保持插入顺序

    Set<String> set = new LinkedHashSet<>();
set.add("C");
set.add("A");
set.add("B");
// 遍历顺序：C, A, B

    3.3 TreeSet¶

    特点：自然排序或自定义排序

    TreeSet<Integer> set = new TreeSet<>();
set.add(3);
set.add(1);
set.add(2);
// 遍历顺序：1, 2, 3（升序）

    4. Map 接口 ⭐⭐⭐¶

    4.1 HashMap¶

    特点： - ✅ 基于哈希表 - ✅ 键不可重复，值可重复 - ✅ 允许一个 null 键 - ❌ 非线程安全 - ❌ 无序

    import java.util.HashMap;
import java.util.Map;

public class HashMapDemo {
    public static void main(String[] args) {
        // 创建
        Map<String, Integer> map = new HashMap<>();

        // 添加
        map.put("Java", 1);
        map.put("Python", 2);

        // 获取
        Integer value = map.get("Java");  // 1
        Integer missing = map.get("Go");  // null

        // 获取或默认
        Integer result = map.getOrDefault("Go", 0);

        // 删除
        map.remove("Java");

        // 遍历
        // 方式 1：keySet
        for (String key : map.keySet()) {
            System.out.println(key + " = " + map.get(key));
        }

        // 方式 2：entrySet（推荐）
        for (Map.Entry<String, Integer> entry : map.entrySet()) {
            System.out.println(entry.getKey() + " = " + entry.getValue());
        }

        // 方式 3：forEach
        map.forEach((k, v) -> System.out.println(k + " = " + v));
    }
}

    内部结构： - Java 7：数组 + 链表 - Java 8+：数组 + 链表/红黑树（链表长度>8 转红黑树）

    4.2 LinkedHashMap¶

    特点：保持插入顺序

    Map<String, Integer> map = new LinkedHashMap<>();
map.put("C", 3);
map.put("A", 1);
map.put("B", 2);
// 遍历顺序：C, A, B

    4.3 TreeMap¶

    特点：按键排序

    Map<String, Integer> map = new TreeMap<>();
map.put("C", 3);
map.put("A", 1);
map.put("B", 2);
// 遍历顺序：A, B, C（自然排序）

    4.4 HashMap vs Hashtable vs ConcurrentHashMap¶

    特性 HashMap Hashtable ConcurrentHashMap
    线程安全 ❌ ✅ ✅
    null 键/值 允许 不允许 不允许
    性能 高 低 高
    推荐 单线程 已过时 多线程 ⭐

    5. 集合工具类¶

    5.1 Collections¶

    import java.util.Collections;

List<Integer> list = new ArrayList<>();
list.add(3);
list.add(1);
list.add(2);

// 排序
Collections.sort(list);  // [1, 2, 3]

// 反转
Collections.reverse(list);  // [3, 2, 1]

// 查找
int index = Collections.binarySearch(list, 2);

// 线程安全
List<String> syncList = Collections.synchronizedList(list);

    5.2 Arrays¶

    import java.util.Arrays;

int[] arr = {3, 1, 4, 1, 5};

// 排序
Arrays.sort(arr);  // [1, 1, 3, 4, 5]

// 查找
int index = Arrays.binarySearch(arr, 3);

// 转列表
List<Integer> list = Arrays.asList(1, 2, 3);

    6. Java 8+ 集合新特性¶

    6.1 Stream API¶

    List<String> list = Arrays.asList("Java", "Python", "C++");

// 过滤 + 映射 + 收集
List<String> result = list.stream()
    .filter(s -> s.length() > 3)
    .map(String::toUpperCase)
    .collect(Collectors.toList());
// 输出：[JAVA, PYTHON]

    6.2 Map 新方法¶

    Map<String, Integer> map = new HashMap<>();

// computeIfAbsent
map.computeIfAbsent("Java", k -> 0);

// computeIfPresent
map.computeIfPresent("Java", (k, v) -> v + 1);

// merge
map.merge("Java", 1, Integer::sum);

    7. 经典算法题¶

    7.1 两数之和¶

    public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();

    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);
    }

    return new int[]{};
}

    7.2 有效的字母异位词¶

    public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;

    Map<Character, Integer> map = new HashMap<>();

    for (char c : s.toCharArray()) {
        map.put(c, map.getOrDefault(c, 0) + 1);
    }

    for (char c : t.toCharArray()) {
        map.put(c, map.getOrDefault(c, 0) - 1);
        if (map.get(c) < 0) return false;
    }

    return true;
}

    8. 本章小结¶

    核心知识点¶

    ✅ List：ArrayList（随机访问）、LinkedList（插入删除）
    ✅ Set：HashSet（无序）、LinkedHashSet（顺序）、TreeSet（排序）
    ✅ Map：HashMap（无序）、LinkedHashMap（顺序）、TreeMap（排序）
    ✅ 工具类：Collections、Arrays

    选择指南¶

    需求 推荐集合
    快速随机访问 ArrayList
    频繁插入删除 LinkedList
    去重 HashSet
    保持顺序 LinkedHashSet/LinkedHashMap
    排序 TreeSet/TreeMap
    键值对 HashMap
    线程安全 ConcurrentHashMap
