    1.2 第一个 Python 程序¶

    🎯 学习目标¶

    • 理解 Python 代码的执行方式
    • 学会运行 Python 代码的两种方法
    • 写出你的第一个程序

    🚀 两种运行方式¶

    方式一：交互式解释器（REPL）¶

    直接在命令行输入代码，立即看到结果：

    # 启动 Python 解释器
python

    你会看到类似这样的提示： 

    Python 3.14.3 (main, Mar 28 2026, 00:00:00) 
[GCC] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>>

    现在可以输入代码： 

    >>> print("Hello, World!")
Hello, World!

>>> 1 + 1
2

>>> name = "Python"
>>> print(f"Welcome to {name}!")
Welcome to Python!

>>> exit()  # 退出解释器

    优点： 快速测试、即时反馈 缺点： 代码不会保存

    方式二：脚本文件¶

    将代码写入 .py 文件，然后运行：

    1. 创建文件 hello.py 

      # hello.py
print("Hello, World!")

name = input("What's your name? ")
print(f"Nice to meet you, {name}!")

    2. 运行脚本 

      python hello.py

    优点： 代码可保存、可复用、可分享 缺点： 需要额外步骤运行

    📝 第一个程序详解¶

    让我们写一个稍微完整的程序：

    # greeting.py
# 这是一个问候程序

# 1. 打印欢迎信息
print("=" * 40)
print("    欢迎来到 Python 世界！")
print("=" * 40)

# 2. 获取用户输入
name = input("\n请问你叫什么名字？ ")

# 3. 个性化问候
print(f"\n你好，{name}！👋")
print("很高兴认识你！")

# 4. 简单计算
print("\n--- 小测试 ---")
num1 = float(input("请输入第一个数字： "))
num2 = float(input("请输入第二个数字： "))

print(f"\n{num1} + {num2} = {num1 + num2}")
print(f"{num1} - {num2} = {num1 - num2}")
print(f"{num1} × {num2} = {num1 * num2}")

if num2 != 0:
    print(f"{num1} ÷ {num2} = {num1 / num2:.2f}")
else:
    print("除数不能为零！")

print("\n--- 程序结束 ---")

    运行它： 

    python greeting.py

    💡 Python 代码特点¶

    1. 简洁的语法¶

    # Python
print("Hello")

# Java
System.out.println("Hello");

# C++
std::cout << "Hello" << std::endl;

    2. 动态类型¶

    # 不需要声明变量类型
x = 10          # x 是整数
x = "hello"     # 现在 x 是字符串
x = 3.14        # 现在 x 是浮点数

    3. 强制缩进¶

    # 正确 ✅
if True:
    print("缩进正确")

# 错误 ❌
if True:
print("缺少缩进")  # IndentationError

    4. 注释¶

    # 单行注释

"""
多行注释（文档字符串）
可以写多行
"""

'''
也可以用三个单引号
'''

    result = x + y
    print(f"DEBUG: result={result}")
    return result

    使用断言¶

    def divide(a, b):
    assert b != 0, "除数不能为零"
    return a / b

    ⚠️ 常见错误¶

    1. 语法错误（SyntaxError）¶

    # 缺少括号
print("Hello"  # ❌ SyntaxError

# 正确
print("Hello")  # ✅

    2. 缩进错误（IndentationError）¶

    def greet():
print("Hello")  # ❌ IndentationError

# 正确
def greet():
    print("Hello")  # ✅

    3. 名称错误（NameError）¶

    print(x)  # ❌ NameError: name 'x' is not defined

# 正确
x = 10
print(x)  # ✅

    📝 练习题¶

    1. 基础练习：编写程序，询问用户年龄并打印出来
    2. 数学练习：编写程序，计算圆的面积（提示：面积 = π × r²）
    3. 创意练习：编写程序，生成一个个性化的自我介绍

    示例答案（练习 1）： 

    # age.py
age = input("How old are you? ")
print(f"You are {age} years old!")
