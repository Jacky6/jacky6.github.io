    附录 3：性能优化¶

    ⚡ 优化原则¶

    ** premature optimization is the root of all evil ** - Donald Knuth

    1. 先让代码工作，再优化
    2. 使用性能分析工具找出瓶颈
    3. 优先优化最耗时的部分
    4. 保持代码可读性

    🔍 性能分析¶

    timeit - 简单测试¶

    import timeit

# 测试列表推导式 vs map
time1 = timeit.timeit(
    "[x**2 for x in range(1000)]",
    number=10000
)

time2 = timeit.timeit(
    "list(map(lambda x: x**2, range(1000)))",
    number=10000
)

print(f"列表推导式：{time1:.4f}秒")
print(f"map: {time2:.4f}秒")

    cProfile - 详细分析¶

    import cProfile
import pstats
from io import StringIO

def slow_function():
    total = 0
    for i in range(1000000):
        total += i * i
    return total

# 分析
profiler = cProfile.Profile()
profiler.enable()
slow_function()
profiler.disable()

# 输出统计
stats = pstats.Stats(profiler)
stats.sort_stats('cumulative')
stats.print_stats(10)

    🚀 优化技巧¶

    1. 使用内置函数¶

    # ❌ 慢
def sum_list(numbers):
    total = 0
    for n in numbers:
        total += n
    return total

# ✅ 快
def sum_list(numbers):
    return sum(numbers)

    2. 列表推导式 vs 循环¶

    # ❌ 慢
squares = []
for i in range(1000):
    squares.append(i ** 2)

# ✅ 快
squares = [i ** 2 for i in range(1000)]

    3. 生成器节省内存¶

    # ❌ 占用大量内存
def get_squares(n):
    return [x ** 2 for x in range(n)]

# ✅ 节省内存
def get_squares(n):
    return (x ** 2 for x in range(n))

    4. 使用 join 连接字符串¶

    # ❌ 慢
result = ""
for word in words:
    result += word + " "

# ✅ 快
result = " ".join(words)

    5. 使用集合进行查找¶

    # ❌ 慢 - O(n)
if item in my_list:
    pass

# ✅ 快 - O(1)
if item in my_set:
    pass

    6. 缓存计算结果¶

    from functools import lru_cache

# ❌ 重复计算
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# ✅ 缓存
@lru_cache(maxsize=None)
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

    7. 使用局部变量¶

    # ❌ 慢
def process(items):
    for i in range(len(items)):
        items[i] = items[i] * 2

# ✅ 快
def process(items):
    length = len(items)  # 缓存到局部变量
    for i in range(length):
        items[i] = items[i] * 2

    8. 避免全局变量查找¶

    # ❌ 慢
def compute():
    total = 0
    for i in range(1000000):
        total += i
    return total

# ✅ 快
def compute():
    total = 0
    range_func = range  # 缓存到局部变量
    for i in range_func(1000000):
        total += i
    return total

    📊 数据结构选择¶

    操作 列表 集合 字典
    索引 O(1) - -
    查找 O(n) O(1) O(1)
    插入 O(n) O(1) O(1)
    删除 O(n) O(1) O(1)

    选择指南¶

    # 需要有序、可重复 → 列表
items = [1, 2, 3, 2, 1]

# 需要唯一、快速查找 → 集合
unique_items = {1, 2, 3}

# 需要键值映射 → 字典
user_data = {"name": "Alice", "age": 25}

    🎯 实际优化例子¶

    1. 词频统计优化¶

    # ❌ 慢
def count_words_slow(text):
    words = text.split()
    counts = {}
    for word in words:
        if word in counts:
            counts[word] += 1
        else:
            counts[word] = 1
    return counts

# ✅ 快
from collections import Counter

def count_words_fast(text):
    return Counter(text.split())

    2. 列表去重优化¶

    # ❌ 慢
def unique_slow(items):
    result = []
    for item in items:
        if item not in result:
            result.append(item)
    return result

# ✅ 快（不保持顺序）
def unique_fast(items):
    return list(set(items))

# ✅ 快（保持顺序）
def unique_ordered(items):
    seen = set()
    return [x for x in items if not (x in seen or seen.add(x))]

    3. 字符串处理优化¶

    # ❌ 慢
def build_string_slow(n):
    result = ""
    for i in range(n):
        result += str(i)
    return result

# ✅ 快
def build_string_fast(n):
    return "".join(str(i) for i in range(n))

    📝 优化检查清单¶

    • 是否使用了合适的内置函数？
    • 是否避免了不必要的循环？
    • 是否使用了合适的数据结构？
    • 是否有重复计算可以缓存？
    • 是否有可以延迟的计算？
    • 是否有不必要的内存分配？
    • 是否使用了生成器处理大数据？
