    07_图（Graph）¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度

    1. 图基础¶

    1.1 知识点¶

    图（Graph）是由顶点（Vertex）和边（Edge）组成的非线性数据结构，记作 G = (V, E)。树其实是一种特殊的图（连通无环图），而图更一般：任意两点都可能相连，也可以有环。理解图抓住三点： - 建模能力强：任何"多对多"关系都能用图表示——朋友圈、网页链接、航线、课程先修关系 - 两个要素：顶点集 V 和边集 E；边可以有向/无向、带权/不带权，这两问决定了用什么算法 - 算法成体系：遍历（DFS/BFS）、最短路、最小生成树、拓扑排序四大类，全部有固定模板

        A —— B
    |    |
    C —— D —— E

    顶点：{A, B, C, D, E}
    边：{(A,B), (A,C), (B,D), (C,D), (D,E)}

    1.2 图的分类¶

    类型 说明 示例
    无向图 边没有方向 朋友圈
    有向图 边有方向 关注关系
    加权图 边有权重 地图距离
    无权图 边无权重 社交网络 
    无向图：A —— B        有向图：A → B
       （A-B 互通）          （A 到 B，B 不一定到 A）

加权图：A --5-- B     无权图：A —— B
       （边有权重 5）        （边无权重）

    选型思路：先问"方向重要吗"（好友关系是无向，关注关系是有向），再问"边权重要吗"（求最短距离才需要权）。这两问决定建图方式和后续算法。

    2. 图的表示¶

    2.1 知识点¶

    图的两种主流表示法是邻接矩阵和邻接表，本质是"空间换时间"与"时间省空间"的取舍： - 邻接矩阵：二维数组，matrix[i][j] = 1 表示有边。查边 O(1)，但空间 O(V²)，稀疏图上大量空间浪费在 0 上 - 邻接表：为每个顶点存一份"邻居列表"。空间 O(V+E)，遍历邻居只要 O(度)

    实际遇到的图绝大多数是稀疏图（边数远小于 V²），所以邻接表是绝对主流；矩阵主要用于稠密图，或需要频繁查"两点是否相连"的场景（Floyd 算法也天然基于矩阵）。

    2.2 邻接矩阵¶

    用二维数组表示，matrix[i][j] = 1 表示 i 和 j 有边。

    # 无向图
#   A  B  C  D
# A 0  1  1  0
# B 1  0  0  1
# C 1  0  0  1
# D 0  1  1  0

graph = [
    [0, 1, 1, 0],  # A
    [1, 0, 0, 1],  # B
    [1, 0, 0, 1],  # C
    [0, 1, 1, 0],  # D
]

# 检查 A 和 B 是否相连
print(graph[0][1])  # 1（相连）

# 加权图（用权重代替 1）
weighted = [
    [0, 5, 3, 0],
    [5, 0, 0, 2],
    [3, 0, 0, 4],
    [0, 2, 4, 0],
]

    特点：

    • ✅ 判断两点是否相连：O(1)
    • ❌ 空间复杂度：O(V²)，适合稠密图

    2.3 邻接表 ⭐¶

    用字典/列表存储每个顶点的邻居。

    from typing import List, Dict, Set
from collections import defaultdict

# 无向图
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D'],
    'D': ['B', 'C', 'E'],
    'E': ['D'],
}

# 有向图
directed = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': ['D'],
    'D': ['E'],
    'E': [],
}

# 加权图
weighted = {
    'A': {'B': 5, 'C': 3},
    'B': {'A': 5, 'D': 2},
    'C': {'A': 3, 'D': 4},
    'D': {'B': 2, 'C': 4, 'E': 1},
    'E': {'D': 1},
}

    class Graph:
    """图的邻接表实现"""

    def __init__(self, directed=False):
        self.directed = directed
        self.graph = defaultdict(list)

    def add_edge(self, u, v):
        """添加边"""
        self.graph[u].append(v)
        if not self.directed:
            self.graph[v].append(u)

    def add_weighted_edge(self, u, v, weight):
        """添加加权边"""
        self.graph[u].append((v, weight))
        if not self.directed:
            self.graph[v].append((u, weight))

    def neighbors(self, node):
        """获取邻居"""
        return self.graph[node]

    def __repr__(self):
        return dict(self.graph)


# 使用示例
g = Graph(directed=False)
g.add_edge('A', 'B')
g.add_edge('A', 'C')
g.add_edge('B', 'D')
g.add_edge('C', 'D')
g.add_edge('D', 'E')

print(g.neighbors('A'))  # ['B', 'C']

    特点：

    • ✅ 空间复杂度：O(V+E)，适合稀疏图
    • ✅ 遍历邻居：O(度)

    2.4 ⚠️ 易错点：无向图必须加双向边¶

    from collections import defaultdict

graph = defaultdict(list)

# ❌ 把无向图建成有向图：只加了一个方向
graph['A'].append('B')
# 后果：B 的邻居表里没有 A，从 B 出发走不回 A，图被"割裂"，遍历/最短路全错

# ✅ 无向图：一条边要登记两次
def add_edge(u, v):
    graph[u].append(v)
    graph[v].append(u)

    另一个隐藏坑：普通 dict 访问不存在的键会抛 KeyError，建图推荐用 defaultdict(list)；孤立节点（没有任何边）要么显式初始化为空列表，要么遍历时用 graph.get(node, []) 兜底。

    3. 图的遍历 ⭐⭐⭐¶

    3.1 知识点¶

    图的遍历是所有图算法的地基，只有两个模板： - DFS（深度优先搜索）：一条路走到黑，走不动就回退。用栈（或递归）实现，适合路径搜索、连通性判断、环检测 - BFS（广度优先搜索）：一圈一圈向外扩。用队列实现，第一次到达某节点时经过的边数最少——天然适合无权最短路径

    两者共享同一个关键部件：visited 集合。图可能有环，不记 visited 就会在有环图上无限打转。DFS/BFS 每个顶点和每条边各访问一次，时间复杂度都是 O(V+E)。

    3.2 DFS 深度优先搜索¶

    def dfs_recursive(graph: Dict, start, visited=None):
    """DFS - 递归"""
    if visited is None:
        visited = set()

    visited.add(start)
    print(start, end=' ')

    for neighbor in graph[start]:
        if neighbor not in visited:
            dfs_recursive(graph, neighbor, visited)

    return visited


def dfs_iterative(graph: Dict, start):
    """DFS - 迭代（栈）"""
    visited = set()
    stack = [start]
    result = []

    while stack:
        node = stack.pop()
        if node not in visited:
            visited.add(node)
            result.append(node)
            # 逆序加入（保证正序访问）
            for neighbor in reversed(graph[node]):
                if neighbor not in visited:
                    stack.append(neighbor)

    return result


# 示例
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E'],
}

print(dfs_recursive(graph, 'A'))  # A B D E F C
print(dfs_iterative(graph, 'A'))  # A B D E F C

    3.3 BFS 广度优先搜索¶

    from collections import deque

def bfs(graph: Dict, start):
    """BFS - 队列"""
    visited = {start}
    queue = deque([start])
    result = []

    while queue:
        node = queue.popleft()
        result.append(node)

        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return result


# 示例
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E'],
}

print(bfs(graph, 'A'))  # A B C D E F

    3.4 DFS vs BFS¶

    特性 DFS BFS
    数据结构 栈（递归） 队列
    空间复杂度 O(H) O(W)
    应用场景 路径、连通性 最短路径（无权）
    遍历顺序 一条路走到黑 层层推进

    3.5 ⚠️ 易错点：visited 不能省，BFS 要在入队时标记¶

    # ❌ 不写 visited：有环图上 A→B→A→B... 无限递归直到栈溢出
def dfs_wrong(graph, node):
    print(node)
    for nb in graph[node]:
        dfs_wrong(graph, nb)  # 环上反复横跳

# ❌ BFS 只在出队时判 visited：同一节点被多个邻居反复入队，队列爆炸
while queue:
    node = queue.popleft()
    if node in visited:
        continue
    visited.add(node)
    for nb in graph[node]:
        queue.append(nb)  # 最坏情况队列规模指数级膨胀

# ✅ BFS 在入队时就标记（见 3.3 模板）：每个节点至多入队一次

    一句话记忆：DFS 访问时标记，BFS 入队时标记。BFS"入队即标记"保证每个节点至多进一次队列；等到出队才检查，同一节点会被它的每个邻居各推一次，时间和空间都会失控。

    4. 最短路径算法 ⭐⭐⭐¶

    4.1 知识点¶

    最短路径分两大场景，按图的特征选算法： - 无权图（所有边等价）：BFS 就够了。BFS 按层推进，第一次到达某节点时走的边数必然最少，天然就是最短路径 - 加权图：Dijkstra（单源、无负权边）。核心思想是贪心：每次从优先队列里取出当前距离最小的未确定节点，"确定后不再改动"——这正是无负权边才能保证的性质 - 多源（任意两点间的最短路）：Floyd-Warshall，三重循环 O(V³)，图小、要全源时最简单

    一个关键前提：Dijkstra 不能处理负权边。一旦出现负权边，"距离最小的节点已确定"这个贪心不变式就被破坏，算法给出错误结果——这是面试最常问的追问。

    4.2 BFS 求无权图最短路径¶

    from collections import deque
from typing import List, Dict, Optional

def shortest_path_bfs(graph: Dict, start, end):
    """
    BFS 求无权图最短路径
    """
    if start == end:
        return [start]

    visited = {start}
    queue = deque([(start, [start])])

    while queue:
        node, path = queue.popleft()

        for neighbor in graph[node]:
            if neighbor not in visited:
                if neighbor == end:
                    return path + [neighbor]
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))

    return None  # 无路径


# 示例
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E'],
}

print(shortest_path_bfs(graph, 'A', 'F'))  # ['A', 'C', 'F'] 或 ['A', 'B', 'E', 'F']

    4.3 Dijkstra 算法（加权图）⭐¶

    import heapq
from typing import Dict, List, Optional

def dijkstra(graph: Dict[str, Dict[str, int]], start: str) -> Dict[str, int]:
    """
    Dijkstra 算法：单源最短路径（无负权边）

    Args:
        graph: 邻接表 {node: {neighbor: weight}}
        start: 起始节点

    Returns:
        {node: shortest_distance}
    """
    # 初始化距离
    distances = {node: float('inf') for node in graph}
    distances[start] = 0

    # 优先队列：(距离，节点)
    heap = [(0, start)]
    visited = set()

    while heap:
        dist, node = heapq.heappop(heap)

        if node in visited:
            continue
        visited.add(node)

        # 更新邻居
        for neighbor, weight in graph[node].items():
            new_dist = dist + weight
            if new_dist < distances[neighbor]:
                distances[neighbor] = new_dist
                heapq.heappush(heap, (new_dist, neighbor))

    return distances


def dijkstra_with_path(graph: Dict[str, Dict[str, int]], start: str, end: str):
    """Dijkstra 求最短路径（带路径）"""
    distances = {node: float('inf') for node in graph}
    distances[start] = 0
    previous = {node: None for node in graph}

    heap = [(0, start)]
    visited = set()

    while heap:
        dist, node = heapq.heappop(heap)

        if node in visited:
            continue
        visited.add(node)

        if node == end:
            break

        for neighbor, weight in graph[node].items():
            new_dist = dist + weight
            if new_dist < distances[neighbor]:
                distances[neighbor] = new_dist
                previous[neighbor] = node
                heapq.heappush(heap, (new_dist, neighbor))

    # 重建路径
    path = []
    current = end
    while current:
        path.append(current)
        current = previous[current]
    path.reverse()

    return distances[end], path if distances[end] != float('inf') else None


# 示例
graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {'B': 5, 'C': 1},
}

print(dijkstra(graph, 'A'))  # {'A': 0, 'B': 1, 'C': 3, 'D': 4}
print(dijkstra_with_path(graph, 'A', 'D'))  # (4, ['A', 'B', 'C', 'D'])

    4.4 Floyd-Warshall 算法（多源最短路径）¶

    def floyd_warshall(graph: List[List[int]]) -> List[List[int]]:
    """
    Floyd-Warshall 算法：所有节点对之间的最短路径

    Args:
        graph: 邻接矩阵，graph[i][j] 表示 i 到 j 的距离
               无边用 float('inf')，自己到自己用 0

    Returns:
        距离矩阵
    """
    n = len(graph)
    dist = [row[:] for row in graph]  # 复制

    for k in range(n):
        for i in range(n):
            for j in range(n):
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

    return dist


# 示例
INF = float('inf')
graph = [
    [0, 3, INF, 5],
    [2, 0, INF, 4],
    [INF, 1, 0, INF],
    [INF, INF, 2, 0],
]

result = floyd_warshall(graph)
for row in result:
    print(row)

    4.5 ⚠️ 易错点：Dijkstra 的负权边陷阱¶

    # ❌ 对含负权边的图跑 Dijkstra，结果可能错误
graph = {
    'A': {'B': 2, 'C': 5},
    'B': {'C': -10},   # 负权边！
    'C': {},
}
# Dijkstra 先确定 B(2)，再确定 C(3)... 但 A→B→C = -8 更短，贪心顺序已错
# ✅ 有负权边改用 Bellman-Ford：O(VE)，能检测负权环

    另一个常见错误：Floyd 的循环顺序。k 必须放在最外层——含义是"允许经过编号 ≤ k 的中间节点"这一动态规划阶段的推进。把 i 或 j 放到最外层，dist[i][k] 用到的还是未更新完的旧值，结果错误。

    # ❌ 错误顺序：i 在最外层
for i in range(n):
    for k in range(n):
        for j in range(n): ...

# ✅ 正确顺序：k 必须在最外层（见 4.4 模板）
for k in range(n):
    for i in range(n):
        for j in range(n): ...

    5. 最小生成树 ⭐¶

    5.1 知识点¶

    最小生成树（MST）：连通加权无向图中，连通所有顶点且边权和最小的树（V 个顶点恰好 V-1 条边）。两大算法思路互补： - Prim：从一个点出发，每次把"连接已选集合与未选集合的最小边"加入，逐步长成一颗树。适合稠密图，本质和 Dijkstra 一样是"堆维护候选边" - Kruskal：把所有边按权排序，从小到大依次尝试加入，用并查集判断加边是否成环，不成环就收。适合稀疏图

    两者都是贪心，区别在于 Prim 从"点/树"生长，Kruskal 从"边"挑选。Kruskal 依赖的并查集（路径压缩 + 按秩合并）本身也是高频考点。

    5.2 Prim 算法¶

    import heapq

def prim(graph: Dict[str, Dict[str, int]], start: str) -> List[tuple]:
    """
    Prim 算法：最小生成树

    Args:
        graph: 邻接表 {node: {neighbor: weight}}
        start: 起始节点

    Returns:
        [(u, v, weight), ...] 最小生成树的边
    """
    mst = []
    visited = {start}
    edges = []

    # 加入起始节点的所有边
    for neighbor, weight in graph[start].items():
        heapq.heappush(edges, (weight, start, neighbor))

    while edges:
        weight, u, v = heapq.heappop(edges)

        if v in visited:
            continue

        visited.add(v)
        mst.append((u, v, weight))

        # 加入新节点的所有边
        for neighbor, w in graph[v].items():
            if neighbor not in visited:
                heapq.heappush(edges, (w, v, neighbor))

    return mst


# 示例
graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {'B': 5, 'C': 1},
}

print(prim(graph, 'A'))  # [('A', 'B', 1), ('B', 'C', 2), ('C', 'D', 1)]

    5.3 Kruskal 算法¶

    class UnionFind:
    """并查集"""

    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False

        # 按秩合并
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True


def kruskal(nodes: List[str], edges: List[tuple]) -> List[tuple]:
    """
    Kruskal 算法：最小生成树

    Args:
        nodes: 节点列表
        edges: 边列表 [(u, v, weight), ...]

    Returns:
        最小生成树的边
    """
    # 边按权重排序
    edges.sort(key=lambda x: x[2])

    # 节点映射到索引
    node_to_idx = {node: i for i, node in enumerate(nodes)}
    uf = UnionFind(len(nodes))

    mst = []
    for u, v, weight in edges:
        if uf.union(node_to_idx[u], node_to_idx[v]):
            mst.append((u, v, weight))

    return mst


# 示例
nodes = ['A', 'B', 'C', 'D']
edges = [
    ('A', 'B', 1),
    ('A', 'C', 4),
    ('B', 'C', 2),
    ('B', 'D', 5),
    ('C', 'D', 1),
]

print(kruskal(nodes, edges))  # [('A', 'B', 1), ('C', 'D', 1), ('B', 'C', 2)]

    # ❌ 图不连通时，Prim 从单个起点出发只能生成"所在连通分量"的树，
#    且返回的 mst 边数 < V-1，却不会报错提示
g = {'A': {'B': 1}, 'B': {'A': 1}, 'X': {'Y': 2}, 'Y': {'X': 2}}  # 两个连通分量

    Kruskal 同理：如果图不连通，kruskal 返回的边数同样少于 V-1，得到的是"最小生成森林"而非生成树，使用前要确认图连通。另外注意 Prim 对有向图无效——MST 只对无向图定义，先把有向图的边当无向处理再跑 Prim 是常见误用。

    6. 拓扑排序 ⭐¶

    6.1 知识点¶

    拓扑排序是对有向无环图（DAG）的线性排序，使得对任意边 u→v，u 都排在 v 前面——典型场景是课程先修、任务依赖、编译顺序。核心算法是 Kahn（入度表法）： - 统计每个节点的入度（有多少前置依赖） - 入度为 0 的节点（无依赖）先入队，依次出队并把它指向的节点入度减 1，减到 0 就入队 - 结束时若输出节点数 < 总节点数，说明图里有环——拓扑排序因此自带环检测功能

    有环的图不存在拓扑排序；无环时拓扑序不唯一（多个入度为 0 的节点谁先出队都行）。DFS 也能做拓扑排序（按完成时间逆序），但 Kahn 更直观、面试更常考。

    6.2 Kahn 算法实现¶

    from collections import deque, defaultdict

def topological_sort(graph: Dict[str, List[str]]) -> List[str]:
    """
    拓扑排序（Kahn 算法）

    适用于：有向无环图（DAG）
    """
    # 计算入度
    in_degree = defaultdict(int)
    for node in graph:
        if node not in in_degree:
            in_degree[node] = 0
        for neighbor in graph[node]:
            in_degree[neighbor] += 1

    # 入度为 0 的节点入队
    queue = deque([node for node in in_degree if in_degree[node] == 0])
    result = []

    while queue:
        node = queue.popleft()
        result.append(node)

        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    # 检查是否有环
    if len(result) != len(in_degree):
        return []  # 有环，无法拓扑排序

    return result


# 示例（课程安排）
# 0 → 1 → 3
#  ↓   ↑
#  2 ──┘
graph = {
    0: [1, 2],
    1: [3],
    2: [1],
    3: [],
}

print(topological_sort(graph))  # [0, 2, 1, 3]

    6.3 ⚠️ 易错点：忘记检测环 / 孤立节点漏进队列¶

    # ❌ 不判环：有环图会静默输出"部分序列"，看起来像成功了
#    比如 0→1→2→0，没有任何节点入度为 0，队列为空，result 直接是 []
#    若调用方把 [] 当成"空图的合法结果"就误判了

# ✅ 模板用 len(result) != len(in_degree) 显式判环（见 6.2）：
#    有环 → 环上节点入度永远减不到 0 → 出队数必然少于总数

# ❌ 只把 graph 的 key 当节点：只有出边没有入边、又不在 key 里的节点会漏掉
#    （例如边表里出现 (3, 1)，但 3 从不作为起点）
# ✅ 6.2 的模板通过遍历所有边的端点累计入度，defaultdict 会自动收录
#    所有出现过的节点；若用数组入度表，则要按节点总数初始化，别只按边数

    7. 经典算法题¶

    7.1 知识点¶

    图论面试高频题型有两类：一是网格类问题——把二维网格看成隐式图，每个格子是节点，上下左右相邻即有边，用 DFS/BFS 做连通块计数、最短路径（代表题：岛屿数量、腐烂的橘子）；二是依赖关系类问题——把先修关系建成有向图，用拓扑排序判环/排序（代表题：课程表、课程表 II）。这两类题的图往往不显式给出，建图/理解隐式图本身就是考点。

    7.2 岛屿数量 ✅⭐¶

    def numIslands(grid: List[List[str]]) -> int:
    """
    LeetCode 200：岛屿数量

    DFS 遍历
    """
    if not grid:
        return 0

    m, n = len(grid), len(grid[0])
    count = 0

    def dfs(i, j):
        if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] != '1':
            return
        grid[i][j] = '0'  # 标记为已访问
        dfs(i+1, j)
        dfs(i-1, j)
        dfs(i, j+1)
        dfs(i, j-1)

    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                dfs(i, j)
                count += 1

    return count

    思路：把网格看成图，每个 '1' 格子是一个节点，上下左右相邻即有边。岛屿数量 = '1' 连通块的个数：扫一遍所有格子，遇到 '1' 就从它开始 DFS 把整座岛"淹没"（改成 '0' 充当 visited），计数 +1。时间 O(mn)，空间 O(mn)（递归栈最坏情况是一整块陆地）。

    7.3 ⚠️ 易错点：DFS 淹没前必须先判边界和字符¶

    # ❌ 先递归再检查：访问 grid[-1][j] 在 Python 里不报错而是"绕到最后一行"，
#    访问 grid[m][j] 才越界——行为完全错乱且难排查
def dfs_wrong(i, j):
    grid[i][j] = '0'
    dfs_wrong(i+1, j)  # i+1 可能已越界
    dfs_wrong(i-1, j)  # i-1 可能是 -1，负索引陷阱！
    dfs_wrong(i, j+1)
    dfs_wrong(i, j-1)

# ✅ 入口先做边界 + 字符判断（见 7.2 模板第一行）：
#    越界或非 '1' 直接 return，递归体永远安全

    另外注意：题目给的是 '1' / '0' 字符串，不是整数 1/0，比较时写 grid[i][j] == '1'，写成 == 1 会永远为假。若不想修改原网格，就用额外 visited 集合，但空间多 O(mn)。

    7.4 课程表 ✅⭐¶

    def canFinish(numCourses: int, prerequisites: List[List[int]]) -> bool:
    """
    LeetCode 207：课程表（检测环）

    拓扑排序
    """
    graph = defaultdict(list)
    in_degree = [0] * numCourses

    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1

    queue = deque([i for i in range(numCourses) if in_degree[i] == 0])
    count = 0

    while queue:
        node = queue.popleft()
        count += 1

        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    return count == numCourses

    思路："所有课程能否修完" 等价于 "先修关系构成的有向图是否有环"：有环（A 依赖 B、B 依赖 A）就永远无法开始。直接套用 Kahn 拓扑排序，出队节点数等于 numCourses 即可修完。时间 O(V+E)。

    7.5 ⚠️ 易错点：建图方向别搞反¶

    # prerequisites[i] = [course, prereq]：prereq 是 course 的前置
# ✅ 边方向 prereq → course（先修完 prereq 才能修 course）：
for course, prereq in prerequisites:
    graph[prereq].append(course)
    in_degree[course] += 1

# ❌ 建反了：graph[course].append(prereq) + in_degree[prereq] += 1
#    判环结论恰好不变（反转所有边不改变环的存在性），
#    但在 LeetCode 210（课程表 II，要输出学习顺序）里方向反了
#    输出的就是逆序答案，直接 WA

    刷题时把这道题和 LeetCode 210 一起练：210 只需在本题基础上收集出队顺序作为结果，环的判定逻辑完全复用。

    8. 本章小结¶

    核心知识点¶

    ✅ 图基础：G=(V,E)，无向/有向、加权/无权四问定建图方式
    ✅ 图的表示：邻接矩阵 O(V²) 查边快、邻接表 O(V+E) 稀疏图首选
    ✅ 图的遍历：DFS（栈/递归）、BFS（队列），均为 O(V+E)，visited 防环
    ✅ 最短路径：BFS（无权）、Dijkstra（加权无负权边）、Floyd（多源 O(V³)）
    ✅ 最小生成树：Prim（堆+生长）、Kruskal（边排序+并查集）
    ✅ 拓扑排序：Kahn 入度表+队列，DAG 排序 + 环检测
    ✅ 经典题：网格 DFS（岛屿数量）、拓扑判环（课程表）

    最佳实践¶

    1. 建图先问两件事：有向还是无向、带不带权——无向图记得双向加边，优先 defaultdict(list)
    2. 遍牢记 visited：DFS 访问时标记，BFS 入队时标记，有环图不记 visited 必死循环
    3. 最短路按权重选算法：无权 → BFS；加权无负权 → Dijkstra；有负权 → Bellman-Ford；全源小图 → Floyd
    4. 依赖关系想拓扑排序：课程表、任务调度、编译顺序统一转成 DAG + Kahn；出队数 ≠ 节点数就是有环
    5. MST 跑完验边数：生成树必为 V-1 条边，不够说明图不连通

    时间复杂度¶

    算法 时间复杂度 空间复杂度
    DFS/BFS O(V+E) O(V)
    Dijkstra O((V+E)log V) O(V)
    Floyd O(V³) O(V²)
    Prim O((V+E)log V) O(V)
    Kruskal O(E log E) O(V)
