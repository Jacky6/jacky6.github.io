    🎯 学习路线¶

    阶段一：基础入门（1-2 周）¶

    1_数组 → 2_链表 → 3_栈 → 4_队列 → 5_哈希表

    目标： - 掌握基础数据结构的定义和操作 - 理解时间/空间复杂度分析 - 完成 20+ 道简单题

    推荐题目： - 数组：两数之和、移除元素 - 链表：反转链表、检测环 - 栈：有效的括号、最小栈 - 队列：层序遍历、滑动窗口最大值 - 哈希表：字母异位词分组

    阶段二：进阶提升（2-3 周）¶

    6_树 → 7_图 → 8_排序 → 9_查找

    目标： - 掌握树和图的遍历算法 - 理解经典排序和查找算法 - 完成 30+ 道中等题

    推荐题目： - 树：最大深度、验证 BST、LCA - 图：岛屿数量、课程表、网络延迟时间 - 排序：排序链表、最大数 - 查找：搜索旋转数组、寻找峰值

    阶段三：高阶突破（3-4 周）¶

    10_动态规划 → 11_贪心 → 12_回溯 → 13_滑动窗口

    目标： - 掌握四大进阶算法思想 - 能够识别题型并选择合适算法 - 完成 40+ 道中等/困难题

    推荐题目： - DP：爬楼梯、零钱兑换、LIS、LCS - 贪心：跳跃游戏、无重叠区间 - 回溯：全排列、N 皇后、单词搜索 - 滑动窗口：最小覆盖子串、无重复字符

    📊 算法复杂度速查¶

    排序算法对比¶

    算法 平均 最好 最坏 空间 稳定
    快速排序 O(n log n) O(n log n) O(n²) O(log n) ❌
    归并排序 O(n log n) O(n log n) O(n log n) O(n) ✅
    堆排序 O(n log n) O(n log n) O(n log n) O(1) ❌
    插入排序 O(n²) O(n) O(n²) O(1) ✅

    数据结构操作对比¶

    数据结构 查找 插入 删除 空间
    数组 O(1) O(n) O(n) O(n)
    链表 O(n) O(1)* O(1)* O(n)
    平衡树 O(log n) O(log n) O(log n) O(n)
    哈希表 O(1) O(1) O(1) O(n)
    堆 O(n) O(log n) O(log n) O(n)

    数组：按下标随机访问/修改 O(1)，末尾追加均摊 O(1)，中间插入/删除需要移动元素所以 O(n)
    链表：*指已定位到插入/删除位置；定位本身需要 O(n) 遍历

    🔑 核心模板¶

    二分查找模板¶

    def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

    DFS 模板¶

    def dfs(graph, node, visited):
    visited.add(node)
    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)

    BFS 模板¶

    from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    回溯模板¶

    def backtrack(path, choices):
    if is_done(path):
        result.append(path[:])
        return

    for choice in choices:
        if not is_valid(choice):
            continue

        path.append(choice)
        backtrack(path, new_choices)
        path.pop()

    💡 解题技巧¶

    1. 识别题型¶

    题目特征 可能算法
    有序数组查找 二分查找
    连续子数组/子串 滑动窗口
    求所有组合/排列 回溯
    最优化问题（最大/最小） DP 或贪心
    树/图的遍历 DFS/BFS
    Top K 问题 堆
    区间问题 排序 + 贪心

    2. 时间复杂度分析¶

    O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)

数据规模    建议算法
n ≤ 50      O(n³) 或 O(2ⁿ)
n ≤ 10⁴     O(n²)
n ≤ 10⁶     O(n log n)
n > 10⁶     O(n) 或 O(log n)

    3. 空间换时间¶

    • 哈希表：O(n) 空间换 O(1) 查找
    • 前缀和：O(n) 空间换 O(1) 区间和
    • 记忆化：O(n) 空间避免重复计算

    📝 刷题建议¶

    新手阶段¶

    1. 按类型刷：集中刷同一类型的题目（如 10 道链表）
    2. 重质量：每道题彻底理解，不要追求数量
    3. 写总结：记录解题思路和易错点
    4. 多复习：定期重做之前的题目

    进阶阶段¶

    1. 按难度刷：挑战中等/困难题
    2. 一题多解：尝试不同解法并比较
    3. 总结模板：归纳通用解题框架
    4. 模拟面试：限时完成题目
