    08_排序（Sorting）¶

    本章知识点清单¶

    # 知识点 一句话结论 重要度

    1. 排序概述与稳定性¶

    1.1 知识点¶

    排序（Sorting）是将一组数据按某种规则（通常是数值大小或字典序）重新排列的操作，是算法中最基础也是最重要的内容之一——几乎所有"有序"前提的算法（二分查找、去重、区间合并）都依赖它。学习排序抓住两条主线： - 比较排序：只靠"两两比较"决定顺序，理论下界是 O(n log n)。包括冒泡、选择、插入、希尔、归并、快速、堆排序。 - 非比较排序：利用数据本身的数值特征（值域、位数、分布），可以突破 O(n log n) 达到 O(n)。包括计数、桶、基数排序，但各有适用前提。

    稳定性（Stability）：相等元素的相对位置在排序后不变。例如排序前 5a 在 5b 前面，排序后依然如此。稳定性在多关键字排序时至关重要——先按次要关键字排一次，再按主要关键字用稳定算法排一次，就能得到两级都正确的结果。面试中"哪些排序是稳定的"是排序章第一高频问题：稳定：冒泡、插入、归并、计数、桶、基数；不稳定：选择、希尔、快速、堆。

    1.2 排序算法对比¶

    算法 平均时间 最好 最坏 空间 稳定性 说明

    选择排序 O(n²) O(n²) O(n²) O(1) ❌ 不稳定 简单，效率低

    希尔排序 O(n log n) O(n log n) O(n²) O(1) ❌ 不稳定 插入排序改进

    稳定性：相等元素的相对位置在排序后不变

    1.3 ⚠️ 易错点：稳定性不是"排完结果对不对"¶

    很多初学者误以为"不稳定 = 排序结果错误"，这是最大的误解。不稳定排序的结果依然有序，只是相等元素之间的先后顺序可能被颠倒。面试要用一个具体反例说明为什么"选择排序不稳定"：

    # 反例：[5a, 5b, 2]（两个 5 用下标区分先后）
# 选择排序第 1 轮找到最小值 2，与位置 0 的 5a 交换：
# [5a, 5b, 2] → [2, 5b, 5a]
# 结果中 5b 跑到了 5a 前面 —— 相对顺序被颠倒，不稳定 ❌

# 什么时候稳定性真的重要？多关键字排序：
students = [("Alice", 90), ("Bob", 85), ("Carol", 90)]
# 先按分数升序，同分者保持原始先后 —— 必须用稳定算法
# Python 的 sorted 底层是稳定的 Timsort，所以可以直接分两步排：
students.sort(key=lambda s: s[1])   # 稳定：同分者相对顺序不变

    2. 基础排序（O(n²)）¶

    2.1 冒泡排序¶

    知识点¶

    冒泡排序（Bubble Sort）：反复比较相邻两个元素，如果前者比后者大就交换，这样每一轮都会把当前未排序部分的最大值"冒"到末尾。它是最直观的排序，也是理解"交换型排序"和"提前退出优化"的入门样本。最好情况（已有序）只需一趟扫描 O(n)；最坏（逆序）O(n²)。因为只在相邻比较时交换、且相等不交换，所以是稳定的。

    def bubble_sort(arr: List[int]) -> List[int]:
    """
    冒泡排序

    原理：相邻元素比较，大的往后冒

    时间复杂度：
    - 平均：O(n²)
    - 最好：O(n)（已有序）
    - 最坏：O(n²)

    空间复杂度：O(1)
    稳定性：稳定
    """
    n = len(arr)
    for i in range(n):
        swapped = False
        # 最后 i 个元素已有序
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        # 如果没有交换，说明已有序
        if not swapped:
            break
    return arr


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(bubble_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

    冒泡过程：
初始：[64, 34, 25, 12, 22, 11, 90]

第 1 轮：
[34, 64, 25, 12, 22, 11, 90]  ← 64 和 34 交换
[34, 25, 64, 12, 22, 11, 90]  ← 64 和 25 交换
...
[34, 25, 12, 22, 11, 64, 90]  ← 64 冒泡到位

第 2 轮：
[25, 34, 12, 22, 11, 64, 90]
...

    ⚠️ 易错点：内层循环边界与提前退出¶

    # ❌ 常见错误 1：内层边界写成 n-1，导致 arr[j+1] 越界；
#    或忘记减 i，对已排好序的尾部重复扫描（结果仍正确，但白费比较）
for i in range(n):
    for j in range(n - 1):        # ❌ 应随 i 收缩
        ...

# ✅ 每轮结束后末尾 i 个元素已就位，内层只需扫到 n-1-i
for i in range(n):
    for j in range(n - 1 - i):
        ...

# ❌ 常见错误 2：忘记 swapped 提前退出，已有序数据也要傻跑 O(n²)
# ✅ 一整轮没有发生任何交换 → 数组已有序，直接 break（最好情况 O(n)）

    2.2 选择排序¶

    知识点¶

    选择排序（Selection Sort）：每轮从未排序部分选出最小值，与未排序部分的第一个元素交换。它的特点是"比较次数与输入无关"——无论数据是否有序，都要做 n(n-1)/2 次比较，所以最好、最坏都是 O(n²)；但交换次数最多 n-1 次，在交换代价很高的场景反而有优势。注意它是不稳定的：交换可能把一个相等元素"跨越"到另一个相等元素前面（见 1.3 反例）。

    def selection_sort(arr: List[int]) -> List[int]:
    """
    选择排序

    原理：每轮选择最小的放到前面

    时间复杂度：O(n²)（无论什么数据都是 O(n²)）
    空间复杂度：O(1)
    稳定性：不稳定
    """
    n = len(arr)
    for i in range(n):
        min_idx = i
        # 找到最小值的索引
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        # 交换
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(selection_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

    选择过程：
初始：[64, 34, 25, 12, 22, 11, 90]

第 1 轮：找到最小值 11，与 64 交换
[11, 34, 25, 12, 22, 64, 90]

第 2 轮：找到最小值 12，与 34 交换
[11, 12, 25, 34, 22, 64, 90]

...

    ⚠️ 易错点：选择排序是唯一"任何输入都 O(n²)"的常见排序¶

    冒泡和插入在已有序数据上都是 O(n)，唯独选择排序做不到优化——因为"找最小值"必须扫完整个未排序区间，无法提前退出。面试若问"哪个排序最好情况和最坏情况一样？"，答案就是选择排序。另外它的不稳定性来自交换这一步（而不是比较），是四个不稳定排序里最容易构造反例的。

    2.3 插入排序¶

    知识点¶

    插入排序（Insertion Sort）：类似整理扑克牌——把数组分成"已排序前缀"和"待处理"两部分，每次取待处理的第一个元素，从后往前扫描，插入到已排序前缀的正确位置。它的比较次数取决于逆序对数量：完全有序时每个元素只比较 1 次，总计 O(n)；完全逆序时 O(n²)。因此它是"近乎有序数据"的最优选择，也是高级排序（希尔、Timsort）的基础构件。只在遇到更大元素时后移、相等不移动，所以稳定。

    def insertion_sort(arr: List[int]) -> List[int]:
    """
    插入排序

    原理：类似整理扑克牌，将当前元素插入到前面已排序部分的正确位置

    时间复杂度：
    - 平均：O(n²)
    - 最好：O(n)（已有序）
    - 最坏：O(n²)

    空间复杂度：O(1)
    稳定性：稳定
    """
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1

        # 将比 key 大的元素向后移动
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1

        arr[j + 1] = key
    return arr


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(insertion_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

    插入过程：
初始：[64, 34, 25, 12, 22, 11, 90]
       ↑
      已排序

第 1 轮：插入 34
[34, 64, 25, 12, 22, 11, 90]
           ↑
          已排序

第 2 轮：插入 25
[25, 34, 64, 12, 22, 11, 90]
               ↑
              已排序

    2.4 希尔排序¶

    知识点¶

    希尔排序（Shell Sort）：插入排序的改进版。插入排序的瓶颈在于"每次只能移动一格"，逆序对多的时候后移次数巨大。希尔排序引入间隔（gap）：先让相距 gap 的元素组内做插入排序，使数组快速趋于"宏观有序"，然后逐步缩小 gap（常见序列 n/2, n/4, …, 1），最后 gap=1 时就是标准插入排序——但此时数组已近乎有序，插入排序跑得飞快。它是第一个突破 O(n²) 的排序算法，代价是不稳定：同一值的元素可能被分到不同组、跨组移动导致相对顺序颠倒。

    def shell_sort(arr: List[int]) -> List[int]:
    """
    希尔排序

    原理：带间隔的插入排序。按 gap 分组做插入排序，
    gap 逐渐缩小，数组越来越"宏观有序"，gap=1 时退化为插入排序

    时间复杂度：取决于 gap 序列，常用序列约 O(n^1.3) ~ O(n²)
    空间复杂度：O(1)
    稳定性：不稳定（同值元素可能跨组移动）
    """
    n = len(arr)
    gap = n // 2

    while gap > 0:
        # 对每个 gap 做一次"间隔插入排序"
        for i in range(gap, n):
            key = arr[i]
            j = i - gap
            # 组内后移：只和同组（相距 gap）的元素比较
            while j >= 0 and arr[j] > key:
                arr[j + gap] = arr[j]
                j -= gap
            arr[j + gap] = key
        gap //= 2  # 缩小间隔

    return arr


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(shell_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

    希尔排序过程（n=8，gap 序列 4 → 2 → 1）：
初始：[64, 34, 25, 12, 22, 11, 90, 8]

gap=4：分成 4 组 (64,22)(34,11)(25,90)(12,8)，组内插入排序
      [22, 11, 25, 8, 64, 34, 90, 12]

gap=2：分成 2 组，组内插入排序，数组趋于宏观有序
      [22, 8, 25, 11, 64, 12, 90, 34] → ... 

gap=1：就是插入排序，但此时逆序对已很少，很快完成
      [8, 11, 12, 22, 25, 34, 64, 90]

    3. 高级排序（O(n log n)）⭐¶

    3.1 归并排序¶

    知识点¶

    归并排序（Merge Sort）：分治法的经典应用，三步走——①分解：把数组从中间切成两半；②解决：递归排序左右两半；③合并：把两个有序数组用双指针合并成一个有序数组。递归深度 log n 层、每层合并总共处理 n 个元素，所以任何输入都是 O(n log n)，且合并时相等元素优先取左边的（<=），保证稳定。代价是需要 O(n) 额外空间存放合并结果。它是外部排序（大文件分批排序）和链表排序的首选，Python/Java 的对象排序底层也是归并思想。

    def merge_sort(arr: List[int]) -> List[int]:
    """
    归并排序

    原理：分治法
    1. 分解：将数组分成两半
    2. 解决：递归排序两半
    3. 合并：合并两个有序数组

    时间复杂度：O(n log n)
    空间复杂度：O(n)
    稳定性：稳定
    """
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    return merge(left, right)


def merge(left: List[int], right: List[int]) -> List[int]:
    """合并两个有序数组"""
    result = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:  # <= 保证稳定性
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1

    # 添加剩余元素
    result.extend(left[i:])
    result.extend(right[j:])

    return result


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(merge_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

    归并过程：
              [64, 34, 25, 12, 22, 11, 90]
                    /               \
          [64, 34, 25, 12]      [22, 11, 90]
             /      \              /      \
        [64, 34]  [25, 12]     [22, 11]   [90]
         /   \     /   \        /   \       |
       [64] [34] [25] [12]   [22] [11]   [90]
         \   /     \   /        \   /       |
       [34, 64]  [12, 25]     [11, 22]   [90]
             \      /              \      /
          [12, 25, 34, 64]      [11, 22, 90]
                    \              /
                  [11, 12, 22, 25, 34, 64, 90]

    ⚠️ 易错点：<= 写成 <，稳定性就丢了¶

    # 合并两个有序数组时：
if left[i] <= right[j]:   # ✅ 相等时优先取左边 → 左边元素保持在前，稳定
    result.append(left[i])

if left[i] < right[j]:    # ❌ 相等时取了右边 → 右边元素插到左边相等元素前面
    result.append(left[i])  #    归并排序从"稳定"变成"不稳定"

# 归并排序的空间也常被误判为 O(log n)：
# ❌ "递归深度 log n，所以空间 O(log n)" —— 那是快排的情况
# ✅ 归并每层合并都要 O(n) 辅助数组，总空间 O(n)，这是它相对快排的最大劣势

    3.2 快速排序 ⭐⭐⭐¶

    知识点¶

    快速排序（Quick Sort）：同样是分治，但思路与归并相反——归并是"先分后治再合并"，快排是"先分区、分区即排序"：①选一个基准值 pivot；②分区：把小于 pivot 的放左边、大于的放右边，pivot 落在最终位置；③递归排序左右两半。平均 O(n log n)，且常数因子小、缓存友好，是实践中最快的通用排序。但最坏 O(n²)：已有序数组 + 固定选端点做 pivot，每次分区极度不均。原地版本只需 O(log n) 递归栈空间。分区会跨距离交换相等元素，所以不稳定。

    def quick_sort(arr: List[int]) -> List[int]:
    """
    快速排序

    原理：分治法
    1. 选择基准值（pivot）
    2. 分区：小于 pivot 的放左边，大于的放右边
    3. 递归排序左右两部分

    时间复杂度：
    - 平均：O(n log n)
    - 最好：O(n log n)
    - 最坏：O(n²)（已有序且选端点为 pivot）

    空间复杂度：O(log n)（递归栈）
    稳定性：不稳定
    """
    if len(arr) <= 1:
        return arr

    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]

    return quick_sort(left) + middle + quick_sort(right)


def quick_sort_inplace(arr: List[int], left: int = 0, right: int = None) -> List[int]:
    """快速排序 - 原地版本（节省空间）"""
    if right is None:
        right = len(arr) - 1

    if left >= right:
        return arr

    pivot_idx = partition(arr, left, right)
    quick_sort_inplace(arr, left, pivot_idx - 1)
    quick_sort_inplace(arr, pivot_idx + 1, right)

    return arr


def partition(arr: List[int], left: int, right: int) -> int:
    """分区函数"""
    pivot = arr[right]  # 选最右为基准
    i = left - 1
    for j in range(left, right):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    arr[i + 1], arr[right] = arr[right], arr[i + 1]
    return i + 1


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(quick_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]
print(quick_sort_inplace(arr.copy()))  # [11, 12, 22, 25, 34, 64, 90]

    快速排序过程：

            pivot 到位

递归右边：[25, 64, 22, 34, 90]

# ✅ 递归出口必须是 left >= right（0 个或 1 个元素的区间天然有序）

    3.3 堆排序¶

    知识点¶

    堆排序（Heap Sort）：利用大顶堆（每个节点 ≥ 其子节点）的性质排序。两步：①建堆：从最后一个非叶子节点（下标 n//2-1）开始自底向上 heapify，O(n) 建成大顶堆；②排序：把堆顶（最大值）与末尾交换，堆大小减 1，对新堆顶做一次 heapify，重复直到堆为空。整体 O(n log n)，且只需要 O(1) 额外空间——这是它相对归并的优势。缺点是常数大、缓存不友好，且交换会打乱相等元素，不稳定。它也是 Top K 问题的核心工具。

    def heap_sort(arr: List[int]) -> List[int]:
    """
    堆排序

    原理：
    1. 构建大顶堆
    2. 将堆顶（最大值）与末尾交换
    3. 调整堆，重复步骤 2

    时间复杂度：O(n log n)
    空间复杂度：O(1)
    稳定性：不稳定
    """
    n = len(arr)

    # 构建大顶堆
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    # 逐个提取元素
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]  # 交换
        heapify(arr, i, 0)  # 调整堆

    return arr


def heapify(arr: List[int], n: int, i: int):
    """调整堆"""
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left

    if right < n and arr[right] > arr[largest]:
        largest = right

    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(heap_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

    ⚠️ 易错点：heapify 时忘记传"有效堆大小"¶

    # 排序阶段每轮把最大值换到 arr[i] 后，arr[i:] 已是有序结果，
# 不再属于堆。heapify 必须只在前 i 个元素里调整：
for i in range(n - 1, 0, -1):
    arr[0], arr[i] = arr[i], arr[0]
    heapify(arr, i, 0)      # ✅ 堆大小传 i，不会碰已排好的尾部
    # heapify(arr, n, 0)    # ❌ 传 n：会把已就位的最大值重新卷入堆中，结果全错

# 另一个常错点：建堆起点。叶子节点不需要调整，从最后一个非叶子节点开始：
for i in range(n // 2 - 1, -1, -1):   # ✅
    ...
# for i in range(n - 1, -1, -1):      # 结果也对，但对叶子白调一次 heapify

    4. 线性排序（O(n)）¶

    4.1 计数排序¶

    知识点¶

    计数排序（Counting Sort）：非比较排序。思路很简单：统计每个值出现的次数，然后按值从小到大依次输出。标准实现分三步：①计数（count[v] = v 出现次数）；②对 count 做前缀和（count[v] 变成"≤ v 的元素总数"，即每个值在结果中的最后位置）；③逆序遍历原数组填结果——逆序是稳定性的关键。时间空间都是 O(n+k)（k 为值域范围），所以只有当 k = O(n) 时才真正高效；值域巨大（比如 32 位整数全范围）时计数数组会爆。它是基数排序的子过程。

    def counting_sort(arr: List[int]) -> List[int]:
    """
    计数排序

    原理：统计每个值出现的次数

    适用：整数，范围较小

    时间复杂度：O(n + k)，k 为值域范围
    空间复杂度：O(k)
    稳定性：稳定
    """
    if not arr:
        return arr

    min_val = min(arr)
    max_val = max(arr)
    range_size = max_val - min_val + 1

    # 计数
    count = [0] * range_size
    for num in arr:
        count[num - min_val] += 1

    # 累加
    for i in range(1, range_size):
        count[i] += count[i - 1]

    # 构建结果
    result = [0] * len(arr)
    for num in reversed(arr):  # 逆序保证稳定性
        count[num - min_val] -= 1
        result[count[num - min_val]] = num

    return result


# 示例
arr = [4, 2, 2, 8, 3, 3, 1]
print(counting_sort(arr))  # [1, 2, 2, 3, 3, 4, 8]

    ⚠️ 易错点：值域过大时计数排序是灾难¶

    # ❌ 误以为计数排序永远 O(n)。若 arr = [1, 10**9]：
#    k = 10**9，开 10 亿长度的数组，时间空间全砸在 k 上
# ✅ 使用前先确认值域：k = max - min + 1 与 n 同数量级时才划算
#    值域大而数据少 → 老老实实用 O(n log n) 的比较排序

# ❌ 忘记处理负数/非零最小值，直接 count = [0] * (max_val + 1)
# ✅ 用 num - min_val 做下标偏移（如上代码），负数也能排

    4.2 桶排序¶

    知识点¶

    桶排序（Bucket Sort）：把数据按值域均匀切分到若干个桶里，每个桶内部单独排序（通常用插入排序或内置排序），最后按桶序拼接。当数据均匀分布时每个桶只有 O(n/k) 个元素，总复杂度 O(n+k)。它是计数排序的推广（计数排序相当于"每个桶只有一个值"），也是"外部排序"和 LeetCode 347 前 K 高频元素的核心思想。数据分布不均（全挤进一个桶）时退化为桶内排序的复杂度。桶内排序若用稳定算法、且按原序入桶，整体就是稳定的。

    def bucket_sort(arr: List[float]) -> List[float]:
    """
    桶排序

    原理：将数据分到多个桶，每个桶内排序

    适用：数据均匀分布

    时间复杂度：O(n + k)
    空间复杂度：O(n + k)
    稳定性：稳定
    """
    if not arr:
        return arr

    # 创建桶
    min_val, max_val = min(arr), max(arr)
    bucket_count = len(arr)
    bucket_range = (max_val - min_val) / bucket_count if max_val > min_val else 1
    buckets = [[] for _ in range(bucket_count)]

    # 分配到桶
    for num in arr:
        idx = min(int((num - min_val) / bucket_range), bucket_count - 1)
        buckets[idx].append(num)

    # 每个桶内排序
    result = []
    for bucket in buckets:
        result.extend(sorted(bucket))

    return result


# 示例
arr = [0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51]
print(bucket_sort(arr))  # [0.32, 0.33, 0.37, 0.42, 0.47, 0.51, 0.52]

    ⚠️ 易错点：桶下标越界¶

    # ❌ 直接用 int((num - min_val) / bucket_range)：
#    当 num == max_val 时 idx 恰好等于 bucket_count，下标越界 IndexError
idx = int((num - min_val) / bucket_range)          # ❌ 最大值会越界
buckets[idx].append(num)

# ✅ 用 min() 夹住上界，把最大值归入最后一个桶
idx = min(int((num - min_val) / bucket_range), bucket_count - 1)  # ✅
buckets[idx].append(num)

    4.3 基数排序¶

    知识点¶

    基数排序（Radix Sort）：按"位"排序非负整数——从个位开始，对每一位做一次稳定的计数排序，一直做到最高位。为什么必须从低位到高位、且每一趟必须稳定？因为后面一趟只按当前位重排，稳定性保证了之前低位排好的相对顺序不被破坏，最终所有位联合决定总顺序。时间 O(n×k)（k 为最大位数），当位数 k 固定（如 32 位整数）时就是 O(n)。它把"值域大"的问题拆成"每轮值域只有 10"的小问题，绕开了计数排序值域爆炸的缺陷。

    def radix_sort(arr: List[int]) -> List[int]:
    """
    基数排序

    原理：按位数从低位到高位排序

    适用：非负整数

    时间复杂度：O(n × k)，k 为最大位数
    空间复杂度：O(n + k)
    稳定性：稳定
    """
    if not arr:
        return arr

    max_val = max(arr)
    exp = 1  # 位数：1, 10, 100...

    while max_val // exp > 0:
        counting_sort_by_digit(arr, exp)
        exp *= 10

    return arr


def counting_sort_by_digit(arr: List[int], exp: int):
    """按指定位数计数排序"""
    n = len(arr)
    result = [0] * n
    count = [0] * 10

    # 统计
    for num in arr:
        digit = (num // exp) % 10
        count[digit] += 1

    # 累加
    for i in range(1, 10):
        count[i] += count[i - 1]

    # 构建结果
    for num in reversed(arr):
        digit = (num // exp) % 10
        count[digit] -= 1
        result[count[digit]] = num

    arr[:] = result


# 示例
arr = [170, 45, 75, 90, 802, 24, 2, 66]
print(radix_sort(arr))  # [2, 24, 45, 66, 75, 90, 170, 802]

    ⚠️ 易错点：每一趟必须用稳定排序¶

    # ❌ 每一趟用不稳定排序（如快排）按当前位排：
#    例 [12, 11]，按个位排后 [11, 12]，十位相同本应保持此顺序，
#    若不稳定排序把十位相同的元素乱序，最终结果就会错
# ✅ 每一趟必须是稳定排序（计数排序），这是基数排序正确性的根基

# ❌ 从高位往低位排：高位排好的顺序会被低位一趟彻底打乱
# ✅ 必须从低位到高位（LSD），低位的顺序靠后续趟的"稳定性"得以保留

    5. 排序算法选择指南与 Python 内置排序¶

    5.1 知识点¶

    实际开发中很少手写排序，但选对算法是面试和工程的共同考点。选择逻辑按四个维度判断：数据规模、是否要稳定、内存是否受限、数据分布特征（整数小值域 / 均匀分布）。另外必须掌握 Python 内置排序：sort() / sorted() 底层是 Timsort（归并 + 插入的混合），稳定、平均 O(n log n)、对近乎有序数据特别快；key 参数接一个函数决定比较依据，reverse=True 降序。

    5.2 选择决策树¶

    数据规模小（n < 50）？
├─ 是 → 插入排序（简单，近乎有序时快）
└─ 否 → 继续判断

需要稳定性？
├─ 是 → 归并排序
└─ 否 → 继续判断

内存受限？
├─ 是 → 堆排序（原地 O(1)）
└─ 否 → 快速排序（平均最快）

数据是整数且范围小？
├─ 是 → 计数排序（O(n)）
└─ 否 → 继续判断

数据均匀分布？
├─ 是 → 桶排序（O(n)）
└─ 否 → 归并排序

    6. 经典算法题¶

    6.1 知识点¶

    排序章的题目考的不是"会不会排序"，而是能不能把排序算法当工具用：链表排序考归并（链表不能随机访问，快排分区困难，归并只需快慢指针找中点）；最大数考自定义比较函数（比较规则从数值大小变成拼接大小）；Top K 问题考堆或快排分区。下面两道是最高频的代表题。

    6.2 排序链表 ✅⭐¶

    class ListNode:
    """链表结点定义"""
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


def sortList(head: Optional[ListNode]) -> Optional[ListNode]:
    """
    LeetCode 148：排序链表

    归并排序实现
    """
    if not head or not head.next:
        return head

    # 找中点
    slow = fast = head
    prev = None
    while fast and fast.next:
        prev = slow
        slow = slow.next
        fast = fast.next.next

    prev.next = None  # 断开

    # 递归排序
    left = sortList(head)
    right = sortList(slow)

    # 合并
    return merge_two_lists(left, right)


def merge_two_lists(l1, l2):
    dummy = ListNode(0)
    curr = dummy

    while l1 and l2:
        if l1.val <= l2.val:
            curr.next = l1
            l1 = l1.next
        else:
            curr.next = l2
            l2 = l2.next
        curr = curr.next

    curr.next = l1 or l2
    return dummy.next

    ⚠️ 易错点：快慢指针找中点时不记录前驱，链表死循环¶

    # ❌ 只用 slow 找中点、不断链：两个节点的链表 [1, 2]，
#    slow 停在第 2 个节点，左半递归还是 [1, 2] → 无限递归栈溢出
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
left = sortList(head)   # ❌ head 到 slow 没断开，规模没缩小

# ✅ 记录 slow 的前驱 prev，递归前执行 prev.next = None 断开
prev = None
while fast and fast.next:
    prev = slow
    slow = slow.next
    fast = fast.next.next
prev.next = None        # ✅ 真正切成两半，递归规模减半

    6.3 最大数 ✅¶

    from functools import cmp_to_key

def largestNumber(nums: List[int]) -> str:
    """
    LeetCode 179：最大数

    自定义排序
    """
    def compare(x, y):
        if x + y > y + x:
            return -1
        elif x + y < y + x:
            return 1
        return 0

    strs = [str(num) for num in nums]
    strs.sort(key=cmp_to_key(compare))

    result = ''.join(strs)
    return '0' if result[0] == '0' else result


# 示例
nums = [3, 30, 34, 5, 9]
print(largestNumber(nums))  # "9534330"

    ⚠️ 易错点：按数值大小排序是错的¶

    # ❌ 直觉做法：按数值降序排 [9, 5, 34, 30, 3] → "9534303"
#    但 3 和 30：拼 "330" > "303"，3 必须排在 30 前面 → 正确答案 "9534330"
# ✅ 比较规则必须是"拼接后比大小"：x 排前面 ⟺ x+y > y+x

# ❌ 全 0 输入 [0, 0]：拼接结果是 "00"，应返回 "0"
# ✅ 判断 result[0] == '0' 说明最大的也是 0，直接返回 "0"

    核心知识点¶

    ✅ 稳定性：相等元素相对位置不变；稳定——冒泡/插入/归并/计数/桶/基数，不稳定——选择/希尔/快速/堆 ✅ 基础排序：冒泡、选择、插入、希尔（O(n²) 级，插入对近乎有序数据最优） ✅ 高级排序：归并（稳定 + O(n) 空间）、快速（平均最快）、堆（原地 + Top K） ✅ 线性排序：计数（小值域）、桶（均匀分布）、基数（按位 + 每趟必须稳定） ✅ 复杂度对比表：10 种排序的平均/最好/最坏/空间/稳定性要能默写 ✅ Python 内置：Timsort 稳定 O(n log n)；sort() 原地返 None，sorted() 返新表 ✅ 应用：链表排序用归并（注意断链）、最大数用自定义比较、Top K 用堆

    最佳实践¶

    1. 面试先背稳定性与复杂度表：这是排序章第一问，答不上来后面全白搭
    2. 手写排序优先掌握快排分区与归并合并：两者覆盖 90% 的手撕排序考察
    3. 选算法按场景：要稳定选归并，内存紧选堆排，近乎有序选插入，整数小值域选计数
    4. 工程直接用 sorted()：手写只发生在面试与特殊场景，写前先想清 key 和稳定性需求
    5. 遇到 Top K / 第 K 大：第一反应是堆（O(n log k)）或快排分区（平均 O(n)），不是全排序

    链表排序 归并排序
    Top K 问题 堆排序 / 快排分区
    近乎有序 插入排序
    整数范围小 计数排序
