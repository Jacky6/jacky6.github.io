    排序算法（Sorting）知识点¶

    1. 概述¶

    排序是算法中最基础也是最重要的内容之一。

    排序算法对比¶

    算法 平均时间 最好 最坏 空间 稳定性 说明
    冒泡排序 O(n²) O(n) O(n²) O(1) ✅ 稳定 简单，效率低
    选择排序 O(n²) O(n²) O(n²) O(1) ❌ 不稳定 简单，效率低
    插入排序 O(n²) O(n) O(n²) O(1) ✅ 稳定 近乎有序时高效
    希尔排序 O(n log n) O(n log n) O(n²) O(1) ❌ 不稳定 插入排序改进
    归并排序 O(n log n) O(n log n) O(n log n) O(n) ✅ 稳定 分治，稳定
    快速排序 O(n log n) O(n log n) O(n²) O(log n) ❌ 不稳定 最常用 ⭐
    堆排序 O(n log n) O(n log n) O(n log n) O(1) ❌ 不稳定 原地，不稳定
    计数排序 O(n+k) O(n+k) O(n+k) O(k) ✅ 稳定 整数，范围小
    桶排序 O(n+k) O(n+k) O(n²) O(n+k) ✅ 稳定 均匀分布
    基数排序 O(n×k) O(n×k) O(n×k) O(n+k) ✅ 稳定 多位数

    稳定性：相等元素的相对位置在排序后不变

    2. 基础排序（O(n²)）¶

    2.1 冒泡排序¶

    def bubble_sort(arr: List[int]) -> List[int]:
    """
    冒泡排序

    原理：相邻元素比较，大的往后冒

    时间复杂度：
    - 平均：O(n²)
    - 最好：O(n)（已有序）
    - 最坏：O(n²)

    空间复杂度：O(1)
    稳定性：稳定
    """
    n = len(arr)
    for i in range(n):
        swapped = False
        # 最后 i 个元素已有序
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        # 如果没有交换，说明已有序
        if not swapped:
            break
    return arr


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(bubble_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

...
[34, 25, 12, 22, 11, 64, 90]  ← 64 冒泡到位

第 2 轮：
[25, 34, 12, 22, 11, 64, 90]

    2.2 选择排序¶

    def selection_sort(arr: List[int]) -> List[int]:
    """
    选择排序

    原理：每轮选择最小的放到前面

    时间复杂度：O(n²)（无论什么数据都是 O(n²)）
    空间复杂度：O(1)
    稳定性：不稳定
    """
    n = len(arr)
    for i in range(n):
        min_idx = i
        # 找到最小值的索引
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        # 交换
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(selection_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

[11, 34, 25, 12, 22, 64, 90]

    2.3 插入排序¶

    def insertion_sort(arr: List[int]) -> List[int]:
    """
    插入排序

    原理：类似整理扑克牌，将当前元素插入到前面已排序部分的正确位置

    时间复杂度：
    - 平均：O(n²)
    - 最好：O(n)（已有序）
    - 最坏：O(n²)

    空间复杂度：O(1)
    稳定性：稳定
    """
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1

        # 将比 key 大的元素向后移动
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1

        arr[j + 1] = key

    return arr


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(insertion_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

      已排序

          已排序

    3. 高级排序（O(n log n)）⭐¶

    3.1 归并排序¶

    def merge_sort(arr: List[int]) -> List[int]:
    """
    归并排序

    原理：分治法
    1. 分解：将数组分成两半
    2. 解决：递归排序两半
    3. 合并：合并两个有序数组

    时间复杂度：O(n log n)
    空间复杂度：O(n)
    稳定性：稳定
    """
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    return merge(left, right)


def merge(left: List[int], right: List[int]) -> List[int]:
    """合并两个有序数组"""
    result = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:  # <= 保证稳定性
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1

    # 添加剩余元素
    result.extend(left[i:])
    result.extend(right[j:])

    return result


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(merge_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

    3.2 快速排序 ⭐⭐⭐¶

    def quick_sort(arr: List[int]) -> List[int]:
    """
    快速排序

    原理：分治法
    1. 选择基准值（pivot）
    2. 分区：小于 pivot 的放左边，大于的放右边
    3. 递归排序左右两部分

    时间复杂度：
    - 平均：O(n log n)
    - 最好：O(n log n)
    - 最坏：O(n²)（已有序且选端点为 pivot）

    空间复杂度：O(log n)（递归栈）
    稳定性：不稳定
    """
    if len(arr) <= 1:
        return arr

    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]

    return quick_sort(left) + middle + quick_sort(right)


def quick_sort_inplace(arr: List[int], left: int = 0, right: int = None) -> List[int]:
    """快速排序 - 原地版本（节省空间）"""
    if right is None:
        right = len(arr) - 1

    if left >= right:
        return arr

    pivot_idx = partition(arr, left, right)
    quick_sort_inplace(arr, left, pivot_idx - 1)
    quick_sort_inplace(arr, pivot_idx + 1, right)

    return arr


def partition(arr: List[int], left: int, right: int) -> int:
    """分区函数"""
    pivot = arr[right]  # 选最右为基准
    i = left - 1

    for j in range(left, right):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    arr[i + 1], arr[right] = arr[right], arr[i + 1]
    return i + 1


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(quick_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]
print(quick_sort_inplace(arr.copy()))  # [11, 12, 22, 25, 34, 64, 90]

    快速排序过程：
初始：[64, 34, 25, 12, 22, 11, 90]
                    ↑ pivot=12

分区后：[11, 12, 25, 64, 22, 34, 90]
               ↑
            pivot 到位

递归右边：[25, 64, 22, 34, 90]

    3.3 堆排序¶

    def heap_sort(arr: List[int]) -> List[int]:
    """
    堆排序

    原理：
    1. 构建大顶堆
    2. 将堆顶（最大值）与末尾交换
    3. 调整堆，重复步骤 2

    时间复杂度：O(n log n)
    空间复杂度：O(1)
    稳定性：不稳定
    """
    n = len(arr)

    # 构建大顶堆
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    # 逐个提取元素
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]  # 交换
        heapify(arr, i, 0)  # 调整堆

    return arr


def heapify(arr: List[int], n: int, i: int):
    """调整堆"""
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left

    if right < n and arr[right] > arr[largest]:
        largest = right

    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(heap_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

    4. 线性排序（O(n)）¶

    4.1 计数排序¶

    def counting_sort(arr: List[int]) -> List[int]:
    """
    计数排序

    原理：统计每个值出现的次数

    适用：整数，范围较小

    时间复杂度：O(n + k)，k 为值域范围
    空间复杂度：O(k)
    稳定性：稳定
    """
    if not arr:
        return arr

    min_val = min(arr)
    max_val = max(arr)
    range_size = max_val - min_val + 1

    # 计数
    count = [0] * range_size
    for num in arr:
        count[num - min_val] += 1

    # 累加
    for i in range(1, range_size):
        count[i] += count[i - 1]

    # 构建结果
    result = [0] * len(arr)
    for num in reversed(arr):  # 逆序保证稳定性
        count[num - min_val] -= 1
        result[count[num - min_val]] = num

    return result


# 示例
arr = [4, 2, 2, 8, 3, 3, 1]
print(counting_sort(arr))  # [1, 2, 2, 3, 3, 4, 8]

    4.2 桶排序¶

    def bucket_sort(arr: List[float]) -> List[float]:
    """
    桶排序

    原理：将数据分到多个桶，每个桶内排序

    适用：数据均匀分布

    时间复杂度：O(n + k)
    空间复杂度：O(n + k)
    稳定性：稳定
    """
    if not arr:
        return arr

    # 创建桶
    min_val, max_val = min(arr), max(arr)
    bucket_count = len(arr)
    bucket_range = (max_val - min_val) / bucket_count if max_val > min_val else 1
    buckets = [[] for _ in range(bucket_count)]

    # 分配到桶
    for num in arr:
        idx = min(int((num - min_val) / bucket_range), bucket_count - 1)
        buckets[idx].append(num)

    # 每个桶内排序
    result = []
    for bucket in buckets:
        result.extend(sorted(bucket))

    return result


# 示例
arr = [0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51]
print(bucket_sort(arr))  # [0.32, 0.33, 0.37, 0.42, 0.47, 0.51, 0.52]

    4.3 基数排序¶

    def radix_sort(arr: List[int]) -> List[int]:
    """
    基数排序

    原理：按位数从低位到高位排序

    适用：非负整数

    时间复杂度：O(n × k)，k 为最大位数
    空间复杂度：O(n + k)
    稳定性：稳定
    """
    if not arr:
        return arr

    max_val = max(arr)
    exp = 1  # 位数：1, 10, 100...

    while max_val // exp > 0:
        counting_sort_by_digit(arr, exp)
        exp *= 10

    return arr


def counting_sort_by_digit(arr: List[int], exp: int):
    """按指定位数计数排序"""
    n = len(arr)
    result = [0] * n
    count = [0] * 10

    # 统计
    for num in arr:
        digit = (num // exp) % 10
        count[digit] += 1

    # 累加
    for i in range(1, 10):
        count[i] += count[i - 1]

    # 构建结果
    for num in reversed(arr):
        digit = (num // exp) % 10
        count[digit] -= 1
        result[count[digit]] = num

    arr[:] = result


# 示例
arr = [170, 45, 75, 90, 802, 24, 2, 66]
print(radix_sort(arr))  # [2, 24, 45, 66, 75, 90, 170, 802]

    5. 排序算法选择指南¶

    数据规模小（n < 50）？
├─ 是 → 插入排序（简单，近乎有序时快）
└─ 否 → 继续判断

需要稳定性？
├─ 是 → 归并排序
└─ 否 → 继续判断

内存受限？
├─ 是 → 堆排序（原地 O(1)）
└─ 否 → 快速排序（平均最快）

数据是整数且范围小？
├─ 是 → 计数排序（O(n)）
└─ 否 → 继续判断

数据均匀分布？
├─ 是 → 桶排序（O(n)）
└─ 否 → 归并排序

    6.1 排序链表 ✅⭐¶

    def sortList(head: Optional[ListNode]) -> Optional[ListNode]:
    """
    LeetCode 148：排序链表

    归并排序实现
    """
    if not head or not head.next:
        return head

    # 找中点
    slow = fast = head
    prev = None
    while fast and fast.next:
        prev = slow
        slow = slow.next
        fast = fast.next.next

    prev.next = None  # 断开

    # 递归排序
    left = sortList(head)
    right = sortList(slow)

    # 合并
    return merge_two_lists(left, right)


def merge_two_lists(l1, l2):
    dummy = ListNode(0)
    curr = dummy

    while l1 and l2:
        if l1.val <= l2.val:
            curr.next = l1
            l1 = l1.next
        else:
            curr.next = l2
            l2 = l2.next
        curr = curr.next

    curr.next = l1 or l2
    return dummy.next

    6.2 最大数 ✅¶

    from functools import cmp_to_key

def largestNumber(nums: List[int]) -> str:
    """
    LeetCode 179：最大数

    自定义排序
    """
    def compare(x, y):
        if x + y > y + x:
            return -1
        elif x + y < y + x:
            return 1
        return 0

    strs = [str(num) for num in nums]
    strs.sort(key=cmp_to_key(compare))

    result = ''.join(strs)
    return '0' if result[0] == '0' else result


# 示例
nums = [3, 30, 34, 5, 9]
print(largestNumber(nums))  # "9534330"

    7. 本章小结¶

    核心知识点¶

    ✅ 基础排序：冒泡、选择、插入（O(n²)）
    ✅ 高级排序：归并、快速、堆（O(n log n)）
    ✅ 线性排序：计数、桶、基数（O(n)）
    ✅ 稳定性、时间复杂度、空间复杂度

    重点掌握¶

    1. 快速排序：最常用，理解分区思想
    2. 归并排序：稳定，链表排序首选
    3. 堆排序：原地，Top K 问题
    4. 排序选择：根据场景选合适算法
