    1. 链表的定义与基本概念¶

    1.1 知识点¶

    链表（Linked List）是一种物理存储上非连续的线性数据结构。理解链表记住三点： - 结点组成：每个结点包含数据域（val）+ 指针域（next），结点之间靠指针串联 - 头与尾：第一个结点称为头结点（head，常用来代指整条链表），最后一个结点的 next 指向 None - 为什么非连续：结点可以散落在内存任意位置，靠指针链接，所以插入/删除不需要移动元素，但随机访问退化为 O(n)

    单链表结构：
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│ 1 │  ┼──┼──▶│ 2 │  ┼──┼──▶│ 3 │  ┼──┼──▶│ 4 │ ─ │
└─────────┘     └─────────┘     └─────────┘     └─────────┘
  ↑               ↑               ↑               ↑
 head            node2           node3           tail (next=None)

    与 C++/Java 对比：Python 没有内置链表类型（最接近的是 collections.deque），算法题里都自己定义 ListNode 类；C++ 的 std::list、Java 的 LinkedList 都是双链表实现。面试手写代码几乎全是单链表。

    1.2 结点定义¶

    # 单链表结点
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# 双链表结点
class DoublyListNode:
    def __init__(self, val=0, prev=None, next=None):
        self.val = val
        self.prev = prev
        self.next = next

    2. 链表的三种类型¶

    2.1 知识点¶

    链表按指针数量和是否成环分成三种变体： - 单链表：每个结点只有一个 next 指针，只能单向遍历，空间最省，算法题的主角 - 双链表：prev + next 两个指针，可双向遍历；已知结点引用时删除/插入不需要找前驱，代价是每个结点多一个指针 - 循环链表：尾结点的 next 指回头结点形成环，从任意结点出发可遍历整表，常用于约瑟夫环、轮转调度这类场景

    选型原则：刷题基本是单链表；工程里需要两端 O(1) 增删的结构（LRU 缓存、浏览器前进后退）用双链表。

    2.2 单链表实现¶

    class SinglyLinkedList:
    def __init__(self):
        self.head = None
        self.size = 0

    def get(self, index: int) -> int:
        """获取第 index 个结点的值"""
        if index < 0 or index >= self.size:
            return -1
        cur = self.head
        for _ in range(index):
            cur = cur.next
        return cur.val

    def addAtHead(self, val: int) -> None:
        """头插法"""
        new_node = ListNode(val, self.head)
        self.head = new_node
        self.size += 1

    def addAtTail(self, val: int) -> None:
        """尾插法"""
        new_node = ListNode(val)
        if not self.head:
            self.head = new_node
        else:
            cur = self.head
            while cur.next:
                cur = cur.next
            cur.next = new_node
        self.size += 1

    def addAtIndex(self, index: int, val: int) -> None:
        """在指定位置插入"""
        if index > self.size:
            return
        if index <= 0:
            self.addAtHead(val)
            return
        if index == self.size:
            self.addAtTail(val)
            return

        # 找到插入位置的前驱结点
        cur = self.head
        for _ in range(index - 1):
            cur = cur.next

        new_node = ListNode(val, cur.next)
        cur.next = new_node
        self.size += 1

    def deleteAtIndex(self, index: int) -> None:
        """删除指定位置的结点"""
        if index < 0 or index >= self.size:
            return

        if index == 0:
            self.head = self.head.next
        else:
            cur = self.head
            for _ in range(index - 1):
                cur = cur.next
            cur.next = cur.next.next

        self.size -= 1

    2.3 双链表实现¶

    class DoublyLinkedList:
    def __init__(self):
        self.head = None
        self.tail = None
        self.size = 0

    def addAtHead(self, val: int) -> None:
        new_node = DoublyListNode(val)
        if not self.head:
            self.head = self.tail = new_node
        else:
            new_node.next = self.head
            self.head.prev = new_node
            self.head = new_node
        self.size += 1

    def addAtTail(self, val: int) -> None:
        new_node = DoublyListNode(val)
        if not self.tail:
            self.head = self.tail = new_node
        else:
            new_node.prev = self.tail
            self.tail.next = new_node
            self.tail = new_node
        self.size += 1

    def deleteNode(self, node: DoublyListNode) -> None:
        """删除指定结点"""
        if node.prev:
            node.prev.next = node.next
        else:
            self.head = node.next

        if node.next:
            node.next.prev = node.prev
        else:
            self.tail = node.prev

        self.size -= 1

    对比注意：双链表的 deleteNode 拿到结点引用就能直接删（prev/next 互相指一下即可），单链表删除却必须先找到前驱——这是双链表多花一个指针换来的便利。

    2.4 循环链表¶

    最后一个结点的指针指向头结点，形成环。

    循环单链表：
┌─────────┐     ┌─────────┐     ┌─────────┐
│ 1 │  ┼──┼──▶│ 2 │  ┼──┼──▶│ 3 │  ┼──┼──┐
└─────────┘     └─────────┘     └─────────┘│
  ▲                                       │
  └───────────────────────────────────────┘

    特点： - 从任意结点出发可遍历整个链表 - 判断结束条件：cur.next != head（不能再用 cur.next != None，否则死循环） - 常用于约瑟夫环等问题

    2.5 ⚠️ 易错点：插入/删除操作的是"前驱"，步数别走错¶

    单链表的插入/删除本质是修改前驱结点的 next，所以定位时必须停在前驱上；多走一步就回不来了（单链表不能回头）。

    # 在位置 index（0 起）插入：需要的是位置 index 的"前驱"
cur = self.head
for _ in range(index):      # ❌ 走 index 步，到达的是位置 index 的结点本身
    cur = cur.next
for _ in range(index - 1):  # ✅ 走 index-1 步，到达前驱，再执行 cur.next = new_node
    cur = cur.next

    这也是"头结点没有前驱"这一特殊情况的来源——第 4 节的虚拟头结点就是为了让头结点也有前驱。

    3. 时间复杂度¶

    3.1 知识点¶

    链表和数组的复杂度对比是面试必问项。核心结论一句话：链表用随机访问换插入删除。 - 数组靠连续内存实现 O(1) 下标访问，但中间插删要移动元素 - 链表靠指针链接，插删只需改指针，但访问第 k 个元素必须从头走 k 步 - 注意区分"操作本身"的复杂度和"加上定位"的总复杂度（见下方易错点）

    3.2 复杂度对比速查¶

    操作 数组 链表
    访问第 k 个元素 O(1) O(k)
    头部插入/删除 O(n) O(1)
    尾部插入/删除 O(1)* O(n)
    中间插入/删除 O(n) O(1)**
    空间 O(n) O(n) + 指针开销

    数组尾部插入摊还 O(1)（动态扩容时）
    *链表需要先找到位置 O(k)，插入/删除本身 O(1)

    3.3 ⚠️ 易错点："链表插入删除是 O(1)" 只对一半¶

    面试里说"链表插删 O(1)"会被追问。插入/删除动作本身是 O(1)，但如果要先按位置找到那个点，总复杂度是 O(k)。真正全程 O(1) 的只有三种情况：头插（已知 head）、已持有前驱结点引用、带尾指针的尾插。

    # ✅ 真 O(1)：已经持有前驱结点 p，直接插
new_node = ListNode(val, p.next)
p.next = new_node

# ❌ 这不是 O(1)："在位置 k 插入"，定位前驱就要 O(k)
cur = head
for _ in range(k - 1):   # 查找 O(k) + 插入 O(1) = 总 O(k)
    cur = cur.next

    4. 虚拟头结点（Dummy Head）¶

    4.1 知识点¶

    虚拟头结点（dummy）是加在真正头结点之前的一个假结点，next 指向 head。它的价值在于：让头结点和普通结点被同一套逻辑处理。 - 链表题最大的特例就是删头结点：删别的结点改"前驱.next"，头结点没有前驱 - 加了 dummy，头结点也有了前驱，所有删除/插入逻辑只写一套，不用 if 特判 - 最后务必返回 dummy.next，那才是新的真正头结点

    适用场景：可能删除头结点、或头结点需要特殊处理的一切题目（本章的 removeElements、reverseBetween、swapPairs、removeNthFromEnd、回文/合并类题目全用得上）。

    4.2 示例：删除链表中的元素¶

    def removeElements(head: ListNode, val: int) -> ListNode:
    """删除链表中所有值为 val 的结点"""
    dummy = ListNode(0, head)  # 虚拟头结点
    cur = dummy

    while cur.next:
        if cur.next.val == val:
            cur.next = cur.next.next
        else:
            cur = cur.next

    return dummy.next  # 返回真正的头结点

    4.3 ⚠️ 易错点：用了 dummy 却返回 head¶

    def removeElements(head, val):
    dummy = ListNode(0, head)
    cur = dummy
    while cur.next:
        if cur.next.val == val:
            cur.next = cur.next.next
        else:
            cur = cur.next
    return head        # ❌ head 可能正是被删的结点，返回的是废弃结点

# ✅ 一律返回 dummy.next
# 反例：链表 1→1→2，val=1，返回 head 仍指向已被跳过的第一个 1

    5. 快慢指针（Floyd 判圈算法）¶

    5.1 知识点¶

    快慢指针是链表里最经典的双指针形态：快指针每次走 2 步，慢指针每次走 1 步，利用相对速度差解决三类问题： - 找中点：快指针到终点时，慢指针恰好在中点（路程是快的一半） - 判环（Floyd）：有环则快指针一定会追上慢指针（操场套圈）；无环则快指针先走到 None - 找环入口：相遇后，一个指针从 head、另一个从相遇点同时每次走 1 步，相遇处即入口（数学推导见 5.4）

    三个应用都是 O(n) 时间、O(1) 额外空间，一趟扫描完成。

    5.2 找中点¶

    def middleNode(head: ListNode) -> ListNode:
    """返回链表的中间结点"""
    slow = fast = head

    while fast and fast.next:
        slow = slow.next      # 走 1 步
        fast = fast.next.next # 走 2 步

    return slow  # 慢指针指向中点

# 测试：1→2→3→4→5 → 返回 3
#       1→2→3→4   → 返回 3（第二个中点）

    5.3 判断是否有环¶

    def hasCycle(head: ListNode) -> bool:
    """判断链表是否有环"""
    if not head or not head.next:
        return False

    slow = fast = head

    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:  # 快慢指针相遇 → 有环
            return True

    return False

    5.4 找环的入口¶

    def detectCycle(head: ListNode) -> ListNode:
    """找到环的入口结点"""
    slow = fast = head

    # 第一步：判断是否有环
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            break
    else:
        return None  # 无环

    # 第二步：找环入口
    # 从头结点和相遇点同时出发，相遇点即为环入口
    ptr1 = head
    ptr2 = slow
    while ptr1 != ptr2:
        ptr1 = ptr1.next
        ptr2 = ptr2.next

    return ptr1

    原理证明： 

    设：头结点到环入口距离 = a
    环入口到相遇点距离 = b
    相遇点到环入口距离 = c

快指针路程 = a + b + n(b+c) = 2(a+b)
慢指针路程 = a + b

推导：a = (n-1)(b+c) + c
当 n=1 时：a = c

结论：从头结点和相遇点同时走 a 步，会在环入口相遇

    5.5 ⚠️ 易错点：循环条件的两个细节¶

    # 快指针一次走 2 步，必须保证 fast 和 fast.next 都非空：
while fast and fast.next:      # ✅ 标准写法
    slow = slow.next
    fast = fast.next.next

while fast:                    # ❌ fast.next 为 None 时，fast.next.next 抛 AttributeError
    slow = slow.next
    fast = fast.next.next

    偶数长度链表时，循环条件还决定返回哪个中点：

    # 链表 1→2→3→4，两种循环条件决定返回哪个中点：
# 条件 1: fast and fast.next            → slow 停在 3（第二个中点，LeetCode 876 的要求）
# 条件 2: fast.next and fast.next.next  → slow 停在 2（第一个中点，回文链表分割用它）

    写之前先想清楚题目要第一个还是第二个中点，别默写错版本。

    6. 反转链表¶

    6.1 知识点¶

    反转链表是链表最基础的指针操作，大量题目直接或间接用到它（区间反转、K 组反转、回文判断都建立在它之上）。两种写法： - 迭代（三指针）：prev/cur/next_temp 三个指针逐结点翻指针，O(1) 空间，面试首选 - 递归：先递归反转后续链表，再令 head.next.next = head，代码短但递归深度 O(n)

    迭代法记住口诀：先存 next，再改指针——否则改完 cur.next 就丢了剩余链表的引用。

    6.2 迭代法（三指针）¶

    def reverseList(head: ListNode) -> ListNode:
    """反转链表 - 迭代法"""
    prev = None
    cur = head

    while cur:
        next_temp = cur.next  # 保存后继
        cur.next = prev       # 反转指针
        prev = cur            # prev 前移
        cur = next_temp       # cur 前移

    return prev  # 新的头结点

# 执行过程：
# 初始：None ← 1 → 2 → 3 → 4 → 5
#        prev cur
# 第 1 步：1 ← 2 → 3 → 4 → 5
#         prev cur
# 第 2 步：1 ← 2 ← 3 → 4 → 5
#              prev cur
# ...
# 最终：1 ← 2 ← 3 ← 4 ← 5
#                   prev

    6.3 递归法¶

    def reverseListRecursive(head: ListNode) -> ListNode:
    """反转链表 - 递归法"""
    # 基础情况：空链表或单结点
    if not head or not head.next:
        return head

    # 递归反转后续链表
    new_head = reverseListRecursive(head.next)

    # 反转当前结点
    head.next.next = head
    head.next = None

    return new_head

    6.4 ⚠️ 易错点：反转时丢链 / 成环¶

    # 迭代法：先改指针就丢了剩余链表
while cur:
    cur.next = prev       # ❌ 覆盖 cur.next 后，后面整条链的引用立刻丢失
    prev = cur
    cur = cur.next        # 此处 cur.next 已是 prev，原地打转死循环

# ✅ 必须先保存 next 再翻指针
while cur:
    next_temp = cur.next
    cur.next = prev
    prev = cur
    cur = next_temp

    递归法对应的坑是漏写 head.next = None：反转后原头结点的 next 仍指向第 2 个结点，链表尾部成环。

    7. 合并与分割链表¶

    7.1 知识点¶

    合并与分割是一对互逆操作：合并把两条有序链表拼成一条，分割把一条链表按条件拆成两条再拼接。 - 合并：dummy + 双指针逐个比较，直接复用原结点（不要新建结点拷贝值），循环结束后把非空剩余整段接上 - 分割：用两条 dummy 链分别收集"小于 x"和"大于等于 x"的结点，最后前链尾接后链头 - 两者都是更难题目的地基：合并两个有序链表是合并 K 个的基本操作（见 8.7），分割思想出现在快排链表版中

    7.2 合并两个有序链表¶

    def mergeTwoLists(l1: ListNode, l2: ListNode) -> ListNode:
    """合并两个有序链表"""
    dummy = ListNode(0)
    cur = dummy

    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1
            l1 = l1.next
        else:
            cur.next = l2
            l2 = l2.next
        cur = cur.next

    # 连接剩余部分
    cur.next = l1 if l1 else l2

    return dummy.next

    7.3 分割链表¶

    def partition(head: ListNode, x: int) -> ListNode:
    """分割链表：小于 x 的在前，大于等于 x 的在后"""
    before_head = ListNode(0)
    after_head = ListNode(0)
    before = before_head
    after = after_head

    cur = head
    while cur:
        if cur.val < x:
            before.next = cur
            before = before.next
        else:
            after.next = cur
            after = after.next
        cur = cur.next

    after.next = None  # 防止成环
    before.next = after_head.next

    return before_head.next

    after.next = None 这一行不能省：after 链的尾结点在原链表中的 next 可能还指着某个被分到 before 链的结点，不置空就会形成环，遍历时死循环。

    8. 经典例题详解 ⭐⭐⭐⭐¶

    8.1 知识点¶

    链表题千变万化，解法框架是同一套： 1. 先画图：把指针变化过程画出来，链表题本质是指针重连，图比代码直观 2. 判断头结点是否可能被删/被换：是就上 dummy，返回 dummy.next 3. 判断是否涉及中点/环/相对位置：是就上快慢指针或前后双指针 4. 最后查边界：空表、单结点、恰好操作头/尾结点

    下面 10 道题覆盖链表全部高频题型，按难度大致从低到高排列。

    8.2 反转链表 II（LeetCode 92）⭐⭐¶

    题目：反转从位置 left 到 right 的链表结点

    def reverseBetween(head: ListNode, left: int, right: int) -> ListNode:
    """
    思路：找到 left 前驱，对 left~right 区间头插法反转
    """
    if not head or left == right:
        return head

    dummy = ListNode(0, head)
    pre = dummy

    # 找到 left 位置的前驱结点
    for _ in range(left - 1):
        pre = pre.next

    # 头插法反转区间 [left, right]
    cur = pre.next
    for _ in range(right - left):
        next_node = cur.next
        cur.next = next_node.next
        next_node.next = pre.next
        pre.next = next_node

    return dummy.next

# 测试：1→2→3→4→5, left=2, right=4
# 结果：1→4→3→2→5

    执行过程： 

    初始：dummy→1→2→3→4→5
              pre cur

第 1 次循环：
  next_node = 3
  cur.next = 4
  next_node.next = 2
  pre.next = 3
  结果：dummy→1→3→2→4→5

第 2 次循环：
  next_node = 4
  cur.next = 5
  next_node.next = 3
  pre.next = 4
  结果：dummy→1→4→3→2→5

    8.3 两两交换结点（LeetCode 24）⭐⭐¶

    题目：两两交换相邻结点

    def swapPairs(head: ListNode) -> ListNode:
    """
    思路：每次处理两个结点，交换它们的顺序
    """
    dummy = ListNode(0, head)
    cur = dummy

    while cur.next and cur.next.next:
        # 标记要交换的两个结点
        node1 = cur.next
        node2 = cur.next.next

        # 交换
        cur.next = node2
        node1.next = node2.next
        node2.next = node1

        # 移动到下一组
        cur = node1

    return dummy.next

# 测试：1→2→3→4→5
# 结果：2→1→4→3→5

    图解： 

    初始：dummy→1→2→3→4→5
             ↑  ↑
           node1 node2

交换后：dummy→2→1→3→4→5
              ↑     ↑
             cur   cur.next(下一轮)

    8.4 K 个一组翻转链表（LeetCode 25）⭐⭐⭐¶

    题目：每 k 个结点一组翻转，不足 k 个保持不变

    def reverseKGroup(head: ListNode, k: int) -> ListNode:
    """
    思路：先判断是否有 k 个结点，有则翻转，无则保持
    """
    dummy = ListNode(0, head)
    pre = dummy

    while True:
        # 1. 检查剩余结点是否有 k 个
        tail = pre
        for _ in range(k):
            if not tail.next:
                return dummy.next
            tail = tail.next

        # 2. 记录下一组的起点
        next_group = tail.next

        # 3. 翻转当前组 [pre.next, tail]
        cur = pre.next
        for _ in range(k - 1):
            next_node = cur.next
            cur.next = next_node.next
            next_node.next = pre.next
            pre.next = next_node

        # 4. 连接下一组
        # 翻转后，原来的首结点变成尾结点
        pre.next.next = next_group

        # 5. 移动 pre 到下一组的前驱
        pre = pre.next.next if next_group else None
        if not pre:
            break

    return dummy.next

# 测试：1→2→3→4→5, k=3
# 结果：3→2→1→4→5

    8.5 删除排序链表中的重复元素（LeetCode 83）⭐¶

    题目：删除重复元素，每个元素只保留一次

    def deleteDuplicates(head: ListNode) -> ListNode:
    """
    思路：有序链表，重复元素相邻，直接跳过
    """
    if not head:
        return head

    cur = head
    while cur.next:
        if cur.val == cur.next.val:
            cur.next = cur.next.next  # 跳过重复结点
        else:
            cur = cur.next

    return head

# 测试：1→1→2→3→3
# 结果：1→2→3

    注意本题不需要 dummy：头结点一定保留（重复的只是被跳过的后继），所以直接返回 head。和下一题 82 对比记忆。

    8.6 删除排序链表中的重复元素 II（LeetCode 82）⭐⭐¶

    题目：删除所有重复的元素，只保留不重复的

    def deleteDuplicatesII(head: ListNode) -> ListNode:
    """
    思路：使用虚拟头结点，遇到重复元素全部跳过
    """
    if not head:
        return head

    dummy = ListNode(0, head)
    cur = dummy

    while cur.next and cur.next.next:
        if cur.next.val == cur.next.next.val:
            # 记录重复值
            val = cur.next.val
            # 跳过所有值为 val 的结点
            while cur.next and cur.next.val == val:
                cur.next = cur.next.next
        else:
            cur = cur.next

    return dummy.next

# 测试：1→2→3→3→4→4→5
# 结果：1→2→5

    本题头结点可能被删（如 1→1→2 删成 2），所以必须上 dummy——这就是 83 与 82 的本质差别。

    8.7 合并 K 个有序链表（LeetCode 23）⭐⭐⭐¶

    题目：合并 k 个升序链表

    解法一：分治法（推荐）

    def mergeKLists(lists: List[ListNode]) -> ListNode:
    """
    分治法：两两合并，时间复杂度 O(N log k)
    N 为所有结点总数，k 为链表数量
    """
    if not lists:
        return None

    def merge(l1, l2):
        """合并两个有序链表"""
        dummy = ListNode(0)
        cur = dummy
        while l1 and l2:
            if l1.val <= l2.val:
                cur.next = l1
                l1 = l1.next
            else:
                cur.next = l2
                l2 = l2.next
            cur = cur.next
        cur.next = l1 if l1 else l2
        return dummy.next

    def divide(left, right):
        """分治"""
        if left == right:
            return lists[left]
        if left > right:
            return None

        mid = (left + right) // 2
        return merge(divide(left, mid), divide(mid + 1, right))

    return divide(0, len(lists) - 1)

    解法二：最小堆

    import heapq

def mergeKListsHeap(lists: List[ListNode]) -> ListNode:
    """
    最小堆：维护 k 个链表当前最小值，时间复杂度 O(N log k)
    """
    if not lists:
        return None

    # 最小堆：(val, index, node)
    heap = []
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))

    dummy = ListNode(0)
    cur = dummy

    while heap:
        val, idx, node = heapq.heappop(heap)
        cur.next = node
        cur = cur.next

        if node.next:
            heapq.heappush(heap, (node.next.val, idx, node.next))

    return dummy.next

    堆解法里元组中间放 idx 不是多余的：两条链表头结点值相同时，heapq 会比较元组第二项，没有 idx 就会去比较两个 ListNode 对象，直接抛 TypeError。

    8.8 环形链表 II（LeetCode 142）⭐⭐¶

    题目：找到环的入口结点

    def detectCycle(head: ListNode) -> ListNode:
    """
    快慢指针法，时间复杂度 O(n)，空间复杂度 O(1)
    """
    if not head or not head.next:
        return None

    slow = fast = head

    # 第一步：判断是否有环
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            break
    else:
        return None  # 无环

    # 第二步：找环入口
    ptr = head
    while ptr != slow:
        ptr = ptr.next
        slow = slow.next

    return ptr

    数学原理见 5.4 的推导：a = c，所以头结点与相遇点同速前进必在入口相遇。

    8.9 相交链表（LeetCode 160）⭐⭐¶

    题目：找到两个单链表相交的起始结点

    def getIntersectionNode(headA: ListNode, headB: ListNode) -> ListNode:
    """
    双指针法：A 走完走 B，B 走完走 A，相遇点即为交点
    时间复杂度 O(m+n)，空间复杂度 O(1)
    """
    if not headA or not headB:
        return None

    pA, pB = headA, headB

    while pA != pB:
        pA = pA.next if pA else headB
        pB = pB.next if pB else headA

    return pA  # 相交则返回交点，不相交则返回 None

    原理： 

    设：A 链表长度 = a，B 链表长度 = b，公共部分长度 = c

pA 路程：a + (b - c)
pB 路程：b + (a - c)

两者相等，会在交点相遇

若不相交：pA 和 pB 同时走到 None，返回 None

    8.10 删除链表的倒数第 N 个结点（LeetCode 19）⭐⭐¶

    题目：删除倒数第 n 个结点

    def removeNthFromEnd(head: ListNode, n: int) -> ListNode:
    """
    快慢指针：快指针先走 n 步，然后同时走
    时间复杂度 O(n)，空间复杂度 O(1)
    """
    dummy = ListNode(0, head)
    fast = slow = dummy

    # 快指针先走 n 步
    for _ in range(n):
        fast = fast.next

    # 同时走，直到快指针到达末尾
    while fast.next:
        fast = fast.next
        slow = slow.next

    # slow 指向倒数第 n+1 个结点
    slow.next = slow.next.next

    return dummy.next

# 测试：1→2→3→4→5, n=2
# 结果：1→2→3→5

    ⚠️ 易错点：删头结点时没有 dummy 会崩

    当 n 恰好等于链表长度（删的就是头结点）时：

    fast = slow = head          # ❌ 不用 dummy
for _ in range(n):
    fast = fast.next        # fast 已变成 None
while fast.next:            # AttributeError: None 没有 next
    ...

# ✅ 从 dummy 出发：删头结点时 slow 停在 dummy（头结点的前驱），逻辑依然成立

    8.11 回文链表（LeetCode 234）⭐⭐¶

    题目：判断链表是否为回文结构

    def isPalindrome(head: ListNode) -> bool:
    """
    思路：找中点 → 反转后半部分 → 比较 → 恢复（可选）
    时间复杂度 O(n)，空间复杂度 O(1)
    """
    if not head or not head.next:
        return True

    # 1. 找中点
    slow = fast = head
    while fast.next and fast.next.next:
        slow = slow.next
        fast = fast.next.next

    # 2. 反转后半部分
    second_half = slow.next
    slow.next = None  # 断开

    prev = None
    cur = second_half
    while cur:
        next_temp = cur.next
        cur.next = prev
        prev = cur
        cur = next_temp

    # 3. 比较两部分
    p1, p2 = head, prev
    result = True
    while p2:
        if p1.val != p2.val:
            result = False
            break
        p1 = p1.next
        p2 = p2.next

    # 4. 恢复链表（可选）
    # ...

    return result

# 测试：1→2→2→1 → True
#       1→2→3     → False

    注意两个细节：第 1 步用 fast.next and fast.next.next 找第一个中点（偶数长度时 slow 停在前半段末尾），这样 slow.next 才是后半段的起点；另外此解法原地修改了输入链表，面试中要主动说明是否需要恢复（第 4 步）。

    9. 链表题型分类总结¶

    9.1 知识点¶

    刷完题要做两件事：按技巧归类，看清"什么题用什么工具"；和数组对比，看清"什么时候该用链表"。两张表就是链表章的检索索引。

    9.2 按技巧分类¶

    技巧 适用题型 代表题目
    虚拟头结点 涉及头结点操作 删除结点、合并链表
    快慢指针 找中点、判环 环形链表、回文链表
    双指针 相交、删除倒数第 N 相交链表
    反转链表 区间反转、K 组反转 反转链表 II
    归并思想 合并有序链表 合并 K 个有序链表
    头插法 区间翻转 反转链表 II
    尾插法 保持顺序的构建 分割链表

    9.3 按难度分类¶

    ⭐ 基础题： - 反转链表 - 合并两个有序链表 - 删除排序链表中的重复元素

    ⭐⭐ 进阶题： - 删除倒数第 N 个结点 - 环形链表 II - 相交链表 - 两两交换结点 - 回文链表

    ⭐⭐⭐ 难题： - 合并 K 个有序链表 - K 个一组翻转链表 - LRU 缓存（链表 + 哈希表）

    9.4 链表 vs 数组¶

    特性 数组 链表
    存储方式 连续内存 非连续内存
    随机访问 O(1) O(n)
    插入/删除 O(n) O(1)*
    空间效率 高 低（指针开销）
    缓存友好 是 否

    *需要先找到位置

    面试结论：读多写少、按下标访问多选数组；频繁在头/中间插删选链表。实际工程中由于缓存亲和性，数组在绝大多数场景仍有常数级优势。

    10. 本章小结¶

    核心知识点¶

    ✅ 链表本质：结点 = 数据域 + 指针域，内存非连续，单/双/循环三种形态
    ✅ 复杂度：访问 O(n)、头插 O(1)、插删动作本身 O(1) 但定位要 O(k)
    ✅ 虚拟头结点：统一头删等边界，最后返回 dummy.next
    ✅ 快慢指针：找中点、判环、找环入口（Floyd），O(1) 空间
    ✅ 双指针：相交链表走完走对方路；倒数第 N 个快先走 n 步
    ✅ 反转链表：迭代三指针（先存 next 再翻）、递归（head.next.next = head）
    ✅ 合并/分割：双指针归并复用结点；K 链表合并分治/堆 O(N log k)
    ✅ 解题框架：画图 → 判头删（dummy）→ 选指针 → 查边界

    最佳实践¶

    1. 动手先画图：把指针变化过程画出来，链表题本质是指针重连，图比代码直观
    2. 头结点可能被删就上 dummy：dummy = ListNode(0, head)，返回 dummy.next
    3. 快慢指针循环条件统一写 while fast and fast.next：防止 fast.next.next 对 None 取属性
    4. 改指针前先存 next：next_temp = cur.next 永远是反转循环的第一行
    5. 原地修改输入链表要说明是否恢复：回文判断这类题面试中主动提一句
