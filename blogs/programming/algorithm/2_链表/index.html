    链表（Linked List）知识点¶

    1. 定义与基本概念¶

    链表是一种物理存储单元上非连续、非顺序的线性数据结构。

    • 由一系列结点（Node）组成
    • 每个结点包含：数据域 + 指针域
    • 结点之间通过指针链接
    • 第一个结点称为头结点（Head）
    • 最后一个结点的指针指向 NULL（或 None）
    单链表结构：
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│ 1 │  ┼──┼──▶│ 2 │  ┼──┼──▶│ 3 │  ┼──┼──▶│ 4 │ ─ │
└─────────┘     └─────────┘     └─────────┘     └─────────┘
  ↑               ↑               ↑               ↑
 head            node2           node3           tail (next=None)

    1.1 结点定义¶

    # 单链表结点
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# 双链表结点
class DoublyListNode:
    def __init__(self, val=0, prev=None, next=None):
        self.val = val
        self.prev = prev
        self.next = next

    2. 链表类型¶

    2.1 单链表（Singly Linked List）¶

    每个结点只有一个 next 指针指向后继结点。

    class SinglyLinkedList:
    def __init__(self):
        self.head = None
        self.size = 0

    def get(self, index: int) -> int:
        """获取第 index 个结点的值"""
        if index < 0 or index >= self.size:
            return -1
        cur = self.head
        for _ in range(index):
            cur = cur.next
        return cur.val

    def addAtHead(self, val: int) -> None:
        """头插法"""
        new_node = ListNode(val, self.head)
        self.head = new_node
        self.size += 1

    def addAtTail(self, val: int) -> None:
        """尾插法"""
        new_node = ListNode(val)
        if not self.head:
            self.head = new_node
        else:
            cur = self.head
            while cur.next:
                cur = cur.next
            cur.next = new_node
        self.size += 1

    def addAtIndex(self, index: int, val: int) -> None:
        """在指定位置插入"""
        if index > self.size:
            return
        if index <= 0:
            self.addAtHead(val)
            return
        if index == self.size:
            self.addAtTail(val)
            return

        # 找到插入位置的前驱结点
        cur = self.head
        for _ in range(index - 1):
            cur = cur.next

        new_node = ListNode(val, cur.next)
        cur.next = new_node
        self.size += 1

    def deleteAtIndex(self, index: int) -> None:
        """删除指定位置的结点"""
        if index < 0 or index >= self.size:
            return

        if index == 0:
            self.head = self.head.next
        else:
            cur = self.head
            for _ in range(index - 1):
                cur = cur.next
            cur.next = cur.next.next

        self.size -= 1

    2.2 双链表（Doubly Linked List）¶

    每个结点有 prev 和 next 两个指针，可双向遍历。

    class DoublyLinkedList:
    def __init__(self):
        self.head = None
        self.tail = None
        self.size = 0

    def addAtHead(self, val: int) -> None:
        new_node = DoublyListNode(val)
        if not self.head:
            self.head = self.tail = new_node
        else:
            new_node.next = self.head
            self.head.prev = new_node
            self.head = new_node
        self.size += 1

    def addAtTail(self, val: int) -> None:
        new_node = DoublyListNode(val)
        if not self.tail:
            self.head = self.tail = new_node
        else:
            new_node.prev = self.tail
            self.tail.next = new_node
            self.tail = new_node
        self.size += 1

    def deleteNode(self, node: DoublyListNode) -> None:
        """删除指定结点"""
        if node.prev:
            node.prev.next = node.next
        else:
            self.head = node.next

        if node.next:
            node.next.prev = node.prev
        else:
            self.tail = node.prev

        self.size -= 1

    2.3 循环链表（Circular Linked List）¶

    最后一个结点的指针指向头结点，形成环。

    循环单链表：
┌─────────┐     ┌─────────┐     ┌─────────┐
│ 1 │  ┼──┼──▶│ 2 │  ┼──┼──▶│ 3 │  ┼──┼──┐
└─────────┘     └─────────┘     └─────────┘│
  ▲                                       │
  └───────────────────────────────────────┘

    特点： - 从任意结点出发可遍历整个链表 - 判断结束条件：cur.next != head - 常用于约瑟夫环等问题

    3. 时间复杂度对比¶

    操作 数组 链表
    访问第 k 个元素 O(1) O(k)
    头部插入/删除 O(n) O(1)
    尾部插入/删除 O(1)* O(n)
    中间插入/删除 O(n) O(1)**
    空间 O(n) O(n) + 指针开销

    数组尾部插入摊还 O(1)（动态扩容时）
    *链表需要先找到位置 O(k)，插入/删除本身 O(1)

    4. 链表经典技巧¶

    4.1 虚拟头结点（Dummy Head）¶

    作用：简化头结点的边界处理

    def removeElements(head: ListNode, val: int) -> ListNode:
    """删除链表中所有值为 val 的结点"""
    dummy = ListNode(0, head)  # 虚拟头结点
    cur = dummy

    while cur.next:
        if cur.next.val == val:
            cur.next = cur.next.next
        else:
            cur = cur.next

    return dummy.next  # 返回真正的头结点

    4.2 快慢指针（Floyd 判圈算法）¶

    快指针每次走 2 步，慢指针每次走 1 步。

    （1）找中点¶

    def middleNode(head: ListNode) -> ListNode:
    """返回链表的中间结点"""
    slow = fast = head

    while fast and fast.next:
        slow = slow.next      # 走 1 步
        fast = fast.next.next # 走 2 步

    return slow  # 慢指针指向中点

# 测试：1→2→3→4→5 → 返回 3
#       1→2→3→4   → 返回 3（第二个中点）

    （2）判断是否有环¶

    def hasCycle(head: ListNode) -> bool:
    """判断链表是否有环"""
    if not head or not head.next:
        return False

    slow = fast = head

    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:  # 快慢指针相遇 → 有环
            return True

    return False

    （3）找环的入口¶

    def detectCycle(head: ListNode) -> ListNode:
    """找到环的入口结点"""
    slow = fast = head

    # 第一步：判断是否有环
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            break
    else:
        return None  # 无环

    # 第二步：找环入口
    # 从头结点和相遇点同时出发，相遇点即为环入口
    ptr1 = head
    ptr2 = slow
    while ptr1 != ptr2:
        ptr1 = ptr1.next
        ptr2 = ptr2.next

    return ptr1

    原理证明： 

    设：头结点到环入口距离 = a
    环入口到相遇点距离 = b
    相遇点到环入口距离 = c

快指针路程 = a + b + n(b+c) = 2(a+b)
慢指针路程 = a + b

推导：a = (n-1)(b+c) + c
当 n=1 时：a = c

结论：从头结点和相遇点同时走 a 步，会在环入口相遇

    4.3 反转链表¶

    （1）迭代法（三指针）¶

    def reverseList(head: ListNode) -> ListNode:
    """反转链表 - 迭代法"""
    prev = None
    cur = head

    while cur:
        next_temp = cur.next  # 保存后继
        cur.next = prev       # 反转指针
        prev = cur            # prev 前移
        cur = next_temp       # cur 前移

    return prev  # 新的头结点

# 执行过程：
# 初始：None ← 1 → 2 → 3 → 4 → 5
#        prev cur
# 第 1 步：1 ← 2 → 3 → 4 → 5
#         prev cur
# 第 2 步：1 ← 2 ← 3 → 4 → 5
#              prev cur
# ...
# 最终：1 ← 2 ← 3 ← 4 ← 5
#                   prev

    （2）递归法¶

    def reverseListRecursive(head: ListNode) -> ListNode:
    """反转链表 - 递归法"""
    # 基础情况：空链表或单结点
    if not head or not head.next:
        return head

    # 递归反转后续链表
    new_head = reverseListRecursive(head.next)

    # 反转当前结点
    head.next.next = head
    head.next = None

    return new_head

    4.4 合并链表¶

    def mergeTwoLists(l1: ListNode, l2: ListNode) -> ListNode:
    """合并两个有序链表"""
    dummy = ListNode(0)
    cur = dummy

    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1
            l1 = l1.next
        else:
            cur.next = l2
            l2 = l2.next
        cur = cur.next

    # 连接剩余部分
    cur.next = l1 if l1 else l2

    return dummy.next

    4.5 分割链表¶

    def partition(head: ListNode, x: int) -> ListNode:
    """分割链表：小于 x 的在前，大于等于 x 的在后"""
    before_head = ListNode(0)
    after_head = ListNode(0)
    before = before_head
    after = after_head

    cur = head
    while cur:
        if cur.val < x:
            before.next = cur
            before = before.next
        else:
            after.next = cur
            after = after.next
        cur = cur.next

    after.next = None  # 防止成环
    before.next = after_head.next

    return before_head.next

    5. 经典例题详解¶

    5.1 反转链表 II（LeetCode 92）⭐⭐¶

    题目：反转从位置 left 到 right 的链表结点

    def reverseBetween(head: ListNode, left: int, right: int) -> ListNode:
    """
    思路：找到 left 前驱，对 left~right 区间头插法反转
    """
    if not head or left == right:
        return head

    dummy = ListNode(0, head)
    pre = dummy

    # 找到 left 位置的前驱结点
    for _ in range(left - 1):
        pre = pre.next

    # 头插法反转区间 [left, right]
    cur = pre.next
    for _ in range(right - left):
        next_node = cur.next
        cur.next = next_node.next
        next_node.next = pre.next
        pre.next = next_node

    return dummy.next

# 测试：1→2→3→4→5, left=2, right=4
# 结果：1→4→3→2→5

    执行过程： 

    初始：dummy→1→2→3→4→5
              pre cur

第 1 次循环：
  next_node = 3
  cur.next = 4
  next_node.next = 2
  pre.next = 3
  结果：dummy→1→3→2→4→5

第 2 次循环：
  next_node = 4
  cur.next = 5
  next_node.next = 3
  pre.next = 4
  结果：dummy→1→4→3→2→5

    5.2 两两交换结点（LeetCode 24）⭐⭐¶

    题目：两两交换相邻结点

    def swapPairs(head: ListNode) -> ListNode:
    """
    思路：每次处理两个结点，交换它们的顺序
    """
    dummy = ListNode(0, head)
    cur = dummy

    while cur.next and cur.next.next:
        # 标记要交换的两个结点
        node1 = cur.next
        node2 = cur.next.next

        # 交换
        cur.next = node2
        node1.next = node2.next
        node2.next = node1

        # 移动到下一组
        cur = node1

    return dummy.next

# 测试：1→2→3→4→5
# 结果：2→1→4→3→5

    图解： 

    初始：dummy→1→2→3→4→5
             ↑  ↑
           node1 node2

交换后：dummy→2→1→3→4→5
              ↑     ↑
             cur   cur.next(下一轮)

    5.3 K 个一组翻转链表（LeetCode 25）⭐⭐⭐¶

    题目：每 k 个结点一组翻转，不足 k 个保持不变

    def reverseKGroup(head: ListNode, k: int) -> ListNode:
    """
    思路：先判断是否有 k 个结点，有则翻转，无则保持
    """
    dummy = ListNode(0, head)
    pre = dummy

    while True:
        # 1. 检查剩余结点是否有 k 个
        tail = pre
        for _ in range(k):
            if not tail.next:
                return dummy.next
            tail = tail.next

        # 2. 记录下一组的起点
        next_group = tail.next

        # 3. 翻转当前组 [pre.next, tail]
        cur = pre.next
        for _ in range(k - 1):
            next_node = cur.next
            cur.next = next_node.next
            next_node.next = pre.next
            pre.next = next_node

        # 4. 连接下一组
        # 翻转后，原来的首结点变成尾结点
        pre.next.next = next_group

        # 5. 移动 pre 到下一组的前驱
        pre = pre.next.next if next_group else None
        if not pre:
            break

    return dummy.next

# 测试：1→2→3→4→5, k=3
# 结果：3→2→1→4→5

    5.4 删除排序链表中的重复元素（LeetCode 83）⭐¶

    题目：删除重复元素，每个元素只保留一次

    def deleteDuplicates(head: ListNode) -> ListNode:
    """
    思路：有序链表，重复元素相邻，直接跳过
    """
    if not head:
        return head

    cur = head
    while cur.next:
        if cur.val == cur.next.val:
            cur.next = cur.next.next  # 跳过重复结点
        else:
            cur = cur.next

    return head

# 测试：1→1→2→3→3

    5.5 删除排序链表中的重复元素 II（LeetCode 82）⭐⭐¶

    题目：删除所有重复的元素，只保留不重复的

    def deleteDuplicatesII(head: ListNode) -> ListNode:
    """
    思路：使用虚拟头结点，遇到重复元素全部跳过
    """
    if not head:
        return head

    dummy = ListNode(0, head)
    cur = dummy

    while cur.next and cur.next.next:
        if cur.next.val == cur.next.next.val:
            # 记录重复值
            val = cur.next.val
            # 跳过所有值为 val 的结点
            while cur.next and cur.next.val == val:
                cur.next = cur.next.next
        else:
            cur = cur.next

    return dummy.next

    5.6 合并 K 个有序链表（LeetCode 23）⭐⭐⭐¶

    题目：合并 k 个升序链表

    解法一：分治法（推荐）

    def mergeKLists(lists: List[ListNode]) -> ListNode:
    """
    分治法：两两合并，时间复杂度 O(N log k)
    N 为所有结点总数，k 为链表数量
    """
    if not lists:
        return None

    def merge(l1, l2):
        """合并两个有序链表"""
        dummy = ListNode(0)
        cur = dummy
        while l1 and l2:
            if l1.val <= l2.val:
                cur.next = l1
                l1 = l1.next
            else:
                cur.next = l2
                l2 = l2.next
            cur = cur.next
        cur.next = l1 if l1 else l2
        return dummy.next

    def divide(left, right):
        """分治"""
        if left == right:
            return lists[left]
        if left > right:
            return None

        mid = (left + right) // 2
        return merge(divide(left, mid), divide(mid + 1, right))

    return divide(0, len(lists) - 1)

    解法二：最小堆

    import heapq

def mergeKListsHeap(lists: List[ListNode]) -> ListNode:
    """
    最小堆：维护 k 个链表当前最小值，时间复杂度 O(N log k)
    """
    if not lists:
        return None

    # 最小堆：(val, index, node)
    heap = []
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))

    dummy = ListNode(0)
    cur = dummy

    while heap:
        val, idx, node = heapq.heappop(heap)
        cur.next = node
        cur = cur.next

        if node.next:
            heapq.heappush(heap, (node.next.val, idx, node.next))

    return dummy.next

    5.7 环形链表 II（LeetCode 142）⭐⭐¶

    题目：找到环的入口结点

    def detectCycle(head: ListNode) -> ListNode:
    """
    快慢指针法，时间复杂度 O(n)，空间复杂度 O(1)
    """
    if not head or not head.next:
        return None

    slow = fast = head

    # 第一步：判断是否有环
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            break
    else:
        return None  # 无环

    # 第二步：找环入口
    ptr = head
    while ptr != slow:
        ptr = ptr.next
        slow = slow.next

    return ptr

    5.8 相交链表（LeetCode 160）⭐⭐¶

    题目：找到两个单链表相交的起始结点

    def getIntersectionNode(headA: ListNode, headB: ListNode) -> ListNode:
    """
    双指针法：A 走完走 B，B 走完走 A，相遇点即为交点
    时间复杂度 O(m+n)，空间复杂度 O(1)
    """
    if not headA or not headB:
        return None

    pA, pB = headA, headB

    while pA != pB:
        pA = pA.next if pA else headB
        pB = pB.next if pB else headA

    return pA  # 相交则返回交点，不相交则返回 None

    原理： 

    设：A 链表长度 = a，B 链表长度 = b，公共部分长度 = c

pA 路程：a + (b - c)
pB 路程：b + (a - c)

两者相等，会在交点相遇

若不相交：pA 和 pB 同时走到 None，返回 None

    5.9 删除链表的倒数第 N 个结点（LeetCode 19）⭐⭐¶

    题目：删除倒数第 n 个结点

    def removeNthFromEnd(head: ListNode, n: int) -> ListNode:
    """
    快慢指针：快指针先走 n 步，然后同时走
    时间复杂度 O(n)，空间复杂度 O(1)
    """
    dummy = ListNode(0, head)
    fast = slow = dummy

    # 快指针先走 n 步
    for _ in range(n):
        fast = fast.next

    # 同时走，直到快指针到达末尾
    while fast.next:
        fast = fast.next
        slow = slow.next

    # slow 指向倒数第 n+1 个结点
    slow.next = slow.next.next

    return dummy.next

# 测试：1→2→3→4→5, n=2
# 结果：1→2→3→5

    5.10 回文链表（LeetCode 234）⭐⭐¶

    题目：判断链表是否为回文结构

    def isPalindrome(head: ListNode) -> bool:
    """
    思路：找中点 → 反转后半部分 → 比较 → 恢复（可选）
    时间复杂度 O(n)，空间复杂度 O(1)
    """
    if not head or not head.next:
        return True

    # 1. 找中点
    slow = fast = head
    while fast.next and fast.next.next:
        slow = slow.next
        fast = fast.next.next

    # 2. 反转后半部分
    second_half = slow.next
    slow.next = None  # 断开

    prev = None
    cur = second_half
    while cur:
        next_temp = cur.next
        cur.next = prev
        prev = cur
        cur = next_temp

    # 3. 比较两部分
    p1, p2 = head, prev
    result = True
    while p2:
        if p1.val != p2.val:
            result = False
            break
        p1 = p1.next
        p2 = p2.next

    # 4. 恢复链表（可选）
    # ...

    return result

    6. 链表题型分类总结¶

    6.1 按技巧分类¶

    技巧 适用题型 代表题目
    虚拟头结点 涉及头结点操作 删除结点、合并链表
    快慢指针 找中点、判环 环形链表、回文链表
    双指针 相交、删除倒数第 N 相交链表
    反转链表 区间反转、K 组反转 反转链表 II
    归并思想 合并有序链表 合并 K 个有序链表
    头插法 区间翻转 反转链表 II
    尾插法 保持顺序的构建 分割链表

    6.2 按难度分类¶

    ⭐ 基础题： - 反转链表 - 合并两个有序链表 - 删除排序链表中的重复元素

    ⭐⭐ 进阶题： - 删除倒数第 N 个结点 - 环形链表 II - 相交链表 - 两两交换结点 - 回文链表

    ⭐⭐⭐ 难题： - 合并 K 个有序链表 - K 个一组翻转链表 - LRU 缓存（链表 + 哈希表）

    7. 总结¶

    7.1 链表 vs 数组¶

    特性 数组 链表
    存储方式 连续内存 非连续内存
    随机访问 O(1) O(n)
    插入/删除 O(n) O(1)*
    空间效率 高 低（指针开销）
    缓存友好 是 否

    *需要先找到位置

    7.2 核心思想¶

    1. 指针操作是链表的核心
    2. 虚拟头结点简化边界处理
    3. 快慢指针解决中点、环问题
    4. 画图辅助理解指针变化
    5. 注意空指针和边界条件

    7.3 易错点¶

    • 忘记更新 next 指针导致断链
    • 忘记处理空链表
    • 反转后未连接后续链表
    • 成环问题（忘记将尾结点 next 置空）
    • 修改了原链表结构但未恢复

    关键思想：链表题目的本质是指针操作，画图 + 虚拟头结点 + 快慢指针，掌握这三招，链表题目不再难！🔗
