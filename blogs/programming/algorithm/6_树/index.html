    1. 树的基础¶

    1.1 知识点¶

    树（Tree）是一种非线性的层次数据结构，由 n（n≥0）个有限节点组成。与数组、链表的"一条线"不同，树是"一层一层"的结构，天然适合表达具有从属关系的数据——文件系统、组织架构、DOM、表达式树都是树。理解树先记住四个角色： - 根节点（Root）：没有父节点的节点，整棵树的入口 - 叶子节点（Leaf）：没有子节点的节点 - 边（Edge）：连接两个节点的线段 - 路径（Path）：从一个节点到另一个节点的边序列

    除根以外每个节点有且只有一个父节点，所以 n 个节点的树恰好有 n-1 条边——这是树题里最常用的隐含条件。

    1.2 结构示意图与术语¶

            A       ← 根节点 (Root)
       / \
      B   C     ← 内部节点
     / \   \
    D   E   F   ← 叶子节点 (Leaf)

    A 是 B、C 的父节点
    B、C 是 A 的子节点
    D、E 是兄弟节点
    术语 说明
    节点的度 节点拥有的子树个数
    树的度 树中所有节点的度的最大值
    节点的深度 从根到该节点的边数
    节点的高度 从该节点到叶子节点的最长路径边数
    树的高度 根节点的高度

    ⚠️ 易错点：深度与高度方向相反，且定义口径不统一

    深度从上往下数（起点是根），高度从下往上数（终点是叶子），两者方向正好相反。更麻烦的是不同教材起点口径不同——有的从 0 开始数边数，有的从 1 开始数层数，公式会整体差一个 1（比如性质"深度为 k 的树最多有 2^k - 1 个节点"用的就是按层数、从 1 起算的口径）。

            A      ← 深度 0 / 高度 2（按边数口径）
       / \
      B   C
     /
    D          ← 深度 2 / 高度 0

    ❌ 面试直接报公式不声明口径，和面试官对不上。✅ 先说清"我按边数（或层数）定义"，再给结论。

    2. 二叉树（Binary Tree）¶

    2.1 知识点¶

    二叉树是每个节点最多有两个子节点（左子树、右子树）的树。"最多两个"不是限制而是简化：左右有序、分支有上限，递归结构变得极其规整——几乎所有树的面试题都默认在二叉树上讨论。三个要点： - 二叉树可以为空（空树也是合法的二叉树） - 子树有左右之分，即使只有一个孩子也要区分是左孩子还是右孩子 - 三种最常考的形态：满二叉树、完全二叉树、二叉搜索树

          1
     / \
    2   3
   / \   \
  4   5   6

    2.2 特殊二叉树¶

    类型 说明 示例
    满二叉树 所有非叶子节点都有 2 个子节点，所有叶子在同一层 完美三角形
    完全二叉树 除最后一层外，其他层都满，最后一层从左到右填充 堆
    二叉搜索树 左 < 根 < 右 有序查找 
    满二叉树：          完全二叉树：        二叉搜索树：
     1                   1                  4
    / \                 / \                / \
   2   3               2   3              2   6
  / \ / \             / \ /               / \ / \
 4  5 6  7           4  5 6              1  3 5  7

    ❌ 别把满二叉树和完全二叉树搞混：满二叉树要求一层不缺；完全二叉树只要求最后一层从左往右连续填充，右边可以缺——堆就是用数组存完全二叉树，正是因为这个"连续"性质才能按下标定位父子。

    2.3 二叉树的重要性质¶

    1. 第 i 层最多有 2^(i-1) 个节点（i≥1）
    2. 深度为 k 的树最多有 2^k - 1 个节点
    3. 叶子节点数 = 度为 2 的节点数 + 1
    4. 完全二叉树深度 = ⌊log₂n⌋ + 1

    这四条是面试估算复杂度的依据：性质 4 直接解释了为什么平衡的二叉树操作都是 O(log n)——树高就是 log n 级别。

    3. 二叉树的实现¶

    3.1 知识点¶

    二叉树通常用链式结构存储：每个节点是一个对象，持有值和左右孩子指针，节点在内存中不连续，靠指针串联。 - 为什么不像数组那样连续存？普通二叉树形状任意，数组存储会留大量空洞；只有完全二叉树（如堆，见第 6 节）才适合按下标紧凑存储 - 所有树的算法题，入口都是拿到根节点 root，然后递归或迭代往下走

    3.2 节点定义¶

    class TreeNode:
    """二叉树节点"""
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


# 创建示例树
#       1
#      / \
#     2   3
#    / \   \
#   4   5   6

root = TreeNode(1)
root.left = TreeNode(2, TreeNode(4), TreeNode(5))
root.right = TreeNode(3, None, TreeNode(6))

    3.3 从层序数组构建二叉树¶

    LeetCode 给出的测试用例都是层序数组（如 [1, 2, 3, None, 4, 5, 6]），用队列逐层挂孩子即可还原：

    from typing import List, Optional
from collections import deque

class BinaryTree:
    """二叉树类"""

    def __init__(self):
        self.root = None

    def build_from_level_order(self, values: List[Optional[int]]):
        r"""
        从层序遍历数组构建二叉树

        示例：[1, 2, 3, None, 4, 5, 6]
             1
            / \
           2   3
            \ / \
            4 5  6
        """
        if not values:
            return None

        self.root = TreeNode(values[0])
        queue = deque([self.root])
        i = 1

        while queue and i < len(values):
            node = queue.popleft()

            # 左子节点
            if i < len(values) and values[i] is not None:
                node.left = TreeNode(values[i])
                queue.append(node.left)
            i += 1

            # 右子节点
            if i < len(values) and values[i] is not None:
                node.right = TreeNode(values[i])
                queue.append(node.right)
            i += 1

        return self.root

    def level_order(self) -> List[List[int]]:
        """层序遍历"""
        if not self.root:
            return []

        result = []
        queue = deque([self.root])

        while queue:
            level_size = len(queue)
            level = []

            for _ in range(level_size):
                node = queue.popleft()
                level.append(node.val)

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

            result.append(level)

        return result


# 使用示例
tree = BinaryTree()
tree.build_from_level_order([1, 2, 3, None, 4, 5, 6])
print(tree.level_order())  # [[1], [2, 3], [4, 5, 6]]

    ⚠️ 易错点：None 占位也必须消耗下标

    层序数组里的 None 表示"这个位置没有节点"，但它占了一个位置。构建时无论当前值是不是 None，下标 i 都要 +1，否则后面所有节点全部错位：

    # ❌ 错误：只在创建出节点时才移动下标
if i < len(values) and values[i] is not None:
    node.left = TreeNode(values[i])
    queue.append(node.left)
    i += 1            # None 时不移动 → 后续值整体错位

# ✅ 正确：占位无条件消耗（上面完整实现采用的写法）
if i < len(values) and values[i] is not None:
    node.left = TreeNode(values[i])
    queue.append(node.left)
i += 1                # 无论是否为 None 都要移动

    4. 树的遍历 ⭐⭐⭐¶

    4.1 知识点¶

    树的遍历分两大流派，所有树题的骨架都出自这里： - 深度优先 DFS：一条路走到黑再回头。按"访问根节点的时机"分三种——前序（进子树前访问根，适合复制/序列化）、中序（左右之间访问根，BST 上输出有序序列）、后序（子树都处理完再访问根，适合自底向上汇总：算高度、删树） - 广度优先 BFS：一层一层往下扫，用队列实现（层序遍历） - 递归是最自然的写法，三行搞定；面试常追问迭代版——用栈模拟递归。注意 Python 默认递归深度约 1000 层，遇到链状退化树会直接 RecursionError，此时必须能写迭代版

           1
      / \
     2   3
    / \   \
   4   5   6

    4.2 前序遍历（Preorder）：根 → 左 → 右¶

    def preorder_recursive(root: Optional[TreeNode]) -> List[int]:
    """前序遍历 - 递归"""
    result = []

    def dfs(node):
        if not node:
            return
        result.append(node.val)      # 根
        dfs(node.left)               # 左
        dfs(node.right)              # 右

    dfs(root)
    return result

# 结果：[1, 2, 4, 5, 3, 6]


def preorder_iterative(root: Optional[TreeNode]) -> List[int]:
    """前序遍历 - 迭代（栈）"""
    if not root:
        return []

    result = []
    stack = [root]

    while stack:
        node = stack.pop()
        result.append(node.val)

        # 先右后左（栈是 LIFO）
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)

    return result

# 结果：[1, 2, 4, 5, 3, 6]

    ⚠️ 易错点：迭代前序入栈顺序——先右后左

    栈是 LIFO（后进先出），想让左子树先出栈，就必须右孩子先入栈。顺序写反，遍历结果会变成"根右左"：

    # ❌ 先压左再压右 → 左孩子后出栈，顺序变成"根右左"
stack.append(node.left)
stack.append(node.right)

# ✅ 先压右再压左 → 弹出顺序才是"根左右"
if node.right:
    stack.append(node.right)
if node.left:
    stack.append(node.left)

    4.3 中序遍历（Inorder）：左 → 根 → 右¶

    def inorder_recursive(root: Optional[TreeNode]) -> List[int]:
    """中序遍历 - 递归"""
    result = []

    def dfs(node):
        if not node:
            return
        dfs(node.left)               # 左
        result.append(node.val)      # 根
        dfs(node.right)              # 右

    dfs(root)
    return result

# 结果：[4, 2, 5, 1, 3, 6]


def inorder_iterative(root: Optional[TreeNode]) -> List[int]:
    """中序遍历 - 迭代（栈）"""
    result = []
    stack = []
    current = root

    while current or stack:
        # 一直向左
        while current:
            stack.append(current)
            current = current.left

        # 弹出栈顶
        current = stack.pop()
        result.append(current.val)

        # 转向右子树
        current = current.right

    return result

# 结果：[4, 2, 5, 1, 3, 6]

    4.4 后序遍历（Postorder）：左 → 右 → 根¶

    def postorder_recursive(root: Optional[TreeNode]) -> List[int]:
    """后序遍历 - 递归"""
    result = []

    def dfs(node):
        if not node:
            return
        dfs(node.left)               # 左
        dfs(node.right)              # 右
        result.append(node.val)      # 根

    dfs(root)
    return result

# 结果：[4, 5, 2, 6, 3, 1]


def postorder_iterative(root: Optional[TreeNode]) -> List[int]:
    """后序遍历 - 迭代（双栈）"""
    if not root:
        return []

    stack1 = [root]
    stack2 = []
    result = []

    while stack1:
        node = stack1.pop()
        stack2.append(node)

        if node.left:
            stack1.append(node.left)
        if node.right:
            stack1.append(node.right)

    while stack2:
        result.append(stack2.pop().val)

    return result

# 结果：[4, 5, 2, 6, 3, 1]

    4.5 层序遍历（BFS）¶

    def level_order(root: Optional[TreeNode]) -> List[List[int]]:
    """
    层序遍历
    LeetCode 102
    """
    if not root:
        return []

    result = []
    queue = deque([root])

    while queue:
        level_size = len(queue)
        level = []

        for _ in range(level_size):
            node = queue.popleft()
            level.append(node.val)

            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

        result.append(level)

    return result

# 结果：[[1], [2, 3], [4, 5, 6]]

    关键点：进入每一层时先用 level_size = len(queue) 固定本层节点数，for 循环只处理这么多——之后新入队的都是下一层的。这个模板可以直接套出"每层最大值""右视图""锯齿遍历"等一大片题。

    4.6 遍历方式对比¶

    遍历方式 顺序 应用场景
    前序 根左右 复制树、序列化
    中序 左根右 BST 获取有序序列
    后序 左右根 计算树高、删除树
    层序 从上到下 BFS、层级处理

    5. 二叉搜索树（BST）⭐⭐¶

    5.1 知识点¶

    二叉搜索树（BST）是带了排序约束的二叉树：左子树所有节点 < 根节点 < 右子树所有节点，且左右子树本身也是 BST。这个约束带来两个核心收益： - 查找像二分：每次比较都能砍掉一半子树，平均时间 O(log n) - 中序遍历天然有序：BST 的中序结果一定是严格递增序列，这是大量 BST 题的突破口

    代价是形态敏感：同样的值，插入顺序不同，树高可以从 log n 一路退化到 n（见 5.2 易错点）。

          4
     / \
    2   6
   / \ / \
  1  3 5  7

    5.2 BST 操作实现¶

    class BST:
    """二叉搜索树"""

    def __init__(self):
        self.root = None

    def search(self, val: int) -> Optional[TreeNode]:
        """查找"""
        current = self.root
        while current:
            if val == current.val:
                return current
            elif val < current.val:
                current = current.left
            else:
                current = current.right
        return None

    def insert(self, val: int):
        """插入"""
        if not self.root:
            self.root = TreeNode(val)
            return

        current = self.root
        while True:
            if val < current.val:
                if not current.left:
                    current.left = TreeNode(val)
                    break
                current = current.left
            else:
                if not current.right:
                    current.right = TreeNode(val)
                    break
                current = current.right

    def delete(self, val: int):
        """删除（LeetCode 450）"""
        self.root = self._delete_node(self.root, val)

    def _delete_node(self, node: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        if not node:
            return None

        if val < node.val:
            node.left = self._delete_node(node.left, val)
        elif val > node.val:
            node.right = self._delete_node(node.right, val)
        else:
            # 找到要删除的节点
            if not node.left:
                return node.right
            if not node.right:
                return node.left

            # 有两个子节点：找右子树最小值
            min_node = self._find_min(node.right)
            node.val = min_node.val
            node.right = self._delete_node(node.right, min_node.val)

        return node

    def _find_min(self, node: TreeNode) -> TreeNode:
        while node.left:
            node = node.left
        return node

    def inorder(self) -> List[int]:
        """中序遍历（得到有序序列）"""
        result = []

        def dfs(node):
            if not node:
                return
            dfs(node.left)
            result.append(node.val)
            dfs(node.right)

        dfs(self.root)
        return result


# 使用示例
bst = BST()
for val in [4, 2, 6, 1, 3, 5, 7]:
    bst.insert(val)

print(bst.search(5))      # TreeNode(5)
print(bst.inorder())      # [1, 2, 3, 4, 5, 6, 7]
bst.delete(4)
print(bst.inorder())      # [1, 2, 3, 5, 6, 7]

    删除是最难的操作，分三种情况：没有左孩子就用右孩子顶上；没有右孩子就用左孩子顶上；两个孩子都有时，用右子树的最小值（中序后继）替换当前节点值，再递归删掉那个最小值。

    ⚠️ 易错点：有序序列插入会让 BST 退化成链表

    BST 的一切复杂度都建立在"树比较平衡"上。如果按已经有序的顺序插入（如 [1, 2, 3, 4, 5]），每个新节点都只能挂在最右链上，树退化成链表，查找/插入全部变成 O(n)：

    插入 1, 2, 3, 4, 5：

1
 \
  2
   \
    3        ← 高度 n-1，退化为链表
     \
      4
       \
        5

    ❌ 只答"BST 增删查都是 O(log n)"——那是平均值。✅ 面试要补一句："最坏情况退化为 O(n)，工程中用自平衡树（AVL 树、红黑树）保证 O(log n)"。

    6. 堆（Heap）⭐⭐¶

    6.1 知识点¶

    堆（Heap）是一种用数组存储的完全二叉树，并满足堆序性： - 大顶堆：父节点 ≥ 子节点（堆顶最大） - 小顶堆：父节点 ≤ 子节点（堆顶最小）

    堆的精髓在于下标关系：节点 i 的左孩子是 2i+1、右孩子是 2i+2、父节点是 (i-1)//2——不用指针就能在数组上玩树。插入靠上浮、删除堆顶靠下沉，都是 O(log n)；从数组建堆只要 O(n)。堆是优先队列的标准实现，也是"Top K / 动态取最值"问题的首选工具。

    大顶堆：              小顶堆：
     9                    1
    / \                  / \
   7   8                3   2
  / \                  / \
 5   6                5   4

    6.2 Python heapq 使用¶

    import heapq

# 小顶堆（默认）
heap = []
heapq.heappush(heap, 3)
heapq.heappush(heap, 1)
heapq.heappush(heap, 2)
print(heapq.heappop(heap))  # 1（最小）

# 大顶堆（取反）
max_heap = []
heapq.heappush(max_heap, -3)
heapq.heappush(max_heap, -1)
heapq.heappush(max_heap, -2)
print(-heapq.heappop(max_heap))  # 3（最大）

# 前 K 个元素
nums = [1, 3, 5, 2, 4, 6]
top3 = heapq.nlargest(3, nums)  # [6, 5, 4]
bottom3 = heapq.nsmallest(3, nums)  # [1, 2, 3]

    ⚠️ 易错点：heapq 只有小顶堆，heap[0] 永远是最小值

    Python 的 heapq 只提供小顶堆实现。想要大顶堆必须存入时取负、取出时再取负回来，直接读 heap[0] 拿"最大值"是高频错误：

    import heapq

nums = [3, 1, 2]
heap = list(nums)
heapq.heapify(heap)

print(heap[0])   # ❌ 想拿最大值？实际是 1（最小值）

# ✅ 大顶堆的正确姿势：全程取负
max_heap = [-x for x in nums]
heapq.heapify(max_heap)
print(-max_heap[0])  # 3（最大值）

    另外：想按自定义字段比较（如元组的第二个值），直接压入元组即可，heapq 会逐元素比较：heapq.heappush(h, (priority, item))。

    6.3 手写小顶堆¶

    面试手写堆只需要记住两个动作：上浮 sift_up（新元素和父节点比，小就交换）和下沉 sift_down（堆顶和较小的孩子比，大就交换）：

    class MinHeap:
    """小顶堆"""

    def __init__(self):
        self.heap = []

    def push(self, val: int):
        """插入"""
        self.heap.append(val)
        self._sift_up(len(self.heap) - 1)

    def pop(self) -> int:
        """弹出最小值"""
        if not self.heap:
            raise IndexError("Heap is empty")

        result = self.heap[0]
        last = self.heap.pop()

        if self.heap:
            self.heap[0] = last
            self._sift_down(0)

        return result

    def _sift_up(self, index: int):
        """上浮"""
        while index > 0:
            parent = (index - 1) // 2
            if self.heap[index] < self.heap[parent]:
                self.heap[index], self.heap[parent] = self.heap[parent], self.heap[index]
                index = parent
            else:
                break

    def _sift_down(self, index: int):
        """下沉"""
        n = len(self.heap)
        while True:
            smallest = index
            left = 2 * index + 1
            right = 2 * index + 2

            if left < n and self.heap[left] < self.heap[smallest]:
                smallest = left
            if right < n and self.heap[right] < self.heap[smallest]:
                smallest = right

            if smallest != index:
                self.heap[index], self.heap[smallest] = self.heap[smallest], self.heap[index]
                index = smallest
            else:
                break

    def min(self) -> int:
        if not self.heap:
            raise IndexError("Heap is empty")
        return self.heap[0]

    def __len__(self):
        return len(self.heap)

    7. 经典算法题¶

    7.1 二叉树的最大深度（LeetCode 104）✅¶

    经典入门题，正好把 DFS 和 BFS 两种思路都练一遍：DFS 递归"当前深度 = 1 + 左右子树深度的较大值"；BFS 则数一共有多少层。

    def maxDepth(root: Optional[TreeNode]) -> int:
    """
    LeetCode 104：二叉树的最大深度

    方法 1：DFS 递归
    """
    if not root:
        return 0
    return 1 + max(maxDepth(root.left), maxDepth(root.right))


def maxDepth_bfs(root: Optional[TreeNode]) -> int:
    """方法 2：BFS 层序遍历"""
    if not root:
        return 0

    depth = 0
    queue = deque([root])

    while queue:
        depth += 1
        for _ in range(len(queue)):
            node = queue.popleft()
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

    return depth

    7.2 验证二叉搜索树（LeetCode 98）✅⭐¶

    题目：判断一棵二叉树是否是合法的 BST。

    BST 的核心性质：对任意节点，其左子树中所有节点的值都 严格小于 它，右子树中所有节点的值都 严格大于 它。

    ⚠️ 常见错误：只比较当前节点和直接子节点 ❌

    很多初学者会这样写：

    # ❌ 错误写法：只比较了当前节点和直接子节点
def isValidBST_wrong(root):
    if not root:
        return True
    if root.left and root.left.val >= root.val:
        return False
    if root.right and root.right.val <= root.val:
        return False
    return isValidBST_wrong(root.left) and isValidBST_wrong(root.right)

    这棵"假 BST"会骗过上面的代码：

          5
     / \
    4   6
       / \
      2   7     ← 2 < 5，但 2 在 5 的右子树里！不合法！

    问题本质：BST 要求的是整棵子树满足大小关系，不是只和直接父节点比。节点 2 虽然小于它的直接父节点 6，但它位于根节点 5 的右子树中，必须满足 > 5，矛盾！

    正确思路：传递上下界¶

    递归时把当前节点允许的值域范围 (lo, hi) 传下去：

    • 往左走：上界收紧为当前节点值 → check(left, lo, node.val)
    • 往右走：下界收紧为当前节点值 → check(right, node.val, hi)
          5          范围 (-∞, +∞)
     / \
    4   6        4 的范围 (-∞, 5)  |  6 的范围 (5, +∞)
       / \
      2   7      2 的范围 (5, 6) → 2 < 5 → 不合法！❌

    解法一：递归传递上下界（推荐）¶

    def isValidBST(root: Optional[TreeNode]) -> bool:
    """
    LeetCode 98：验证二叉搜索树

    方法 1：递归传递上下界
    时间 O(n)，空间 O(h)（h 为树高，递归栈深度）
    """
    def check(node, lo, hi):
        if not node:
            return True
        # 当前节点必须在 (lo, hi) 开区间内
        if not (lo < node.val < hi):
            return False
        # 左子树：上界收紧为 node.val
        # 右子树：下界收紧为 node.val
        return check(node.left, lo, node.val) and \
               check(node.right, node.val, hi)

    return check(root, float('-inf'), float('inf'))

    解法二：中序遍历（更直观）¶

    BST 的中序遍历结果一定是严格递增的序列，利用这个性质可以直接判断：

    def isValidBST_inorder(root: Optional[TreeNode]) -> bool:
    """
    方法 2：中序遍历，检查是否严格递增

    中序遍历顺序：左 → 根 → 右
    BST 中序遍历结果一定是递增的
    """
    prev = float('-inf')  # 记录上一个访问的节点值

    def dfs(node):
        nonlocal prev
        if not node:
            return True

        # 先检查左子树
        if not dfs(node.left):
            return False

        # 检查当前节点是否大于前一个
        if node.val <= prev:
            return False
        prev = node.val

        # 再检查右子树
        return dfs(node.right)

    return dfs(root)

    两种解法对比¶

    方法 时间 空间 特点
    上下界递归 O(n) O(h) 一次遍历，最常用
    中序遍历 O(n) O(h) 更直观，利用 BST 性质

    💡 面试技巧：两种方法都能写的话，优先写上下界法，然后提一句"也可以用中序遍历"，展示你理解全面。

    7.3 二叉树的中序后继（Inorder Successor）⭐⭐¶

    题目：给定二叉树中的任意一个节点，找到它在中序遍历中的下一个节点（后继节点）。

    节点结构包含 parent 指针（双向链表型节点）。

    理解"中序后继"¶

    先回顾中序遍历的顺序：左 → 根 → 右

            20
       /  \
      10   30
     /  \     \
    5   15    35
   / \
  3   7

中序遍历：3 → 5 → 7 → 10 → 15 → 20 → 30 → 35

    各节点的后继： - 3 的后继是 5（父节点） - 5 的后继是 7（右子树最左） - 7 的后继是 10（向上找祖先） - 15 的后继是 20（向上找祖先） - 35 的后继是 None（最后一个节点，没有后继）

    分两种情况分析¶

    情况一：节点有右子树

        5               节点 5 有右子树
     \
      8
     /
    6               后继 = 右子树中最左边的节点 = 6
     \
      7

    为什么？ 中序遍历是"左→根→右"，当前节点访问完后，下一个就是右子树里的第一个节点（最左边的节点）。

    情况二：节点没有右子树

            20
       /  \
      10   30
     /  \
    5   15        ← 节点 15 没有右子树

中序遍历：5 → 10 → 15 → 20 → 30

    为什么？ 没有右子树意味着"右子树里没有下一个节点"，那后继只能在祖先中。

    怎么找？ 沿 parent 指针向上走，找到第一个满足"当前节点在它左子树中"的祖先。

    判断方法：如果 curr == curr.parent.right，说明 curr 是从右子树上来的，继续往上找；否则就是从左子树上来的，找到了！

    15 → parent 是 10，15 == 10.right → 从右边来的，继续上
10 → parent 是 20，10 == 20.left  → 从左边来的！后继就是 20 ✅

    代码实现¶

    class TreeNodeWithParent:
    """带 parent 指针的节点"""
    def __init__(self, val=0, left=None, right=None, parent=None):
        self.val = val
        self.left = left
        self.right = right
        self.parent = parent


def inorderSuccessor(node: 'TreeNodeWithParent') -> 'TreeNodeWithParent':
    """
    二叉树任意节点的中序后继

    时间 O(h)，空间 O(1)
    h 为树的高度
    """
    if not node:
        return None

    # 情况一：有右子树 → 右子树的最左节点
    if node.right:
        curr = node.right
        while curr.left:
            curr = curr.left
        return curr

    # 情况二：无右子树 → 向上找第一个"从左子树上来"的祖先
    curr = node
    while curr.parent:
        # 如果当前节点是父节点的左孩子 → 父节点就是后继
        if curr == curr.parent.left:
            return curr.parent
        # 否则继续向上
        curr = curr.parent

    # 走到了根节点的父节点（None）→ 说明是最后一个节点，没有后继
    return None

    图解完整流程¶

            20
       /  \
      10   30
     /  \     \
    5   15    35

求节点 15 的后继：
  ① 15 没有右子树 → 走情况二
  ② curr = 15, curr.parent = 10
     15 == 10.right → 从右边来的，继续上
  ③ curr = 10, curr.parent = 20
     10 == 20.left  → 从左边来的！
  ④ 返回 20 ✅

求节点 5 的后继：
  ① 5 有右子树（7）→ 走情况一
  ② 右子树最左节点 = 7
  ③ 返回 7 ✅

求节点 35 的后继：
  ① 35 没有右子树 → 走情况二
  ② 35 → 30（35 == 30.right，继续上）
  ③ 30 → 20（30 == 20.right，继续上）
  ④ 20.parent = None → 退出循环
  ⑤ 返回 None ✅（35 是最后一个节点）

    进阶：如果节点没有 parent 指针？¶

    如果只有普通的 TreeNode（没有 parent），可以利用 BST 性质从根往下二分查找：

    def inorderSuccessor_no_parent(root: TreeNode, p: TreeNode) -> TreeNode:
    """
    没有 parent 指针时的解法

    方法：中序遍历，找到第一个值大于 p.val 的节点
    """
    result = None
    curr = root

    while curr:
        if curr.val > p.val:
            result = curr      # 可能是后继，先记下来
            curr = curr.left   # 继续往左找更小的候选
        else:
            curr = curr.right  # 当前节点不够大，往右找

    return result

    💡 面试技巧：先问面试官"节点有没有 parent 指针"，这决定了最优解法。两种都会的话，展示两种思路加分很多。

    7.4 对称二叉树（LeetCode 101）✅¶

    思路：不是比较"左右子树是否相同"，而是镜像地同时遍历两棵子树——t1 的左对 t2 的右、t1 的右对 t2 的左。

    def isSymmetric(root: Optional[TreeNode]) -> bool:
    """
    LeetCode 101：对称二叉树
    """
    def is_mirror(t1, t2):
        if not t1 and not t2:
            return True
        if not t1 or not t2:
            return False
        return (t1.val == t2.val and
                is_mirror(t1.left, t2.right) and
                is_mirror(t1.right, t2.left))

    return is_mirror(root, root)

    7.5 路径总和（LeetCode 112）✅¶

    思路：每往下一层就把 targetSum 减去当前节点值，到达叶子时检查剩余值是否恰好等于叶子值——注意必须走到叶子才算一条完整路径。

    def hasPathSum(root: Optional[TreeNode], targetSum: int) -> bool:
    """
    LeetCode 112：路径总和
    """
    if not root:
        return False

    if not root.left and not root.right:
        return targetSum == root.val

    return (hasPathSum(root.left, targetSum - root.val) or
            hasPathSum(root.right, targetSum - root.val))

    7.6 二叉树的最近公共祖先（LeetCode 236）✅⭐¶

    思路：后序遍历（自底向上）。如果当前节点就是 p 或 q，直接上报；左右子树各递归找一次——左右都找到了，说明 p、q 分居两侧，当前节点就是 LCA；只有一侧找到就把那一侧的结果继续往上传。

    def lowestCommonAncestor(root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
    """
    LeetCode 236：二叉树的最近公共祖先
    """
    if not root or root == p or root == q:
        return root

    left = lowestCommonAncestor(root.left, p, q)
    right = lowestCommonAncestor(root.right, p, q)

    if left and right:
        return root
    return left if left else right

    8. 本章小结¶

    核心知识点¶

    ✅ 树的基本概念：根、叶子、深度、高度；n 个节点恰好 n-1 条边
    ✅ 特殊二叉树：满二叉树、完全二叉树（堆的形态）、二叉搜索树
    ✅ 二叉树性质：第 i 层最多 2^(i-1) 个节点；叶子数 = 度 2 节点数 + 1
    ✅ 树的遍历：前序、中序、后序（DFS）+ 层序（BFS）
    ✅ 递归遍历三行模板；迭代遍历用栈模拟（前序先压右后压左）
    ✅ BFS 模板：队列 + 每轮记录 level_size
    ✅ 二叉搜索树：左 < 根 < 右，中序有序；增删查平均 O(log n)、最坏 O(n)
    ✅ 验证 BST：传上下界或中序判严格递增，只比直接子节点必错
    ✅ 堆：大顶堆、小顶堆，heapq 默认小顶堆、取负实现大顶堆，优先队列的基础
    ✅ 中序后继 / 最近公共祖先：树形结构中的经典定位问题

    时间复杂度¶

    操作 普通树 BST（平均） BST（最坏）
    查找 O(n) O(log n) O(n)
    插入 O(n) O(log n) O(n)
    删除 O(n) O(log n) O(n)

    最佳实践¶

    1. 遍历是树的通用语言：先判断题目要"自顶向下传信息"（前序）还是"自底向上汇总"（后序），再套递归框架
    2. 看到 BST 先想中序遍历：验证、第 K 小、后继前驱等题几乎都从"中序严格递增"这一性质切入
    3. 迭代遍历用栈模拟：前序先压右后压左；中序"一路向左压栈"；后序可用双栈；树可能退化成链时优先写迭代版，避免递归爆栈
    4. 层序题套模板：队列 + 每轮固定 level_size，需要层级信息时按层收集结果
    5. Top K / 动态取最值 → 堆：求最大的 K 个用小顶堆，求最小的 K 个用大顶堆（heapq 记得取负）
