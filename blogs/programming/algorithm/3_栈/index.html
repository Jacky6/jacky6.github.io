    1. 栈基础¶

    1.1 知识点¶

    栈（Stack）是一种后进先出（LIFO - Last In First Out）的线性数据结构，就像一摞盘子——最后放上去的盘子最先被拿走。 - 只允许在一端进行插入和删除操作 - 允许操作的一端称为栈顶（Top） - 另一端称为栈底（Bottom） - 不含元素的空表称为空栈

        ↑ 栈顶 (Top)
    │
┌───┐
│ C │  ← 最后压入，最先弹出
├───┤
│ B │
├───┤
│ A │  ← 最先压入，最后弹出
└───┘
    │
    ↓ 栈底 (Bottom)

    为什么要限制成"只能动栈顶"？正是这个限制让栈天然具备记忆顺序与撤销的能力——最近压入的元素总是最先被弹出，所以括号嵌套、函数调用、撤销操作、深度优先搜索这些"后来者先处理"的场景全都靠它。语言层面：Python 直接用 list（append/pop 末尾操作均为 O(1)）；Java 推荐 ArrayDeque（老的 java.util.Stack 带同步锁，已不推荐）；C++ 用 std::stack。

    1.2 基本操作¶

    操作 描述 时间复杂度
    push(x) 将元素 x 压入栈顶 O(1)
    pop() 弹出栈顶元素 O(1)
    top() / peek() 返回栈顶元素（不弹出） O(1)
    isEmpty() 判断栈是否为空 O(1)
    size() 返回栈中元素个数 O(1)

    2. 栈的实现¶

    2.1 知识点¶

    栈的两种实现方式接口完全相同，差别在内部结构： - 数组栈（顺序栈）：用动态数组的末尾当栈顶。push/pop 均摊 O(1)，连续内存缓存友好；固定容量版本要防上溢（Stack overflow），动态扩容版本（如 Python list）自动处理。 - 链表栈（链式栈）：用单链表的头节点当栈顶。push/pop 是严格 O(1)，永不扩容；代价是每个节点多一个指针的空间，且内存不连续、缓存不友好。 - 怎么选：刷题面试直接用 Python list；手写实现题数组版更简单；容量波动极大、想彻底避免扩容拷贝时才考虑链表版。

    2.2 数组实现（顺序栈）¶

    class ArrayStack:
    def __init__(self, capacity=100):
        self.data = []
        self.capacity = capacity

    def push(self, x):
        if len(self.data) >= self.capacity:
            raise Exception("Stack overflow")
        self.data.append(x)

    def pop(self):
        if self.is_empty():
            raise Exception("Stack underflow")
        return self.data.pop()

    def top(self):
        if self.is_empty():
            raise Exception("Stack is empty")
        return self.data[-1]

    def is_empty(self):
        return len(self.data) == 0

    def size(self):
        return len(self.data)

    2.3 链表实现（链式栈）¶

    class Node:
    def __init__(self, val):
        self.val = val
        self.next = None

class LinkedStack:
    def __init__(self):
        self.head = None
        self._size = 0

    def push(self, x):
        node = Node(x)
        node.next = self.head
        self.head = node
        self._size += 1

    def pop(self):
        if self.is_empty():
            raise Exception("Stack underflow")
        val = self.head.val
        self.head = self.head.next
        self._size -= 1
        return val

    def top(self):
        if self.is_empty():
            raise Exception("Stack is empty")
        return self.head.val

    def is_empty(self):
        return self.head is None

    def size(self):
        return self._size

    2.4 时间复杂度对比¶

    操作 数组实现 链表实现
    push O(1)* O(1)
    pop O(1) O(1)
    top O(1) O(1)
    空间 O(n) O(n)

    *数组实现动态扩容时摊还 O(1)

    2.5 ⚠️ 易错点：链式栈必须头插，尾插会让所有操作退化成 O(n)¶

    # ❌ 错误：尾插需要遍历到链表末尾，push 变 O(n)，top/pop 也一样退化
def push_wrong(self, x):
    node = Node(x)
    cur = self.head
    while cur and cur.next:
        cur = cur.next
    if cur:
        cur.next = node
    else:
        self.head = node

# ✅ 正确：头插法，push/pop/top 全部 O(1)
def push(self, x):
    node = Node(x)
    node.next = self.head
    self.head = node

    另外注意：固定容量的数组栈必须先判满再 push（上面 Stack overflow 检查不能省）；所有 pop/top 之前必须先判空，否则空栈操作直接抛异常。

    3. 括号匹配¶

    3.1 知识点¶

    括号匹配是栈最经典的应用，也是所有嵌套结构校验的模板题（LeetCode 20）： - 左括号入栈：遇到左括号直接压栈，表示"这里有一层还没闭合" - 右括号与栈顶匹配：遇到右括号，栈顶必须是它对应的左括号，否则嵌套顺序错误（如 ([)]） - 最终栈必须为空：栈非空说明还有左括号没闭合

    为什么不能用计数器？只有一种括号时计数就行；但多种括号时，嵌套必须满足"后开的先闭合"，这正是 LIFO 顺序，只有栈能天然表达。

    3.2 实现¶

    def isValid(s: str) -> bool:
    # 奇数长度直接返回 False
    if len(s) % 2 == 1:
        return False

    stack = []
    mapping = {')': '(', '}': '{', ']': '['}

    for char in s:
        if char in mapping:
            # 右括号：检查栈顶
            if not stack or stack.pop() != mapping[char]:
                return False
        else:
            # 左括号：入栈
            stack.append(char)

    return not stack

# 测试
print(isValid("()[]{}"))      # True
print(isValid("([)]"))        # False
print(isValid("{[]}"))        # True

    变体：

    • 生成有效括号组合（回溯 + 栈）
    • 最长有效括号子串（栈存索引）
    • 最少添加使括号有效

    3.3 ⚠️ 易错点：两个"忘记"导致漏判¶

    # ❌ 错误写法：两处漏洞
def isValid_wrong(s: str) -> bool:
    stack = []
    mapping = {')': '(', '}': '{', ']': '['}
    for ch in s:
        if ch in mapping:
            if stack.pop() != mapping[ch]:  # ❌ 漏洞1：空栈时遇右括号，直接 IndexError
                return False
        else:
            stack.append(ch)
    return True  # ❌ 漏洞2：遍历完不检查栈是否为空，"(" 会被判为 True

# ✅ 正确：弹栈前先判空，结束后检查栈空
def isValid_right(s: str) -> bool:
    stack = []
    mapping = {')': '(', '}': '{', ']': '['}
    for ch in s:
        if ch in mapping:
            if not stack or stack.pop() != mapping[ch]:
                return False
        else:
            stack.append(ch)
    return not stack

    三个必查边界：空字符串 → True；栈空时遇到右括号 → False；遍历完栈非空 → False。

    4. 表达式求值¶

    4.1 知识点¶

    中缀表达式 3 + 4 × 2 符合人类习惯，但优先级和括号让它难以直接解析；后缀表达式（逆波兰表示）3 4 2 × + 没有括号、运算符紧跟操作数，用一个栈从左到右一趟就能算完——这就是编译器和计算器先把中缀转后缀的原因。整个流程分两步： 1. 中缀转后缀（Shunting Yard 调度场算法）：操作数直接输出，运算符入栈并按优先级比较决定何时弹出输出，括号用于分组 2. 后缀表达式求值：操作数入栈，遇到运算符就弹出栈顶两个数计算，结果压回栈中

    4.2 中缀转后缀（Shunting Yard）¶

    def infixToPostfix(expression):
    precedence = {'+': 1, '-': 1, '*': 2, '/': 2, '^': 3}
    output = []
    stack = []

    for token in expression.split():
        if token.isdigit():  # 操作数
            output.append(token)
        elif token == '(':
            stack.append(token)
        elif token == ')':
            while stack and stack[-1] != '(':
                output.append(stack.pop())
            stack.pop()  # 弹出 '('
        else:  # 运算符
            while (stack and stack[-1] != '(' and 
                   precedence.get(stack[-1], 0) >= precedence.get(token, 0)):
                output.append(stack.pop())
            stack.append(token)

    while stack:
        output.append(stack.pop())

    return ' '.join(output)

# 测试
print(infixToPostfix("3 + 4 * 2"))  # "3 4 2 * +"

    4.3 后缀表达式求值¶

    def evalRPN(tokens):
    stack = []
    ops = {
        '+': lambda a, b: a + b,
        '-': lambda a, b: a - b,
        '*': lambda a, b: a * b,
        '/': lambda a, b: int(a / b),  # 向零取整
    }

    for token in tokens:
        if token in ops:
            b = stack.pop()
            a = stack.pop()
            stack.append(ops[token](a, b))
        else:
            stack.append(int(token))

    return stack[0]

# 测试
print(evalRPN(["3", "4", "2", "*", "+"]))  # 11
print(evalRPN(["10", "6", "9", "3", "+", "-11", "*", "/", "*", "17", "+", "5", "+"]))  # 22

    4.4 ⚠️ 易错点：后缀求值的操作数顺序¶

    # 减法和除法不满足交换律：先弹出的是右操作数 b，后弹出的才是左操作数 a
# ❌ 错误：把先弹出的当左操作数，10 - 2 会算成 2 - 10 = -8
stack.append(b - a)

# ✅ 正确：b = stack.pop() 是右操作数，a = stack.pop() 是左操作数，计算 a - b
b = stack.pop()
a = stack.pop()
stack.append(a - b)

    同理，Shunting Yard 中比较优先级用的是 >=（而不是 >），这保证了同级运算符按左结合处理：3 - 2 - 1 转成 3 2 - 1 - 而不是 3 2 1 - -。

    5. 函数调用栈与递归¶

    5.1 知识点¶

    每次函数调用时，系统会把调用信息压入调用栈（系统栈）；函数返回时弹出对应栈帧，回到调用处继续执行。递归的本质就是"不断压栈直到基准条件，再不断弹栈返回结果"。这也解释了两件事： - 递归的空间开销：递归深度 d 占用 O(d) 栈空间（Python 不做尾递归优化） - 无限递归为什么报 RecursionError：栈帧一直压入，最终超出栈容量上限

    5.2 调用栈示例¶

    调用栈示例：
main() 调用 fact(3)
┌─────────────────┐
│ fact(3)         │ ← 栈顶（当前执行）
├─────────────────┤
│ fact(2)         │
├─────────────────┤
│ fact(1)         │
├─────────────────┤
│ main()          │ ← 栈底
└─────────────────┘

fact(3) = 3 × fact(2)
fact(2) = 2 × fact(1)
fact(1) = 1 × fact(0)
fact(0) = 1  ← 开始返回

    递归的栈帧包含：

    • 返回地址
    • 参数值
    • 局部变量
    • 保存的寄存器

    5.3 栈溢出：递归必须有终止条件¶

    # ❌ 没有终止条件 → 栈溢出
def infinite_recursion(n):
    # 没有终止条件 → 栈溢出
    return n + infinite_recursion(n + 1)

# 运行结果：RecursionError: maximum recursion depth exceeded

# ✅ 有基准条件，且每次递归都向基准条件推进
def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)

    Python 默认递归深度限制约 1000 层，深度递归（如链状树遍历）可能直接爆栈——此时要么 sys.setrecursionlimit 调高（治标），要么改写成显式栈迭代版（治本，见下一节 DFS）。

    6. 浏览器历史记录（双栈模型）¶

    6.1 知识点¶

    浏览器的后退/前进是经典的双栈模型（LeetCode 1472）： - back_stack（后退栈）：保存访问过的页面，栈顶是当前页 - forward_stack（前进栈）：保存后退时退出来的页面，等着被"前进"回去 - visit 新页面：压入 back_stack，同时清空 forward_stack——后退后又去了新页面，原来的前进历史就失效了（和真实浏览器行为一致）

    本质是用两个栈把"线性历史"变成"可双向恢复的状态"，每次操作都是 O(1) 的弹压。

    6.2 双栈实现¶

    class BrowserHistory:
    def __init__(self, homepage: str):
        self.back_stack = [homepage]  # 后退栈
        self.forward_stack = []       # 前进栈

    def visit(self, url: str) -> None:
        """访问新页面，清空前进历史"""
        self.back_stack.append(url)
        self.forward_stack.clear()

    def back(self, steps: int) -> str:
        """后退 steps 步"""
        while steps > 0 and len(self.back_stack) > 1:
            self.forward_stack.append(self.back_stack.pop())
            steps -= 1
        return self.back_stack[-1]

    def forward(self, steps: int) -> str:
        """前进 steps 步"""
        while steps > 0 and self.forward_stack:
            self.back_stack.append(self.forward_stack.pop())
            steps -= 1
        return self.back_stack[-1]

# 测试
browser = BrowserHistory("leetcode.com")
browser.visit("google.com")
browser.visit("facebook.com")
print(browser.back(1))      # "google.com"
print(browser.forward(1))   # "facebook.com"

    6.3 状态变化¶

    访问顺序：A → B → C
back_stack:  [A, B, C]
forward_stack: []

执行 back(1):
back_stack:  [A, B]
forward_stack: [C]

执行 forward(1):
back_stack:  [A, B, C]
forward_stack: []

    注意两个细节：后退时 len(self.back_stack) > 1 保证首页不会被退出；visit 后必须清空前进栈，否则"后退→访问新页→前进"会穿越回旧历史。

    7. 深度优先搜索（DFS）¶

    7.1 知识点¶

    DFS 的递归写法本质上用的是系统调用栈；改成显式栈就能摆脱递归深度限制，并完全控制遍历过程。两者等价，按场景选： - 递归版：代码简洁，栈帧由系统管理，适合树 - 迭代版：手动压弹，注意入栈顺序决定访问顺序（栈是 LIFO，想先访问左子树就要后压左子树） - 图的 DFS：图可能有环，必须配 visited 集合，否则会无限循环

    7.2 树的 DFS（递归版）¶

    def dfs_recursive(node):
    if not node:
        return
    print(node.val)      # 前序遍历
    dfs_recursive(node.left)
    dfs_recursive(node.right)

    7.3 树的 DFS（显式栈版）¶

    def dfs_iterative(root):
    if not root:
        return

    stack = [root]
    while stack:
        node = stack.pop()
        print(node.val)
        # 先右后左，保证左子树先处理
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)

    7.4 图的 DFS¶

    def dfs_graph(graph, start):
    visited = set()
    stack = [start]
    result = []

    while stack:
        node = stack.pop()
        if node not in visited:
            visited.add(node)
            result.append(node)
            # 逆序入栈，保证正序访问
            for neighbor in reversed(graph[node]):
                if neighbor not in visited:
                    stack.append(neighbor)

    return result

    8. 单调栈¶

    8.1 知识点¶

    单调栈：栈内元素保持严格单调递增或递减。每次新元素入栈前，把所有"破坏单调性"的栈顶元素弹出——弹出的瞬间，正是它们找到"下一个更大/更小元素"的时刻。每个元素最多入栈、出栈各一次，所以整体 O(n)。

    类型 栈内顺序 弹出条件 典型应用
    单调递增 小 → 大 当前 < 栈顶 找前一个更小元素
    单调递减 大 → 小 当前 > 栈顶 找下一个更大元素

    什么时候用？两个信号：① 题目要求"下一个/前一个更大（更小）元素"；② 需要知道每个元素的左右边界（宽度×高度的面积类问题）。记忆口诀：找更大用递减栈，找更小用递增栈。

    8.2 通用模板¶

    def monotonic_stack_template(nums):

    def trap(height):
    stack = []  # 存索引，单调递减
    water = 0

    for i, h in enumerate(height):
        # 遇到更高的柱子，计算积水
        while stack and h > height[stack[-1]]:
            bottom = stack.pop()
            if not stack:
                break
            # 宽度：当前索引 - 新栈顶索引 - 1
            width = i - stack[-1] - 1
            # 高度：两侧较矮者 - 底部高度
            bound_h = min(height[stack[-1]], h) - height[bottom]
            water += width * bound_h

        stack.append(i)

    return water

    9.1 有效的括号（LeetCode 20）⭐¶

    题目：判断只包含 '()[]{}' 的字符串是否有效

    有效条件：

    1. 左括号必须用相同类型的右括号闭合
    2. 左括号必须以正确的顺序闭合
    3. 空字符串有效
    def isValid(s: str) -> bool:
    # 优化：奇数长度直接返回
    if len(s) % 2 == 1:
        return False

    stack = []
    # 映射：右括号 → 左括号
    mapping = {')': '(', '}': '{', ']': '['}

    for char in s:
        if char in mapping:
            # 右括号：栈顶必须匹配
            top = stack.pop() if stack else '#'
            if mapping[char] != top:
                return False
        else:
            # 左括号：入栈
            stack.append(char)

    # 栈空说明全部匹配
    return not stack

    9.2 最小栈（LeetCode 155）⭐⭐¶

    题目：设计支持 push/pop/top/getMin 的栈，所有操作 O(1)

    思路：辅助栈同步记录最小值

    class MinStack:
    def __init__(self):
        self.stack = []       # 主栈
        self.min_stack = []   # 辅助栈，记录最小值

    def push(self, val: int) -> None:
        self.stack.append(val)
        # 辅助栈：保持栈顶为当前最小值
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)
        else:
            # 重复压入当前最小值，保证两栈同步
            self.min_stack.append(self.min_stack[-1])

    def pop(self) -> None:
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]

# 测试

minStack.push(2)

print(minStack.getMin())  # 1
minStack.pop()

    优化版本（空间更优）： 

    class MinStackOptimized:
    def __init__(self):
        self.stack = []
        self.min_stack = []  # 只在更小/相等时压入

    def push(self, val: int) -> None:
        self.stack.append(val)
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)

    def pop(self) -> None:
        if self.stack.pop() == self.min_stack[-1]:
            self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]

    两种实现对比： | 版本 | push 空间 | pop 逻辑 | 适用场景 | |------|----------|---------|---------| | 同步版 | O(n) 固定 | 简单 | 代码清晰 | | 优化版 | O(n) 最坏 | 需判断 | 节省空间 |

    ⚠️ 易错点：等值最小值必须用 <= 压入辅助栈

    # ❌ 优化版若用严格小于：连续相等的最小值只记录一次，弹出一个就把唯一记录"误伤"弹掉
# push 3, push 3 → min_stack=[3]
# pop() 弹出 3，3 == min_stack[-1] → min_stack 被弹空 → getMin() 报错

# ✅ 必须用 <=：相等的最小值也要入栈，弹出时一一对应
if not self.min_stack or val <= self.min_stack[-1]:

    9.3 接雨水（LeetCode 42）⭐⭐⭐¶

    题目：给定 n 个非负整数表示高度图，计算能接多少雨水

    解法一：单调栈 

    def trap_stack(height):
    """
    单调递减栈：遇到更高柱子时计算积水
    """
    stack = []  # 存索引
    water = 0

    for i, h in enumerate(height):
        # 当前高度 > 栈顶高度 → 形成凹槽
        while stack and h > height[stack[-1]]:
            bottom = stack.pop()  # 凹槽底部
            if not stack:
                break
            # 左边界（栈顶）和右边界（当前）
            left = stack[-1]
            width = i - left - 1
            bound_h = min(height[left], h) - height[bottom]
            water += width * bound_h

        stack.append(i)

    return water

    解法二：预处理左右最大值 

    def trap_two_pointers(height):
    """
    预处理左右最大值，然后双指针扫描
    """
    if not height:
        return 0

    n = len(height)
    left_max = [0] * n
    right_max = [0] * n

    # 预处理
    left_max[0] = height[0]
    for i in range(1, n):
        left_max[i] = max(left_max[i-1], height[i])

    right_max[n-1] = height[n-1]
    for i in range(n-2, -1, -1):
        right_max[i] = max(right_max[i+1], height[i])

    # 计算雨水
    water = 0
    for i in range(n):
        water += min(left_max[i], right_max[i]) - height[i]

    return water

    解法三：双指针优化（空间 O(1)） 

    def trap_optimized(height):
    left, right = 0, len(height) - 1
    left_max = right_max = 0
    water = 0

    while left < right:
        if height[left] < height[right]:
            if height[left] >= left_max:
                left_max = height[left]
            else:
                water += left_max - height[left]
            left += 1
        else:
            if height[right] >= right_max:
                right_max = height[right]
            else:
                water += right_max - height[right]
            right -= 1

    return water

    def largestRectangleArea(heights):
    """
    单调递增栈：找到每个柱子能扩展的最大宽度
    """
    # 添加哨兵，简化边界处理
    heights = [0] + heights + [0]
    stack = [0]  # 存索引
    max_area = 0

            w = i - stack[-1] - 1
            max_area = max(max_area, h * w)
        stack.append(i)

    return max_area

    9.6 最大栈（LeetCode 716）⭐⭐⭐¶

    题目：设计支持查找/删除最大元素的栈

    class MaxStack:
    """
    使用双向链表 + HashMap 实现高效操作
    """
    def __init__(self):
        self.stack = []  # (value, index)
        self.max_map = {}  # value -> [indices]

    def push(self, x: int) -> None:
        idx = len(self.stack)
        self.stack.append((x, idx))
        if x not in self.max_map:
            self.max_map[x] = []
        self.max_map[x].append(idx)

    def pop(self) -> int:
        val, idx = self.stack.pop()
        self.max_map[val].pop()
        if not self.max_map[val]:
            del self.max_map[val]
        return val

    def top(self) -> int:
        return self.stack[-1][0]

    def peekMax(self) -> int:
        return max(self.max_map.keys())

    def popMax(self) -> int:
        max_val = self.peekMax()
        idx = self.max_map[max_val].pop()
        if not self.max_map[max_val]:
            del self.max_map[max_val]

        # 标记删除（惰性删除）
        self.stack[idx] = None

        # 清理栈顶的 None
        while self.stack and self.stack[-1] is None:
            self.stack.pop()

        return max_val

# 测试

    10.4 移除 K 位数字使剩余最小（LeetCode 402）⭐⭐⭐¶

    def removeKdigits(num: str, k: int) -> str:
    """
    单调递增栈：保持结果最小
    """
    stack = []

    for digit in num:
        # 栈顶 > 当前数字，且还能删除 → 弹出
        while k > 0 and stack and stack[-1] > digit:
            stack.pop()
            k -= 1
        stack.append(digit)

    # 如果还有剩余删除次数，从末尾删除
    while k > 0:
        stack.pop()
        k -= 1

    # 处理前导零
    result = ''.join(stack).lstrip('0')
    return result if result else '0'

# 测试
print(removeKdigits("1432219", 3))  # "1219"
print(removeKdigits("10200", 1))    # "200"
print(removeKdigits("10", 2))       # "0"

    10.5 最长连续子数组（最小值×和最大）⭐⭐¶

    def maxScore(nums, k):
    """
    找长度为 k 的子数组，使得 min(subarray) * sum(subarray) 最大
    """
    n = len(nums)

    # 单调栈找左右边界
    left = [-1] * n
    right = [n] * n
    stack = []

    # 找左边第一个更小的
    for i in range(n):
        while stack and nums[stack[-1]] >= nums[i]:
            stack.pop()
        left[i] = stack[-1] if stack else -1
        stack.append(i)

    stack = []

    for i in range(n-1, -1, -1):
        while stack and nums[stack[-1]] >= nums[i]:
            stack.pop()
        right[i] = stack[-1] if stack else n
        stack.append(i)

    # 计算每个元素作为最小值时的最大贡献
    max_score = 0

        # 以 nums[i] 为最小值的最大窗口
        window_len = right[i] - left[i] - 1
        if window_len >= k:

    10.6 解题技巧总结¶

    识别单调栈的信号：

    1. 找"下一个更大/更小"元素
    2. 找"前一个更大/更小"元素
    3. 涉及"宽度×高度"的面积问题
    4. 需要知道元素左右边界

    选择栈类型： 

    找下一个更大 → 单调递减栈
找下一个更小 → 单调递增栈
找前一个更大 → 单调递减栈
找前一个更小 → 单调递增栈

    边界处理技巧：

    1. 添加哨兵元素（如首尾加 0）
    2. 存索引而非值
    3. 循环数组：遍历 2n 次取模

    常见陷阱：

    • 忘记处理栈中剩余元素
    • 相等元素的处理（严格 vs 非严格单调）
    • 边界条件（空数组、单元素）

    单调栈口诀：

    更大用递减，更小用递增； 存索引不存值，边界要处理； 面积问题找左右，宽度乘高度。

    11. 本章小结¶

    特性 说明
    核心原则 后进先出（LIFO）
    操作限制 只能在一端操作
    时间复杂度 基本操作均为 O(1)
    空间复杂度 O(n)
    典型应用 括号匹配、表达式求值、DFS、单调栈

    单调栈进阶：

    • 识别模式：下一个/前一个更大更小
    • 选择类型：递增/递减
    • 处理边界：哨兵、存索引、循环数组

    核心知识点¶

    ✅ 栈 = 后进先出（LIFO）：push/pop/top 全 O(1)，天然适配"回溯、撤销、嵌套"场景
    ✅ 两种实现：数组栈均摊 O(1)、缓存友好；链表栈严格 O(1)、无扩容，空间都是 O(n)
    ✅ 括号匹配：左括号入栈、右括号配栈顶、最终栈空，三个边界一个都不能少
    ✅ 表达式求值：Shunting Yard 中缀转后缀，后缀求值注意操作数顺序（先弹的是右操作数）
    ✅ 函数调用栈：递归 = 系统栈帧，必须有终止条件，深度受限就改显式栈迭代
    ✅ 双栈模型：浏览器后退/前进，visit 新页面要清空前进栈
    ✅ DFS：递归是隐式栈、迭代是显式栈；入栈顺序决定访问顺序，图必须记 visited
    ✅ 单调栈：O(n) 解决"下一个更大/更小"与面积类问题，存索引、分严格/非严格、处理剩余元素
    ✅ 设计题：MinStack 辅助栈同步（等值用 <=），MaxStack 索引映射 + 惰性删除

    最佳实践¶

    1. 看到"嵌套、撤销、回溯"想栈；看到"下一个更大/更小、左右边界"想单调栈
    2. Python 直接用 list 当栈（append/pop 末尾操作 O(1)），别用 pop(0)/insert(0)
    3. 单调栈三件套：存索引、按题意定严格/非严格单调、最后清空栈中剩余元素
    4. 写 pop/top 先问"栈空了吗"；括号匹配最后问"栈空了吗"
    5. 递归太深改显式栈：Python 默认递归深度约 1000 层，图/树的深度遍历优先迭代版

    关键思想：当你需要回溯、撤销、或者处理嵌套结构时，优先考虑栈！
