分支操作

分支操作

git stash

git stash save "stash_name"
git stash list
git stash show stash@{1}
git stash pop
git stash drop stash@{1}
git stash clear

查

强制 log 显示分支和标签信息

git log --decorate

1.7.2 版本之后，log 和 decorate 默认绑定，即默认打开

View the change history of a file

git log -p -- filename

tag

git tag -a v1.0 -m "version 1.0"
git push origin v1.0
