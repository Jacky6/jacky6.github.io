A simple demo:

import argparse
parser = argparse.ArgumentParser(
    prog="batch_remote_api_yq",
    description="Batch run VLM/OCR API on datasets and save per-sample JSON results.",
)

g_srv = parser.add_argument_group("Service")
g_srv.add_argument(
    "--srv_type",
    type=str,
    default="openai",
    choices=["openai", "dashhttp", "ocr_edu_agent"],
    help="Backend service type.",
)
g_srv.add_argument("--llm_srv", type=str, default=None, help="Service base url / endpoint.")
g_srv.add_argument("--api_key", type=str, default=None, help="API key/token if needed.")
g_srv.add_argument("--model_name", type=str, required=True, help="Model name, e.g. qwen-vl-max.")

g_pr = parser.add_argument_group("Prompt")
g_pr.add_argument(
    "--prompt_type",
    type=str,
    default="default",
    help="Key to select prompt from prompt dict in qa.jsonl.",
)
g_pr.add_argument(
    "--prompt_content",
    type=str,
    default=None,
    help="Override prompt content for all samples if provided.",
)

Argparse Tutorial

This tutorial is intended to be a gentle introduction to argparse, the recommended command-line parsing module in the Python standard library.

Note The standard library includes two other libraries directly related to command-line parameter processing: the lower level optparse module (which may require more code to configure for a given application, but also allows an application to request behaviors that argparse doesn’t support), and the very low level getopt (which specifically serves as an equivalent to the getopt() family of functions available to C programmers). While neither of those modules is covered directly in this guide, many of the core concepts in argparse first originated in optparse, so some aspects of this tutorial will also be relevant to optparse users.
