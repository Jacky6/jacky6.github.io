1. Circus 是什么？

Circus 是一个由 Mozilla 开发的 Python 工具，类似于 supervisord，用于管理多个子进程、监听事件、重启失败进程等。

GitHub 地址：https://github.com/circus-tent/circus

2. 功能特点

  • 支持进程管理（启动、停止、重启）
  • 支持 WebSockets 实时通信
  • 可通过命令行或配置文件控制
  • 支持插件扩展
  • 可用于部署 Flask、Django、Node.js 等服务

3. 安装方式（Python 环境下）

pip install circus

4. 示例配置文件 circus.ini

; [circus]
; watcher=myapp
; cmd=python app.py
; args=--port=8000
; use_sockets=True
; numprocesses=2

[watcher:webapp]
cmd = gunicorn -b 0.0.0.0:8000 myapp:app
numprocesses = 4
autostart = true
autorestart = true
stderr_path = /var/log/webapp.err.log
stdout_path = /var/log/webapp.out.log

[watcher:celery]
cmd = celery -A myapp.tasks worker --loglevel=info
numprocesses = 2
autostart = true
autorestart = true
stderr_path = /var/log/celery.err.log
stdout_path = /var/log/celery.out.log

5. 常用命令

# 启动服务
circusd circus.ini

# 查看状态
circusctl status

# 重启某个 watcher
circusctl restart myapp

# 
circusd --daemon ${APP_HOME}/conf/circus.ini
# --daemon：
    # 以守护进程（后台）方式运行 circusd，不占用当前终端。

6. 适用场景

  • 多进程 Web 应用部署
  • 需要自动重启的服务管理
  • 日志收集与进程监控
