supervisord 和 gunicorn 是在部署 Python Web 应用（尤其是基于 Flask、FastAPI、Django 等框架）时常用的两个工具，它们职责不同、层级不同，但经常协同工作。

典型部署架构如下：

Client → Nginx（反向代理） → 应用服务器（Gunicorn/Uvicorn） → Python App（Flask/FastAPI/Django）
                              ↑
                       进程管理（supervisord/systemd）

协作方式：

  1. 反向代理：用于暴露服务、SSL 终止、静态文件处理、负载均衡。
  2. nginx：最常用，高性能，支持 HTTPS、缓存、限流
  3. Apache：最常用，高性能，支持 HTTPS、缓存、限流
  4. Traefik： 云原生网关，自动发现服务（适合 Docker/K8s）

  5. Caddy：自动申请 HTTPS 证书，配置极简

  6. 进程管理工具（确保服务常驻）

  7. Supervisord 负责启动 Gunicorn：（Linux）轻量级，配置简单，支持日志管理
    • 监控 Gunicorn 是否崩溃，自动重启
  8. systemd：（Linux&unix）系统级服务管理，无需额外安装

  9. pm2：（跨平台）原为 Node.js 设计，也支持 Python

  10. WSGI/ASGI 应用服务器：真正运行你的 Python 代码的服务器。

特性 Gunicorn Supervisord
类型 WSGI/ASGI HTTP 服务器 进程管理工具
作用 处理 HTTP 请求，运行 Web 应用 管理进程的启动、重启、日志、崩溃恢复等
运行层级 应用服务器层 系统进程管理层
是否处理请求？ ✅ 是 ❌ 否
是否监控进程？ ⚠️ 有限（可配合） ✅ 强大
是否跨平台？ ✅（Linux/Unix） ✅（但主要用在 Linux）
配置文件 gunicorn.conf.py 或命令行 supervisord.conf 或 .ini 文件

Gunicorn 官网

  • 官方文档

Gunicorn 原生不支持异步，但通过 uvicorn 或其他 ASGI worker，可以支持异步应用。

  1. 是什么？
  2. Gunicorn（Green Unicorn）是一个 Python WSGI HTTP Server。
  3. 支持同步和异步（通过 gevent 或 uvicorn 工作模式）。

  4. 用于生产环境部署 Web 应用。

  5. 使用方法，参数介绍

# 使用 uvicorn worker 运行 FastAPI（支持 ASGI）
gunicorn -k uvicorn.workers.UvicornWorker -w 4 -b 0.0.0.0:8000 main:app
  • -k: 指定 worker 类型（如 UvicornWorker 支持 async）
  • -w: worker 数量， 每个 worker 是一个独立的 Python 进程，可并行处理请求（Gunicorn 主要靠多进程实现并发）。
  • -b: 绑定地址

  • main:app: 模块名:应用实例

  • 配置文件示例（gunicorn.conf.py）

bind = "0.0.0.0:8000"
workers = 4
worker_class = "uvicorn.workers.UvicornWorker"
timeout = 30
max_requests = 1000
max_requests_jitter = 100

进程管理工具

Supervisord 详解官网

  1. 是什么？ 一个用 Python 写的进程管理工具。 可以监控多个进程，崩溃后自动重启。 提供命令行工具（supervisorctl）和 Web UI。
  2. 安装
pip install supervisor
# 或系统安装
sudo apt install supervisor
  1. 配置文件示例（/etc/supervisor/conf.d/fastapi.conf）
[program:fastapi]
command=/path/to/venv/bin/gunicorn -k uvicorn.workers.UvicornWorker -w 2 -b 127.0.0.1:8000 main:app
directory=/path/to/app
user=www-data
autostart=true
autorestart=true
redirect_stderr=true
stdout_logfile=/var/log/fastapi.log
stderr_logfile=/var/log/fastapi_err.log
environment=DATABASE_URL="xxx",DEBUG="false"
  1. 常用命令
supervisorctl status           # 查看进程状态
supervisorctl start fastapi    # 启动
supervisorctl stop fastapi     # 停止
supervisorctl restart fastapi  # 重启
supervisorctl reread           # 读取新配置
supervisorctl update           # 应用配置

为什么需要两者结合？

问题 解决方案
如何让 Gunicorn 在后台运行？ Supervisord 可以 daemonize 进程
Gunicorn 崩溃了怎么办？ Supervisord 自动重启
如何统一管理多个服务？ Supervisord 可管理多个 [program:x]
如何查看日志？ Supervisord 可重定向输出到文件
如何开机自启？ Supervisord 可配合 systemd 实现
误解 正确理解
“Supervisord 能处理 HTTP 请求” ❌ 它只是进程管理器
“Gunicorn 能自动重启自己” ❌ 它崩溃就没了，需要外部监控
“Nginx + Gunicorn 就够了” ✅ 可行，但无进程监控
“可以用 systemd 替代 supervisord” ✅ 可以，但 supervisord 更轻量、易配置
