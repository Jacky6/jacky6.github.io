前言

定义：事件循环（Event Loop） 是 Python 异步编程的核心机制，它是 asyncio 模块的“引擎”，负责调度和执行协程（coroutines）、任务（tasks）、回调（callbacks）等异步操作。

事件循环是一个无限循环，它不断地监听和处理“事件”，比如：

  • 协程完成
  • 网络 I/O 完成（如 HTTP 请求返回）
  • 定时器触发
  • 文件读写完成

它采用 单线程 + 非阻塞 I/O 的方式，实现高并发处理能力。

类比理解：

想象一个餐厅服务员（事件循环）服务多个顾客（协程）：

  • 顾客点完菜后说：“我等上菜，好了叫我。”
  • 服务员不去干等着，而是去服务其他顾客。
  • 当厨房做好菜（I/O 完成），服务员收到通知，回来继续服务这个顾客。

这就是 异步非阻塞 的思想。
