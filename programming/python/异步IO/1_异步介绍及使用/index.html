Python 异步编程（Asynchronous Programming）是一种并发编程模型，用于高效处理 I/O 密集型任务（如网络请求、文件读写、数据库操作等），通过避免线程阻塞来提升程序性能和资源利用率。它自 Python 3.4 起逐步完善，特别是从 Python 3.5 开始，async 和 await 关键字的引入使得异步编程更加直观和易用。 ---

一、异步编程基本概念

1. 什么是异步？

异步编程允许程序在等待某个耗时操作（如网络请求）完成时，不阻塞主线程，而是去执行其他任务。当等待的操作完成后，程序再回来处理结果。

2. 同步 vs 异步

特性 同步（Synchronous） 异步（Asynchronous）
执行方式 顺序执行，一个任务完成后再执行下一个 并发执行，多个任务可以“同时”进行
阻塞性 阻塞，等待 I/O 时 CPU 空闲 非阻塞，I/O 等待时可执行其他任务
性能 低并发，适用于少量任务 高并发，适合大量 I/O 操作
编程复杂度 简单直观 相对复杂，需理解事件循环、协程等概念

二、Python 异步核心组件

1. async 和 await

  • async def：定义一个协程函数（coroutine function），返回一个协程对象。

  • await：用于等待一个协程完成，只能在 async 函数内部使用。 

import asyncio 
async def say_hello():    
        print("Hello")    
    await asyncio.sleep(1)  # 模拟异步等待    
    print("World") 
# 运行协程 
asyncio.run(say_hello())

### 2. 事件循环（Event Loop）

  • 异步的核心是事件循环，负责调度和执行协程。
  • Python 使用 asyncio 模块提供事件循环支持。
  • asyncio.run() 会自动创建并运行事件循环。

3. 协程（Coroutine）

  • 协程是异步函数的执行体，由 async def 定义。

  • 协程不是线程，它是单线程内的协作式多任务。

4. 任务（Task）

  • Task 是对协程的包装，使其在事件循环中被并发调度。

  • 使用 asyncio.create_task() 创建任务。 

async def main():
        task1 = asyncio.create_task(say_hello())    
    task2 = asyncio.create_task(say_hello())    
    await task1    
    await task2

5. 异步上下文管理器、异步迭代器

  • 支持 async with 和 async for，用于异步资源管理。 
async with aiohttp.ClientSession() as session:    
        async with session.get(url) as response:        
            text = await response.text()

三、异步编程使用场景

适用场景（I/O 密集型）

  • 网络爬虫（大量 HTTP 请求）

  • Web 服务器（如 FastAPI、Starlette）

  • 数据库操作（异步 ORM 如 databases, SQLAlchemy 2.0+ async）

  • 实时通信（WebSocket）

  • 文件读写（异步文件操作库如 aiofiles）

不适用场景（CPU 密集型）

  • 图像处理、科学计算、加密解密等 CPU 密集任务

此类任务应使用多进程（multiprocessing）而非异步

四、实际使用示例

示例 1：并发下载多个网页

import asyncio
import aiohttp

async def fetch_url(session, url):
    async with session.get(url) as response:
        return await response.text()

async def main():
    urls = [
        "https://httpbin.org/delay/1",
        "https://httpbin.org/delay/2",
        "https://httpbin.org/delay/1"
    ]
    async with aiohttp.ClientSession() as session:
        tasks = [fetch_url(session, url) for url in urls]
        results = await asyncio.gather(*tasks)
        print(f"获取到 {len(results)} 个响应")

# 运行
asyncio.run(main())

使用 aiohttp 实现异步 HTTP 请求，asyncio.gather() 并发执行多个任务。

示例 2：异步读写文件

import asyncio
import aiofiles

async def write_read_file():
    async with aiofiles.open('test.txt', 'w') as f:
        await f.write("Hello Async!")

    async with aiofiles.open('test.txt', 'r') as f:
        content = await f.read()
        print(content)

asyncio.run(write_read_file())

五、异步编程的优缺点

✅ 优点

优点 说明
高并发性能 单线程可处理数千并发连接，适用于高 I/O 场景
资源利用率高 不需要为每个任务创建线程，节省内存和上下文切换开销
响应快 避免阻塞，提升用户体验（如 Web API 响应速度）
现代框架支持好 FastAPI、Django 4.1+、Tornado、Quart 等均支持异步
可扩展性强 易于与消息队列、WebSocket、微服务集成

❌ 缺点

缺点 说明
学习曲线陡峭 需理解事件循环、协程、await、死锁等概念
调试困难 异步栈跟踪复杂，错误定位不如同步直观
不适用于 CPU 密集任务 异步无法利用多核 CPU，需配合多进程
库支持有限 并非所有第三方库都支持异步（如某些数据库驱动）
潜在的死锁风险 错误使用 await 或阻塞调用（如 time.sleep()）会导致事件循环卡住
混合同步/异步代码复杂 在异步函数中调用同步阻塞函数会阻塞整个事件循环

六、常见陷阱与最佳实践

❌ 常见错误

# 错误：在 async 函数中使用同步阻塞函数
async def bad_example():
    time.sleep(1)  # 阻塞事件循环！

# 正确：使用异步替代
await asyncio.sleep(1)

✅ 最佳实践

  1. 使用 asyncio.run() 作为异步程序入口。

  2. 使用 asyncio.create_task() 并发启动多个协程。

  3. 使用 asyncio.gather() 并行执行多个协程并收集结果。

  4. 避免在协程中调用阻塞函数，必要时使用 loop.run_in_executor()。

  5. 使用异步库（如 aiohttp, aiomysql, aiofiles）替代同步库。 

# 在线程池中运行阻塞函数
def blocking_io():
    time.sleep(1)
    return "Done"

async def main():
    loop = asyncio.get_running_loop()
    result = await loop.run_in_executor(None, blocking_io)
    print(result)

七、异步框架推荐

框架 用途
FastAPI 现代异步 Web 框架，支持自动文档生成
Starlette 异步 Web 基础框架，FastAPI 的底层
aiohttp 异步 HTTP 客户端/服务器
Quart Flask 风格的异步框架
Tornado 支持异步的 Web 框架和 HTTP 客户端
Databases 异步数据库查询工具（支持 SQLite、PostgreSQL 等）

八、总结

项目 内容
适用场景 I/O 密集型任务（网络、文件、数据库）
核心机制 协程 + 事件循环 + async/await
优势 高并发、低资源消耗、响应快
劣势 学习成本高、不适合 CPU 密集任务
建议 新项目优先考虑异步，尤其是 Web 服务和爬虫
