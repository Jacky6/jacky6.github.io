在 Python 中，日志记录（logging）是非常重要的调试和监控工具。Python 标准库提供了 logging 模块，而第三方库 loguru 则是为简化日志使用体验而设计的现代替代方案。

📌 一、Python 内置 logging 模块

✅ 简介：

Python 自带的标准模块，功能强大、灵活，支持多级日志、输出到文件/控制台、格式化、过滤器等。

✅ 使用方式：

import logging

# 基本配置
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler("app.log"),
        logging.StreamHandler()
    ]
)

logger = logging.getLogger(__name__)

logger.info("这是一个信息日志")
logger.warning("这是一个警告日志")
logger.error("这是一个错误日志")

✅ 优点：

  • 标准库：无需安装，跨平台兼容性好。
  • 高度可定制：支持 Handler、Formatter、Filter、Logger 层级结构。
  • 企业级应用常用：适合大型项目、框架集成（如 Django、Flask）。

❌ 缺点：

  • 配置繁琐：新手容易被 basicConfig()、getLogger()、addHandler()、setLevel() 等搞晕。
  • 默认不输出到控制台或文件：需要手动配置。
  • 没有彩色输出、异步支持、自动轮转等现代特性。
  • 格式化语法老旧（如 % 或 .format()，不如 f-string 直观）。

📌 二、第三方库 loguru

✅ 简介：

Loguru 是一个“开箱即用”的日志库，目标是让日志记录变得简单、直观、强大。它封装了 logging 的复杂性，同时增加了许多现代开发者喜欢的功能。

✅ 安装：

pip install loguru

✅ 使用方式：

from loguru import logger

# 默认就输出到 stderr + 彩色 + 时间戳 + 级别 + 文件名行号
logger.info("Hello, Loguru!")
logger.warning("This is a warning.")
logger.error("Something went wrong!")

# 添加文件输出（自动轮转、压缩）
logger.add("app.log", rotation="10 MB", retention="10 days", compression="zip")

# 异常捕获（自动打印堆栈）
try:
    1 / 0
except Exception:
    logger.exception("An error occurred")

✅ 优点：

  • 零配置启动：导入即可用，无需 basicConfig()。
  • 彩色终端输出（自动识别是否支持 ANSI）。
  • 自动包含文件名、行号、函数名。
  • 支持异步写入、线程安全、进程安全。
  • 内置旋转、保留、压缩日志文件功能。
  • 支持 f-string 和结构化日志（JSON）。
  • 异常捕获更友好：logger.exception() 自动打印完整堆栈。
  • API 简洁优雅：比如 logger.add(...) 替代多个 handler 配置。

❌ 缺点：

  • 非标准库：需要额外安装。
  • 不适合与传统 logging 生态深度集成（如某些框架要求使用 logging.getLogger()）。
  • 部分高级功能需手动配置（虽然比原生简单很多）。
  • 社区规模小于标准库（但活跃度高，文档优秀）。

🧪 四、代码对比示例

📄 1. 简单输出

# logging
import logging
logging.basicConfig(level=logging.INFO)
logging.info("Hello logging")

# loguru
from loguru import logger
logger.info("Hello loguru")

✅ Loguru 更简洁！

📄 2. 输出到文件 + 控制台 + 彩色 + 自动轮转

# logging（繁琐）
import logging
from logging.handlers import RotatingFileHandler

logger = logging.getLogger()
logger.setLevel(logging.INFO)

handler1 = logging.StreamHandler()
handler2 = RotatingFileHandler("app.log", maxBytes=10*1024*1024, backupCount=5)

formatter = logging.Formatter('%(asctime)s - %(levelname)s - %(message)s')
handler1.setFormatter(formatter)
handler2.setFormatter(formatter)

logger.addHandler(handler1)
logger.addHandler(handler2)

logger.info("Logging with rotating file")

# loguru（一行搞定）
from loguru import logger
logger.add("app.log", rotation="10 MB", retention="10 days", compression="zip")
logger.info("Loguru with auto rotate")

✅ Loguru 几乎是“一行解决”。

📈 五、选型建议

项目类型 推荐日志库
小型脚本、工具、学习项目 ✅ Loguru（简单高效）
Web 应用（Django/Flask） ⚠️ 通常用 logging（兼容框架）
大型系统、微服务、企业级 ✅ logging（可扩展性强）或混合使用
需要彩色日志、结构化日志、快速开发 ✅ Loguru
需要与现有 logging 生态（如 Sentry、ELK）集成 ✅ logging（有成熟适配器）

💡 六、进阶技巧：Loguru 高级用法

1. 自定义格式：

logger.remove()  # 移除默认 handler
logger.add(sys.stderr, format="<green>{time}</green> <level>{message}</level>")

2. 输出为 JSON：

logger.add("app.json", serialize=True)  # 自动转成 JSON 行

3. 捕获所有未处理异常：

import sys
logger.add(sys.stderr, backtrace=True, diagnose=True)  # 显示变量值

@logger.catch
def risky_function():
    return 1 / 0

risky_function()  # 自动记录异常

4. 异步写入：

logger.add("async.log", enqueue=True)  # 异步写入避免阻塞主线程

🎯 总结

  • 如果你是初学者或想快速搭建日志系统 → 选 loguru
  • 如果你在做企业级项目或需要与框架深度集成 → 选 logging
  • 如果你两者都想兼顾 → 可以在项目中混用（例如用 loguru 主日志，logging 用于第三方库）

✅ 推荐语：

“Loguru 让日志记录像写 print 一样简单，却拥有企业级能力。”
