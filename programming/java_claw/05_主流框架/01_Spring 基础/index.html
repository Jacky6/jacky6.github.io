29_Spring 基础

1. Spring 概述

1.1 什么是 Spring

Spring 是一个开源的 Java 企业级应用框架，由 Rod Johnson 于 2003 年创建。

核心特性： - ✅ IOC（控制反转）：依赖注入 - ✅ AOP（面向切面编程）：横切关注点 - ✅ 事务管理：声明式事务 - ✅ 集成支持：与其他框架无缝集成

1.2 Spring 模块

Spring Framework
├── Core Container（核心容器）
│   ├── Beans（Bean 管理）
│   ├── Core（核心工具）
│   ├── Context（上下文）
│   └── SpEL（表达式语言）
├── AOP（面向切面）
├── Data Access（数据访问）
│   ├── JDBC
│   ├── ORM
│   └── Transaction（事务）
├── Web
│   ├── MVC
│   └── WebSocket
└── Test（测试）

2. IOC 控制反转

2.1 什么是 IOC

IOC（Inversion of Control）控制反转，将对象创建和依赖关系的管理交给容器。

DI（Dependency Injection）依赖注入，是 IOC 的实现方式。

// 传统方式：自己创建依赖
public class UserService {
    private UserDao userDao = new UserDaoImpl();
}

// IOC 方式：容器注入
public class UserService {
    private UserDao userDao;

    // 通过构造方法注入
    public UserService(UserDao userDao) {
        this.userDao = userDao;
    }

    // 或通过 setter 注入
    public void setUserDao(UserDao userDao) {
        this.userDao = userDao;
    }
}

2.2 IOC 容器

BeanFactory：基础 IOC 容器
ApplicationContext：高级 IOC 容器（推荐）

// 创建容器
ApplicationContext context = new ClassPathXmlApplicationContext("applicationContext.xml");

// 获取 Bean
UserService userService = context.getBean("userService", UserService.class);

3. Bean 管理

3.1 XML 配置

<!-- applicationContext.xml -->
<beans>
    <!-- 基本 Bean -->
    <bean id="userDao" class="com.example.UserDaoImpl"/>

    <bean id="userService" class="com.example.UserServiceImpl">
        <!-- 构造方法注入 -->
        <constructor-arg ref="userDao"/>

        <!-- Setter 注入 -->
        <property name="userDao" ref="userDao"/>
    </bean>

    <!-- 值注入 -->
    <bean id="config" class="com.example.Config">
        <property name="timeout" value="3000"/>
        <property name="url" value="http://localhost:8080"/>
    </bean>
</beans>

3.2 注解配置

// 组件扫描
@Component
public class UserDaoImpl implements UserDao {
}

@Service
public class UserServiceImpl implements UserService {

    // 自动注入
    @Autowired
    private UserDao userDao;
}

@Controller
public class UserController {

    @Autowired
    private UserService userService;
}

// 配置类
@Configuration
@ComponentScan("com.example")
public class AppConfig {

    @Bean
    public DataSource dataSource() {
        return new HikariDataSource();
    }
}

3.3 注入方式对比

注入方式 优点 缺点
构造方法注入 依赖明确、不可变 参数多时复杂
Setter 注入 灵活、可选依赖 依赖不明确
字段注入 简洁 难以测试、不推荐

推荐：优先使用构造方法注入

4. AOP 面向切面

4.1 什么是 AOP

AOP（Aspect Oriented Programming）面向切面编程，将横切关注点（日志、事务、安全）与业务逻辑分离。

核心概念： - Aspect（切面）：横切关注点的模块化 - Joinpoint（连接点）：程序执行的点（方法执行） - Pointcut（切点）：匹配连接点的表达式 - Advice（通知）：切面在连接点执行的动作 - Weaving（织入）：将切面应用到目标对象

4.2 通知类型

@Aspect
@Component
public class LogAspect {

    // 前置通知
    @Before("execution(* com.example.service.*.*(..))")
    public void before(JoinPoint joinPoint) {
        System.out.println("方法执行前");
    }

    // 后置通知
    @After("execution(* com.example.service.*.*(..))")
    public void after(JoinPoint joinPoint) {
        System.out.println("方法执行后");
    }

    // 返回通知
    @AfterReturning(pointcut = "execution(* com.example.service.*.*(..))", 
                    returning = "result")
    public void afterReturning(Object result) {
        System.out.println("返回结果：" + result);
    }

    // 异常通知
    @AfterThrowing(pointcut = "execution(* com.example.service.*.*(..))", 
                   throwing = "ex")
    public void afterThrowing(Exception ex) {
        System.out.println("异常：" + ex.getMessage());
    }

    // 环绕通知
    @Around("execution(* com.example.service.*.*(..))")
    public Object around(ProceedingJoinPoint pjp) throws Throwable {
        System.out.println("环绕通知 - 前");
        Object result = pjp.proceed();
        System.out.println("环绕通知 - 后");
        return result;
    }
}

4.3 切点表达式

// execution 表达式
execution(* com.example.service.*.*(..))
//     │    │         │      │   │  └─ 任意参数
//     │    │         │      │   └─ 任意方法名
//     │    │         │      └─ service 包下任意类
//     │    │         └─ 包名
//     │    └─ 返回类型（* 任意）
//     └─ 方法执行

// 常用表达式
@Pointcut("execution(* com.example.service.*.*(..))")
public void serviceLayer() {}

@Pointcut("within(com.example.controller..*)")
public void controllerLayer() {}

@Pointcut("@annotation(org.springframework.web.bind.annotation.GetMapping)")
public void getMapping() {}

// 组合
@Pointcut("serviceLayer() && !controllerLayer()")
public void combined() {}

5. 事务管理

5.1 声明式事务

@Service
public class UserServiceImpl implements UserService {

    @Autowired
    private UserDao userDao;

    // 添加事务
    @Transactional
    @Override
    public void createUser(User user) {
        userDao.insert(user);
        // 如果抛异常，整个方法回滚
    }

    // 配置事务属性
    @Transactional(
        isolation = Isolation.DEFAULT,      // 隔离级别
        propagation = Propagation.REQUIRED, // 传播行为
        timeout = 30,                        // 超时时间
        readOnly = false,                    // 只读
        rollbackFor = Exception.class        // 回滚异常
    )
    @Override
    public void updateUser(User user) {
        userDao.update(user);
    }
}

5.2 事务传播行为

传播行为 说明
REQUIRED 有事务则加入，无事务则新建（默认）
REQUIRES_NEW 新建事务，挂起当前事务
NESTED 嵌套事务
SUPPORTS 有事务则支持，无事务则非事务
NOT_SUPPORTED 非事务执行，挂起当前事务
MANDATORY 必须有事务，否则抛异常
NEVER 必须非事务，否则抛异常

6. 实战示例

6.1 Spring 配置

@Configuration
@ComponentScan("com.example")
@EnableAspectJAutoProxy
@EnableTransactionManagement
public class AppConfig {

    @Bean
    public DataSource dataSource() {
        HikariDataSource ds = new HikariDataSource();
        ds.setJdbcUrl("jdbc:mysql://localhost:3306/test");
        ds.setUsername("root");
        ds.setPassword("password");
        return ds;
    }

    @Bean
    public PlatformTransactionManager transactionManager(DataSource dataSource) {
        return new DataSourceTransactionManager(dataSource);
    }
}

6.2 完整示例

// DAO 层
@Repository
public class UserDaoImpl implements UserDao {

    @Autowired
    private JdbcTemplate jdbcTemplate;

    @Override
    public void insert(User user) {
        jdbcTemplate.update(
            "INSERT INTO users (name, email) VALUES (?, ?)",
            user.getName(), user.getEmail()
        );
    }
}

// Service 层
@Service
public class UserServiceImpl implements UserService {

    @Autowired
    private UserDao userDao;

    @Transactional
    @Override
    public void register(User user) {
        // 检查用户是否存在
        // 插入用户
        userDao.insert(user);
        // 发送欢迎邮件
        // 如果任何一步失败，全部回滚
    }
}

// Controller 层
@RestController
@RequestMapping("/users")
public class UserController {

    @Autowired
    private UserService userService;

    @PostMapping
    public ResponseEntity<?> create(@RequestBody User user) {
        userService.register(user);
        return ResponseEntity.ok().build();
    }
}

7. 本章小结

核心知识点

✅ IOC：控制反转、依赖注入
✅ Bean 管理：XML 配置、注解配置
✅ AOP：切面、切点、通知
✅ 事务管理：@Transactional、传播行为

最佳实践

  1. 使用构造方法注入：依赖明确
  2. 优先使用注解：简洁清晰
  3. AOP 用于横切关注点：日志、事务、安全
  4. 声明式事务：@Transactional
  5. 合理设置事务边界：Service 层
