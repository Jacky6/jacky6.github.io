11_字符串

1. String 类

1.1 String 概述

String 是 Java 中最常用的类，用于表示不可变的字符序列。

特点： - ✅ 不可变性：创建后不能修改 - ✅ 线程安全：不可变所以线程安全 - ✅ 字符串常量池：节省内存 - ✅ 基于 char 数组（Java 8）或 byte 数组（Java 9+）

String str1 = "Hello";
String str2 = "Hello";
String str3 = new String("Hello");

System.out.println(str1 == str2);      // true（同一对象）
System.out.println(str1 == str3);      // false（不同对象）
System.out.println(str1.equals(str3)); // true（内容相同）

1.2 字符串创建

// 方式 1：字面量（推荐）
String str1 = "Hello";

// 方式 2：new 关键字
String str2 = new String("Hello");

// 方式 3：字符数组
char[] chars = {'H', 'e', 'l', 'l', 'o'};
String str3 = new String(chars);

// 方式 4：字节数组
byte[] bytes = {72, 101, 108, 108, 111};
String str4 = new String(bytes);

1.3 常用方法

String str = "Hello, World!";

// 获取长度
int len = str.length();  // 13

// 获取字符
char c = str.charAt(0);  // 'H'

// 子字符串
String sub1 = str.substring(7);     // "World!"
String sub2 = str.substring(0, 5);  // "Hello"

// 查找
int index = str.indexOf("World");   // 7
int last = str.lastIndexOf("o");    // 8

// 判断
boolean b1 = str.startsWith("Hello");  // true
boolean b2 = str.endsWith("!");        // true
boolean b3 = str.contains("World");    // true
boolean b4 = str.isEmpty();            // false

// 比较
boolean eq1 = str.equals("Hello, World!");  // true
boolean eq2 = str.equalsIgnoreCase("hello, world!");  // true
int cmp = str.compareTo("Hello, World!");  // 0

// 替换
String replaced = str.replace("World", "Java");  // "Hello, Java!"

// 分割
String[] parts = str.split(", ");  // ["Hello", "World!"]

// 转大小写
String upper = str.toUpperCase();  // "HELLO, WORLD!"
String lower = str.toLowerCase();  // "hello, world!"

// 去空格
String trimmed = "  Hello  ".trim();  // "Hello"

// 转数组
char[] chars = str.toCharArray();
byte[] bytes = str.getBytes();

2. StringBuilder 和 StringBuffer

2.1 为什么需要可变字符串

// ❌ 低效：每次 + 都创建新对象
String str = "";
for (int i = 0; i < 1000; i++) {
    str += i;  // 创建 1000 个临时对象
}

// ✅ 高效：只使用一个对象
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}
String result = sb.toString();

2.2 StringBuilder

特点： - ✅ 可变字符序列 - ✅ 非线程安全 - ✅ 性能高（单线程推荐）

StringBuilder sb = new StringBuilder();

// 追加
sb.append("Hello");
sb.append(", ");
sb.append("World");
sb.append("!");

// 插入
sb.insert(5, " Java");  // "Hello Java, World!"

// 删除
sb.delete(5, 10);  // "Hello, World!"

// 替换
sb.replace(7, 12, "Java");  // "Hello, Java!"

// 反转
sb.reverse();  // "!dlraW ,olleH"

// 长度
int len = sb.length();  // 13

// 容量
int cap = sb.capacity();  // 默认 16

// 转字符串
String str = sb.toString();

2.3 StringBuffer

特点： - ✅ 可变字符序列 - ✅ 线程安全（方法有 synchronized） - ❌ 性能略低

StringBuffer sb = new StringBuffer();
sb.append("Hello");
sb.append(" World");

// 方法同 StringBuilder
String str = sb.toString();

2.4 三者对比

特性 String StringBuilder StringBuffer
可变性 不可变 可变 可变
线程安全 ✅ ❌ ✅
性能 低 高 中
使用场景 少量操作 单线程多操作 多线程多操作

3. 字符串常量池

3.1 常量池原理

String str1 = "Hello";
String str2 = "Hello";
String str3 = new String("Hello");

// str1 和 str2 指向常量池中的同一对象
// str3 在堆中创建新对象

System.out.println(str1 == str2);      // true
System.out.println(str1 == str3);      // false
System.out.println(str1.equals(str3)); // true

// intern() 方法
String str4 = str3.intern();
System.out.println(str1 == str4);      // true

3.2 常量池优化

// ✅ 推荐：使用字面量
String str1 = "Hello";

// ❌ 不推荐：无意义地 new
String str2 = new String("Hello");

// 字符串拼接
String a = "Hello";
String b = "World";

// 编译期优化（常量拼接）
String c = "Hello" + "World";  // 等效于 "HelloWorld"

// 运行期拼接（创建新对象）
String d = a + b;  // 使用 StringBuilder

4. 字符串格式化

4.1 String.format()

// 格式化字符串
String str1 = String.format("Hello, %s!", "World");
// "Hello, World!"

// 数字格式化
String str2 = String.format("Price: %.2f", 19.99);
// "Price: 19.99"

// 整数格式化
String str3 = String.format("Count: %05d", 42);
// "Count: 00042"

// 日期格式化
String str4 = String.format("Date: %tY-%tm-%td", new Date());
// "Date: 2026-03-26"

4.2 printf

System.out.printf("Name: %s, Age: %d%n", "Alice", 25);
System.out.printf("Price: $%.2f%n", 19.99);

5. 经典算法题

5.1 反转字符串

public String reverseString(String s) {
    char[] chars = s.toCharArray();
    int left = 0, right = chars.length - 1;
    while (left < right) {
        char temp = chars[left];
        chars[left] = chars[right];
        chars[right] = temp;
        left++;
        right--;
    }
    return new String(chars);
}

// 使用 StringBuilder
public String reverseString2(String s) {
    return new StringBuilder(s).reverse().toString();
}

5.2 验证回文串

public boolean isPalindrome(String s) {
    s = s.toLowerCase().replaceAll("[^a-z0-9]", "");
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s.charAt(left) != s.charAt(right)) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

5.3 字符串转整数

public int myAtoi(String s) {
    s = s.trim();
    if (s.isEmpty()) return 0;

    int sign = 1, index = 0;
    if (s.charAt(0) == '-') {
        sign = -1;
        index++;
    } else if (s.charAt(0) == '+') {
        index++;
    }

    long result = 0;
    while (index < s.length() && Character.isDigit(s.charAt(index))) {
        result = result * 10 + (s.charAt(index) - '0');
        if (result * sign > Integer.MAX_VALUE) return Integer.MAX_VALUE;
        if (result * sign < Integer.MIN_VALUE) return Integer.MIN_VALUE;
        index++;
    }

    return (int) result * sign;
}

5.4 最长公共前缀

public String longestCommonPrefix(String[] strs) {
    if (strs == null || strs.length == 0) return "";

    String prefix = strs[0];
    for (int i = 1; i < strs.length; i++) {
        while (strs[i].indexOf(prefix) != 0) {
            prefix = prefix.substring(0, prefix.length() - 1);
            if (prefix.isEmpty()) return "";
        }
    }
    return prefix;
}

6. 本章小结

核心知识点

✅ String：不可变、常用方法、常量池
✅ StringBuilder：可变、非线程安全、高性能
✅ StringBuffer：可变、线程安全
✅ 字符串格式化：format、printf

最佳实践

  1. 少量操作用 String：代码简洁
  2. 单线程多操作用 StringBuilder：性能最优
  3. 多线程多操作用 StringBuffer：线程安全
  4. 字符串比较用 equals：不用 ==
  5. 注意空指针：先判断 null 和 empty

性能对比

// 场景：拼接 10000 次字符串

// String：约 500ms
String str = "";
for (int i = 0; i < 10000; i++) {
    str += i;
}

// StringBuilder：约 5ms
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i);
}

// StringBuffer：约 10ms
StringBuffer sb2 = new StringBuffer();
for (int i = 0; i < 10000; i++) {
    sb2.append(i);
}
