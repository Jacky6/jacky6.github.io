14_泛型

1. 泛型概述

1.1 什么是泛型

泛型（Generics）是参数化类型，让代码可以适用于多种类型。

优点： - ✅ 类型安全：编译时检查类型 - ✅ 消除强制转换：自动类型转换 - ✅ 代码复用：一套代码适用于多种类型

// 不使用泛型
List list = new ArrayList();
list.add("Hello");
list.add(123);  // 可以添加任何类型
String str = (String) list.get(0);  // 需要强制转换

// 使用泛型
List<String> list = new ArrayList<>();
list.add("Hello");
// list.add(123);  // 编译错误
String str = list.get(0);  // 自动转换

1.2 泛型的使用场景

  • 集合框架（List、Set、Map）
  • 泛型类
  • 泛型方法
  • 泛型接口

2. 泛型类

2.1 定义泛型类

// 泛型类定义
public class Box<T> {
    private T content;

    public void set(T content) {
        this.content = content;
    }

    public T get() {
        return content;
    }
}

// 使用
Box<String> stringBox = new Box<>();
stringBox.set("Hello");
String str = stringBox.get();

Box<Integer> intBox = new Box<>();
intBox.set(123);
Integer num = intBox.get();

2.2 多个类型参数

public class Pair<K, V> {
    private K key;
    private V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    public K getKey() { return key; }
    public V getValue() { return value; }
}

// 使用
Pair<String, Integer> pair = new Pair<>("age", 25);
String key = pair.getKey();
Integer value = pair.getValue();

2.3 泛型继承

// 子类指定具体类型
public class StringBox extends Box<String> {
}

// 子类也是泛型
public class GenericBox<T> extends Box<T> {
}

3. 泛型方法

3.1 定义泛型方法

public class Utils {
    // 泛型方法：类型参数在返回值前
    public static <T> T getFirst(T[] array) {
        if (array == null || array.length == 0) {
            return null;
        }
        return array[0];
    }

    // 多个类型参数
    public static <K, V> boolean containsKey(Map<K, V> map, K key) {
        return map.containsKey(key);
    }
}

// 使用
String[] arr = {"A", "B", "C"};
String first = Utils.getFirst(arr);  // 自动推断类型

// 或显式指定
String first2 = Utils.<String>getFirst(arr);

3.2 泛型方法 vs 类中的泛型

public class Box<T> {
    private T content;

    // 类中的泛型方法（使用类的 T）
    public T get() {
        return content;
    }

    // 独立的泛型方法（使用自己的 U）
    public <U> U convert(Function<T, U> func) {
        return func.apply(content);
    }
}

4. 通配符

4.1 无界通配符

// ? 表示任意类型
public static void printList(List<?> list) {
    for (Object obj : list) {
        System.out.println(obj);
    }
}

// 可以接受任何类型的 List
printList(new ArrayList<String>());
printList(new ArrayList<Integer>());

4.2 上界通配符

// ? extends T 表示 T 或其子类
public static double sum(List<? extends Number> list) {
    double total = 0;
    for (Number num : list) {
        total += num.doubleValue();
    }
    return total;
}

// 可以使用
sum(new ArrayList<Integer>());
sum(new ArrayList<Double>());
sum(new ArrayList<Number>());

// 不能添加元素（除了 null）
// list.add(1);  // 编译错误

4.3 下界通配符

// ? super T 表示 T 或其父类
public static void addNumbers(List<? super Integer> list) {
    list.add(1);
    list.add(2);
    list.add(3);
}

// 可以使用
addNumbers(new ArrayList<Integer>());
addNumbers(new ArrayList<Number>());
addNumbers(new ArrayList<Object>());

// 读取时只能得到 Object
Object obj = list.get(0);

4.4 PECS 原则

PECS：Producer Extends, Consumer Super

  • 生产者用 extends：从集合读取数据
  • 消费者用 super：向集合写入数据
// 生产者（读取）
public static void printList(List<? extends Number> list) {
    for (Number num : list) {
        System.out.println(num);
    }
}

// 消费者（写入）
public static void fillList(List<? super Integer> list) {
    list.add(1);
    list.add(2);
}

5. 类型擦除

5.1 擦除原理

泛型在编译后会被擦除，替换为原始类型。

// 编译前
List<String> list = new ArrayList<>();
list.add("Hello");

// 编译后（字节码）
List list = new ArrayList();
list.add("Hello");

5.2 擦除的限制

// ❌ 不能创建泛型数组
List<T>[] arr = new List<T>[10];  // 编译错误

// ❌ 不能使用 instanceof
if (obj instanceof List<String>) {}  // 编译错误

// ✅ 可以使用无界通配符
if (obj instanceof List<?>) {}  // 正确

// ❌ 不能创建泛型实例
T obj = new T();  // 编译错误

// ✅ 使用 Class 参数
public <T> T createInstance(Class<T> clazz) {
    return clazz.newInstance();
}

6. 泛型实战

6.1 通用结果类

public class Result<T> {
    private int code;
    private String message;
    private T data;

    public static <T> Result<T> success(T data) {
        Result<T> result = new Result<>();
        result.code = 200;
        result.message = "success";
        result.data = data;
        return result;
    }

    public static <T> Result<T> error(String message) {
        Result<T> result = new Result<>();
        result.code = 500;
        result.message = message;
        return result;
    }

    // getter/setter
}

// 使用
Result<User> userResult = Result.success(user);
Result<String> errorResult = Result.error("操作失败");

6.2 通用 DAO

public interface DAO<T> {
    void save(T entity);
    void delete(Long id);
    T findById(Long id);
    List<T> findAll();
}

public class UserDAO implements DAO<User> {
    @Override
    public void save(User user) {
        // 保存用户
    }

    @Override
    public void delete(Long id) {
        // 删除用户
    }

    @Override
    public User findById(Long id) {
        return null;
    }

    @Override
    public List<User> findAll() {
        return new ArrayList<>();
    }
}

6.3 函数式接口

@FunctionalInterface
public interface Converter<T, R> {
    R convert(T source);
}

// 使用
Converter<String, Integer> converter = Integer::parseInt;
Integer result = converter.convert("123");  // 123

7. 本章小结

核心知识点

✅ 泛型类：定义、使用、多个类型参数
✅ 泛型方法：定义、与类泛型的区别
✅ 通配符：无界、上界、下界、PECS 原则
✅ 类型擦除：原理、限制

最佳实践

  1. 优先使用泛型：类型安全、代码清晰
  2. 遵循 PECS 原则：生产者 extends，消费者 super
  3. 避免泛型数组：使用 List 代替
  4. 使用 diamond 操作符：new ArrayList<>()
  5. 泛型方法优先：能使用方法就不用类

常见错误

// ❌ 错误：泛型不是协变的
List<String> strings = new ArrayList<>();
List<Object> objects = strings;  // 编译错误

// ✅ 正确：使用通配符
List<? extends Object> objects = strings;

// ❌ 错误：不能实例化类型参数
T obj = new T();

// ✅ 正确：使用 Class 参数
public <T> T create(Class<T> clazz) {
    return clazz.newInstance();
}
