07_访问修饰符

1. 访问修饰符概述

1.1 什么是访问修饰符

访问修饰符（Access Modifier）用于控制类、方法、字段的访问权限。

四种访问级别：

修饰符 同类 同包 子类 其他包
private ✅ ❌ ❌ ❌
default ✅ ✅ ❌ ❌
protected ✅ ✅ ✅ ❌
public ✅ ✅ ✅ ✅ 
访问权限范围：

private < default < protected < public

┌─────────────────────────────────────┐
│          public (所有类)             │
│  ┌─────────────────────────────┐    │
│  │     protected (子类)         │    │
│  │  ┌──────────────────────┐   │    │
│  │  │   default (同包)      │   │    │
│  │  │  ┌──────────────┐    │   │    │
│  │  │  │  private     │    │   │    │
│  │  │  │  (同类)      │    │   │    │
│  │  │  └──────────────┘    │   │    │
│  │  └──────────────────────┘   │    │
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘

2. private 私有

2.1 特点

  • ✅ 只能在本类中访问
  • ✅ 封装性最强
  • ❌ 子类和外部类无法访问

2.2 使用示例

public class Person {
    // 私有字段
    private String name;
    private int age;

    // 私有构造方法（单例模式）
    private Person() {
    }

    // 私有方法
    private void validateAge(int age) {
        if (age < 0 || age > 150) {
            throw new IllegalArgumentException("年龄不合法");
        }
    }

    // 公共 getter/setter
    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        validateAge(age);  // 内部调用私有方法
        this.age = age;
    }
}

// 使用
public class Main {
    public static void main(String[] args) {
        Person p = new Person();

        // ✅ 可以通过公共方法访问
        p.setName("张三");
        String name = p.getName();

        // ❌ 不能直接访问私有成员
        // p.name = "张三";  // 编译错误
        // p.validateAge(25);  // 编译错误
    }
}

2.3 使用场景

  1. 字段封装：所有字段应设为 private
  2. 内部辅助方法：不对外暴露的方法
  3. 单例模式：私有构造方法

3. default 默认（包私有）

3.1 特点

  • ✅ 同包内可访问
  • ✅ 不写修饰符即为 default
  • ❌ 不同包无法访问

3.2 使用示例

// 文件：com/example/demo/Animal.java
package com.example.demo;

// default 访问级别（不写修饰符）
class Animal {
    void eat() {
        System.out.println("吃东西");
    }
}

// 文件：com/example/demo/Dog.java
package com.example.demo;

// 同包可访问
public class Dog extends Animal {
    public void bark() {
        eat();  // ✅ 可以访问
    }
}

// 文件：com/example/other/Cat.java
package com.example.other;

import com.example.demo.Animal;

// 不同包无法访问
public class Cat extends Animal {
    public void meow() {
        // eat();  // ❌ 编译错误
    }
}

3.3 使用场景

  1. 包内工具类：只在本包使用
  2. 测试类：测试代码与被测试类同包
  3. 内部协作：包内类之间协作

4. protected 受保护

4.1 特点

  • ✅ 同包内可访问
  • ✅ 子类可访问（即使在不同包）
  • ❌ 其他包的非子类无法访问

4.2 使用示例

// 文件：com/example/demo/Person.java
package com.example.demo;

public class Person {
    protected String name;
    protected int age;

    protected void showInfo() {
        System.out.println(name + ", " + age);
    }
}

// 文件：com/example/demo/Student.java（同包）
package com.example.demo;

public class Student extends Person {
    public void study() {
        System.out.println(name);  // ✅ 同包可访问
        showInfo();  // ✅ 同包可访问
    }
}

// 文件：com/example/other/Employee.java（不同包，子类）
package com.example.other;

import com.example.demo.Person;

public class Employee extends Person {
    public void work() {
        System.out.println(name);  // ✅ 子类可访问
        showInfo();  // ✅ 子类可访问
    }
}

// 文件：com/example/other/Other.java（不同包，非子类）
package com.example.other;

import com.example.demo.Person;

public class Other {
    public void test() {
        Person p = new Person();
        // p.name = "张三";  // ❌ 编译错误
        // p.showInfo();  // ❌ 编译错误
    }
}

4.3 使用场景

  1. 继承体系：父类希望子类访问
  2. 模板方法模式：子类需要重写的方法
  3. 框架设计：提供扩展点

5. public 公共

5.1 特点

  • ✅ 任何地方都可访问
  • ✅ 公开 API
  • ❌ 过度使用破坏封装

5.2 使用示例

// 文件：com/example/demo/UserService.java
package com.example.demo;

public class UserService {
    // 公共方法 - 对外 API
    public void createUser(String name) {
        // ...
    }

    public void deleteUser(Long id) {
        // ...
    }

    // 内部方法 - 不应公开
    private void validateName(String name) {
        // ...
    }
}

// 任何地方都可使用
public class Main {
    public static void main(String[] args) {
        UserService service = new UserService();
        service.createUser("张三");  // ✅ 可访问
    }
}

5.3 使用场景

  1. 对外 API：提供给外部调用的方法
  2. 工具类方法：通用的工具方法
  3. 入口类：main 方法所在类

6. 类的访问修饰符

6.1 顶层类

// ✅ public - 任何地方可访问
public class PublicClass {
}

// ✅ default - 同包可访问
class DefaultClass {
}

// ❌ private - 顶层类不能用 private
// private class PrivateClass {}  // 编译错误

// ❌ protected - 顶层类不能用 protected
// protected class ProtectedClass {}  // 编译错误

6.2 内部类

public class Outer {
    // 内部类可以使用所有访问修饰符
    public class PublicInner {}
    protected class ProtectedInner {}
    class DefaultInner {}
    private class PrivateInner {}
}

7. 访问修饰符对比

7.1 完整对比表

修饰符 类 字段 方法 构造器 说明
public ✅ ✅ ✅ ✅ 完全公开
protected ❌ ✅ ✅ ✅ 子类 + 同包
default ✅ ✅ ✅ ✅ 仅同包
private ❌ ✅ ✅ ✅ 仅本类

7.2 选择指南

设计原则：最小权限原则

1. 字段：优先 private + getter/setter
2. 方法：
   - 对外 API → public
   - 子类扩展 → protected
   - 包内使用 → default
   - 内部辅助 → private
3. 构造器：
   - 正常创建 → public
   - 单例模式 → private
   - 工厂模式 → protected/default
4. 类：
   - 对外暴露 → public
   - 包内使用 → default

8. 最佳实践

8.1 封装原则

// ✅ 推荐：字段私有，通过方法访问
public class Person {
    private String name;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}

// ❌ 不推荐：字段公开
public class Person {
    public String name;  // 破坏封装
}

8.2 API 设计

// ✅ 推荐：最小暴露
public class UserService {
    // 公共 API
    public User createUser(String name) {
        validate(name);
        return doCreate(name);
    }

    // 内部实现
    private void validate(String name) {
        // ...
    }

    private User doCreate(String name) {
        // ...
    }
}

9. 本章小结

核心知识点

✅ private：仅本类访问，封装性最强
✅ default：同包访问，默认级别
✅ protected：子类 + 同包访问
✅ public：完全公开

最佳实践

  1. 字段永远 private：通过 getter/setter 访问
  2. 方法按需暴露：优先 private，必要时 public
  3. 类最少暴露：内部类用 default 或 private
  4. 遵循最小权限：只暴露必要的接口
