28_Maven

1. Maven 概述

1.1 什么是 Maven

Maven 是 Apache 开发的 Java 项目构建和管理工具。

核心功能： - ✅ 项目构建：编译、测试、打包、部署 - ✅ 依赖管理：自动下载和管理 jar 包 - ✅ 统一结构：标准的项目目录结构 - ✅ 插件系统：丰富的插件扩展功能

1.2 Maven vs Gradle

特性 Maven Gradle
配置语言 XML Groovy/Kotlin
构建速度 较慢 较快（增量构建）
学习曲线 平缓 较陡
灵活性 一般 高
推荐使用 传统项目 新项目

2. 安装和配置

2.1 安装 Maven

Windows

  1. 下载：Maven 官网
  2. 解压到：C:\Program Files\Apache\maven
  3. 配置环境变量： MAVEN_HOME = C:\Program Files\Apache\maven Path = %MAVEN_HOME%\bin
  4. 验证： cmd mvn -version

macOS

# 使用 Homebrew
brew install maven

# 验证
mvn -version

Linux

# Ubuntu/Debian
sudo apt install maven

# 验证
mvn -version

2.2 配置 settings.xml

<!-- Maven 安装目录/conf/settings.xml -->
<settings>
    <!-- 本地仓库路径 -->
    <localRepository>D:\maven-repo</localRepository>

    <!-- 镜像配置（加速下载） -->
    <mirrors>
        <mirror>
            <id>aliyun</id>
            <name>Aliyun Maven</name>
            <url>https://maven.aliyun.com/repository/public</url>
            <mirrorOf>central</mirrorOf>
        </mirror>
    </mirrors>
</settings>

3. 项目结构

3.1 标准目录结构

my-project/
├── pom.xml              # 项目配置文件
├── src/
│   ├── main/
│   │   ├── java/        # Java 源代码
│   │   ├── resources/   # 资源文件
│   │   └── webapp/      # Web 应用（可选）
│   └── test/
│       ├── java/        # 测试代码
│       └── resources/   # 测试资源
├── target/              # 构建输出目录
└── .mvn/                # Maven 配置（可选）

3.2 创建 Maven 项目

# 命令行创建
mvn archetype:generate \
  -DgroupId=com.example \
  -DartifactId=my-project \
  -DarchetypeArtifactId=maven-archetype-quickstart \
  -DinteractiveMode=false

# 或使用 IDE
# IntelliJ IDEA: File → New → Project → Maven

4. POM 文件详解

4.1 基本结构

<project>
    <!-- 坐标（必须） -->
    <groupId>com.example</groupId>
    <artifactId>my-project</artifactId>
    <version>1.0.0</version>
    <packaging>jar</packaging>

    <!-- 项目信息 -->
    <name>My Project</name>
    <description>项目描述</description>
    <url>https://github.com/example/my-project</url>

    <!-- 属性 -->
    <properties>
        <maven.compiler.source>11</maven.compiler.source>
        <maven.compiler.target>11</maven.compiler.target>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    </properties>

    <!-- 依赖 -->
    <dependencies>
        <dependency>
            <groupId>org.springframework</groupId>
            <artifactId>spring-core</artifactId>
            <version>5.3.0</version>
        </dependency>
    </dependencies>

    <!-- 构建配置 -->
    <build>
        <plugins>
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-compiler-plugin</artifactId>
                <version>3.8.1</version>
            </plugin>
        </plugins>
    </build>
</project>

4.2 坐标说明

<groupId>com.example</groupId>    <!-- 组织/公司标识 -->
<artifactId>my-project</artifactId> <!-- 项目名称 -->
<version>1.0.0</version>          <!-- 版本号 -->
<packaging>jar</packaging>        <!-- 打包方式：jar/war/pom -->

5. 依赖管理

5.1 依赖配置

<dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-core</artifactId>
    <version>5.3.0</version>
    <scope>compile</scope>
</dependency>

5.2 依赖作用域

scope 编译 测试 运行 说明
compile ✅ ✅ ✅ 默认，全程有效
provided ✅ ✅ ❌ 容器提供（如 servlet-api）
runtime ❌ ✅ ✅ 运行时有效（如 JDBC 驱动）
test ❌ ✅ ❌ 仅测试有效（如 JUnit）

5.3 常用命令

# 清理
mvn clean

# 编译
mvn compile

# 测试
mvn test

# 打包
mvn package

# 安装到本地仓库
mvn install

# 跳过测试
mvn package -DskipTests

# 查看依赖树
mvn dependency:tree

6. 常用插件

6.1 编译插件

<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <version>3.8.1</version>
    <configuration>
        <source>11</source>

    </configuration>
</plugin>

6.2 打包插件

<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-jar-plugin</artifactId>
    <version>3.2.0</version>
    <configuration>
        <archive>
            <manifest>
                <mainClass>com.example.Main</mainClass>
            </manifest>
        </archive>
    </configuration>
</plugin>

7. 多模块项目

7.1 父 POM

<project>
    <groupId>com.example</groupId>
    <artifactId>parent</artifactId>
    <version>1.0.0</version>
    <packaging>pom</packaging>

    <modules>
        <module>module-a</module>
        <module>module-b</module>
    </modules>
</project>

7.2 子模块

<project>
    <parent>
        <groupId>com.example</groupId>
        <artifactId>parent</artifactId>
        <version>1.0.0</version>
    </parent>

    <artifactId>module-a</artifactId>
</project>

8. 最佳实践

8.1 版本管理

<properties>
    <spring.version>5.3.0</spring.version>
</properties>

<dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-core</artifactId>
    <version>${spring.version}</version>
</dependency>

8.2 使用 BOM

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-dependencies</artifactId>
            <version>2.5.0</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

9. 本章小结

核心知识点

✅ 安装配置：Maven 安装、settings.xml 配置
✅ 项目结构：标准目录、pom.xml 结构
✅ 依赖管理：坐标、作用域、传递依赖
✅ 构建命令：clean、compile、package、install
✅ 多模块：父 POM、子模块

最佳实践

  1. 使用镜像加速：阿里云 Maven 镜像
  2. 统一版本管理：使用 properties 或 BOM
  3. 跳过测试：-DskipTests
  4. 查看依赖树：mvn dependency:tree
  5. 多模块项目：父 POM 统一管理
