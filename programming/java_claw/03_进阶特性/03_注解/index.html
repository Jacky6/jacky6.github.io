20_注解

1. 注解概述

1.1 什么是注解

注解（Annotation）是 Java 5 引入的元数据机制，用于为代码添加标记和信息。

作用： - ✅ 编译检查（如 @Override） - ✅ 运行时处理（如 Spring 的 @Autowired） - ✅ 生成文档（如 @author）

// 使用注解
@Override
public String toString() {
    return "Hello";
}

@Deprecated
public void oldMethod() {
}

1.2 内置注解

注解 说明
@Override 重写父类方法
@Deprecated 标记已过时
@SuppressWarnings 忽略警告
@FunctionalInterface 标记函数式接口

2. 元注解

2.1 元注解类型

元注解是用于定义注解的注解。

元注解 说明
@Target 注解作用目标
@Retention 注解保留策略
@Documented 是否包含在 Javadoc
@Inherited 是否可继承
@Repeatable 是否可重复

2.2 @Target

import java.lang.annotation.*;

// 注解可以用于类、方法、字段
@Target({ElementType.TYPE, ElementType.METHOD, ElementType.FIELD})
@interface MyAnnotation {
}

// 可用目标
ElementType.TYPE           // 类、接口、枚举
ElementType.METHOD         // 方法
ElementType.FIELD          // 字段
ElementType.PARAMETER      // 参数
ElementType.CONSTRUCTOR    // 构造方法
ElementType.LOCAL_VARIABLE // 局部变量

2.3 @Retention

// 保留策略
@Retention(RetentionPolicy.SOURCE)  // 仅源代码，编译后丢弃
@Retention(RetentionPolicy.CLASS)   // 编译到 class 文件，运行时不可见
@Retention(RetentionPolicy.RUNTIME) // 运行时可见（反射可用）

// 示例
@Retention(RetentionPolicy.RUNTIME)
@interface MyAnnotation {
}

3. 自定义注解

3.1 定义注解

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface MyAnnotation {
    // 属性
    String value();
    int count() default 1;
}

3.2 使用注解

public class Test {
    @MyAnnotation(value = "test", count = 5)
    public void method() {
    }

    // 如果只有一个 value 属性，可以省略
    @MyAnnotation("test")
    public void method2() {
    }
}

3.3 注解属性

public @interface MyAnnotation {
    // 基本类型
    int value();
    String name() default "default";

    // 数组
    String[] tags() default {};

    // 枚举
    Level level() default Level.INFO;

    // 注解
    AnotherAnnotation another();

    // Class
    Class<?> clazz() default Object.class;
}

enum Level {
    INFO, WARN, ERROR
}

4. 注解处理器

4.1 反射获取注解

public class AnnotationProcessor {
    public static void processMethod(Method method) {
        if (method.isAnnotationPresent(MyAnnotation.class)) {
            MyAnnotation anno = method.getAnnotation(MyAnnotation.class);
            System.out.println("Value: " + anno.value());
            System.out.println("Count: " + anno.count());
        }
    }

    public static void processClass(Class<?> clazz) {
        for (Method method : clazz.getDeclaredMethods()) {
            processMethod(method);
        }
    }
}

4.2 注解处理示例

// 定义注解
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
@interface Test {
    String name();
}

// 使用注解
public class TestClass {
    @Test(name = "test1")
    public void testMethod1() {
    }

    @Test(name = "test2")
    public void testMethod2() {
    }
}

// 处理器
public class TestRunner {
    public static void runTests(Object obj) throws Exception {
        Class<?> clazz = obj.getClass();

        for (Method method : clazz.getDeclaredMethods()) {
            if (method.isAnnotationPresent(Test.class)) {
                Test test = method.getAnnotation(Test.class);
                System.out.println("Running: " + test.name());
                method.setAccessible(true);
                method.invoke(obj);
            }
        }
    }
}

6. 本章小结

核心知识点

✅ 内置注解：@Override、@Deprecated
✅ 元注解：@Target、@Retention、@Documented
✅ 自定义注解：定义、属性、使用
✅ 注解处理：反射获取注解

最佳实践

  1. 使用 RUNTIME 保留策略：运行时可通过反射获取
  2. 明确 Target：指定注解可用位置
  3. 提供默认值：简化注解使用
  4. 使用 value 属性：简化单属性注解
  5. 结合反射使用：实现框架功能
