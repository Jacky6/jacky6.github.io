23_Optional

1. Optional 概述

1.1 什么是 Optional

Optional 是 Java 8 引入的容器类，用于包装可能为 null 的值，避免 NullPointerException。

优点： - ✅ 避免空指针异常 - ✅ 代码更清晰 - ✅ 函数式编程风格

// 传统方式
String name = user.getName();
if (name != null) {
    System.out.println(name.toUpperCase());
}

// Optional 方式
Optional.ofNullable(user.getName())
    .ifPresent(n -> System.out.println(n.toUpperCase()));

1.2 创建 Optional

import java.util.Optional;

// 包装非空值
Optional<String> opt1 = Optional.of("Hello");

// 包装可能为 null 的值
Optional<String> opt2 = Optional.ofNullable(getName());

// 空 Optional
Optional<String> opt3 = Optional.empty();

// ❌ 错误：不能包装 null
Optional<String> opt4 = Optional.of(null);  // NullPointerException

2. 常用方法

2.1 获取值

Optional<String> opt = Optional.of("Hello");

// get() - 获取值（可能抛异常）
String value = opt.get();

// orElse() - 为空时返回默认值
String value1 = opt.orElse("Default");

// orElseGet() - 为空时执行 Supplier
String value2 = opt.orElseGet(() -> "Default");

// orElseThrow() - 为空时抛异常
String value3 = opt.orElseThrow(() -> new RuntimeException("Value is null"));

2.2 判断

Optional<String> opt = Optional.ofNullable(getName());

// isPresent() - 是否有值
if (opt.isPresent()) {
    System.out.println(opt.get());
}

// isEmpty() - 是否为空（Java 11+）
if (opt.isEmpty()) {
    System.out.println("Empty");
}

2.3 消费

Optional<String> opt = Optional.of("Hello");

// ifPresent() - 有值时执行
opt.ifPresent(value -> System.out.println(value));

// ifPresentOrElse() - Java 9+
opt.ifPresentOrElse(
    value -> System.out.println(value),
    () -> System.out.println("Empty")
);

3. 转换和过滤

3.1 map

Optional<User> userOpt = Optional.of(new User("张三", 25));

// map - 转换
Optional<String> nameOpt = userOpt.map(User::getName);

// flatMap - 转换（返回 Optional）
Optional<String> upperNameOpt = userOpt.flatMap(u -> 
    Optional.ofNullable(u.getName().toUpperCase())
);

3.2 filter

Optional<User> userOpt = Optional.of(new User("张三", 25));

// filter - 过滤
Optional<User> adultOpt = userOpt.filter(u -> u.getAge() >= 18);

// 链式调用
String result = userOpt
    .filter(u -> u.getAge() >= 18)
    .map(User::getName)
    .orElse("未成年");

4. 实战示例

4.1 嵌套 Optional

// 传统方式
if (user != null) {
    Address address = user.getAddress();
    if (address != null) {
        String city = address.getCity();
        if (city != null) {
            System.out.println(city);
        }
    }
}

// Optional 方式
Optional.ofNullable(user)
    .map(User::getAddress)
    .map(Address::getCity)
    .ifPresent(System.out::println);

4.2 数据库查询

// Repository 层
public Optional<User> findById(Long id) {
    User user = dao.findById(id);
    return Optional.ofNullable(user);
}

// Service 层
public String getUserName(Long id) {
    return findById(id)
        .map(User::getName)
        .orElse("Unknown");
}

// 或使用 orElseThrow
public User getUserOrThrow(Long id) {
    return findById(id)
        .orElseThrow(() -> new UserNotFoundException(id));
}

4.3 方法返回 Optional

// ✅ 推荐：返回 Optional
public Optional<User> findUser(String email) {
    return Optional.ofNullable(dao.findByEmail(email));
}

// ❌ 不推荐：返回 null
public User findUser(String email) {
    return dao.findByEmail(email);  // 可能返回 null
}

// 使用
findUser("test@example.com")
    .ifPresent(user -> System.out.println(user.getName()));

5. 最佳实践

5.1 使用场景

// ✅ 推荐：作为方法返回值
public Optional<String> getUserName() {
    return Optional.ofNullable(name);
}

// ❌ 不推荐：作为字段
public class User {
    private Optional<String> name;  // 不好
}

// ❌ 不推荐：作为方法参数
public void process(Optional<String> name) {  // 不好
}

5.2 避免的用法

Optional<String> opt = Optional.of("Hello");

// ❌ 不要这样用
if (opt.isPresent()) {
    System.out.println(opt.get());
}

// ✅ 推荐
opt.ifPresent(System.out::println);

// ❌ 不要这样用
String value = opt.orElse(getDefault());  // getDefault() 总会执行

// ✅ 推荐
String value = opt.orElseGet(() -> getDefault());  // 延迟执行

5.3 链式调用

String result = Optional.ofNullable(user)
    .filter(u -> u.getAge() >= 18)
    .map(User::getName)
    .map(String::toUpperCase)
    .orElse("UNKNOWN");

6. 本章小结

核心知识点

✅ 创建 Optional：of()、ofNullable()、empty()
✅ 获取值：get()、orElse()、orElseGet()、orElseThrow()
✅ 判断：isPresent()、isEmpty()
✅ 消费：ifPresent()、ifPresentOrElse()
✅ 转换：map()、flatMap()
✅ 过滤：filter()

最佳实践

  1. 作为返回值：不要返回 null，返回 Optional
  2. 不要作为字段：Optional 不是用来替代字段的
  3. 不要作为参数：增加调用复杂度
  4. 使用 orElseGet：延迟执行默认值
  5. 链式调用：代码更简洁
