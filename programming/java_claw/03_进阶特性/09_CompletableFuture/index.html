09_CompletableFuture

1. CompletableFuture 概述

1.1 什么是 CompletableFuture

CompletableFuture 是 Java 8 引入的异步编程工具，支持链式调用和组合。

优点： - ✅ 异步执行 - ✅ 链式调用 - ✅ 组合多个异步任务 - ✅ 异常处理

1.2 Future vs CompletableFuture

特性 Future CompletableFuture
异步执行 ❌ ✅
链式调用 ❌ ✅
组合任务 ❌ ✅
异常处理 ❌ ✅
回调 ❌ ✅

2. 创建异步任务

2.1 使用 supplyAsync

import java.util.concurrent.CompletableFuture;

// 有返回值
CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
    // 耗时操作
    return "Hello";
});

// 获取结果
String result = future.get();  // 阻塞

2.2 使用 runAsync

// 无返回值
CompletableFuture<Void> future = CompletableFuture.runAsync(() -> {
    System.out.println("执行任务");
});

2.3 自定义线程池

Executor executor = Executors.newFixedThreadPool(10);

CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
    return "Hello";
}, executor);

3. 回调方法

3.1 thenApply（转换）

CompletableFuture<String> future = CompletableFuture
    .supplyAsync(() -> "Hello")
    .thenApply(s -> s + " World");

String result = future.get();  // "Hello World"

3.2 thenAccept（消费）

CompletableFuture<String> future = CompletableFuture
    .supplyAsync(() -> "Hello")
    .thenAccept(s -> System.out.println(s));  // 打印 Hello

3.3 thenRun（执行）

CompletableFuture<String> future = CompletableFuture
    .supplyAsync(() -> "Hello")
    .thenRun(() -> System.out.println("任务完成"));

3.4 thenCompose（链式）

// 依赖前一个任务的结果
CompletableFuture<String> future = CompletableFuture
    .supplyAsync(() -> "Hello")
    .thenCompose(s -> CompletableFuture.supplyAsync(() -> s + " World"));

String result = future.get();  // "Hello World"

3.5 thenCombine（合并）

CompletableFuture<String> future1 = CompletableFuture.supplyAsync(() -> "Hello");
CompletableFuture<String> future2 = CompletableFuture.supplyAsync(() -> "World");

CompletableFuture<String> combined = future1.thenCombine(future2, (s1, s2) -> s1 + " " + s2);

String result = combined.get();  // "Hello World"

4. 异常处理

4.1 exceptionally

CompletableFuture<String> future = CompletableFuture
    .supplyAsync(() -> {
        throw new RuntimeException("错误");
    })
    .exceptionally(ex -> "默认值");

String result = future.get();  // "默认值"

4.2 handle（无论成功失败）

CompletableFuture<String> future = CompletableFuture
    .supplyAsync(() -> {
        throw new RuntimeException("错误");
    })
    .handle((result, ex) -> {
        if (ex != null) {
            return "处理异常：" + ex.getMessage();
        }
        return result;
    });

4.3 whenComplete（完成回调）

CompletableFuture<String> future = CompletableFuture
    .supplyAsync(() -> "Hello")
    .whenComplete((result, ex) -> {
        if (ex == null) {
            System.out.println("成功：" + result);
        } else {
            System.out.println("失败：" + ex.getMessage());
        }
    });

5. 组合多个任务

5.1 allOf（全部完成）

CompletableFuture<String> f1 = CompletableFuture.supplyAsync(() -> "任务 1");
CompletableFuture<String> f2 = CompletableFuture.supplyAsync(() -> "任务 2");
CompletableFuture<String> f3 = CompletableFuture.supplyAsync(() -> "任务 3");

// 等待所有完成
CompletableFuture<Void> all = CompletableFuture.allOf(f1, f2, f3);

all.thenRun(() -> {
    try {
        String r1 = f1.get();
        String r2 = f2.get();
        String r3 = f3.get();
        System.out.println("全部完成：" + r1 + ", " + r2 + ", " + r3);
    } catch (Exception e) {}
});

5.2 anyOf（任一完成）

CompletableFuture<String> f1 = CompletableFuture.supplyAsync(() -> {
    sleep(1000);
    return "任务 1";
});

CompletableFuture<String> f2 = CompletableFuture.supplyAsync(() -> {
    sleep(500);
    return "任务 2";
});

// 取最快完成的结果
CompletableFuture<Object> any = CompletableFuture.anyOf(f1, f2);

any.thenAccept(result -> {
    System.out.println("最快完成：" + result);  // 任务 2
});

6. 实战示例

6.1 并行调用多个 API

public class UserService {

    public UserProfile getUserProfile(Long userId) {
        // 并行获取用户信息、订单、积分
        CompletableFuture<UserInfo> userInfoFuture = getUserInfoAsync(userId);
        CompletableFuture<List<Order>> ordersFuture = getOrdersAsync(userId);
        CompletableFuture<Integer> pointsFuture = getPointsAsync(userId);

        // 等待所有完成并组合
        return CompletableFuture.allOf(userInfoFuture, ordersFuture, pointsFuture)
            .thenApply(v -> {
                UserInfo info = userInfoFuture.join();
                List<Order> orders = ordersFuture.join();
                Integer points = pointsFuture.join();

                return new UserProfile(info, orders, points);
            })
            .join();
    }

    private CompletableFuture<UserInfo> getUserInfoAsync(Long userId) {
        return CompletableFuture.supplyAsync(() -> {
            // 调用用户服务
            return userInfoDao.findById(userId);
        });
    }
}

6.2 超时处理

CompletableFuture<String> future = CompletableFuture
    .supplyAsync(() -> {
        // 耗时操作
        return "结果";
    })
    .orTimeout(5, TimeUnit.SECONDS);  // 5 秒超时

try {
    String result = future.get();
} catch (TimeoutException e) {
    System.out.println("超时");
}

6.3 重试机制

public static <T> CompletableFuture<T> retry(
    Supplier<CompletableFuture<T>> task,
    int maxRetries
) {
    return task.get()
        .exceptionally(ex -> {
            if (maxRetries > 0) {
                return retry(task, maxRetries - 1).join();
            }
            throw new RuntimeException(ex);
        });
}

// 使用
CompletableFuture<String> result = retry(
    () -> CompletableFuture.supplyAsync(() -> {
        // 可能失败的操作
        return "结果";
    }),
    3
);

6.4 流水线处理

CompletableFuture<String> pipeline = CompletableFuture
    .supplyAsync(() -> fetchData())      // 获取数据
    .thenApply(data -> parseData(data))  // 解析
    .thenApply(parsed -> transform(parsed))  // 转换
    .thenApply(transformed -> save(transformed))  // 保存
    .exceptionally(ex -> {
        log.error("处理失败", ex);
        return "失败";
    });

String result = pipeline.get();

7. 完整示例

public class OrderService {

    public CompletableFuture<OrderResult> processOrder(Order order) {
        return CompletableFuture
            // 1. 验证订单
            .supplyAsync(() -> validateOrder(order))

            // 2. 扣减库存
            .thenCompose(valid -> decreaseStock(order))

            // 3. 创建订单
            .thenCompose(stock -> createOrder(order))

            // 4. 发送通知
            .thenCompose(created -> sendNotification(created))

            // 5. 返回结果
            .thenApply(notification -> {
                OrderResult result = new OrderResult();
                result.setSuccess(true);
                result.setMessage("订单处理成功");
                return result;
            })

            // 异常处理
            .exceptionally(ex -> {
                OrderResult result = new OrderResult();
                result.setSuccess(false);
                result.setMessage("订单处理失败：" + ex.getMessage());
                return result;
            });
    }

    private boolean validateOrder(Order order) {
        // 验证逻辑
        return true;
    }

    private CompletableFuture<Boolean> decreaseStock(Order order) {
        return CompletableFuture.supplyAsync(() -> {
            // 扣减库存
            return true;
        });
    }

    private CompletableFuture<Order> createOrder(Order order) {
        return CompletableFuture.supplyAsync(() -> {
            // 创建订单
            return order;
        });
    }

    private CompletableFuture<String> sendNotification(Order order) {
        return CompletableFuture.supplyAsync(() -> {
            // 发送通知
            return "通知已发送";
        });
    }
}

8. 本章小结

核心知识点

✅ 创建任务：supplyAsync、runAsync
✅ 回调方法：thenApply、thenAccept、thenCompose
✅ 异常处理：exceptionally、handle、whenComplete
✅ 组合任务：allOf、anyOf、thenCombine
✅ 超时处理：orTimeout

最佳实践

  1. 使用自定义线程池：避免使用默认 ForkJoinPool
  2. 链式调用：代码更清晰
  3. 异常处理：always handle exceptions
  4. 避免阻塞：使用 thenApply 代替 get()
  5. 超时设置：防止任务无限期等待
