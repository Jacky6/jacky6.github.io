19_反射

1. 反射概述

1.1 什么是反射

反射（Reflection）是 Java 在运行时获取类信息并操作类成员的能力。

作用： - ✅ 运行时获取类的信息（属性、方法、构造器） - ✅ 运行时创建对象 - ✅ 运行时调用方法 - ✅ 运行时访问和修改字段 - ✅ 框架的基础（Spring、MyBatis 等）

编译时：已知类名 → 直接使用
运行时：类名是字符串 → 通过反射获取

1.2 反射的优缺点

优点： - ✅ 灵活：运行时动态操作 - ✅ 通用：框架开发的基础 - ✅ 解耦：降低代码耦合度

缺点： - ❌ 性能开销：比直接调用慢 - ❌ 安全问题：可以访问私有成员 - ❌ 代码复杂：可读性差

2. 获取 Class 对象

2.1 三种方式

// 方式 1：Class.forName()（推荐）
Class<?> clazz1 = Class.forName("com.example.Person");

// 方式 2：类名.class
Class<?> clazz2 = Person.class;

// 方式 3：对象.getClass()
Person p = new Person();
Class<?> clazz3 = p.getClass();

// 三种方式获取的是同一个 Class 对象
System.out.println(clazz1 == clazz2);  // true
System.out.println(clazz2 == clazz3);  // true

2.2 基本类型的 Class

Class<Integer> intClass = int.class;
Class<Boolean> booleanClass = boolean.class;
Class<Void> voidClass = void.class;

// 包装类的 TYPE 字段
Class<Integer> intClass2 = Integer.TYPE;

2.3 数组的 Class

int[] arr = new int[10];
Class<?> clazz = arr.getClass();

// 二维数组
Class<?> clazz2 = int[][].class;

3. 创建对象

3.1 使用 Class.newInstance()（已过时）

Class<?> clazz = Class.forName("com.example.Person");
Object obj = clazz.newInstance();  // 调用无参构造

3.2 使用 Constructor

// 无参构造
Class<?> clazz = Class.forName("com.example.Person");
Constructor<?> constructor = clazz.getDeclaredConstructor();
Object obj = constructor.newInstance();

// 有参构造
Constructor<?> constructor2 = clazz.getDeclaredConstructor(
    String.class, int.class);
Object obj2 = constructor2.newInstance("张三", 25);

3.3 访问私有构造

Constructor<?> constructor = clazz.getDeclaredConstructor();
constructor.setAccessible(true);  // 绕过访问检查
Object obj = constructor.newInstance();

4. 访问字段

4.1 获取字段

Class<?> clazz = Class.forName("com.example.Person");

// 获取公共字段
Field field1 = clazz.getField("name");

// 获取所有公共字段
Field[] fields = clazz.getFields();

// 获取所有字段（包括私有）
Field field2 = clazz.getDeclaredField("name");
Field[] allFields = clazz.getDeclaredFields();

4.2 读取和修改字段

Person p = new Person("张三", 25);
Class<?> clazz = p.getClass();

// 获取公共字段
Field nameField = clazz.getField("name");
String name = (String) nameField.get(p);  // 读取
nameField.set(p, "李四");  // 修改

// 获取私有字段
Field ageField = clazz.getDeclaredField("age");
ageField.setAccessible(true);  // 绕过访问检查
int age = (int) ageField.get(p);  // 读取
ageField.set(p, 30);  // 修改

// 修改静态字段
Field staticField = clazz.getDeclaredField("COUNT");
staticField.setAccessible(true);
staticField.set(null, 100);  // 静态字段传入 null

5. 访问方法

5.1 获取方法

Class<?> clazz = Class.forName("com.example.Person");

// 获取公共方法
Method method1 = clazz.getMethod("sayHello");

// 获取带参数的方法
Method method2 = clazz.getMethod("setName", String.class);

// 获取所有公共方法
Method[] methods = clazz.getMethods();

// 获取所有方法（包括私有）
Method method3 = clazz.getDeclaredMethod("privateMethod");
Method[] allMethods = clazz.getDeclaredMethods();

5.2 调用方法

Person p = new Person("张三", 25);
Class<?> clazz = p.getClass();

// 调用无参方法
Method sayHello = clazz.getMethod("sayHello");
sayHello.invoke(p);  // 输出：Hello

// 调用带参方法
Method setName = clazz.getMethod("setName", String.class);
setName.invoke(p, "李四");  // 设置名字为李四

// 调用带返回值的方法
Method getName = clazz.getMethod("getName");
String name = (String) getName.invoke(p);  // "李四"

// 调用静态方法
Method staticMethod = clazz.getMethod("staticMethod");
staticMethod.invoke(null);  // 静态方法传入 null

// 调用私有方法
Method privateMethod = clazz.getDeclaredMethod("privateMethod");
privateMethod.setAccessible(true);
privateMethod.invoke(p);

6. 反射实战

6.1 通用对象创建工厂

public class ObjectFactory {
    public static <T> T createObject(Class<T> clazz) {
        try {
            Constructor<T> constructor = clazz.getDeclaredConstructor();
            constructor.setAccessible(true);
            return constructor.newInstance();
        } catch (Exception e) {
            throw new RuntimeException("创建对象失败", e);
        }
    }
}

// 使用
Person p = ObjectFactory.createObject(Person.class);

6.2 通用属性复制

public class BeanUtils {
    public static void copyProperties(Object src, Object dest) {
        Class<?> srcClass = src.getClass();
        Class<?> destClass = dest.getClass();

        for (Field srcField : srcClass.getDeclaredFields()) {
            try {
                String name = srcField.getName();
                Field destField = destClass.getDeclaredField(name);

                srcField.setAccessible(true);
                destField.setAccessible(true);

                Object value = srcField.get(src);
                destField.set(dest, value);
            } catch (Exception e) {
                // 忽略不匹配的属性
            }
        }
    }
}

// 使用
Person p1 = new Person("张三", 25);
Person p2 = new Person();
BeanUtils.copyProperties(p1, p2);

6.3 注解处理器

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.FIELD)
@interface MyAnnotation {
    String value();
}

public class AnnotationProcessor {
    public static void processAnnotation(Object obj) {
        Class<?> clazz = obj.getClass();

        for (Field field : clazz.getDeclaredFields()) {
            if (field.isAnnotationPresent(MyAnnotation.class)) {
                MyAnnotation anno = field.getAnnotation(MyAnnotation.class);
                System.out.println("字段：" + field.getName());
                System.out.println("注解值：" + anno.value());
            }
        }
    }
}

7. 泛型与反射

7.1 获取泛型信息

public class GenericTest {
    private List<String> list;

    public void test() throws Exception {
        Field field = this.getClass().getDeclaredField("list");
        Type type = field.getGenericType();

        if (type instanceof ParameterizedType) {
            ParameterizedType pt = (ParameterizedType) type;
            Type[] actualTypes = pt.getActualTypeArguments();

            for (Type t : actualTypes) {
                System.out.println(t.getTypeName());  // java.lang.String
            }
        }
    }
}

8. 性能优化

8.1 缓存 Class 对象

public class ClassCache {
    private static final Map<String, Class<?>> cache = new ConcurrentHashMap<>();

    public static Class<?> getClass(String className) {
        return cache.computeIfAbsent(className, name -> {
            try {
                return Class.forName(name);
            } catch (ClassNotFoundException e) {
                throw new RuntimeException(e);
            }
        });
    }
}

8.2 缓存 Method 和 Constructor

public class MethodCache {
    private static final Map<String, Method> cache = new ConcurrentHashMap<>();

    public static Method getMethod(Class<?> clazz, String name, Class<?>... params) {
        String key = clazz.getName() + "#" + name;
        return cache.computeIfAbsent(key, k -> {
            try {
                return clazz.getMethod(name, params);
            } catch (NoSuchMethodException e) {
                throw new RuntimeException(e);
            }
        });
    }
}

8.3 关闭访问检查

// 性能对比
// 正常访问：100ms
// setAccessible(true)：50ms（提升约 50%）

method.setAccessible(true);  // 关闭访问检查
method.invoke(obj, args);

9. 本章小结

核心知识点

✅ 获取 Class：forName()、.class、getClass()
✅ 创建对象：Constructor.newInstance()
✅ 访问字段：Field.get()、Field.set()
✅ 访问方法：Method.invoke()
✅ 实战应用：工厂模式、属性复制、注解处理

最佳实践

  1. 缓存 Class 对象：避免重复加载
  2. 关闭访问检查：提高性能
  3. 使用泛型：避免强制类型转换
  4. 异常处理：反射容易抛出异常
  5. 谨慎使用：性能敏感场景避免反射

性能对比

操作 直接调用 反射调用
创建对象 1x 10-100x
调用方法 1x 10-50x
访问字段 1x 10-50x
