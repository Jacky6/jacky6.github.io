18_多线程基础

1. 线程基础

1.1 什么是线程

线程（Thread）是程序执行的最小单元，一个进程可以包含多个线程。

进程 vs 线程：

特性 进程 线程
资源 独立内存空间 共享进程资源
开销 大 小
通信 复杂（IPC） 简单（共享内存）

1.2 线程生命周期

NEW → RUNNABLE → RUNNING → BLOCKED/WAITING → TERMINATED

NEW：新建状态，创建但未启动
RUNNABLE：可运行状态，等待或正在 CPU 执行
BLOCKED：阻塞状态，等待获取锁
WAITING：等待状态，无限期等待
TIMED_WAITING：超时等待状态
TERMINATED：终止状态，执行完成

2. 创建线程

2.1 继承 Thread 类

class MyThread extends Thread {
    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println(Thread.currentThread().getName() + " - " + i);
        }
    }
}

// 使用
MyThread t1 = new MyThread();
t1.start();  // 启动线程，调用 run()

2.2 实现 Runnable 接口

class MyRunnable implements Runnable {
    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println(Thread.currentThread().getName() + " - " + i);
        }
    }
}

// 使用
Thread t1 = new Thread(new MyRunnable());
t1.start();

// Lambda 简化
Thread t2 = new Thread(() -> {
    for (int i = 0; i < 5; i++) {
        System.out.println(Thread.currentThread().getName() + " - " + i);
    }
});
t2.start();

2.3 实现 Callable 接口（有返回值）

import java.util.concurrent.Callable;
import java.util.concurrent.FutureTask;

class MyCallable implements Callable<Integer> {
    @Override
    public Integer call() throws Exception {
        int sum = 0;
        for (int i = 1; i <= 100; i++) {
            sum += i;
        }
        return sum;
    }
}

// 使用
FutureTask<Integer> task = new FutureTask<>(new MyCallable());
Thread t1 = new Thread(task);
t1.start();

// 获取返回值
Integer result = task.get();  // 阻塞等待结果
System.out.println("结果：" + result);  // 5050

2.4 四种方式对比

方式 优点 缺点 推荐
Thread 简单 不能继承其他类 ❌
Runnable 可继承、可共享 无返回值 ⭐⭐
Callable 有返回值、可抛异常 较复杂 ⭐⭐⭐
线程池 高效、可管理 需理解配置 ⭐⭐⭐⭐

3. 线程同步

3.1 synchronized 关键字

同步方法

class Counter {
    private int count = 0;

    public synchronized void increment() {
        count++;
    }

    public synchronized int getCount() {
        return count;
    }
}

同步代码块

class Counter {
    private int count = 0;
    private final Object lock = new Object();

    public void increment() {
        synchronized (lock) {
            count++;
        }
    }
}

3.2 volatile 关键字

class Flag {
    private volatile boolean running = true;

    public void stop() {
        running = false;
    }

    public void run() {
        while (running) {
            // 每次循环都会读取最新值
        }
    }
}

volatile 作用： - ✅ 保证可见性（一个线程修改，其他线程立即可见） - ✅ 禁止指令重排序 - ❌ 不保证原子性

3.3 ReentrantLock

import java.util.concurrent.locks.ReentrantLock;

class Counter {
    private int count = 0;
    private final ReentrantLock lock = new ReentrantLock();

    public void increment() {
        lock.lock();
        try {
            count++;
        } finally {
            lock.unlock();  // 必须释放
        }
    }
}

synchronized vs ReentrantLock：

特性 synchronized ReentrantLock
实现 JVM 层面 API 层面
锁释放 自动 手动
可中断 ❌ ✅
超时 ❌ ✅
公平锁 ❌ ✅

4. 线程池 ⭐⭐⭐

4.1 使用 Executors 创建

import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

// 固定大小线程池
ExecutorService fixedPool = Executors.newFixedThreadPool(10);

// 单线程池
ExecutorService singlePool = Executors.newSingleThreadExecutor();

// 缓存线程池
ExecutorService cachedPool = Executors.newCachedThreadPool();

// 定时任务
ScheduledExecutorService scheduledPool = Executors.newScheduledThreadPool(5);
scheduledPool.scheduleAtFixedRate(() -> {
    System.out.println("定时执行");
}, 0, 1, TimeUnit.SECONDS);

4.2 ThreadPoolExecutor（推荐）

import java.util.concurrent.*;

ThreadPoolExecutor executor = new ThreadPoolExecutor(
    5,                      // corePoolSize：核心线程数
    10,                     // maximumPoolSize：最大线程数
    60L,                    // keepAliveTime：空闲线程存活时间
    TimeUnit.SECONDS,       // 时间单位
    new ArrayBlockingQueue<>(100),  // workQueue：任务队列
    new ThreadPoolExecutor.CallerRunsPolicy()  // handler：拒绝策略
);

executor.submit(() -> {
    System.out.println("任务执行");
});

executor.shutdown();

参数说明：

任务提交流程：
1. 核心线程数未满 → 创建新线程
2. 核心线程已满 → 加入队列
3. 队列已满 → 创建非核心线程
4. 达到最大线程 → 触发拒绝策略

拒绝策略： - AbortPolicy：抛异常（默认） - CallerRunsPolicy：调用者线程执行 - DiscardPolicy：直接丢弃 - DiscardOldestPolicy：丢弃最老任务

5. 线程通信

5.1 CountDownLatch

import java.util.concurrent.CountDownLatch;

CountDownLatch latch = new CountDownLatch(3);

// 线程 1
new Thread(() -> {
    System.out.println("任务 1 完成");
    latch.countDown();
}).start();

// 线程 2
new Thread(() -> {
    System.out.println("任务 2 完成");
    latch.countDown();
}).start();

// 线程 3
new Thread(() -> {
    System.out.println("任务 3 完成");
    latch.countDown();
}).start();

// 主线程等待
latch.await();
System.out.println("所有任务完成");

5.2 CyclicBarrier

import java.util.concurrent.CyclicBarrier;

CyclicBarrier barrier = new CyclicBarrier(3, () -> {
    System.out.println("所有线程到达，执行屏障动作");
});

for (int i = 0; i < 3; i++) {
    new Thread(() -> {
        System.out.println("线程到达");
        try {
            barrier.await();
        } catch (Exception e) {
            e.printStackTrace();
        }
        System.out.println("继续执行");
    }).start();
}

6. 经典问题

6.1 生产者 - 消费者

class ProducerConsumer {
    private final Queue<Integer> queue = new LinkedList<>();
    private final int LIMIT = 10;
    private final Object lock = new Object();

    class Producer implements Runnable {
        public void run() {
            int value = 0;
            while (true) {
                synchronized (lock) {
                    while (queue.size() == LIMIT) {
                        try { lock.wait(); } catch (InterruptedException e) {}
                    }
                    queue.offer(value++);
                    lock.notifyAll();
                }
            }
        }
    }

    class Consumer implements Runnable {
        public void run() {
            while (true) {
                synchronized (lock) {
                    while (queue.isEmpty()) {
                        try { lock.wait(); } catch (InterruptedException e) {}
                    }
                    queue.poll();
                    lock.notifyAll();
                }
            }
        }
    }
}

6.2 单例模式（双重检查）

class Singleton {
    private static volatile Singleton instance;

    private Singleton() {}

    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}

7. 本章小结

核心知识点

✅ 创建线程：Thread、Runnable、Callable、线程池
✅ 线程同步：synchronized、volatile、ReentrantLock
✅ 线程通信：CountDownLatch、CyclicBarrier
✅ 线程池：Executors、ThreadPoolExecutor

最佳实践

  1. 优先使用线程池，不要手动创建线程
  2. 优先使用并发工具类（ConcurrentHashMap、CountDownLatch）
  3. 避免死锁：按顺序获取锁、使用 tryLock
  4. 合理设置线程池参数：CPU 密集 vs IO 密集
