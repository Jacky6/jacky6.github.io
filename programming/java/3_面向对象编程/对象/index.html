对象具有状态、行为和标识。

  1. 万物皆对象。你可以把对象想象为一种神奇的变量，它可以存储数据，同时你可以“发出请求”，让它执行一些操作。对于你想要解决的问题中的任何元素，你都可以在程序中用对象来呈现（比如狗、建筑、服务等）。
  2. 一段程序实际上就是多个对象通过发送消息来通知彼此要干什么。当你向一个对象“发送消息”时，实际情况是你发送了一个请求去调用该对象的某个方法。
  3. 从内存角度而言，每一个对象都是由其他更为基础的对象组成的。换句话说，通过将现有的几个对象打包在一起，你就创建了一种新的对象。这种做法展现了对象的简单性，同时隐藏了程序的复杂性。
  4. 每一个对象都有类型。具体而言，每一个对象都是通过某个类生成的实例，这里说的“类”就（几乎）等同于“类型”。一个类最为显著的特性是“你可以发送什么消息给它。
  5. 同一类型的对象可以接收相同的消息。举例来说，因为一个“圆形”对象同样也是一个“形状”对象，所以“圆形”也可以接收“形状”类型的消息。这就意味着，你为“形状”对象编写的代码自然可以适用于任何的“形状”子类对象。这种可替换性是面向对象编程的一个基石。

访问控制（访问修饰符：access specifier）

  • public: 表示定义的内容可以被所有人访问。
  • privated: 标识定义的内容只能通过该类自身的方法访问。
  • protected: 类似privated，区别是继承的子类可以访问protected成员，但是不可以访问privated成员。
  • 包访问（package access）：如果不使用上述任意一种访问修饰符，Java 会提供一种”默认“ 访问权限，通常称作“包访问”。意思是一个类可以访问同一个包内（库组建）的其他类，但是如果从外部访问这些类的话，它们就像privated一样不可访问。
