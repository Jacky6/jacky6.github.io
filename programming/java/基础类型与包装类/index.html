在 Java 中，包装类（Wrapper Class） 是为基本数据类型（如 int、float、boolean 等）提供面向对象特性的类。Java 中共有 8 个基本数据类型，也对应有 8 个包装类，如下：

基本数据类型 包装类
byte Byte
short Short
int Integer
long Long
float Float
double Double
char Character
boolean Boolean

🎯 包装类的主要作用

1. 让基本类型具有对象特性

Java 是一种面向对象的语言，很多操作和结构（如集合类）只能处理对象，不能直接使用基本类型。

✅ 示例：集合类只支持对象 

List<Integer> list = new ArrayList<>();
list.add(10); // 自动装箱：int -> Integer

如果没有包装类，就无法将基本类型放入 ArrayList、HashMap 等集合中。

2. 支持泛型

Java 的泛型机制不支持基本类型，所以必须使用对应的包装类。

✅ 示例：

Map<String, Integer> map = new HashMap<>();
map.put("age", 25);

这里 Integer 是必需的，不能用 int。

3. 自动装箱与拆箱

从 Java 5 开始，Java 提供了自动装箱（Autoboxing） 和 自动拆箱（Unboxing） 功能，简化了基本类型与包装类之间的转换。

✅ 示例：

Integer a = 10;   // 自动装箱：int -> Integer
int b = a;        // 自动拆箱：Integer -> int

4. 提供更多实用方法

每个包装类都提供了许多静态方法来解析字符串、比较数值、进行进制转换等。

✅ 示例：

int num = Integer.parseInt("123");      // 将字符串转为整数
double d = Double.parseDouble("3.14");
String hex = Integer.toHexString(255);  // 转十六进制字符串

5. 可以表示 null 值

基本类型不能为 null，而包装类允许值为 null，这在数据库映射、可选值、空状态判断等场景非常有用。

✅ 示例：

Integer age = null;
if (age == null) {
    System.out.println("年龄未知");
}

🔁 基本类型 vs 包装类对比

特性 基本类型 包装类
是否是对象 否 是
是否支持泛型 否 是
是否能为 null 否 是
性能 更快、更省内存 相对慢一些
默认值 有（如 0, false） 初始为 null

✅ 总结

包装类的作用主要体现在以下几点：

  • 允许基本类型参与面向对象编程；
  • 支持集合、泛型等高级特性；
  • 提供丰富的工具方法；
  • 支持 null 表示缺失或未定义值；
  • 实现了自动装箱与拆箱，使代码更简洁。
