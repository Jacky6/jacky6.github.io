    🚀 快速开始¶

    使用 Spring Initializr 创建项目¶

    访问 start.spring.io 创建新项目：

    Project: Maven
Language: Java
Spring Boot: 3.2.x
Dependencies: Spring Web, Spring Data JPA, Spring Security

    最简 Spring Boot 应用¶

    package com.example.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@SpringBootApplication
@RestController
public class DemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }

    @GetMapping("/hello")
    public String hello() {
        return "Hello, Spring!";
    }
}

    运行应用¶

    # MacOS/Linux
./mvnw spring-boot:run

# Windows
.\mvnw.cmd spring-boot:run

# 或打包后运行
./mvnw package
java -jar target/demo-0.0.1-SNAPSHOT.jar

    访问 http://localhost:8080/hello

    🎯 学习路径¶

    入门 → Spring Boot 基础 → REST API → 数据访问 → 安全 → 测试 → 部署
       ↓
    依赖注入 (贯穿始终)

    推荐学习顺序¶

    1. 入门 → 01-Spring 简介 了解 Spring 生态系统
    2. 基础 → 02-Spring Boot 入门 创建第一个应用
    3. 核心 → 03-RESTful Web 服务 学习 Web 开发
    4. 数据 → 04-数据访问 掌握数据库操作
    5. 进阶 → 05-依赖注入 深入 IoC 容器
    6. 安全 → 06-安全认证 添加安全保护
    7. 质量 → 07-测试 编写测试用例
    8. 上线 → 08-部署与生产 部署到生产环境

    工具 说明

    📝 前置知识¶

    • ✅ Java 基础（Java 17+ 推荐）
    • ✅ 基本的 Web 知识（HTTP、REST）
    • ✅ SQL 基础（用于数据访问章节）
    • ✅ Maven 或 Gradle 基础

    版本说明¶

    本教程基于以下版本：

    • Spring Boot: 3.2.x
    • Spring Framework: 6.1.x
    • Java: 17+ (推荐 Java 21)

    ⚠️ Spring Boot 3.x 需要 Java 17 或更高版本
