    01. Spring 简介¶

    什么是 Spring？¶

    Spring Framework 是一个开源的 Java 应用框架，由 Rod Johnson 于 2003 年创建。它的核心目标是简化企业级应用开发。

    Spring 的核心理念¶

    ┌─────────────────────────────────────────────────┐
│           Spring 生态系统                        │
├─────────────────────────────────────────────────┤
│                                                 │
│   ┌─────────────┐      ┌─────────────────────┐ │
│   │ Spring Boot │ ←─── │ Spring Framework    │ │
│   │ (快速启动)   │      │ (核心容器、AOP 等)    │ │

│         ↓                       ↓               │

│   │Spring Security│    │  Spring MVC         │ │

│   └─────────────┘      └─────────────────────┘ │
│                                                 │
└─────────────────────────────────────────────────┘

    Spring 的核心特性¶

    1. 依赖注入（Dependency Injection）¶

    传统方式：对象自己创建依赖

    // ❌ 紧耦合
public class UserService {
    private UserRepository repository = new UserRepository();
}

    Spring 方式：容器注入依赖

    // ✅ 松耦合
@Service
public class UserService {
    private final UserRepository repository;

    // 通过构造函数注入
    public UserService(UserRepository repository) {
        this.repository = repository;
    }
}

    2. 面向切面编程（AOP）¶

    将横切关注点（日志、事务、安全）与业务逻辑分离：

    @Transactional  // 声明式事务管理
public void transferMoney(Account from, Account to, double amount) {
    from.withdraw(amount);
    to.deposit(amount);
}

    3. 约定优于配置¶

    Spring Boot 提供默认配置，减少 XML 和样板代码：

    // 只需一个注解，自动配置所有组件
@SpringBootApplication
public class MyApplication {
    public static void main(String[] args) {
        SpringApplication.run(MyApplication.class, args);
    }
}

    Spring 主要项目¶

    项目 说明 用途
    Spring Framework 核心框架 IoC 容器、AOP、事务等基础功能
    Spring Boot 快速启动 自动配置、内嵌服务器、生产就绪
    Spring MVC Web 框架 构建 Web 应用和 REST API
    Spring Data 数据访问 简化数据库操作（JPA、MongoDB 等）
    Spring Security 安全框架 认证、授权、防护攻击
    Spring Cloud 微服务 服务发现、配置中心、负载均衡
    Spring Batch 批处理 大规模数据处理
    Spring Integration 集成 企业应用集成模式

    为什么选择 Spring？¶

    ✅ 优势¶

    优势 说明
    生态完善 覆盖 Web、数据、安全、微服务等所有领域
    社区活跃 最大的 Java 社区，问题容易找到答案
    企业认可 全球数百万企业在使用，就业市场需求大
    易于测试 设计之初就考虑了可测试性
    模块化 按需引入，不用的功能可以不加载
    约定优于配置 Spring Boot 让新手也能快速上手

    ⚠️ 注意事项¶

    注意 说明
    学习曲线 生态系统庞大，需要时间掌握
    版本升级 Spring Boot 3.x 需要 Java 17+
    过度工程 小项目可能显得臃肿

    环境搭建¶

    1. 安装 JDK¶

    # 检查 Java 版本（需要 17+）
java -version

# 推荐安装
# - Oracle JDK 17/21
# - OpenJDK 17/21
# - Amazon Corretto 17/21

    2. 安装构建工具¶

    Maven： 

    # 检查版本
mvn -version

# 或使用项目自带的 Maven Wrapper
./mvnw -version

    Gradle： 

    # 检查版本
gradle -version

# 或使用项目自带的 Gradle Wrapper
./gradlew -version

    3. 安装 IDE¶

    IntelliJ IDEA（推荐）： - 下载：https://www.jetbrains.com/idea/ - 社区版免费，旗舰版对学生免费 - 对 Spring 支持最好

    Eclipse： - 免费开源 - 需要安装 Spring Tools 插件

    VS Code： - 轻量级 - 安装 Spring Boot Extension Pack

    创建第一个 Spring 项目¶

    方式 1：使用 Spring Initializr（推荐）¶

    1. 访问 https://start.spring.io
    2. 配置项目： 
      Project: Maven
Language: Java
Spring Boot: 3.2.x
Group: com.example
Artifact: demo
Dependencies: Spring Web
    3. 点击 "Generate" 下载项目
    4. 解压到工作目录

    方式 2：使用 IDE 创建¶

    IntelliJ IDEA： 1. File → New → Project 2. 选择 Spring Initializr 3. 配置项目信息 4. 选择依赖 5. 完成创建

    方式 3：手动创建¶

    # 创建目录结构
mkdir -p demo/src/main/java/com/example/demo
mkdir -p demo/src/main/resources

# 创建 pom.xml（Maven）
# 或 build.gradle（Gradle）

    核心注解速查¶

    注解 说明 使用位置
    @SpringBootApplication 启动类标识 主类
    @RestController REST 控制器 类
    @GetMapping GET 请求映射 方法
    @PostMapping POST 请求映射 方法
    @Service 服务层组件 类
    @Repository 数据访问组件 类
    @Autowired 自动注入依赖 字段/构造器
    @Configuration 配置类 类
    @Bean 定义 Bean 方法
    @Value 注入配置值 字段

    运行应用¶

    # 方式 1：使用 Maven
./mvnw spring-boot:run

# 方式 2：使用 Gradle
./gradlew bootRun

# 方式 3：打包后运行
./mvnw package
java -jar target/demo-0.0.1-SNAPSHOT.jar
