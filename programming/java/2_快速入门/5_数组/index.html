数组定义&初始化

  • 数组是一个对象序列或基本类型序列，其中含有的元素类型相同，用同一个标识符名字打包在了一起。数组通过方括号索引操作符（indexing operator []）来定义。
  • 如何定义一个数组：在类型名称后面加上 [] 即可，也可以将 [] 放到标识符后面。
int [] arr1; // 1. [] 放到类型名称后面
int arr2[];  // 2. [] 放到标识符后面
  • 所有数组都有一个固有成员 length，可以通过它查询数组长度，但不能对其修改。

​ Java 编译器不允许指定数组的大小，所以现在 arr1、arr2 只是对数组的引用，并没有为数组对象本身分配任何空间。要为数组对象分配存储空间，就必须进行初始化。初始化分为默认初始化、静态初始化、动态初始化

默认初始化

特点：若未显式初始化，数组元素会自动赋予默认值：

  • 基本类型：int（0）、double（0.0）、boolean（false）等。
  • 引用类型：null。
int[] arr1 = new int[3];      // arr1 = [0, 0, 0]
String[] arr2 = new String[2]; // arr2 = [null, null]

静态初始化的三种方式

  1. 采用大括号和一组值进行初始化。这种情况下，编译器负责存储的分配（相当于使用 new）。
  2. 采用以有的数组进行赋值初始化。但是这样其实只是复制了一个引用，即两个引用指向同一块内存区域，所以修改会互相影响。
  3. 采用 new 进行初始化。
int[] arr1 = {1, 2, 3}; // 1. 采用 {} 进行初始化
int[] arr2 = arr1; // 2. 赋值初始化，这里arr2和arr1其实是同一个数组的不同别名，因此通过修改arr2可以在arr1中看到
int[] arr3;
arr3 = new int[]{4, 5, 6}; // 3. 分步初始化，采用 new 进行初始化

动态初始化

  • 先声明并分配内存，在后续操作中进行初始化。
// 一维数组
int[] arr1 = new int[3]; //声明并分配内存
arr1[0] = 1;
arr1[1] = 2;
arr1[2] = 3;
// 多维数组
int[][] arr2 = new int[2][3]; // 创建2行3列的二维数组
arr2[0] = new int[]{1, 2, 3};
arr2[1] = new int[]{4, 5, 6};
// 不规则数组（交错数组）
int[][] arr3 = new int[2][];
arr3[0] = new int[2]; // 第一行 2 个元素
arr3[1] = new int[3]; // 第二行 3 个元素

使用 Arrays.fill() 方法

特点：通过 java.util.Arrays 工具类快速填充数组。

import java.util.Arrays;

int[] arr1 = new int[3];
Arrays.fill(arr1, 5); // arr1 = [5, 5, 5]

// 填充指定范围
Arrays.fill(arr1, 0, 2, 7); // arr1 = [7, 7, 5]

数组复制初始化

特点：通过 clone() 或 Arrays.copyOf() 方法复制已有数组。

int[] original = {1, 2, 3};
int[] copy1 = original.clone(); // 浅拷贝
int[] copy2 = Arrays.copyOf(original, original.length);

数组是一组对象

​ 不论哪种类型的数组，数组的标识符[] 实际上都是对某个在堆上创建的真实对象的引用，因此数组就是一种保存对其他对象的引用的对象。

  • 对象数组和基本类型数组的使用方式基本一致。唯一的区别在于，对象数组保存的是引用，而基本类型数组保存的是基本类型。

方法 返回数组

​ 在 Java 中可以直接返回一个数组，不需要担心数组的内存管理问题。例如：

// arrays/IceCreamFlavors.java
// (c)2021 MindView LLC: see Copyright.txt
// We make no guarantees that this code is fit for any purpose.
// Visit http://OnJava8.com for more book information.
// Returning arrays from methods
import java.util.*;
import static onjava.ArrayShow.*;

public class IceCreamFlavors {
  private static SplittableRandom rand =
    new SplittableRandom(47);
  static final String[] FLAVORS = {
    "Chocolate", "Strawberry", "Vanilla Fudge Swirl",
    "Mint Chip", "Mocha Almond Fudge", "Rum Raisin",
    "Praline Cream", "Mud Pie"
  };
  public static String[] flavorSet(int n) {
    if(n > FLAVORS.length)
      throw new IllegalArgumentException("Set too big");
    String[] results = new String[n];
    boolean[] picked = new boolean[FLAVORS.length];
    for(int i = 0; i < n; i++) {
      int t;
      do
        t = rand.nextInt(FLAVORS.length);
      while(picked[t]);
      results[i] = FLAVORS[t];
      picked[t] = true;
    }
    return results;
  }
  public static void main(String[] args) {
    for(int i = 0; i < 7; i++)
      show(flavorSet(3));
  }
}
/* Output:
[Praline Cream, Mint Chip, Vanilla Fudge Swirl]
[Strawberry, Vanilla Fudge Swirl, Mud Pie]
[Chocolate, Strawberry, Vanilla Fudge Swirl]
[Rum Raisin, Praline Cream, Chocolate]
[Mint Chip, Rum Raisin, Mocha Almond Fudge]
[Mocha Almond Fudge, Mud Pie, Vanilla Fudge Swirl]
[Mocha Almond Fudge, Mud Pie, Mint Chip]
*/
