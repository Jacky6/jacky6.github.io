1. JAVA 主类结构

​ Java 是面向对象的程序设计语言，java程序的基本组成单元是类，类体中包括 属性 与 方法两部分。

​ 每一个java程序都必须包含一个 main() 方法，含有 main() 方法的类被称为 主类。

以下面 First.java 文件为例

​ 文件名必须和 public 类名相同，注意：java区分大小写。

package HelloWorld;
public class First {
        static String s1 = "hello from world!";
    public static void main(String[] args) {
      String s2 = "局部变量"；
      System.out.println(s1);
    }
}
  1. 包声明

​ 语句 package HelloWorld; 声明了该类所在的包名，package 是包的关键字。

  1. 生命成员变量和局部变量

​ 通常将类的属性称为类的全局变量（成员变量），将方法中的属性称为局部变量。例如 s1 是成员变量。

  1. 编写主方法

main() 方法是类体中的主方法。public、static、void分别是main() 方法的 权限修饰符、静态修饰符和返回值修饰符。java 中程序的 main() 方法必须声明为 public static void

String[] args 是一个字符串类型的数组，它是main方法的参数。

  1. 导入 API 类

​ java 中通过 import 关键字导入依赖的类。

2. 基本数据结构

​ java 中有 8 种基本数据类型来存储数值、字符和布尔值。

  • 基本数据类型

  • 数值型

    • 整数类型（byte / short / int / long）
    • 浮点类型（float / double）

  • 字符型

  • 布尔型

2.1 整数类型

​ java 中整数数据有 3 种表示形式，分别为 十进制、八进制和十六进制。

  1. 十进制：120，0，-120

  2. 除了数字 0， 不能以 0 作为其他十进制数的开头。

  3. 八进制：必须以 0 开头，例如 0123（十进制83）

  4. 十六进制：必须以 0X 或 0x 开头，如 0x25（十进制 37）

​ 整数类型根据所占内存大小的区别，可以分为 byte、short、int 和 long 四种类型。如下：

数据类型 内存大小（8位等于1字节） 取值范围
byte 8 位 -128～127
short 16 位 -32768～32767
int 32 位 -2147483648～2147483647
long 64 位 -9223372036854775808～9223372036854775807
  • 对于 long 类型值，若赋给的值大于 int 类型最大值或小于 int 类型最小值，需要在数字后面加上 L 或 l，表示该数值为长整数，如 long num = 2147483650L

2.2 浮点类型

​ 浮点类型表示有小数部分的数值。java 中浮点类型分为 单精度浮点类型（float） 和 双精度浮点类型（double），所占空间大小和取值范围如下：

数据类型 内存大小（8位1字节） 取值范围
float 32 位 1.4E-45 ~ 3.4028235E38
double 64 位 4.9E-324 ～ 1.7976931348623157E308
  • 在默认情况下，java 中的小数都被看作 double 类型，若使用 float 类型小数，则需要在小数后面添加 F 或 f。也可以使用后缀 d 或 D 来明确这是一个 double 类型数据。

2.3 字符类型

2.3.1 char 型

​ 字符类型（char）用于存储单个字符，占用 16 位（两个字节）的内存空间。

​ 在定义字符类型变量时，需要使用单引号表示，如 's' 表示一个字符，而 "s" 表示一个字符串。

2.3.2 转义字符

​ 转义字符是一种特殊的字符变量，它以反斜杠 "\" 开头，后面跟一个或多个字符。转义字符具有特定的含义。例如：

转义字符 含义
\ddd 1~3 位八进制数据表示的字符，如 \123
\uxxxx 4 位十六进制数据表示的字符，如 \u0052
\' 单引号字符
\\ 反斜杠字符
\t 垂直制表符，将光标移动到下一个制表符的位置
\r 回车
\n 换行
\b 退格
\f 换页

2.4 布尔类型

​ 布尔类型又称逻辑类型，通过关键字 boolean 来定义布尔类型变量，只有 true 和 false 两个值。

​ 布尔值不能与整数类型进行转换。

3 变量与常量

​ 在程序执行过程中，值不能被改变的量称为常量；值可以被改变的量称为变量。

3.1 标识符和关键字

3.1.1 标识符

​ 标识符可以简单地理解为一个名字，用来表示类名、变量名、方法名、数组名、文件名的有效字符序列。

​ java 中规定标识符由任意顺序的字母、下划线（_）、美元符号（$）和数字组成，并且第一个字符不能是数字。标识符不能是 java 中的保留关键字。

3.1.2 关键字

​ 关键字是 java 中已经被赋予特定意义的一些单词，不可以用这些单词作为标识符来使用。

3.2 声明变量

​ 定义变量就是要告诉编译器（compiler）这个变量的数据类型（内存空间大小）。

int age;        // 声明 int 类型的变量
char char1 = 'r';       // 声明 char 类型的变量并赋值

​ java 中允许使用 汉字或其他语言文字作为变量名，但是建议不要这样做。

3.3 声明常量

​ 在程序运行过程中一直不会改变的量称为常量（constant），通常也被称为 final 变量。

​ java 中声明一个常量，除了要指定数据类型外，还需要通过 final 关键字进行限定。标准语法如下：

final 数据类型 常量名称[=值]
  • 常量通常使用大写字母表示。
  • 当定义的 final 变量属于 成员变量 时，必须在定义时就设定初始值，否则将会产生变编译错误。

4.6 位运算符

​ 位运算符除 “按位与”和“按位或” 外，其他只能用于处理整数的操作数。

4.6.1 按位与 &
4.6.2 按位或 |
4.6.3 按位取反 ~
4.6.4 按位异或 ^
4.6.5 移位操作
符号 含义
<< 左移：将运算符左边的操作数的二进制数据，按照运算符右边操作数指定的位数向左移动，右边移空补 0.
>> 右移：如果最高位是 0，右移空的就补 0；如果最高位是 1，右移空的位就补 1。
>>> 无符号右移：无论最高位是0还是1，左侧移空的高位都填入 0.
  • 移位运算符使用的数据类型有：byte、short、chart、int 和 long
  • 移位可以实现整数除以（右移）或乘以 （左移）2n 的效果。例如 y << 2 与 y * 4 结果相同；y >> 1 与 y/2 结果相同。

4.7 三元运算符

格式：条件式 ? 值1 : 值2

运算规则：如果条件成立（true），则整个表达式取值1，否则取 值2。

4.8 运算符优先级

  • 增量&减量运算 > 算术运算 > 比较运算 > 逻辑运算 > 赋值运算

  • 如果两个运算有相同的优先级，左边优先。

5. 数据类型转换

​ 类型转换是指一个值从一种类型更改为另外一种类型。

  • 如果从低精度类型向高精度类型转换，则永远不会溢出。
  • 如果从高精度向低精度转换，则会有信息丢失，可能失败。

5.1 隐式类型转换

​ 从低级类型向高级类型的转换，系统自动执行，称为隐式转换。

  • 涉及隐式类型转换的基本类型，按精度从低到高排列顺序为：byte < short < int < long < float < double。

  • 隐式类型转换规则如下

操作数1 的数据类型 操作数2 的数据类型 转换后的数据类型
byte、short、char int int
byte、short、char、int long long
byte、short、char、int、long float float
byte、short、char、int、long、float double double

5.2 显式类型转换

​ 当把高精度的变量值赋给低精度的变量时，必须使用显式类型转换（又称为强制转换）。语法如下

(类型名)要转换的值
  • 执行显示转换时，可能会导致精度损失。
  • 除 boolean 类型以外其他基本类型，都可以显式类型的方式转换。
  • 当把一个整数赋值给一个 byte、short、int、long 类型变量时，不可以超出这些变量的范围，否则必须进行强制类型转换。例如 byte b = (byte)129
