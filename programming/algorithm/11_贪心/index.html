贪心算法（Greedy Algorithm）知识点

1. 概述

贪心算法是一种在每一步选择中都采取当前状态下最优选择的算法。

核心思想

  • 局部最优：每一步都选当前最好的
  • 希望导致全局最优：局部最优解 → 全局最优解
  • 不回溯：一旦做出选择就不后悔
贪心 vs 动态规划

贪心：
  每一步选当前最优，一条路走到底
  快，但不一定能得到最优解

动态规划：
  考虑所有可能，选全局最优
  慢，但一定能得到最优解

适用场景

✅ 贪心选择性质：局部最优能导致全局最优
✅ 最优子结构：大问题的最优解包含子问题的最优解
⚠️ 需要证明：贪心策略的正确性

2. 基础贪心问题 ⭐

2.1 分配饼干

def findContentChildren(g: List[int], s: List[int]) -> int:
    """
    LeetCode 455：分配饼干

    g: 孩子的胃口值
    s: 饼干尺寸
    每个孩子最多一块饼干，饼干尺寸 >= 胃口才能满足

    贪心策略：
    1. 用小饼干满足小胃口（不浪费）
    2. 排序后双指针
    """
    g.sort()  # 孩子胃口
    s.sort()  # 饼干尺寸

    child = cookie = 0

    while child < len(g) and cookie < len(s):
        if s[cookie] >= g[child]:
            # 这块饼干能满足这个孩子
            child += 1
        # 无论是否满足，饼干都用掉了
        cookie += 1

    return child


# 示例
g = [1, 2, 3]
s = [1, 1]
print(findContentChildren(g, s))  # 1

g = [1, 2]
s = [1, 2, 3]
print(findContentChildren(g, s))  # 2

2.2 分发糖果

def candy(ratings: List[int]) -> int:
    """
    LeetCode 135：分发糖果

    规则：
    1. 每个孩子至少 1 颗糖果
    2. 相邻孩子中，评分高的必须获得更多糖果

    贪心策略：
    1. 从左到右：右边评分高 → 糖果多
    2. 从右到左：左边评分高 → 糖果多
    3. 取两次遍历的最大值
    """
    n = len(ratings)
    candies = [1] * n

    # 从左到右
    for i in range(1, n):
        if ratings[i] > ratings[i - 1]:
            candies[i] = candies[i - 1] + 1

    # 从右到左
    for i in range(n - 2, -1, -1):
        if ratings[i] > ratings[i + 1]:
            candies[i] = max(candies[i], candies[i + 1] + 1)

    return sum(candies)


# 示例
ratings = [1, 0, 2]
print(candy(ratings))  # 5 ([2, 1, 2])

ratings = [1, 2, 2]
print(candy(ratings))  # 4 ([1, 2, 1])

2.3 无重叠区间

def eraseOverlapIntervals(intervals: List[List[int]]) -> int:
    """
    LeetCode 435：无重叠区间

    求需要移除的最小区间数

    贪心策略：
    1. 按结束时间排序
    2. 优先保留结束早的区间（给后面留更多空间）
    """
    if not intervals:
        return 0

    # 按结束时间排序
    intervals.sort(key=lambda x: x[1])

    count = 1  # 保留的区间数
    end = intervals[0][1]

    for i in range(1, len(intervals)):
        if intervals[i][0] >= end:
            # 不重叠，可以保留
            count += 1
            end = intervals[i][1]

    return len(intervals) - count


# 示例
intervals = [[1, 2], [2, 3], [3, 4], [1, 3]]
print(eraseOverlapIntervals(intervals))  # 1（移除 [1,3]）

3. 区间问题 ⭐⭐

3.1 合并区间

def merge(intervals: List[List[int]]) -> List[List[int]]:
    """
    LeetCode 56：合并区间

    贪心策略：
    1. 按开始时间排序
    2. 遍历合并重叠区间
    """
    if not intervals:
        return []

    # 按开始时间排序
    intervals.sort(key=lambda x: x[0])

    merged = [intervals[0]]

    for interval in intervals[1:]:
        last = merged[-1]

        if interval[0] <= last[1]:
            # 重叠，合并
            last[1] = max(last[1], interval[1])
        else:
            # 不重叠，添加新区间
            merged.append(interval)

    return merged


# 示例
intervals = [[1, 3], [2, 6], [8, 10], [15, 18]]
print(merge(intervals))  # [[1, 6], [8, 10], [15, 18]]

3.2 跳跃游戏

def canJump(nums: List[int]) -> bool:
    """
    LeetCode 55：跳跃游戏

    每个位置表示能跳跃的最大长度
    判断能否到达最后一个位置

    贪心策略：
    维护能到达的最远位置
    """
    max_reach = 0

    for i, jump in enumerate(nums):
        if i > max_reach:
            # 当前位置不可达
            return False

        max_reach = max(max_reach, i + jump)

        if max_reach >= len(nums) - 1:
            return True

    return max_reach >= len(nums) - 1


# 示例
nums = [2, 3, 1, 1, 4]
print(canJump(nums))  # True

nums = [3, 2, 1, 0, 4]
print(canJump(nums))  # False

3.3 跳跃游戏 II

def jump(nums: List[int]) -> int:
    """
    LeetCode 45：跳跃游戏 II

    求到达最后位置的最少跳跃次数

    贪心策略：
    在可达范围内选择能跳最远的位置
    """
    if len(nums) <= 1:
        return 0

    jumps = 0
    current_end = 0
    farthest = 0

    for i in range(len(nums) - 1):
        farthest = max(farthest, i + nums[i])

        if i == current_end:
            # 必须跳跃了
            jumps += 1
            current_end = farthest

            if current_end >= len(nums) - 1:
                break

    return jumps


# 示例
nums = [2, 3, 1, 1, 4]
print(jump(nums))  # 2 (0→1→4)

4. 霍夫曼编码 ⭐

4.1 数据流中的第 K 大元素

import heapq

class KthLargest:
    """
    LeetCode 703：数据流中的第 K 大元素

    贪心 + 堆
    维护大小为 k 的最小堆
    """

    def __init__(self, k: int, nums: List[int]):
        self.k = k
        self.heap = nums[:k]
        heapq.heapify(self.heap)

        for num in nums[k:]:
            self.add(num)

    def add(self, val: int) -> int:
        if len(self.heap) < self.k:
            heapq.heappush(self.heap, val)
        elif val > self.heap[0]:
            heapq.heapreplace(self.heap, val)

        return self.heap[0]

4.2 前 K 个高频元素

from collections import Counter
import heapq

def topKFrequent(nums: List[int], k: int) -> List[int]:
    """
    LeetCode 347：前 K 个高频元素

    贪心 + 堆
    """
    counter = Counter(nums)

    # 维护大小为 k 的最小堆
    heap = []
    for num, freq in counter.items():
        if len(heap) < k:
            heapq.heappush(heap, (freq, num))
        elif freq > heap[0][0]:
            heapq.heapreplace(heap, (freq, num))

    return [num for freq, num in heap]


# 示例
nums = [1, 1, 1, 2, 2, 3]
k = 2
print(topKFrequent(nums, k))  # [1, 2]

5. 经典算法题

5.1 盛最多水的容器

def maxArea(height: List[int]) -> int:
    """
    LeetCode 11：盛最多水的容器

    贪心 + 双指针
    从两端向中间移动，每次移动较短的板
    """
    left, right = 0, len(height) - 1
    max_area = 0

    while left < right:
        # 计算当前面积
        h = min(height[left], height[right])
        w = right - left
        area = h * w
        max_area = max(max_area, area)

        # 移动较短的板
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1

    return max_area


# 示例
height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
print(maxArea(height))  # 49

5.2 加油站

def canCompleteCircuit(gas: List[int], cost: List[int]) -> int:
    """
    LeetCode 134：加油站

    判断能否绕环路行驶一周

    贪心策略：
    1. 如果总油量 < 总消耗，肯定不行
    2. 从某个起点开始，如果到不了下一站，说明起点到当前点之间的任何点都不行
    """
    if sum(gas) < sum(cost):
        return -1

    start = 0
    tank = 0

    for i in range(len(gas)):
        tank += gas[i] - cost[i]

        if tank < 0:
            # 从 start 到 i 都不可行
            start = i + 1
            tank = 0

    return start


# 示例
gas = [1, 2, 3, 4, 5]
cost = [3, 4, 5, 1, 2]
print(canCompleteCircuit(gas, cost))  # 3

5.3 单调递增的数字

def monotoneIncreasingDigits(n: int) -> int:
    """
    LeetCode 738：单调递增的数字

    找到小于等于 n 的最大单调递增数字

    贪心策略：
    从左到右找到第一个下降的位置，将该位减 1，后面全变为 9
    """
    s = list(str(n))
    n_len = len(s)

    # 找到第一个下降的位置
    marker = n_len
    for i in range(n_len - 1, 0, -1):
        if s[i] < s[i - 1]:
            marker = i
            s[i - 1] = str(int(s[i - 1]) - 1)

    # marker 之后全变为 9
    for i in range(marker, n_len):
        s[i] = '9'

    return int(''.join(s))


# 示例
n = 332
print(monotoneIncreasingDigits(n))  # 299

5.4 摆动序列

def wiggleMaxLength(nums: List[int]) -> int:
    """
    LeetCode 376：摆动序列

    求最长摆动子序列的长度

    贪心策略：
    只统计峰值（局部最大/最小）
    """
    if len(nums) < 2:
        return len(nums)

    up = down = 1

    for i in range(1, len(nums)):
        if nums[i] > nums[i - 1]:
            up = down + 1
        elif nums[i] < nums[i - 1]:
            down = up + 1

    return max(up, down)


# 示例
nums = [1, 7, 4, 9, 2, 5]
print(wiggleMaxLength(nums))  # 6 ([1, 7, 4, 9, 2, 5])

6. 贪心证明技巧

6.1 交换论证

思想：假设存在更优解，通过交换操作导出矛盾。

示例：活动选择问题

问题：选择最多的互不重叠的活动

贪心策略：按结束时间排序，优先选结束早的

证明：
1. 假设贪心解不是最优，存在更优解 O
2. 设贪心解为 G，第一个不同的活动为 a_i 和 o_i
3. 由于贪心选结束最早的，所以 a_i.end <= o_i.end
4. 用 a_i 替换 o_i，仍然可行且活动数不变
5. 逐步替换，可将 O 转换为 G
6. 因此 G 也是最优解

6.2 归纳法

思想：证明贪心选择后，剩余子问题仍保持最优结构。

7. 贪心 vs 动态规划

特性 贪心 动态规划
选择方式 当前最优 全局最优
回溯 不回溯 考虑所有可能
效率 O(n log n) 或 O(n) O(n²) 或 O(n³)
正确性 需证明 必然正确
适用 特殊问题 一般最优化问题 
如何判断能否用贪心？

1. 尝试证明贪心策略的正确性
2. 如果无法证明，可能需要 DP
3. 可以写暴力解验证贪心结果

9. 本章小结

核心知识点

✅ 贪心思想：局部最优 → 全局最优
✅ 区间问题：合并、调度、覆盖
✅ 贪心证明：交换论证、归纳法

重点掌握

  1. 排序 + 贪心：大多数贪心需要排序
  2. 双指针：盛水容器、两数之和
  3. 堆的应用：Top K 问题
  4. 贪心证明：理解为什么贪心有效
