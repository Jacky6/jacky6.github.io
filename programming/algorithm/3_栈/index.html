栈（Stack）知识点

1. 定义

栈是一种后进先出（LIFO - Last In First Out）的线性数据结构。

  • 只允许在一端进行插入和删除操作
  • 允许操作的一端称为栈顶（Top）
  • 另一端称为栈底（Bottom）
  • 不含元素的空表称为空栈
    ↑ 栈顶 (Top)
    │
┌───┐
│ C │  ← 最后压入，最先弹出
├───┤
│ B │
├───┤
│ A │  ← 最先压入，最后弹出
└───┘
    │
    ↓ 栈底 (Bottom)

2. 基本操作

操作 描述 时间复杂度
push(x) 将元素 x 压入栈顶 O(1)
pop() 弹出栈顶元素 O(1)
top() / peek() 返回栈顶元素（不弹出） O(1)
isEmpty() 判断栈是否为空 O(1)
size() 返回栈中元素个数 O(1)

3. 实现方式

3.1 数组实现（顺序栈）

class ArrayStack:
    def __init__(self, capacity=100):
        self.data = []
        self.capacity = capacity

    def push(self, x):
        if len(self.data) >= self.capacity:
            raise Exception("Stack overflow")
        self.data.append(x)

    def pop(self):
        if self.is_empty():
            raise Exception("Stack underflow")
        return self.data.pop()

    def top(self):
        if self.is_empty():
            raise Exception("Stack is empty")
        return self.data[-1]

    def is_empty(self):
        return len(self.data) == 0

    def size(self):
        return len(self.data)

3.2 链表实现（链式栈）

class Node:
    def __init__(self, val):
        self.val = val
        self.next = None

class LinkedStack:
    def __init__(self):
        self.head = None
        self._size = 0

    def push(self, x):
        node = Node(x)
        node.next = self.head
        self.head = node
        self._size += 1

    def pop(self):
        if self.is_empty():
            raise Exception("Stack underflow")
        val = self.head.val
        self.head = self.head.next
        self._size -= 1
        return val

    def top(self):
        if self.is_empty():
            raise Exception("Stack is empty")
        return self.head.val

    def is_empty(self):
        return self.head is None

    def size(self):
        return self._size

4. 时间复杂度分析

操作 数组实现 链表实现
push O(1)* O(1)
pop O(1) O(1)
top O(1) O(1)
空间 O(n) O(n)

*数组实现动态扩容时摊还 O(1)

5. 应用场景（详解）

5.1 括号匹配 ✅

问题：判断字符串中的括号是否有效配对

核心思想： - 左括号入栈 - 右括号与栈顶匹配 - 最终栈应为空

def isValid(s: str) -> bool:
    # 奇数长度直接返回 False
    if len(s) % 2 == 1:
        return False

    stack = []
    mapping = {')': '(', '}': '{', ']': '['}

    for char in s:
        if char in mapping:
            # 右括号：检查栈顶
            if not stack or stack.pop() != mapping[char]:
                return False
        else:
            # 左括号：入栈
            stack.append(char)

    return not stack

# 测试
print(isValid("()[]{}"))      # True
print(isValid("([)]"))        # False
print(isValid("{[]}"))        # True

变体： - 生成有效括号组合（回溯 + 栈） - 最长有效括号子串（栈存索引） - 最少添加使括号有效

5.2 表达式求值 🧮

（1）中缀转后缀（逆波兰表示）

中缀表达式：3 + 4 × 2（人类习惯）
后缀表达式：3 4 2 × +（计算机友好）

转换算法（Shunting Yard）：

def infixToPostfix(expression):
    precedence = {'+': 1, '-': 1, '*': 2, '/': 2, '^': 3}
    output = []
    stack = []

    for token in expression.split():
        if token.isdigit():  # 操作数
            output.append(token)
        elif token == '(':
            stack.append(token)
        elif token == ')':
            while stack and stack[-1] != '(':
                output.append(stack.pop())
            stack.pop()  # 弹出 '('
        else:  # 运算符
            while (stack and stack[-1] != '(' and 
                   precedence.get(stack[-1], 0) >= precedence.get(token, 0)):
                output.append(stack.pop())
            stack.append(token)

    while stack:
        output.append(stack.pop())

    return ' '.join(output)

# 测试
print(infixToPostfix("3 + 4 * 2"))  # "3 4 2 * +"

（2）后缀表达式求值

def evalRPN(tokens):
    stack = []
    ops = {
        '+': lambda a, b: a + b,
        '-': lambda a, b: a - b,
        '*': lambda a, b: a * b,
        '/': lambda a, b: int(a / b),  # 向零取整
    }

    for token in tokens:
        if token in ops:
            b = stack.pop()
            a = stack.pop()
            stack.append(ops[token](a, b))
        else:
            stack.append(int(token))

    return stack[0]

# 测试
print(evalRPN(["3", "4", "2", "*", "+"]))  # 11
print(evalRPN(["10", "6", "9", "3", "+", "-11", "*", "/", "*", "17", "+", "5", "+"]))  # 22

5.3 函数调用栈 📞

原理：每次函数调用时，系统会将调用信息压入调用栈

调用栈示例：
main() 调用 fact(3)
┌─────────────────┐
│ fact(3)         │ ← 栈顶（当前执行）
├─────────────────┤
│ fact(2)         │
├─────────────────┤
│ fact(1)         │
├─────────────────┤
│ main()          │ ← 栈底
└─────────────────┘

fact(3) = 3 × fact(2)
fact(2) = 2 × fact(1)
fact(1) = 1 × fact(0)
fact(0) = 1  ← 开始返回

递归的栈帧包含： - 返回地址 - 参数值 - 局部变量 - 保存的寄存器

栈溢出示例：

def infinite_recursion(n):
    # 没有终止条件 → 栈溢出
    return n + infinite_recursion(n + 1)

5.4 浏览器历史记录 🌐

双栈实现：后退/前进功能

class BrowserHistory:
    def __init__(self, homepage: str):
        self.back_stack = [homepage]  # 后退栈
        self.forward_stack = []       # 前进栈

    def visit(self, url: str) -> None:
        """访问新页面，清空前进历史"""
        self.back_stack.append(url)
        self.forward_stack.clear()

    def back(self, steps: int) -> str:
        """后退 steps 步"""
        while steps > 0 and len(self.back_stack) > 1:
            self.forward_stack.append(self.back_stack.pop())
            steps -= 1
        return self.back_stack[-1]

    def forward(self, steps: int) -> str:
        """前进 steps 步"""
        while steps > 0 and self.forward_stack:
            self.back_stack.append(self.forward_stack.pop())
            steps -= 1
        return self.back_stack[-1]

# 测试
browser = BrowserHistory("leetcode.com")
browser.visit("google.com")
browser.visit("facebook.com")
print(browser.back(1))      # "google.com"
print(browser.forward(1))   # "facebook.com"

状态变化：

访问顺序：A → B → C
back_stack:  [A, B, C]
forward_stack: []

执行 back(1):
back_stack:  [A, B]
forward_stack: [C]

执行 forward(1):
back_stack:  [A, B, C]
forward_stack: []

5.5 深度优先搜索（DFS）🔍

（1）树的 DFS（递归版）

def dfs_recursive(node):
    if not node:
        return
    print(node.val)      # 前序遍历
    dfs_recursive(node.left)
    dfs_recursive(node.right)

（2）树的 DFS（显式栈版）

def dfs_iterative(root):
    if not root:
        return

    stack = [root]
    while stack:
        node = stack.pop()
        print(node.val)
        # 先右后左，保证左子树先处理
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)

（3）图的 DFS

def dfs_graph(graph, start):
    visited = set()
    stack = [start]
    result = []

    while stack:
        node = stack.pop()
        if node not in visited:
            visited.add(node)
            result.append(node)
            # 逆序入栈，保证正序访问
            for neighbor in reversed(graph[node]):
                if neighbor not in visited:
                    stack.append(neighbor)

    return result

# 测试
graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': ['F'],
    'F': []
}
print(dfs_graph(graph, 'A'))  # ['A', 'B', 'D', 'E', 'F', 'C']

应用场景： - 路径查找 - 连通分量 - 拓扑排序 - 迷宫求解

5.6 单调栈 📊

定义：栈内元素保持单调递增或递减

模板代码

# 单调递减栈（找下一个更大元素）
def nextGreaterElement(nums):
    n = len(nums)
    res = [-1] * n
    stack = []  # 存索引

    for i in range(n):
        # 当前元素比栈顶大 → 找到栈顶的下一个更大元素
        while stack and nums[stack[-1]] < nums[i]:
            idx = stack.pop()
            res[idx] = nums[i]
        stack.append(i)

    return res

# 测试
print(nextGreaterElement([2, 1, 2, 4, 3]))  # [4, 2, 4, -1, -1]

经典问题对比

问题 栈类型 触发条件
下一个更大元素 单调递减 当前 > 栈顶
接雨水 单调递减 当前 > 栈顶
最大矩形 单调递增 当前 < 栈顶
每日温度 单调递减 当前 > 栈顶

接雨水详解

def trap(height):
    stack = []  # 存索引，单调递减
    water = 0

    for i, h in enumerate(height):
        # 遇到更高的柱子，计算积水
        while stack and h > height[stack[-1]]:
            bottom = stack.pop()
            if not stack:
                break
            # 宽度：当前索引 - 新栈顶索引 - 1
            width = i - stack[-1] - 1
            # 高度：两侧较矮者 - 底部高度
            bound_h = min(height[stack[-1]], h) - height[bottom]
            water += width * bound_h

        stack.append(i)

    return water

# 测试
print(trap([0,1,0,2,1,0,1,3,2,1,2,1]))  # 6

可视化：

输入：[0,1,0,2,1,0,1,3,2,1,2,1]

    █
    █   █
█   █ █ █
█ █ █ █ █ █ █
0 1 0 2 1 0 1 3 2 1 2 1
    ↑ ↑ ↑   ↑ ↑
    这些位置会积水，总共 6 单位

6. 经典例题（详解）

6.1 有效的括号（LeetCode 20）⭐

题目：判断只包含 '()[]{}' 的字符串是否有效

有效条件： 1. 左括号必须用相同类型的右括号闭合 2. 左括号必须以正确的顺序闭合 3. 空字符串有效

def isValid(s: str) -> bool:
    # 优化：奇数长度直接返回
    if len(s) % 2 == 1:
        return False

    stack = []
    # 映射：右括号 → 左括号
    mapping = {')': '(', '}': '{', ']': '['}

    for char in s:
        if char in mapping:
            # 右括号：栈顶必须匹配
            top = stack.pop() if stack else '#'
            if mapping[char] != top:
                return False
        else:
            # 左括号：入栈
            stack.append(char)

    # 栈空说明全部匹配
    return not stack

# 测试用例
test_cases = [
    ("()", True),
    ("()[]{}", True),
    ("(]", False),
    ("([)]", False),
    ("{[]}", True),
    ("", True),
    ("(", False),
    ("]", False),
]

for s, expected in test_cases:
    result = isValid(s)
    status = "✓" if result == expected else "✗"
    print(f"{status} isValid('{s}') = {result}")

复杂度分析： - 时间：O(n)，遍历一次 - 空间：O(n)，最坏全左括号

易错点： - 空字符串 → True - 栈空时遇到右括号 → False - 遍历完栈非空 → False

6.2 最小栈（LeetCode 155）⭐⭐

题目：设计支持 push/pop/top/getMin 的栈，所有操作 O(1)

思路：辅助栈同步记录最小值

class MinStack:
    def __init__(self):
        self.stack = []       # 主栈
        self.min_stack = []   # 辅助栈，记录最小值

    def push(self, val: int) -> None:
        self.stack.append(val)
        # 辅助栈：保持栈顶为当前最小值
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)
        else:
            # 重复压入当前最小值，保证两栈同步
            self.min_stack.append(self.min_stack[-1])

    def pop(self) -> None:
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]

# 测试
minStack = MinStack()
minStack.push(3)
minStack.push(5)
print(minStack.getMin())  # 3
minStack.push(2)
minStack.push(1)
print(minStack.getMin())  # 1
minStack.pop()
print(minStack.getMin())  # 2

优化版本（空间更优）：

class MinStackOptimized:
    def __init__(self):
        self.stack = []
        self.min_stack = []  # 只在更小/相等时压入

    def push(self, val: int) -> None:
        self.stack.append(val)
        if not self.min_stack or val <= self.min_stack[-1]:
            self.min_stack.append(val)

    def pop(self) -> None:
        if self.stack.pop() == self.min_stack[-1]:
            self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]

两种实现对比： | 版本 | push 空间 | pop 逻辑 | 适用场景 | |------|----------|---------|---------| | 同步版 | O(n) 固定 | 简单 | 代码清晰 | | 优化版 | O(n) 最坏 | 需判断 | 节省空间 |

6.3 接雨水（LeetCode 42）⭐⭐⭐

题目：给定 n 个非负整数表示高度图，计算能接多少雨水

解法一：单调栈

def trap_stack(height):
    """
    单调递减栈：遇到更高柱子时计算积水
    """
    stack = []  # 存索引
    water = 0

    for i, h in enumerate(height):
        # 当前高度 > 栈顶高度 → 形成凹槽
        while stack and h > height[stack[-1]]:
            bottom = stack.pop()  # 凹槽底部
            if not stack:
                break
            # 左边界（栈顶）和右边界（当前）
            left = stack[-1]
            width = i - left - 1
            bound_h = min(height[left], h) - height[bottom]
            water += width * bound_h

        stack.append(i)

    return water

解法二：双指针

def trap_two_pointers(height):
    """
    预处理左右最大值，然后双指针扫描
    """
    if not height:
        return 0

    n = len(height)
    left_max = [0] * n
    right_max = [0] * n

    # 预处理
    left_max[0] = height[0]
    for i in range(1, n):
        left_max[i] = max(left_max[i-1], height[i])

    right_max[n-1] = height[n-1]
    for i in range(n-2, -1, -1):
        right_max[i] = max(right_max[i+1], height[i])

    # 计算雨水
    water = 0
    for i in range(n):
        water += min(left_max[i], right_max[i]) - height[i]

    return water

解法三：双指针优化（空间 O(1)）

def trap_optimized(height):
    left, right = 0, len(height) - 1
    left_max = right_max = 0
    water = 0

    while left < right:
        if height[left] < height[right]:
            if height[left] >= left_max:
                left_max = height[left]
            else:
                water += left_max - height[left]
            left += 1
        else:
            if height[right] >= right_max:
                right_max = height[right]
            else:
                water += right_max - height[right]
            right -= 1

    return water

题目：给定每天温度，返回等待更高温度的天数

def dailyTemperatures(temps):
    """
    单调递减栈：找到下一个更高温度
    """
    n = len(temps)
    res = [0] * n  # 默认 0（无更高温度）
    stack = []     # 存索引

    for i, t in enumerate(temps):
        # 当前温度 > 栈顶温度 → 找到答案
        while stack and temps[stack[-1]] < t:
            idx = stack.pop()
            res[idx] = i - idx  # 天数差
        stack.append(i)

    return res

6.5 柱状图中最大矩形（LeetCode 84）⭐⭐⭐

题目：给定柱状图，求最大矩形面积

def largestRectangleArea(heights):
    """
    单调递增栈：找到每个柱子能扩展的最大宽度
    """
    # 添加哨兵，简化边界处理
    heights = [0] + heights + [0]
    stack = [0]  # 存索引
    max_area = 0

    for i in range(1, len(heights)):
        # 当前高度 < 栈顶高度 → 计算栈顶的矩形
        while heights[i] < heights[stack[-1]]:
            h = heights[stack.pop()]
            # 宽度 = 右边界(i) - 左边界(新栈顶) - 1
            w = i - stack[-1] - 1
            max_area = max(max_area, h * w)
        stack.append(i)

    return max_area

6.6 最大栈（LeetCode 716）⭐⭐⭐

题目：设计支持查找/删除最大元素的栈

class MaxStack:
    """
    使用双向链表 + HashMap 实现高效操作
    """
    def __init__(self):
        self.stack = []  # (value, index)
        self.max_map = {}  # value -> [indices]

    def push(self, x: int) -> None:
        idx = len(self.stack)
        self.stack.append((x, idx))
        if x not in self.max_map:
            self.max_map[x] = []
        self.max_map[x].append(idx)

    def pop(self) -> int:
        val, idx = self.stack.pop()
        self.max_map[val].pop()
        if not self.max_map[val]:
            del self.max_map[val]
        return val

    def top(self) -> int:
        return self.stack[-1][0]

    def peekMax(self) -> int:
        return max(self.max_map.keys())

    def popMax(self) -> int:
        max_val = self.peekMax()
        idx = self.max_map[max_val].pop()
        if not self.max_map[max_val]:
            del self.max_map[max_val]

        # 标记删除（惰性删除）
        self.stack[idx] = None

        # 清理栈顶的 None
        while self.stack and self.stack[-1] is None:
            self.stack.pop()

        return max_val

# 测试
stk = MaxStack()
stk.push(5)
stk.push(1)
stk.push(5)
print(stk.top())      # 5
print(stk.popMax())   # 5（最靠近栈顶的 5）
print(stk.top())      # 1
print(stk.peekMax())  # 5
print(stk.pop())      # 1
print(stk.top())      # 5

复杂度： - push/pop/top: O(1) - peekMax: O(k)，k 为不同值的数量 - popMax: O(n)，需要清理

7.1 核心概念

（1）下一个更大元素 I（LeetCode 496）⭐

def nextGreaterElement(nums1, nums2):
    """
    nums1 是 nums2 的子集，找 nums1 中元素在 nums2 中的下一个更大元素
    """
    # 先处理 nums2，建立映射
    next_greater = {}
    stack = []

    for num in nums2:
        while stack and stack[-1] < num:
            next_greater[stack.pop()] = num
        stack.append(num)

    # 查询 nums1
    return [next_greater.get(num, -1) for num in nums1]

def nextGreaterElements(nums):
    """
    数组是循环的，最后一个元素的下一个是第一个元素
    """
    n = len(nums)
    res = [-1] * n
    stack = []

    # 遍历两遍模拟循环
    for i in range(n * 2):
        idx = i % n
        while stack and nums[stack[-1]] < nums[idx]:
            res[stack.pop()] = nums[idx]
        if i < n:
            stack.append(idx)

    return res

class StockSpanner:
    """
    计算股票价格跨度：小于等于今天价格的连续天数
    """
    def __init__(self):
        self.stack = []  # (price, span)

    def next(self, price: int) -> int:
        span = 1
        # 弹出所有小于等于当前价格的
        while self.stack and self.stack[-1][0] <= price:
            span += self.stack.pop()[1]
        self.stack.append((price, span))
        return span

（4）移除 K 位数字使剩余最小（LeetCode 402）⭐⭐⭐

def removeKdigits(num: str, k: int) -> str:
    """
    单调递增栈：保持结果最小
    """
    stack = []

    for digit in num:
        # 栈顶 > 当前数字，且还能删除 → 弹出
        while k > 0 and stack and stack[-1] > digit:
            stack.pop()
            k -= 1
        stack.append(digit)

    # 如果还有剩余删除次数，从末尾删除
    while k > 0:
        stack.pop()
        k -= 1

    # 处理前导零
    result = ''.join(stack).lstrip('0')
    return result if result else '0'

# 测试

7.4 解题技巧总结

识别单调栈的信号： 1. 找"下一个更大/更小"元素 2. 找"前一个更大/更小"元素 3. 涉及"宽度×高度"的面积问题 4. 需要知道元素左右边界

选择栈类型：

找下一个更大 → 单调递减栈
找下一个更小 → 单调递增栈
找前一个更大 → 单调递减栈
找前一个更小 → 单调递增栈

边界处理技巧： 1. 添加哨兵元素（如首尾加 0） 2. 存索引而非值 3. 循环数组：遍历 2n 次取模

常见陷阱： - 忘记处理栈中剩余元素 - 相等元素的处理（严格 vs 非严格单调） - 边界条件（空数组、单元素）

8. 总结

特性 说明
核心原则 后进先出（LIFO）
操作限制 只能在一端操作
时间复杂度 基本操作均为 O(1)
空间复杂度 O(n)
典型应用 括号匹配、表达式求值、DFS、单调栈

单调栈进阶： - 识别模式：下一个/前一个更大更小 - 选择类型：递增/递减 - 处理边界：哨兵、存索引、循环数组

关键思想：当你需要回溯、撤销、或者处理嵌套结构时，优先考虑栈！

单调栈口诀：

更大用递减，更小用递增； 存索引不存值，边界要处理； 面积问题找左右，宽度乘高度。
