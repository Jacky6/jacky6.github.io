图（Graph）知识点

1. 定义

图是由顶点（Vertex）和边（Edge）组成的数据结构。

  • 顶点（V）：节点
  • 边（E）：连接两个顶点的线段
  • 图 G = (V, E)
    A —— B
    |    |
    C —— D —— E

    顶点：{A, B, C, D, E}
    边：{(A,B), (A,C), (B,D), (C,D), (D,E)}

图的分类

类型 说明 示例
无向图 边没有方向 朋友圈
有向图 边有方向 关注关系
加权图 边有权重 地图距离
无权图 边无权重 社交网络 
无向图：A —— B        有向图：A → B
       （A-B 互通）          （A 到 B，B 不一定到 A）

加权图：A --5-- B     无权图：A —— B
       （边有权重 5）        （边无权重）

2. 图的表示

2.1 邻接矩阵

用二维数组表示，matrix[i][j] = 1 表示 i 和 j 有边。

# 无向图
#   A  B  C  D
# A 0  1  1  0
# B 1  0  0  1
# C 1  0  0  1
# D 0  1  1  0

graph = [
    [0, 1, 1, 0],  # A
    [1, 0, 0, 1],  # B
    [1, 0, 0, 1],  # C
    [0, 1, 1, 0],  # D
]

# 检查 A 和 B 是否相连
print(graph[0][1])  # 1（相连）

# 加权图（用权重代替 1）
weighted = [
    [0, 5, 3, 0],
    [5, 0, 0, 2],
    [3, 0, 0, 4],
    [0, 2, 4, 0],
]

特点： - ✅ 判断两点是否相连：O(1) - ❌ 空间复杂度：O(V²)，适合稠密图

2.2 邻接表 ⭐

用字典/列表存储每个顶点的邻居。

from typing import List, Dict, Set
from collections import defaultdict

# 无向图
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D'],
    'D': ['B', 'C', 'E'],
    'E': ['D'],
}

# 有向图
directed = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': ['D'],
    'D': ['E'],
    'E': [],
}

# 加权图
weighted = {
    'A': {'B': 5, 'C': 3},
    'B': {'A': 5, 'D': 2},
    'C': {'A': 3, 'D': 4},
    'D': {'B': 2, 'C': 4, 'E': 1},
    'E': {'D': 1},
}

class Graph:
    """图的邻接表实现"""

    def __init__(self, directed=False):
        self.directed = directed
        self.graph = defaultdict(list)

    def add_edge(self, u, v):
        """添加边"""
        self.graph[u].append(v)
        if not self.directed:
            self.graph[v].append(u)

    def add_weighted_edge(self, u, v, weight):
        """添加加权边"""
        self.graph[u].append((v, weight))
        if not self.directed:
            self.graph[v].append((u, weight))

    def neighbors(self, node):
        """获取邻居"""
        return self.graph[node]

    def __repr__(self):
        return dict(self.graph)


# 使用示例
g = Graph(directed=False)
g.add_edge('A', 'B')
g.add_edge('A', 'C')
g.add_edge('B', 'D')
g.add_edge('C', 'D')
g.add_edge('D', 'E')

print(g.neighbors('A'))  # ['B', 'C']

特点： - ✅ 空间复杂度：O(V+E)，适合稀疏图 - ✅ 遍历邻居：O(度)

3. 图的遍历 ⭐⭐⭐

3.1 DFS 深度优先搜索

def dfs_recursive(graph: Dict, start, visited=None):
    """DFS - 递归"""
    if visited is None:
        visited = set()

    visited.add(start)
    print(start, end=' ')

    for neighbor in graph[start]:
        if neighbor not in visited:
            dfs_recursive(graph, neighbor, visited)

    return visited


def dfs_iterative(graph: Dict, start):
    """DFS - 迭代（栈）"""
    visited = set()
    stack = [start]
    result = []

    while stack:
        node = stack.pop()
        if node not in visited:
            visited.add(node)
            result.append(node)
            # 逆序加入（保证正序访问）
            for neighbor in reversed(graph[node]):
                if neighbor not in visited:
                    stack.append(neighbor)

    return result


# 示例
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E'],
}

print(dfs_recursive(graph, 'A'))  # A B D E F C
print(dfs_iterative(graph, 'A'))  # A B D E F C

3.2 BFS 广度优先搜索

from collections import deque

def bfs(graph: Dict, start):
    """BFS - 队列"""
    visited = {start}
    queue = deque([start])
    result = []

    while queue:
        node = queue.popleft()
        result.append(node)

        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return result


# 示例
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E'],
}

print(bfs(graph, 'A'))  # A B C D E F

3.3 DFS vs BFS

特性 DFS BFS
数据结构 栈（递归） 队列
空间复杂度 O(H) O(W)
应用场景 路径、连通性 最短路径（无权）
遍历顺序 一条路走到黑 层层推进

4. 最短路径算法 ⭐⭐⭐

4.1 BFS 求无权图最短路径

from collections import deque
from typing import List, Dict, Optional

def shortest_path_bfs(graph: Dict, start, end):
    """
    BFS 求无权图最短路径
    """
    if start == end:
        return [start]

    visited = {start}
    queue = deque([(start, [start])])

    while queue:
        node, path = queue.popleft()

        for neighbor in graph[node]:
            if neighbor not in visited:
                if neighbor == end:
                    return path + [neighbor]
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))

    return None  # 无路径


# 示例
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E'],
}

print(shortest_path_bfs(graph, 'A', 'F'))  # ['A', 'C', 'F'] 或 ['A', 'B', 'E', 'F']

4.2 Dijkstra 算法（加权图）⭐

import heapq
from typing import Dict, List, Optional

def dijkstra(graph: Dict[str, Dict[str, int]], start: str) -> Dict[str, int]:
    """
    Dijkstra 算法：单源最短路径（无负权边）

    Args:
        graph: 邻接表 {node: {neighbor: weight}}
        start: 起始节点

    Returns:
        {node: shortest_distance}
    """
    # 初始化距离
    distances = {node: float('inf') for node in graph}
    distances[start] = 0

    # 优先队列：(距离，节点)
    heap = [(0, start)]
    visited = set()

    while heap:
        dist, node = heapq.heappop(heap)

        if node in visited:
            continue
        visited.add(node)

        # 更新邻居
        for neighbor, weight in graph[node].items():
            new_dist = dist + weight
            if new_dist < distances[neighbor]:
                distances[neighbor] = new_dist
                heapq.heappush(heap, (new_dist, neighbor))

    return distances


def dijkstra_with_path(graph: Dict[str, Dict[str, int]], start: str, end: str):
    """Dijkstra 求最短路径（带路径）"""
    distances = {node: float('inf') for node in graph}
    distances[start] = 0
    previous = {node: None for node in graph}

    heap = [(0, start)]
    visited = set()

    while heap:
        dist, node = heapq.heappop(heap)

        if node in visited:
            continue
        visited.add(node)

        if node == end:
            break

        for neighbor, weight in graph[node].items():
            new_dist = dist + weight
            if new_dist < distances[neighbor]:
                distances[neighbor] = new_dist
                previous[neighbor] = node
                heapq.heappush(heap, (new_dist, neighbor))

    # 重建路径
    path = []
    current = end
    while current:
        path.append(current)
        current = previous[current]
    path.reverse()

    return distances[end], path if distances[end] != float('inf') else None


# 示例
graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {'B': 5, 'C': 1},
}

print(dijkstra(graph, 'A'))  # {'A': 0, 'B': 1, 'C': 3, 'D': 4}
print(dijkstra_with_path(graph, 'A', 'D'))  # (4, ['A', 'B', 'C', 'D'])

4.3 Floyd-Warshall 算法（多源最短路径）

def floyd_warshall(graph: List[List[int]]) -> List[List[int]]:
    """
    Floyd-Warshall 算法：所有节点对之间的最短路径

    Args:
        graph: 邻接矩阵，graph[i][j] 表示 i 到 j 的距离
               无边用 float('inf')，自己到自己用 0

    Returns:
        距离矩阵
    """
    n = len(graph)
    dist = [row[:] for row in graph]  # 复制

    for k in range(n):
        for i in range(n):
            for j in range(n):
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

    return dist


# 示例
INF = float('inf')
graph = [
    [0, 3, INF, 5],
    [2, 0, INF, 4],
    [INF, 1, 0, INF],
    [INF, INF, 2, 0],
]

result = floyd_warshall(graph)
for row in result:
    print(row)

5. 最小生成树 ⭐

5.1 Prim 算法

import heapq

def prim(graph: Dict[str, Dict[str, int]], start: str) -> List[tuple]:
    """
    Prim 算法：最小生成树

    Args:
        graph: 邻接表 {node: {neighbor: weight}}
        start: 起始节点

    Returns:
        [(u, v, weight), ...] 最小生成树的边
    """
    mst = []
    visited = {start}
    edges = []

    # 加入起始节点的所有边
    for neighbor, weight in graph[start].items():
        heapq.heappush(edges, (weight, start, neighbor))

    while edges:
        weight, u, v = heapq.heappop(edges)

        if v in visited:
            continue

        visited.add(v)
        mst.append((u, v, weight))

        # 加入新节点的所有边
        for neighbor, w in graph[v].items():
            if neighbor not in visited:
                heapq.heappush(edges, (w, v, neighbor))

    return mst


# 示例
graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {'B': 5, 'C': 1},
}

print(prim(graph, 'A'))  # [('A', 'B', 1), ('B', 'C', 2), ('C', 'D', 1)]

5.2 Kruskal 算法

class UnionFind:
    """并查集"""

    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False

        # 按秩合并
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True


def kruskal(nodes: List[str], edges: List[tuple]) -> List[tuple]:
    """
    Kruskal 算法：最小生成树

    Args:
        nodes: 节点列表
        edges: 边列表 [(u, v, weight), ...]

    Returns:
        最小生成树的边
    """
    # 边按权重排序
    edges.sort(key=lambda x: x[2])

    # 节点映射到索引
    node_to_idx = {node: i for i, node in enumerate(nodes)}
    uf = UnionFind(len(nodes))

    mst = []
    for u, v, weight in edges:
        if uf.union(node_to_idx[u], node_to_idx[v]):
            mst.append((u, v, weight))

    return mst


# 示例
nodes = ['A', 'B', 'C', 'D']
edges = [
    ('A', 'B', 1),
    ('A', 'C', 4),
    ('B', 'C', 2),
    ('B', 'D', 5),
    ('C', 'D', 1),
]

print(kruskal(nodes, edges))  # [('A', 'B', 1), ('C', 'D', 1), ('B', 'C', 2)]

6. 拓扑排序 ⭐

from collections import deque, defaultdict

def topological_sort(graph: Dict[str, List[str]]) -> List[str]:
    """
    拓扑排序（Kahn 算法）

    适用于：有向无环图（DAG）
    """
    # 计算入度
    in_degree = defaultdict(int)
    for node in graph:
        if node not in in_degree:
            in_degree[node] = 0
        for neighbor in graph[node]:
            in_degree[neighbor] += 1

    # 入度为 0 的节点入队
    queue = deque([node for node in in_degree if in_degree[node] == 0])
    result = []

    while queue:
        node = queue.popleft()
        result.append(node)

        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    # 检查是否有环
    if len(result) != len(in_degree):
        return []  # 有环，无法拓扑排序

    return result


# 示例（课程安排）
# 0 → 1 → 3
#  ↓   ↑
#  2 ──┘
graph = {
    0: [1, 2],
    1: [3],
    2: [1],
    3: [],
}

print(topological_sort(graph))  # [0, 2, 1, 3]

7. 经典算法题

7.1 岛屿数量 ✅⭐

def numIslands(grid: List[List[str]]) -> int:
    """
    LeetCode 200：岛屿数量

    DFS 遍历
    """
    if not grid:
        return 0

    m, n = len(grid), len(grid[0])
    count = 0

    def dfs(i, j):
        if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] != '1':
            return
        grid[i][j] = '0'  # 标记为已访问
        dfs(i+1, j)
        dfs(i-1, j)
        dfs(i, j+1)
        dfs(i, j-1)

    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                dfs(i, j)
                count += 1

    return count

7.2 课程表 ✅⭐

def canFinish(numCourses: int, prerequisites: List[List[int]]) -> bool:
    """
    LeetCode 207：课程表（检测环）

    拓扑排序
    """
    graph = defaultdict(list)
    in_degree = [0] * numCourses

    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1

    queue = deque([i for i in range(numCourses) if in_degree[i] == 0])
    count = 0

    while queue:
        node = queue.popleft()
        count += 1

        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    return count == numCourses

8. 本章小结

核心知识点

✅ 图的表示：邻接矩阵、邻接表
✅ 图的遍历：DFS、BFS
✅ 最短路径：BFS（无权）、Dijkstra（加权）
✅ 最小生成树：Prim、Kruskal
✅ 拓扑排序：DAG 排序

重点掌握

  1. 邻接表实现：灵活、节省空间
  2. DFS/BFS 模板：遍历基础
  3. Dijkstra 算法：优先队列 + 贪心
  4. 拓扑排序：入度表 + 队列

时间复杂度

算法 时间复杂度 空间复杂度
DFS/BFS O(V+E) O(V)
Dijkstra O((V+E)log V) O(V)
Floyd O(V³) O(V²)
Prim O((V+E)log V) O(V)
Kruskal O(E log E) O(V)
