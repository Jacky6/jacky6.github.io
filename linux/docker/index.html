Mac 使用 colima 运行docker

ref：https://piaohua.github.io/post/docker/20231028-mac-colima/

修改docker 镜像源，

  • 此时修改 docker 配置文件是无效的，需要修改 colima 镜像源，配置文件 ~/.colima/default/colima.yaml 在文件下图位置添加源。
  • 然后重启：colima restart

docker:
  registry-mirrors:
    # 网易云
    - https://hub-mirror.c.163.com
    # 百度云
    - https://mirror.baidubce.com
    # Azure中国
    - https://dockerhub.azk8s.cn
    # 科大
    - https://docker.mirrors.ustc.edu.cn
    # 南京大学
    - https://docker.nju.edu.cn
