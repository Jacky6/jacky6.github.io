grep 是 Linux/Unix 系统中最常用、最强大的文本搜索工具之一，全称是 Global Regular Expression Print，意思是“全局正则表达式匹配并打印”。它用于在文件中查找包含指定模式（字符串或正则表达式）的行，并将这些行输出到终端或其他程序。

📌 一、基本语法

grep [选项] '搜索模式' 文件名

示例：

grep 'error' log.txt

在 log.txt 文件中查找所有包含 error 的行并打印。

🔍 二、常用选项（Options）

选项 说明
-i 忽略大小写（ignore case）
-v 反向匹配，只显示不包含模式的行（invert match）
-n 显示匹配行的行号
-r 或 -R 递归搜索目录中的所有子文件
-l 只显示包含匹配项的文件名，不显示具体内容
-c 只显示匹配的行数（计数）
-w 匹配整个单词，而非部分字符串
-A N 显示匹配行及其后 N 行（After）
-B N 显示匹配行及其前 N 行（Before）
-C N 显示匹配行前后各 N 行（Context）
-E 使用扩展正则表达式（相当于 egrep）
-F 将模式视为普通字符串，不使用正则表达式（相当于 fgrep）
--color=auto 高亮显示匹配内容

🧩 三、实用示例

1. 基本搜索

grep 'hello' file.txt

查找 file.txt 中包含 hello 的行。

2. 忽略大小写

grep -i 'error' system.log

查找 system.log 中所有 error、Error、ERROR 等。

3. 显示行号

grep -n 'warning' app.log

输出格式：行号:匹配内容

4. 反向查找（排除某内容）

grep -v 'success' result.log

显示所有不包含 success 的行。

5. 统计匹配行数

grep -c 'failed' log.txt

输出匹配 failed 的总行数。

6. 只显示文件名（用于多文件搜索）

grep -l 'TODO' *.py

列出所有包含 TODO 的 Python 文件名。

7. 递归搜索整个目录

grep -r 'main()' /path/to/code/

在指定目录及其子目录中查找包含 main() 的文件。

8. 显示上下文（前后几行）

grep -C 3 'segfault' dmesg.log

显示匹配 segfault 的行及其前后各 3 行，便于分析上下文。

9. 匹配完整单词

grep -w 'root' /etc/passwd

防止把 root 匹配成 router 的一部分。

10. 使用正则表达式

grep -E '^[0-9]{3}-[0-9]{4}$' phone.txt

查找符合 123-4567 格式的电话号码。

-E 支持扩展正则（如 {}, |, + 等）

11. 多个模式匹配

grep -E 'error|warning|fail' log.txt

查找包含 error、warning 或 fail 的行。

12. 结合管道使用（与其他命令配合）

ps aux | grep 'nginx'

查找正在运行的 nginx 进程。

dmesg | grep -i 'usb'

查看内核日志中与 USB 相关的信息。

cat access.log | grep '404' | wc -l

统计 Web 日志中 404 错误的次数。

⚠️ 四、注意事项

  1. 模式要用引号包裹
    特别是含有空格或特殊字符时，避免被 shell 解析错误： bash grep 'hello world' file.txt # 正确 grep hello world file.txt # 错误（grep 会认为 world 是另一个文件名）

  2. 正则表达式与通配符区别

  3. grep 使用的是 正则表达式（regex），不是文件名通配符（wildcard）。

  4. 例如：. 表示任意字符，.* 表示任意多个字符。

  5. 性能提示

  6. 大文件搜索建议使用 -m N 限制输出前 N 行： bash grep -m 1 'start' huge_file.log # 找到第一个就停止

🧰 五、相关命令（grep 家族）

命令 说明
grep 基础版本，支持基本正则表达式
egrep 等价于 grep -E，支持扩展正则
fgrep 等价于 grep -F，快速查找固定字符串，不解析正则
pgrep 按进程名查找进程 ID（Process grep）

✅ 六、总结：grep 的核心用途

场景 命令示例
查找错误日志 grep -i 'error' *.log
排查配置项 grep -v '^#' nginx.conf（忽略注释）
审计代码 grep -r 'password' src/ --include="*.py"
分析访问日志 grep '404' access.log \| awk '{print $1}' \| sort \| uniq -c
快速定位函数 grep -n 'def login' app.py

📘 附加技巧

忽略注释和空行：

grep -v '^#' config.conf | grep -v '^$'

过滤掉以 # 开头的注释和空行。

高亮显示匹配内容（推荐）：

grep --color=auto 'pattern' file.txt

很多系统默认已启用。

📚 总结一句话：

grep 是文本处理的瑞士军刀，掌握它就等于掌握了快速定位、分析和筛选文本数据的能力。

如果你经常处理日志、代码、配置文件，grep 是必须熟练掌握的命令之一！
