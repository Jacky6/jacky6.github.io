01_Redis 入门

Redis 是什么？为什么它如此流行？如何开始使用 Redis？

1. Redis 简介

1.1 什么是 Redis？

Redis（Remote Dictionary Server）是一个开源的、基于内存的键值对存储系统，常用作：

  • 🗄️ 数据库（Database）
  • 🚀 缓存（Cache）
  • 📨 消息中间件（Message Broker）

核心特点：

特性 说明
内存存储 数据存储在内存中，读写速度极快
数据结构丰富 支持 String、List、Hash、Set、Sorted Set 等多种数据结构
持久化 支持 RDB 和 AOF 两种持久化方式
高可用 支持主从复制、哨兵、集群
单线程 核心网络 I/O 和键值对读写由单线程完成
开源 BSD 协议，可自由使用

1.2 Redis 历史

2009 年  →  Salvatore Sanfilippo 创建 Redis
2010 年  →  VMware 赞助开发
2013 年  → Redis Labs 成立
2020 年  → Redis 6.0 发布（支持多线程 I/O）
2022 年  → Redis 7.0 发布
2024 年  → Redis 7.2+ 稳定版本

1.3 应用场景

场景 说明 使用的数据结构
缓存 热点数据缓存，减轻数据库压力 String、Hash
会话存储 用户登录 Session 存储 String（带过期时间）
排行榜 游戏积分榜、销售排行 Sorted Set
消息队列 异步任务处理 List、Stream
分布式锁 多进程/多机互斥访问 String（SETNX）
计数器 点赞数、访问量统计 String（INCR）
好友关系 共同好友、关注列表 Set（交集/并集）
地理位置 附近的人、距离计算 Geo
实时分析 UV 统计、在线用户数 HyperLogLog、Bitmap

2. 安装 Redis

2.1 Linux 安装（推荐）

方式一：包管理器安装

# Ubuntu/Debian
sudo apt update
sudo apt install redis-server redis-tools

# 启动 Redis
sudo systemctl start redis-server

# 设置开机自启
sudo systemctl enable redis-server

# 查看状态
sudo systemctl status redis-server

# CentOS/RHEL
sudo yum install epel-release
sudo yum install redis

sudo systemctl start redis
sudo systemctl enable redis

方式二：源码编译安装（获取最新版本）

# 下载源码
cd /tmp
wget https://download.redis.io/releases/redis-7.2.4.tar.gz

# 解压
tar xzf redis-7.2.4.tar.gz
cd redis-7.2.4

# 编译
make

# 安装到系统目录
sudo make install

# 验证安装
redis-server --version
# 输出：Redis server v=7.2.4 sha=00000000:0 malloc=jemalloc-5.3.0 bits=64

2.2 Docker 安装

# 拉取最新镜像
docker pull redis:latest

# 运行 Redis 容器
docker run -d \
  --name redis \
  -p 6379:6379 \
  -v /mydata/redis/data:/data \
  -v /mydata/redis/conf/redis.conf:/etc/redis/redis.conf \
  redis:latest \
  redis-server /etc/redis/redis.conf

# 进入容器
docker exec -it redis redis-cli

# 查看日志
docker logs -f redis

2.3 macOS 安装

# 使用 Homebrew
brew install redis

# 启动
brew services start redis

# 停止
brew services stop redis

# 重启
brew services restart redis

2.4 Windows 安装

⚠️ Redis 官方不支持 Windows，但有社区维护版本

# 方式一：使用 WSL（推荐）
wsl --install Ubuntu
# 然后在 WSL 中按 Linux 方式安装

# 方式二：使用 Docker Desktop
docker run -d -p 6379:6379 --name redis redis:latest

3. 配置 Redis

3.1 配置文件位置

安装方式 配置文件路径
apt/yum 安装 /etc/redis/redis.conf
源码安装 redis-7.2.4/redis.conf
Docker 挂载自定义配置文件

3.2 核心配置项

# ==================== 网络配置 ====================

# 绑定地址（默认只允许本地访问）
bind 127.0.0.1

# 生产环境建议绑定具体 IP
# bind 192.168.1.100

# 端口（默认 6379）
port 6379

# 保护模式（生产环境必须开启）
protected-mode yes

# 密码认证（生产环境必须设置）
requirepass your-strong-password

# ==================== 持久化配置 ====================

# RDB 快照
save 900 1        # 900 秒内至少 1 个 key 变化
save 300 10       # 300 秒内至少 10 个 key 变化
save 60 10000     # 60 秒内至少 10000 个 key 变化

# RDB 文件名
dbfilename dump.rdb

# 工作目录
dir /var/lib/redis

# AOF 持久化
appendonly yes
appendfilename "appendonly.aof"

# AOF 同步策略（always/everysec/no）
appendfsync everysec

# ==================== 内存配置 ====================

# 最大内存限制
maxmemory 2gb

# 内存淘汰策略
# volatile-lru：从有过期时间的数据中淘汰最近最少使用
# allkeys-lru：从所有数据中淘汰最近最少使用（推荐用于缓存）
# volatile-ttl：从有过期时间的数据中淘汰即将过期的
# noeviction：不淘汰，写操作返回错误（默认）
maxmemory-policy allkeys-lru

# ==================== 日志配置 ====================

# 日志级别（debug/verbose/notice/warning）
loglevel notice

# 日志文件路径
logfile /var/log/redis/redis-server.log

# ==================== 安全配置 ====================

# 重命名危险命令（生产环境建议）
rename-command FLUSHDB ""
rename-command FLUSHALL ""
rename-command DEBUG ""
rename-command CONFIG ""

# ==================== 客户端配置 ====================

# 最大客户端连接数
maxclients 10000

# 客户端空闲超时（秒）
timeout 300

# ==================== 主从复制 ====================

# 作为从库时配置主库地址
# replicaof <masterip> <masterport>

# 从库只读
replica-read-only yes

3.3 启动 Redis

# 使用默认配置启动
redis-server

# 指定配置文件启动
redis-server /etc/redis/redis.conf

# 后台运行
redis-server /etc/redis/redis.conf --daemonize yes

# 指定端口启动
redis-server --port 6380

# 带密码启动
redis-server --requirepass your-password

5. 第一个 Redis 程序

5.1 Python 示例

# 安装依赖
# pip install redis

import redis
import json

# 连接 Redis
r = redis.Redis(
    host='localhost',
    port=6379,
    db=0,
    password=None,  # 如果有密码则填写
    decode_responses=True  # 自动解码为字符串
)

# 测试连接
print(r.ping())  # True

# ===== String 操作 =====
# 设置字符串
r.set('name', 'Redis')
r.set('age', '25')

# 获取字符串
name = r.get('name')
print(f"name: {name}")  # Redis

# 设置过期时间（10 秒）
r.setex('temp_key', 10, 'temporary value')

# 自增
r.set('counter', 0)
r.incr('counter')      # 1
r.incrby('counter', 5) # 6

# ===== Hash 操作 =====
# 存储用户信息
user_data = {
    'name': '张三',
    'email': 'zhangsan@example.com',
    'age': '25'
}
r.hset('user:1001', mapping=user_data)

# 获取单个字段
email = r.hget('user:1001', 'email')
print(f"email: {email}")

# 获取所有字段
user = r.hgetall('user:1001')
print(f"user: {user}")

# ===== List 操作 =====
# 左侧推入
r.lpush('tasks', 'task1', 'task2', 'task3')

# 右侧弹出
task = r.rpop('tasks')
print(f"task: {task}")  # task1

# 获取列表长度
length = r.llen('tasks')
print(f"length: {length}")  # 2

# ===== Set 操作 =====
# 添加成员
r.sadd('tags', 'python', 'redis', 'database')

# 判断成员是否存在
is_member = r.sismember('tags', 'python')
print(f"is_member: {is_member}")  # True

# 获取所有成员
tags = r.smembers('tags')
print(f"tags: {tags}")

# ===== Sorted Set 操作 =====
# 添加成员和分数
r.zadd('leaderboard', {'Alice': 100, 'Bob': 85, 'Charlie': 92})

# 获取排行榜（分数从高到低）
top3 = r.zrevrange('leaderboard', 0, 2, withscores=True)
print(f"top3: {top3}")

# 获取排名
rank = r.zrevrank('leaderboard', 'Bob')
print(f"Bob rank: {rank}")  # 2

# ===== 过期时间操作 =====
# 设置键值对，10 秒后过期
r.setex('cache_key', 10, 'cached_value')

# 查看剩余生存时间
ttl = r.ttl('cache_key')
print(f"ttl: {ttl}")

# 移除过期时间
r.persist('cache_key')

# ===== 事务操作 =====
# 使用管道进行批量操作
pipe = r.pipeline()
pipe.set('a', 1)
pipe.set('b', 2)
pipe.set('c', 3)
results = pipe.execute()
print(f"results: {results}")  # [True, True, True]

# ===== 发布订阅 =====
# 订阅频道（需要在另一个终端运行）
# pubsub = r.pubsub()
# pubsub.subscribe('news')
# for message in pubsub.listen():
#     print(message)

# 发布消息
r.publish('news', 'Hello Redis!')

print("\n✅ Redis 基础操作完成！")

5.2 Java 示例（Jedis）

// Maven 依赖
// <dependency>
//     <groupId>redis.clients</groupId>
//     <artifactId>jedis</artifactId>
//     <version>5.0.0</version>
// </dependency>

import redis.clients.jedis.Jedis;
import redis.clients.jedis.JedisPool;
import redis.clients.jedis.JedisPoolConfig;
import java.util.Map;
import java.util.HashMap;

public class RedisExample {
    public static void main(String[] args) {
        // 连接池配置
        JedisPoolConfig poolConfig = new JedisPoolConfig();
        poolConfig.setMaxTotal(10);
        poolConfig.setMaxIdle(5);
        poolConfig.setMinIdle(1);

        // 创建连接池
        JedisPool pool = new JedisPool(poolConfig, "localhost", 6379);

        // 从连接池获取连接
        try (Jedis jedis = pool.getResource()) {
            // 测试连接
            System.out.println("PING: " + jedis.ping());  // PONG

            // String 操作
            jedis.set("name", "Redis");
            System.out.println("GET name: " + jedis.get("name"));

            // Hash 操作
            Map<String, String> user = new HashMap<>();
            user.put("name", "李四");
            user.put("email", "lisi@example.com");
            jedis.hset("user:1002", user);
            System.out.println("GET user: " + jedis.hgetAll("user:1002"));

            // List 操作
            jedis.lpush("queue", "job1", "job2", "job3");
            System.out.println("RPOP: " + jedis.rpop("queue"));

            // Set 操作
            jedis.sadd("skills", "Java", "Python", "Go");
            System.out.println("SMEMBERS: " + jedis.smembers("skills"));

            // Sorted Set 操作
            jedis.zadd("scores", 95.5, "Alice");
            jedis.zadd("scores", 88.0, "Bob");
            jedis.zadd("scores", 92.0, "Charlie");
            System.out.println("ZRANGE: " + jedis.zrevrangeWithScores("scores", 0, 2));

            // 设置过期时间
            jedis.setex("temp", 10, "expires in 10s");
            System.out.println("TTL: " + jedis.ttl("temp"));

        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            pool.close();
        }
    }
}

5.3 Node.js 示例（ioredis）

// npm install ioredis

const Redis = require('ioredis');

// 创建 Redis 客户端
const redis = new Redis({
  host: 'localhost',
  port: 6379,
  // password: 'your-password',
  db: 0,
});

// 连接事件
redis.on('connect', () => {
  console.log('✅ Connected to Redis');
});

redis.on('error', (err) => {
  console.error('❌ Redis error:', err);
});

async function main() {
  // String 操作
  await redis.set('name', 'Redis');
  const name = await redis.get('name');
  console.log('GET name:', name);

  // Hash 操作
  await redis.hset('user:1003', {
    name: '王五',
    email: 'wangwu@example.com',
  });
  const user = await redis.hgetall('user:1003');
  console.log('GET user:', user);

  // List 操作
  await redis.lpush('tasks', 'task1', 'task2');
  const task = await redis.rpop('tasks');
  console.log('RPOP task:', task);

  // Set 操作
  await redis.sadd('tags', 'nodejs', 'redis');
  const tags = await redis.smembers('tags');
  console.log('SMEMBERS tags:', tags);

  // Sorted Set 操作
  await redis.zadd('leaderboard', 100, 'Alice', 85, 'Bob');
  const top = await redis.zrevrange('leaderboard', 0, 1, 'WITHSCORES');
  console.log('ZRANGE:', top);

  // 设置过期时间
  await redis.setex('cache', 10, 'value');
  const ttl = await redis.ttl('cache');
  console.log('TTL:', ttl);

  // 关闭连接
  await redis.quit();
  console.log('✅ Disconnected from Redis');
}

main().catch(console.error);

练习 4：实现排行榜

# 场景：游戏积分榜

7. 常见问题（FAQ）

Q1: Redis 是单线程还是多线程？

A: Redis 的核心网络 I/O 和键值对读写是单线程的，但： - Redis 4.0+ 引入了后台线程处理删除操作 - Redis 6.0+ 引入了多线程 I/O（处理网络读写） - 持久化（RDB/AOF）使用子进程

Q2: Redis 为什么这么快？

A: 主要原因： 1. 纯内存操作 - 数据存储在内存中 2. 单线程模型 - 无线程切换和锁竞争 3. I/O 多路复用 - 使用 epoll/kqueue 4. 高效数据结构 - 针对场景优化的数据结构 5. 简单协议 - RESP 协议解析简单

Q3: Redis 和 Memcached 有什么区别？

特性 Redis Memcached
数据结构 丰富（String/List/Hash/Set/ZSet） 仅 String
持久化 支持 RDB/AOF 不支持
集群 原生支持 Cluster 需要客户端分片
事务 支持 不支持
发布订阅 支持 不支持
多线程 6.0+ 支持网络 I/O 多线程 多线程
内存管理 支持多种淘汰策略 LRU

Q4: Redis 最大能存储多少数据？

A: - 理论上限：2^32 个键（约 42 亿） - 实际限制：取决于可用内存 - 单个键最大：512MB - 建议：合理设置 maxmemory，使用内存淘汰策略

Q5: 如何保证 Redis 数据安全？

A: 1. 开启持久化 - RDB + AOF 混合 2. 设置密码 - requirepass 3. 绑定 IP - bind 指定内网 IP 4. 禁用危险命令 - rename-command 5. 主从复制 - 数据冗余 6. 定期备份 - 备份 RDB/AOF 文件
