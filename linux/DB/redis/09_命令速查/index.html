    09_命令速查¶

    Redis 常用命令分类速查表

    1. 通用命令¶

    命令 说明 时间复杂度 示例
    KEYS pattern 查找匹配的键 O(N) KEYS user:*
    SCAN cursor [MATCH pattern] [COUNT n] 迭代键 O(1) SCAN 0 MATCH user:* COUNT 100
    EXISTS key [key ...] 检查键是否存在 O(1) EXISTS key1 key2
    TYPE key 返回值类型 O(1) TYPE key
    DEL key [key ...] 删除键 O(1) DEL key1 key2
    UNLINK key [key ...] 异步删除键 O(1) UNLINK bigkey
    EXPIRE key seconds 设置过期时间 O(1) EXPIRE key 60
    EXPIREAT key timestamp 设置过期时间戳 O(1) EXPIREAT key 1711353600
    PEXPIRE key milliseconds 设置过期时间（毫秒） O(1) PEXPIRE key 60000
    TTL key 查看剩余时间（秒） O(1) TTL key
    PTTL key 查看剩余时间（毫秒） O(1) PTTL key
    PERSIST key 移除过期时间 O(1) PERSIST key
    MOVE key db 移动键到指定数据库 O(1) MOVE key 1
    RENAME key newkey 重命名键 O(1) RENAME key newkey
    RENAMENX key newkey 不存在才重命名 O(1) RENAMENX key newkey
    DBSIZE 返回键数量 O(1) DBSIZE
    RANDOMKEY 随机返回一个键 O(1) RANDOMKEY
    OBJECT ENCODING key 查看内部编码 O(1) OBJECT ENCODING key
    OBJECT IDLETIME key 查看空闲时间 O(1) OBJECT IDLETIME key
    OBJECT REFCOUNT key 查看引用计数 O(1) OBJECT REFCOUNT key

    2. String 命令¶

    命令 说明 时间复杂度 示例
    SET key value 设置字符串 O(1) SET name "Redis"
    SET key value EX seconds 设置带过期时间 O(1) SET key val EX 60
    SET key value NX 不存在才设置 O(1) SET lock val NX
    SETNX key value 不存在才设置 O(1) SETNX key val
    SETEX key seconds value 设置带过期时间 O(1) SETEX key 60 val
    GET key 获取字符串 O(1) GET name
    GETSET key value 设置并返回旧值 O(1) GETSET key val
    MSET key val [key val ...] 批量设置 O(1) MSET k1 v1 k2 v2
    MSETNX key val [key val ...] 批量设置（不存在） O(1) MSETNX k1 v1 k2 v2
    MGET key [key ...] 批量获取 O(1) MGET k1 k2 k3
    APPEND key value 追加字符串 O(1) APPEND key val
    STRLEN key 获取长度 O(1) STRLEN key
    INCR key 自增 1 O(1) INCR counter
    INCRBY key increment 自增 N O(1) INCRBY key 10
    INCRBYFLOAT key increment 自增浮点数 O(1) INCRBYFLOAT key 0.5
    DECR key 自减 1 O(1) DECR counter
    DECRBY key decrement 自减 N O(1) DECRBY key 10
    GETRANGE key start end 获取子串 O(1) GETRANGE key 0 10
    SETRANGE key offset value 设置子串 O(1) SETRANGE key 0 val
    SETBIT key offset value 设置位 O(1) SETBIT key 0 1
    GETBIT key offset 获取位 O(1) GETBIT key 0
    BITCOUNT key [start end] 统计 1 的数量 O(1) BITCOUNT key
    BITOP op destkey key [...] 位运算 O(1) BITOP AND dst k1 k2

    3. List 命令¶

    命令 说明 时间复杂度 示例
    LPUSH key val [val ...] 左侧插入 O(1) LPUSH list a b
    RPUSH key val [val ...] 右侧插入 O(1) RPUSH list a b
    LPUSHX key value 左侧插入（存在） O(1) LPUSHX list val
    RPUSHX key value 右侧插入（存在） O(1) RPUSHX list val
    LPOP key [count] 左侧弹出 O(1) LPOP list
    RPOP key [count] 右侧弹出 O(1) RPOP list
    BLPOP key [key ...] timeout 阻塞左侧弹出 O(1) BLPOP list 5
    BRPOP key [key ...] timeout 阻塞右侧弹出 O(1) BRPOP list 5
    LINDEX key index 获取指定索引 O(N) LINDEX list 0
    LLEN key 获取长度 O(1) LLEN list
    LRANGE key start stop 获取范围 O(N) LRANGE list 0 10
    LINSERT key BEFORE/AFTER pivot value 插入指定位置 O(N) LINSERT list BEFORE a b
    LSET key index value 设置指定索引 O(N) LSET list 0 val
    LREM key count value 删除指定值 O(N) LREM list 2 val
    LTRIM key start stop 截取列表 O(N) LTRIM list 0 9
    RPOPLPUSH source destination 右弹左推 O(1) RPOPLPUSH src dst
    BRPOPLPUSH source dest timeout 阻塞右弹左推 O(1) BRPOPLPUSH s d 5
    LMOVE src dst LEFT/RIGHT LEFT/RIGHT 移动元素 O(1) LMOVE s d LEFT RIGHT

    4. Hash 命令¶

    命令 说明 时间复杂度 示例
    HSET key field value 设置字段 O(1) HSET user name "张三"
    HSETNX key field value 不存在才设置 O(1) HSETNX user name val
    HMSET key f v [f v ...] 批量设置 O(1) HMSET user n v a v
    HGET key field 获取字段 O(1) HGET user name
    HMGET key field [field ...] 批量获取 O(1) HMGET user n a
    HGETALL key 获取所有字段 O(N) HGETALL user
    HKEYS key 获取所有字段名 O(N) HKEYS user
    HVALS key 获取所有值 O(N) HVALS user
    HLEN key 获取字段数量 O(1) HLEN user
    HEXISTS key field 判断字段存在 O(1) HEXISTS user name
    HDEL key field [field ...] 删除字段 O(1) HDEL user name
    HINCRBY key field increment 字段自增 O(1) HINCRBY user age 1
    HINCRBYFLOAT key field inc 字段自增浮点 O(1) HINCRBYFLOAT u a 0.5
    HSTRLEN key field 获取字段值长度 O(1) HSTRLEN user name
    HSCAN key cursor [MATCH] [COUNT] 迭代字段 O(1) HSCAN user 0 COUNT 10
    HRANDFIELD key [count] [WITHVALUES] 随机获取字段 O(1) HRANDFIELD user 5

    5. Set 命令¶

    命令 说明 时间复杂度 示例
    SADD key member [member ...] 添加成员 O(1) SADD set a b c
    SREM key member [member ...] 删除成员 O(1) SREM set a b
    SPOP key [count] 随机弹出 O(1) SPOP set 2
    SRANDMEMBER key [count] 随机获取 O(1) SRANDMEMBER set 5
    SISMEMBER key member 判断存在 O(1) SISMEMBER set a
    SMEMBERS key 获取所有成员 O(N) SMEMBERS set
    SCARD key 获取集合大小 O(1) SCARD set
    SDIFF key [key ...] 差集 O(N) SDIFF s1 s2
    SDIFFSTORE dst key [key ...] 差集并存储 O(N) SDIFFSTORE d s1 s2
    SINTER key [key ...] 交集 O(N*M) SINTER s1 s2
    SINTERSTORE dst key [key ...] 交集并存储 O(N*M) SINTERSTORE d s1 s2
    SUNION key [key ...] 并集 O(N) SUNION s1 s2
    SUNIONSTORE dst key [key ...] 并集并存储 O(N) SUNIONSTORE d s1 s2
    SMOVE source dest member 移动成员 O(1) SMOVE s1 s2 a
    SSCAN key cursor [MATCH] [COUNT] 迭代成员 O(1) SSCAN set 0 COUNT 10

    6. Sorted Set 命令¶

    命令 说明 时间复杂度 示例
    ZADD key [NX\|XX] [GT\|LT] [CH] score member 添加成员 O(logN) ZADD zset 100 a
    ZREM key member [member ...] 删除成员 O(logN) ZREM zset a b
    ZSCORE key member 获取分数 O(1) ZSCORE zset a
    ZRANK key member 获取排名（低→高） O(1) ZRANK zset a
    ZREVRANK key member 获取排名（高→低） O(1) ZREVRANK zset a
    ZCARD key 获取成员数量 O(1) ZCARD zset
    ZCOUNT key min max 统计分数范围 O(1) ZCOUNT zset 0 100
    ZRANGE key start stop [WITHSCORES] 按排名（低→高） O(logN+M) ZRANGE zset 0 10
    ZREVRANGE key start stop [WITHSCORES] 按排名（高→低） O(logN+M) ZREVRANGE zset 0 9
    ZRANGEBYSCORE key min max [WITHSCORES] 按分数（低→高） O(logN+M) ZRANGEBYSCORE z 0 100
    ZREVRANGEBYSCORE key min max [WITHSCORES] 按分数（高→低） O(logN+M) ZREVRANGEBYSCORE z 100 0
    ZINCRBY key increment member 增加分数 O(logN) ZINCRBY zset 10 a
    ZINTER key1 key2 [WEIGHTS w] 交集 O(N*K+MlogM) ZINTER z1 z2
    ZINTERSTORE dst numkeys key [...] 交集并存储 O(N*K+MlogM) ZINTERSTORE d 2 z1 z2
    ZUNION key1 key2 [WEIGHTS w] 并集 O(N*K+MlogM) ZUNION z1 z2
    ZUNIONSTORE dst numkeys key [...] 并集并存储 O(N*K+MlogM) ZUNIONSTORE d 2 z1 z2
    ZREMRANGEBYRANK key min max 删除排名范围 O(logN+M) ZREMRANGEBYRANK z 0 10
    ZREMRANGEBYSCORE key min max 删除分数范围 O(logN+M) ZREMRANGEBYSCORE z 0 100
    ZRANDMEMBER key [count] [WITHSCORES] 随机获取 O(1) ZRANDMEMBER zset 5
    ZSCAN key cursor [MATCH] [COUNT] 迭代成员 O(1) ZSCAN zset 0 COUNT 10

    7. 高级数据结构命令¶

    7.1 Bitmap¶

    命令 说明 示例
    SETBIT key offset value 设置位 SETBIT key 0 1
    GETBIT key offset 获取位 GETBIT key 0
    BITCOUNT key [start end] 统计 1 BITCOUNT key
    BITOP AND/OR/XOR/NOT dst src [...] 位运算 BITOP AND d s1 s2
    BITPOS key bit [start] [end] 查找位 BITPOS key 1

    7.2 HyperLogLog¶

    命令 说明 示例
    PFADD key element [...] 添加元素 PFADD hll a b c
    PFCOUNT key [key ...] 统计基数 PFCOUNT hll
    PFMERGE destkey sourcekey [...] 合并 PFMERGE dst s1 s2

    7.3 Geo¶

    命令 说明 示例
    GEOADD key lng lat member [...] 添加位置 GEOADD loc 116.4 39.9 bj
    GEOPOS key member [...] 获取位置 GEOPOS loc bj
    GEODIST key m1 m2 [m/km/ft/mi] 计算距离 GEODIST loc bj sh km
    GEORADIUS key x y radius m/km/ft/mi 范围查询 GEORADIUS loc x y 10 km
    GEORADIUSBYMEMBER key member radius 按成员范围 GEORADIUSBYMEMBER loc bj 10 km
    GEOHASH key member [...] 获取 Geohash GEOHASH loc bj

    7.4 Stream¶

    命令 说明 示例
    XADD key * field val [field val ...] 添加消息 XADD stream * name val
    XREAD [COUNT n] [BLOCK ms] STREAMS key id 读取消息 XREAD COUNT 1 STREAMS s 0
    XREADGROUP GROUP group consumer STREAMS key id 消费者组读取 XREADGROUP GROUP g c STREAMS s >
    XGROUP CREATE key groupname id|$ 创建消费者组 XGROUP CREATE s g 0
    XACK key group id [id ...] 确认消息 XACK s g 123-0
    XLEN key 消息数量 XLEN stream
    XRANGE key start end [COUNT n] 范围查询 XRANGE s - +
    XDEL key id [id ...] 删除消息 XDEL s 123-0
    XTRIM key MAXLEN n 修剪 XTRIM s MAXLEN 1000

    13. 常用组合操作¶

    13.1 分布式锁¶

    # 获取锁
SET lock_key unique_value NX EX 30

# 释放锁（Lua 脚本）
EVAL "if redis.call('get', KEYS[1]) == ARGV[1] then return redis.call('del', KEYS[1]) else return 0 end" 1 lock_key unique_value

    13.2 限流¶

    # 简单限流
INCR rate_limit_key
EXPIRE rate_limit_key 60

# 滑动窗口限流
ZADD rate_limit timestamp member
ZREMRANGEBYSCORE rate_limit 0 (timestamp-window)
ZCARD rate_limit

    13.3 缓存更新¶

    # Cache-Aside 读
GET key
# 未命中则读 DB 后 SETEX

# Cache-Aside 写
UPDATE database
DEL key

    14. 命令分类索引¶

    按数据结构¶

    • String: SET, GET, INCR, DECR, APPEND, STRLEN, BIT*
    • List: LPUSH, RPUSH, LPOP, RPOP, LRANGE, LLEN
    • Hash: HSET, HGET, HGETALL, HDEL, HLEN
    • Set: SADD, SREM, SMEMBERS, SISMEMBER, SINTER, SUNION
    • Sorted Set: ZADD, ZREM, ZRANGE, ZREVRANGE, ZSCORE, ZRANK
    • Stream: XADD, XREAD, XREADGROUP, XACK, XGROUP

    按功能¶

    • 连接: PING, AUTH, SELECT, QUIT
    • 数据操作: SET, GET, DEL, EXISTS
    • 过期: EXPIRE, TTL, PERSIST
    • 服务器: INFO, CONFIG, SLOWLOG
    • 持久化: SAVE, BGSAVE, BGREWRITEAOF
    • 事务: MULTI, EXEC, WATCH
    • 脚本: EVAL, EVALSHA, SCRIPT
    • 集群: CLUSTER INFO, CLUSTER NODES
    • 发布订阅: PUBLISH, SUBSCRIBE, UNSUBSCRIBE
