01. LangGraph 简介

什么是 LangGraph？

LangGraph 是 LangChain 团队推出的一个库，用于构建有状态的、多角色的应用程序。它基于图（Graph）的概念，让你能够清晰地定义和控制 AI 应用的执行流程。

核心思想

LangGraph 将应用程序建模为一个状态图（State Graph）：

┌─────────┐     ┌─────────┐     ┌─────────┐
│  Node A │ ──→ │  Node B │ ──→ │  Node C │
└─────────┘     └─────────┘     └─────────┘
     ↑                                  │
     └──────────────────────────────────┘
  • 节点（Nodes）：执行具体任务的函数（如调用 LLM、调用工具、处理数据）
  • 边（Edges）：定义节点之间的执行顺序
  • 状态（State）：在节点之间传递和共享的数据

为什么需要 LangGraph？

传统 Chain 的局限

# LangChain Chain - 线性执行
chain = prompt | model | output_parser
result = chain.invoke({"question": "..."})

Chain 适合线性流程，但无法处理： - 循环（需要多次调用 LLM） - 条件分支（根据结果选择不同路径） - 多 Agent 协作（多个角色交替执行） - 需要记忆/状态的场景

LangGraph 的优势

# LangGraph - 支持循环、分支、状态
graph = StateGraph(State)
graph.add_node("agent", agent_node)
graph.add_node("tool", tool_node)
graph.add_conditional_edges("agent", should_continue)  # 条件分支
graph.add_edge("tool", "agent")  # 循环回 agent
app = graph.compile()

适用场景： - ✅ Agent（需要循环调用工具） - ✅ 多轮对话（需要维护对话状态） - ✅ 工作流引擎（复杂的业务流程） - ✅ 多 Agent 协作（多个角色配合）

核心概念预览

概念 说明 类比
StateGraph 状态图的定义 流程图的设计稿
State 状态数据结构 全局变量/共享内存
Node 执行单元 函数/任务
Edge 执行顺序 箭头/连接线
Checkpoint 状态持久化 游戏存档点

pip install langgraph

pip install langchain langchain-core langgraph

# 常用扩展
pip install langchain-openai  # OpenAI 模型
pip install langchain-anthropic  # Anthropic 模型
pip install langgraph-checkpoint-sqlite  # SQLite 检查点

第一个 LangGraph 应用

让我们从一个最简单的例子开始：

from typing import TypedDict
from langgraph.graph import StateGraph, START, END

# 1. 定义状态
class State(TypedDict):
    value: int

# 2. 定义节点函数
def add_one(state: State) -> State:
    print(f"Adding 1 to {state['value']}")
    return {"value": state["value"] + 1}

# 3. 创建图
graph = StateGraph(State)

# 4. 添加节点
graph.add_node("add_one", add_one)

# 5. 添加边
graph.add_edge(START, "add_one")
graph.add_edge("add_one", END)

# 6. 编译图
app = graph.compile()

# 7. 运行
result = app.invoke({"value": 0})
print(result)  # {'value': 1}

代码解析

  1. 定义状态：使用 TypedDict 定义图的状态结构
  2. 定义节点：节点函数接收状态，返回状态更新
  3. 创建图：StateGraph(State) 创建状态图
  4. 添加节点：add_node(name, function) 注册节点
  5. 添加边：add_edge(from, to) 定义执行顺序
  6. 编译：compile() 准备执行
  7. 运行：invoke(input) 执行图

状态是如何更新的？

# 节点返回 {"value": 1}
# 状态从 {"value": 0} 变为 {"value": 1}

# 如果有多个键：
class State(TypedDict):
    value: int
    messages: list

# 节点返回 {"value": 5}
# 只会更新 value 键，messages 保持不变

关键理解：节点返回的是状态更新（State Update），不是完整状态。LangGraph 会自动合并更新。

可视化你的图

# 生成图的 PNG 图片
app.get_graph().draw_mermaid_png(output_file_path="graph.png")

# 或者获取 Mermaid 源码
print(app.get_graph().draw_mermaid())

Mermaid 输出示例：

graph LR
    __start__ --> add_one
    add_one --> __end__
