01. LangChain 简介

什么是 LangChain？

LangChain 是一个开源框架，提供预构建的 Agent 架构和各种集成，让你能够快速构建由大语言模型（LLM）驱动的智能 Agent 和应用程序。

官方定义

LangChain is an open source framework with a prebuilt agent architecture and integrations for any model or tool—so you can build agents that adapt as fast as the ecosystem evolves.

通俗理解

LangChain = LLM + 工具 + 记忆 + 编排

为什么需要 LangChain？

问题：直接使用 LLM 的局限

# ❌ 直接使用 LLM 的问题

from openai import OpenAI

client = OpenAI()

# 问题 1：不知道实时信息
response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "今天北京的天气如何？"}]
)
# 回答：抱歉，我不知道...（训练数据截止到 2023 年）

# 问题 2：无法执行操作
response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "帮我订一张明天去上海的机票"}]
)
# 回答：我无法帮你订票，但可以告诉你...

# 问题 3：无法访问私有数据
response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "我的邮箱里有什么重要邮件？"}]
)
# 回答：我无法访问你的邮箱...

解决：LangChain Agent

# ✅ 使用 LangChain Agent

from langchain.agents import create_agent

# 定义工具
def get_weather(city: str) -> str:
    """获取天气信息"""
    # 实际调用天气 API
    return f"{city}今天晴朗，25°C"

def search_flights(date: str, destination: str) -> str:
    """搜索航班"""
    # 实际调用航班 API
    return f"明天去{destination}的航班有：CA123, MU456..."

def check_email() -> str:
    """检查邮箱"""
    # 实际调用邮箱 API
    return "你有 3 封未读邮件..."

# 创建 Agent
agent = create_agent(
    model="claude-sonnet-4-6",
    tools=[get_weather, search_flights, check_email],
    system_prompt="You are a helpful assistant",
)

# 现在 Agent 可以：
# - 回答天气问题（调用工具获取实时数据）
# - 搜索航班（调用工具执行操作）
# - 检查邮箱（访问私有数据）

LangChain 的核心特性

1. 标准化模型接口

问题：不同 LLM 提供商有不同的 API

# ❌ 不使用 LangChain - 每个提供商代码不同

# OpenAI
from openai import OpenAI
client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4",
    messages=[...]
)
result = response.choices[0].message.content

# Anthropic
from anthropic import Anthropic
client = Anthropic()
response = client.messages.create(
    model="claude-sonnet-4-6",
    messages=[...]
)
result = response.content[0].text

# Google
from google import genai
client = genai.Client()
response = client.models.generate_content(
    model="gemini-2.0",
    contents="..."
)
result = response.text

解决：LangChain 提供统一接口

# ✅ 使用 LangChain - 统一接口

from langchain_anthropic import ChatAnthropic
from langchain_openai import ChatOpenAI
from langchain_google_genai import ChatGoogleGenerativeAI

# 所有模型使用相同的接口
model = ChatAnthropic(model="claude-sonnet-4-6")
# model = ChatOpenAI(model="gpt-4o")  # 轻松切换
# model = ChatGoogleGenerativeAI(model="gemini-2.0")

response = model.invoke([{"role": "user", "content": "Hello!"}])
print(response.content)

优势： - ✅ 避免厂商锁定 - ✅ 轻松测试不同模型 - ✅ 代码可移植 - ✅ 统一的响应格式

2. 简单易用的 Agent

# 只需 10 行代码创建 Agent
from langchain.agents import create_agent

def get_weather(city: str) -> str:
    """Get weather for a given city."""
    return f"It's always sunny in {city}!"

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=[get_weather],
    system_prompt="You are a helpful assistant",
)

agent.invoke({"messages": [{"role": "user", "content": "what is the weather in sf"}]})

3. 基于 LangGraph 构建

LangChain Agents 底层使用 LangGraph，因此自动拥有：

✅ 持久化执行（Durable execution）
   - 中断后可以从断点继续
   - 支持长时间运行的任务

✅ 流式输出（Streaming）
   - 实时查看 Agent 思考过程
   - 更好的用户体验

✅ 人机交互（Human-in-the-loop）
   - 在关键步骤等待人工确认
   - 支持审批流程

✅ 状态持久化（Persistence）
   - 保存对话历史
   - 支持跨会话继续

你不需要了解 LangGraph 的细节就能享受这些功能！

4. LangSmith 集成

# 启用 LangSmith 追踪
import os

LangSmith 提供： - 🔍 执行路径可视化 - 📊 状态转换追踪 - 📈 运行时指标 - 🐛 调试工具 - ✅ 评估框架

第一个示例

示例 1：简单的问答 Agent

from langchain.agents import create_agent

# 创建 Agent（没有工具）
agent = create_agent(
    model="claude-sonnet-4-6",
    system_prompt="You are a helpful assistant.",
)

# 运行
result = agent.invoke({
    "messages": [{"role": "user", "content": "什么是量子力学？"}]
})

print(result["messages"][-1].content)

示例 2：带工具的 Agent

from langchain.agents import create_agent

# 定义工具
def calculator(expression: str) -> str:
    """Calculate a mathematical expression."""
    try:
        result = eval(expression)
        return str(result)
    except Exception as e:
        return f"Error: {e}"

# 创建 Agent
agent = create_agent(
    model="claude-sonnet-4-6",
    tools=[calculator],
    system_prompt="You are a helpful assistant. Use the calculator tool for math.",
)

# 运行
result = agent.invoke({
    "messages": [{"role": "user", "content": "计算 (123 + 456) * 789"}]
})

print(result["messages"][-1].content)
# 输出：457659

示例 3：多工具协作

from langchain.agents import create_agent
import datetime

def get_weather(city: str) -> str:
    """Get current weather for a city."""
    # 实际应用中调用天气 API
    return f"{city}今天晴朗，25°C"

def get_time() -> str:
    """Get current time."""
    return datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")

def search_web(query: str) -> str:
    """Search the web for information."""
    # 实际应用中调用搜索 API
    return f"搜索结果：{query}的相关信息..."

# 创建 Agent
agent = create_agent(
    model="claude-sonnet-4-6",
    tools=[get_weather, get_time, search_web],
    system_prompt="You are a helpful assistant with access to tools.",
)

# 运行 - Agent 会自动选择工具
result = agent.invoke({
    "messages": [{
        "role": "user",
        "content": "现在几点了？北京天气如何？"
    }]
})

print(result["messages"][-1].content)

核心概念预览

Agent（智能体）

Agent = LLM（大脑） + 工具（双手） + 系统提示（行为准则）

┌─────────────────────────────────────────┐
│              Agent                       │
├─────────────────────────────────────────┤
│                                         │
│  输入：{"messages": [...]}              │
│       ↓                                 │
│  ┌─────────────────────────────────┐   │
│  │  LLM 思考：                      │   │
│  │  "用户需要什么？"                │   │
│  │  "我应该使用哪个工具？"          │   │
│  └─────────────────────────────────┘   │
│       ↓                                 │
│  ┌─────────────────────────────────┐   │
│  │  工具执行：                      │   │
│  │  - get_weather("北京")           │   │
│  │  - get_time()                    │   │
│  └─────────────────────────────────┘   │
│       ↓                                 │
│  ┌─────────────────────────────────┐   │
│  │  整合结果：                      │   │
│  │  "现在时间是...北京天气..."      │   │
│  └─────────────────────────────────┘   │
│       ↓                                 │
│  输出：{"messages": [...]}              │
│                                         │
└─────────────────────────────────────────┘

Tool（工具）

# 工具就是一个普通的 Python 函数
def tool_name(param1: str, param2: int) -> str:
    """工具的文档字符串。

    Args:
        param1: 参数 1 说明
        param2: 参数 2 说明

    Returns:
        返回值说明
    """
    # 工具实现
    return "结果"

# LangChain 会自动：
# 1. 解析函数签名
# 2. 提取文档字符串
# 3. 创建 LLM 可调用的格式
# 4. 处理参数验证

Message（消息）

# LangChain 使用标准的消息格式
messages = [
    {"role": "system", "content": "你是助手"},
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好！有什么可以帮助你的？"},
]

# 支持的消息类型：
# - system: 系统提示
# - user: 用户消息
# - assistant: AI 回复
# - tool: 工具调用结果
