一、张量并行

张量并行（tensor_parallel_size选项）可以将模型拆分到多个 GPU 上。

以下代码将模型拆分到 2 个 GPU 上。

llm = LLM(model="ibm-granite/granite-3.1-8b-instruct",
          tensor_parallel_size=2)

二、量化

量化模型以降低精度为代价占用更少的内存。静态量化模型可以从 HF Hub 下载（一些流行的模型可在 Neural Magic 找到），并直接使用而无需额外配置。

动态量化也通过 quantization 选项支持——更多详细信息请参阅此处。
https://docs.vllm.ai/en/latest/features/quantization/index.html#quantization-index

三、上下文长度和批量大小

可以通过限制模型的上下文长度（max_model_len 选项）和最大批量大小（max_num_seqs 选项）来进一步减少内存使用。

llm = LLM(model="adept/fuyu-8b",
          max_model_len=2048,
          max_num_seqs=2)

四、调整缓存大小

如果您的 CPU RAM 不足，请尝试以下选项： （仅限多模态模型）您可以使用环境变量（默认为 4 GiB）设置多模态输入缓存的大小 VLLM_MM_INPUT_CACHE_GIB。 （仅限 CPU 后端）您可以使用环境变量（默认 4 GiB）VLLM_CPU_KVCACHE_SPACE 设置 KV 缓存的大小。

五、性能优化和调优

您可以通过微调各种选项来潜在地提高 vLLM 的性能。更多详细信息请参阅 https://docs.vllm.ai/en/latest/configuration/optimization.html#optimization-and-tuning
